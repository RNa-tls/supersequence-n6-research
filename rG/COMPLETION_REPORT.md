# 완성(completion) 문제 — 집중 공격 보고서

브랜치 `claude/final-attack`. 이 문서는 `FINAL_ATTACK_REPORT.md` 이후의 작업입니다. **임의 n의 L_n은 여전히 열려 있습니다.**

## 1. 표준 정의 (코드와 무관하게)

**입력:** kernel `K = (R_1, …, R_k)`.
- 생략(omission) 없는 row들의 trail이며, row block이 서로 다르고 visible 순환류 집합이 서로소입니다.
- row R_i는 block 안의 호(arc)입니다. 그 상태들의 순환류가 visible이고, block의 나머지 상태가 **구멍(hole)**입니다.
- V = ∪ V(R_i), `U = (모든 순환류) ∖ V`.

**완성 후보:** kernel row block이 아닌 모든 block. 각 block은 n−1개 순환류로 된 초간선(hyperedge)입니다.

**완성:** block 집합 P로서 다음 조건을 만족하는 것입니다.
- 포함 그래프 I(K, P)가 숲(forest)입니다. 정점은 row, P의 block, 순환류이고, 간선은 row–visible 순환류와 block–그 block의 모든 순환류입니다.
- 모든 순환류를 덮습니다.
- 연결 성분이 정확히 k개이며, 각 성분에 row가 하나씩 있습니다.

**부착(attachment)과 충돌.**
- block이 이미 덮인 순환류와 정확히 하나를 공유하면 부착입니다.
- 둘 이상을 공유하면 충돌(I에 순환이 생김)입니다.

**route 실현.** 완성 하나는 길이 `CONST + ((n−2)! − (k − G))/(n−2)`인 superpermutation을 줍니다(G = kernel charge).
- 구성: 각 성분의 `T = F∘A` 순환을 row start에서 순회합니다(최종 보고서 정리 E의 일반화).
- n = 6(표준 kernel)과 n = 8, 9(외부 단어에서 추출한 forest)에서 독립 재구성으로 확인했습니다.

## 2. 증명된 정리

**C1 (순서 무관).** P가 완성인 것은 최종 집합의 I(K, P)가 위 조건을 만족하는 것과 동치입니다. 부착 순서는 언제나 존재합니다.
- 증명: row에서 시작하는 BFS 순서에서 각 block은 부모 순환류 하나로만 이미 덮인 집합과 만납니다(더 만나면 I에 순환이 있음). 역으로 부착 열은 매 단계 잎 초간선을 더하므로 숲을 유지합니다. ∎
- 따라서 최종 forest의 존재만 따지면 되고, 순서는 따질 필요가 없습니다.

**C2 (후보와 소유).**
- 완성 forest를 row에서 뿌리내리면, 각 payload block은 부모 순환류(부착)를 제외한 n−2개 순환류를 **소유**합니다. row는 자신의 visible 순환류를 소유합니다. 소유는 모든 순환류를 분할합니다.
- 따라서 다음이 성립합니다.
  - P의 모든 block은 U와 ≥ n−2개 순환류를 공유합니다("후보").
  - P가 소유하는 집합들은 U를 정확히 분할합니다.
  - `|P| = |U|/(n−2)`. 그러므로 `kernel 점수 ≡ 0 (mod n−2)`이며, 이는 Houston/Egan의 기존 조건과 같습니다.
- ∎ (부모가 유일하다는 데서 나옵니다.)

**C3 (흐름 특성화).** 다음 둘은 동치입니다.
- (a) 완성이 존재한다.
- (b) U의 정확 소유 덮개(각 선택 block이 자신의 U-순환류 중 n−2개를 소유하고, U-순환류가 n−1개인 block은 나머지 하나가 부착)가 존재하고, 부모 관계 "B → (B 부착 순환류의 소유자)"에 순환이 없다.
- (c) (b)의 덮개 위에 kernel에서 공급되는 단일 품목 흐름(각 block이 1을 흡수)이 존재한다.

증명:
- (b)⇒(a): 부모 관계가 숲이면 I는 숲이고, 계수가 성분 수 k를 줍니다.
- (a)⇒(b): C2.
- (b)⇔(c): 순환 성분 Q는 유입이 0인데 |Q|를 흡수해야 하므로 흐름이 불가능합니다. 숲에서는 부분트리 크기를 흐름으로 쓰면 됩니다. ∎
- 구현: `src/flowsat.py`. 해마다 `verify`로 숲 조건을 독립 검사했습니다.

**C4 (고아 장애물).** 어떤 c ∈ U가 후보 block에 하나도 속하지 않으면 완성은 없습니다.
- 증명서: c와, c를 포함하는 n개 block(special 하나당 하나) 각각이 kernel row block이거나 V와 ≥ 2개 순환류를 공유한다는 사실. 손으로 검사할 수 있습니다.

**C5 (매트로이드 아님).** n = 5 표준 kernel의 완성은 정확히 6개입니다. Egan의 `PermutationChains` README("PermutationChains 5 … should find 6 solutions")와 일치합니다.
- 이 6개 집합에서 기저 교환 공리가 성립하지 않습니다. 명시적 반례는 `certs/matroidtest_n5.txt`에 있습니다.
- 따라서 완성 집합족은 어떤 매트로이드의 기저족도 아닙니다.

## 4. n = 7 점수 15 (조건부 길이 5905)

- 최단 kernel 3개(27 row)와 5906 kernel의 +5 확장 4개는 모두 C4를 통과했습니다.
- 정확한 흐름 모형(C3)은 각각 300초 안에 **UNKNOWN**이었습니다.
- 확장 하나에서는 "기존 payload block 하나는 어떤 완성에도 쓸 수 없다"는 단일 block 강제 배제를 증명했습니다(`fixcore.py`, CP-SAT 가정 코어). 이는 국소 사실일 뿐 전역 장애물은 아닙니다.
- **결론: 완성도, 장애물도 얻지 못했습니다.** 5905를 상계라고 주장하지 않습니다.
- 남은 핵심: |U| = 570, 후보 ~560개, |P| = 114인 비순환 정확 소유 덮개 문제입니다.

## 5. f(n) 일반 구성

- 표준 kernel의 완성은 n = 5, 6(이번 작업), 7(Egan `PermutationChains`, 문헌), 8, 9, 10(외부 단어)에서 존재합니다.
- 일반 n의 귀납적 구성은 **얻지 못했습니다.**
- C5에 의해 매트로이드 교집합식 일반 존재 정리도 바로 쓸 수 없습니다.

## 6. 정확한 남은 장애물

**비순환 정확 소유 덮개.**
- (n−1)-균일 후보 초그래프에서, U를 정확히 분할하는 "구멍 뚫린 block" 선택에 대해 kernel에 뿌리를 둔 spanning arborescence 조건이 요구됩니다.
- 정확 덮개 부분만으로도 일반적으로 어려운 문제입니다.
- 실험상 순환 덮개가 비순환 덮개보다 훨씬 많아, 비순환 조건이 결정적인 제약입니다.
- 고아 조건(C4) 외의 일반 필요조건, 그리고 어떤 충분조건도 증명하지 못했습니다.
