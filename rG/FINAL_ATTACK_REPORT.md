# 최종 공격 — Σ*(n) 결정 시도

브랜치 `claude/final-attack` (`claude/final-universal`에서 분기). **결과: 풀지 못했습니다.**

## 1. 이번 실행에서 새로 얻은 것

**국소 순절약 법칙 (계산; n = 6, 7, 8, 9 각각 전수, 검증기 A와 B 일치 — 모든 n에 대한 증명은 아님).**
생략 없는 non-full row y(charge c)가 full 구간 두 개 사이 `[full^a, y, full^b]`에 있을 때:
- c = 1: 양쪽이 full인 배치는 불가능합니다(R182 창 보조정리와 일치).
- c ≥ 2: 최대 a = b = n − 3이고, 국소 순절약은 `vis(y) − δ_seg = (n−1−c) − 2 = n − 3 − c`입니다.
- 최댓값은 c = 2인 T-row에서 `n − 5`입니다.

출력: `certs/localnet.txt` (B), `certs/localnetA.txt` (A, n = 6, 7).

**귀결 — 결정적 정보는 국소적이지 않습니다.**
- n = 6에서도 T-row 하나는 국소적으로 +1을 법니다.
- R179의 n = 6 완화 인스턴스(row 22개, trail 하나)는 정리 C 기준 Σ = 24 − 4·5 = 4 > 0입니다.
- 그런데 실제 Σ*(6) = 0입니다(L₆ = 872, 외부 Lean superperm6).
- 따라서 n = 6과 n = 7의 차이는 국소 법칙이 아니라 **전역 덮기(payload forest의 실현 가능성)**에서 옵니다.
- 국소 법칙은 n에 대해 균일합니다. n ≡ ? (mod k) 같은 합동 의존성은 관찰되지 않았습니다.
- n = 6에서 이 전역 제약을 판정한 유일한 방법은 외부 Lean의 전수 계산입니다.

## 2. 왜 Σ*(n)이 결정되지 않는가 (정확한 진술)

- 정리 C에 의해 `Σ = Σ_{non-full rows} (국소 순절약) − (전역 낭비: u_out, (n−1)a, (n−2)(δ_S + δ_τ))`이고, 국소 항의 합은 ≤ (n−5)·N_nf입니다(위 계산 기준).
- 하계를 얻으려면 Σ*의 상계, 곧 "**덮기 제약을 만족하는 route에서 non-full row의 국소 순절약이 얼마나 많이 실현될 수 있는가**"의 상계가 필요합니다.
- 이 프로젝트가 가진 도구는 모두 이 양을 (1−ε)(n−2)! 아래로 묶지 못합니다.
  - **trail별 capacity:** R180 천장 정리. 하한의 차수가 Θ((n−4)!)를 넘지 못합니다.
  - **non-full row 수 제어:** 정리 Q. 덮기 제약만으로는 N_nf가 (m+b+η)에 묶이지 않습니다.
  - **special 평균화:** R182 명제 AV. 공허합니다.
  - **payload 계수:** R179 명제 V, E. 극단점에서 공허합니다.
- 남은 문제는 **"Δ(n)이 Egan과 같은 차수 Θ((n−3)!)인가"**보다도 강한 것입니다. 정확한 Σ*(n)을 요구하기 때문입니다.
  - 그 차수 질문조차 `Σ*(n) ≤ (1−ε)(n−2)!`과 동치이며, 문헌에서도 열린 문제입니다. 접근 가능한 출처에서 일반 하한의 차수 개선을 찾지 못했습니다.
  - 이 질문이 이번 시도를 막은 환원 불가능한 정리입니다.

## 3. 현재 알려진 값 (정리 C 기준)

- `L_n = f(n) − Σ*(n)/(n−2)`
- Σ*(n) = 0: n = 4, 5, 6 (n = 3도 정확값 L₃ = f(3)).
- Σ*(7)/5 ∈ [1, 9]: 5906 [검증]과 5898 [외부 Lean, 미재빌드]에서. 5905 [보고, 미검증]를 받아들이면 [2, 9].
- Σ*(n) ≥ 0: n = 8, 9, 10 [단어 검증].
- 일반 n ≥ 7: `−(n−2) ≤ Σ*(n) ≤ (n−2)! − (n−2)(1 + max(Liu(n), R178(n)))`.
- 따라서 하한 쪽 간격은 Θ(n)배입니다.
