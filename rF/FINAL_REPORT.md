# 최종 라운드 — 일반 n 최소 superpermutation 문제: 정리, 보존 법칙, 남은 핵심

브랜치: `claude/final-universal` (R182 커밋에서 분기). production 브랜치(`codex/round171-joint-audit`)와 n = 6 production 인증서는 건드리지 않았습니다.

## 0. 결론 먼저

- **임의 n에 대한 정확한 L_n은 얻지 못했습니다.** 이 문제는 여전히 열려 있으며, 이 프로젝트가 풀었다고 주장하지 않습니다.
- 이번 라운드에서 얻은 것은 다음 네 가지입니다.
  1. **정확한 보존 법칙(정리 C).** 모든 정규화 route의 길이를 정확히 다음과 같이 씁니다.
     `L(route) = f(n) − (V_nf − Ω)/(n−2) + E₅`, `f(n) = n! + (n−1)! + (n−2)! + (n−3)! + n − 4`.
     여기서 Ω ≥ 0은 낭비 항이고, V_nf는 non-full row의 visible 상태 수입니다. 따라서 **f(n)보다 짧아지는 효과는 오직 non-full row에서만 나옵니다.**
  2. **Egan − 1 구조의 특성화(정리 E).** non-full row가 없는 길이 f(n)의 superpermutation은 "φ-cycle에 뿌리를 둔, 구멍 없는 최소 spanning block forest"와 **정확히 대응**합니다(양방향 증명). 외부 기록 단어 n = 8, 9, 10에서 이를 검증했습니다.
  3. **NF의 무한 반례족(정리 Q).** `N_nf/(m+b+η) > n/5`인 기호적 구성입니다. R182가 남긴 NF 문제(영역 A)는 **부정으로 해결**되었습니다.
  4. **C1(g = 0)의 수리(보조정리 C0).** 핵심 단어 항등식은 Lean으로 검증했습니다.
- **남은 핵심은 하나의 양**입니다. `Σ*(n) := max_route (V_nf − Ω − (n−2)E₅)`이고 `L_n = f(n) − Σ*(n)/(n−2)`입니다(§8).
  - 다만 이 등식은 L_n의 **재표현**이므로, Σ*(n)을 구하는 것은 하계 쪽에서 원래 문제와 같은 난이도입니다. 이 점을 숨기지 않습니다.

## 2. 가장 강한 새 정리들 (정확한 진술)

**기호.**
- n ≥ 4, `ORB = (n−2)!`, `HEX = (n−1)!`, `CONST(n) = n! + (n−1)! + (n−2)! + n − 3`, `f(n) = CONST(n) + (n−3)! − 1`.
- 정규화 route와 그 Bridge 인스턴스(모든 선택에 대해 성립)에서 m, r, a, b, η, k, u, D는 R178의 정의 그대로입니다.
- `E₅ := Σ_{비용 ≥ 5인 간선}(비용 − 4)`이므로 `L(route) = CONST + D + E₅`입니다(B5).
- row 관련:
  - `F_rows`, `N_nf`: full row 수와 non-full row 수
  - `V_nf`: non-full row들의 visible 상태 수의 합
  - `S_f`: trail 안에서 full row의 최대 연속 구간 수
  - `τ_used`: 비어 있지 않은 trail 수
  - `G`: 총 charge
- 낭비 항:
  - `δ_seg = (n−2)S_f − F_rows`
  - `δ_S = τ_used + N_nf − S_f`
  - `δ_τ = 1 + b + η − τ_used`
  - `u_out = u − G` (row block이 아닌 block의 구멍)
  - `Ω = u_out + (n−1)a + (n−2)(δ_S + δ_τ) + δ_seg`

**보조정리 C0 (모든 n ≥ 4).** full row (p, n−1) 다음에 올 수 있는 compatible full row는 start가 φ(p)인 것뿐입니다.
- **따름정리 C1(0):** charge 0인 trail은 row가 ≤ n−2개입니다(φ의 위수는 n−2). 따라서 δ_seg ≥ 0입니다.

**정리 C (정확한 보존 법칙, 모든 n ≥ 4, 모든 정규화 route와 Bridge 인스턴스).**

`(n−2)(D + 1) = ORB − V_nf + Ω`, 이고 Ω의 다섯 항은 모두 ≥ 0입니다.

동치인 형태는 다음과 같습니다.

`L(route) = f(n) − (V_nf − Ω)/(n−2) + E₅`

**따름정리.**
- (C-a) `L(route) ≥ f(n) − V_nf/(n−2) ≥ f(n) − N_nf`.
- (C-b) 길이가 f(n) − j인 superpermutation의 정규화 route는, **어느 Bridge 인스턴스에서나** non-full row를 ≥ j개, visible 상태로는 ≥ (n−2)j개 가집니다. non-full row가 없으면 길이는 ≥ f(n)입니다.
- (C-c) N_nf = 0일 때, `L(route) = f(n) ⟺ Ω = 0이고 E₅ = 0`.
- (C-d) R182의 정리 F는 V_nf ≤ (n−2)N_nf와 u_out ≥ 0을 써서 이것을 약화한 것입니다. 이번 결과가 더 강합니다.

**정리 E (Egan − 1 구조의 특성화, n ≥ 4).** 다음 둘은 동치입니다.
1. non-full row가 없는 Bridge 인스턴스를 가지며, 길이가 정확히 f(n)인 정규화 route가 존재한다.
2. τ ≥ 1과 block 집합 𝔅가 존재하며 다음을 만족한다.
   - (i) 𝔅의 block들이 모든 순환류를 덮는다.
   - (ii) block–순환류 포함 그래프가 forest이다.
   - (iii) 연결 성분이 정확히 τ(n−2)개이다(이때 `|𝔅| = ORB + (n−3)! − τ`).
   - (iv) 성분들을 φ-cycle τ개로 묶을 수 있다. 각 φ-cycle은 n−2개 성분에 하나씩 있는 full row `p, φp, …, φ^{n−3}p`이다.
   - (v) τ ≥ 2이면 φ-cycle 사이의 연결 간선 비용이 모두 정확히 4이다.

추가로, (ii)–(iii)의 forest는 성분 수가 반드시 n−2의 배수입니다(`(n−2)|𝔅| = HEX − K`). 따라서 τ = 1이 구멍 없는 forest가 가질 수 있는 **최소 성분 수**입니다.

**정리 Q (NF의 무한 반례족, n ≥ 6).** 기호 0, …, n−1, `s = n−1`, `Y₀ = 0`, `t₀ = 1`로 둡니다.
- **s-row:** {1, …, n−2}의 각 순환 단어 F에 대해 start `p = (f₁, …, f_{n−3}, 0, f₀, s)`인 T-row(길이 n−3)를 둡니다. trail은 `p, tm p, …, tm^{n−3} p`이며, tm은 R180의 사상입니다.
- **patch:** {2, …, n−2}의 각 배열 x와 쌍 `π ∈ {(0,s), (s,0)}`에 대해 start `q = x + π + (1)`인 charge-1 row(길이 n−2)를 두고, 각각 따로 trail로 둡니다.
- **결론:** 이 trail들은 모든 순환류를 정확히 분할하는 생략 없는 전역 packing입니다. 정리 Z에 의해 덮개 정규화 route가 되고, 그 매개변수는 다음과 같습니다.
  - `r = a = b = 0`, `m = 2(n−3)!`, `η ≤ 3(n−3)! − 1`, `N_nf = n·(n−3)!`
  - 따라서 `N_nf/(m+b+η) > n/5 → ∞`.
- **결과:** n과 무관한 θ에 대해 **NF_A(θ)는 모두 거짓입니다.** R182 영역 A = B에서 그렇습니다. 영역 C(D ≤ (n−3)!)에는 해당하지 않습니다. 이 족은 D ≈ 4(n−3)!로 Egan보다 깁니다.

## 3. 증명 사슬 (처음부터)

1. **경로 공식.** superpermutation W는 순열 route(첫 출현 순서)를 줍니다. 그 무게(간선 비용 = n − 최대 겹침)에 대해 `|W| ≥ n + 무게`입니다. 정규화(R178 Lemma 2.2)는 무게를 늘리지 않습니다. 따라서 L_n은 정규화 route에서의 최소 `n + 무게`입니다.
2. **Bridge(n)** [P]. 정의된 양들 m, r, a, b, η, k, u에 대해 다음이 성립합니다.
   - `L_c = CONST + D` (B5)
   - `k = ORB + m − r + a`, `u = (n−1)m − r` (B4)
   - trail 수 ≤ 1 + b + η (B8)
   - row의 charge = 그 row block의 구멍 수 (B9)
   - 비용 ≥ 4인 간선을 4로 셌으므로 `L(route) = CONST + D + E₅`입니다.
3. **C0 증명.** full row의 start를 `p = (a, β, b, s)`, `|β| = n−3`이라 하면, 호환 후계 start는 `β + σ(a, b, s)`입니다(σ는 순서 6가지).
   - **(a, b, s):** φ(p).
   - **(b, a, s):** F(p)로, 같은 block입니다.
   - **(b, s, a):** start가 R(p)이므로 p의 상태 0과 같은 순환류입니다.
   - **(s, b, a):** start가 `R²(F^{n−2}p)`이므로 p의 상태 n−2와 같은 순환류입니다.
   - **(a, s, b):** 후계의 상태 n−3이 `R^{n−2}(F p)`입니다.
   - **(s, a, b):** 후계의 상태 n−3이 `R^{n−1}(p)`입니다.
   - 두 row가 모두 full이면 모든 상태가 visible이므로 마지막 네 경우는 서로소 조건에 어긋납니다. ∎
   - Lean `rF/lean/C0Core.lean`이 여섯 단어 항등식을 일반 β에 대해 검증합니다.
4. **정리 C 증명.**
   - (2)에서 `(n−2)D = ORB − k + (n−1)a + u + (n−2)(b+η)`입니다.
   - 여기에 `u = G + u_out`, `G = (n−1)N_nf − V_nf`, `k = F_rows + N_nf`, `F_rows = (n−2)S_f − δ_seg`, `S_f = τ_used + N_nf − δ_S`, `b + η = τ_used − 1 + δ_τ`를 대입하면 등식이 나옵니다.
   - 비음수성: δ_seg ≥ 0은 C1(0), δ_S ≥ 0은 j개의 non-full row가 trail을 ≤ j+1개 구간으로 나누기 때문, δ_τ ≥ 0은 B8, u_out ≥ 0과 a ≥ 0은 B4와 B9에서 나옵니다. ∎
   - 산술은 Lean `ConsTm.conservation`입니다.
5. **정리 E.**
   - **(⇒)** (C-c)에서 Ω = 0입니다.
     - a = 0이므로 A-그래프의 순환 차수가 0, 즉 forest입니다.
     - G = 0이고 u_out = 0이므로 u = 0, 즉 구멍이 없고 모든 touched block이 완전히 선택됩니다.
     - δ_S = 0, δ_seg = 0이므로 각 trail은 정확히 n−2개 full row로 된 구간 하나이고, C0에 의해 φ-cycle입니다.
     - δ_τ = 0, E₅ = 0입니다.
   - **(⇐)** 실현.
     - 모든 상태를 선택하고, A를 같은 순환류 안에서 R-순서로 다음 선택 상태로 둡니다.
     - forest 조건에서 `T = F∘A`는 성분마다 순환 하나입니다. 서로 다른 순환을 잇는 전치는 순환 둘을 합치기 때문입니다.
     - 각 성분을 row start에서 시작해 T-순환 한 바퀴로 순회합니다. run 안은 비용 1, run 끝에서 `F(A x) = N₂(R^{−1}A x)`로는 비용 2입니다(B3; R179 Lean `F_rot_eq_N2`).
     - 연속한 φ-row 사이는 β = α이고, 비용 ≤ 2는 불가능하므로 비용 3입니다. φ-cycle 사이는 가정 (v)에서 비용 4입니다.
     - 무게를 세면 `L = n + (N − |S|) + 2(|S| − K) + 3(K − τ) + 4(τ − 1) = f(n)`입니다(`|S| = (n−1)|𝔅|`, `(n−2)|𝔅| = HEX − K`, `K = τ(n−2)`). ∎
   - **검증:** n = 8(46204)과 n = 9(408965)의 forest를 단어에서 추출한 뒤, block 집합과 row start만으로 route를 **다시 만들었습니다.** 결과는 Hamilton·정규화 route였고, 길이는 정확히 f(n), 최대 간선 비용은 3이었습니다(`certs/forest_realize.txt`).
6. **정리 Q 증명.**
   - (a) **tm-orbit = 틀(frame).**
     - p를 `A ++ [x, y, z] ++ [s]`로 쓰면 `tm p = [z] ++ A ++ [y, x] ++ [s]`입니다.
     - 숨은 글자(위치 n−3)는 y로 유지되고, 단어는 x, y 교환의 회전이며, y를 지운 단어는 불변입니다. 이는 Lean `tm_hidden`, `tm_word_swap`, `tm_frame`입니다.
     - 위치 사상 `0 ↦ n−2 ↦ n−4 ↦ … ↦ 1 ↦ 0`은 길이 n−2인 순환이므로 tm의 위수는 n−2입니다. 그 n−2개 iterate는 Y₀가 F의 n−2개 간격을 한 번씩 지나는 서로 다른 단어입니다. 따라서 trail은 같은 special의 서로 다른 단어로 된 ModelTrail입니다.
   - (b) 각 T-row가 숨기는 것은 s와 Y₀가 이웃한 두 순환류입니다. 고정된 Y₀에 대한 틀들은 s-단어 전체를 분할하므로, s-row의 visible 집합은 정확히 "s와 Y₀가 이웃하지 않은 순환류"입니다.
   - (c) s와 Y₀가 이웃한 순환류 c는 각각 정확히 하나의 1-block `(c∖1, 1)`에 들어갑니다. 그 단어에서도 s, Y₀는 이웃하므로, 그 둘 사이 간격만 숨긴 charge-1 row가 c를 정확히 덮습니다.
   - (d) 따라서 정확 분할이고 block이 서로 다르며, 정리 Z가 적용됩니다.
   - (e) 매개변수를 세면 결론이 나옵니다. ∎
   - **검증:** n = 6, 7, 8, 9에서 정확 분할, 검증기 A·B, 쌍별 서로소(n ≤ 8), 덮개 route, Bridge 재계산(n ≤ 8)이 모두 일치했습니다. 비율은 1.57, 1.77, 2.00, 2.25로 ≈ n/4입니다(`certs/nfcex.json`).
7. **수치 대조.** 정리 C의 등식을 route 291개(n = 5, 6, 7, 8; archive, 섭동, greedy, r = 0, 정리 Q족)에서 검사했습니다. 등식과 비음수성 모두 **위반 0**입니다(`certs/conservation.txt`, `conservation_n8.txt`).

## 4. L_n의 정확한 형태와 현재 최선

**정확한 재표현 (정리 C).**

`L_n = f(n) − Σ*(n)/(n−2)`,

`Σ*(n) := max_{정규화 route} [V_nf − Ω − (n−2)E₅]` (Σ는 route 불변량입니다).

| n | 알려진 L_n | f(n) | Σ*(n)/(n−2) | 근거 |
|---|---|---|---|---|
| 3 | 9 | 9 | 0 | 정확(고전) |
| 4 | 33 | 33 | 0 | 정확 |
| 5 | 153 | 153 | 0 | 정확(전수, R173 재현) |
| 6 | 872 | 872 | 0 | 정확(외부 Lean superperm6) |
| 7 | [5898, 5906] (5905 보고) | 5907 | 1..9 (5905가 맞다면 2..9) | 5906은 아카이브에서 검증. 하한 5898은 jlebar Lean(외부, 미재빌드). 5905는 검색 스니펫에서만 확인(1차 출처 접근 불가) |

## 5. 상계 구성

- **Egan(n ≥ 7):** 길이 f(n) + 1. 정리 C의 언어로는 row 1개(charge 1, 구멍 1개), V_nf = n−2, Ω = 2(n−2), Σ = −(n−2)입니다. n = 7 Egan 길이 route(5908)에서 측정했고(`certs/conservation.txt`), 구멍 구조는 n = 7, 8, 9에서 측정했습니다(`certs/eganhole.txt`).
- **길이 f(n) (Egan − 1):** n = 5, 6, 8, 9, 10의 단어가 존재합니다.
  - n = 8: Raudvere, 2026-07. n = 9, 10: Echols, 2026-07(GPT-5.6-Sol와 Codex 세션). 이 라운드에서 독립 슬라이딩 창 검사로 검증했습니다.
  - n = 8, 9 단어는 정확히 정리 E의 τ = 1 구조입니다. n−2개 성분의 크기는 n = 8: [1,1,6,26,86,719], n = 9: [1,1,7,37,157,517,5039]입니다.
  - 따라서 **일반 n의 Egan − 1은 "φ-cycle에 뿌리를 둔 최소 구멍 없는 spanning block forest"의 존재 문제와 동치**입니다(정리 E).
- **이번 라운드의 시도 (모두 실패, 증명 아님):**
  - 고정 이동 글자 φ-cycle 사슬: n = 6..9에서 찾지 못함(DFS, 노드 한도 2×10⁶).
  - 임의 틀의 m = 0 덮개: n = 6에서 400개 덮개를 검사해 최선 873(= Egan).
  - 탐욕적 단일 부착 성장: n = 6에서 108/120에서 막힘.
  - Egan tree에서 구멍 block 제거: 그 block에 중복도 1인 순환류가 있어 직접 적용되지 않음. 다만 성분 크기가 −1 단어와 거의 같습니다(n = 8: [1,6,26,86,720] vs [1,1,6,26,86,719]).
  - **일반 n에서 길이 f(n)의 구성은 증명하지 못했습니다.** 상계로는 Egan의 f(n) + 1만 일반적으로 증명되어 있습니다.
- **f(n)보다 짧은 구성:** n = 7(5906, 보고된 5905)뿐입니다. (C-b)에 의해 이런 단어는 non-full row가 필수입니다. 5906 route는 T-row 4개(V_nf = 16), δ_seg = 11, Σ = 5였습니다.
- **정리 Q족과 r = 0 구성들:** 유효한 superpermutation이지만 Egan보다 깁니다. **상계 개선은 없습니다.**

## 8. 남은 환원 불가능한 핵심

**대상 (하나).** `Σ*(n) = max_{정규화 route} (V_nf − Ω − (n−2)E₅)`. 정리 C에 의해 `L_n = f(n) − Σ*(n)/(n−2)`가 **모든 n ≥ 4에서 정확한 등식**입니다.

**다른 모든 간격이 이 대상으로 환원되었다는 것.**
- R173–R182의 미해결 양(NF, CS의 ω_s, PI, LS, payload, P-global, Δ의 차수)은 모두 Σ의 항(V_nf, u_out, a, δ_S, δ_τ, δ_seg, E₅)이거나 그 항들의 상계입니다.
- 정리 C는 등식이므로 다른 숨은 항이 없습니다. 이번 라운드에 C1(0)을 C0로 수리해, Ω의 비음수성에 남아 있던 전제도 닫혔습니다.

**상계 쪽.**
- `Σ* ≥ 0 ⟺ L_n ≤ f(n)`. non-full row가 없는 경우에는 이것이 φ-rooted 최소 forest의 존재와 동치입니다(정리 E).
- `Σ* > 0`은 non-full row를 반드시 필요로 합니다(C-b).
- Σ* ≥ 0은 n = 3..6, 8, 9, 10에서 확인되었고, n = 7에서는 Σ*/5 ≥ 1입니다. 일반 n에서 증명된 것은 Σ* ≥ −(n−2)(Egan)뿐입니다.

**하계 쪽 — 왜 현재 틀이 더 나아갈 수 없는가.** Σ*의 상계는 V_nf를 Ω로 갚게 하는 논법에서만 나옵니다. 틀이 쓸 수 있는 도구와 그 한계는 다음과 같습니다.
- (i) **국소·trail별 제약(C1, 창, 카탈로그):**
  - R180 정리 W의 walk는 T-row 하나당 순절약 V − δ_seg = n − 5를 실제로 냅니다.
  - R180 천장 정리에 의해 trail별 capacity 논법은 R178의 2.5배를 넘지 못합니다. 따라서 국소 논법으로 얻는 하한은 차수 Θ((n−4)!)를 넘지 못합니다.
- (ii) **전역 덮기 제약(UPL, CS, PI):**
  - 정리 Q는 덮기가 non-full row 수를 (m+b+η)로 제어하지 못함을 보입니다(영역 A).
  - R182 명제 AV는 special 평균화가 공허함을 보입니다.
- 따라서 하계에 남은 정보는 **"덮기 제약 아래에서 non-full row의 순절약을 전역적으로 제한하는 것"** 하나입니다.
- 특히 `liminf Δ(n)/(n−3)! > 0`인지(Egan과 같은 차수인지)는 `Σ*(n) ≤ (1−ε)(n−2)!`와 동치입니다. 이것은 이 프로젝트 밖에서도 알려지지 않은 열린 문제로 보입니다. 문헌 하한은 Liu 하한(≈ (n−4)! 규모)이 최선으로 보이며, 접근 가능한 출처에서 차수 개선은 찾지 못했습니다.
- **이 환원의 한계:** Σ*(n)은 L_n의 아핀 재표현이므로 "원래 문제보다 쉬운 최적화"는 아닙니다. 얻은 것은 구조입니다.
  - 편차의 **유일한 원천**이 non-full row라는 것
  - f(n)에서 정확히 어떤 낭비가 일어나는지
  - Egan − 1의 정확한 조합적 대응물
