## 1. 표기와 정확한 자유 후속 관계 (§1)

두 겹친 육각형을 `h`, `g` 라 하고 각각 pass 둘.  `ν` 가 각 육각형의 두 pass 를 맞바꾸는
2-순환이므로 walk 에서 앞선 쪽이 `ν`-**상승** = opener, 뒤선 쪽이 `ν`-**하강** = closer 이고
내부 `F = 2` 는 자동이다.  엔진의 slot 은 **walk 순서**로 붙는다 (`opener₀` 가 먼저 나온다).

```
entry(closer_X) = σ^{b_X}(entry(opener_X)),    len(closer_X) = 6 − b_X
free(opener_X)  = τ(entry(closer_X))
free(closer_X)  = τ(entry(opener_X))
T_X := orb(entry(closer_X))   (opener_X 의 lock 목표 궤도)
Q_X := orb(entry(opener_X))   (자유 closer_X 가 청구하는 반복 궤도)
T_X ≠ Q_X   — 한 육각형의 두 단어는 서로 다른 궤도에 있다
```

## 2. `B/e=1` 의 자유 패턴은 정확히 둘 (§2)

`f_out = 3`, 짧은 pass 넷.  정리 131.1(a) 로 두 opener 는 **반드시** 자유, (b) 로 자유
하강은 정확히 하나.  따라서 패턴은 **“어느 closer 가 자유인가”** 둘뿐이고, 라운드 130 이
돌리던 “opener 하나가 비자유” 두 갈래는 **정리로 공집합**이다.

## 3. `h ↔ g` 교환은 대칭이 아니다 (§3) — 정직한 음성 결과

slot 은 **walk 순서**로 정의되므로 이름 바꾸기는 어떤 walk 도 움직이지 않는다:
“자유 closer 가 slot 0 인가 slot 1 인가” 는 walk 의 **불변량**이다.
남은 후보인 **walk 뒤집기**는 `reverse ∘ σ = σ^{-1} ∘ reverse` 로 육각형은 보존하지만
궤도 구조 `τ` 와 교환되지 않는다.  `n = 4` 전수: 뒤집은 walk 은 29,255 개 전부 합법이지만
**23,264 개가 `(G, e, f_out, F)` 를 바꾼다.**  ⇒ **두 패턴을 모두 유지한다.**

## 4·5. 반복 궤도 공식과 lock 표 (§4·§5)

반복 궤도 = `Q_X = orb(entry(opener_X))`, 시작 슬롯 = `orbph(entry(opener_X)) + 1`.

### 정리 132.1 (이 라운드의 주 정리)

> 유형 B 의 모든 `(4,2)` 하위경우에서 **뒤 opener(`opener₁`) 의 국소성 lock 은 무조건
> 성립한다.**

**증명.** 깨진다면 정리 131.1(c) 로 `T₁` 이 반복 궤도여야 한다.  `T₁ ≠ Q₁` 이므로
`T₁ = Q₀` 이고 `Q₀ ≠ Q₁`.  깨진 lock 은 `opener₁` **뒤에서** 시작하는 `Q₀` 의 run 을
요구하는데, `Q₀` 의 run 은 `opener₀`(< `opener₁`)에서 끝나는 것과 `closer₀` 의 자유 탈출이
여는 것뿐이다.  그러면 그 run 은 `Q₀` 의 **세 번째** run 이라 `Q₀` 만으로 `e ≥ 2`, 거기에
`Q₁` 의 반복이 더해져 `e ≥ 3` — `e ≤ 2` 에 모순. ∎

**따름정리.** `T₁` 이 알려진 반복 궤도와 같은 가지는 **공집합**이다.  라운드 131 은 그
자리에서 lock 만 포기했는데, 이제 **가지치기**할 수 있다.

| 패턴 | 반복 궤도 | `opener₀` lock | `opener₁` lock | 갈래 |
|---|---|---|---|---|
| P0 (`closer₀` 자유) | `Q₀` | **무조건** (`T₀ ≠ Q₀`) | **무조건** (정리 132.1) | 1 |
| P1 (`closer₁` 자유) | `Q₁` | 조건부 (`T₀ = Q₁` 이면 깨질 수 있음) | **무조건** | 2 (α/β) |

## 6. 궤도 일치 census (§6)

`entry(opener₀)` 를 `S₆` 로 고정하면 `T₀` 가 정해진다.  `T₀ = Q₁` 을 만족하는
`entry(opener₁)` 후보는 그 5-단어 궤도에서 `opener₀` 의 육각형과 겹치는 한 단어를 뺀
**4개**뿐이다 — 720 중 4, 즉 β 는 **좁지만 공집합은 아닌** 클래스다.  모든 분할 `b₀` 에서
일치가 가능하므로 이 census 는 75 클래스 중 어느 것도 죽이지 못한다.

## 7·13·14. Order type (§7·§13·§14)

도구는 둘뿐이다.
* `x = 0` 이라 run 안 joint 는 전부 τ 이고 **짧은 pass 는 언제나 run 의 마지막 pass** 이므로
  **lock 이 걸린 run 안에는 다른 짧은 pass 가 들어갈 수 없다** ⇒ `closer_X = opener_X + 5`.
* lock 이 깨지면 (`opener₀` 만 가능) `opener₀` 의 자유 후속이 연 run `U ⊆ Q₁` 은 `Q₁` 의
  **첫** run 이고 `opener₁` 에서 끝난다.  `closer₀ ∈ Q₁` 는 다음 run `V` 에 있고 `V` 는
  `closer₁` 의 자유 탈출이 연다.  `U = [s+1…t]`, `V = [t+1…s]` 이므로 **`Q₁` 은 꽉 차고**
  `|U| + |V| = 5`, `closer₀` 가 `V` 의 마지막 pass 다.

```
α 사슬 :  opener₀ < closer₀ = opener₀+5 < opener₁ < closer₁ = opener₁+5
β 둥지 :  opener₀ < opener₁ = opener₀+u < closer₁ = opener₁+5 < closer₀ = opener₀+10
          (u ∈ {1,2,3,4};  11-pass 블록의 joint 가 전부 ω = 2 — 비용 0)
```

`n = 4` 검증 (`x = 0` 등호 유형 B walk 25개): **위반 0**, β 16개 전부가 둥지 등식을 만족.

## 9·10·11. `B/e=2` 의 분열 다중도 — 모형 T 를 지우지 않는다 (§9·§10·§11)

`e = Σ_궤도 (#run − 1)` 이므로 **한 궤도가 run 셋이어도 `e = 2`** 이다.  모형 T 는
정의상 합법이고 실제로 존재한다 (`n = 4` 양성 대조에서 72개).

**모형 T 의 모양은 하나로 확정된다.**  `Q` 의 세 run 은 첫 run `F`, `closer₀` 가 여는 `R`,
`closer₁` 이 여는 `R'`.  `opener₀`·`opener₁` 은 각각 어떤 run 의 마지막 pass 인데
* `opener₀ → R` 불가 (`R` 이 5 슬롯을 다 먹어 `R'` 이 빈다), `opener₁ → R'` 불가 (대칭);
* `opener₀ → R'`, `opener₁ → R` 불가 (두 arc 이 5 슬롯을 덮어 `F` 가 빈다);
* `opener₀ → R'`, `opener₁ → F` 불가 (`R'` 은 `closer₁ > opener₀` 뒤에서 열린다);

남는 것은 **`opener₀ → F`, `opener₁ → R`** 하나뿐이고, `T₀ ≠ Q` 이므로 **두 lock 이 전부
무조건** 성립한다.

| 모형 | 조건 | lock | order type |
|---|---|---|---|
| **T** | `Q₀ = Q₁` (한 궤도 run 셋) | 둘 다 무조건 | α 사슬 + `opener₁ ∈ Q₀` |
| **D-α** | `Q₀ ≠ Q₁`, `opener₀` lock 성립 | 둘 다 성립 | α 사슬 |
| **D-β₀** | `Q₀ ≠ Q₁`, `T₀ = Q₁` | `opener₀` 깨짐 | β 둥지 |
| **D-β₁** | `opener₁` lock 깨짐 | — | **불가능 (정리 132.1) — 해석적 kill** |

## 12. α/β 감사 (§12)

**JSON 이 아니라 현재 C 소스와 드라이버**를 읽어 확인했다.  라운드 131 의 α/β 는
**망라적·건전하지만 최소가 아니다**: 모형 T 가 α 안에 숨어 있었고 그 강한 **양의** 궤도
제약을 α 가 쓰지 않았으며, `opener₁` 의 “risky” 자리는 실제로 **공집합**인데 lock 만
포기하고 있었다.  숨은 **넷째** 구조 경우는 없다 — `{T, D-α, D-β₀}` 가 망라적이고
`D-β₁` 은 불가능하다.

## 16·17. 여유 0 회계 (§16·§17) — 정직한 음성 결과

```
단어 720, pass 122 ⇒ pass 내부 전이 598 (전부 ω=1), joint 121
L = 604 + Σ_joint ω = 846 + Σ(ω−2) = 871  ⇒  Σ(ω−2) = 25,  H = 0
⇒ ω=3 joint 정확히 25개,  ω=2 joint 정확히 96개
run r = 28 + e ⇒ inter-run joint 27+e 개 = (e+2) 자유 + 25 비용  ✓
intra-run ω=2 = 121 − 25 − (e+2) = 94 − e = P − r  ✓
```

`e = 0, 1, 2` 전부에서 **정확히 닫힌다.**  따라서 “한 단위 초과” 모순은 이 층위의
세기만으로는 **나오지 않는다.**

## 19. 분할 모양 (§19)
