## 0. 결과

> ### `F = 2` 는 **두 개의 모형으로 갈린다.**
>
> `F = Σ_h (e_h − 1) = 2` 이고 양수 부분들은 `2` 의 분할이므로 유형은 정확히 둘이다.
>
> | 유형 | 진입 중복 | 다중 진입 육각형 수 `m` | **짧은 pass 수** | 자유 후속 `ν` 의 순환형 | 길이 분해 |
> |---|---|---|---|---|---|
> | **A** | 육각형 하나를 **세 번** 진입 | 1 | **3** | **3-순환** 하나 | `6 = a+b+c`, 10가지 |
> | **B** | 육각형 **둘**을 각각 두 번 진입 | 2 | **4** | **2-순환 둘** | `(b, 6−b)` 각각, 25가지 |
>
> 두 유형은 짧은 pass 수도, 자유 후속의 순환 구조도, 그리고 아래에서 보듯 **`f_out` 상한의
> 증명 상태도** 다르다.  하나의 모형으로 묶을 수 없다.
>
> ### 새 항등식 (일반 `n`, 일반 `F`)
>
>     P = n!/n + F                     Σ_pass len = n!  ⇒  총 결손 = n·F
>     육각형 h 의 결손 = n(e_h − 1)     ⇒  e_h ≥ 2 인 육각형의 pass 는 **전부 짧다**
>     짧은 pass 수 = F + m
>     S = (r − 1) + x − f_out          ← **유도에 `F` 가 전혀 안 들어간다**
>     N = F − 1 + e + x − f_out
>     **L = 867 + k + F + e + x + H − f_out**      (n = 6)
>
> `F = 2` 에서 **`L = 869 + k + e + x + H − f_out`**, 따라서
> **`L ≤ 871 ⟺ k + e + x + H − f_out ≤ 2`.**
>
> ### 자유 후속은 육각형 위의 **순환 치환**이다
>
> `y` 에서 `ω = 2` 인 단어는 **둘**이다: `T1(y)` 와 `σ²(y)`.  뒤엣것은 같은 육각형이고
> 중간 창 `σ(y)` 가 순열이라 **joint 가 아니다**(회전 두 번이다).  따라서 합법 `ω=2` 후속은
> `T1(y)` 하나뿐이고, `T1(σ^{n−1}(w)) = τ(w)` 에서
>
> > **진입 `u`, 길이 `len` 인 pass 의 자유 후속 = `τ(σ^{len}(u))` = `τ(같은 육각형에서
> > 순환적으로 다음 pass 의 진입 단어)` = `τ(entry(ν(p)))`.**
>
> `ν` 는 pass 집합 위의 치환이고 **그 순환이 정확히 육각형**이다(순환 길이 `e_h`).
> `F=1` 은 2-순환 하나, `F=2` 유형 A 는 3-순환 하나, 유형 B 는 2-순환 둘.
> full pass 는 `ν`-고정점이라 자유 후속이 같은 궤도에 있어 **절대 inter-run 이 될 수 없고**,
> 짧은 pass 는 `ν(p) ≠ p` 이며 육각형의 6개 단어가 서로 다른 6개 궤도에 있으므로
> 자유 후속이 **언제나 궤도를 바꾼다.**  `n = 4, 5, 6` 전수 확인 (위반 0).
>
> ### 보조정리 E 의 올바른 일반화
>
> > **보조정리 E′ (모든 `F`).** `e_h ≥ 2` 인 육각형 `h` 의 **모든** pass 가 자유로 나가면
> > 어떤 궤도가 run 을 둘 이상 갖는다 — 즉 **`e ≥ 1`**.
>
> 증명은 순서 논증이다: `p` 가 자유로 나가고 경우 (i) 이면 walk 순서로 `p < ν(p)` 이므로,
> `h` 의 pass 가 전부 그러면 `ν`-순환을 따라 `p < ν(p) < … < p` 라는 모순이 된다.
>
> | | 상태 |
> |---|---|
> | `f_out ≤ #짧은 pass = F + m` | **증명됨** (모든 `F`) |
> | `F = 1`: `f_out ≤ 1 + e` (보조정리 E) | **증명됨** (라운드 117) |
> | `F = 2` **유형 A**: `f_out ≤ F + e` | **증명됨** (이 라운드) |
> | `F = 2` **유형 B**: `e = 0 ⟹ f_out ≤ 2` | **증명됨** (비둘기집 + E′) |
> | `F = 2` **유형 B**: `f_out = 4 ⟹ e ≥ 2` | **미해결 — 유일한 구멍** |
>
> ### 그 구멍 하나가 `F = 2` 열의 크기를 정한다
>
> | | `k` 범위 | 칸 수 | `max H` | `k+x+H` |
> |---|---|---|---|---|
> | 무조건 | `1 … 5` | **5** | **4** | ≤ 5 |
> | 정리 A(`f_out ≤ F+e+x`) 가정 | `1 … 4` | **4** | **3** | ≤ 5 |
> | `f_out ≤ F + e` 가정 | `1 … 4` | **4** | **3** | **≤ 4** |
>
> 세 줄의 차이는 **전부 같은 한 설정** — 유형 B, `f_out = 4`, `e = 1`, `x = 0` — 에서 온다.
>
> ### 그리고 그 설정은 `n = 4` 전수에서 **한 번도 나타나지 않는다**
>
> 합법 walk **29,255개**(그중 `F=2` 가 **10,625개**)에서 이 라운드의 모든 주장을 검사해
> **위반 0**.  유형 B, `f_out = 4` 인 walk 은 **56개**[^r127] 관측됐고 **최소 `e` 는 언제나 2** 다.
>
> [^r127]: **라운드 127 정정.** 이 문서의 초판은 이 자리와 §10.3 에 **79** 라고 적었다. 아티팩트 `outputs/rr_f2_structure_126.json` 은 처음부터 **56**(`e=2` 34개 · `e=3` 20개 · `e=4` 2개)을 기록했으므로 **56 이 옳고 79 는 산문 전사 오류**다. 실질 주장(최소 `e` = 2, 예외 설정 0회)은 영향받지 않는다.
> 게다가 `f_out` 마다의 **최소 `e` 가 정확히 `max(0, f_out − F)`** 로 나온다 —
> `f_out ≤ F + e` 는 성립할 뿐 아니라 **딱 맞게 성립한다(tight).**
>
> ### 모형 정정 — `n = 4` 대조에는 **joint 합법성**이 필요하다
>
> `a → b` 가 `ω = m` 이면 오프셋 `1..m−1` 의 중간 창이 **순열이면 안 된다**.
> 라운드 120·122 의 `n = 4` 대조는 이 조건을 걸지 않아 **합법 walk 의 초집합**을 돌았다.
> 초집합에서 그 라운드들의 결론은 그대로 유효하지만(초집합에서 성립하면 부분집합에서도
> 성립한다), 구조 통계는 다르고 이 라운드의 두 주장은 초집합에서 **실제로 깨진다.**
> 라운드 122 의 결론은 합법 모형에서 다시 재도 살아남는다 (첫 pass full 66.7%, 양 끝 full 49.1%).
>
> **폐쇄는 없다. Claude 가 닫은 바깥 칸은 `9 / 55` 그대로다.**

## 1. 전역 항등식 재유도 (§1)

`F = 1` 형태를 상속하지 않고 일반 `n`, 일반 `F` 에서 다시 센다.

| 값 | 일반 형태 | `n=6, F=2` |
|---|---|---|
| pass 수 | `P = n!/n + F` | **122** |
| 총 pass 길이 | `Σ len = n!` | 720 |
| 총 길이 결손 | `Σ (n − len) = n·P − n! = n·F` | **12** |
| 육각형별 결손 | `n(e_h − 1)` | — |
| 궤도 수 | `O = n!/(n(n−1)) + k` | `24 + k` |
| 궤도 결손 | `D = (n−1)O − P = (n−1)k − F ≥ 0` | `5k − 2 ≥ 0` ⟹ **`k ≥ 1`** |
| 길이 | `L = (n + n! − 2 + n!/n) + F + S + H` | `846 + S + H` |
| | `L ≤ 871 ⟺ S + H ≤ 25` | |
| `N` | `N = S + F − O` | `S − 22 − k` |

`k ≥ 1` 은 **`F = 1` 의 패턴을 가정한 것이 아니라** `F ≤ (n−1)k` 에서 바로 나온다.

## 2. 진입 다중도 유형 (§2)

`F := Σ_h (e_h − 1)` 이고 `e_h ≥ 1` 인 정수이므로 **양수 부분들은 `F` 의 분할**이다.
`2` 의 분할은 `{2}` 와 `{1,1}` 뿐 — 따라서 유형은 **정확히 둘**이고 분류는 **완전**하다.

* **유형 A** — 육각형 하나를 **세 번** 진입 (`m = 1`).
* **유형 B** — 육각형 **둘**을 각각 두 번 진입 (`m = 2`).

## 3. 짧은 pass 수 (§3)

육각형 `h` 의 6개 단어는 각각 정확히 한 번 방문되므로 **`h` 의 pass 길이 합은 6** 이다.
따라서

* `e_h = 1` ⟹ 길이 6 의 **full pass** 하나,
* `e_h ≥ 2` ⟹ 길이가 전부 `≤ 5` — **그 육각형의 pass 는 전부 짧다.**

> **짧은 pass 수 = `Σ_{e_h ≥ 2} e_h = F + m`.**  유형 A 는 **3**, 유형 B 는 **4**.

`F = 1` 에서 추론하지 않았다 — `F = 1` 은 `m = 1` 이라 우연히 `F + 1 = 2` 였을 뿐이다.

### 같은 육각형의 pass 는 절대 연속하지 않는다 (모든 `F`, 모든 `n`)

두 pass 가 같은 육각형이면 `z = σ^m(y)` (`1 ≤ m ≤ n−1`) 이다.  `m = 1` 이면 회전이라
두 pass 가 아니라 하나다.  `m ≥ 2` 이면 문자열 `y·(z 의 마지막 m 글자)` 의 오프셋
`j = 1..m−1` 창이 정확히 `σ^j(y)` — **전부 순열**이므로 비반복 walk 에서 그 지점을
지나간 것이 되어 역시 하나의 pass 다.  `n = 4,5,6` 전수 확인 (`ω(y, σ^m y) = m` 이고
중간 창이 전부 순열: 위반 0).

`F = 1` 의 정리 D(라운드 116)는 이것의 특수한 경우다.

## 5. 자유 탈출 수 `f_out` 의 일반화 (§5)

### 5.1 `ω = 2` 후속은 **둘**이고 그중 하나만 합법이다

`ω(y,z) = 2` 인 `z` 는 `T1(y) = (y[2],…,y[n−1],y[1],y[0])` 와 `σ²(y)` 둘이다.
`σ²(y)` 는 같은 육각형이고 중간 창 `σ(y)` 가 순열이라 **joint 가 아니다.**
따라서 **합법 자유 후속은 `T1(y)` 하나뿐**이다.  `n = 4,5,6` 전수 확인.

이것은 라운드 125 §4 가 무게-6 목록에서 찾은 퇴화와 **같은 현상**이다.

### 5.2 자유 후속 공식과 `ν`

`T1(σ^{n−1}(w)) = τ(w)` 이고 진입 `u`·길이 `len` 인 pass 의 탈출 단어는
`σ^{len−1}(u) = σ^{n−1}(σ^{len}(u))` 이므로

> **자유 후속 = `τ(σ^{len}(u)) = τ(entry(ν(p)))`.**

여기서 `ν` 는 **육각형 후속 치환** — pass `p` 를 같은 육각형에서 순환적으로 다음 호(arc)로
보낸다.  `ν` 의 순환은 정확히 육각형이고 순환 길이는 `e_h` 다.

* full pass: `ν(p) = p` ⟹ 자유 후속 `τ(u)` 는 **같은 궤도** ⟹ inter-run 이 될 수 없다.
* 짧은 pass: `ν(p) ≠ p` 이고 육각형의 `n` 개 단어는 서로 다른 `n` 개 궤도에 있으므로
  자유 후속은 **반드시 궤도를 바꾼다** ⟹ 언제나 inter-run.

⟹ **`f_out ≤ 짧은 pass 수 = F + m`.**  (유형 A: 3, 유형 B: 4.)

### 5.3 순진한 일반화를 능동적으로 반증한다

* `f_out ≤ F`? — **거짓.** 유형 A 에서 `f_out = 3 > 2` 인 walk 이 `n=4` 에 실재한다.
* `f_out ≤ 2`(`F=1` 값 그대로)? — **거짓.** 유형 B 에서 `f_out = 4` 가 실재한다.
* `f_out ≤ F + m`? — **참이고 증명됨**, 그러나 유형 B 에서 느슨하다.
* **`f_out ≤ F + e`?** — 아래 §6 참조.  유형 A 는 증명, 유형 B 는 한 설정만 미해결.

## 6. 교차 구조와 보조정리 E′ (§6)

`p` 가 자유로 나가면 후속 pass 는 `τ(entry(ν(p)))` 이고, 이것은 `orb(entry(ν(p)))` 의 어떤
run 의 **첫 pass** 다.  두 경우뿐이다.

* **경우 (i)** — 그 run 이 `ν(p)` 를 담는다.
* **경우 (ii)** — `ν(p)` 는 **같은 궤도의 다른 run** 에 있다 ⟹ 그 궤도의 run 이 둘 ⟹ `e ≥ 1`.

**순서 보조정리.** 경우 (i) 이면 walk 순서로 **`p < ν(p)`** 다.  (그 run 은
`τ(entry(ν(p)))` 에서 시작하는데 `τ` 는 크기 `n−1` 궤도에 고정점이 없으므로
`τ(entry(ν(p))) ≠ entry(ν(p))`, 즉 `ν(p)` 는 run 의 첫 pass 가 아니고 `p` 의 바로 다음
pass 보다 뒤에 있다.)

> ### 보조정리 E′ (모든 `F`, 모든 `n`)
> `e_h ≥ 2` 인 육각형 `h` 의 pass 가 **전부** 자유로 나가면, 그중 하나는 경우 (ii) 이고
> 따라서 **`e ≥ 1`** 이다.
>
> *증명.* 전부 경우 (i) 이면 `ν`-순환을 따라 `p < ν(p) < ν²(p) < … < ν^{e_h}(p) = p`.  모순. ∎

`F = 1` 특수화가 정확히 라운드 117 의 보조정리 E 다(순환 길이 2, `f_out = 2 ⟹ e ≥ 1`).
라운드 117 이 따로 다룬 경계 경우(A 가 첫 pass / B 가 마지막 pass)는 순서 보조정리
형태에서는 **필요 없다.**

### 6.1 유형별 귀결

* **유형 A** (`ν` 가 3-순환): `f_out = 3` ⟺ 세 pass 가 모두 자유 ⟹ E′ ⟹ `e ≥ 1`.
  세 후속의 목표 궤도는 육각형의 서로 다른 세 단어의 궤도라 **서로 다르므로**,
  경우 (ii) 인 궤도에서 run 이 둘이 되어 `e ≥ 1` 이 확실하다.
  ⟹ **`f_out ≤ F + e` 증명됨.**
* **유형 B** (`ν` 가 2-순환 둘): `f_out ≥ 3` 이면 비둘기집으로 어느 한 육각형이 완전 자유
  ⟹ E′ ⟹ `e ≥ 1`.  따라서 **`e = 0 ⟹ f_out ≤ 2 = F + e`** 이고
  **`e ≥ 2 ⟹ f_out ≤ 4 ≤ F + e`** 다.
  남는 것은 **`f_out = 4` 이면서 `e = 1`** 하나뿐이다.  이때 두 육각형이 각각 경우 (ii) 를
  하나씩 내놓는데, **두 경우 (ii) 가 같은 궤도를 가리킬 수 있어** `e ≥ 2` 가 강제되지 않는다.

> **`F = 2` 에서 `f_out ≤ F + e` 는 정확히 한 설정으로 환원된다 —
> 유형 B, `f_out = 4`, `e = 1`.**

## 7. 자원 회계 (§7)

**`S = (r − 1) + x − f_out`, `r = O + e`.  유도에 `F` 가 들어가지 않는다.**

inter-run joint 는 `r − 1` 개다.  §5.2 에 의해
(a) full pass 에서 나가는 `ω=2` joint 는 같은 궤도라 inter-run 이 아니고,
(b) 짧은 pass 에서 나가는 `ω=2` joint 는 언제나 inter-run 이다.
따라서 `#{inter-run, ω=2} = f_out` 이고 나머지 `r − 1 − f_out` 개는 `ω ≥ 3`.
intra-run 중 `ω ≥ 3` 인 것이 `x` 개이므로 `S = #{ω≥3} = (r−1−f_out) + x`. ∎

귀결:

    N = S + F − O = F − 1 + e + x − f_out
    **L = 867 + k + F + e + x + H − f_out**            (n = 6)
    F = 2:  L = 869 + k + e + x + H − f_out
    **L ≤ 871  ⟺  k + e + x + H − f_out ≤ 2**

두 실제 문자열에서 검산된다: 검증된 872 witness(`k=5, F=25, S=3, H=0`)는
`e+x−f_out = −25` 라 `L = 867+5+25−25 = 872` ✓, greedy 873(`k=0,F=0,S=23,H=6`)은
`e+x−f_out = 0` 이라 `L = 867+0+0+0+6 = 873` ✓.

### 7.1 정리 A 의 정확한 지위

`O ≤ 1 + S + F` ⟺ **`f_out ≤ F + e + x`** 다.  이것이 프로젝트의 **55칸 표**(`k + H ≤ 4`)를
지탱하는데, 라운드 110 은 이것을 **문자열 5개와 `n=4` 전수에서 경험적으로만** 확인했고
라운드 117 이 `F = 1` 에서 보조정리 E 로 증명했다.

> **이 라운드는 정리 A 를 `F = 2` 유형 A 전체와 유형 B 의 한 설정을 뺀 전부에서 증명한다.**
> 남는 구멍은 **유형 B, `f_out = 4`, `e = 1`, `x = 0`** 딱 하나다.
> `F ≥ 3` 에서 정리 A 는 여전히 **경험적**이다.

## 8. 무거운 tail 과 `H` (§8)

라운드 125 가 정정한 목록을 쓴다: 무게 1·2·3·4·5 는 `1, 1, 3, 13, 71`,
무게 6 은 **진짜 이음매 308개**(분해불가 순열 461개가 아니다).

`k + e + x + H − f_out ≤ 2` 와 `k ≥ 1` 에서 `H ≤ 1 + f_out − k − e − x` 이므로:

| 경우 | `f_out` | 강제되는 `e` | `H` 상한 |
|---|---|---|---|
| 유형 A, `f_out ≤ 2` | ≤2 | 0 | **3** |
| 유형 A, `f_out = 3` | 3 | ≥1 | **3** |
| 유형 B, `f_out ≤ 2` | ≤2 | 0 | **3** |
| 유형 B, `f_out = 3` | 3 | ≥1 | **3** |
| 유형 B, `f_out = 4` | 4 | ≥1 | **4** ← 구멍 |

> **`H > 3` 은 오직 유형 B 의 그 한 설정(`f_out=4, e=1, x=0, k=1`)에서만 가능하다.**
> `f_out ≤ F + e` 든 정리 A 든 하나만 있으면 **`H ≤ 3`** 이고, `F = 1` 과 같은 상한이 된다.

`H = 4` 의 무거운 조성은 `[6,4] · [5,5] · [5,4,4] · [4,4,4,4]` 네 가지다.

## 9. 실현 가능한 `(k, F=2)` 칸 (§9)

`k` 가 1에서 시작한다고 **가정하지 않았다** — `F ≤ (n−1)k` 에서 `k ≥ 1` 이 나온다.

| 가정 | `k` 범위 | 칸 수 |
|---|---|---|
| 없음 | `1, 2, 3, 4, 5` | **5** |
| 정리 A | `1, 2, 3, 4` | **4** |
| `f_out ≤ F + e` | `1, 2, 3, 4` | **4** |

프로젝트의 표준 55칸 표는 `F = 2` 열에 **4칸**(`k = 1..4`)을 둔다 — 그 표가 정리 A 를
쓰기 때문이다.  **정리 A 없이는 `(5,2)` 가 산술적으로 열려 있다.**
`f_out ≤ F + e` 를 가정하면 추가로 **`k + x + H ≤ 4`** 가 나와 `F = 1` 의 라운드-121
따름정리와 정확히 같은 모양이 된다.

## 10. `n = 4` 반증 (§10)

### 10.1 모형 정정 — joint 합법성

`a → b` 가 `ω = m` 이면 문자열은 `a` 뒤에 `b` 의 마지막 `m` 글자를 붙인 것이고 오프셋
`1..m−1` 에 새 창이 생긴다.  NR6 walk 의 문자열은 각 순열을 정확히 한 번 창으로 가져야
하므로 **그 중간 창은 순열이면 안 된다.**

**라운드 120·122 의 `n = 4` 대조는 이 조건을 걸지 않았다.**  대조로서는 유효하다
(초집합에서 성립하면 부분집합에서도 성립한다).  그러나 구조 통계는 크게 달라진다 —
`maxlen = 35` 에서 walk 345개(초집합) 대 **131개**(합법).  라운드 122 의 결론은 합법
모형에서 다시 재도 살아남는다:

| | walk | `F=1` walk | 첫 pass full | 양 끝 full |
|---|---|---|---|---|
| 초집합 (라운드 120·122 형태) | 345 | 145 | 100 (69.0%) | 64 (44.1%) |
| **합법** | 131 | 57 | 38 (**66.7%**) | 28 (**49.1%**) |
