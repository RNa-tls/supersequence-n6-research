## 2. genuine 후속 구조 (§2)

미래 이력은 의무를 `v1, …, vm` 으로 정렬하고 연속쌍이 합법 전이로 이어진다. 따라서 선택된
간선은 **`({root} ∪ 의무∖{terminal}) → 의무` 의 전단사**다:

* root 는 정확히 하나의 첫 의무를 공급한다 — **root 는 반드시 쓰인다**;
* 모든 의무는 실제 선행자를 정확히 하나 가진다;
* terminal 하나를 뺀 모든 의무는 실제 후속을 정확히 하나 가진다;
* 의무는 두 번 나타나지 않는다.

root 는 의무 정점이 **아니다**(현재 pass 는 이미 시작된 pass이고 진입 의무가 아니다).

## 5. 왜 둘 다 공허한가

A+B2 를 통과한 그래프에서 source 는 `m+1` 개, target 은 `m` 개이고 root 는 모든 의무에
도달한다. 그러면 증가경로가 언제나 root 를 편입시킬 수 있어 Hall 포화 매칭을 root 사용
매칭으로 바꿀 수 있다. 즉 **차수 완화는 Hall + A + B2 를 넘어서지 못한다.**

`r` 분해도 이번엔 차이가 없다 — `r=0` 4,476 · `r=1` 326, 양쪽 다 폐쇄 0.
`UNIQUE_AB` 1,069 에서도 폐쇄 0이다.

## 6. C3 — 하지 않았고, 여기서 정확 복잡도가 시작된다 (§6, §11)

§11 게이트대로 C1 → C2 순으로 돌렸고 둘 다 0이므로 C3(subtour/컷 제거)만 남는다.
그러나 **차수 배정 + subtour 제거는 뿌리 Hamilton 경로와 사실상 동치**다 — 라운드 94 에서
그 정확 탐색이 427/427 쌍 캡 도달이었던 바로 그 문제다. 따라서 C3 은 "값싼 완화" 가 아니며,
**정확 경로 복잡도가 시작되는 지점**으로 명확히 표시한다.
