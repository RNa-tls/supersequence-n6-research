## 1. `(2,1)` 예산을 제1원리에서 다시 유도한다 (§1)

라운드 110 의 정정된 항등식만 쓴다.

    P = 120 + F,   O = 24 + k,   D = 5O − P,   L = 844 + F + S + H,
    S = #{이음매: ω ≥ 3},   H = Σ (ω−3)₊,   cost(ω) = [ω≥3] + (ω−3)₊

`k = 2`, `F = 1` 이면

    P = 121,  O = 26,  D = 5·26 − 121 = **9**,  L = 845 + S + H,
    L ≤ 871  ⟺  **S + H ≤ 26**

이음매는 120개다. run 수를 `r`, run **내부** 비용-1 이음매 수를 `x`, run **사이**
자유(ω=2) 이음매 수를 `f_out` 이라 하면 run 내부 이음매는 `121 − r` 개, run 사이는
`r − 1` 개이므로

    S = x + (r − 1) − f_out,     r = O + e = 26 + e
    ⇒  **S = 25 + e + x − f_out**

(이 상수는 브리프를 믿지 않고 위처럼 다시 유도했다.)  따라서

    S + H ≤ 26  ⟺  **e + x + H ≤ 1 + f_out**

여기에 **보조정리 E**(`F=1` ⟹ `f_out ≤ 1 + e`, 라운드 117)와 `f_out ≤ 2`(짧은 pass 가
둘뿐)를 넣으면

    e + x + H ≤ 1 + f_out ≤ 2 + e   ⇒  **x + H ≤ 2**
    f_out = 2 ⟹ e ≥ 1

### 1.1 곁따름 — `F = 1` 이면 `k ≤ 4`

같은 회계를 일반 `k` 로 쓰면 `S = 23 + k + e + x − f_out` 이고 `S + H ≤ 26` 에서

    k + e + x + H ≤ 3 + f_out ≤ 4 + e   ⇒  **k + x + H ≤ 4**

`D = 5k − 1 ≥ 0` 이므로 `k ≥ 1`. 즉 **`F = 1` 인 길이 ≤871 walk 은 `k ∈ {1,2,3,4}`**
에만 있을 수 있고, 라운드 117·120 이 `(4,1)`·`(3,1)` 을 닫았으므로 **남은 것은
`(2,1)` 과 `(1,1)` 뿐**이다.

## 2. `H` 의 정확한 범위 (§2)

`x + H ≤ 2` 에서 **`H ≤ 2`** — 가정이 아니라 유도다. 그리고

* `H = 2` ⟹ `x = 0`, `f_out ≥ e + 1` ⟹ `e ≤ 1`
* `H = 1` ⟹ `x ≤ 1`, `e + x ≤ f_out`
* `H = 0` ⟹ `x ≤ 2`

`t`(사슬 수) = 1 + (무거운 이음매 수).

## 3. 허브세 조성 (§3)

`cost(ω) = [ω≥3] + (ω−3)₊` 이므로 `ω = 2,3,4,5,6` 의 `(S,H)` 기여는
`(0,0), (1,0), (1,1), (1,2), (1,3)` 이다. 따라서 `H = 2` 는 **정확히 두 가지**로만
나온다:

| `H` | 조성 | 무거운 이음매 수 `= t − 1` |
|---|---|---|
| 0 | 없음 | 0 |
| 1 | 무게-4 하나 | 1 |
| 2 | **무게-4 두 개** | 2 |
| 2 | **무게-5 하나** | 1 |

`ω = 6` 은 `H = 3 > 2` 라 불가능하다. 혼합(예: 무게-4 하나 + 무게-3 하나)은 무게-3 이
`H` 에 0 을 내므로 `H` 조성에 들어오지 않는다. **브리프 §12 대로 두 조성을 합치지 않고
따로 탐색한다.**

### 3.1 tail 목록 — 550개

무게 `w` 이음매는 `z = (y[w], …, y[5], y[π(0)], …, y[π(w−1)])` 이고 `π` 는 `{0..w−1}` 의

## 5. 뒤집기 대칭 `Φ` 로 무엇을 줄일 수 있는가 — **증명해서만** 쓴다 (§5)

라운드 120 의 `Φ`(pass 열을 뒤집고 `(u,m) ↦ (ρ(σ^{m−1}u), m)`)는 `L·P·F·S·H` 를 보존하고
`b ↦ 6−b`, 그리고 **X 앞 pass 수 ↔ Y 뒤 pass 수**를 맞바꾼다.

**하지만 `Φ` 는 `O`(따라서 `k`)를 일반적으로 보존하지 않는다.** 전수로 확인한 사실:

    u ↦ ρ(σ^{m−1} u) 가 tau-궤도를 궤도 위로 보내는 것은 **m = 6 일 때뿐**이다
    (m = 1..5 에서는 궤도 상의 크기가 5 — 완전히 흩어진다).

full pass 는 `m = 6` 이라 `R = ρ∘σ⁵` 로 궤도가 옮겨가지만 **짧은 pass 두 개는 아니다**.
그래서 `Φ` 가 `(2,1)` 을 자기 자신으로 보낸다고 **가정하면 안 된다** — 라운드 120 처럼
`b ↔ 6−b` 를 그냥 반으로 접는 것은 `k=2` 에서 **불건전**하다.

### 5.1 보조정리 — `X` 의 탈출이 자유이면 `Φ` 는 `O` 를 보존한다

`A` := 119개 full pass 진입 단어의 궤도 집합. 그러면 `O = |A ∪ {orb X, orb Y}|`.

`X` 의 탈출 이음매가 자유(`ω = 2`)라 하자.

* `X` 의 자유 후속은 `τ(entry_Y) ∈ orb(Y)` 이고, 라운드 116 **정리 D** 로 `X` 와 `Y` 는
  이웃하지 않으므로 그 pass 는 **full** 이다. 따라서 **`orb(Y) ∈ A`**.
* 뒤집힌 walk 에서 `Φ(X)` 로 들어오는 이음매는 그 full pass 의 상에서 나오므로 `ℓ = 5`,
  무게 2 — 즉 **`τ`(궤도 내부)** 다(라운드 120 규칙 R3). 따라서
  `orb(Φ(X)) = R̂(orb(τ(entry_Y))) = R̂(orb Y)`.
* `Y` 의 상 진입 단어는 `ρ(σ^{5−b}(σ^b v)) = ρ(σ⁵ v) = R(v) ∈ R̂(orb X)`.

그러므로 뒤집힌 walk 의 궤도 집합은 `R̂(A) ∪ {R̂(orb X)} = R̂(A ∪ {orb X})` 이고
`orb(Y) ∈ A` 이므로

    O_rev = |A ∪ {orb X}| = |A ∪ {orb X, orb Y}| = O.        ∎

`f_out = 2` 는 짧은 pass **둘 다** 자유로 나가므로 이 조건을 **항상** 만족한다.

### 5.2 따라서 정규형은 `f_out = 2` 그룹에만 쓴다

> 17개 그룹의 합집합이 `(2,1)` 의 **모든** 행을 **모든 분할**에서 덮는다.
> `f_out = 2` 인 walk `W` 의 접두가 접미보다 길면 `Φ(W)` 는 **여전히 `(2,1)` 의 walk**
> (§5.1)이고 접두 ≤ 접미이며 분할이 `6−b` 다 — 그것이 속한 그룹은 `f_out = 2` 면
> 정규형을 만족하고, 아니면 정규형 없이 돌린다. **어느 쪽이든 잡힌다.**
> `f_out ≤ 1` 그룹에는 정규형을 **쓰지 않는다**(그 경우 `Φ` 가 `k=1` 로 내보낼 수 있고
> `(1,1)` 은 아직 열려 있다).

`pmax` 는 라운드 120 의 59 를 그대로 쓰면 **틀린다**. 다시 유도한다: 접두 ≤ 접미는
`p − 1 ≤ 121 − q` 이고 `dist(X,Y) = q − p ≥ 2`(정리 D)이므로 `2p ≤ 120`, 즉

    **pmax = 60**  (라운드 120 의 59 는 `B_ii` 전용 `dist ≥ 4` 에서 나온 값이다)

`seam` 은 라운드 120 에서 "경계 경우의 `Φ` 상이 이미 닫힌 행에 있다" 는 논증으로만
정당화됐다. `k = 2` 에서는 그 상들이 **이 칸 안**이거나 `(1,1)` 이라 **쓸 수 없다.**
`revonly`·`yfresh` 도 마찬가지로 쓰지 않았다.

## 7. 자원 행 표 (§7)

`e + x + H ≤ 1 + f_out` 과 `f_out ≤ min(2, 1+e)` 로 **24개 행**(`H` 조성을 가르면
**26개 하위경우**)이 나온다. 구조로는:

| 구조 | 조건 | 행 수 |
|---|---|---|
| **A. all-light 사슬 하나** (`t=1`) | `H = 0` | 14 |

## 10. 무거운 이음매 위치 조건화와 간격 분기 (§10, §11)

`f_out = 2` 이면 `X` 의 자유 후속이 `orb(Y)` 의 run 을 열고 `Y` 의 자유 후속이 `orb(X)` 의
run 을 연다. `R_X^end`(X 에서 끝남)와 `R_X^start`(Y 뒤에서 시작)는 **언제나 다른 run** 이므로
**`orb(X)` 가 `e` 를 한 단위 쓴다.**

* **`e = 1`**: 그것이 유일한 여분 run 이므로 **`orb(Y)` 는 run 이 하나**다. 그 run 은
  phase `φ+1` 에서 `φ` 까지 **+4** 를 나아가야 하고 run 내부 걸음은 `τ`(+1)·`W3a`(+2)·
  `W4_0`(+3)·`W5_0`(+4) 뿐이며 phase 가 서로 달라야 하므로 **합이 정확히 4**, 걸음 수 ≤ 4.
  ⇒ **`dist(X,Y) ≤ 5`** (`ygap = 5`). `x = 0` 이면 순수 `τ` 블록이라 **정확히 5** 이고
  블록 전체가 강제된다.
* **`e ≥ 2`**: 갈린다.
  * **A**: `dist(X,Y) ≤ 5` (`orb(Y)` 가 run 하나인 경우를 포함한다)
  * **B**: `dist(X,Y) ≥ 6` ⟹ **`orb(Y)` 는 run 이 둘 이상**이다. `e = 2` 면 여분 run 두 개가
    `orb(X)`·`orb(Y)` 로 **정확히** 소진되므로 **다른 궤도는 재방문되지 않고**(`revonly`)
    **`orb(Y)` 는 X 이전에 진입될 수 없다**(`yfresh`) — 라운드 119 §3 의 논증을 다시 유도한 것이다.

무거운 이음매는 `x = 0` 인 행에서 **run 내부가 될 수 없으므로**(궤도 내부 무게-4/5 는 `x` 를
쓴다) 전부 inter-run 이고, `f_out = 2` 가 `X`·`Y` 의 탈출을 자유로 강제하므로 **강제 블록
안에도, 두 짧은 pass 의 탈출에도 올 수 없다** — `X` 앞 또는 `Y` 뒤다.

**§11 이 요구한 위치 유형 정리는 얻지 못했다.** `Φ` 로 "둘 다 X 앞" ↔ "둘 다 Y 뒤" 를
짝지을 수는 있지만 대합의 정규형은 이미 `b ≤ 3` 에 썼고, 위치로 3분할하면 접두를 세 번
다시 탐색해야 해서 **순이득이 없다**. 정직하게 적어 둔다.

## 13. `D = 9` 를 더 강한 결손 예산으로 쓴다 (§13)

`D = 5O − P = 9` 는 `e` 와 **무관하게** 고정이다(궤도 수 `O = 26` 이 고정이므로).
`k=3` 의 14 보다 훨씬 빡빡하고, 실제로

* §8 의 해석적 폐쇄 2행이 `D = 9` 덕분에 생겼다(같은 계산이 `D = 14` 에서는 아무것도 못 죽인다).
* 같은 구조의 탐색이 `k=3` 보다 **수십 배 싸다** — 예: `e=0, H=0, b=1` 은 **1,160만 노드/1초**.

### 13.1 새 정확 프룬 — 신선 궤도 결손 (`fod`)

`O = 26` 이 정확하므로 앞으로 **정확히 `26 − orbits` 개**의 신선 궤도를 더 열어야 한다.
신선 궤도 `Q` 의 다섯 육각형 중 **이미 쓰인 것**에는 영원히 진입할 수 없으므로

    d_Q ≥ blk(Q) := |hex(Q) ∩ (이미 쓰인 육각형)|

이고, 이미 **떠난** 궤도의 결손과는 서로 다른 궤도를 세므로 그냥 더할 수 있다:

> **`dcommitted + (신선 궤도의 blk 중 작은 것 `26−orbits` 개의 합) ≤ D = 9`**

`h*` 만 두 번 진입되고 두 번째가 `Y` 이므로 **`X` 의 육각형은 `Y` 가 놓일 때까지 막지
않는다**(그렇게 구현했다). 육각형이 쓰일 때 그 육각형을 만나는 6개 궤도의 `blk` 을 올리는
증분 갱신이라 노드당 비용이 사실상 0 이다.

## 14. 궤도-덮개 잉여와 `h*` 재진입의 한 단위 차이 (§14)

궤도 하나는 정확히 5개 육각형을, 육각형 하나는 정확히 6개 궤도를 만난다. 쓰인 궤도가
120개 육각형을 전부 덮어야 하므로 `Σ_h m_h = 5O = 130` 이고

    **EXC := Σ_h (m_h − 1) = 5O − 120 = 5k = 10**
    **D   := Σ_Q d_Q      = 5O − 121 = 9**

차이 **정확히 1** 은 **`h*` 의 두 번째 진입**이다: 육각형 `h` 에서 "진입하지 않는" 접촉 수는
`m_h − 1`(단 `h*` 는 `m_h − 2`)이고, 합이 `130 − 121 = 9 = D` 인 반면 `Σ(m_h−1) = 10 = EXC`.

> **더 날카로운 진술 (§14 가 요구한 것).** `orb(X) ≠ orb(Y)` 이고 둘 다 `h*` 를 만나므로
> **`m_{h*} ≥ 2`** 다. 따라서
>
>     Σ_{h ≠ h*} (m_h − 1) = D − (m_{h*} − 2) ≤ 9
>
> 즉 **보통 궤도 겹침의 예산은 `h*` 재진입과 분리해 정확히 `D = 9`** 이고, `h*` 가 두 궤도만
> 만나면(`m_{h*} = 2`) 그 예산이 온전히 남는다.
>
> **따름 (완전 궤도 서로소).** `d_Q = 0` 인 궤도(다섯 단어가 전부 진입 단어)를 **완전 궤도**라
> 하자. 완전 궤도 둘이 육각형 `h` 를 공유하면 `h` 에 진입이 둘 생기므로 `h = h*` 이고
> 그 둘은 `{orb(X), orb(Y)}` 다. `D = 9` 이므로 **26개 궤도 중 적어도 17개가 완전 궤도**이고,
> 그 17개는 `h*` 를 통한 한 쌍을 빼면 **서로 육각형-서로소**다.

**정직한 계측.** `EXC ≤ 10` 프룬(`exccap`)은 라운드 120 에서와 마찬가지로 거의 효과가
없었다 — `EXC = 5·orbits − (덮인 육각형 수)` 라 `dcap` 과 거의 같은 정보이기 때문이다.
**이번 라운드에서 실제로 효과를 낸 것은 `dcap = 9` 자체와 `f_out` 분할(2.5배)이다.**
