**작성:** Claude 단독. **정리 라운드 + 유한 전수 탐색. 두 원장 변경 없음.**
**라운드:** 121 (generic `(2,1)` closure)
**원장:** INDEPENDENTLY AUDITED **4,782** · CLAUDE FULL-JOINT Q2 **6,396/6,396** — 변경 없음.

## 1. `(2,1)` 예산을 제1원리에서 다시 유도한다 (§1)

라운드 110 의 정정된 항등식만 쓴다.

    P = 120 + F,   O = 24 + k,   D = 5O − P,   L = 844 + F + S + H,
    S = #{이음매: ω ≥ 3},   H = Σ (ω−3)₊,   cost(ω) = [ω≥3] + (ω−3)₊

`k = 2`, `F = 1` 이면

    P = 121,  O = 26,  D = 5·26 − 121 = **9**,  L = 845 + S + H,
    L ≤ 871  ⟺  **S + H ≤ 26**

이음매는 120개다. run 수를 `r`, run **내부** 비용-1 이음매 수를 `x`, run **사이**
자유(ω=2) 이음매 수를 `f_out` 이라 하면 run 내부 이음매는 `121 − r` 개, run 사이는
`r − 1` 개이므로

    S = x + (r − 1) − f_out,     r = O + e = 26 + e
    ⇒  **S = 25 + e + x − f_out**

(이 상수는 브리프를 믿지 않고 위처럼 다시 유도했다.)  따라서

    S + H ≤ 26  ⟺  **e + x + H ≤ 1 + f_out**

여기에 **보조정리 E**(`F=1` ⟹ `f_out ≤ 1 + e`, 라운드 117)와 `f_out ≤ 2`(짧은 pass 가
둘뿐)를 넣으면

    e + x + H ≤ 1 + f_out ≤ 2 + e   ⇒  **x + H ≤ 2**
    f_out = 2 ⟹ e ≥ 1

### 1.1 곁따름 — `F = 1` 이면 `k ≤ 4`

같은 회계를 일반 `k` 로 쓰면 `S = 23 + k + e + x − f_out` 이고 `S + H ≤ 26` 에서

    k + e + x + H ≤ 3 + f_out ≤ 4 + e   ⇒  **k + x + H ≤ 4**

`D = 5k − 1 ≥ 0` 이므로 `k ≥ 1`. 즉 **`F = 1` 인 길이 ≤871 walk 은 `k ∈ {1,2,3,4}`**
에만 있을 수 있고, 라운드 117·120 이 `(4,1)`·`(3,1)` 을 닫았으므로 **남은 것은
`(2,1)` 과 `(1,1)` 뿐**이다.

## 2. `H` 의 정확한 범위 (§2)

`x + H ≤ 2` 에서 **`H ≤ 2`** — 가정이 아니라 유도다. 그리고

* `H = 2` ⟹ `x = 0`, `f_out ≥ e + 1` ⟹ `e ≤ 1`
* `H = 1` ⟹ `x ≤ 1`, `e + x ≤ f_out`
* `H = 0` ⟹ `x ≤ 2`

`t`(사슬 수) = 1 + (무거운 이음매 수).

## 3. 허브세 조성 (§3)

`cost(ω) = [ω≥3] + (ω−3)₊` 이므로 `ω = 2,3,4,5,6` 의 `(S,H)` 기여는
`(0,0), (1,0), (1,1), (1,2), (1,3)` 이다. 따라서 `H = 2` 는 **정확히 두 가지**로만
나온다:

| `H` | 조성 | 무거운 이음매 수 `= t − 1` |
|---|---|---|
| 0 | 없음 | 0 |
| 1 | 무게-4 하나 | 1 |
| 2 | **무게-4 두 개** | 2 |
| 2 | **무게-5 하나** | 1 |

`ω = 6` 은 `H = 3 > 2` 라 불가능하다. 혼합(예: 무게-4 하나 + 무게-3 하나)은 무게-3 이
`H` 에 0 을 내므로 `H` 조성에 들어오지 않는다. **브리프 §12 대로 두 조성을 합치지 않고
따로 탐색한다.**

### 3.1 tail 목록 — 550개

무게 `w` 이음매는 `z = (y[w], …, y[5], y[π(0)], …, y[π(w−1)])` 이고 `π` 는 `{0..w−1}` 의
**분해불가** 순열이다(분해가능하면 중간 창이 그 자체로 순열이라 순열 하나를 건너뛰게 되어
pass 분해의 이음매가 아니다). 개수는

    w = 1,2,3,4,5,6  →  1, 1, 3, 13, 71, 461     합 **550**

전수로 확인했다. 이 라운드가 실제로 쓰는 것은 **무게-4 13개**와 **무게-5 71개**다.

## 5. 뒤집기 대칭 `Φ` 로 무엇을 줄일 수 있는가 — **증명해서만** 쓴다 (§5)

라운드 120 의 `Φ`(pass 열을 뒤집고 `(u,m) ↦ (ρ(σ^{m−1}u), m)`)는 `L·P·F·S·H` 를 보존하고
`b ↦ 6−b`, 그리고 **X 앞 pass 수 ↔ Y 뒤 pass 수**를 맞바꾼다.

**하지만 `Φ` 는 `O`(따라서 `k`)를 일반적으로 보존하지 않는다.** 전수로 확인한 사실:

    u ↦ ρ(σ^{m−1} u) 가 tau-궤도를 궤도 위로 보내는 것은 **m = 6 일 때뿐**이다
    (m = 1..5 에서는 궤도 상의 크기가 5 — 완전히 흩어진다).

full pass 는 `m = 6` 이라 `R = ρ∘σ⁵` 로 궤도가 옮겨가지만 **짧은 pass 두 개는 아니다**.
그래서 `Φ` 가 `(2,1)` 을 자기 자신으로 보낸다고 **가정하면 안 된다** — 라운드 120 처럼
`b ↔ 6−b` 를 그냥 반으로 접는 것은 `k=2` 에서 **불건전**하다.

### 5.1 보조정리 — `X` 의 탈출이 자유이면 `Φ` 는 `O` 를 보존한다

`A` := 119개 full pass 진입 단어의 궤도 집합. 그러면 `O = |A ∪ {orb X, orb Y}|`.

`X` 의 탈출 이음매가 자유(`ω = 2`)라 하자.

* `X` 의 자유 후속은 `τ(entry_Y) ∈ orb(Y)` 이고, 라운드 116 **정리 D** 로 `X` 와 `Y` 는
  이웃하지 않으므로 그 pass 는 **full** 이다. 따라서 **`orb(Y) ∈ A`**.
* 뒤집힌 walk 에서 `Φ(X)` 로 들어오는 이음매는 그 full pass 의 상에서 나오므로 `ℓ = 5`,
  무게 2 — 즉 **`τ`(궤도 내부)** 다(라운드 120 규칙 R3). 따라서
  `orb(Φ(X)) = R̂(orb(τ(entry_Y))) = R̂(orb Y)`.
* `Y` 의 상 진입 단어는 `ρ(σ^{5−b}(σ^b v)) = ρ(σ⁵ v) = R(v) ∈ R̂(orb X)`.

그러므로 뒤집힌 walk 의 궤도 집합은 `R̂(A) ∪ {R̂(orb X)} = R̂(A ∪ {orb X})` 이고
`orb(Y) ∈ A` 이므로

    O_rev = |A ∪ {orb X}| = |A ∪ {orb X, orb Y}| = O.        ∎

`f_out = 2` 는 짧은 pass **둘 다** 자유로 나가므로 이 조건을 **항상** 만족한다.

### 5.2 따라서 정규형은 `f_out = 2` 그룹에만 쓴다

> 17개 그룹의 합집합이 `(2,1)` 의 **모든** 행을 **모든 분할**에서 덮는다.
> `f_out = 2` 인 walk `W` 의 접두가 접미보다 길면 `Φ(W)` 는 **여전히 `(2,1)` 의 walk**
> (§5.1)이고 접두 ≤ 접미이며 분할이 `6−b` 다 — 그것이 속한 그룹은 `f_out = 2` 면
> 정규형을 만족하고, 아니면 정규형 없이 돌린다. **어느 쪽이든 잡힌다.**
> `f_out ≤ 1` 그룹에는 정규형을 **쓰지 않는다**(그 경우 `Φ` 가 `k=1` 로 내보낼 수 있고
> `(1,1)` 은 아직 열려 있다).

`pmax` 는 라운드 120 의 59 를 그대로 쓰면 **틀린다**. 다시 유도한다: 접두 ≤ 접미는
`p − 1 ≤ 121 − q` 이고 `dist(X,Y) = q − p ≥ 2`(정리 D)이므로 `2p ≤ 120`, 즉

    **pmax = 60**  (라운드 120 의 59 는 `B_ii` 전용 `dist ≥ 4` 에서 나온 값이다)

`seam` 은 라운드 120 에서 "경계 경우의 `Φ` 상이 이미 닫힌 행에 있다" 는 논증으로만
정당화됐다. `k = 2` 에서는 그 상들이 **이 칸 안**이거나 `(1,1)` 이라 **쓸 수 없다.**
`revonly`·`yfresh` 도 마찬가지로 쓰지 않았다.

## 7. 자원 행 표 (§7)

`e + x + H ≤ 1 + f_out` 과 `f_out ≤ min(2, 1+e)` 로 **24개 행**(`H` 조성을 가르면
**26개 하위경우**)이 나온다. 구조로는:

| 구조 | 조건 | 행 수 |
|---|---|---|
| **A. all-light 사슬 하나** (`t=1`) | `H = 0` | 14 |
| **B. 무게-4 하나로 갈린 사슬 둘** (`t=2`) | `H = 1` | 7 |
| **C. 무게-4 둘, 사슬 셋** (`t=3`) | `H = 2` (4+4) | 3 |
| **D. 무게-5 하나, 사슬 둘** (`t=2`) | `H = 2` (5) | 3 |

(B/C/D 의 행 수는 `H` 를 고정한 뒤 남는 `(e,x,f_out)` 조합 수다. C 와 D 는 같은 `(e,x,f_out)`
행을 공유하지만 **조성이 달라 따로 센다** — §12.)

**숨은 여유는 없다**: `e ≥ 4` 는 `e + x + H ≤ 1 + f_out ≤ 3` 에 걸리고, `x ≥ 3` · `H ≥ 3` 도
같은 부등식에 걸린다.

## 8. 탐색 전에 회계로만 죽는 행 (§8)

라운드 115 의 전수 사슬 용량표 `NTAB[s]`(run 결손 `s` 이하인 R115-모델 all-light 사슬

무거운 이음매 `t−1` 개가 walk 을 조각으로 자르므로 조각 수는

    m = 3 + x + e + (t − 1),      전체 run 결손 = 5r − 121 = 9 + 5e

| 행 | `m` | 결손 | 용량 상한 | 판정 |
|---|---|---|---|---|
| `(e,x,f_out,H) = (0,0,0,0)` | 3 | 9 | **112** | **DEAD** (121 에 9 부족) |
| `(0,0,1,0)` | 3 | 9 | **112** | **DEAD** |
| 나머지 22행 | ≥ 4 | ≥ 9 | ≥ 132 | 탐색 필요 |

> `k = 2` 의 run 결손 예산 9 로는 세 조각이 합쳐 **최대 112 pass** 밖에 못 담는다.

> **`D = 9` 가 실제로 더 강하다는 첫 번째 증거다.**

두 행 모두 `x = 0` 이므로 `xcap ≥ 0` 인 그룹 안에 들어 있어 실행 수를 줄이지는 않는다.
**해석적 폐쇄로 따로 기록한다.**
