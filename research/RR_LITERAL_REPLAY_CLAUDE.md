## 1. literal 재생 (§1, §2)

재생은 사후 검사가 아니라 **엔진 구동**이다. 각 pass 를 `ℓ` 번의 회전(weight 1) + joint
(weight ≥ 2)로 전개하고 `extend()` 를 그대로 호출한다. `extend` 는 반복 창이면 `None` 을
돌려주고, pass-start 위상 재등록이면 `AssertionError` 를 던진다.

## 2. 그럼에도 `final_target` 은 전부 실패한다 — 놓친 좌표 (§3)

엔진의 목표 술어는

```
visited_count == 720  ∧  F == 1  ∧  P == 121  ∧  O == 25  ∧  D == 4
                      ∧  Ndef + H ≤ 3          (TARGET_BUDGET)
```

이고 `Ndef = S + F − O` 다. 재생 결과 마지막 항이 **전부 위반**된다:

| SID (예) | `S` | `H` | `Ndef` | **`Ndef+H`** | 예산 |
|---|---|---|---|---|---|
| `3d53e37d` | 59 | 0 | 35 | **35** | 3 |
| `4d5ecc56` | 68 | 0 | 44 | **44** | 3 |
| `e8bba8e4` | 61 | 0 | 37 | **37** | 3 |

22개 전체 분포: `Ndef+H ∈ [35, 58]`. 예산의 **10배 이상**이다.

**왜 모델이 이것을 못 봤는가.** 의무/단어 그래프는 네 joint target 을 **동등하게** 취급한다.
그러나 엔진은 그렇지 않다 — 라운드 100 의 문자열 규칙으로 쓰면

```
T1 = x2 x3 x4 x5 x1 x0     ← weight 2   (dS = 0)
T2 = x3 x4 x5 x1 x2 x0     ← weight 3   (dS = 1)
T3 = x3 x4 x5 x2 x0 x1     ← weight 3   (dS = 1)
T4 = x3 x4 x5 x2 x1 x0     ← weight 3   (dS = 1)
```

즉 **네 간선 중 하나만 공짜이고 셋은 `S` 를 1씩 쓴다.** `dH = max(w−3,0) = 0` 이므로 `H` 는
변하지 않는다. 미래 구간에서 `ΔO = K`(아직 열어야 할 궤도 수)가 고정이므로

> **미래에 쓸 수 있는 weight-3 joint 의 개수 `E` 는**
> `E ≤ B := 3 + K − Ndef_now − H_now`
> **로 정확히 제한된다.**

이것이 §3 이 요구한 **가장 작은 추가 좌표**다 — 720-bit 방문 마스크가 아니라 **정수 하나**.

## 3. 새 좌표의 크기 (전수 측정)

W-A 통과 15,781 쌍 전부에서:

| | 중앙값 | 최소 | 최대 |
|---|---|---|---|
| 예산 `B = 3 + K − Ndef − H` | **21** | 18 | 24 |
| 의무 수 `m` | 107–108 | | |

즉 **107–108 개의 미래 pass 중 많아야 ~21 개만 weight-3 joint 를 쓸 수 있고, 나머지 86개
이상은 유일한 weight-2 joint `T1` 을 써야 한다.** 재생된 22개 증인은 `E ≈ 56–79` 를 써서
이 예산을 크게 넘긴다 — **모델이 SAT 이라고 부른 경로들은 전부 예산 위반이다.**

가장 값싼 즉시 검사(“`T1` 간선으로 진입할 수 없는 의무의 수 ≤ `B`”)는 이번에 **한 번도
발동하지 않았다**(그 수의 중앙값 4, `B` 중앙값 21). 따라서 이 좌표의 힘은 단순 계수가
아니라 **경로 위의 가중 제약**(“싼 간선이 아닌 간선을 `B` 개 이하로 쓰는 rooted Hamilton
경로”)에 있고, 그것이 라운드 104 의 표적이다.

`T1` 부분그래프는 단어마다 후속이 **정확히 하나**인 함수형 그래프이므로, 경로는
“`T1` 사슬들을 `≤ B` 번의 비싼 점프로 이어붙인 것”이 된다. 이 구조는 이미 증명된 조건들과
독립적이고 훨씬 강하다.

## 5. W-E 건전성 (§9)

genuine 완성은 (i) W-A 통과 최종 cover 하나, (ii) 구체 단어 배정 `A` 하나, (iii) `G_A` 위의
rooted Hamilton 순서 하나를 **결정한다**. 그 순서는 이미 증명된 필요조건 A/B2/D4/D1 을 전부
만족해야 한다. 따라서 **모든 cover 의 모든 배정이 그중 하나라도 위반하면 그 상태는 불가능**
하다. 단어 고정은 휴리스틱 삭제가 아니라 "genuine 배정과 양립하지 않는 간선" 을 지우는
것이므로 D4/D1 을 그 위에 거는 것도 건전하다.

이 라운드의 새 발견은 이 논증을 **약화하지 않는다** — `N+H` 예산은 **추가** 필요조건이므로
178 폐쇄는 그대로 유효하고, 오히려 앞으로 더 강해질 여지를 뜻한다.
