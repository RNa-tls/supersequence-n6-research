## 2. port 등록 의미론 (§4)

`extend()` 를 그대로 읽어 유도했다. 추론이 아니라 코드다.

| 사건 | 등록되는 port |
|---|---|
| 회전 `σ` (weight 1) | **없음** — target window 를 방문 처리만 한다 |
| 매크로 joint (weight ≥ 2) | **정확히 1개** — target 단어의 port (`om[q] \|= 1<<phase`) |
| `E¹` (`ℓ=5`, w2:10) | 1개 (같은 궤도, 위상 +1) |
| `E²` (`ℓ=5`, w3:120) | 1개 (같은 궤도, 위상 +2) |
| `G5` opening | 1개 (fresh target 궤도) |
| 재진입 | 1개 (열린 궤도의 미등록 port) |
| **2개 이상 등록** | **불가능** |
| 등록된 port 를 다시 endpoint 로 | **불가능** — 엔진이 `AssertionError` 로 막는다 |

**따름정리.** pass 는 육각형 하나를 소비하고 **진입 칸 하나만** 등록한다. 나머지 5칸은 회전
내부로 방문되므로 no-repeat 상 다시 joint target 이 될 수 없다 — **영원히 등록 불가**다.

아카이브 전수 확인(6,657 상태 × 120 육각형):

| 육각형 종류 | 등록 port 수 | 사례 |
|---|---|---|
| 빈 육각형 | **0** | 709,312 |
| 지나간 육각형 | **1** | 76,214 |
| 지나간 육각형 | **2** | **710** — 정확히 이미 수리된 fragment 수 |
| fragment(미수리) | 1 | 5,947 |
| 현재 육각형 | 1 | 6,657 |

예외 0. `passed:2` 가 정확히 710(= 예산 0 상태 수)이라는 점이 따름정리의 독립 확인이다.

## 3. 경로 조건 (§3, §5, §7)

계수는 이미 `D = 5O − P` 로 표현돼 있으므로 다시 증명하지 않았다(§10 지침). 새로운 것은
**순서**다.

> 남은 빈 육각형 `h` 는 각각 정확히 한 번 진입되고, 진입 칸 `u_h` 는 등록되는 port 이므로
> **최종 25궤도의 단어**여야 한다. 진입 칸에서의 출발은 `ℓ = 5`(fragment 수리만 `5−c_f`)
> 이므로 다음 진입 칸은 `joint(σ^ℓ(u))` 중 하나다. 각 pass 는 정확히 한 번 발사한다.

이는 남은 육각형 위의 Hamilton 경로 조건이다. 폐쇄에는 그 **완화**만 쓴다.

    왼쪽  = 진입해야 하는 육각형(빈 육각형 + fragment)
    오른쪽 = 발사 슬롯(현재 pass + 각 빈 육각형 + fragment), 각각 1회 발사
    간선  = 슬롯의 **어떤** 진입 후보에서 `σ^ℓ` + joint 로 왼쪽 육각형의 **어떤** 후보에 닿음

후보를 합집합으로 쓰므로 관대한 과대근사이고, **Hall 위반만** 폐쇄 근거다. 캡도 타임아웃도
없다 — 매칭은 항상 완전히 끝난다.

관측된 구조적 사실: 전형적인 상태에서 빈 육각형 107개 중 **105~106개가 최종 궤도 단어를
단 하나만** 포함한다. 즉 진입 칸이 사실상 강제되고, 그래서 이 조건이 힘을 가진다.

**리터럴 해부.** 상태 `14fda65d` 의 육각형 101 은 최종 궤도 단어를 **단 하나**(`(0,5,1,4,3,2)`,
궤도 101 위상 0) 포함한다. 그 단어의 **전체** 전임자는 4개뿐이고 — 엔진 대조로 넷 다
`σ⁵ + joint` 관계임을 확인했다 —

* 2개는 비선택 궤도(97, 99)의 단어 → 쓰면 26번째 궤도가 열려 `O > 25`
* 2개는 궤도 101 이지만 **이미 방문됨**(가득 찬 육각형 100, 97) → no-repeat 상 다시 joint
  target 이 될 수 없고, 그 pass 는 이미 발사를 마쳤다

따라서 육각형 101 은 영원히 진입 불가이고, 그 6칸은 결코 다 방문될 수 없다.

**중요한 주의.** 처음에 보존된 witness cover 하나로만 전체를 검사해 "72 % 거부" 라는 숫자를
얻었는데, 그것은 **상태 폐쇄가 아니라 cover 하나의 실패**다. 상태 폐쇄는 아래처럼 모든
valid cover 를 열거해야 성립한다.

## 6. 남은 좌표 (§11)

이번 조건도 여전히 완화다. 아직 쓰지 않은 것:

1. **진입 칸의 일관성.** 매칭은 한 육각형의 후보를 "source 역할" 과 "target 역할" 에서 서로
   다르게 골라도 허용한다. 실제로는 하나의 칸이어야 한다.
2. **경로성.** 매칭은 여러 경로/사이클로 쪼개져도 통과한다. 진짜 조건은 **하나의 경로**다.
3. **fragment 수리 시점.** 수리 pass 가 순서상 어디에 오는지는 아직 자유롭게 둔다.
4. 720-window 전체 이력은 여전히 추상화돼 있다.

1·2 는 같은 자료 위에서 곧바로 강화할 수 있고(경로 커버 수, in/out 차수 정합성),
그것이 다음 라운드의 자연스러운 단계다.
