# 라운드 117 — `(k,F) = (4,1)` 칸: 보조정리 E 와 정확한 all-light 배제

**작성:** Claude 단독. **정리 라운드 + 유한 전수 탐색. 두 원장 변경 없음.**
**라운드:** 117 (F=1 cell closure)
**원장:** INDEPENDENTLY AUDITED **4,782** · CLAUDE FULL-JOINT Q2 **6,396/6,396** — 변경 없음.
**라벨:** ROUND-117 PROVISIONAL · CLAUDE 단독 · 독립 감사 없음.

이 라운드도 **Q2 아카이브에서 아무것도 물려받지 않는다.** `F=0` 열은 건드리지 않았고
`F ≥ 2` 로 넘어가지도 않았다.

---

## 0. 결과

> ### 정리 (`(k,F) = (4,1)` 배제)
> **NR6 아래에서, `F = 1` 이고 `O = 28` 인 모든 walk 은 `L ≥ 872` 다.**
> 즉 길이 ≤ 871 인 초순열은 `(4,1)` 칸에 존재할 수 없다.
>
> `F = 1` 열 네 칸 중 **첫 폐쇄**이며, `F = 0` 열 5칸과 합쳐 **55칸 중 6칸**이 닫혔다.
> `(3,1)`, `(2,1)`, `(1,1)` 은 **열려 있다.**

이 폐쇄를 가능하게 한 것은 아래의 새 보조정리다.

## 0.1 이 라운드의 새 정리

> ### 보조정리 E (`F = 1`)
> **`F = 1` 인 모든 NR6 walk 에서 `f_out ≤ 1 + e` 다.**
> (`f_out` = 자유(무게 2) inter-run 호의 개수, `e = r − O` = 여분 run 수.)
>
> **따름정리.** `F = 1` 에서 `O ≤ 1 + S + F` 는 `f_out ≤ 1 + e + x` 와 **동치**이므로,
> 보조정리 E 가 라운드 110 의 정리 A 를 **`F = 1` 에서 증명한다.** 지금까지 그것은
> 5개 문자열과 `n=4` 전수에서의 **경험적 확인**이었다.

**왜 이것이 필요한가.** 라운드 116 은 `(4,1)` 에서 `H = 0` 이 강제된다고 적었지만, 그
유도는 `O ≤ 1 + S + F` 를 썼다. 이 라운드가 그 근거를 직접 확인해 보니, **내 자신의
회계에서 나오는 것은 더 약한 `O ≤ 1 + S + f_out − x` 뿐**이었다. `f_out = 2, x = 0` 이면
`H ≤ 1` 이 되어 `(4,1)` 이 넓어진다. 보조정리 E 가 그 구멍을 메운다.

## 1. 보조정리 E 의 증명

`h*` 의 두 짧은 pass 를 **A**(진입 `v`, 길이 `b`)와 **B**(진입 `σ^b(v)`, 길이 `6−b`)라 하자
(라운드 116 정리 B·C).

### 1.1 짝지음 항등식 (720 × 5 전수, 3,600/3,600)

pass 의 진입 단어가 `u`, 회전 수가 `ℓ` 이면 탈출 단어는 `σ^ℓ(u)` 이고 자유(무게 2) 후속은
`T1(σ^ℓ(u))` 다. `T1(σ^5(w)) = τ(w)` 이므로:

* **A** 의 탈출 단어는 `σ^{b−1}(v)`, 그리고 `σ^{b−1}(v) = σ^5(σ^{b}(v))`
  → **A 의 자유 후속 = `τ(σ^b(v)) = τ(entry_B)`**.
* **B** 의 탈출 단어는 `σ^{5−b}(σ^b v) = σ^5(v)`
  → **B 의 자유 후속 = `τ(v) = τ(entry_A)`**.

> 두 짧은 pass 의 자유 후속은 **서로의 궤도로 정확히 교차한다.** 720 단어 × 5 분할 전부에서
> 확인했다 (3,600/3,600, 두 항등식 각각).

### 1.2 순환 논증

`f_out = 2` 라 하자 — 즉 A 와 B 가 **둘 다** 자유 호로 나간다.

* 자유 후속 `τ(entry_B)` 는 `orb(B)` 안에 있고 A 는 `orb(A) ≠ orb(B)` 안에 있으므로,
  그 joint 는 **inter-run** 이다. 따라서 `τ(entry_B)` 는 `orb(B)` 의 어떤 run 의 **첫 pass** 다.
* 짧은 pass 에서 나가는 모든 경량 이동은 궤도를 바꾸므로(라운드 116 §7) **B 는 자기 run 의
  마지막 pass** 다. 대칭으로 A 도 그렇다.

두 경우뿐이다.

* **(ii)** `τ(entry_B)` 가 B 의 run 과 **다른** `orb(B)` run 에 있다 → `orb(B)` 의 run 이 둘 →
  **`e ≥ 1`**. (A 쪽도 마찬가지.)
* **(i)** `τ(entry_B)` 가 B 와 **같은** run 에 있다 → 그 run 은 `τ(entry_B)` 에서 시작해 `B` 에서
  끝난다. A 에 대해서도 같으면, walk 은
  > `A → [orb(B) 의 run … 끝이 B] → B → [orb(A) 의 run … 끝이 A] → A`
  라는 **닫힌 순환**을 담는다. 그러나 walk 은 121개 pass 의 **경로**이고 각 pass 는 정확히
  한 번 나오므로 후속을 따라가 출발점으로 되돌아올 수 없다. **모순.**

따라서 A 또는 B 중 적어도 하나가 경우 (ii) 이고 `e ≥ 1` 이다. 즉 **`f_out = 2 ⟹ e ≥ 1`**,
곧 `f_out ≤ 1 + e`. ∎

**경계 경우.**

* `orb(A) ≠ orb(B)` 는 항상 참이다 — 육각형의 6개 단어는 서로 다른 6개 궤도에 있다.
* `τ(entry_B) = B` 는 불가능하다 — `τ` 는 크기 5 의 궤도에 자유롭게 작용해 고정점이 없다.
* **A 가 walk 의 첫 pass 인 경우**: 경우 (i) 은 A 의 run 이 `τ(entry_A)` 에서 시작한다고
  하는데 첫 pass 의 run 은 A 에서 시작하므로 `τ(entry_A) = A`, 모순 → 경우 (ii) → `e ≥ 1`.
* **B 가 walk 의 마지막 pass 인 경우**: B 에는 후속이 없으므로 자유 호를 내지 못해
  `f_out ≤ 1` 이고 가정 `f_out = 2` 와 어긋난다.
* 증명은 `H = 0` 을 쓰지 않는다 — 두 짧은 pass 가 **자유로** 나간다는 것만 쓴다.
  따라서 보조정리 E 는 `F = 1` 열 **전체**에서 성립한다.

*(`f_out ≤ 2` 는 라운드 116 §10.2 다: 자유 호가 궤도를 바꾸려면 짧은 pass 뒤여야 하고
`F = 1` 의 짧은 pass 는 정확히 둘이다.)*

### 1.3 범위 — 이 보조정리는 `F = 1` 전용이다

증명은 `h*` 의 **유일한 상보 쌍**을 쓴다. `n = 4` 전수(2,598 walk)에서:

| | 결과 |
|---|---|
| `F = 1` (971개) 에서 `f_out ≤ 1+e` 위반 | **0** |
| `F = 1` 에서 `f_out = 2` 인데 `e = 0` | **0** |
| `F ≥ 2` 에서 위반 | **450** (`F=2`: 238, `F=3`: 194, `F=4`: 18) |
| 모든 2,598 walk 에서 `O ≤ 1+S+F` 위반 | **0** |

> **`F ≥ 2` 에서 깨지는 것이 증명의 가설과 정확히 일치한다.** 이 라운드는 그것을
> `F ≥ 2` 로 옮기지 않는다.

## 2. `(4,1)` 의 정확한 예산 (§1)

`k = 4`, `F = 1`, `L ≤ 871`. 라운드 116 §10 의 회계:

    S = (r − 1) + x − f_out,   r = O + e = 28 + e   ⟹   S = 27 + e + x − f_out
    H ≥ t − 1,                 L = 845 + S + H ≤ 871 ⟺ S + H ≤ 26

보조정리 E (`f_out ≤ 1 + e`) 를 넣으면

    S ≥ 27 + e + x − (1 + e) = 26 + x   ⟹   S + H ≤ 26 이므로
    **S = 26,  H = 0,  x = 0,  f_out = 1 + e**,  그리고 `f_out ≤ 2` 에서 **`e ≤ 1`**.

> ### `(4,1)` 은 정확히 두 하위경우다
>
> | 하위경우 | `e` | `x` | `f_out` | `r` | `S` | `H` | `t` |
> |---|---|---|---|---|---|---|---|
> | **A** | 0 | 0 | 1 | 28 | 26 | 0 | 1 |
> | **B1** | 1 | 0 | 2 | 29 | 26 | 0 | 1 |
>
> `H = 0` 이므로 **`t = 1`**: 반례는 **walk 전체가 단 하나의 all-light 사슬**이어야 하고
> 121개 joint 가 전부 경량(무게 ≤ 3)이며 그중 정확히 **26개**가 무게 3 이다.

슬랩 전체도 같은 방식으로 **증명된다**(더 이상 가정이 아니다): `k = 1,2,3,4` 에서
`H ≤ 3, 2, 1, 0`.

## 3. 두 짧은 pass 의 포트 분류 (§3)

`b = 1..5` 마다 A 는 진입 `v`, 길이 `b`, `ℓ = b−1`, 탈출 `σ^{b−1}(v)`;
B 는 진입 `σ^b(v)`, 길이 `6−b`, `ℓ = 5−b`, 탈출 **항상 `σ^5(v)`**.

라운드 116 §7 의 표에서 각 `ℓ` 의 네 경량 이동이 읽힌다. 요약하면:

* `ℓ < 5` 의 네 이동은 **전부 궤도를 바꾼다** → 짧은 pass 는 자기 run 의 마지막이다.
* 어떤 `ℓ` 에서도 경량 이동은 **출발 육각형으로 돌아오지 않는다** → 두 `h*` 방문은 경량
  이동으로 직접 이어질 수 없다 (라운드 116 정리 D 의 기하학적 재확인).
* `W2`(자유)는 위 §1.1 의 짝지음 항등식을 만족한다.

비순서 분할은 `(5,1)`, `(4,2)`, `(3,3)` 세 가지, 순서까지 세면 `b = 1..5` 다섯 가지다.

## 4. 탐색 모델 (§2, §7, §8)

**상태**(§7 의 최소 좌표):

| 좌표 | 이유 |
|---|---|
| 현재 진입 단어 + 현재 pass 길이 | 탈출 단어 `σ^{len−1}(u)` 를 정한다 |
| 사용된 육각형 **120비트** | pass ↔ 육각형은 `h*` 하나만 이중 |
| 궤도별 사용 phase 마스크 | 궤도 수 `O ≤ 28`, 단어 중복 금지 |
| 비용 (무게-3 joint 수) | `S ≤ 26` |
| run 수 · 현재 run 길이 · run 결손 | `r ≤ RMAX`, 결손 상한 |
| 짧은 pass 상태 `(0 / 첫 방문 v / 완료)` | 두 `h*` 방문을 **구별해서** 유지한다 |
| `f_out`, `x`, 재방문 수 | 하위경우 예산과 보조정리 E |

720 단어 전체 이력은 쓰지 않는다 — 육각형 마스크와 궤도 phase 마스크로 유도된다.

**두 번째 `h*` 방문은 강제된다.** 첫 방문이 `(v, 길이 b)` 로 정해지면 두 번째 진입 단어는
**`σ^b(v)` 하나뿐**이고 길이는 `6−b` 다. `h*` 의 다른 단어로는 절대 들어갈 수 없다
(그 육각형은 이미 쓰였다).

### 4.1 대칭 축약이 완전함 (§8)

단어를 `S₆` 의 원소로 보면 재라벨은 **왼쪽 곱셈**이고, `σ`, `τ`, 네 경량 이동은 전부
**오른쪽 곱셈**이므로 서로 교환한다. 왼쪽 곱셈은 720 단어 위에서 **단순 추이적**이다.
따라서 임의의 해를 walk 의 **첫 진입 단어가 0** 이 되도록 옮기는 `g ∈ S₆` 가 **정확히 하나**
존재한다 — 과소·과대 계수 없이 **완전한 720배 축약**이다.

`h*` 나 짧은 pass 방향은 **추가로 고정하지 않았다.** 두 `h*` 방문의 상대 위치는
`b` 로 분리해 **다섯 번 따로** 돌린다 (몫으로 지우지 않는다).

### 4.2 가지치기 (전부 admissible)

1. **비용 대 남은 run**: 현재 run 을 채워도 남는 pass 는 `≤ 5`짜리 run 들로 채워야 하고
   각 run 은 inter-run joint 를 하나씩 쓰며 그중 자유는 `f_out` 잔량뿐이다.
2. **run 결손**: `Σ(5 − run 길이) = 5r − 121` 이 `5·RMAX − 121` 이하.
3. **조각 용량**: 짧은 pass · `W3a` jump · 궤도 재방문은 walk 을 **R115-모델 all-light 사슬
   조각**들로 자른다. 각 조각의 pass 수는 라운드 115 의 **전수 용량표** `N*(0,0,s)` 로
   위에서 눌린다. 이 프룬이 없으면 탐색이 끝나지 않는다.

> **투명성.** 3번 프룬의 건전성은 라운드 115 의 `N*(0,0,s)` 표(전수, 캡 도달 0)에 의존한다.
> 그 표 자체는 **Claude 계산**이며 라운드 115 감사에서 `k=0,1,4` 경로로 독립 확인됐다.
> `s > 20` 은 라운드 115 가 표로 만들지 않았으므로 **자명한 상한 120** 을 쓴다.

### 5.2 하위경우 B1 의 구조 환원 (§4 의 비이웃성 활용)

`B1` 은 `e = 1`, `x = 0`, `f_out = 2` 다. 보조정리 E 의 증명을 그대로 밀면 강한 구조가 나온다.

`h*` 의 두 pass 를 walk 순서대로 **X**(먼저), **Y**(나중)라 하자.

* **X 는 항상 경우 (ii) 다.** 경우 (i) 은 `orb(X)` 의 run 이 `τ(entry_X)` 에서 시작해 X 에서
  끝난다는 뜻인데, `τ(entry_X)` 의 선행자는 Y 이므로 **Y 가 X 보다 앞에** 있게 된다 — 순서에
  모순. 따라서 `orb(X)` 가 run 을 두 개 갖는 **유일한 궤도**(`e = 1`)다.
* **따라서 Y 는 경우 (i) 다** (아니면 `orb(Y)` 도 두 run 이 되어 `e ≥ 2`).
  즉 `orb(Y)` 의 run 이 `τ(entry_Y)` 에서 시작해 Y 에서 끝나고, `x = 0` 이므로 `τ` 스텝만으로
  `τ(entry_Y) → τ⁵(entry_Y) = entry_Y` 즉 **정확히 5 pass** 다.

> **결론: `B1` 에서 두 짧은 pass 는 walk 에서 정확히 5 pass 떨어져 있고, 그 사이 다섯 pass 는
> `orb(Y)` 의 완전한 `τ`-블록으로 완전히 강제된다.** X 의 탈출부터 Y 까지의 여섯 이동이 전부
> 결정적이다.

탐색기는 이것을 `foutmin = 2`(짧은 pass 의 탈출을 자유 이동으로 강제)와 `ygap = 5`(Y 의 위치
강제)로 그대로 넣는다. 라운드 116 정리 D(두 짧은 pass 는 이웃할 수 없다)와 모순되지 않는다 —
간격은 5 이지 1 이 아니다.
