## 1. 정리 1 — 제한 성분 하한 (§1, §2)

> **정리 1.** 유향 그래프 `G` 의 각 호에 비용 `0/1` 이 붙어 있고, ROOT 가 아닌 모든 정점의
> **비용-0 유출 차수가 ≤ 1** 이라 하자. 정점 집합 `R` 위에서 비용-0 호들이 만드는 **약연결
> 성분**의 개수를 `c(R)` 이라 하면, `x ∉ R` 에서 출발해 `R` 의 모든 정점을 **정확히 한 번씩**
> 지나는 임의의 경로가 쓰는 비용-1 호의 개수는 최소
>
> * `c(R) − 1`  — `x` 에서 `R` 로 가는 비용-0 호가 있을 때
> * `c(R)`   — 없을 때
>
> 이다.

**증명.** 그런 경로는 진입 호 1개와 `R` 내부 호 `|R| − 1` 개로 이루어진다. 내부 호 중 비용이
0 인 것들의 집합 `F` 는 단순 경로의 부분집합이므로 **선형 숲**이고, `|F| = y` 이면 `F` 가
`R` 위에 만드는 성분은 정확히 `|R| − y` 개다. `F` 의 각 성분은 비용-0 호로 연결돼 있으므로
전체 비용-0 약연결 성분 **하나 안에** 들어간다. 즉 `F` 의 성분 분할은 약연결 성분 분할을
**세분**하고, 따라서 `|R| − y ≥ c(R)`, 곧 `y ≤ |R| − c(R)`. 내부 비용-1 호는
`(|R| − 1) − y ≥ c(R) − 1` 개다. 진입 호가 비용 0 일 수 없으면 여기에 1 이 더해진다. ∎

### 왜 유출 차수 ≤ 1 이 필요한가 (§3)

증명 자체는 유출 차수와 무관하다. 필요한 것은 **구현**이다. 성분을 셀 때 정점마다 비용-0
후속을 **하나만** 병합하면, 어떤 정점이 비용-0 후속을 둘 이상 가질 때 실제 약연결 성분보다
**많이** 세게 되고 하한이 부풀어 **불건전**해진다.

라운드 105 는 이것이 이론적 흠이 아니라 실재하는 결함임을 전수 열거로 확인했다 —
제한 없는 무작위 그래프 42,052 (그래프, `B`) 쌍 중 **111건이 `솔버 UNSAT / 참 SAT`**.
그래서 인증기는 가설을 **매 탐색 노드에서** 확인한다(§11).

라운드 104/105 는 뿌리에서 항상 `c − 1` 을 썼다. 정리 1 의 두 번째 경우(진입 비용-0 호가
없으면 `c`)는 **더 강하고 여전히 건전**하므로 라운드 106 인증기는 그쪽을 쓴다. 그래서 뿌리
마진 분포가 라운드 105 와 다르다 — 표본 15,545 배정 중 **870 개**에서 ROOT 의 비용-0 진입이
없어 하한이 1 커진다(§10 표).

## 2. 정리 2 — Q2 에서 가설이 구조적으로 성립한다 (§4)

> **정리 2.** 고정된 단어 배정 `A` 아래에서 각 의무 `h` 의 비용-0 유출 차수는 0 또는 1 이다.

**증명.** 배정은 의무마다 진입 단어 `U_h` 를 **하나** 고정한다. `ℓ` 은 감사된 강제 규칙으로
결정되므로(빈 육각형 5, 조각 수리 `5 − c_f`) 문자열 `T1(σ^ℓ(U_h))` 는 **유일**하고, 그 단어가
속한 의무도 많아야 하나다. 비용-0 호는 `T1` 뿐이므로 유출 차수 ≤ 1. 또 라운드-99 기하 정리에
의해 네 joint target 은 **서로 다른 네 육각형**에 있으므로, 한 의무에서 나온 두 개의 `T_i` 가
같은 의무로 들어가 `T1` 을 가리는 일도 없다. ∎

## 3. 정리 3 — 예산, 사건표로 완결 (§6, §7)

엔진 갱신 (`legacy_research/work/superperm_partial_f1.py`, 라운드 105 §1 에서 직접 읽음):

| joint weight | `dS` | `dH` | `dF` |
|---|---|---|---|
| 2 (`T1`) | 0 | 0 | 0 |
| 3 (`T2/T3/T4`) | 1 | 0 | 0 |
| 4 | 1 | 1 | 0 |
| 5 | 1 | 2 | 0 |
| 6 | 1 | 3 | 0 |

`Ndef = S + F − O`, 완성 조건은 `O = 25` 이므로 `ΔO = K = 25 − O`. `ΔF = 0`(정리 4),
`ΔH ≥ 0` 을 `= 0` 으로 **낙관적으로 완화**하면

    final(Ndef + H) = current(Ndef + H) + E − K,     E = 미래 weight-3 joint 개수

이고 완성은 `final(Ndef+H) ≤ 3` 을 요구하므로 **`E ≤ B := 3 + K − Ndef − H`**. ∎

`ΔH = 0` 완화가 하한을 **크게** 잡는 방향임에 주의한다 — 실제 walk 이 더 비쌀 수는 있어도
더 쌀 수는 없으므로 필요조건으로 안전하다.

**§7 `K` 검증.** 아카이브 6,396 상태 전부에서 `K = 25 − O` — **위반 0**.
`B` 분포(6,396 상태 전체):

| `B` | 18 | 19 | 20 | 21 | 22 | 23 | 24 | 25 |
|---|---|---|---|---|---|---|---|---|
| 상태 | 75 | 602 | 1,563 | 2,029 | 1,512 | 515 | 95 | 5 |

의무는 **107–108개**인데 예산은 **18–25** — 미래 pass 의 80개 이상이 유일한 무료 간선 `T1` 을
써야 한다. 이 격차가 붕괴의 진짜 원인이다.

## 4. 정리 4 — `ΔF = 0` 의 **정정된** 서술 (§5)

> **주의.** "`ℓ < 5` 이면 `ΔF = 0`" 은 **거짓이다.** 라운드 105 가 반증했다 — 임의 시작점에서
> `ℓ = 0..4` 는 각각 ~148k 문맥 **전부**에서 abandonment 를 일으킨다.

> **정리 4 (정정판).** 모델이 쓰는 두 종류의 pass 에서만 `ΔF = 0` 이다.
> (a) `ℓ = 5` pass — 회전 뒤 커서의 σ-후속이 진입 단어 자신이므로 이미 방문됐다
> (147,782 문맥 전부 확인, 예외 0).
> (b) fragment 수리 `ℓ = 5 − c_f` — 회전이 조각의 미방문 부분을 정확히 채우고 끝나므로
> σ-후속이 조각의 **이미 방문된** 칸이다. `r=0` 상태 **5,732/5,732** 확인
> (`c_f` 별 1,487 / 1,562 / 1,323 / 915 / 445, 예외 0).

즉 `ΔF = 0` 은 회전 길이의 일반 성질이 아니라 **조각 경계의 기하적 사실**이며, 유한 인증서로
뒷받침된다.

손으로 확인 가능한 최소 예제로 규약을 못 박았다 (`expectation_mismatches = 0`).

| 예제 | 기대 | 결과 |
|---|---|---|
| 정점 2개, 비용-0 호 없음, ROOT 비용-0 진입 없음 | `c = 2` | 2 |
| 같은 그래프, ROOT 비용-0 진입 있음 | `c − 1 = 1` | 1 |
| 비용-0 사슬 하나, ROOT 비용-0 진입 없음 | 1 | 1 |

| 사슬의 참 최소비용 (ROOT 비용-1 진입) | 1 | 1 |

확정한 규약:

* **ROOT 는 성분에 포함하지 않는다.** 성분은 의무 정점 위에서만 센다.
* `c` 대 `c−1` 은 **ROOT(또는 현재 정점)에서 잔여로 가는 비용-0 호의 유무**로 갈린다.
* **terminal 을 따로 두지 않는다** — 경로의 마지막 정점이 곧 terminal 이다.
* **조각(fragment) 의무도 같은 비용 규칙**을 쓴다 (`T1` = 0, 나머지 = 1). 다른 점은 `ℓ` 뿐이다.
* `K = 25 − O`, `B = 3 + K − (S+F−O) − H`, 6,396 상태에서 `B ∈ [18, 25]`.
