## 1. lift 문제의 형식화 (§1)

의무 경로 `ROOT → h1 → … → hm` 의 **literal lift** 는 구체 단어열 `u1,…,um` 으로,
각 `ui` 가 `hi` 의 진입 후보이고 연속 전이가 전부 합법 엔진 전이인 것이다.
한 단계가 보존해야 하는 것:

| 항목 | 이 모델에서 |
|---|---|
| 순열 단어 | `id` + 문자열 (`geometry.jsonl.gz`) |
| 궤도 / 위상(=port) | `orbit`, `phase` |
| `ℓ` | 빈 육각형 5, fragment `5−c_f` — **강제** (라운드 90/91) |
| joint | `joint_targets[ℓ]` 의 4개 |
| 방문 창 제한 | 의무는 **빈 육각형**뿐 (+ fragment) |
| 등록 port 제한 | 진입 단어의 궤도가 **최종 25궤도**에 있어야 한다 (라운드 93) |
| fragment 상태 | 점유 칸 수 `c_f`, 수리 진입 단어 |

핵심은 **분리**다 — "그래프 간선이 있다"(어떤 후보에서 어떤 후보로 닿는다)와 "직전에 **실제로
선택된** 구체 단어가 그 간선을 지지한다"는 다른 명제다. 라운드 94 가 명시한 과대근사가 정확히
이 자리에 있다.

## 2. 기하 정리와 결정성 (§3, §8)

전수 검사(720 단어 × 6 `ℓ` = 4,320 문맥):

| | |
|---|---|
| 네 target 의 서로 다른 육각형 수 | **전부 4** (4,320/4,320) |
| 한 육각형에 target 2개 이상인 문맥 | **0** |
| target 이 source 육각형에 떨어지는 문맥 | **0** |
| 네 target 의 서로 다른 궤도 수 | 전부 3 (두 target 이 궤도를 공유하되 위상이 다름) |

따라서 `WORD_NEXT` 는 함수다 — §3 의 A/B/C 중 **A(정리)**. 구현 artifact 도, 네 경로만의
성질도 아니다. `>= 2` 인 문맥을 능동적으로 찾았으나 **존재하지 않는다.**

가장 약한 참인 진술로 적으면: *`ℓ` 이 결정되어 있으면* 목표 육각형이 구체 단어를 결정한다.
`ℓ` 자체는 라운드 90/91 에서 이미 강제됐으므로 ordinary `ℓ=5` 와 fragment `ℓ=5−c_f` 양쪽
모두에 적용된다 — 부류를 나눌 필요가 없었다.

## 5. 단어 수준 정적 조건 (§15) — 이 라운드의 payoff

결정성이 있으면 단어 수준 그래프를 따로 만들 필요가 없다. 후보 단어마다 `{목표 의무: 목표 단어}`
가 함수이므로 그래프 수준 층 A/B2 를 그대로 옮길 수 있다.

| 조건 | 내용 |
|---|---|
| **W-A** | 모든 의무가 **현재 구체 단어**에서 단어 전이로 도달 가능 |
| **W-B2** | 단어 전이로 다른 의무에 못 가는 의무 ≤ 1 |
| **W-IN** | 모든 의무는 단어 전이로 진입 가능 |

전수 결과 (19,172 쌍 / 4,790 상태, 930초):

| | PASS | **W-A 실패** | W-B2 | W-IN |
|---|---|---|---|---|
| 쌍 | 15,781 | **3,391** | 0 | 0 |

| 상태 | SAT | **UNSAT(폐쇄)** |
|---|---|---|
| 전체 | 4,230 | **560** |
| `r=0` | 4,056 | 409 |
| `r=1` | 174 | 151 |

라운드 98 의 감사된 8개를 빼면 **새 잠정 폐쇄 552**. cover 수 분해: 유일 cover 145 ·
2개 173 · 3개 63 · 4개 69 · 5개 25 · 6개 이상 77 — **다중 cover 상태는 모든 cover 가 실패한
경우만** 셌다. root 분해: `short_ell4` 219 · `short_ell2` 143 · `short_ell1` 99 ·
`short_ell3` 71 · `short_ell0` 20.

`r=1` 의 폐쇄율이 46 %(151/325) 로 `r=0` 의 9 %(409/4,465)보다 훨씬 높다. fragment 가 이미
수리된 상태는 진입 단어가 하나로 고정돼 있어 단어 도달성이 훨씬 잘 깨진다 — 라운드 94 가
규명하지 못한 채 남긴 `r=1` 비대칭에 대한 **구조적 설명**이 여기서 처음 나온다.

## 6. lift 인지 정확 탐색 (§9, §11)

탐색 상태를 `(현재 구체 단어, 남은 의무 집합)` 으로 두고 — 정리 덕분에 단어 **집합**이 아니라
단어 **하나** — 그래프 수준과 같은 건전한 가지치기(도달성, 유출-0 의무 ≤ 1, 정확 상태 키 memo)를
얹었다. 14개 표본, 캡 300,000:

| SID | 정적 | **lift 인지** | 그래프 전용 |
|---|---|---|---|
| `02eafeaa` | W-A 실패 | **UNSAT 1 노드** | UNKNOWN 300k |
| `c1dd5467` | W-A 실패 | **UNSAT 1 노드** | UNKNOWN 300k |
| `7bb6b67c` | W-A 실패 | **UNSAT 1 노드** | UNKNOWN 300k |
| `77fbaf89` | W-A 실패 | **UNSAT 1 노드** | UNKNOWN 300k (라운드 98 은 3M 에서 2.7M 노드) |

## 8. 필요한 메모리 (§10)

결정하기에 충분하고, 그 이상이 필요하다는 반례를 이 라운드에서 만나지 못했다. 다만 이는

들어오면 다시 물어야 한다.
