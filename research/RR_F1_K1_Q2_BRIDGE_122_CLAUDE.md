## 0. 결과

> ### 다리는 서 있지 않다. 그리고 그 이유는 자원 표가 아니라 **뿌리**에 있다.
>
> 6,396 아카이브 상태를 **직접 읽어** 확인한 사실:
>
> * 전부 `F = 1`, `H = 0`, `Ndef = 0`, `D = 5O − P`, `K = 25 − O`, `S = O − 1`
> * 전부 `P ∈ {13, 14}` — walk 시작에서 **13~14 pass** 떨어진 **아주 이른 접두**다
> * 전부 뿌리가 **`short_ell0..4` 다섯 개뿐**
>
> 그리고 그 다섯 뿌리는 엔진에서 이렇게 만들어진다:
>
>     short_root(ell) = initial_state() 에서 sigma 를 ell 번 (ell = 0..4)
>                       -> 그 다음 `w2:10` (무게 2, abandonment=True, new_orbit=True)
>
> 즉 **walk 의 첫 pass 가 길이 `ell+1 ∈ {1..5}` 인 짧은 pass 이고 그 탈출이 자유(무게 2)**
> 라는 것이 뿌리의 정의다. 이 한 걸음이 `F` 를 0 에서 1 로 올린다(`P = 2` 에서 이미 `F = 1`).
>
> **일반 `(1,1)` 은 첫 pass 가 짧다고 요구하지 않는다.** `n=4` 전수 대조에서 `F=1` walk
> **5,764개 중 4,139개(72%)가 첫 pass 가 full** 이고, **2,667개(46%)는 양 끝이 모두 full**
> 이라 뒤집기 `Φ` 로도 짧은-뿌리 가족으로 옮길 수 없다.
>
> ⇒ **`G \ Q` 는 비어 있지 않고 작지도 않다.** 일반 `(1,1)` 은 현재 상태로 Q2 에 환원되지
> 않는다. **`(1,1)` 은 열려 있고 Claude 가 닫은 칸은 8/55 그대로다.**

## 1. `(1,1)` 예산 (§1)

    F = 1, k = 1  ⟹  P = 121,  O = 25,  D = 5·25 − 121 = **4**,  L = 845 + S + H

이음매 120개 중 run 내부가 `121 − r`, run 사이가 `r − 1` 이고 `r = O + e = 25 + e` 이므로

    S = x + (r − 1) − f_out = **24 + e + x − f_out**
    N := S + F − O = **e + x − f_out**            (따라서 **L = 869 + N + H**)
    L ≤ 871 ⟺ S + H ≤ 26 ⟺ **e + x + H ≤ 2 + f_out** ⟺ **N + H ≤ 2**

보조정리 E(`f_out ≤ 1+e`)와 `f_out ≤ 2` 를 넣으면 **`x + H ≤ 3`**, 그리고 `f_out = 2 ⟹ e ≥ 1`.
라운드 121 의 일반식 `k + x + H ≤ 4` 와도 일치한다(`k=1`).

전수 열거: **정수 행 50개 / 하위경우 61개**(`H` 조성을 가르면). 라운드 115 조각 용량표로
**9개 하위경우가 탐색 없이 죽는다** — `e = 0` 이면 run 결손이 **4** 뿐이라 조각 `m ≤ 4` 는
최대 **106 pass < 121** 이다. **살아남는 것은 하위경우 52개 / 행 44개.**

`H` 는 여기서 **3 까지** 갈 수 있고(`k=2` 에서는 2 였다), 무거운 조성은

    [] · [4] · [4,4] · [4,4,4] · [5] · [5,4] · **[6]**

일곱 가지다. `[6]` 은 **무게-6 tail 461개**를 뜻한다 — `(2,1)` 에는 없던 규모다.
(참고로 `(2,1)` 은 24행/26하위경우, 15.5시간이었다. `(1,1)` 은 그 두 배 규모다.)

## 3. 역사적 상태가 Q2 에 **들어가는** 방식 (§3)

`src/analyze_rr_short_root_envelope.py::short_root(ell)` 를 실제로 실행해 확인했다:

```
short_root(ell):
    st = exact.initial_state()                 # P=1, O=1, F=0, S=1, H=0, D=4
    st = sigma^ell (st)                        # 첫 pass 를 길이 ell+1 로 늘린다
    tr = extend(st, w2:10)                     # 무게 2, abandonment=True, new_orbit=True
    return tr.state                            # P=2, O=2, F=1, S=1, H=0, D=8, Ndef=0
```

| 항목 | 값 |
|---|---|
| **경계 사건** | **두 번째 R 이벤트** (`joint_kind == "R"`, 즉 무게 3 · abandonment 없음 · 새 궤도 아님). 탐색은 그 뒤로 **절대 확장하지 않는다** |
| **현재 pass** | 아카이브 상태에서 `P ∈ {13, 14}` — walk 시작에서 13~14 pass |
| **조각(fragment) 조건** | `fragment = {hex, c_f, ell, entry_id, port}` — 버려진 육각형의 미완성 조각. `b + c = 5` 가 **6,396/6,396** 에서 성립 |
| **자원 슬랩** | `Ndef + H ≤ 3` (= `L ≤ 872`), 아카이브 상태 자체는 `Ndef = 0`, `H = 0` |
| **`H`/`Ndef` 조건** | 경계까지 `H = 0` (단조 + Target A 인식기가 요구), 경계에서 `Ndef = 0` |
| **강제 `ell`** | 뿌리가 `ell ∈ {0,1,2,3,4}` 로 **다섯 갈래**뿐 — 첫 pass 길이 1..5 |
| **국소성 가정** | 라운드 91 의 짧은-pass 국소성 (`short_local_fresh_targets` 필드가 아카이브에 그대로 있다) |

> **일반 후보가 만족하지 못하는 것은 무엇보다 첫 줄이다: `initial_state()` 바로 다음에
> 짧은 pass 가 와야 한다.**

## 5. 자원 행 → Q2 사상 (§5)

**행 수준에서는 결정되지 않는다** — 그것이 이 라운드의 첫 번째 정직한 결론이다.
Q2 소속을 결정하는 것은 `(e, x, f_out, H)` 가 아니라 **짧은 pass 의 위치**와
**무거운 이음매의 위치**다. 그래도 행 수준에서 말할 수 있는 것은 있다:

| 유형 | 일반적으로 가능한가 | Q2 안인가 | 이유 |
|---|---|---|---|
| **T1** `H = 0`, 첫 pass 가 짧고 그 탈출이 자유 | 예 (행 22개) | **모양은 맞다** | `short_ell{b−1}` 뿌리와 정확히 같은 시작. 단 뿌리 이후 경로가 RR 알파벳 안이고 2번째 R 이 `P=13~14` 에 와야 한다 — **증명되지 않았다** |
| **T2** `H = 0`, 첫 pass 가 짧지만 탈출이 자유가 아님 | 예 | **밖** | 뿌리가 `w2:10`(무게 2)을 강제한다 |
| **T3** `H = 0`, 첫 pass 가 full, 마지막 pass 가 짧음 | 예 | **`Φ` 로 T1/T2 로** (§7) | `Φ` 가 마지막 pass 를 첫 pass 로 보낸다. 단 `O` 보존 조건 필요 |
| **T4** `H = 0`, **양 끝이 모두 full** | 예 — `n=4` 전수에서 **2,667/5,764 (46%)** | **밖. `Φ` 로도 못 들어온다** | 짧은 pass 가 둘 다 내부라 어떤 뿌리와도 시작이 다르다 |
| **T5** `H ≥ 1`, 무거운 이음매가 경계(`P≤14`) **앞** | 예 (행 22개가 `H≥1`) | **밖** | 무게 ≥ 4 는 RR 알파벳 밖 (§2.1) |
| **T6** `H ≥ 1`, 무거운 이음매가 전부 경계 **뒤** | 예 | **모양은 맞다** | 경계까지 `H=0` 을 만족한다 |
| **T7** 경계 앞에 A2 / A3 / J 이음매를 쓰는 walk | 예 | **밖** | RR 알파벳 밖 (다른 corpus) |
| **T8** 2번째 R 에 아예 도달하지 않는 walk | 예 | **밖** | Target A 경계가 없으면 아카이브 상태를 지나지 않는다 |

**총계로 논증하지 않았다** — 각 유형은 위 표의 개별 근거로 판정했다.

## 6. 재뿌리내리기(re-rooting) (§6)

> **불가능하다.** 초순열은 **선형 문자열**이고 NR6 walk 은 **경로**(순환이 아니다)다.
> 시작점을 옮기는 것은 문자열을 순환 이동하는 것인데, 그러면 길이도 초순열성도 보존되지
> 않는다. 역사적 뿌리도 "임의의 경계" 가 아니라 `exact.initial_state()` — **walk 의 실제
> 시작**이다(라운드 11 이후 `p_0 = IDENTITY` 고정, `RR_INITIAL_ROOT_AXIOM.md`).

따라서 §6 이 기대한 "첫 짧은 pass / 둘째 짧은 pass / 재진입 경계에 재뿌리내리기" 는
**세 가지 모두 성립하지 않는다.** 유일하게 시작점을 옮기는 합법적 사상은 `Φ` 뿐이고,
그것은 **끝 ↔ 시작** 하나만 바꾼다 (§7).

## 7. 뒤집기 `Φ` 가 옮길 수 있는 것 (§7)

라운드 120/121: `Φ` 는 pass 열을 뒤집고 `(u,m) ↦ (ρ(σ^{m−1}u), m)` 로 보낸다.
`L·P·F·S·H` 를 보존하고 `b ↦ 6−b` 이며 **마지막 pass 를 첫 pass 로** 보낸다.
`O`(따라서 `k`) 보존은 **일반적으로 성립하지 않고**, 라운드 121 §5.1 이 준 충분조건은
**`X` 의 탈출 이음매가 자유**라는 것이다.

> **따라서:** 마지막 pass 가 짧은(즉 `Y` 가 마지막인) 일반 `(1,1)` walk 은 `Φ` 아래
> 첫 pass 가 짧은 walk 으로 간다 — **`X` 의 탈출이 자유일 때에 한해** `k` 도 보존된다.
> 이것이 `T3 → T1/T2` 다.
>
> **양 끝이 모두 full 인 walk(T4)에는 `Φ` 가 아무 것도 해 주지 못한다.** `Φ` 는 대합이고
> 양 끝의 길이를 맞바꿀 뿐이므로, 둘 다 6 이면 상도 둘 다 6 이다.

## 8. `Ndef + H` 예산의 off-by-one (§8)

    일반:   L ≤ 871  ⟺  N + H ≤ 2
    역사적: final_target 은 `Ndef + H ≤ 3`  ⟺  L ≤ 872

`L = 869 + N + H` (§1) 이므로 두 조건의 차이는 **정확히 한 칸의 길이 껍질**이다.

> **방향은 유리하다.** Q2 의 슬랩이 **더 넓다** — 일반 요구(`N+H ≤ 2`)를 만족하는 walk 은
> 전부 역사적 슬랩(`≤ 3`)도 만족한다. **여기에는 빈틈이 없다.**
> (라운드 110 §0 이 이미 지적했고, 이번 라운드가 `L = 869+N+H` 로 다시 확인했다.)
>
> 즉 **자원 슬랩은 다리의 장애물이 아니다.** 장애물은 §2.1(알파벳)과 §3(뿌리)이다.

## 9. 강제 `ell` (§9)

pass 길이 결손의 총합은 항상 **6** 이다: 121 pass 가 720 단어를 덮으므로
`Σ(6 − len) = 726 − 720 = 6`. `F = 1` 은 짧은 pass 가 정확히 둘임을 주므로 길이는
`b` 와 `6−b`, 결손은 `6−b` 와 `b` — **합이 6, 자동**이다.

| 역사적 `ell` 강제 규칙 | 판정 |
|---|---|
| 짧은 pass 가 정확히 둘, 길이 합 6 | **AUTOMATIC** — 총 결손 6 에서 따라 나온다 |
| 뿌리의 `ell ∈ {0..4}` (첫 pass 길이 1..5) | **Q2-SPECIFIC** — "첫 pass 가 짧다" 를 가정한 뒤의 다섯 갈래일 뿐이다. 일반 `(1,1)` 에서는 `b` 가 첫 pass 의 길이라는 보장이 없다 |
| `ell = 5` 에서 abandonment 불가 (`F=0` full-sweep 정리) | **AUTOMATIC** — full pass 는 육각형을 다 덮으므로 버릴 것이 없다 |
| 라운드 90/91 의 나머지 `ell` 강제 | **독립 감사됨 — 단 Area-A 안에서** (라운드 110 표 H3) |

## 10. 조각 국소성 (§10)

라운드 91 은 Q2 **안에서** 짧은-pass 국소성을 세웠다(아카이브의 `short_local_fresh_targets`

증명하지 못했고, 조용히 확장하지도 않았다.**

> ### 구체적 반례 가족 (§10 이 요구한 것)
>
> `n = 4` 전수(길이 ≤ 37, walk 16,186개) 중 `F = 1` walk 은 **5,764개**다.
>
> | | 개수 | 비율 |
> |---|---|---|
> | 첫 pass 가 **짧음** | 1,625 | 28% |
> | 첫 pass 가 **full** | **4,139** | **72%** |
> | 마지막 pass 가 짧음 | 1,625 | 28% |
> | **양 끝이 모두 full** | **2,667** | **46%** |
>
> `F = 1` 은 짧은 pass 가 둘 있다는 것만 말하고 **그 위치는 전혀 강제하지 않는다.**
> 양 끝이 모두 full 인 46% 는 `Φ` 로도 짧은-뿌리 가족에 들어가지 못한다.
> 이것은 `n=4` 사실이지 `n=6` 정리가 아니지만, **"첫 pass 가 짧다" 가 `F=1` 에서
> 따라 나온다는 어떤 논증도 성립할 수 없음**을 보이기에는 충분하다.

## 11·12. 다리 표와 여집합 `G \ Q` (§11, §12)

`G` := NR6 아래 `F=1, k=1, L ≤ 871` 인 일반 walk 전부.
`Q` := 6,396 아카이브 상태를 지나는 walk 전부.

> ### `G \ Q` 는 적어도 다음을 포함한다
>
> 1. **양 끝 pass 가 모두 full 인 walk (T4).** 어떤 뿌리와도 시작이 다르고 `Φ` 도 소용없다.
>    `n=4` 전수에서 `F=1` walk 의 **46%**.
> 2. **첫 pass 는 짧지만 그 탈출이 자유가 아닌 walk (T2).** 뿌리가 `w2:10` 을 강제한다.
> 3. **경계 앞에 무게 ≥ 4 이음매를 쓰는 walk (T5).** RR 알파벳 밖. 살아 있는 44개 행 중
>    **22개가 `H ≥ 1`** 이고, 그 위치는 자원 표가 정하지 않는다.
> 4. **경계 앞에 A2 / A3 / J 를 쓰는 walk (T7).** 다른 corpus.
> 5. **두 번째 R 이벤트에 도달하지 않는 walk (T8).** Target A 경계 자체가 없다.
>
> **`G \ Q ≠ ∅` 이고 작지 않다. 최소 유한 여집합으로 줄이지 못했다.**

다리가 서려면 필요한 것(전부 미증명):

| 필요한 명제 | 지위 |
|---|---|
| **뿌리 집합 완전성**: 모든 일반 `(1,1)` walk 이 33개 뿌리 중 하나를 지난다 | **미증명.** 5개 short 뿌리는 "첫 pass 가 짧다" 클래스에서 완전하지만, 28개 long 뿌리는 **탐색으로 발견된 것**(`long_found_*`, `long_q1_*`, `P_root ∈ {9,10}`, `Ndef_root = 1`)이지 클래스로 열거된 것이 아니다. 저장소 자신의 기준(`RR_EXHAUSTIVENESS_STANDARD.md` 조건 1)이 요구하는 "root class 완전성" 이 서술되어 있지 않다 |
| **알파벳 완전성**: 경계 앞 구간이 언제나 `{Z2, Z2abandon, R, Z3}` 안이다 | **거짓일 수 있다** — `H ≥ 1` 행이 22개 있고 A2/A3/J 도 배제되어 있지 않다 |
| **경계 존재**: 모든 일반 walk 이 두 번째 R 이벤트를 갖는다 | **미증명** |
| **경계 깊이**: 그 경계가 `P = 13~14` 에 온다 | **미증명** (아카이브의 관측 사실일 뿐) |

## 13·14. 계산 정책 (§13, §14)

**일반 `(1,1)` DFS 를 돌리지 않았다.** 이 라운드의 계산은 전부 가볍다 — 자원 행 유한 열거,
아카이브 읽기, 뿌리 다섯 개 실제 인스턴스화, `n=4` 전수 대조. **30분을 넘긴 작업은 없다.**

참고로 `(1,1)` 전수 탐색의 규모: 살아 있는 하위경우 **52개**(`(2,1)` 은 26개)이고 `H = 3` 이
가능해 **무게-6 tail 461개**가 들어온다. `(2,1)` 이 6.9×10¹¹ 노드 · 15.5시간이었으므로
`(1,1)` 은 그 몇 배다. **다리를 이해하기 전에 그것을 돌리지 않는 것이 옳다(§13).**
