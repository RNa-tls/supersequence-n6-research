# H.envelope 독립 감사 — 예산 봉투는 추출 정리의 따름정리인가

**대상 노드**  `H.envelope`
**감사 라운드**  158  **기반 커밋**  `dad0c1c` (branch `round153-equality-coexistence`)
**산출물**  `r158/src/*.py`, `r158/certs/*.json`, 그리고 이 문서
**이 문서의 지위**  수리된 DAG(`r158/certs/dag_158.json`)의 `H.envelope.where`
가 가리키는 정본 감사 문서.

이 감사는 `H.envelope` **하나만** 다룬다.  `H.extract`, `H.incidence`,
`H.tight`, `H.feas`, `H.models`, `H.samehex` 는 재감사하지 않고 명시적 의존으로만
인용한다.

---

## 요약

* **네 부등식은 전부 라운드 156 추출 정리의 따름정리다.**  `a <= D2`,
  `bb <= Qs`, `e <= Z - Qs` 는 `r156/THEOREM.md` (7) 의 **축자 절**이고,
  `a + bb + e <= 2g` 는 (5) 의 더 강한 형태 `a+bb+e = rep <= R_int <= 2g` 의
  약한 결과다.  네 인용문이 그 파일에 실재함을 기계적으로 확인했다.
* **그럼에도 `H.envelope` 은 독립적으로 재증명되었다.**  봉투를 **구조 반쪽**
  (`a = D2 - x`, `bb = Qs - y`, `x + y <= d`) 과 **산술 반쪽** (그로부터
  `E1..E4`, `Z0`, `L1`, `L2` 를 유도) 으로 쪼개어 각각 완전 유한 우주에서
  판정했다 — 구조 **1,156,734** · 분리성 **12,867** · 산술 **241,944** 사례,
  **위반 0**.  실제 덮개 517 개 × 절단 정책 8 × heavy 2 = **8,272 회** 위반 0.
* **새 발견 (적재).**  인구조사의 **조각 모형**은 `what` 에 없는 **하계 두 개**
  를 소비한다: `a >= D2 - d` (`nA`) 와 `a + bb >= D2 + Qs - d` (`m_lo`).
  하계가 너무 **크면** 조각 상한이 낮아져 실재하는 덮개의 행을 닫는다.
  둘 다 구조 반쪽의 같은 항등식에서 즉시 나오므로 **증명되었고**, 노드의
  `what` 을 완성해 수리했다.
* **정정 (라운드 156 서술의 범위).**  `e <= Z - Qs` 의 빈틈 있는 유도는
  `r149/PROOF.md` §3 의 것이다.  `H.envelope` 자신의 `where` 인
  `src/l6_envelope_146.py` 6–33 행은 **이미 올바른 유도**(`x + y <= d` 단계
  포함)를 담고 있다.  이 노드의 출처는 **낡지 않았다**.
* **h / H 혼동은 없다.**  봉투의 네(여섯) 부등식에는 `h` 도 `H` 도 등장하지
  않는다.

               "deps":  [],

`r158/certs/implies_158.json` — 인용문이 `r156/THEOREM.md`

| H.envelope | r156 절 | 인용 | 분류 | 확인 |
|---|---|---|---|---|
| `a <= D2` | (7) | `` `a := sum a_i <= D2` `` | **IDENTICAL_TO_R156** | ✓ |
| `bb <= Qs` | (7) | `` `bb := sum bb_i <= Qs` `` | **IDENTICAL_TO_R156** | ✓ |

**라운드 156 의 `H_EXTRACT_PARTIAL` 판정과의 관계.**  그 PARTIAL 은
`src/l6_extraction_145.py` 와 `r149/PROOF.md` 에 **적힌** 절단 절차가 결함이라는

**결론 (Phase 3).**  `H.envelope` 의 네 진술은 라운드 156 정리에 이미

추출 감사를 되풀이하지 않고 **구조 반쪽 한 줄**과 **산술 반쪽**만 본다.

## Phase 4 — `a <= D2` (소유·과금 증명)

`beta` 는 순열이므로 각 pass `u` (단, `nu(P-1)` 제외) 는 **정확히 하나**의
유형 붙은 나가는 간선을 갖는다.  그 간선은 절단되었거나 사슬 안에 있다.
절단 집합은 `{비순수 비더미 성분마다 개방 하나} ∪ {무게 >= 4 조인트}` 이다.

* type A 조인트는 무게 **2** 이므로 heavy 절단 대상이 **아니다**.
* 순수 성분의 간선은 전부 clean E 이므로 A 조인트가 순수 삭제로 사라지지 않는다.
* 더미 꼭짓점에 붙은 두 간선은 **유형이 없다**.

따라서 유지되지 않은 A 조인트는 **반드시 개방**이고

```
a = D2 - x,    x := (개방으로 쓰인 A 조인트 수) >= 0.
```

`a` 가 세는 대상은 단어의 A 조인트 **집합의 부분집합**이고 각 원소는 자기
자신을 소유하므로 대응은 **항등 단사**이며 다중도는 1 이다.  `a > D2` 는
부분집합의 크기가 전체보다 클 수 없다는 이유로 **구성적으로 불가능**하다 —
`a > D2` 를 만들려면 어떤 사슬 간선이 단어에 없는 A 조인트여야 하는데
`etype` 은 조인트 위의 함수라 그럴 수 없다.  전수 구조 검증
(1,156,734 사례) 과 실제 덮개 8,272 회에서 위반 0.

## Phase 5 — `bb <= Qs`

같은 논증을 **독립적으로** 반복한다.  type B 조인트는 무게 **3** 이므로 역시
heavy 절단 대상이 아니고, 순수 성분에도 없으며, 더미 간선도 아니다.  그러므로

```
bb = Qs - y,    y := (개방으로 쓰인 B 조인트 수) >= 0.
```

각 유지된 B 간선이 소비하는 것은 **자기 자신인 B 조인트 하나**이고, 서로 다른
유지 B 간선은 서로 다른 조인트이므로 같은 `Qs` 자원을 두 번 청구할 수 없다
(다중도 1).  경계: `Qs = 0` 이면 `bb = 0`; `y = Qs` 이면 `bb = 0` 이고 이때도
(L2) 가 `a >= D2 + Qs - d - bb` 를 준다.  등호 `bb = Qs` 는 `y = 0`, 즉 어떤
개방도 B 간선이 아닐 때다 — 실측 8,191/8,272 회.

## Phase 6 — `e <= Z - Qs` (핵심)

**옛 유도를 쓰지 않는다.**  `r149/PROOF.md` §3 은
`e <= 2g - D2 - Qs = Z - d - Qs <= Z - Qs` 로 적는데, 첫 등호는 `a = D2`
**그리고** `bb = Qs` 일 때만 성립한다.  올바른 유도는 다음과 같다 — 그리고
이것은 `src/l6_envelope_146.py` 25–28 행에 **이미 적혀 있다**.

**보조 사실 (E6).**  §4·§5 에서 `a = D2 - x`, `bb = Qs - y` 이고, **개방은
비순수 비더미 성분마다 정확히 하나**이므로 개방 총수는 `d` 다.  `x`, `y` 는
서로 다른 개방을 세므로

```
x + y <= d.                                                   (E6)
```

**유도.**  (5) 로 `a + bb + e = rep <= R_int` 이고 H.incidence 로 `R_int <= 2g`
이므로

```
e = (a + bb + e) - a - bb
  <= 2g - (D2 - x) - (Qs - y)
  =  2g - D2 - Qs + (x + y)
  <= 2g - D2 - Qs + d            (E6)
  =  (z - d) - D2 - Qs + d       (2g = z - d, 즉 z = 2g + d)
  =  z - D2 - Qs = Z - Qs.       (Z = z - D2)                  ∎
```

**어느 단계도 `a = D2` 나 `bb = Qs` 를 쓰지 않는다.**  각 요소의 역할:

* **잘린 A/B 사건** — `x + y` 만큼 `a + bb` 를 줄이므로 `e` 의 여유를 **늘린다**.
  그래서 유도에 `+ (x+y)` 가 들어가고, 그것을 되받는 것이 (E6) 이다.
* **개방** — 그 수가 정확히 `d` 라는 사실이 (E6) 의 전부다.
* **`d`** — `2g = z - d` 로 우변에서 정확히 상쇄된다.  `d` 가 두 번(한 번은
  `x+y` 의 상한으로, 한 번은 `2g` 와 `z` 의 차로) 쓰여 서로 지워지는 것이
  이 부등식의 전체 내용이다.
* **`Z`, `Qs`** — 정의 `Z = z - D2` 로 `z - D2 - Qs` 를 `Z - Qs` 로 다시 쓴다.

**`e > Z - Qs` 인 배치 탐색.**  산술 반쪽을 완전 정수 상자에서 판정했다
(`r158/src/abstract158.py::arith_box`, 상자 `<= 4, 6, 8` 에서 241,944 사례):
가설 `H1`(`a+bb+e <= R_int`), `H2`(`R_int <= 2g`), `H3`(`x+y <= d`),
`H4`(정의), `H5`(SAME-HEX) 아래 **위반 0**.  가설 제거:

| 제거 | `E3` 반례 | 다른 붕괴 |
|---|---:|---|
| `H1` | 1,168 | `E4` 3,224 |
| `H2` | 2,876 | `E4` 5,523, `Z0` 5,845 |
| **`H3` (`x+y <= d`)** | **544** | `L1` 3,030, `L2` 6,060 |
| `H5` | 0 | `Z0` 2,756 |

즉 **옛 유도가 건너뛴 바로 그 단계 `x + y <= d` 가 없으면 `e <= Z - Qs` 는
실제로 깨진다** (544 사례).  실제 덮개에서도 `x + y > 0` 인 경우가 364 회
(그중 `x>0` 287, `y>0` 81) 나타나므로 이 단계는 공허하지 않다.

부수적으로 `Z - Qs >= d >= 0`: SAME-HEX `D2 + Qs <= R_int` 와 `R_int <= 2g`
에서 `Z - Qs = 2g + d - D2 - Qs >= d`.  그래서 코드의 `max(0, Z - Qs)` 는
실제로는 그냥 `Z - Qs` 다.

## Phase 7 — 총합 봉투 `a + bb + e <= 2g`

**단순히 앞의 세 부등식을 더해서 얻는 것이 아니다** (`D2 + Qs + Z - Qs = z`
는 `2g` 가 아니다).  직접 과금 분할로 얻는다.

사슬의 첫 포트가 아닌 모든 포트 `v` 는 **정확히 하나**의 사슬 선행자 `u` 를
갖고 (`beta` 가 단사), 간선 `u -> v` 는 **정확히 하나**의 유형을 갖는다.
육각형이 앞서 나온 포트(=반복)들을 그 간선의 유형으로 분류하면

```
rep = a + bb + e        (정확한 분할, 겹침 없음)
```

이고, 유지된 A/B 간선의 표적은 (K2) 로 출발과 같은 육각형이며 출발이 바로 앞
포트이므로 **반드시** 반복이다 — 그래서 `a + bb <= rep`, `e >= 0`.

`2g` 의 구조적 의미는 **`beta`-성분이 공유하는 반복 예산**이다: 라운드 157 의
항등식 `2g = mu(B) + R_int` 에서 `R_int` 는 이분 접합 그래프의 다중 간선 초과
이고 `mu(B) >= 0` 이므로 `R_int <= 2g`.  그리고 사슬은 성분의 **부분경로**이므로
성분 `y` 안에서 육각형 `f` 의 포트 `m` 개가 사슬들에 `m_1, …, m_t` 로 나뉘면

```
sum_j max(m_j - 1, 0) = m - #{j : m_j >= 1} <= max(m - 1, 0),
```

이고 이 우변의 `(y, f)` 합이 정확히 `R_int` 다.  따라서

```
a + bb + e = rep <= R_int <= 2g.
```

즉 **A/B/e 사건 하나하나가 서로 다른 반복 포트를 소유하고, 그 반복 포트들이
`R_int` 라는 크기의 자원 풀에 단사로 들어간다.**

## Phase 9 — 안전 방향

행은 `bound < required` 일 때 닫힌다.  따라서

* **상계**(`a <= D2`, `bb <= Qs`, `e <= Z-Qs`, `a+bb+e <= 2g`) 가 실제보다
  **작으면** 탐색기의 자유도가 줄어 용량이 작아지고 상한이 낮아져 **실재하는
  덮개의 행을 닫는다** — 불건전.  그러므로 넷 모두 **실제 추출 사용량의 진짜
  상계**여야 한다.  그 방향이 §4–§7 에서 증명된 방향이다.
* **하계**(`a >= D2-d`, `a+bb >= D2+Qs-d`) 가 실제보다 **크면** 제약된
  이음매가 늘거나 `m_lo` 가 올라가 같은 실패가 난다.  그러므로 둘 모두
  **진짜 하계**여야 한다.

**단조성을 수치로 확인**했다 (`r158/certs/models_158.json`, 인증된 용량표로):
모형 상한은 `a`·`e`·`tot` 예산에 대해 **비감소** (450 회 비교, 위반 0),
조각 상한은 `nmark` 에 대해 **비증가** (270 회 비교, 위반 0).

**민감도** (실제 인구조사 1,609 행, 기준 1,607 닫힘 / 2 등호 재현):

| 섭동 | 방향 | 결과 |
|---|---|---|
| `bb` 예산 `+1` | 봉투가 거짓이라면 | **284 행이 더 이상 닫히지 않음** |
| `e` 예산 `+1` | " | **300 행** |
| `2g` 총예산 `+1` | " | **18 행** |

## Phase 14 — 종이 증명

> **정리 (봉투).**  `W` 를 고정 대표원이라 하고, 추출 정리대로 `beta` 구조를
> 사슬로 자르자: 더미 꼭짓점을 지우고, 순수 clean-E 순환 `c` 개를 지우고,
> 비순수 비더미 성분 `d` 개를 각각 비-E 간선 하나에서 열고, (분할 모형이면)
> 무게 `>= 4` 인 조인트를 전부 자른다.  `D2`, `Qs` 를 `W` 의 type A · type B
> 조인트 수, `x`, `y` 를 그중 개방으로 쓰인 수, `a`, `bb` 를 사슬 내부에 남은
> 수, `rep` 을 자기 사슬 안에서 육각형이 앞서 나온 포트 수,
> `e := rep - a - bb` 라 하자.  그러면
>
> **(i)** `a = D2 - x`, `bb = Qs - y`, `x + y <= d`;
> **(ii)** `a + bb + e = rep <= R_int <= 2g`;
> **(iii)** `D2 - d <= a <= D2`, `Qs - d <= bb <= Qs`, `a + bb >= D2 + Qs - d`;
> **(iv)** `e <= Z - Qs`, 그리고 `Z - Qs >= d >= 0`.

**증명.**

**(i)**  `beta` 는 순열이므로 유형 붙은 조인트를 갖는 각 pass 는 나가는 간선이
정확히 하나이고, 그 간선은 잘렸거나 사슬 안에 있다.  절단 집합은 `{성분마다
개방 하나} ∪ {무게 >= 4}` 다.  type A 의 무게는 2, type B 의 무게는 3 이므로
어느 쪽도 heavy 절단이 아니고, 순수 성분의 간선은 전부 clean E 이며 더미에
붙은 두 간선은 유형이 없다.  그러므로 유지되지 않은 A(resp. B) 조인트는
반드시 개방이고 `a = D2 - x`, `bb = Qs - y`.  개방은 성분마다 정확히 하나,
즉 전부 `d` 개이고 `x`, `y` 는 서로 다른 개방을 세므로 `x + y <= d`.

**(ii)**  사슬의 첫 포트가 아닌 각 포트 `v` 는 유일한 사슬 선행자 `u` 를 갖고
간선 `u -> v` 는 유형이 하나다.  반복 포트를 그 유형으로 분류하면
`a + bb + e = rep` 이 항등식이다.  유지된 A(resp. B) 간선은 `v_u` 를
`sigma(v_u)` (resp. `sigma^2(v_u)`) 로 보내므로 표적 육각형이 출발과 같고,
출발이 바로 앞 포트이므로 표적은 반복이다; `beta` 가 단사라 서로 다른 A/B
간선은 서로 다른 표적을 가지므로 `a + bb <= rep`, `e >= 0`.
성분 `y` 안의 사슬들은 `y` 의 포트를 분할하므로, 육각형 `f` 의 `y`-포트 `m`
개가 `m_1, …, m_t` 로 나뉘면
`sum_j max(m_j-1, 0) = m - #{j : m_j >= 1} <= max(m-1, 0)`;
`(y, f)` 에 대해 더하면 `rep <= R_int`.  마지막으로 `R_int <= 2g` 는 접합
정리다.

**(iii)**  (i) 과 `0 <= x, 0 <= y, x + y <= d` 에서 즉시.

**(iv)**  (ii) 과 (i) 에서
```
e = (a+bb+e) - a - bb <= 2g - (D2-x) - (Qs-y) = 2g - D2 - Qs + (x+y)
                      <= 2g - D2 - Qs + d.
```
`z := G - c = 2g + d` 와 `Z := z - D2` 로 우변은
`(z-d) - D2 - Qs + d = z - D2 - Qs = Z - Qs`.
또 SAME-HEX `D2 + Qs <= R_int` 와 `R_int <= 2g` 에서
`Z - Qs = 2g + d - D2 - Qs >= d >= 0`. ∎

**비고.**  (iv) 는 `a = D2` 도 `bb = Qs` 도 쓰지 않는다.  `d` 는 두 번
들어와 서로 지워진다: 한 번은 `x + y <= d` 로 위에서, 한 번은 `2g = z - d`
로 아래에서.
