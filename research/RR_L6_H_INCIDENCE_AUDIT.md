# H.incidence 독립 감사 — 접합 부등식의 재구성, 증명, 그리고 출처 수리

**대상 노드**  `H.incidence` (`r153/certs/dag_153.json`)
**감사 라운드**  157  **기반 커밋**  `92a94cd` (branch `round153-equality-coexistence`)
**산출물**  `r157/src/*.py`, `r157/certs/*.json`, 그리고 이 문서
**이 문서의 지위**  수리된 DAG(`r157/certs/dag_157.json`)의 `H.incidence.where`
가 가리키는 **정본(canonical) 진술·증명 문서**.  §2–§5 가 정리와 증명이고,
나머지는 감사다.

이 감사는 `H.incidence` **하나만** 다룬다.  `H.extract`, `H.tight`, `H.feas`,
`H.models`, `H.envelope`, `H.samehex` 는 재감사하지 않고, 명시적으로 필요한
곳에서만 이미 증명된 의존으로 인용한다.

## 요약

* **정리는 참이고, 완전한 셈 논증으로 증명된다.**  이분 접합 그래프 `B` 의
  **오일러 표수 하나**에서 부등식·등호 특징화·패리티가 모두 나온다.  핵심은
  부등식이 아니라 **항등식**이다:

  > `2g := (G+1) − K = mu(B) + R_int`,  `mu(B) = |E(B)| − |V(B)| + 1 >= 0`.

* **연결성이 유일한 비자명 가설**이고, `T` 가 한 개의 `(P+1)`-순환이라는
  구성적 사실에서 나온다.  `T` 가 순환이라는 가설을 빼면 정리는 **실제로
  깨진다** — 완전 유한 우주에서 105,077 개의 반례를 찾았다.
* **검증 규모**: 추상 완전 유한 우주 `N = 1..9` **전수 409,113 사례**
  (켤레 대칭으로 우주 전체), `T` 제한을 푼 533,417 사례, 표본 1,100,000 사례,
  실제 덮개 **513 개** (n=3 66 · n=4 306 · n=5 140 · n=6 1) — **위반 0**,
  `K + R_int > G+1` **0 건**, `등호이면서 나무가 아님` **0 건**.
* **결함은 전부 메타데이터**이며, 게다가 **라운드 153 의 퇴행**이다:
  `r148/src/dag148.py` 와 `r150/certs/dag150.json` 은 둘 다 올바른 판본을
  갖고 있었다.  (W1) `where` 가 무관한 n=5 시절 문서를 가리킨다.
  (W2) **패리티 절 `K = G+1 (mod 2)` 가 `what` 에서 빠졌다** — 이것은
  행 열거의 완비성에 적재된다.  둘 다 `r157/certs/dag_157.json` 에서
  **비파괴적으로 수리**했고, 불변이어야 할 19 개 산출물의 `sha256` 이
  하나도 바뀌지 않았음을 확인했다.

## Phase 2 + Phase 4 — 셈 항등식과 정리

정리는 `n`, 육각형, 덮개와 **무관한** 순수 치환 명제다.  그 형태로 세운다.

### 추상 설정

유한 집합 `X` (`|X| = M`), 치환 `alpha`, 치환 `T`, `beta := T alpha^{-1}`
(따라서 `beta alpha = T`).  `B~`, `B`, `R := |E(B~)| − |E(B)|` 는 위와 같이.

### 정리 (추상판)

> **(G1)** `comp(B) = ⟨alpha, beta⟩` 의 `X` 위 궤도 수.
> **(G2)** `mu(B) := |E(B)| − |V(B)| + comp(B) = M − R − c(alpha) − c(beta) + comp(B)`.
> **(G3)** `mu(B) >= 0`, 즉 **`c(alpha) + c(beta) + R <= M + comp(B)`**.
> **(G4)** `T` 가 `M`-순환이면 `comp(B) = 1` 이고 **`c(alpha) + c(beta) + R <= M + 1`**.
> **(G5)** (G4) 의 **등호 ⟺ `mu(B) = 0` ⟺ `B` 가 나무**.
> **(G6)** `T` 가 `M`-순환이면 `c(alpha) + c(beta) ≡ M + 1 (mod 2)`, 따라서
> `2g := M + 1 − c(alpha) − c(beta)` 는 **음이 아닌 짝수**.
> **(G7)** **분해 항등식** `2g = mu(B) + R`.

### 저장소 사례로의 대입

`M = |X| = P + 1 = HEX + 1 + G`, `c(alpha) = HEX + 1`, `c(beta) = K`,
`R = R_int`.  (G4) 가

```
(HEX + 1) + K + R_int  <=  (HEX + 1 + G) + 1      즉      K + R_int <= G + 1
```

가 되고, (G6) 이 `K ≡ G + 1 (mod 2)`, (G7) 이 `2g = mu(B) + R_int` 가 된다.
**`HEX` 는 양변에서 상쇄되므로 정리는 `n` 에 의존하지 않는다** (§11).

### 꼭짓점·간선 수

```
|V(B~)| = |V(B)| = c(alpha) + c(beta)            = (HEX + 1) + K
|E(B~)| = |X|                = M                 = HEX + 1 + G
|E(B)|  = |E(B~)| − R                            = HEX + 1 + G − R_int
```

오일러:

```
mu(B) = |E(B)| − |V(B)| + comp(B)
      = (HEX + 1 + G − R_int) − (HEX + 1 + K) + 1
      = G + 1 − K − R_int
      = 2g − R_int.
```

`mu(B) >= 0` 이 곧 `K + R_int <= G + 1` 이다.  **부등식은 오일러 표수 한 줄의
따름정리이고, 진짜 내용은 `2g = mu(B) + R_int` 라는 항등식이다.**

## Phase 3 — 그래프 구성의 여섯 가지 확인

**3.1 모든 꼭짓점이 정당한 구조적 대상이다.**
`alpha`-순환은 (i) 각 육각형 `h` 의 pass 들이 이루는 `nu`-순환 (보조정리 B)
또는 (ii) 더미 `{*}` 이다.  **모든 육각형이 pass 를 갖는다**: `n!` 개 창이
전부 선택되고, 육각형 `h` 의 창은 `h` 의 호(=pass) 안에서만 선택될 수 있으므로
`m_h >= 1` 이다 (보조정리 A; `l6_incidence_graph_146.py` 따름정리 (i)).
그러므로 `c(alpha) = HEX + 1` 이 **무조건** 성립한다.  `beta`-순환은 정의상
비어 있지 않다.  실제 덮개 513 개에서 `c(alpha) = n!/n + 1` 과 "각
`alpha`-순환이 정확히 한 육각형(또는 더미)" 을 확인했다 (검사 V1).

**3.2 모든 간선이 정확히 주장된 접합이다.**  간선은 **원소마다 하나**다:
`x ↦ {alpha-순환(x), beta-순환(x)}`.  이것이 "pass `x` 가 육각형 `h` 에도
속하고 성분 `C` 에도 속한다"는 접합 그 자체다.

**3.3 빠진 접합도, 중복 계수도 없다.**  `|E(B~)| = |X| = P+1` 은 구성에서
자명하다.  실제 덮개에서 양쪽 차수 합이 모두 `P+1` 임을 확인했고, 육각형
꼭짓점 차수에서 `sum_h (deg − 1) = G` (보조정리 A) 도 확인했다.

**3.4 다중도 처리.**  `|A ∩ C| = m > 1` 인 쌍은 `B~` 에서 평행 간선 `m` 개,
`B` 에서 간선 1 개가 되어 `R` 에 `m−1` 을 기여한다.  실제 덮개 285 개에서
다중 간선이 실제로 나타난다.  **두 `R_int` 정의의 일치**:

> 그래프판은 쌍 `(A,C)` 에 대한 `(|A∩C|−1)` 의 합이다.  `A` 가 더미
> `alpha`-순환 `{*}` 인 유일한 쌍은 `|{*} ∩ C_*| = 1` 이라 **0 을 기여**한다.
> 나머지 쌍은 (육각형, `beta` 성분) 쌍이므로, 합은 성분마다 육각형 중복
> 초과를 더미를 빼고 센 것과 **같다**. ∎

513 개 실제 덮개에서 두 값이 항상 일치했다 (검사 R1).

**3.5 더미·시작·끝 처리.**  `alpha(*) = *` 이므로 `{*}` 은 크기 1 의
`alpha`-순환이고, `B` 에서 **차수 1 의 잎**이다 (확인함).  `beta(*) = 0` 이고
`beta(nu(P−1)) = *` 이므로 `*` 은 언제나 어떤 `beta`-순환 안에 있다.
`T = (0 1 … P−1 *)` 은 구성상 **한 개의 `(P+1)`-순환**이다.

**3.6 숨은 가정 수색.**  명시적으로 확인한 것:

| 위험 | 판정 |
|---|---|
| 반복 창 | `B` 는 **선택된 창(=pass 진입점)** 만 본다.  연결자 내부의 반복 창은 pass 가 아니므로 `X` 에 없다.  `R_int` 는 "같은 성분 안에서 같은 육각형이 다시 나타남" 이지 단어의 반복 창이 아니다. |
| `beta` 성분 | 정리는 `beta` 의 **순환 수**만 쓴다.  성분의 종류(순수/비순수)는 전혀 쓰지 않는다. |
| 순수 clean-E 순환 | 특별 취급 없음.  순수 순환은 그냥 `beta`-순환 하나이고, `r` 개의 **서로 다른** 육각형에 붙어 다중 간선을 만들지 않는다. |
| heavy 조인트 · 사슬 절단 · 분할/병합 모형 | **정리 이전 단계가 아니다.**  `B` 는 절단 전의 `beta` 에서 만들어진다.  절단은 `H.extract` 의 일이고 `H.incidence` 와 무관하다. |
| 더미 성분 `Y_*` | 다른 `beta`-순환과 똑같이 취급된다.  특권 없음. |
| 공유 육각형 | 여러 성분이 한 육각형을 공유하면 그 육각형 꼭짓점의 차수가 커질 뿐이다.  이것이 그래프가 나무일 수 있는 이유이자 `mu > 0` 일 수 있는 이유다. |
| **`alpha`-순환과 `beta`-순환이 집합으로 같을 때** | 두 꼭짓점을 **반드시 구별**해야 한다.  집합 자체를 꼭짓점 id 로 쓰면 둘이 합쳐져 `\|V\|` 가 줄고 자기 고리가 생겨 계산이 깨진다.  `l6_incidence_graph_146.py` 는 `"A%d"`/`"B%d"` 접두사로, `r157` 은 `("A",i)`/`("B",i)` 로 구별한다.  `M=1` 에서 실제로 일어나는 경우다. |

## Phase 5 — 등호 특징화 (양방향)

> **(G5)** `T` 가 `M`-순환일 때
> `c(alpha) + c(beta) + R = M + 1` ⟺ `mu(B) = 0` ⟺ `B` 는 **나무**.

**(⟸)** `B` 가 나무면 연결이고 `|E(B)| = |V(B)| − 1` 이므로
`mu(B) = 0`, 즉 등호.

**(⟹)** 등호면 `mu(B) = |E(B)| − |V(B)| + comp(B) = 0`.  `comp(B) = 1`
(§6 에서 **따로** 증명) 이므로 `|E(B)| = |V(B)| − 1` 이고, 연결이면서 간선이
`|V|−1` 개인 단순 그래프는 나무다. ∎

**주의 두 가지.**
1. `mu(B) = 0` 만으로는 "비순환"까지이고, **연결성이 따로 증명되어야** 나무가
   된다.  (G3) 의 일반형은 `c(alpha)+c(beta)+R <= M + comp(B)` 이고, 등호는
   "`B` 가 **숲**" 을 준다.  저장소 사례에서는 `comp = 1` 이 항상 참이므로
   숲 = 나무다.
2. **"나무"는 단순 그래프 `B` 에 대한 말이다.**  `R_int > 0` 이면 `B~` 는
   평행 간선을 가지므로 `B` 가 나무여도 `B~` 는 나무가 아니다.  `r153` 의
   `what` 은 "the incidence graph" 라고만 적어 이 구별을 흐린다 —

## Phase 6 — 연결성 (최고 위험 지점)

> **명제.**  `T` 가 `X` 위의 한 개 `|X|`-순환이면 `B` 는 연결이다.

**증명.**  `beta alpha = T` 이므로 `T ∈ ⟨alpha, beta⟩` 이고, `T` 가 한 개의
`|X|`-순환이므로 `⟨alpha, beta⟩` 는 `X` 위에서 **추이적**이다.
이제 사상 `x ↦ (x 의 간선이 속한 B 의 성분)` 을 보자.  `x` 와 `alpha(x)` 의
간선은 `alpha`-순환 꼭짓점을 공유하고, `x` 와 `beta(x)` 의 간선은 `beta`-순환
꼭짓점을 공유한다.  따라서 이 사상은 `⟨alpha, beta⟩`-궤도 위에서 상수다.
추이성으로 모든 간선이 한 성분에 있다.  모든 꼭짓점(=순환)은 비어 있지 않아
간선 하나 이상에 닿으므로, 모든 꼭짓점이 그 성분에 있다. ∎

역방향도 참이고 (G1) 이 그것이다: 두 원소의 간선이 같은 성분에 있으면, 성분
안의 경로가 `alpha`-순환/`beta`-순환을 번갈아 지나므로 두 원소는 같은
`⟨alpha, beta⟩`-궤도에 있다.  즉 **`comp(B) = #⟨alpha,beta⟩-궤도**.
513 개 실제 덮개와 409,113 개 추상 사례에서 `comp = orbits` 를 확인했다.

**저장소에서 가설이 성립하는 이유**는 구성적이다: `T(i) = i+1` (`i < P−1`),
`T(P−1) = *`, `T(*) = 0` — 곧 순환 `(0 1 … P−1 *)` 이다.  길이 `P+1` 의
**한 개** 순환이므로 조건은 **무조건** 성립한다.  더미 성분, 고립된
`alpha`-순환, 순수 clean-E 순환, 분리된 `beta` 구조, 잘린 heavy 간선 —
어느 것도 이 사실을 건드리지 못한다.  절단은 `H.extract` 가 `beta` 로부터
사슬을 만들 때 하는 일이고, `B` 는 **절단 이전의** `beta` 에서 만들어진다.

**가설이 장식이 아님을 보이는 실험.**  `T` 가 한 개 순환이라는 가설만 빼고
`M <= 6` 의 모든 `(alpha, T)` 쌍 443,978 개를 돌렸다:

```
(G1),(G2),(G3)  일반형 c(alpha)+c(beta)+R <= M + comp(B)   : 위반 0
(G4) 형태       c(alpha)+c(beta)+R <= M + 1                : 반례 105,077
```

즉 **연결성이 정확히 `+1` 을 사는 유일한 가설**이다.

## Phase 7 — 라운드 155 의 `2g = mu(B) + R_int` 와의 관계 (독립 유도)

라운드 155 를 인용하지 않고 §2 에서 독립적으로 유도했다.  `T` 가 `M`-순환일 때

```
2g := M + 1 − c(alpha) − c(beta) = (G + 1) − K      (저장소 대입)
mu(B) = M − R − c(alpha) − c(beta) + 1 = 2g − R
⟹  2g = mu(B) + R_int,   mu(B) >= 0,  R_int >= 0.
```

따라서 **정확한 동치**는 다음과 같다:

> `H.incidence` 의 부등식 `K + R_int <= G + 1`
> ⟺ `mu(B) >= 0`
> (항등식 `2g = mu(B) + R_int` 를 전제로).
>
> 그리고 `mu(B) >= 0` 은 **모든 그래프에 대해 자명하게 참**이다.
> 그러므로 정리의 실질 내용은 부등식이 아니라 **네 개의 셈**이다:
> `|E(B~)| = |X|`, `|V(B)| = c(alpha)+c(beta)`, `R_int = |E(B~)|−|E(B)|`,
> `comp(B) = 1`.

패리티 (G6) 은 이와 독립적인 두 번째 내용이며, 부호 준동형에서 나온다 (§12).
`2g >= 0` (부등식) 과 `2g` 짝수 (패리티) 가 합쳐져 **`g` 가 음이 아닌
정수**임을 준다 — 이것이 행 열거가 실제로 소비하는 형태다.

두 하류 소비 형태도 항등식에서 즉시 나온다:

* `R_int <= 2g`  (행 열거·`H.samehex` 가 쓰는 형태) — `mu(B) >= 0` 에서.
* `g = 0 ⟹ mu(B) = 0 그리고 R_int = 0` — 음이 아닌 두 항의 합이 0.
  즉 `g = 0` 이면 `B` 는 나무이고 사슬은 육각 단순이다.

513 개 실제 덮개에서 `S1`(항등식), `D1`, `D2` 를 전부 확인했다.

## Phase 12 — 종이 증명

> **정리.**  `X` 를 유한 집합, `alpha ∈ Sym(X)`, `T ∈ Sym(X)` 를 한 개의
> `|X|`-순환, `beta := T alpha^{-1}` 라 하자.  `B` 를 `alpha`-순환과
> `beta`-순환을 꼭짓점으로 하고, 원소 `x` 마다 `alpha`-순환`(x)` 과
> `beta`-순환`(x)` 을 잇는 간선을 둔 **단순** 이분 그래프라 하고,
> `R := |X| − |E(B)|` 라 하자.  그러면
>
> `c(alpha) + c(beta) + R <= |X| + 1`,
> `c(alpha) + c(beta) ≡ |X| + 1 (mod 2)`,
> 그리고 등호는 `B` 가 나무인 것과 동치다.

**증명.**
*(연결성)* `beta alpha = T` 이므로 `⟨alpha, beta⟩` 는 `T` 를 품고, `T` 가 한
개의 `|X|`-순환이므로 `X` 위에서 추이적이다.  `x` 와 `alpha(x)` 의 간선은
`alpha`-쪽 끝점을, `x` 와 `beta(x)` 의 간선은 `beta`-쪽 끝점을 공유하므로,
"간선이 속한 성분" 은 `⟨alpha, beta⟩`-궤도 위에서 상수다.  추이성으로 모든
간선이 한 성분에 있고, 모든 꼭짓점은 비어 있지 않은 순환이라 간선에 닿으므로
`B` 는 연결이다.

*(셈)* 원소마다 간선 하나를 놓았으므로 다중그래프의 간선 수는 `|X|` 이고,
평행 간선을 합치면 `|E(B)| = |X| − R`.  꼭짓점 수는 `c(alpha) + c(beta)`.
연결 그래프는 `|E| >= |V| − 1` 이므로

```
|X| − R  >=  c(alpha) + c(beta) − 1,     즉     c(alpha)+c(beta)+R <= |X|+1.
```

동치로, 첫 베티 수 `mu(B) = |E(B)| − |V(B)| + 1 = |X|+1−c(alpha)−c(beta)−R`
가 음이 아니다.

*(등호)* `mu(B) = 0` ⟺ `|E(B)| = |V(B)| − 1`; 연결성과 합쳐 `B` 는 나무.

*(패리티)* `sgn(alpha) = (−1)^{|X| − c(alpha)}`, 같은 식이 `beta`, `T` 에도
성립한다.  `beta = T alpha^{-1}` 에서 `sgn(beta) = sgn(T) sgn(alpha)` 이므로

```
|X| − c(beta) ≡ (|X| − 1) + (|X| − c(alpha))   (mod 2)
⟹  c(alpha) + c(beta) ≡ |X| + 1   (mod 2).  ∎
```

**저장소 대입.**  `X = {pass} ∪ {*}`, `|X| = P+1 = HEX+1+G`,
`c(alpha) = HEX+1` (모든 육각형이 pass 를 갖는다), `c(beta) = K`,
`R = R_int`.  세 결론이 각각

```
K + R_int <= G + 1,        K ≡ G + 1 (mod 2),        등호 ⟺ B 가 나무
```

가 되고, `2g := G+1−K` 에 대해 `2g = mu(B) + R_int` 이다. ∎

**비고.**  이 명제는 고전적이다: 추이적 삼중쌍 `(alpha, beta, T^{-1})` 에
대한 하이퍼맵 오일러 공식 `c(alpha)+c(beta)+c(T) = |X| + 2 − 2·genus` 가
`c(T)=1` 에서 `2g = 2·genus` 를 주며, 위 `g` 가 곧 하이퍼맵의 **종수**다.
위 증명은 그 사실을 쓰지 않고 초등적으로 닫혀 있으며, `R_int` 라는 다중도
항까지 분리해 낸다는 점에서 조금 더 정밀하다.

## 결함 목록

### W1 (라운드 153 퇴행, 수리함) — `where` 가 무관한 문서를 가리켰다
`research/RR_INCIDENCE_FOREST_LEMMA.md` 는 n=5 시절 RR 코퍼스의 union-find

있었다.  `r157/certs/dag_157.json` 에서 수리.

### W2 (라운드 153 퇴행, 수리함) — 패리티 절이 `what` 에서 빠졌다
`K = G+1 (mod 2)` 는 **적재 조항**이다.  행 열거는 `K = G+1−2g` 로 좌표를
잡고 **정수** `g >= 0` 만 열거하므로, `G+1−K` 가 홀수인 실제 덮개가 있다면
그 덮개는 어떤 행과도 맞지 않아 인구조사를 빠져나간다.  패리티가 그런 덮개가
없음을 보증한다.  `r148`·`r150` 의 `what` 에는 있었다.  수리함.

### W3 (경미, 수리함) — "나무"의 대상이 단순 그래프임이 명시되지 않았다
`R_int > 0` 이면 `B~` 는 평행 간선을 가지므로 나무일 수 없다.  등호가 주는
것은 **`B` 가 나무**다.  `what` 에 `SIMPLE` 을 넣어 수리.  (하류의 두
등호행은 `R_int = 0` 이라 어느 읽기로도 결론이 같다.)

### 수학적 결함 — **없음**
`src/l6_incidence_144.py` 와 `src/l6_incidence_graph_146.py` 의 진술과 증명은
읽은 대로 정확하다.  §12 의 종이 증명은 그 둘을 합쳐 최소 형태로 다시 쓴
것이며, 새로 추가한 것은 (a) `comp(B) = #⟨alpha,beta⟩-궤도` 라는 역방향,
(b) 두 `R_int` 정의가 같다는 한 줄 증명, (c) 분해 항등식 `2g = mu(B) + R_int`
의 독립 유도, (d) `alpha`-순환과 `beta`-순환을 꼭짓점으로 반드시 구별해야
한다는 함정의 명시다.
