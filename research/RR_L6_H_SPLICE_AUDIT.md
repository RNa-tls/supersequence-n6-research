# H.splice 독립 감사 — 스플라이싱과 beta 구조 보조정리 A–F

**대상 노드**  `H.splice`
**감사 라운드**  161  **기반 커밋**  `561db9c` (branch `round153-equality-coexistence`)
**산출물**  `r161/src/*.py`, `r161/certs/*.json`, 그리고 이 문서
**이 문서의 지위**  수리된 DAG(`r161/certs/dag_161.json`)의 `H.splice.where`
가 가리키는 정본 감사 문서.  §2·§22 가 정의와 종이 증명이다.

이 감사는 `H.splice` **하나만** 다룬다.  `H.master`, `H.samehex`,
`H.incidence`, `H.extract`, `H.envelope`, `H.tight`, `H.feas`, `H.models`,
`H.catalogue`, `H.wlog` 는 재감사하지 않고 이미 인증된 의존으로만 인용한다.
이전 라운드의 부분 감사(E/F)를 대체물로 쓰지 않고 **처음부터 다시** 세웠다.

## 요약

* **여섯 보조정리를 절 단위로 쪼개 전부 증명·검증했다** — A1–A5, B1–B3,
  C1–C3, D1–D3, E1–E4, F1–F4, 그리고 국소 기하 G1.  실제 덮개 **646 개**
  위반 0, 국소 기하 **전수**(n=6 에서 518,400 쌍) 위반 0, 추상 전수
  (보조정리 E 1,161 사례 · 보조정리 F **695,482** 사례) 위반 0.  가설을
  제거하면 각각 반례가 나온다 (덮개 300/300 · E 의 진입점 구별 5 · F 의
  `beta` 순열성 1,306).
* **가설이 정확히 어디에 걸리는지 확정했다.**  A·B·D·E·F 는 "`W` 가 **덮개**"
  만 필요하고, **오직 C3**("재배정된 간선이 최단 연결자") 만이 고정 대표원
  가설을 쓴다.  고정 대표원이 **아닌** 덮개 92 개에서 **C3 만** 깨지고 다른
  절은 전부 살아남는다.
* **따라서 `H.splice` 는 미증명 `H.fixedrep` 정리를 수입하지 않는다.**
  필요한 것은 주어진 단어의 **검사 가능한 성질**(덮개이다 / 선택 간격이
  `omega` 다) 이지 WLOG 정리가 아니다.
* **보조정리 E 의 역은 거짓이고 쓰이지 않는다** — 완전한 `tau`-궤도가 pass
  진입점으로 전부 나타나면서도 순수 순환을 이루지 **않는** 덮개가
  646 개 중 **324 개**다.  프로젝트는 정방향만 소비한다.
* **`tau`-궤도가 `n-1` 개의 서로 다른 육각형을 만난다**(라운드 155 가 쓴 사실)
  는 **한 줄로 증명**된다: `tau` 는 마지막 글자를 고정하고, 육각형은 마지막
  글자마다 창을 정확히 하나씩 갖는다.  저장소는 이것을 전수 검사 노드
  `A.orbitfive` 로 갖고 있는데, 이제 정리로 승급 가능하다.
* **다섯 유형 beta-성분 분류는 어디에도 쓰지 않았다.**  적재 이분법은
  순수 / 비순수뿐이다.
* **결함은 메타데이터 하나**: `what` 이 "successor splicing and the beta
  permutation" 이라고만 적어 **여섯 보조정리를 하나도 열거하지 않았다**.
  비파괴적으로 열거하도록 고쳤다.

## Phase 3 — 기본 beta 항등식

`alpha = nu + (*↦*)`, `T = (0 1 … P-1 *)`, `beta := T alpha^{-1}`.

* `beta(nu(i)) = T(alpha^{-1}(nu(i))) = T(i) = i+1` (`0 <= i <= P-2`);
* `beta(nu(P-1)) = T(P-1) = *`;
* `beta(*) = T(alpha^{-1}(*)) = T(*) = 0`.

**끝점·더미 규약.**  `src/l6_splicing_145.py` 의 서술은 1-기반
(`T(P) = *`, `T(*) = 1`) 이고 코드는 0-기반이다 (`T[P-1] = dummy`,
`T[dummy] = 0`).  같은 `(P+1)`-순환이며 `beta(nu(i)) = i+1` 도 같다 —
**규약 차이일 뿐 내용 차이가 아니다**.  더미는 pass 가 아니고 `alpha` 의
고정점이며, `beta` 의 두 간선(`nu(P-1) -> *`, `* -> 0`) 은 **유형이 없다**.

`r161/src/lemmas161.py` 는 `beta` 가 순열임(D1), 위 세 등식(D2), 그리고
**`beta` 의 간선 집합이 정확히 재배정된 조인트 `P-1` 개 + 더미 간선 2 개**
임을 집합으로 대조해 646 개 단어 전부에서 확인한다.

## Phase 4 — 보조정리 A

**진술** (`src/l6_splicing_145.py` 16–19 행):
> 각 `n!` 창은 정확히 한 번 선택되고, 육각형 `h` 의 창은 `h` 의 pass 에만
> 속할 수 있으므로 `h` 의 호들은 서로소이고 `h` 의 `n` 원소를 덮는다.
> 따라서 `sum_h m_h = P`, `sum_h (m_h - 1) = G`.

**증명.**
*(A2)* `g_j = 1` 이면 `q_{j+1} = q_j[1:] + W[i_j+n]` 이고 그 `n` 글자가 서로
다르므로 `W[i_j+n] = q_j[0]`, 즉 `q_{j+1} = sigma(q_j)`.  그러므로 pass 의
연속 창은 `sigma` 로 이어지고 pass 는 **한 육각형의 호**다.
*(A1)* `selected` 는 첫 출현 목록이고 `W` 는 덮개이므로 각 순열이 정확히 한 번.
*(A3)* `h` 의 각 창은 한 번 선택되어 어떤 pass 에 속하고, (A2) 로 그 pass 는
`h` 의 호다.  따라서 `h` 의 호들은 서로소이고 합집합이 `h` 전체다.
*(A4)* `h` 는 창을 `n >= 1` 개 가지므로 pass 가 적어도 하나. ∎
*(A5)* pass 는 정확히 한 육각형에 속하므로 `sum m_h = P`;
`sum (m_h - 1) = P - HEX = G`. ∎

**"H.tight 가 쓴 것이 정말 A 인가."**  그렇다.  §9 는 "120 개 육각형이 전부
쓰인다" 를 "아니면 반복 초과가 `G` 를 넘는다" 로 정당화하는데 이는 순환
논증이고, 라운드 155 감사가 이미 지적해 **보조정리 A4 로 대체**했다.
`src/l6_incidence_graph_146.py` 따름정리 (i) 도 같은 말을 한다
("TRUE UNCONDITIONALLY").  **소유권은 `H.splice`(A4)** 이지 `H.tight` 가 아니다.

**여섯 창이 모두 다뤄지는가.**  (A3) 이 정확히 그 진술이다 — 실측으로
각 육각형의 호 합집합이 크기 `n` 이고 중복이 없음을 646 단어 전부에서 확인.

**육각형이 pass 를 못 받는 반례 탐색.**  덮개에서는 (A4) 로 불가능하다.
`W` 가 덮개가 **아니면** 가능하다 — `r161/src/abstract161.py::sweep_A` 가
덮개가 아닌 단어를 만들어 A1 이 즉시 깨짐을 확인한다 (§20).

## Phase 5 — 보조정리 B

**진술**: `nu` 는 pass 의 순열이고 그 순환이 정확히 육각형이며 길이가 `m_h`,
`c(nu) = n!/n`.  **`beta`-성분도, 스플라이싱도, 순수 순환도 아니다** —
`nu` 는 "같은 육각형의 다음 호" 사상이고 B 는 그 **순환 구조**에 대한
진술이다.

**증명.**  (A3) 로 `h` 의 호들은 `sigma` 아래 `h` 를 순환적으로 분할한다.
`sigma^{l_i}(v_i)` 는 pass `i` 의 마지막 창 바로 다음 창이므로 `h` 의
**다음 호의 첫 창**, 즉 pass 진입점이다 (B1).  `h` 안에서 `nu` 는 `m_h` 개
호 위의 순환 후자 사상이므로 길이 `m_h` 의 한 순환이다 (B3).  모든 pass 가
정확히 한 육각형에 속하므로 `nu` 는 순열이고 `c(nu) = HEX` 다 (B2). ∎

**경계.**  `m_h = 1` 이면 `nu(i) = i` (고정점) — 정상이며 (A4) 로 `m_h = 0` 은
없다.  실측: `m_h` 최대값이 3 이상인 단어 305 개, 4 이상 94 개.

## Phase 6 — 보조정리 C

**증명.**
*(C1)* pass `i` 의 마지막 창은 `sigma^{l_i-1}(v_i) = sigma^{-1}(sigma^{l_i}(v_i))
= sigma^{-1}(v_{nu(i)}) = end(v_{nu(i)})`.  순수 대수 + (B1).
*(C2)* 조인트는 **단어 안의 한 자리**다.  재배정은 그 자리를 어느 pass 가
소유하는지를 바꾸는 **라벨링**이고 단어를 건드리지 않는다.  (C1) 로 출발
창이 같고, 표적·간격·철자·내부(숨은) 창은 그 자리의 성질이므로 불변이다.
*(C3)* 고정 대표원에서는 `g_j = omega(q_j, q_{j+1})` 이고 (C1) 로
`q_j = end(v_{nu(i)})` 이므로 재배정된 간선은 `end(v_{nu(i)})` 에서 나가는
최단 연결자다. ∎

**국소 순열 기하를 카탈로그 라벨 없이 직접 확인**했다: `r161/src/geom161.py`
가 `n = 3,4,5,6` 의 **모든** `(v, tgt)` 쌍(`n=6` 에서 518,400) 에서 간격과
표적의 대수적 정체를 계산하고, 독립 분류를 저장소 카탈로그
`src/l6_splicing_145.py::classify` 와 대조한다 — **불일치 0**.

**적재 여부.**  C 는 적재다: `H.samehex` 의 과금이 **재배정된 간선**에 대해
이루어지므로, C2 가 없으면 그 논증이 단어의 조인트가 아닌 다른 대상에 대한
것이 된다 (§15).

## Phase 7 — 보조정리 D

**증명.**  `alpha` 는 순열(B2 + 고정점 `*`), `T` 는 순열이므로 `beta` 도
순열이다 (D1).  §3 의 세 등식이 D2 다.  `beta` 의 간선은 `P+1` 개이고 그중
`P-1` 개가 재배정된 조인트 `(nu(i), i+1)`, 나머지 둘이 더미 간선이다.
`c(alpha) = c(nu) + 1 = HEX + 1` (B3), `c(T) = 1` (구성). ∎

**무엇이 불변이고 무엇이 바뀌는가** (스플라이싱/변환별):

| 대상 | 스플라이싱(재배정) 후 |
|---|---|
| 단어 `W`, 그 길이 | **불변** (연산이 단어를 건드리지 않는다) |
| 선택 창 집합과 위치 | **불변** |
| pass 집합, `P`, `G` | **불변** |
| 조인트의 출발 문자열·표적·간격·철자·숨은 창 | **불변** (C2) |
| 무게 `w`, `S`, `H`, dirty 유형 | **불변** (C2 의 따름) |
| 조인트의 **소유 pass** | `i` 에서 `nu(i)` 로 **바뀐다** |
| 접합 다중도 / `beta`-성분 | 재배정의 **결과로 생기는** 대상; 재배정 전에는 존재하지 않는다 |

**`beta`-성분의 생성/소멸**은 이 연산에서 문제가 되지 않는다 — `beta` 는
재배정 **이후에 정의되는** 순열이고, 재배정 전의 "성분" 이라는 것이 없다.

## Phase 8 — 보조정리 E 재감사

**현재 진술** (`src/l6_splicing_145.py` 49–57 행): 순수 clean-E 순환은
길이가 정확히 `n-1` 이고 그 진입점이 한 `tau`-궤도의 `n-1` 원소 전부이며
그 궤도에는 다른 pass 가 없다.

**종이 증명.**  clean-E 간선은 진입점 `v` 를 `tau(v)` 로 보내므로 `tau`-궤도를
유지하고 위상을 정확히 `+1 (mod n-1)` 시킨다 (E1).  길이 `m` 의 순수 순환을
따라 위상은 `m` 만큼 진행하고 출발로 돌아와야 하므로 `(n-1) | m`.  pass
진입점은 서로 다른 선택 창이고 (A1) 궤도에는 원소가 `n-1` 개뿐이므로
`m <= n-1`.  따라서 `m = n-1` 이고 진입점이 궤도 전부다 (E2, E3).  궤도 밖
pass 가 그 궤도에 있으면 `n` 번째 서로 다른 진입점이 필요해 모순이다 (E4). ∎

**독립 유한 우주.**  `U-E` = 한 `m`-순환 위의 위상 라벨 `Z/r` 전부와 간선
라벨 `{E, nonE}` 전부 중 (e1) `E` 간선이 위상을 `+1` 시키는 것.
`r = 2..5`, `m = 1..2r` 에서 **전수** — 사례 1,161, 그중 all-E 순환 14 개,
**위반 0**.  (all-E 순환이 14 개뿐인 것이 결론 그 자체다: 가설 아래에서
all-E 순환은 `m = r` 일 때만, 그것도 `r` 가지 회전으로만 존재한다.)

**옛 기계 인증서와의 대조.**  `src/l6_splicing_145.py` 282–306 행의 검사는
실제 덮개에서 (i) 길이 `n-1`, (ii) 궤도 하나, (iii) 진입점 = 궤도 전부,
(iv) 궤도 밖 pass 없음을 확인한다 — **현재 보조정리와 낱말 단위로 일치**한다.
r161 은 같은 네 항목을 독립 구현으로 646 단어에서 다시 확인했다 (위반 0).

## Phase 9 — 보조정리 F 재감사

**진술**: 조인트는 `P-1` 개, 그중 `S` 개가 유료(`w>=3`), 자유 조인트 중
`D2` 개가 dirty 무게 2 (type A).  따라서 clean-E 간선은 `P-1-S-D2` 개이고
나머지를 전부 자르면 `S+1+D2` 개의 극대 clean-E 블록이 남는다.  순수 순환을
지우면 꼭짓점 `n-1` 개와 clean-E 간선 `n-1` 개가 사라져 블록 수가 변하지 않는다.

**독립 증명.**
*(F1, gap-2 이분법)* `p' = end(v) = v[n-1] + v[:n-1]` 이므로
`p'[2:] = v[1:n-1]`.  `omega(p', tgt) = 2` 는 `p'[2:] = tgt[:n-2]` 이므로
`tgt = v[1:n-1] + (남은 두 글자의 배열)`, 즉
`tgt in {v[1:n-1]+v[0]+v[n-1], v[1:n-1]+v[n-1]+v[0]} = {tau(v), sigma(v)}`.
**무게 2 조인트는 clean-E 아니면 type A 다.** ∎
*(F2)* 조인트 `P-1` 개 중 `S` 개가 `w>=3`; 나머지는 무게 2 이고 (F1) 로
`D2` 개가 A, 나머지가 clean-E.
*(F3)* `blocks := P - cleanE = P - (P-1-S-D2) = S+1+D2`.
*(F4)* `beta` 가 순열이므로 clean-E 부분그래프는 진입·진출 차수 `<= 1`, 즉
경로와 순환의 분리합집합이다.  꼭짓점 `k` 개 경로는 간선 `k-1` 개, 순환은
`k` 개이므로 `P - cleanE = #(경로 성분)` 이고 순환은 0 을 기여한다.
순수 순환은 **정확히** clean-E 순환이므로 (보조정리 E), 그 `n-1` 꼭짓점과
`n-1` 간선을 지워도 `P - cleanE` 도 경로 성분 수도 변하지 않는다. ∎

**가설 제거.**  `beta` 가 순열이라는 가정을 빼면 (F4) 와 `P-|E| = #경로 성분`
이 둘 다 깨진다 — §20 의 실험이 반례를 낸다.  "clean-E 순수성" · "성분 길이"
· "방향" · "반복 육각형 없음" · "특정 시작 대표원" 중 F 가 쓰는 것은
**clean-E 순수성과 (E 를 통한) 성분 길이뿐**이고, 방향·반복 육각형·시작
대표원은 **쓰지 않는다** (§20 표).

**독립 유한 우주.**  `U-F` = `{0..m-1}` 의 순열 `beta` 전부 × 간선 부분집합
전부.  `m <= 7` 에서 `sum_m m! * 2^m = 695,482` 사례 **전수**, **위반 0**.

## Phase 11 — `tau`-궤도 기하

> **보조정리 G1.**  `tau` 는 마지막 글자를 고정한다.  육각형은 마지막 글자마다
> 창을 정확히 하나씩 갖는다.  따라서 육각형과 `tau`-궤도는 **최대 한 창**에서
> 만나고, `tau`-궤도는 `n-1` 개의 **서로 다른** 육각형에 놓인다.

**증명.**  `tau(w) = w[1:n-1] + w[0] + w[n-1]` 이므로 `tau(w)[n-1] = w[n-1]`.
육각형의 `n` 개 창은 `sigma^k(w)` (`k = 0..n-1`) 이고 그 마지막 글자는
`w[n-1], w[0], …, w[n-2]` — 전부 다르다.  따라서 한 육각형에는 주어진 마지막
글자를 갖는 창이 하나뿐이다.  `tau`-궤도의 `n-1` 창은 마지막 글자가 같으므로
`n-1` 개의 서로 다른 육각형에 놓인다. ∎

**따름**: 순수 순환은 `R_int` 에 **0 을 기여**하고, 접합 그래프에서 차수가
정확히 `n-1 = 5` 다 (§14).

**전수 확인** (`r161/certs/geometry_161.json`): `n = 3,4,5,6` 의 모든 궤도
(3 / 8 / 30 / **144**) 가 각각 `n-1` (2 / 3 / 4 / **5**) 개의 서로 다른
육각형을 만난다 — 예외 0.  `n=6` 기준 518,400 쌍 전수.

**저장소와의 관계.**  이 사실은 `A.orbitfive` 라는 **별도 노드**로,
`r153/src/coexist153.py` 가 144 개를 전수 검사한 `CERTIFIED_MACHINE` 이다.
r161 의 증명은 그것을 **정리로 승급**시킨다 (이 감사는 그 노드를 수정하지
않고 사실만 기록한다).

## Phase 12 — 스플라이싱 연산

**연산이 작용하는 대상**: 조인트의 **소유 pass 라벨**.  단어에도, 선택 창에도,


| 선택 창이 셈을 무너뜨리게 복제되는가 | **아니오** — 복제가 없다 |
