## 1. 2-예외 보조정리 — 정확한 서술과 증명 (§1)

> **보조정리.** 앞으로의 매크로 간선 중 `ℓ < 5` 인 것은 **최대 2개**다.
> **범위: 모든 미래 매크로 간선.** fresh-orbit opening 에 한정되지 않는다.

**(a) `F = 1` 이면 앞으로 abandonment 는 불가능하다.** `extend()` 에서 `dF = int(abandonment)`
이고 `F ≤ TARGET_F = 1` 이 `F_exceeded`(Q1-SAFE)로 강제된다. 잔여 6,657 상태는 전부 `F = 1`
(라운드 83에서 실측)이므로 `abandonment = True` 인 전이는 `F = 2` 가 되어 즉시 제거된다.

**(b) 새 육각형에 진입한 pass 는 `ℓ = 5` 로 떠나야 한다.** 진입점을 `e` 라 하면 진입 시점에
그 육각형의 6개 창이 모두 미방문이다. 떠나려면 joint 가 필요하고, `abandonment = not
visited(σ(p'))` 가 False 여야 하므로 `σ(p')` 가 방문돼 있어야 한다. `p' = σ^j(e)` 일 때
`σ^{j+1}(e) ∈ {e, …, σ^j(e)}` 가 되는 것은 `j+1 ≡ 0 (mod 6)`, 즉 `j = 5` 뿐이다. ∎

**(c) 따라서 `ℓ < 5` 는 최대 2회.** (b)에 의해 새 육각형에 들어간 pass 는 그 육각형을 가득
채우고 나오며, 가득 찬 육각형은 다시 진입할 수 없다(joint target 이 미방문이어야 하므로).
그러므로 **앞으로 새로운 부분방문 육각형은 생기지 않는다.** 현재 부분방문 육각형은
`f1_normal_form` 의 제약(비현재 부분육각형 최대 1개)에 의해 현재 육각형 `hc` 와 fragment
둘뿐이다. `ℓ < 5` 로 출발할 수 있는 매크로 간선은 현재 pass 의 출발 간선(`hc` 가 부분방문일
때)과 fragment 수리 pass 의 출발 간선뿐이다. ∎

정확히는 그 개수가 `[pc(hc) > 1] + [fragment 수리 pass 가 마지막이 아님]` 이며 0·1·2 가
모두 가능하다. 여기서는 `≤ 2` 로 완화해 사용했다.

**라운드 84의 서술과 일치하므로 수정할 것은 없다.** 이번에 명확히 한 것은 **적용 범위가
"모든 매크로 간선"** 이라는 점이며, 그 덕분에 §3의 사용법이 정당해진다.

> **안전한 완화.** 보조정리가 모든 매크로 간선에 대한 것이므로, opening 간선에만 예산 2를
> 쓰는 것은 필요조건을 **약화**시키는 방향이다. 3회 이상을 요구하는 상태는 확실히 정리를
> 위반한다.

## 2. 두 관계 (§2)

| 관계 | 간선 | out-degree | SCC |
|---|---|---|---|
| **G5** (`ℓ = 5`) | **1,440** | **10** | 1 (전체 144) |
| **Gshort** (`ℓ < 5`) | 7,920 | 55 | 1 |
| 전체 Z3 | 7,920 | 55 | 1 |

검증된 관계식: `G5 ⊆ 전체 Z3`, **`Gshort = 전체 Z3`**, `G5 ∪ Gshort = 전체 Z3`,
`Gshort ∖ G5` 는 6,480 간선.

주목할 점: **`Gshort` 만으로 이미 전체 Z3 관계가 나온다.** 즉 `ℓ < 5` 간선이 관계 전체를
만들어내고, 제약을 만드는 것은 오직 **G5 로의 제한**(out-degree 55 → 10, 5.5배 성김)이다.
G5 도 여전히 강연결이므로, 도달 가능성만으로는 아무것도 닫히지 않는다 — 라운드 84가
이미 측정한 대로다. 소득은 **induced(선택집합 내부) 조건 + 예외 예산**의 결합에서만 나온다.

## 3. 집합 수준 필요조건 (§3)

`A` 를 현재 열린 궤도 집합, `S` 를 유효한 slack-cover 선택 집합이라 하자. 모든 opening 은
그 시점에 열려 있는 궤도에서 출발하므로, `S` 는 어떤 순서 `r_1 … r_K` 로 열려야 하고 각
`r_i` 는 `A ∪ {r_1 … r_{i-1}}` 안에 선행자를 가져야 한다. 여기에 보조정리를 적용하면
**그 선행 간선 중 G5 에 속하지 않는 것은 최대 2개**다.

`min_exceptions(A, S)` 의 방향이 결정적이다. 이 값을 **과대평가하면 잘못 닫게 되어
UNSOUND** 이므로, G5 로 도달 가능한 것은 언제나 먼저 무료로 닫고(단조 폐포이므로 미룰
이유가 없다) 예외 대상만 전수 분기했다.

## 7. 왜 13개뿐인가

닫힌 13개는 **cover 해 자체가 1~4개뿐인 극도로 제약된 인스턴스**다. slack-cover 가 사실상
유일하게 결정되고, 그 유일한 cover 가 3회 예외를 요구한다. 나머지 상태는 cover 해가 많아
그중 하나는 거의 항상 0회 예외로 생성된다 — **6,396/6,657 (96.1 %)** 이 예외 0회로 생성
가능하다.

**궤도 수준이 완전히 소진되지는 않았다.** 모든 상태가 ≤2 예외로 생성 가능한 것은 아니므로
§10의 종료 조건은 성립하지 않는다. 그러나 남은 여유는 매우 작다: 예외 0회 실패가 261개뿐이고
그중 248개가 ≤2로 통과한다. 궤도 수준에서 더 짜낼 수 있는 최대치는 **248개**이며, 그것도
이미 건전한 정리로는 통과한 상태들이다.
