## 1. 일반 entry 대상 (§1)

`P = 120 + F` 는 라운드 110 에서 5개 문자열에서 확인된 항등식이다. 그 `P` 개의 **pass** 각각이
하나의 **entry 사건**이다.

> **정의 (entry 의무).** 비반복 walk 의 **pass** 는 극대 회전 런이다. 각 pass 는 정확히 한
> 육각형 안에 있다. 육각형 `h` 가 `e_h ≥ 1` 번 진입되면 그 진입들을
> `(h, 1), …, (h, e_h)` 로 번호 매긴다. **entry 의무** 는 이 쌍들이며 총 개수는
> `Σ_h e_h = P = 120 + F` 다. `Σ_h (e_h − 1) = F`.

네 종류를 구분한다:

| 종류 | 서술 |
|---|---|
| 최초 진입 | `(h, 1)` — 120개, 육각형마다 정확히 하나 |
| abandonment 로 인한 재진입 | `(h, i), i ≥ 2` — 합계 `F` 개 |
| fragment / 국소 짧은 수리 | 재진입 중 회전 길이가 `ℓ < 5` 인 것. Q2 의 `ℓ = 5 − c_f` 는 `F = 1` 의 경우다 |
| 같은 육각형의 반복 진입 | 위와 같음. `e_h ≥ 3` 도 산술적으로 가능하다 |

> **`F > 0` 이면 의무를 육각형과 동일시하지 않는다.** 이것이 이 라운드의 출발점이다.

## 2. pass ↔ entry 전단사 (§2)

> **보조정리 1′ (일반형).** 임의의 `F` 에 대해 미래 pass 와 미래 entry 의무 사이에 전단사가
> 있다. 완성은 각 **entry 의무**를 정확히 한 번 방문한다 — 각 **육각형**을 한 번이 아니다.

**증명.** pass 의 정의(극대 회전 런)에서 walk 은 pass 열로 유일하게 분해된다. 각 pass 는 한
육각형에 있으므로 entry 사건 하나를 정의한다. 역으로 각 entry 사건은 그 pass 다. ∎

라운드-93 의 Q2 형태("빈 육각형 120개 + fragment 수리 1개 = 121 pass")는 `F = 1` 의 특수
경우다. 다중도는 `e_h` 로 명시적으로 추적한다.

> **주의 (§12 계승).** `F = 0` 일 때만 "pass ↔ **육각형**" 전단사가 성립한다.

## 3. 단어 배정 모델의 일반화 (§3)

> **보조정리 3′.** 구체 출발 단어 `u` 와 회전 길이 `ℓ` 이 고정되면 무료 joint 의 target 은
> **문자열 하나** `T1(σ^ℓ(u))` 다. 따라서 목표 entry 의무는 **많아야 하나**다.

**증명.** `T1` 은 weight-2 indecomposable tail 이 **유일**하다는 사실에서 결정된다
(weight 별 tail 수 `1,1,3,13,71,461`). 그러므로 무료 target 문자열은 하나다. walk 은
비반복이므로 서로 다른 entry 의무의 진입 단어는 **서로 다르다**. 따라서 그 문자열을 배정받은
entry 의무는 많아야 하나다. ∎

**재진입 라벨은 문제가 되지 않는다** — 같은 육각형의 두 진입은 서로 다른 단어를 쓰므로
`(h,1)` 과 `(h,2)` 가 같은 target 문자열을 놓고 충돌할 수 없다.

**단, `ℓ` 은 일반적으로 강제되지 않는다.** 라운드 90/91 의 `ℓ` 강제는 Q2 의 `Φ` 가 빠듯한
데서 나오며 `F = 1` 에 의존한다. 일반형은 §5 의 **회전 결손 항등식**이다.

## 4. 일반 비용-0 그래프와 자유 호의 정체 (§4)

> **보조정리 4′ (T1 유일성).** 임의의 `F` 에서 비용-0 tail 은 `T1` 뿐이다.
> `cost(ω) = [ω≥3] + (ω−3)_+ = 0 ⟺ ω = 2` 이고 weight-2 indecomposable tail 은 하나다.
> **`F` 와 무관한 순수 tail 계수 사실이다.** ∎

> **보조정리 4″ (유출 차수).** 고정된 진입-단어 배정에서 `G₀` 의 모든 정점의 유출 차수는 ≤ 1.
> (보조정리 3′ 에서 즉시.) ∎

**그리고 이번 라운드가 자유 호의 정체를 밝혔다.**

> **보조정리 5′ (자유 호 = `τ`).** entry 단어 `u`, 회전 길이 `ℓ` 의 무료 후속은
> `T1(σ^ℓ(u)) = u_{2+ℓ} u_{3+ℓ} u_{4+ℓ} u_{5+ℓ} u_{1+ℓ} u_{ℓ}` (첨자 mod 6) 이고,
> **`ℓ = 5` 일 때 정확히 `τ(u) = u₁u₂u₃u₄u₀u₅`** — 즉 **같은 E-궤도의 다음 phase** 다.
> `ℓ < 5` 이면 궤도를 벗어난다.

이것이 프로젝트의 `O`, `P`, `D` 좌표가 왜 그런 모양인지를 설명한다: **가득 찬 pass 뒤의 무료
joint 는 E-궤도 안에서 phase 를 하나 전진시킨다.** 그래서 `P ≤ 5O`, 즉 `D = 5k − F ≥ 0` 이다.

## 5. 일반 자원 예산 (§5)

`Q2` 의 `B` 공식을 재사용하지 않고 처음부터 유도한다.

* 전체 joint 수 `= P − 1 = 119 + F`.
* 각 joint 의 예산 비용 `cost(ω) = [ω≥3] + (ω−3)_+` 이므로
  **`Σ_{모든 joint} cost = S + H`**.
* 라운드-110 의 정정된 항등식 **`L = 844 + F + S + H`**.

> **정리 (일반 예산).** `L ≤ 871` ⟺ **`S + H ≤ 27 − F`**.
> 진행 중인 walk 에서 남은 예산은 `27 − F_final − (이미 쓴 cost)` 다.

`k`, `O` 는 **여기에 전혀 나타나지 않는다** — Q2 의 `B = 3 + K − Ndef − H` 는 `F=1, O=25`
를 대입한 특수형이다.

> **회전 결손 항등식.** `Σ_pass (5 − ℓ_p) = 6F`.
> (872 witness 에서 확인: `17·4 + 16·3 + 17·2 = 150 = 6·25`.)
> **따름:** `F = 0` 이면 모든 pass 가 `ℓ = 5` 로 **강제**된다 — `F = 0` 열에서는 `ℓ` 강제가
> 공짜로 얻어진다. `F ≥ 1` 이면 결손 예산 `6F` 가 있어 `ℓ` 이 열린다.

## 6. entry 그래프 성분 하한 (§6)

> **정리 (일반 성분 하한).** `R` 을 남은 entry 의무 집합, `G₀|_R` 의 약연결 성분 수를
> `c(R)` 이라 하자. 남은 구간의 총 예산 비용은 **`≥ c(R) − 1`** 이다.

**증명.** 라운드 107 의 제한 성분 보조정리를 임의 비음 비용에 대해 그대로 쓴다: 쓰인 비용-0
내부 호는 선형 숲이고 그 성분이 약연결 성분을 세분하므로 무료 호는 `≤ |R| − c(R)` 개, 따라서
무료가 아닌 호가 `≥ (|R|−1) − (|R|−c(R)) = c(R) − 1` 개이고 각각 비용 `≥ 1`. ∎

**재진입이 깨뜨리지 않는 것을 확인한다.**

| 검사 | 결과 |
|---|---|
| 유출 차수 ≤ 1 | **유지** — 진입 단어가 서로 달라 같은 육각형의 두 진입이 충돌하지 않는다 |
| 성분 계수 | **유지** — 정점은 육각형이 아니라 entry 이므로 `(h,1)`, `(h,2)` 는 별개 정점이다 |
| terminal 규약 | **유지** — 경로의 마지막 entry 가 terminal 이고 계수는 그것에 의존하지 않는다 |

## 7. 주 정리와 셀 수준 부등식 (§7)

두 결과를 합치면:

> ### 정리 (일반 entry 정리)
> 임의의 비반복 n=6 walk 에 대해
> > **`L ≥ 843 + F + c(G₀)`**
>
> 일반 `n`: `L ≥ n + n! − 3 + n!/n + F + c(G₀)`.
> 따라서 **`L ≤ 871` ⟹ `F + c(G₀) ≤ 28`**, 대우로
> **모든 walk 에서 `F + c(G₀) ≥ 29` 이면 (NR6 아래) `L₆ ≥ 872`.**

**셀 수준 하한.** `ℓ<5` 인 pass 는 많아야 `6F` 개이고 그 pass 뒤의 무료 호만 궤도를 벗어나므로,
그 호들을 제거하면 모든 성분이 한 궤도 안에 들어가 성분이 `≥ O` 개다. 호를 되돌리면 성분은

> **`c(G₀) ≥ O − 6F = 24 + k − 6F`**, 그리고 `F = 0` 이면 **`c(G₀) ≥ O = 24 + k`**.

`F = 0` 에서 이것을 주 정리에 넣으면 **`L ≥ 867 + k`** — `k = 0` 에서 **Houston 하한 867 을
그대로 재현한다.** 좋은 정합성 검사다.

## 10. `k = 0` 과 `F = 0` (§10)

역사적 표에서 누락됐던 두 줄을 명시적으로 다룬다.

**`F = 0`.** 회전 결손 `6F = 0` 이므로 **모든 pass 가 `ℓ = 5`**, 즉 모든 육각형이 정확히 한 번
진입되어 통째로 지나간다. 자유 호는 **전부 `τ`** 이고 `G₀` 는 궤도 안의 phase 사슬이다.
`c ≥ O = 24 + k` 이므로 `L ≥ 867 + k`. **즉시 불가능하지 않다.**
이 저장소의 greedy n=6 이 바로 이 칸(`k=0, F=0`)에 있고 `L = 873`(`S=23, H=6`)이다.

**`k = 0`.** `O = 24`, `D = 0` 이므로 24개 궤도가 **전부 포화**(각 5 phase). `F ≤ 5k = 0`
이므로 `k=0 ⟹ F=0`. `G₀` 는 24개의 완전한 5-순환이고 `c = 24` 가 **정확히** 결정된다.

> 역사적 누락이 불가능을 뜻하지 않았다. `(0,0)` 은 **가장 중요한 칸**이다.

## 12. 소형 `n` 반증 시험 (§12) — **`O = 1+S+F` 등식은 반증됐다**

`n = 4`, 길이 ≤ 35 의 초순열을 전수 열거해 **비반복 walk 169개**에서 모든 후보 항등식을 시험했다.

| 명제 | 결과 |
|---|---|
| `P = n!/n + F` | **169 / 169** ✔ |
| `L = n + n! − 2 + n!/n + F + S + H` | **169 / 169** ✔ |
| `O ≤ 1 + S + F` | **169 / 169** ✔ |
| **`O = 1 + S + F` (등식)** | **84 / 169 — 반증됨** |
| `S + H ≥ c(G₀) − 1` | **169 / 169** ✔ |
| `L ≥ base + F + c(G₀)` | **169 / 169** ✔ |

> **왜 이 반증이 중요했는가.** 명명된 5개 walk 에서는 `O = 1 + S + F` 가 **등호로** 성립해서
> `N = S + F − O ≡ −1`, 따라서 `L = 867 + k + H` 라는 훨씬 단순한 항등식이 성립하는 것처럼
> 보였다. 표본을 169개로 넓히자 **85개가 등식을 깼다** (`O − (1+S+F) ∈ {−2,−1,0}`).
> 부등식 형태만 살아남는다. **소형 n 은 n=6 을 증명하지 않는다 — 오직 반증에만 썼다.**

## 15. 남은 문제의 재서술

> 라운드 110 이 "54칸" 이라고 말한 것을 이제 **한 줄**로 쓸 수 있다:
>
> > **모든 비반복 n=6 walk 에서 `F + c(G₀) ≥ 29` 인가?**
>
> * 872 witness 는 정확히 **29** 다 (`F=25, c=4`).
> * `F = 0` 이면 `c ≥ 24 + k` 이고 `k ≤ 4` 이므로 `F + c` 는 24…28 사이에 있을 수 있다 —
>   **부족하다.**
> * 이것은 `L₆ ≥ 872` 의 **충분조건**이지 필요조건이 아니다 (`F+c = 28` 이어도 `S+H` 가
>   `c−1` 보다 크면 `L ≥ 872` 일 수 있다).

다음 라운드의 자연스러운 표적은 **`c(G₀)` 의 하한을 `O − 6F` 보다 강하게 만드는 것**이다.
현재 하한은 짧은 pass 하나가 성분 하나를 병합할 수 있다고 최악으로 가정하는데, 짧은 pass 는
회전 결손 예산 `6F` 를 소비하므로 실제로는 그렇게 자유롭지 않다.
