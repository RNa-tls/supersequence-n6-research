## 1. 단일 short pass 정리

**정리.** `F = 1 = TARGET_F` 이고 현재 육각형의 방문 칸이 정확히 1개(= 현재 endpoint)인
도달가능 Q2 상태에서, 모든 합법적 완성에 대하여 — *(라운드 90c 표현 정정: 부분 육각형이 항상
2개인 것은 아니다. `r = 0` 이면 fragment 부분 + 현재 부분, `r = 1` 이면 fragment 는 이미
수리되어 있고 현재 육각형만 부분이다. 예산은 `1 − r`.)*:

1. pass 는 한 육각형 안의 **연속된 `ℓ+1` 칸**을 방문하고 joint 로 떠난다. (σ 는 육각형
   내부의 6-순환이고 no-repeat 가 재방문을 막는다.)
2. `F = TARGET_F` 이므로 앞으로 **abandonment 는 불가능**하다. 엔진의
   `abandonment = not visited(σ(p))` 에 의해, 떠나는 칸 `w` 는 `σ(w)` 가 이미 방문된 칸이어야
   한다.
3. 육각형은 120개, `P = 121`, 모든 육각형은 pass 를 최소 1회 받는다(모든 칸이 방문돼야
   하므로). 따라서 **정확히 한 육각형만 2회** 받는다. fragment 는 이미 1회 받았고 아직
   불완전하므로 **그 육각형이 바로 그 하나**이고, 나머지는 전부 정확히 1회다.
4. 그러므로 fragment 수리를 제외한 모든 미래 pass 는 육각형을 통째로 채워야 하고 `ℓ = 5`
   다. 현재 pass 도 방문 칸이 1개이므로 `ℓ = 5` 다 — 1·2 로부터 직접: 칸 `w₀` 만 방문된
   육각형에서 `w₁…w₅` 는 모두 미방문이고 `σ(w_i)` 가 방문된 것은 `i = 5` 뿐이다.
5. fragment `h_f` 의 방문 칸이 연속된 `c_f` 개라면, 남은 `6−c_f` 칸을 **한 pass 가 전부**
   방문해야 하므로 그 pass 의 시작 칸은 **유일하게** 방문 블록 바로 다음 칸 `v_{c_f}` 이고
   회전 길이는 **정확히 `ℓ = 5 − c_f`** 다.

**따라서 미래의 `ℓ<5` 매크로 edge 는 `1 − r` 개다** — fragment 가 남아 있으면(`r=0`) 정확히
1개, 이미 수리됐으면(`r=1`) 0개. **Codex 독립 감사에서 확인된 부분은 여기까지다.**
그 1개의 출발 port·`ℓ`·목표 후보까지 고정된다는 부분(§4 에서 4개 폐쇄에 쓴 것)은 독립
재현되지 않았으므로 **라운드 91 에서 검증한다.**

라운드 85 의 `≤2` 는 "현재 pass 와 fragment 수리"를 셌지만, 현재 pass 가 짧게 떠나려면 그
육각형이 새 fragment 가 되어 `F = 2` 가 된다. 잔여 상태에서는 그것이 불가능하다.

## 2. 19개 유일-cover 상태 동결과 재검증 (§1)

19개를 라운드-80 아카이브 + 리터럴 체크포인트에서 다시 읽어, **다른 변수 순서(비-MRV
사전식)** 의 cover 열거와 **독립 재구현한 판정식**(G5 induced-reachability + port 매칭)으로
라운드 89 의 유일성을 재검증했다: **19/19 일치**.

그 과정에서 정정할 사실 하나가 나왔다.

> **정정 (라운드 88/89 의 cover 개수).** slack-cover 의 블록은 `U` 안에서 겹칠 수 있으므로
> 같은 cover **집합**이 서로 다른 분기 경로로 여러 번 생성된다. 라운드 88/89 가 센 것은
> **집합이 아니라 도출(derivation)** 수였다. 중복을 제거하면 **19개 중 18개는 정적 cover
> 집합이 애초에 단 하나**뿐이다(나머지 1개는 2개).
> 방향은 안전한 쪽이다 — "동적 허용 도출이 1개" ⟹ "동적 허용 집합이 1개" 이므로 라운드 89
> 의 19개는 그대로 옳고, 다만 **19 는 하한**이며 히스토그램은 집합 기준의 과대계수다.

## 3. 최소 예외 witness 완전 열거와 dynamic backbone (§2, §3)

고정된 `S` 에 대해 **port 수준** 생성 구조(모델 M1)를 완전 열거했다. 사용한 사실은 전부
증명된 것뿐이다: opening 은 등록 port 에서 출발하고(라운드 87) 각 port 는 1회만 발사하며,
opening 은 Z3 joint 여야 하고(라운드 83), source 궤도는 `A ∪ S` 안에서 그 시점에 열려 있어야
한다(부모 구조가 `A`-rooted ⟺ 사이클 없음).

* 최소 예외 수는 라운드 88 의 관대한 모델과 **정확히 일치**했다 — 1 이 4개, 2 가 15개.
  모든 판정이 완전(캡 미도달, 노드 2~54,686).
* 최소 witness 개수는 상태당 **10⁶ 규모**(예: 1,123,808 / 1,882,684, 완전 열거)였고, 그
  결과 backbone(모든 witness 가 공유하는 사실)은 **12~16개**로 얇다. 대부분 "이 target 은
  short edge 가 아니다" 형태이고, 강제된 부모·port·순서는 상태당 0~1개뿐이다.

즉 **§3 방향만으로는 아무것도 닫히지 않는다.** 부검이 성과를 낸 것은 §4(short edge 배치)
였다.

## 4. short edge 배치가 결정타였다 (§4)

정리 (v) 로 short edge 의 출발 port 와 `ℓ` 이 고정되므로, 그 edge 가 열 수 있는 궤도는
**최대 4개**(4개 joint 의 target)뿐이다. 19개 상태에서 그 target 궤도 집합은 `{0, 32, 138}`

| 분기 | 판정 |

| 고정 short edge 가 `r ∈ S` 를 여는 각 경우 | 내 M2 는 전부 UNSAT 이라 보고했다 |

## 7. §10 범위 확인 — 무엇이 강제되는지

라운드 89 의 유일성은 **필요조건에 대한 유일성**이다. 그것이 진짜 완성의 유일성을 함의하려면
사슬이 필요하다: 완성은 (i) `O_final = 25` 이므로 정확히 `K = 25 − O` 개의 궤도를 열고,
(ii) 그 `K` 개는 `U` 를 정확히 덮어야 하며(라운드 79), (iii) 라운드 84/85/87/88 의 필요조건을
만족해야 한다. (iii) 를 통과하는 정적 cover 가 하나뿐이면 완성의 cover 는 그것이다.

이번 라운드의 폐쇄는 그 함의에 기대지 않는다 — 각 상태의 모든 정적 cover 를 직접 열거하기
때문이다. 다만 **58개 폐쇄는 예산 계수만** 쓰고, 철회된 4개만이 출발 port 고정을 썼다.

## 8. 남은 좌표 — 다음에 무엇이 달라지는가 (§11)

이번에 쓰지 않고 남겨둔 **건전한 과대근사**가 아직 셋 있고, 이것이 다음 표적이다.

1. **비-opening edge 의 port 소비.** `E¹`/`E²` 수리와 재진입도 port 를 태우지만 M2 는 세지
   않는다.
2. **opening 출발 port 가 빈 육각형에 있어야 한다**(정리 4 로 `ℓ=5` 가 강제되므로). 지금은
   `A ∪ S` 의 아무 port 나 허용한다.
3. **125 port 중 121 을 지나는 하나의 경로.** `O = 25`, `P = 121` 이므로 최종 25궤도의
   125 port 중 **미등록으로 남을 수 있는 것은 정확히 4개**(= `D_final`)다. 즉 미래 walk 은
   사실상 near-Hamiltonian 경로다. 이번 라운드에 유입차수 0 검사와 SCC 응축 검사를 해봤지만
   관대한 관계에서는 19개 모두 **강연결**이라 아무것도 닫히지 않았다 — 회전 run 의 window
   소비를 넣어야 의미가 생긴다.

또한 M2(완전 열거) 를 잔여 전체에 돌리는 것은 이번 라운드에 **완료하지 못했다**(상태당 수 초
