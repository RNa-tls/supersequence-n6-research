## 1. 기하 정리의 구조적 증명 (§1)

joint 네 개를 순열 문자열로 쓰면 (`x = x0x1x2x3x4x5`):

```
T1 = x2 x3 x4 x5 x1 x0      T2 = x3 x4 x5 x1 x2 x0
T3 = x3 x4 x5 x2 x0 x1      T4 = x3 x4 x5 x2 x1 x0
```

이 규칙이 아카이브의 `joint_targets` 와 **4,320 문맥에서 전부 일치**한다(불일치 0).
그리고 **육각형 = 순환 회전류**임을 문자열에서 직접 확인했다.

회전류는 **순환 후속 함수**로 결정되므로 다음을 비교하면 된다:

| | 후속 |
|---|---|
| `x` | `x0→x1→x2→x3→x4→x5→x0` |
| `T1` | `x0→x2`, `x2→x3→x4→x5`, `x5→x1`, `x1→x0` |
| `T2` | `x0→x3`, `x3→x4→x5`, `x5→x1`, `x1→x2`, `x2→x0` |
| `T3` | `x0→x1`, `x1→x3`, `x3→x4→x5`, `x5→x2`, `x2→x0` |
| `T4` | `x0→x3`, `x3→x4→x5`, `x5→x2`, `x2→x1`, `x1→x0` |

* `x` 와의 구분 — 넷 다 `x5` 의 상이 `x0` 이 아니다 (`x1` 또는 `x2`).
* `T1` 대 `T2` — `x1→x0` 대 `x1→x2`.
* `{T1,T2}` 대 `{T3,T4}` — `x5→x1` 대 `x5→x2`.
* `T3` 대 `T4` — `x2→x0` 대 `x2→x1`.

여섯 비교로 끝난다. 심볼이 서로 다르다는 것 외에는 아무것도 쓰지 않았으므로 **열거에
의존하지 않는 증명**이다. 전수 4,320 검사는 인증서로 남긴다. ∎

## 5. **`r=1` 비대칭 — 라운드 99 의 설명을 철회한다** (§6)

라운드 99 는 "fragment 가 이미 수리된 `r=1` 은 진입 단어가 고정돼 도달성이 잘 깨진다" 고
적었다. **틀렸다.** `r=1` 상태에는 fragment 의무가 **아예 없다** (`r=0` ⟺ fragment 존재,
아카이브 6,396 상태에서 예외 0).

먼저 비대칭이 실재하는지부터 확인했다. 쌍 수준에서:

| | 상태 | 쌍 | **쌍당 W-A 실패율** | cover/상태 평균 | 상태 폐쇄율 |
|---|---|---|---|---|---|
| `r=0` | 4,469 | 17,515 | **11.4 %** | 3.92 | 9.2 % |
| `r=1` | 325 | 1,661 | **83.8 %** | 5.11 | 46.5 % |

**cover 수 artifact 가 아니다** — `r=1` 은 cover 를 오히려 **더** 많이 갖는데도 더 닫힌다.
`c` 로 층화해도 사라지지 않는다(`c=1`: 0.00 대 0.70, `c=2`: 0.12 대 0.91, `c=3`: 0.27 대 0.83).

기전은 **절제 실험**이 지목한다. `r=0` 쌍 1,500 표본에서:

| 조작 | W-A 실패율 |
|---|---|
| 그대로 (fragment 가 `ℓ = 5−c_f` 로 출발) | **12.8 %** |
| fragment 의 유출 간선을 끊음 | **53.1 %** |
| fragment 도 `ℓ = 5` 로 정규화 | **49.3 %** |

즉 `r=0` 의 fragment 수리 pass 는 `ℓ ≠ 5` 라서 **다른 joint target 집합**을 갖고, 그것이
단어 그래프를 잇는 **중계기**로 작동한다. §6 이 물은 그대로 — **`r=0` 에는 fragment 가
매개하는 여분의 단어 선택지가 있고 `r=1` 은 그것을 이미 소비했다.**

**과대허용 대조 (§6, 폐쇄에는 쓰지 않는다).** 모든 단어에서 `ℓ ∈ {0..5}` 를 전부 허용하면
**564개 폐쇄가 전부 사라진다** (`r=0` 0/413, `r=1` 0/151). 따라서 W-A 의 힘은 단어 기하가
아니라 **`ℓ` 강제 정리**(라운드 90/91, 감사 완료)에서 나온다. 이 의존성은 `SCHEMA.md` 에도
적어 두었다 — `ℓ` 강제가 흔들리면 552 도 전부 무효다.

또 하나: 실패 쌍의 **불도달 의무 수는 거의 항상 10개 이상**이다(`r=0` 1,019/1,035,
`r=1` 891/891). 한 점이 막히는 것이 아니라 단어 그래프가 크게 갈라진다.

## 6. 정확 탐색: 상태 키와 대조 (§9, §10, §11)

**상태 키 충분성.** 모델 안에서 `(현재 구체 단어 u, 남은 의무 집합 R)` 은 **정확한 상태**다.
`u` 는 자기 의무를 결정하므로 `ℓ` 도 결정하고(root 는 `ℓ=5` 로 따로 둔다 — 현재 육각형은
빈 육각형이 아니므로 `p` 는 후보 단어가 아니다), 후속 집합은
`{(v, R∖{h}) : h ∈ R, v = WORD_NEXT(u, ℓ(u), h)}` 로 `(u,R)` 만의 함수다. 따라서 memo 는
**모델에 대해 정보 손실이 없다.**

여기서 주장하는 것은 **모델 UNSAT** 이다. 모델이 genuine 전이를 전부 포함하는 과대근사이므로
모델 UNSAT ⟹ genuine UNSAT 이고, 그것이 폐쇄에 필요한 전부다. 반대로 모델 SAT 은 genuine
completion 을 뜻하지 않는다 — 방문 창 이력·소비된 port·궤도 개방 시점 같은 이력 의존 제약이
모델에 없기 때문이다. **폐쇄에 이력 의존은 필요 없고, SAT 해석에는 필요하다.**

**no-memo 대조 (§11).** 같은 표본 33개를 memo 켜고/끄고 완전 탐색:

| | |
|---|---|
| `UNSAT/UNSAT` | 10 |
| `UNKNOWN/UNKNOWN` | 21 |
| `SAT/SAT` | 2 |
| **결정된 판정의 불일치** | **0** |

## 7. hard control 과 그래프-SAT 재분류 (§8, §12, §13)

캡은 150,000 노드로 낮췄다.

| | LIFT_HAMILTON_UNSAT_COMPLETE | LIFT_HAMILTON_SAT | UNKNOWN |
|---|---|---|---|
| 옛 hard control 8개 | **4** | 1 | 3 |
| 그래프-Hamilton SAT 25개 | **6** | 1 | 18 |

그래프 수준에서 Hamilton 경로가 **존재했던** 상태 6개가 단어 수준에서는 **완전 소진 UNSAT**
이다. 이것은 "증인 하나가 lift 에 실패했다" 가 아니라 **모든 경로의 소진**이므로 §12 규칙을
만족한다.

**§8 의 분리된 답:** 이 표본에서 완전 소진 UNSAT 은 **전부 1 노드**에서 끝났다 — 즉 정적
W-A 가 이미 잡은 것들이고, **LIFT-DFS 가 W-A 위에 추가로 얻은 폐쇄는 0**이다. 현재로서
lift 인지 탐색의 값은 새 폐쇄가 아니라 (i) SAT 증인 구성과 (ii) W-A 통과 상태를 완전 소진할
가능성에 있다. 후자는 아직 대부분 캡에 걸린다.
