## 0. 이 라운드가 찾아낸 것 — 기초 항등식에 **1 만큼의 오차**가 있다

> 이 프로젝트의 기초 기록(KO-RECORD §5)이 상자로 강조한 길이 항등식
>
>     L = 843 + cost = 867 + (k + N + H),      cost := F + S + H
>
> 은 **실제 초순열에서 성립하지 않는다.** 저장소가 보유한 두 개의 실제 n=6 초순열에서
> 직접 계산하면
>
> | | `L` | `P` | `F` | `S` | `H` | `O` | `D` | `k` | `N` | `867+(k+N+H)` | `868+(k+N+H)` |
> |---|---|---|---|---|---|---|---|---|---|---|---|
> | 검증된 872 witness | **872** | 145 | 25 | 3 | 0 | 29 | 0 | 5 | −1 | 871 ✗ | **872 ✓** |
> | 이 저장소의 greedy 873 | **873** | 120 | 0 | 23 | 6 | 24 | 0 | 0 | −1 | 872 ✗ | **873 ✓** |
>
> **정정된 항등식은 `L = 844 + F + S + H = 868 + (k + N + H)` 다.**
>
> 같은 뿌리에서 나온 두 번째 오차: KO-RECORD 의 정리 A `O ≤ S + F` 도 두 예에서 **거짓**이고
> (각각 29 ≤ 28, 24 ≤ 23), 정정된 형태 **`O ≤ 1 + S + F`** 는 두 예에서 **등호로** 성립한다.
> 원인은 하나다 — **첫 pass 시작은 어떤 joint 도 소비하지 않고 궤도를 하나 연다.**
>
> 반면 KO-RECORD 의 나머지 두 항등식 **`P = 120 + F`** 와 **`D = 5k − F`** 는 두 예에서
> **정확히 성립한다.**

### 즉각적인 귀결

* 조건부 목표는 `k + N + H ≥ 5` 가 아니라 **`k + N + H ≥ 4`** 다.
* 엔진의 `final_target`(`F=1`, `O=25` ⟹ `k=1`, `Ndef + H ≤ 3`)은 `k+N+H ≤ 4`,
  즉 **`L ≤ 872`** 를 뜻한다. `L ≤ 871` 이 아니다.
  → Q2 배제는 **필요한 것보다 한 칸 더 넓은** 길이 띠를 덮는다. 결과를 약화시키지 않는다.
* `L ≤ 871` 의 슬랩 분해는 KO-RECORD 의 표에서 **한 칸 이동**하며, `k = 0` 과 `F = 0` 이
  새로 들어온다 (§10).

**검증 범위(정직하게).** 위 정정은 **실제 초순열 2개 + n=3,4,5,6 greedy 4개**, 합 5개의
독립 문자열에서 항등식을 직접 계산해 확인했다. 일반 `n` 형태
`L = n + n! − 2 + n!/n + F + S + H` 도 그 5개 전부에서 성립한다. 이것은 **유한 검증**이며,
아래 §10 에 짧은 계수 증명을 붙였다.

## 2. NR6 의 정확한 정의 (§2)

> **NR6.** 어떤 최소 길이 n=6 초순열은 720개 순열을 각각 **정확히 한 번** 창으로 갖는
> 문자열로 잡을 수 있다. 동치로: 그 문자열의 순열 창 개수 `m` 이 정확히 `720` 이다.

이 정의에 대해 §2 가 요구한 항목:

| 질문 | 답 |
|---|---|
| 무엇을 제약하는가 | **문자열 `X` 자체**(그 순열 창들의 다중집합)를 제약한다. 걸음의 그래프 표현이 아니다 |
| 정규형 주장인가 | **그렇다** — "일반성을 잃지 않고 반복 없는 것을 고를 수 있다" 는 형태다 |
| 반복 창을 금지하는가 | **정확히 그것이다.** `m = 720` ⟺ 어떤 순열도 두 번 창으로 나타나지 않는다 |
| 비잉여성(irredundancy) 인가 | 아니다. 비순열 창은 얼마든지 있어도 된다 (872 witness 는 867 창 중 720 개만 순열) |
| 허용되는 변환은 | **프로젝트 어디에도 명시되어 있지 않다.** 이것이 공백의 핵심이다 |
| 길이는 보존되는가 | **명시되어 있지 않다.** 환원이 쓸 수 있으려면 "길이를 늘리지 않는다" 가 필요하다 |

**출처.** `research/SUPERPERMUTATION_N6_MASTER_STATUS.md` §2 는 NR6 를 "이 프로젝트의 원래
과제 서술에 있었고 여기서 증명도 반증도 되지 않은 **가정**" 이라고 명시한다.
`research/RR_NR6_IMPACT_ASSESSMENT.md` §5 도 "NR6 가정의 지위 — 별개 문제" 로 둔다.

**NR6 는 공짜가 아니다.** `|X| = 871` 이면 창은 866 개이고 전이는 `m − 1 ≤ 865` 개이므로
`m ≤ 866` — **최대 146 개의 반복 창이 산술적으로 허용된다.** 따라서 `m = 720` 은 실질적 제약이다.

## 4. NR6 공격 — 소형 n 전수 (§4, §13)

| n | 길이 | 해의 수 | 창 개수 분포 | 반복이 있는 해 |
|---|---|---|---|---|

| 4 | ≤ 35 (최소+2) | 251 | `24`: 169 · `25`: 59 · `26`: 21 · `27`: 2 | **82** |

`1234123142134214321423124312413241`

> **결론.** 소형 n 에서 "반복 없음" 은 **정확히 최소 길이에서만** 성립하고 **최소+1 에서 즉시

> 이것은 **n=6 의 NR6 를 증명하지 않는다.** 숨은 가정을 드러내는 falsification 실험이다.

## 5. Q1 의 정의 (§5)

저장소에서 `Q1` 은 독립 문서로 정의되어 있지 않다. 사용례에서 복원하면:

> **Q1** — `ExactState` 엔진의 비반복 walk 모델에서, **용량 함수 `Φ` 를 쓰지 않는** 질문.
> 즉 walk 규칙(무반복, 550 tail, 계수기 갱신)만으로 판정되는 성질.

> **Q2 / Area-A** — Q1 에 **`Φ ≥ 0`**(`remaining_window_capacity_prune`)과 나머지
> `f1_prune_reason` 항목을 얹은 좁은 질문. 여기서
> `Φ = 5 + 6(TARGET_P − P) − (720 − visited)`.

근거: 마스터 문서 §13 이 라운드-69b 결과를 두고 명시적으로 적는다 —
*"이것은 **Q2 수준** 결과다 — `Φ ≥ 0`, 즉 `remaining_window_capacity_prune` 을 소비하는데,
그것은 **순수 Q1 질문에서는 쓸 수 없다**."* 또 라운드 70 은 1,398 경계를 두고
*"전부 replay 확인된 **Q1 경계**이지만 그중 **6개만 Q2/Area-A 허용**"* 이라고 적는다.

| | Q1 | Q2 / Area-A |
|---|---|---|
| 대상 | 비반복 walk 일반 | walk + Area-A prune 집합 |
| `Φ ≥ 0` | **쓰지 않는다** | **쓴다** |
| `F` | 제한 없음 | `F ≤ 1`, 목표 `F = 1` |
| `TARGET_P` | 없음 | `121` (= `120 + F` 의 `F=1` 경우) |
| 관계 | 상위 | **Q1 의 부분 슬랩** (부분집합이지 몫이 아니다) |

`Φ` 자체가 `TARGET_P = 121` 을 쓰므로 **`Φ ≥ 0` 은 `F = 1` 조건부다.** 그래서 Q2 는 Q1 의
*부분집합*이며, Q1 이 "잊는" 정보가 아니라 Q1 이 **가정하지 않는 것을 추가로 가정**한다.

## 10. 길이 회계 — 871 은 어디서 들어오는가 (§10)

### 10.1 계수 증명 (모든 상수 명시)

`X` 를 비반복 walk 이라 하자. 순열 `720` 개, 전이 `719` 개.

1. `L = 6 + Σ_{i=1}^{719} ω_i`.  (문자열 정의)
2. 전이를 **회전**(`ω = 1`)과 **joint**(`ω ≥ 2`)로 나누고 joint 수를 `J` 라 하면
   `Σ ω = (719 − J) + Σ_{joint} ω`.
3. `S := #{ω ≥ 3}`, `H := Σ (ω−3)_+` 로 두면 각 joint 에서 `ω = 2 + [ω≥3] + (ω−3)_+`
   이므로 `Σ_{joint} ω = 2J + S + H`.
4. 따라서 **`L = 725 + J + S + H`**.
5. 회전은 육각형 안에 머물고 joint 는 육각형을 떠나므로, **pass**(극대 회전 런) 하나는
   정확히 한 육각형에 들어 있고 `P = J + 1` 이다.
6. 육각형은 120개이고 각각 최소 한 번 진입된다. 추가 진입은 정확히 **abandonment** 마다
   하나씩 생기므로 **`P = 120 + F`**.  (5개 문자열에서 정확히 확인)
7. 5·6 에서 `J = 119 + F`, 이를 4 에 넣으면
   > **`L = 844 + F + S + H`.**
8. `k := O − 24`, `N := S + F − O` 이면 `F + S + H = 24 + k + N + H` 이므로
   > **`L = 868 + (k + N + H)`.**

일반 `n` 형태: `L = n + n! − 2 + n!/n + F + S + H` (n=3,4,5,6 에서 확인).

### 10.2 871 이 들어오는 지점

> **`L ≤ 871` ⟺ `F + S + H ≤ 27` ⟺ `k + N + H ≤ 3`.**

871 은 **오직 이 한 부등식으로만** 들어온다. 다른 모든 것(육각형 120, 궤도 144, phase 5,
`P = 120+F`, `D = 5k−F`)은 **구조적**이며 목표 길이와 무관하다.

### 10.3 정정된 슬랩 표

`O ≤ 1 + S + F` 에서 `S ≥ 23 + k − F`, 이를 `F+S+H ≤ 27` 에 넣으면 **`k + H ≤ 4`**.
`D = 5k − F ≥ 0` 에서 **`F ≤ 5k`**. 따라서 `L ≤ 871` 인 비반복 walk 은 아래 표의 한 칸에 있다.

| `k` | `O` | `F` 범위 | `H` 상한 | `N + H` 상한 | 칸 수 |
|---|---|---|---|---|---|
| 0 | 24 | `F = 0` | ≤ 4 | ≤ 3 | 1 |
| 1 | 25 | `0 … 5` | ≤ 3 | ≤ 2 | 6 |
| 2 | 26 | `0 … 10` | ≤ 2 | ≤ 1 | 11 |
| 3 | 27 | `0 … 15` | ≤ 1 | ≤ 0 | 16 |
| 4 | 28 | `0 … 20` | = 0 | ≤ −1 | 21 |
| | | | | **합계** | **55** |

**Q2/Area-A 가 덮은 것은 `(k,F) = (1,1)` 한 칸뿐이다** (게다가 `N+H ≤ 3` 으로, 필요한
`≤ 2` 보다 넉넉하게). **54칸이 비어 있다.**

비교를 위해 KO-RECORD 의 원래 표(오차 포함)는 `k ∈ {1,2,3}`, `F ≥ 1` 만 담고 있었다 —
**`k = 0` 과 `F = 0` 이 누락되어 있었다.**

> **실제 최적해가 어디 있는지도 이제 정확히 말할 수 있다.** 검증된 872 witness 는
> `k = 5, F = 25, S = 3, H = 0, N = −1`, 즉 `k+N+H = 4` 다. `L ≤ 871` 은 `k+N+H ≤ 3` 이므로
> witness 는 정확히 **한 칸 위**에 있다. 그리고 witness 의 `k = 5` 는 위 표의 어떤 행도 아니다 —
> `L ≤ 871` 이 아니기 때문이다. 반면 **Q2 가 조사하는 `k=1, F=1` 은 실제 최적해가 있는
> 곳에서 멀다.** 이것은 모순이 아니지만, 슬랩 선택이 얼마나 좁은지를 보여 준다.

## 11. Q2 이전에 자원 부등식을 정의할 수 있는가 (§11)

**할 수 있다 — 그리고 그것이 바로 §10 의 길이 항등식이다.**

| Q2 안의 도구 | 바깥에서의 지위 |
|---|---|
| 예산 `Σ cost ≤ B` | **일반적이다.** `cost(ω) = [ω≥3] + (ω−3)_+` 이고 전체 합이 `F+S+H` 다. `B` 는 `L ≤ 871` 에서 나오는 `27 − (이미 쓴 cost)` 이며 `F=1` 을 쓰지 않는다 |
| 비용-0 구조 (유일한 무료 tail `T1`) | **일반적이다.** weight-2 indecomposable tail 이 하나뿐이라는 것은 순수 군/문자열 사실이다 |
| 제한 성분 하한 | **일반적이다.** 임의 비음 비용에서 성립하도록 라운드 107 에서 이미 서술을 고쳤다 |
| `Ndef + H ≤ 3` 이라는 **목표 상수** | **`F=1, k=1` 조건부다.** 일반형은 `F+S+H ≤ 27` 이다 |
| 의무 그래프의 정점 집합 | **`F` 에 의존한다** — 정점은 육각형이 아니라 **육각형 진입**이고 그 수는 `120 + F` 다 |

> **따라서 Q2 의 가중/성분 논증은 슬랩 밖에서도 그대로 쓸 수 있다.** 필요한 수정은
> "정점 = 의무(육각형)" 를 "정점 = 육각형 진입(`120+F` 개, 그중 `F` 개 육각형은 두 번 진입)"
> 으로 바꾸는 것뿐이다. **이것이 공백 2·3 을 공략하는 가장 값싼 경로로 보인다.**
> (이번 라운드에서는 탐색을 돌리지 않았다.)

## 12. pass ↔ 의무 전단사의 유효 범위 (§12)

> **정확한 사실:** 일반적으로 성립하는 것은 **`P = 120 + F`**, 즉 "pass ↔ **육각형 진입**"
> 전단사다. "pass ↔ **육각형**" 전단사는 **`F = 0` 일 때만** 성립한다.
> Q2 가 쓰는 형태("120개 빈 육각형 + fragment 수리 1개 = 121 pass")는 **`F = 1` 의 경우**다.

* `F = 0` ⟹ `P = 120`, 모든 육각형이 정확히 한 번씩 진입 — **완전한 전단사**.
* `F = 1` ⟹ `P = 121`, 한 육각형만 두 번 진입 (= fragment) — **Q2 가 쓰는 형태**.
* `F ≥ 2` ⟹ `P = 120 + F`, `F` 개 육각형이 두 번 이상 진입 — **Q2 의 서술은 그대로 쓸 수 없다.**

**바깥 환원에서 이 전단사가 처음 유효해지는 지점은 화살표 (E) 직후**, 즉 `F = 1` 이 확립된
뒤다. 그 전에는 **유추로 확장하지 않는다.** (`f1_normal_form` 이 "`F ≤ 1` 이면 조각은 많아야
하나" 를 강제하는 것도 같은 이유로 `F ≤ 1` 조건부다.)

## 14. `L₆ ≥ 872` 로 가는 가장 짧은 경로 (§16-5)

정정된 회계 위에서 가장 짧아 보이는 경로는 다음이다.

1. **공백 1 (NR6)** 을 형태 B 로 확립하거나, walk 모델을 반복 창까지 포함하도록 확장한다.
   (후자가 더 현실적일 수 있다 — §10.1 의 계수는 `m > 720` 에서도 다시 쓸 수 있다.)

4. 남는 칸에 대해 아카이브를 다시 만들거나 (H1 을 슬랩마다 확장), 칸 자체를 산술로 배제한다.
