# 라운드 113 — **hub defect**: `(0,0)` 칸의 주요 부분경우에서 `H ≥ 5` 를 증명한다

**작성:** Claude 단독. **정리 라운드 + 경량 census. 두 원장 변경 없음.**
**라운드:** 113 (hub-defect / heavy-joint)
**원장:** INDEPENDENTLY AUDITED **4,782** · CLAUDE FULL-JOINT Q2 **6,396/6,396** — 변경 없음.

---

## 0. 결과

> **정리 (증명됨).** `(k,F) = (0,0)` 이고 자유 호가 96개(동치로 `S = 23`, 동치로 24개 궤도가
> 각각 **하나의 연속 `τ`-런**으로 지나가는 경우) 인 모든 NR6 walk 은
> > **`H ≥ 5`, 따라서 `cost = S + H ≥ 28`, 따라서 `L ≥ 872`.**
>
> **이 부분경우에는 길이 ≤ 871 인 반례가 존재할 수 없다.**
>
> 하한은 **빠듯하다** — 이 저장소의 greedy 873 walk 이 정확히 이 형태이며 **사슬 6개 × 블록 4개,
> 무거운 연결자 정확히 5개**로 등호를 달성한다.
>
> 남은 것은 `(0,0)` 의 `r ∈ [25, 28]` 구간뿐이다 (`r` = 궤도 런 수). `r = 24` 는 위 정리로,
> `r ≥ 29` 는 `cost ≥ r − 1 ≥ 28` 로 자명하게 처리된다.

---

## 1. `H` 의 구현 독립적 정의 (§1)

> **정의.** walk 의 각 joint(무게 `w ≥ 2` 인 이동)에 **hub tax** `max(w − 3, 0)` 를 매기고
> > **`H := Σ_joints max(w − 3, 0)`.**
>
> 회전(무게 1)은 기여하지 않는다. 모든 항이 비음이므로 **`H` 는 감소할 수 없다.**

엔진 변수명을 근거로 쓰지 않는다 — 위 정의만으로 이후 전부가 따라 나온다.

## 2. `F = 0` 의 완전한 구조 (§2)

> **보조정리 A.** `F = 0` ⟹ 육각형별 결손 항등식 `Σ_p (5−ℓ) = 6(e_h − 1)` 에서 모든 `e_h = 1`,
> 따라서 **모든 pass 가 `ℓ = 5`**, entry 는 육각형마다 정확히 하나(총 120개), 자유 사상은 `τ`.
> 추가로 `k = 0` 이면 `D = 5k − F = 0` 이므로 열린 24개 궤도가 **전부 포화**되어
> **`G₀` = 서로소인 유향 5-순환 24개**, `c(G₀) = 24` 가 **정확히** 결정된다.

남은 자유도는 넷뿐이다: (i) 어느 24개 궤도인가(120 육각형의 **정확 덮개**), (ii) 블록 순서,
(iii) 각 블록의 진입 phase, (iv) 블록 사이의 연결자.

## 3. 경량 이동의 완전 분류

`ℓ = 5` 인 pass 의 끝에서 나가는 무게 ≤ 3 이동은 정확히 네 개다 (720 단어 전수).

| 이동 | 비용 | 궤도 | 비고 |
|---|---|---|---|
| `W2` (`= τ`) | **0** | 같은 궤도, phase **+1** | 자유 호 |
| `W3a` | 1 | 같은 궤도, phase **+2** | 궤도를 바꾸지 않는다 |
| `W3b` | 1 | 궤도 변경 | **`(0,0)` 에서 절대 사용 불가** |
| `W3c` | 1 | 궤도 변경 | **유일한 경량 연결자** |

> **보조정리 B (`W3b` 배제).** 모든 단어 `u` 에 대해 `orb(W3b(u))` 는 `orb(u)` 와 **육각형을
> 공유한다** (**720/720**). `(0,0)` 의 덮개는 24개 궤도가 쌍마다 육각형-서로소여야 하고
> `W3b` 는 궤도를 바꾸므로, `W3b` 의 target 궤도는 덮개에 들어갈 수 없다. ∎

> **보조정리 C (`W3a` 배제, 블록 경우).** 블록 끝 `v = τ⁴(u)` 에서 `W3a(v) = τ(u)` 이며
> (**720/720**) 그것은 같은 블록의 두 번째 entry 로 **이미 방문**됐다. ∎

> **보조정리 D (`W3c` 적법성).** 모든 `u` 에서 `orb(W3c(u))` 는 `orb(u)` 와 육각형-서로소다
> (**720/720**).

## 4. 블록-사슬 정리 (§3, §4, §6, §7)

`S = 23` 이면 자유 호가 96개이고, 5-순환 하나에서 쓸 수 있는 `τ`-호는 최대 4개이므로
**24개 궤도가 각각 정확히 4개**를 쓴다 — 즉 walk 은 **블록 24개**(각각 한 궤도의 전체 5 entry)를
**23개의 궤도변경 연결자**로 이은 것이다.

보조정리 B·C·D 에 의해 각 연결자는 **`W3c`(비용 1)** 또는 **무거운 joint(무게 ≥ 4, 비용 ≥ 2,
hub tax ≥ 1)** 다.

> **보조정리 E (사슬 사상의 결정성).** 블록 진입 단어 `u` 에서 다음 블록 진입은 경량이면
> **유일**하게 `D(u) := W3c(τ⁴(u))` 다.

> **보조정리 F (사슬 길이 = 4).** `D` 를 따라가며 궤도를 모으면, 쌍마다 육각형-서로소인
> 궤도를 **정확히 4개**까지만 담을 수 있다. **720개 시작 단어 전부에서 4** (분포 `{4: 720}`).

**따름.** 24개 블록은 경량 사슬로 분할되며 각 사슬은 블록 ≤ 4개 → **사슬 `t ≥ ⌈24/4⌉ = 6`**
→ **무거운 연결자 `≥ t − 1 = 5`** → 각각 hub tax ≥ 1 → **`H ≥ 5`**.

    cost = S + H = 23 + H ≥ 28        L = 844 + F + cost = 844 + 0 + 28 = 872.  ∎

## 5. 양성 대조 (§11) — **등호로 달성된다**

이 저장소의 greedy n=6 초순열(`L = 873`)은 정확히 이 형태다.

| | 값 |
|---|---|
| `k`, `F`, `S`, `H` | 0, 0, 23, **6** |
| 블록 | **24개, 전부 길이 5**, 각각 한 궤도의 `τ`-런 |
| 24개 궤도가 120 육각형을 정확히 덮는가 | **예** |
| 경량 사슬 | **6개, 길이 `[4,4,4,4,4,4]`** |
| 무거운 연결자 | **5개** (`w=4` 네 개 · `w=5` 한 개) |
| 연결자 분류 | `W3c` **18** · `heavy(w=4)` 4 · `heavy(w=5)` 1 |
| hub tax 합 | `4·1 + 1·2 = 6 = H` ✔ |

> **하한 `H ≥ 5` 가 정확히 달성된다** (사슬 6개 · 무거운 연결자 5개). `H = 6` 인 것은 그중 한
> 연결자가 무게 5 라 tax 를 2 내기 때문이다. 어떤 단계에서도 이 walk 을 거부하지 않는다.

## 6. 남은 공백 — `r ∈ [25, 28]` (§13 예고)

`r` 을 궤도 런 수라 하자 (`r ≥ 24`, `r = 24` ⟺ 모든 궤도가 한 런).
일반 하한은 `cost ≥ (r − 1) + #heavy` 다 (비자유 호 `≥ r−1`, 무거운 호는 1 을 더 낸다).

| `r` | 하한 | 상태 |
|---|---|---|
| 24 | `23 + 5 = 28` | **해결** (§4 정리) |
| 25 | `24 + ?` | **미해결** — `? ≥ 4` 가 필요 |
| 26 | `25 + ?` | **미해결** — `? ≥ 3` 필요 |
| 27 | `26 + ?` | **미해결** — `? ≥ 2` 필요 |
| 28 | `27 + ?` | **미해결** — `? ≥ 1` 필요 |
| ≥ 29 | `≥ 28` | **자명하게 해결** |

**왜 막히는가.** `r ≥ 25` 이면 어떤 궤도가 여러 런으로 쪼개지므로 런의 **탈출 entry** 가
`τ⁴(진입)` 으로 강제되지 않는다. 보조정리 E 의 **결정성이 깨지고** 분기 인자가 1 → 5 로 커진다.

**과대근사는 실패한다.** 런이 자기 궤도의 **아무 phase 로나** 탈출할 수 있다고 허용하면
사슬 길이가 **≥ 24** 까지 늘어난다(탐색 노드 상한 800만 도달). 즉 phase 상관을 지우는 순간
하한이 완전히 무너진다 — 라운드 브리프 §8 이 경고한 바로 그 실패 모드다.
**`(궤도, 진입 phase, 탈출 phase)` 수준의 더 세밀한 상태가 필요하다.**

## 8. 역사적 `H = 0` 프로그램과의 관계 (§12)

일반 바깥 모델에서 `F = 0` 일 때 **`H = 0` 은 "23개 연결자가 전부 무게 ≤ 3"** 을 뜻한다.
§4 의 정리는 그것이 **불가능**함을 보인다 (최소 5개는 무게 ≥ 4).
역사적 RR 프로그램은 `H = 0` 슬랩 **안에서** 작업했으므로, 이 정리는 그 슬랩이
`(k,F,r) = (0,0,24)` 에서 **비어 있음**을 뜻한다. 다만 가설이 정확히 일치하는 기존 정리를
찾지는 못했으므로 어떤 옛 결과도 되살리지 않는다.
