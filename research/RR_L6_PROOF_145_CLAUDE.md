## 0. 진술

`L6` = 여섯 기호 모든 순열을 창으로 포함하는 가장 짧은 단어의 길이.

> **정리.**  `L6 = 872`.

증명은 두 부분이다: **상한** `L6 <= 872` (§1) 과 **하한** `L6 >= 872` (§2–§10).

용어.  길이 `n = 6` 창 `W[i:i+6]` 이 여섯 글자 전부 다르면 **순열 창**.  모든
720 순열이 창으로 나오는 단어를 **덮개**라 한다.  `sigma(w) = w[1:]+w[0]`
(전체 회전, **육각형** = `sigma`-순환, 120 개), `tau(w) = w[1:5]+w[0]+w[5]`
(앞 다섯 회전, **궤도** = `tau`-순환, 144 개, 각 다섯 원소), `end(v) = sigma^{-1}(v)`,
`omega(a,b) = min{k : a[k:] = b[:6-k]}`.

## 2. 고정 대표원 — 라운드 142 B1 을 처음부터

`src/l6_fixed_representative_145.py`.  덮개 `W` 의 첫 발생을 시간순으로
`q_1@i_1 < ... < q_N@i_N` (`N = 720`), 실제 간격 `g_j = i_{j+1}-i_j`.  창이
겹치므로 언제나 `g_j >= omega(q_j,q_{j+1})`.  `Phi(W)` := `q_1` 을 쓰고 이어서
각 `q_j` 의 마지막 `omega(q_{j-1},q_j)` 글자를 붙인 단어.

* **보조정리 1.** `Phi(W)` 는 덮개다 — 구성상 모든 `q_j` 가 창으로 나온다.
* **보조정리 2.** `|Phi(W)| = 6 + sum omega_j <= 6 + sum g_j = |W_trim| <= |W|`.
* **보조정리 3.** `|Phi(W)| = |W|` 이면 자르기가 없고 모든 `g_j = omega_j` 이므로
  `W = W_trim = Phi(W)`.
* **보조정리 4.** `|Phi^m(W)|` 은 6 이상의 비증가 정수열이라 결국 일정해지고, 그
  지점에서 보조정리 3 이 `Phi(W^*) = W^*` 를 준다.  `|W^*| <= |W|`.
* **보조정리 5.** 고정점에서 (a) 구성에 쓴 선택열이 곧 그 단어 자신의 첫 발생열,
  (b) **모든 선택 연결자가 최단**(간격 = `omega`), (c) 모든 반복 창은 선택
  연결자의 **숨은 창**이다 (선택 시작 위치가 아닌 창은 두 선택 시작 사이에
  들어가고 첫 발생이 아니므로 반복).

**따름정리.**  모든 고정 대표원에 대한 하한은 모든 덮개에 대한 하한이다.

**검증** (`step2`): `n=4` 249 개 덮개 (247 개가 실제로 짧아짐), `n=5` 여덟 개
153-최소해가 **모두 이미 고정점**, `n=6` 872 증인이 **이미 고정점**이고
**반복 창 0 개**, 간격 분포 `1:575, 2:141, 3:3`.  자르기·비덮개·길이 증가 등
위반 0.  `n=6` 교란 10 개도 위반 0.

## 3. `(FO)` 항등식

고정 대표원은 잘려 있으므로 `L = 6 + sum_j g_j`.  간격 `N-1 = 719` 개 중
`omega = 1` 인 것은 pass 내부 회전이고 그 수는 `720 - P` (`P` = pass 수), 나머지
`P-1` 개가 **조인트**이며 `sum_{joints} w = 2(P-1) + S + H`
(`S = #{w>=3}`, `H = sum (w-3)_+`).  그러므로

    L = 6 + (720-P) + 2(P-1) + S + H = 844 + G + S + H,     G := P - 120.

**검증** (`step3`): 872 증인에서 `P = 145, G = 25, S = 3, H = 0` →
`844+25+3+0 = 872` = 실제 길이.  `n=4`·`n=5` 의 모든 시험 단어에서도 성립.

## 4. Successor splicing — 전체 조합 논증

`src/l6_splicing_145.py`.  `omega(a,b) = 1` 은 `b = sigma(a)` 와 동치이므로 pass
는 한 육각형의 **호**다: pass `i` = `(v_i, sigma v_i, ..., sigma^{l_i-1} v_i)`.

* **보조정리 A.** 각 창은 정확히 한 번 선택되고 육각형 `h` 의 창은 `h` 의 pass
  에만 속하므로, `h` 의 호들은 서로 겹치지 않고 `h` 의 여섯 원소를 덮는다.
  따라서 `sum_h m_h = P`, `sum_h (m_h - 1) = G`.
* **보조정리 B.** `nu(i)` := 진입이 `sigma^{l_i}(v_i)` 인 pass.  보조정리 A 로
  잘 정의되고, 육각형 `h` 안에서는 "다음 호" 사상, 즉 길이 `m_h` 의 한 순환이다.
  그러므로 `nu` 는 pass 들의 순열이고 `c(nu) = 120`, 순환 길이 = `m_h`.
* **보조정리 C.** pass `i` 의 마지막 창은
  `sigma^{l_i-1}(v_i) = sigma^{-1}(v_{nu(i)}) = end(v_{nu(i)})`.
  따라서 조인트 `i -> i+1` 을 쌍 `(nu(i), i+1)` 로 재배정하면 **아무것도 바뀌지
  않는다**: 같은 출발 문자열, 같은 표적, 같은 간격, 같은 철자, 같은 숨은 창.
  즉 `S, H` 와 dirty 유형이 보존되고, 모든 재배정 간선은 **full pass 끝점
  `sigma^{-1}(v)` 에서 나가는 최단 연결자**다.
* **보조정리 D.** `alpha = nu` (더미 고정), `T` = `(P+1)`-순환,
  `beta = T alpha^{-1}`.  그러면 `beta` 는 순열이고 `beta(nu(i)) = i+1`.
  `c(alpha) = 121`, `c(T) = 1` 이므로 `src/l6_incidence_144.py` 의 접합 부등식이
  `K + R_int <= G+1`, `K = G+1 (mod 2)` 를 준다 (`K = c(beta)`).
* **보조정리 E.** 순수 clean-E `beta`-순환은 한 궤도 안에 머물고 길이가 정확히
  5 이며 그 궤도의 **모든** 포트를 쓴다.  궤도가 다섯 원소뿐이므로 그 궤도는
  다른 어디에도 나타나지 않는다.
* **보조정리 F.** 조인트는 `P-1` 개, 그중 유료가 `S` 개, 자유 중 dirty w2(type
  A)가 `D2` 개다.  따라서 clean E 간선은 `P-1-S-D2` 개이고 나머지를 자르면
  **블록 = `S+1+D2`**.  순수 순환을 지우면 정점 다섯과 clean-E 간선 다섯이 함께
  사라져 블록 수가 변하지 않는다.

**조인트 목록**(720/720 확인, `step8`): `end(v)` 에서 나가는 최단 연결자는
자유 `E = tau(v)`; 유료 `120 = E^2(v)`, `201`, `210`; 혼합 `C = E(sigma v)`,
`D = sigma(E v)`; 같은 육각형 `A = sigma(v)`, `B = sigma^2(v)`; 그리고 무게
`>= 4` 인 heavy 710 개.  다른 것은 없다.  부분 pass 도 예외가 아니다: 길이 `l`
인 pass 의 조인트는 `u = sigma^l(v)` 에 같은 사상을 적용한 것이고, 전수 확인
결과 `l < 6` 인 pass 의 깨끗한 `w in {2,3}` 후속은 **하나도** 같은 궤도에 없다.

**검증** (`step4`): `n=4` 최적해, `n=5` 여덟 최소해, 그리고 **872 증인**에서
보조정리 A–F 의 모든 절이 위반 0.  872 증인의 값:

    P=145, G=25, O=29, k=5, S=3, H=0, D2=0, Qs=0,
    K=26, R_int=0, c=25, d=0, g=0, Z=0, B*=0,
    유형 분포 = {E:141, clean_w3:3}

## 5. 접합 부등식 — 독립 증명

`src/l6_incidence_144.py`.  원소는 pass `P` 개 + 더미 (`n = 121+G`).
`alpha` 의 순환은 120 육각형 + 더미, `T = beta alpha` 는 `n`-순환이라
`<alpha,beta>` 가 추이적이고 육각형 121 개와 `beta` 성분 `K` 개를 잇는 이분
그래프가 **연결**이다.  연결 이분 그래프는 변이 `121+K-1` 개 이상이고, 원소를
(육각형, 성분) 쌍으로 세면

    121 + G = E + R_int >= (121 + K - 1) + R_int      즉   K + R_int <= G + 1,

부호 계산이 `K = G+1 (mod 2)` 를 준다.  **여유는 정확히 그 이분 그래프의 독립
순환 수**이므로 **등호 ⟺ 그 그래프가 나무**다 (§10 에서 쓴다).

**검증** (`step5`): 추상 무작위 사례 3,000 개 위반 0; 872 증인에서
`K + R_int = 26 = G+1` (등호).

## 6. SAME-HEX `D2 + Qs <= R_int` — 마지막 수입 관계를 증명

`src/l6_same_hex_145.py`.

1. **같은 육각형.** type A 는 `v_q = sigma(v_p)`, type B 는 `v_q = sigma^2(v_p)`
   이므로 `h(v_q) = h(v_p)`, 그리고 `q = beta(p)` 라 같은 성분이다.
2. **지표가 진짜로 증가한다.** type A 연결자의 유일한 숨은 창은
   `sigma(p') = v_{nu(i)}`, type B 는 `sigma(p'), sigma^2(p')`.  고정 대표원에서
   숨은 창은 **반복**이므로 `v_{nu(i)}` 는 더 앞에서 나왔고, pass 진입이므로
   `nu(i) <= i`.  등호면 `l_i = 6` (전체 육각형 pass)이 되어 표적이 pass `i`
   안에 이미 있어 첫 발생일 수 없다.  따라서 `nu(i) < i < i+1`.
3. **셈.** 육각형 `h`, 성분 `j` 안의 pass 를 `m = m_{h,j}` 개라 하자.  1 에 의해
   A/B 간선은 양 끝이 이 묶음 안에 있고, 2 에 의해 지표가 증가하므로 유향
   순환이 없다.  `beta` 가 순열이므로 각 pass 의 **진입 차수는 1 이하**다.
   진입 차수 `<= 1` 이고 유향 순환이 없는 유향 그래프는 in-tree 숲이므로 변이
   `m-1` 개 이하다.  모든 `(h,j)` 에 대해 합하면
   `D2 + Qs <= sum (m_{h,j}-1) = R_int`.

**따름정리.**  `R_int <= 2g` 와 합쳐 `D2 + Qs <= 2g`, 따라서
`Z = 2g + d - D2 >= Qs >= 0`.  이것이 MASTER-142 의 모든 항을 음이 아니게 만든다.

**검증** (`step6`): dirty 조인트를 실제로 갖는 고정 대표원 `n=4` 304 개 + `n=5`
251 개 (type A 322 개, type B 153 개, C 264 개, D 261 개, heavy 548 개 단어,
등호 사례 9 개, 최대 `D2=5`, `Qs=4`, `R_int=64`) 에서 SAME-HEX·접합·`Z>=0`·
`Qs<=Z`·`D2+Qs<=2g`·`(FO)` 전부 위반 0.

## 7. 추출과 MASTER-142 — 사슬 단위로 직접 유도

`src/l6_extraction_145.py`.  `B*` 를 **분해와 무관하게**
`B* := 블록 - (O-c) = S+1+D2-O+c` 로 정의한다 (MASTER-142 가 대입하는 바로 그 양).
순수 순환 `c` 개를 지우고 남은 `K-c = d+1` 개 성분을 각각 비-E 간선 하나에서
열고 heavy 조인트 `h` 개를 자른다.  **clean E 간선은 절대 잘리지 않으므로** 모든
블록은 정확히 한 사슬 안에 있다.

* **Claim 1.** `sum_i P_i = P - 5c = 120 + G - 5c`.
* **Claim 2.** `sum_i D_i = 5 sum_i O_i - sum_i P_i = 5k - G + 5 sigma`,
  `sigma := sum_i O_i - (O-c) >= 0`.
* **Claim 3.** 사슬 안에서 clean E 간선만이 궤도와 블록을 동시에 유지하므로
  `블록_i = O_i + tok_i` (`tok_i` = 이미 열린 궤도로 들어가는 비-E 간선 수).
  합하면 **`sum_i tok_i = B* - sigma`**.
* **Claim 4.** `sigma >= 0`, 그리고 **사슬이 하나면 `sigma = 0`**.
* **Claim 5.** 사슬 안에서 육각형이 앞서 나온 포트의 수를 모두 합하면 `R_int`
  이하이고, 유지된 A/B 간선은 각각 그중 하나를 차지한다 (표적 육각형 = 바로 앞
  출발 육각형).

사슬 수는 `d+1+h` **이하**다 (순환 개방이 heavy 간선과 겹치면 더 적어진다).
용량 모형은 정확히 `d+1+h` (병합 모형은 `d+1`) 를 쓰는데, 객체가 많을수록 상한이
**느슨**해지므로 건전하다.  `(FO)` 에 `G = Z+D2+c` 와 `S = B*+O-1-D2-c` 를
대입하면

> **MASTER-142**   `L = 867 + k + Z + H + B*`,   모든 항이 음이 아니다.

**검증** (`step7`): 기호 사례 50,000 개 위반 0.  실제 추출은 `n=4` 최적해, `n=5`
여덟 최소해, **872 증인**(heavy 유지/절단 두 판), 그리고 dirty 고정 대표원
`n=4`·`n=5` 각각에 대해 heavy 유지/절단 두 판 — 다중 사슬 285 사례, `sigma>0`
270 사례, 유지 A/B 188 사례 — 전부 위반 0.

872 증인의 추출: 사슬 **한 개**, `sum P_i = 20`, `O_1 = 4`, `sum D_i = 0`,
`sum tok_i = 0`, `sigma = 0`, 블록 4 개, `B* = 0`, 육각 반복 0.
즉 증인의 사슬은 정확히 `C(0,0) = 20` 의 **극값 사슬**이다 — 모형이 진실에서
정확히 빡빡하다.

## 8. 남은 것은 `t <= 4` 의 유한 열거

MASTER-142 와 §6 의 부등식들에서, 길이 `L = 867 + t` 의 고정 대표원은 좌표

    (k, Z, H, B*, G, g, c, d, D2, Qs, h),   t = k+Z+H+B*,

를 가지며 `0 <= G <= 5k`, `K = G+1-2g`, `d = K-1-c >= 0`, `G = 2g+c+d`,
`z = G-c = 2g+d`, `Z = z-D2 >= 0`, `0 <= Qs <= Z`, `D2+Qs <= 2g`,
`H >= 1 => 1 <= h <= H`, `B* >= 0`, `k >= 0` 을 만족한다.  `L <= 871` 은
`t <= 4` 와 동치다.

각 좌표행에 대해 세 개의 **상한 모형**(조각 / 분할사슬 / 병합사슬, 라운드 144
§5–§6)으로 `sum_i P_i` 의 상한을 구하고, `s` 가 모형 의존이므로

    bound_M(C) = max over (M 에 허용되는 s) of bound_M(C, s),
    배제 <=> min over M of bound_M(C) < 120 + G - 5c

로 결합한다 (라운드 144 §7).  용량표는 전부 전수·무제한(capped 0): 조각 칸 55 개,
사슬 칸 1,501 개, 노드 합 약 `9.8 x 10^10`; 두 독립 구현이 노드 수까지 일치한다.

**결과** (`step9`, 미증명 칸 0, 대체값 0, 시그마 결손 정리 미사용):

"같은 것에 무게 4 조인트 하나, 포트 92, 궤도 20, 결손 8" 이다.  두 예산 모두
항등식이므로 **정확한 값**이다.

**등호 증인 전수 열거.**  좌 `S6` 는 포트 위에서 추이적이고 여덟 사상 전부와
가환이므로 (720 원소 확인) 시작 포트를 0 으로 고정할 수 있다.  증인은

| 방법 | Q1 | Q2 |
|---|---|---|
| C 탐색기 + 부트스트랩 UB 표 | **2** / 16,555 노드 | **1** / 5,775 노드 |
| C 탐색기, **UB 표 없이** | **2** / 900,166,560 노드 | **1** / 149,792,913 노드 |
| 파이썬 run 단위 열거기 | **2** / 1,618,863 노드 | — |
| 파이썬 강제 분할 경로 | — | **1** / 536+790 노드 |

전부 capped=false 이고 **SHA-256 이 완전히 일치**한다.  (Q2 의 강제 분할: 토큰
0 이므로 heavy 간선은 새 궤도로 가고 성분을 heavy 없는 두 사슬로 쪼갠다;
`P_i <= C(0,D_i)` 와 `C(0,0..8) = 20,20,33,33,46,46,49,58,62` 에서 92 에 닿는
분할은 `(D_1,D_2)=(4,4)`, `(P_1,P_2)=(46,46)` 뿐이고, 포트 46·결손 4 의 육각
단순 사슬은 좌 `S6` 를 법으로 **딱 하나**다.)

**순수 순환 공존 시험.**  두 행 모두 `c = G`, `K = c+1`, `R_int = 0` 이므로
`K + R_int = G+1` — §5 의 **등호**다.  그러므로 이분 그래프가 **나무**이고,

* 120 개 육각형이 **전부** 쓰인다 (아니면 반복 초과가 `G` 를 넘는다);
* `R_int = 0` 이라 사슬은 육각 단순, 육각형 `P` 개를 쓴다;
* 남은 `|F| = 120 - P = 4c` 개 육각형을 `c` 개 순수 순환(전체 `tau`-궤도, 각
  육각형 다섯 개, 궤도는 사슬과 겹치지 않음 — 보조정리 E)이 **덮어야** 한다.

세 증인 모두 **불가능**하다.  서로 다른 두 solver 로 확인:

| 증인 | 포트 | `\|F\|` | `c` | exact-cover DFS | 부분집합 열거 | 판정 |
|---|---:|---:|---:|---:|---:|---|
| Q1 #0 | 96 | 24 | 6 | 36 노드 | 1 노드 | 불가능 |
| Q1 #1 | 96 | 24 | 6 | 76 노드 | 1,028 노드 | 불가능 |
| Q2 #0 | 92 | 28 | 7 | 47 노드 | 519,948 노드 | 불가능 |

Q1 #0 은 손으로도 즉시 불가능하다: `|hex(orbit) cap F|` 의 상위 여섯 값이
`5,5,3,3,3,3 = 22 < 24`.

## 10. 결론

§2 로 임의의 덮개는 길이가 늘지 않는 고정 대표원을 갖는다.  §3–§7 로 그
고정 대표원은 `L = 867 + k + Z + H + B*` 를 만족하고 모든 항이 음이 아니다.
`L <= 871` 이면 `t = k+Z+H+B* <= 4` 이고, §8 로 그런 좌표행은 두 개만 남으며
§9 로 그 둘도 배제된다.  그러므로 길이 `<= 871` 인 덮개는 **없다**:

    L6 >= 872.

§1 의 증인이 `L6 <= 872` 를 주므로

> # `L6 = 872`

`NR6` 는 이 증명의 어느 단계에도 쓰이지 않았다.  시그마 결손 정리(라운드 144
§2)도 쓰이지 않았다 — 독립적으로 증명했지만 필요하지 않았다.

**이 프로젝트는 `L6 >= 872` 를 증명했다.  그리고 길이 872 의 덮개가 존재하므로
`L6 = 872` 이다.**
