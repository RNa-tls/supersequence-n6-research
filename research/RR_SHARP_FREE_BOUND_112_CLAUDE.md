## 0. 결론 한 문단

> 결손 예산을 이용해 하한을 세 배 예리하게 만들었다 — 짧은 pass 수는 `6F` 가 아니라
> **`F + m ≤ 2F`** 이고, 이는 872 witness 에서 **빠듯**하다. 그 결과
> **`c(G₀) ≥ (24+k) − 2F`**, 따라서 **`F + c ≥ 24 + k − F`** 이며 최대값은 `(k,F)=(4,0)` 에서
> **28** — 목표 **29** 에 **정확히 1 모자란다.**
>
> **그리고 §9 가 제안한 tradeoff `F + Q(G₀) ≥ 29` 는 반증됐다.** 이 저장소가 이미 가지고 있는
> **greedy 873 walk 이 `F = 0, c(G₀) = 24`, 즉 `F + c = 24 < 29`** 다. 경로덮개 정련도
> 같은 walk 에서 `p = c = 24` 라 구제하지 못한다.
>
> **왜 실패하는지도 정확히 밝혀졌다.** 두 개의 실제 walk 모두에서
> **비자유 호의 *개수* 하한 `S ≥ c − 1` 이 등호로 빠듯**하다
> (872 witness `S=3=c−1`, greedy 873 `S=23=c−1`).
> 남는 차이는 **전부 `H`** — weight ≥ 4 인 무거운 joint 다.
> **자유-호 구조는 비자유 호의 개수를 완벽하게 결정하지만 그 무게는 전혀 보지 못한다.**
> 867 에서 872 로 가려면 `F=0` 열에서 **`H ≥ 5 − k` 를 강제**해야 하며, 그것은 `G₀` 에 대한
> 명제가 아니라 **hub defect 에 대한 명제**다.

## 1. 짧은 pass 의 유한 기하 분류 (§1, §10)

entry 단어 `u`, 회전 길이 `ℓ` 의 자유 target 은 `T1(σ^ℓ(u))` 다. 720개 단어 전부에 대해
`ℓ = 0..5` 를 계산했다.

| `ℓ` | 결손 `d = 5−ℓ` | 같은 E-궤도로 가는 단어 수 | 같은 육각형 | 마지막 글자 보존 | phase 변화 |
|---|---|---|---|---|---|
| 5 | 0 | **720 / 720** | 0 | **720 / 720** | **+1 (전부)** |
| 4 | 1 | **0 / 720** | 0 | 0 | — |
| 3 | 2 | **0 / 720** | 0 | 0 | — |
| 2 | 3 | **0 / 720** | 0 | 0 | — |
| 1 | 4 | **0 / 720** | 0 | 0 | — |
| 0 | 5 | **0 / 720** | 0 | 0 | — |

> **분류 정리.** 자유 호는 `ℓ = 5` 일 때 **정확히 `τ`** (같은 E-궤도, phase +1, 마지막 글자
> 보존)이고, **`ℓ < 5` 이면 결손 `d` 가 무엇이든 반드시 E-궤도를 벗어난다.**
> 즉 **짧은 pass ⟺ 궤도를 바꾸는 자유 호**다. 예외 0/720·5.

## 2. 성분 병합 효율 `m(d)` (§2)

> **보조정리.** 결손 `d` 의 짧은 pass 하나가 줄일 수 있는 약연결 성분 수는 **최대 1** 이다.
> 즉 `m(d) = 1` (모든 `d`).

**증명.** 짧은 pass 는 그 entry 정점의 **유출 호 하나**만 `τ(u)` 에서 `T1(σ^ℓ(u))` 로 바꾼다.
호 하나를 더해 줄어드는 약연결 성분 수는 최대 1 이다. ∎

`m(d)` 가 `d` 에 의존하지 않으므로 `Σd = 6F` 를 그대로 쓰는 것은 낭비다 — **필요한 것은 결손의
총량이 아니라 짧은 pass 의 개수**다. 그것이 §3 이다.

## 3. 짧은 pass 는 몇 개인가 — `6F` 가 아니라 `F + m` (§12)

> **정리 (육각형별 결손 항등식).** 육각형 `h` 가 `e_h` 번 진입되면 그 pass 들에 대해
> `Σ (ℓ_p + 1) = 6` 이므로 **`Σ_p (5 − ℓ_p) = 6(e_h − 1)`**.

두 실제 walk 에서 육각형 **전부**에 대해 확인했다.

**따름 1.** `e_h = 1` 이면 `ℓ = 5` (가득 찬 pass). `e_h ≥ 2` 이면 `Σℓ = 6 − e_h ≤ 4` 이므로
그 육각형의 **`e_h` 개 pass 가 전부 짧다.**

**따름 2.** `m := #{h : e_h ≥ 2}` 라 하면
> **`#짧은 pass = Σ_{e_h≥2} e_h = (120+F) − (120 − m) = F + m`**, 그리고 `F = Σ(e_h−1) ≥ m`
> 이므로 **`#짧은 pass ≤ 2F`**.

라운드 111 의 `6F` 보다 **3배 강하다.** 872 witness 에서 `#short = 50 = 2·25` 로 **빠듯**하다
(`e_h` 분포: `1`:95, `2`:25 → `m = 25 = F`).

**따라서** `c(G₀) ≥ c_τ − #short ≥ (24 + k) − 2F`, 즉

> **`F + c(G₀) ≥ 24 + k − F`.**

`k ≤ 4`, `F ≤ 5k` 아래 최대값은 **`(k,F) = (4,0)` 에서 28** — 목표 29 에 **1 모자란다.**

## 4. 경로덮개 하한 (§5, §6)

> **정리 (경로덮개).** `p(G₀)` 를 `G₀` 의 호만 써서 모든 entry 를 덮는 **정점-서로소 유향 경로**
> 최소 개수라 하면, 임의의 Hamilton 경로는 비자유 호를 **`≥ p(G₀) − 1`** 개 쓴다.

**증명.** Hamilton 경로가 쓴 자유 호들은 그 경로의 부분집합이므로 유입·유출 차수 ≤ 1 이고
무순환이다 — 즉 정점-서로소 경로계이며 모든 정점을 덮는다. 그 경로 수는 `V − |자유사용|` 이고
`≥ p` 이므로 `|자유사용| ≤ V − p`. 따라서 비자유 호 `= (V−1) − |자유사용| ≥ p − 1`. ∎

> **정리 (유출 차수 ≤ 1 인 유향 그래프의 정확한 `p`).**
> `I₀` = 유입 차수 0 인 정점 수, `Z_bare` = **맨 순환**(붙은 in-tree 가 없는 순환) 성분 수라 하면
> > **`p(G₀) = I₀ + Z_bare`.**

**증명 스케치.** 유출 차수가 이미 ≤ 1 이므로 제약은 유입 차수 ≤ 1 과 무순환뿐이다. 유입 차수가
≥ 1 인 정점마다 유입 호를 하나씩 고르면 `T = V − I₀` 개를 쓸 수 있다. 순환이 생기는 것은 그
순환의 모든 정점이 유입 차수 1 인 경우(=맨 순환)뿐이며, 그때만 호 하나를 버려야 한다.
따라서 최대 호 수 `= T − Z_bare`, `p = V − (T − Z_bare) = I₀ + Z_bare`. ∎

`p ≥ c` 는 항상 성립하고, **`p > c` 는 `G₀` 에 분기(두 entry 가 같은 자유 target 을 공유)가
있을 때만** 일어난다.

> **그러나 `F = 0` 에서는 이득이 없다.** `F = 0` 이면 모든 호가 `τ` 호이고 `τ` 는 **단사**이므로
> 유입 차수 ≤ 1, 따라서 `I₀ + Z_bare = c`, 즉 **`p = c`**. 분기는 짧은 pass 가 있어야만 생긴다.

실측: 두 walk 모두 `arcs = V`, `I₀ = 0`, 성분이 전부 맨 순환이라 **`p = c`** 다
(872 witness `p=c=4`, greedy 873 `p=c=24`).

## 5. `F = 0` 보정 사례 (§3, §7)

`F = 0` ⟹ 모든 pass 가 `ℓ=5` ⟹ `G₀` 는 entry 위의 `τ` 이고 `c ≥ O = 24 + k`.
`k = 0` 이면 24개 궤도가 전부 포화되어 `G₀` 는 **24개의 서로소 유향 5-순환**, `c = 24` 가 정확히 결정된다.

> `S + H ≥ c − 1 ≥ 23 + k` ⟹ **`L ≥ 867 + k`** ⟹ `k = 0` 에서 **`L ≥ 867`**.

**이것은 정확히 Houston 하한이다.** 즉 이 라운드의 도구는 `F=0` 열에서 **문헌의 하한을 정확히
재현할 뿐 넘어서지 못한다.** 모자란 것은 **`5 − k` 단위**다.

**`(0,0)` 칸을 산술로 죽일 수 있는가?** `F=0, k=0` 은 "24개 E-궤도가 120개 육각형을 **정확히 한
번씩** 덮는다" 를 요구한다(각 궤도의 5단어는 서로 다른 5개 육각형에 있음을 확인: 위반 0/144;
각 육각형은 정확히 6개 궤도에 닿는다). Algorithm X 로 **정확 덮개가 존재함**을 확인했다
(탐색 노드 25). **따라서 `(0,0)` 은 이 조건으로 제거되지 않는다.**

## 7. §9 tradeoff 는 **반증됐다**

> **주장.** 모든 NR6 walk 에서 `F + c(G₀) ≥ 29`.
>
> ### **거짓.** 반례: 이 저장소의 **greedy n=6 초순열** (`L = 873`).
> `F = 0`, `c(G₀) = 24` → **`F + c = 24 < 29`.**
> 경로덮개로 바꿔도 `p = 24` 라 마찬가지다.

`F + c ≥ 29` 는 `L ≥ 872` 의 **충분조건이지 필요조건이 아니다** — 길이 873 인 합법 walk 이
24 에 앉아 있으므로 이 부등식은 **보편적으로 참이 아니고, 따라서 증명할 수 없다.**

> 더 강한 불변량 `Q` 로 `Q(greedy 873) ≥ 29` 를 만들 수 있다면 경로 자체는 죽지 않는다.
> 그러나 이번 라운드가 만든 두 후보(`c`, `p`)는 **둘 다 그 walk 에서 24** 다.

## 8. 빠진 다섯 단위의 정체 (§7, §11)

두 실제 walk 에서 **비자유 호의 개수 하한이 등호로 빠듯**하다.

| walk | 비자유 호 개수 `S` | 하한 `c − 1` | 빠듯? | 총비용 `S+H` | 차이 | 차이의 출처 |
|---|---|---|---|---|---|---|
| 872 witness | 3 | 3 | **예** | 3 | 0 | — |
| greedy 873 | 23 | 23 | **예** | 29 | **6** | **전부 `H`** (weight-4 4개, weight-5 1개) |

> **진단.** `G₀` 는 비자유 호의 **개수**를 완벽하게 결정한다 — 두 사례 모두 등호다.
> `G₀` 가 보지 못하는 것은 그 호들의 **무게**다. greedy 873 은 23개의 비자유 호를 쓰지만
> 그중 다섯 개가 weight ≥ 4 라서 `H = 6` 을 추가로 지불한다.

따라서 남은 명제는 **`G₀` 에 관한 것이 아니다**:

> ### 남은 열린 명제 (`F = 0` 열)
> 모든 NR6 walk 에 대해  **`H + (c − (24+k)) ≥ 5 − k`**.
>
> 즉 "추가 자유-성분" 과 "무거운 joint" 의 합이 `5 − k` 이상이어야 한다.
> `k = 0` 이면 **`H ≥ 5`** — 이것은 hub defect 에 대한 명제이며, 이 프로젝트의 RR 프로그램이
> 줄곧 `H = 0` 슬랩 안에서 작업해 온 바로 그 좌표다.

이것이 `867 → 872` 의 실제 내용이며, **문헌의 열린 문제 그 자체**다. 이번 라운드의 도구로는
닿지 않는다.
