# H.samehex 독립 감사 — 같은 육각형 셈 정리

**대상 노드**  `H.samehex`
**감사 라운드**  159  **기반 커밋**  `aa5ce85` (branch `round153-equality-coexistence`)
**산출물**  `r159/src/*.py`, `r159/certs/*.json`, 그리고 이 문서
**이 문서의 지위**  수리된 DAG(`r159/certs/dag_159.json`)의 `H.samehex.where`
가 가리키는 정본 감사 문서.  §2–§7 과 §14 가 정리와 증명이다.

이 감사는 `H.samehex` **하나만** 다룬다.  `H.extract`, `H.envelope`,
`H.incidence`, `H.tight`, `H.feas`, `H.models`, `H.catalogue`, `H.wlog` 는
재감사하지 않고 **이미 인증된 의존**으로만 인용한다.

---

## 요약

* **하계 `D2 + Qs <= R_int` 는 증명된다.**  세 단계 — (1) 같은 육각형·같은
  성분, (2) pass 지표 **엄격 증가**, (3) `beta` 가 단사 — 에서
  **간선 ↦ 표적**이라는 명시적 단사를 얻고, 각 (육각형, 성분) 묶음의
  **최소 지표 꼭짓점이 결코 표적이 될 수 없다**는 한 줄로 `m - 1` 이 나온다.
* **상계 `R_int <= 2g` 는 이 노드의 정리가 아니다.**  라운드 157 에서
  인증된 `H.incidence` (`2g = mu(B) + R_int`, `mu(B) >= 0`) 의 것이고, 여기서는
  **수입**된다.  두 절반이 쓰는 `R_int` 와 `g` 가 **글자 그대로 같은 양**임을
  기계적으로 확인했다 (히스토그램판 = 접합 그래프 다중간선 초과판).
* **추출 정리의 따름정리가 아니다.**  수정된 추출 정리는 **절단 후** 반복수
  `rep` 를 묶지만 `D2 + Qs = a + bb + (x+y)` 이므로 `D2 + Qs <= rep + d` 밖에
  주지 않는다.  실제로 **`D2 + Qs > rep` 인 실제 덮개가 650 개 중 47 개**
  존재한다.  따라서 `H.samehex` 는 **독립적으로 필요하다**.
* **검증**: 국소 기하 전수 (n=4,5,6, `n=6` 에서 518,400 쌍, A/B/E 검사
  2,160 회 실패 0), 셈 보조정리 완전 유한 우주 전수 (`m <= 7`, 42,275 사례,
  위반 0), 실제 덮개 650 개 + 표적 탐색 **254,519 개** 위반 0.  가설 (h1)(h2)(h3) 을
  하나씩 빼면 각각 반례가 나온다.
* **결함은 메타데이터 하나.**  `what` 이 두 노드의 정리를 한 사슬로 묶어
  적어, `where` 가 증명하지 않는 절반까지 이 노드의 것으로 보이게 했다.
  비파괴적으로 수리했다.

## Phase 0 — 대상 노드

```json
"H.samehex": {"status": "AUDITED_HAND_PROOF",
              "what":  "SAME-HEX: D2 + Qs <= R_int <= 2g",
              "deps":  [],
              "where": "src/l6_same_hex_145.py"}
```

* **직접 하류**: `C.census` 하나.
* **전이 하류**: `C.census`, `E.enumeration`, `X.structure`, `X.exclusion`,
  `X.nolemmaE`, `X.controls`, `X.adversarial`, `T.ge872`, `T.eq872`.
* **최종 정리에서의 역할**: 행 열거가 좌표를 자르는 데 쓴다.
  `r152/src/rows152.py` 54 행은 `D2 > 2*g` 인 행을 버리고, 59 행은
  `Qs` 를 `0..min(Z, 2g - D2)` 로 돌린다.  둘 다 **따름정리 `D2 + Qs <= 2g`**
  에서 나온다.  또 `Z = 2g + d - D2 >= Qs >= 0` 이 MASTER-142 의 모든 항을
  음이 아니게 만든다.  **부등식이 거짓이면 열거가 행을 빠뜨려 인구조사가
  불완전해진다 — 불건전.**
* **저장소가 실제로 진술하는 것** (`src/l6_same_hex_145.py` 7–47 행):
  > STATEMENT … `D2 + Qs <= R_int`.
  > COROLLARY.  With the incidence bound `R_int <= 2g` this gives
  > `D2 + Qs <= 2g`, hence `Z = 2g + d - D2 >= Qs >= 0`.

  즉 **이 노드가 증명하는 것은 하계뿐**이고, 상계는 `H.incidence` 에서
  가져온다.  프롬프트의 도식 `D2 + Qs <= R_int <= 2g` 는 두 노드의 결과를
  이어 붙인 것이다.

| | 진술 | 가설 | 구조적 의미 | 등호 | 하류 소비 |

## Phase 3 — 하계의 증명 (과금/단사)

**과금 규칙.**  각 type A 또는 type B 조인트를 그 `beta` 간선 `p -> q = beta(p)`
로 보고, **그 간선의 표적 `q`** 에 청구한다.

1. **어떤 반복을 강제하는가.**  (1) 로 `hex(v_q) = hex(v_p)` 이고 `q` 는 `p` 와
   같은 `beta` 성분에 있다.  따라서 성분 `j = comp(p)`, 육각형 `h = hex(v_p)`
   묶음 안에 pass 가 **적어도 둘** (`p` 와 `q`) 있고, 이 묶음은 `R_int` 에
   `m_{h,j} - 1 >= 1` 을 기여한다.
2. **어느 단위에 배정되는가.**  간선 `p -> q` 는 묶음 `(h, j)` 의 `m_{h,j} - 1`
   개 단위 중 **꼭짓점 `q` 에 대응하는 단위**를 가져간다.  아래 3 에서 그런
   단위가 실제로 `m_{h,j} - 1` 개뿐이고 배정이 단사임을 본다.
3. **단사성.**  `beta` 는 순열이므로 각 pass 는 **들어오는 `beta` 간선이 정확히
   하나**다.  A/B 간선은 `beta` 간선이므로, 서로 다른 A/B 간선은 **서로 다른
   표적**을 갖는다.  따라서 간선 ↦ 표적은 **단사**이고 다중도는 **정확히 1**
   이다.  나아가 (2) 로 모든 A/B 간선은 지표를 **엄격히 증가**시키므로
   묶음의 **최소 지표 꼭짓점은 결코 표적이 아니다**.  그러므로
   ```
   |{묶음 (h,j) 의 A/B 간선}| = |{그 표적들}| <= m_{h,j} - 1.
   ```
4. **D2 사건과 Qs 사건이 같은 단위를 청구할 수 있는가.**  **없다.**  그러려면
   한 type A 간선과 한 type B 간선이 **같은 표적**을 가져야 하는데, 그것은
   그 표적에 들어오는 `beta` 간선이 둘이라는 뜻이라 `beta` 가 순열이라는
   사실에 모순이다.  따라서 A-청구와 B-청구는 **서로소**이고, 정리가
   허용하는 다중도는 1 이며 그 이상은 발생할 수 없다.

묶음에 대해 합하면 (모든 A/B 간선은 정확히 한 묶음에 속한다 — 출발점의
육각형과 성분이 묶음을 결정한다)

```
D2 + Qs = sum_{(h,j)} |S_{h,j}| <= sum_{(h,j)} (m_{h,j} - 1) = R_int.   ∎
```

실제 덮개 650 개에서 이 네 단계를 항목별로 확인했다 (검사 F1/S1/S2):
묶음 이탈 0, 표적 공유 0, 지표 비증가 0, 뿌리 없는 묶음 0,
`|S| > m-1` 0, `총 간선 수 != D2+Qs` 0, `D2+Qs > R_int` 0.

## Phase 4 — 국소 기하 (전수, 생산 라벨에 의존하지 않음)

`r159/src/geometry159.py` 는 `n = 4, 5, 6` 에서 **모든** 순열 쌍 `(v, tgt)` 를
열거해 (각각 `n!^2` 개; `n=6` 에서 **518,400 쌍**) 연결자
`end(v) = sigma^{-1}(v) -> tgt` 의 간격 `w = omega(end(v), tgt)`, 표적의 대수적
정체, `hex(tgt) = hex(v)?`, `orb(tgt) = orb(v)?`, 그리고 **문자열에서 직접 센
숨은 창**을 표로 만든다.

읽어 낸 사실 (`n = 6`, 각 소스마다 정확히 하나씩):

| 유형 | 간격 | 표적 | 출발 육각형과 같은가 | 숨은 창 | 소비 자원 |
|---|---:|---|---|---|---|
| **A** | 2 | `sigma(v)` | **같다** | `[v]` | 자기 육각형·자기 성분 안의 반복 1 |
| **B** | 3 | `sigma^2(v)` | **같다** | `[v, sigma(v)]` | 같음 |
| **E** | 2 | `tau(v)` | **다르다** | `[]` | 없음 (궤도 유지) |

A/B/E 검사 `n=4` 72 회 · `n=5` 360 회 · `n=6` 2,160 회 — **실패 0**.

또 표는 **A·B 말고 어떤 연결자가 출발 육각형에 착지하는지**도 보여 준다
(`n=6`): 간격 1 자기 자신 720 (조인트가 아님, 배제), **heavy (간격 `>=4`)
2,160**.  heavy 는 `D2`·`Qs` 에 세어지지 않으면서 `R_int` 를 **키울 수만**
있으므로 하계에 **안전**하다.  `C`, `D`, `120`, `clean_w3` 는 출발 육각형에
착지하지 않는다.

**종이 증명 (A/B 가 같은 육각형).**  `sigma` 는 육각형(=`sigma`-류)을 보존하므로
`hex(sigma(v)) = hex(sigma^2(v)) = hex(v)`. ∎
**종이 증명 (숨은 창).**  간격 `w` 인 연결자의 원문은 `p'` 뒤에 `w` 글자이므로
오프셋 `1..w-1` 이 숨은 창이다.  `w = 2` 면 오프셋 1 하나 `= sigma(p') = v`;
`w = 3` 이면 `sigma(p') = v` 와 `sigma^2(p')`. ∎

## Phase 5 — D2·Qs 청구의 서로소성

> **같은 구조적 반복이 D2 단위 하나와 Qs 단위 하나에 동시에 기여할 수 있는가?**
> **없다.**  §3.4 참조: 청구는 `beta` 간선의 **표적**으로 하고, `beta` 가
> 순열이라 한 표적에 들어오는 `beta` 간선은 하나뿐이다.

이 논증은 **패턴의 모양에 전혀 무관하다** — 표적만 보기 때문이다.  그래도
프롬프트가 지목한 패턴을 명시적으로 점검한다:

| 패턴 | 논증에 미치는 영향 |
|---|---|
| 인접 `A-B` (`p ->A q ->B r`) | 표적 `q`, `r` 로 서로 다름.  두 단위를 쓰고 묶음 크기는 `>= 3` 이므로 `m-1 >= 2`. |
| 인접 `B-A`, `A-A`, `B-B` | 동일. |
| 중첩 구조 | `beta` 간선은 함수 그래프라 "중첩"이 생기지 않는다 (진출 차수 1). |
| 표적 반복 | 불가능 (진입 차수 `<= 1`). |
| 육각형 공유 | 같은 육각형의 다른 성분은 **다른 묶음**이고, 같은 묶음이면 `m` 이 커져 예산도 커진다. |
| 한 성분 안 여러 사건 | 묶음별로 세므로 그대로 성립; `m_{h,j} - 1` 이 그 예산이다. |

이 모든 배치는 §11 의 **완전 유한 우주 전수**에 포함된다 (임의의 지표 증가
간선 집합, 진입 차수 `<= 1`).

## Phase 6 — 상계 `R_int <= 2g`

라운드 157 (`H_INCIDENCE_FULLY_CERTIFIED`) 이 **항등식**

```
2g := (G + 1) - K = mu(B) + R_int,     mu(B) = |E(B)| - |V(B)| + 1 >= 0
```

을 확립했다.  `mu(B) >= 0` 이 곧 `R_int <= 2g` 다.

**같은 양을 쓰는가** — 기호가 같다고 가정하지 않고 확인했다:

* `R_int`: `H.samehex` 는 **성분별 육각형 히스토그램 초과**를 쓰고
  `H.incidence` 는 **접합 그래프의 다중간선 초과** `|E(B~)| - |E(B)|` 를 쓴다.
  라운드 157 §3.4 가 둘이 같음을 증명했다 (더미 `alpha`-순환이 짝을 이루는
  쌍은 `|{*} ∩ C| = 1` 이라 0 을 기여).  `r159/src/samehex159.py` 는 **두 값을
  따로 계산해** 650 단어 전부에서 일치를 확인한다 (검사 R1).
* `g`: 양쪽 다 `(G + 1 - K)/2`, `G = P - n!/n`, `K = c(beta)`.  같은 식으로
  다시 계산해 확인했다.

따라서 상계는 즉시 성립하며, 이 노드에서 **증명되지 않고 수입된다**.

## Phase 8 — H.extract / H.envelope 와의 관계

라운드 156 의 수정된 추출 정리는 **절단 후** 양을 묶는다:
`a + bb + e = rep <= R_int`, 그리고 `a = D2 - x`, `bb = Qs - y`, `x + y <= d`.
따라서 그것이 주는 것은

```
D2 + Qs = a + bb + (x + y) <= rep + d <= R_int + d,
```

즉 `d` 만큼 **약하다**.  `d = 0` 일 때만 SAME-HEX 와 일치한다.

> **그러므로 `D2 + Qs <= R_int` 는 수정된 추출 정리의 따름정리가 **아니다**.**

이것은 공식 모양으로 내린 판단이 아니라 **반례로 확인**했다:
650 개 실제 덮개 중 **47 개에서 `D2 + Qs > rep`** 다.  가장 작은 예
(`n = 4`): `D2 = 1, Qs = 0, rep = 0, R_int = 1, d = 1, 2g = 2` — 유일한 A 간선이
순환 개방으로 잘려 사슬에서 사라졌으므로 절단 후 반복은 0 이지만, **절단 전**
`R_int = 1` 이 그 A 간선을 여전히 지불한다.  추출 정리만으로는
`D2 + Qs <= 0 + 1` 밖에 얻지 못하고 `D2 + Qs <= R_int = 1` 은 우연히 맞을 뿐,
`d` 가 크면 무너진다.

`H.envelope` (라운드 158) 과의 관계도 같은 방향이다: 봉투는 SAME-HEX 를
`Z - Qs >= d` 에 쓰지만 SAME-HEX 를 **증명하지는 않는다**.

## Phase 14 — 종이 증명

> **같은 육각형 보조정리 (Same-Hexagon Lemma).**
> `W` 를 고정 대표원, pass 를 시간순으로 `0, …, P-1`, `nu` 를 같은 육각형의
> 다음 호 사상, `beta = T alpha^{-1}` 를 스플라이싱 치환이라 하자.  `D2`,
> `Qs` 를 type A · type B 조인트 수,
> `R_int = sum_{beta 성분 j} sum_h (m_{h,j} - 1)_+` 라 하자.  그러면
>
> `D2 + Qs <= R_int`.

**증명.**  A/B 조인트를 `beta` 간선 `p -> q = beta(p)` 로 본다 (`p = nu(i)`,
`q = i+1`, `i` 는 그 조인트가 떠나는 pass).

**(1) 같은 육각형, 같은 성분.**  type A 는 `v_q = sigma(v_p)`, type B 는
`v_q = sigma^2(v_p)` 이고 `sigma` 는 육각형을 보존하므로 `hex(v_q) = hex(v_p)`.
`q = beta(p)` 이므로 둘은 같은 `beta` 성분에 있다.

**(2) 지표가 엄격히 증가한다.**  조인트의 출발 문자열은
`p' = end(v_p) = sigma^{-1}(v_p)` 다.  type A 연결자는 `p'` 뒤에 두 글자를
적으므로 숨은 창이 하나, 곧 `sigma(p') = v_p`; type B 는 세 글자를 적으므로
숨은 창이 `sigma(p') = v_p` 와 `sigma^2(p')` 다.  고정 대표원에서 선택
연결자의 숨은 창은 **반드시 반복**이므로 `v_p` 는 이 조인트보다 **앞서**
나타났고, `v_p` 는 pass 진입점이라 그 첫 출현이 pass `p` 의 시작이다.
따라서 `p <= i`.  `p = i` 라면 `nu(i) = i`, 즉 육각형 `hex(v_i)` 가 호 하나
뿐이어서 `l_i = n`; 그러면 표적(`A` 는 `sigma^2(p')`, `B` 는 `sigma^3(p')`)이
그 육각형 안, 곧 pass `i` 안에 이미 있으므로 첫 출현일 수 없다 — 모순.
그러므로 `p = nu(i) < i < i+1 = q`.

**(3) 셈.**  pass 를 쌍 `(hex, beta 성분)` 으로 묶는다.  (1) 로 모든 A/B
간선은 두 끝이 한 묶음에 있다.  크기 `m` 인 묶음의 A/B 간선 집합을 `S` 라
하자.  `beta` 가 순열이므로 각 pass 에 들어오는 `beta` 간선은 정확히 하나,
따라서 `S -> (표적)` 은 **단사**다.  (2) 로 모든 간선이 지표를 키우므로
묶음의 **최소 지표 꼭짓점은 표적이 될 수 없다**.  그러므로
`|S| = |표적 집합| <= m - 1`.  묶음에 대해 합하면

```
D2 + Qs = sum_{(h,j)} |S_{h,j}| <= sum_{(h,j)} (m_{h,j} - 1) = R_int.   ∎
```

> **따름정리.**  접합 정리 `R_int <= 2g` (라운드 157: `2g = mu(B) + R_int`,
> `mu(B) >= 0`) 와 합쳐
> `D2 + Qs <= 2g`, 따라서 `D2 <= 2g`, `Qs <= 2g - D2`,
> 그리고 `Z = 2g + d - D2 >= Qs >= 0`. ∎
