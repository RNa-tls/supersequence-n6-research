# `H.tight` 독립 감사

감사 대상은 최종 `L6 = 872` DAG 의 손 증명 노드 **`H.tight` 하나**다.
다른 노드는 명시적 의존으로 필요한 경우에만 인용한다.

---

## 0. 대상 확인

`r153/certs/dag_153.json` 에서 그대로:

```json
"H.tight": {
  "status": "AUDITED_HAND_PROOF",
  "what": "at an equality row the incidence bound is tight, so the chain is
           hexagon-simple, all 120 hexagons are used, and the c pure circuits
           (complete tau-orbits) must cover the |F| = 4c unused ones",
  "deps": [],
  "where": "research/RR_L6_PROOF_145_CLAUDE.md section 9"
}
```

* **노드 ID**: `H.tight`
* **출처**: `research/RR_L6_PROOF_145_CLAUDE.md` §9, 292–300 행 (DAG 가
  가리키는 그대로이며, 이 노드에 대해서는 **출처가 맞다**).
* **원문 진술** (292–300 행, 그대로 옮김):

  > **순수 순환 공존 시험.**  두 행 모두 `c = G`, `K = c+1`, `R_int = 0` 이므로
  > `K + R_int = G+1` — §5 의 **등호**다.  그러므로 이분 그래프가 **나무**이고,
  >
  > * 120 개 육각형이 **전부** 쓰인다 (아니면 반복 초과가 `G` 를 넘는다);
  > * `R_int = 0` 이라 사슬은 육각 단순, 육각형 `P` 개를 쓴다;
  > * 남은 `|F| = 120 - P = 4c` 개 육각형을 `c` 개 순수 순환(전체 `tau`-궤도,
  >   각 육각형 다섯 개, 궤도는 사슬과 겹치지 않음 — 보조정리 E)이 **덮어야**
  >   한다.

* **직접 하위**: `X.structure` (DAG 에서 유일).
  전이적으로 `X.structure -> X.exclusion -> {X.nolemmaE, X.controls,
  X.adversarial} -> T.ge872 -> T.eq872` (7 노드).
* **`L6 = 872` 에서의 역할**: 라운드 152 가 남긴 두 등호 행에 대해,
  "용량을 달성하는 실현" 을 **유한한 집합 덮개 문제**로 바꾸는 유일한 환원이다.
  라운드 153 의 공존 배제 전체가 이 환원 위에 서 있다.

## 2. 완전한 부등식 사슬

`n_elt := P + 1`, `A := c(alpha) = 121`, `E :=` `B` 의 변 수,
`mu(B) := E - (A + K) + 1` (연결 그래프의 첫 베티 수).

| # | 문장 | 종류 | 근거 |
|---|---|---|---|
| (1) | `sum_h m_h = P` | **정확한 항등식** | 보조정리 A (`H.splice`) |
| (2) | 모든 `h` 에 대해 `m_h >= 1`, 따라서 `sum_h (m_h - 1) = G` | **단사/셈** + 항등식 | 보조정리 A: 육각형 `h` 의 6 개 창이 전부 선택되고 `h` 의 호들로 분할된다 |
| (3) | `n_elt = sum_{(a,j)} |a ∩ j|` | **정확한 항등식** | 원소마다 `alpha`-순환 하나, `beta`-순환 하나 |
| (4) | `sum_{(a,j) nonempty} |a ∩ j| = E + R_int` | **정확한 항등식** | `R_int` 의 정의 |
| (5) | `T = beta alpha` 가 `n_elt`-순환 ⇒ `<alpha,beta>` 추이적 ⇒ `B` 연결 | **구조적 사실** | `src/l6_incidence_144.py` 20–23 행 |
| (6) | `B` 가 `A+K` 정점에서 연결 ⇒ `E >= A + K - 1`, 여유 `= mu(B) >= 0` | **셈 부등식** (스패닝 트리) | 그래프 이론 |
| (7) | `121 + G = E + R_int >= (121 + K - 1) + R_int`, 즉 `K + R_int <= G + 1` | **셈 부등식** ((3)(4)(6) 합성) | `H.incidence` |
| (8) | `K = G + 1 (mod 2)`, 따라서 `2g := (G+1) - K` 는 짝수인 비음 정수 | **정확한 항등식 + 패리티** | `src/l6_incidence_144.py` 16–18 행 |
| (9) | **`2g = mu(B) + R_int`** | **정확한 항등식** ((6)(7) 정리) | 이 감사에서 명시 |

(9) 가 이 감사의 축이다.  `mu(B) = E - (A+K) + 1` 와
`E = n_elt - R_int = 121 + G - R_int` 를 대입하면
`mu(B) = G + 1 - K - R_int = 2g - R_int`. ∎

## 3. 등호 전파 — 명시적 여유 분해

요구된 형태 그대로:

    2g  =  s1 + s2 ,        s1 := mu(B) >= 0 ,      s2 := R_int >= 0

**가설.**  `g = 0`.  (이것은 수치적 용량 등호가 아니라 **행 좌표**다.  §10 참조.)

    g = 0  =>  s1 = s2 = 0  =>  mu(B) = 0  and  R_int = 0.

`R_int` 자체가 다시 비음 항의 합이다:

    R_int = sum_{(a,j)}  s_{a,j} ,      s_{a,j} := |a ∩ j| - 1 >= 0 ,

따라서 `R_int = 0` 은 **모든** `(alpha-순환, beta-성분)` 쌍이 pass 를 많아야
하나 공유함을 준다.

**중요 — 논리 방향에 관한 지적.**  DAG 문구 *"at an equality row the incidence
bound is tight"* 는 "수치적 등호 (상한 = required) 가 접합 부등식을 tight 하게
만든다" 로 읽힐 수 있다.  **그렇지 않다.**  `2g = (G+1) - K` 는 정의상
항등식이므로, 접합 부등식의 tight 함은 행 좌표 `g = 0` 에서 **직접** 나온다.
수치적 등호는 그 행이 인구조사를 통과해 살아남는 이유일 뿐, `H.tight` 의
어떤 단계에도 쓰이지 않는다.  이 사실은 `H.tight` 를 **원문보다 강하게**
만든다 — 취약한 "등호가 모든 성분으로 전파된다" 식 논증이 아예 필요 없다.

## 4. 나무 조건

`H.incidence` 의 실제 정리 (DAG 의 `where` 는 틀렸다 — §13):

> `K + R_int <= G + 1`, `K = G + 1 (mod 2)`
> (`src/l6_incidence_144.py` 1–30 행; 등호 성격은
> `research/RR_L6_PROOF_145_CLAUDE.md` 150–167 행)

여유가 정확히 `mu(B)` 이므로:

    K + R_int = G + 1   <=>   mu(B) = 0   <=>   B 는 나무 (B 는 연결이므로).

`H.tight` 는 **한 방향만** 필요하다: `g = 0` ⇒ `mu(B) = 0` ⇒ 나무.
역방향은 쓰지 않는다.

## 5. "120 개 육각형이 전부 쓰인다" — **원문의 근거는 부적절하고, 주장은 참이다**

§9 는 괄호로 *"아니면 반복 초과가 `G` 를 넘는다"* 라고만 적었다.  이것은
**유효한 유도가 아니다**: `sum_h (m_h - 1) = G` 는 항등식이고, 그것을
"반복 초과" 로 읽으려면 이미 `m_h >= 1` 을 알아야 한다.  즉 원문은 증명하려는
것을 전제한다.

**올바른 증명 (한 줄, 보조정리 A 로부터).**  덮개의 `720` 개 창은 각각 정확히
한 번 선택되고, 육각형 `h` 의 창은 `h` 의 pass 에만 속한다.  `h` 는 창을
`6` 개 가지므로 `h` 의 호는 적어도 하나 있다.  따라서 **모든** `h` 에 대해
`m_h >= 1`. ∎

**자원 보상 가능성은 제기되지 않는다.**  `m_h >= 1` 은 덮개의 선택 구조에
대한 사실이고 `a`, `bb`, `e`, heavy, repeat, token 중 어떤 자원과도 무관하다.
어떤 자원 배분도 육각형의 6 개 창을 "선택되지 않은" 것으로 만들 수 없다.
그러므로 보상으로 이 결론을 깨는 경로는 **존재하지 않는다**.

이 사실은 등호와도 무관하다 — **모든** 덮개에서 성립한다.
(저장소의 덮개 10 개 전부에서 `min m_h >= 1` 확인:
`r155/certs/tight_real_covers_155.json`.)

## 6. 사슬의 육각 단순성

(9) + 가설 `g = 0` ⇒ `R_int = 0` ⇒ 모든 `s_{a,j} = 0` ⇒ 모든 β-성분이 각
육각형을 많아야 한 번 만난다.  `d = 0` 이면 비순수 성분은 더미 성분 하나뿐이고
사슬은 거기서 더미를 뺀 것이므로 (더미는 자기 자신이 `alpha`-순환이라 육각형
수에 영향이 없다) **사슬은 육각 단순**하고 `P - 5c` 개 육각형을 쓴다.

**"육각형을 반복하되 다른 데서 그만큼 아끼는" 구성은 불가능하다.**
(9) 가 부등식이 아니라 **항등식**이기 때문이다: `g = 0` 에서 `R_int > 0` 이면
`mu(B) = -R_int < 0` 이 되는데, `mu(B)` 는 연결 그래프의 첫 베티 수라
음수일 수 없다.  보상할 자리가 구조적으로 없다.

## 7. `|F| = 4c` 의 유도

가정하지 않고 유도한다.

* `d = 0` ⇒ `K = c + 1` ⇒ 성분은 순수 순환 `c` 개 + 비순수 하나.
* 보조정리 E: 순수 순환은 `tau`-궤도 전체이므로 pass 를 정확히 5 개 쓴다.
* 원소 수 세기: `P + 1 = 5c + (사슬 pass 수 + 1)` ⇒ **사슬 pass 수 = `P - 5c`**.
  (`H.extract` 의 Claim 1 을 인용할 필요 없이 직접 나온다.)
* §6 ⇒ 사슬 육각형 수 = `P - 5c = 120 + G - 5c` (`P = 120 + G`).
* 정의 `F := ` 사슬이 쓰지 않은 육각형 ⇒ `|F| = 120 - (120 + G - 5c) = 5c - G`.
* 정의에서 `2g + c + d = (G+1-K) + c + (K-1-c) = G` 이므로 `g = d = 0` 에서
  **`c = G`**, 따라서 **`|F| = 5c - c = 4c`**. ∎

`c` 는 **순수 β-순환(= 완전한 `tau`-궤도)의 개수**다.  성분 전체의 개수도,
궤도 전체의 개수도 아니다.

**정수성·경계.**  `c = G >= 0` 이고 `|F| = 4c >= 0`.  `c = 0` 이면 `|F| = 0`
이고 주장은 공허하게 참이다.  일반 `n` 에서는 `|F| = (n-1)c - G`, `c = G`
에서 `(n-2)c` 다 — n=6 의 `4c` 는 그 특수한 경우다
(n=5 덮개 8 개에서 `(n-2)c = 3c` 로 확인).

## 8. `c` 개 `tau`-궤도가 `F` 를 덮어야 한다

1. **왜 `tau`-궤도만이 덮개 객체인가.**  pass 는 β-성분으로 분할되고,
   `d = 0` 이므로 성분은 사슬 하나와 순수 순환 `c` 개뿐이다.  보조정리 E 로
   순수 순환은 **완전한 `tau`-궤도**다.
2. **왜 정확히 `c` 개인가.**  `d := K - 1 - c = 0` 이 곧 `K = c + 1`,
   즉 순수 순환이 정확히 `c` 개이고 비순수가 정확히 하나라는 뜻이다.
   (비순수 성분은 더미를 포함하므로 정의상 순수가 아니다 — 저장소의 덮개
   10 개에서 "비순수 성분 = 더미 성분" 확인.)
3. **왜 `F` 의 모든 원소가 덮여야 하는가.**  §5 로 모든 육각형은 pass 를
   적어도 하나 갖는다.  `F` 의 육각형은 사슬 pass 를 갖지 않는다.  pass 는
   사슬과 순수 순환으로 분할되므로 그 pass 들은 전부 순수 순환의 것이다.
   따라서 `F ⊆ ∪_{i=1..c} hex(궤도_i)`. ∎
4. **궤도끼리의 겹침이 셈을 빠져나가지 못하는 이유.**  주장은 **분할이 아니라
   덮개**다.  겹침은 합집합의 크기를 **줄이므로** 덮기를 더 어렵게 만들 뿐이다.
   각 궤도는 정확히 다섯 육각형과 만나므로 (144/144 전수 확인)
   `|∪ hex(궤도_i)| <= 5c` 이고, 덮어야 할 것은 `|F| = 4c` 다.
   (서로 다른 순수 순환은 서로 다른 궤도를 쓴다: 순환이 궤도의 다섯 포트를
   전부 소비하고 pass 진입은 서로 다르므로 — 보조정리 E.)
5. **dirty/heavy 구조가 대신할 수 없는 이유.**  `d = 0` 이라 비-E 간선을 갖는
   성분은 사슬 하나뿐이고, 사슬의 육각형 집합은 `F` 의 **여집합**으로 정의된다.
   dirty A/B·heavy 간선은 전부 사슬 안에 있으므로 `F` 의 육각형을 덮을 수
   없다.  (게다가 `R_int = 0` 이라 사슬이 이미 쓴 육각형을 다시 쓸 수도 없다.)

## 9. 반증 탐색

### 9.1 추상 전수 시험 (`r155/src/abstract155.py`)

* **유한 우주**: 각 `m` 에 대해 `{0..m-1}` 의 **모든** 순열 `alpha`,
  `T` 는 표준 `m`-순환으로 고정, `beta := T alpha^{-1}`.
* **대칭 몫**: `(alpha, T)` 를 `pi` 로 켤레하면 `beta` 도 켤레되고
  `A, K, R_int, E`, `B` 의 동형류가 모두 보존된다.  모든 `m`-순환은
  켤레이므로 `T` 고정은 **정확한 몫**이다 (표본 아님).
* **가지치기**: 없음.
* **검사 항목**: (I1) `m = E + R_int`, (I2) `B` 연결, (I3) `mu >= 0`,

## 12. 가장 짧은 지필 증명

> **정리.**  고정 대표원 덮개의 스플라이싱 구조에서, `alpha` 를 다음-호 사상에
> 더미 고정점을 붙인 것, `T` 를 시간순 `(P+1)`-순환, `beta = T alpha^{-1}`,
> `K = c(beta)`, `R_int` 를 성분 내부 육각형 중복 초과, `c` 를 순수 clean-E
> 순환의 개수, `g = (G+1-K)/2`, `d = K-1-c` 라 하자.
> `g = 0` 이고 `d = 0` 이면:
> (i) 접합 이분 그래프 `B` 는 나무이고 `R_int = 0`;
> (ii) 사슬은 육각 단순하고 `P - 5c = 120 + G - 5c` 개 육각형을 쓴다;
> (iii) `120` 개 육각형은 모두 pass 를 가지며, 사슬이 쓰지 않는 것들의 집합
> `F` 는 `|F| = 4c` 를 만족한다;
> (iv) `c` 개의 완전한 `tau`-궤도가 `F` 를 덮는다.
>
> **증명.**  원소는 `P` 개 pass 와 더미, 합 `n_elt = 121 + G`.  각 원소는
> `alpha`-순환 하나와 `beta`-순환 하나에 들어가므로, 비어 있지 않은 쌍의 수를
> `E` 라 하면 `n_elt = E + R_int`.  `T = beta alpha` 가 `n_elt`-순환이라
> `<alpha, beta>` 는 추이적이고 `B` 는 연결이므로
> `E >= (121 + K) - 1` 이며 그 여유가 `B` 의 첫 베티 수 `mu(B)` 다.  둘을
> 합치면
>
>     2g = (G+1) - K = mu(B) + R_int ,      mu(B) >= 0 ,  R_int >= 0 .
>
> `g = 0` 이므로 `mu(B) = R_int = 0`: `B` 는 나무이고 (i), 모든
> `(alpha-순환, beta-성분)` 쌍이 pass 를 많아야 하나 공유한다.
> `d = 0` 이므로 성분은 순수 순환 `c` 개와 더미를 담은 성분 하나뿐이다.
> 순수 순환은 한 `tau`-궤도의 다섯 포트를 전부 쓰므로 (clean E 는 `tau` 이고
> 궤도는 원소가 다섯이다), 원소 세기 `P + 1 = 5c + (사슬 pass 수 + 1)` 가
> 사슬 pass 수 `= P - 5c` 를 준다.  `R_int = 0` 을 그 성분에 적용하면 사슬은
> 육각 단순이고 정확히 `P - 5c` 개 육각형을 쓴다 (ii).
> 육각형 `h` 의 여섯 창은 모두 선택되고 `h` 의 호로 분할되므로 `m_h >= 1`,
> 즉 모든 육각형이 pass 를 갖는다.  `F` 를 사슬이 쓰지 않는 육각형이라 하면
> `|F| = 120 - (120 + G - 5c) = 5c - G`, 그리고 `2g + c + d = G` 가
> `g = d = 0` 에서 `c = G` 를 주므로 `|F| = 4c` (iii).
> 끝으로 `F` 의 육각형은 사슬 pass 를 갖지 않으므로 그 pass 들은 전부 순수
> 순환의 것이다.  따라서 그 `c` 개의 완전한 `tau`-궤도가 `F` 를 덮는다 (iv). ∎
