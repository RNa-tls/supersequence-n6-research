## 1. 출발 port 의미론 (§1) — 증명

> **정리.** 각 port 는 최대 1개의 매크로 edge 를 발사한다.

**증명.** 모든 매크로 edge 는 walk 의 현재 endpoint 에서 출발한다. endpoint 는 언제나 직전
joint 의 target 이고, `extend()` 는 weight ≥ 2 인 joint 의 target 을 **항상 등록**하므로
endpoint 는 등록된 port 다(초기 endpoint 도 `initial_state` 가 등록한다). no-repeat 에 의해
각 window 는 정확히 한 번 방문되므로 **각 port 가 endpoint 인 시점은 최대 한 번**이고, 그때
발사되는 매크로 edge 도 최대 하나다. ∎

엔진 확인: 임의 legal walk 400 스텝에서 매크로 edge 직후 endpoint 가 등록 port 인 사례
**39/39, 위반 0**.

따라서 안전한 상한은

```
cap_s(q)   = (q 의 미방문 port 수) + [q 가 현재 endpoint 를 포함]
cap_new(r) = (r 의 미방문 port 수)
```

이며, **재사용은 불가능하다** — 재진입은 아직 미방문인 *다른* port 를 등록할 뿐이고 이미
소비된 port 를 복원하지 않는다. `E¹`/`E²` 도 마찬가지로 새 port 를 소비할 뿐이다.

방향성: 용량 **과대평가는 안전**, 과소평가는 UNSOUND. 이번 라운드의 계산은 전부 과대평가
쪽(모든 궤도의 5 port 전부 사용 가능, 미방문 여부 무시)으로 잡았다.

## 2. source-port 로 라벨링한 G5 (§3)

| 측정 | 값 |
|---|---|
| source port 당 target 궤도 수 | **정확히 2** (720/720) |
| 궤도당 서로 다른 target 수 | **10** (144/144) |
| **같은 궤도 두 port 의 target 겹침** | **0** (1,440쌍 전부) |
| target 당 공급 (궤도, port) 수 | **10** |
| target 당 공급 **궤도** 수 | **10** |

> 궤도의 10개 out-neighbour 가 5개 port 에 **2개씩 완전 분할**된다. 역으로 target 하나를 열
> 수 있는 것은 정확히 10개 궤도이고, 각 궤도에서 **특정 1개 port** 뿐이다.

즉 "어느 궤도에서 여느냐"가 정해지면 "어느 port 를 쓰느냐"도 **유일하게 결정**된다. 이는
서로 다른 target 들이 같은 port 를 놓고 경쟁할 수 있다는 뜻이며, 진짜 이분 매칭 구조다.

## 3. 적대적 검사 (§10) — 그중 하나가 결정적이었다

| 검사 | 결과 |
|---|---|
| 재진입으로 한 port 가 2개 opening 을 지원하는가 | **불가** — port 는 1회 방문 |
| `E¹`/`E²` 가 소비된 출발점을 복원하는가 | **불가** — 새 port 를 소비할 뿐 |
| 표에 없는 port 에서 opening 이 가능한가 | `ℓ=5` Z3 는 이 표가 전부 |
| **short edge 가 용량 회계를 우회하는가** | **가능하며 결정적** |

`ℓ<5` Z3 opening 은 이 매칭을 우회하고 그 예산이 **2**(라운드 85)이므로, **최대 2개 target
은 자원 없이 열릴 수 있다.** 그러므로 건전한 폐쇄 기준은 **매칭 결손 ≥ 3** 이다.

> 이 항목을 반영하지 않았다면 결손 1인 4개 상태를 **잘못 닫았을 것**이다.

## 6. 왜 소득이 0인가

자원이 남아돌아서가 아니다. 구조는 진짜로 조밀하고(`target` 당 공급 궤도 10개 중 `A ∪ S`
안에 드는 것은 평균 1.7개), 고정된 cover 에서는 Hall 결손이 실제로 발생한다.

문제는 **cover 선택의 자유도**다. `slack-cover` 는 어떤 `K`-부분집합이 가능한지를 제약할 뿐
개별 궤도의 사용 가능 여부는 거의 제약하지 않으므로, 결손이 생기는 조합을 피하는 다른
cover 가 언제나 존재한다. 이는 라운드 81 이후 모든 라운드에서 반복된 동일한 이유이며,
이번에는 자원 용량 수준에서 재확인된 것이다.
