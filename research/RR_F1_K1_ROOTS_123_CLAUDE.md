**작성:** Claude 단독. **정리 + 유한 열거 라운드. 새 폐쇄 없음, 두 원장 변경 없음.**
**라운드:** 123 (complete generic-(1,1) root)
**원장:** INDEPENDENTLY AUDITED **4,782** · CLAUDE FULL-JOINT Q2 **6,396/6,396** — 변경 없음.
**라벨:** ROUND-123 PROVISIONAL · CLAUDE 단독 · **독립 감사 없음** (Codex 쿼터 소진).

## 1. 첫-짧은-pass 분해 (§1)

`F = 1` 이면 (라운드 116) 반복되는 육각형 `h*` 가 **정확히 하나**, 짧은 pass 가
**정확히 둘**(`h*` 의 두 pass, 길이 `b` 와 `6−b`)이고 **나머지 119개 pass 는 전부 full** 이다.

`X` 를 walk 순서상 **먼저** 오는 짧은 pass, `Y` 를 나중 것이라 하고

    walk = A · X · B · Y · C ,   A = X 앞의 pass 열

라 쓴다.

> **명제 1.** `A` 의 모든 pass 는 full(길이 6)이다.
> **증명.** 짧은 pass 는 `X`, `Y` 둘뿐이고 `X` 가 둘 중 먼저다. `A` 는 `X` 앞이므로
> `X` 도 `Y` 도 포함하지 않는다. 따라서 `A` 의 pass 는 전부 길이 6 이다. ∎

역사적 Q2 가정은 하나도 쓰지 않았다.

## 2. 접두 `A` 는 `F = 0` 접두다 (§2)

`A` 의 `q` 개 full pass 는 각각 육각형 하나를 **통째로** 덮고, `h*` 의 재진입은 `Y` 에서야
일어나므로 `A` 안에서는 육각형이 반복되지 않는다 — **`A` 는 `F = 0` 접두**다.

라운드 115 의 `F=0` 사실 중 **접두에서도 유효한 것**과 **아닌 것**을 갈랐다:

| 사실 | 접두에서 유효? |
|---|---|
| full pass 길이 6, 육각형 하나를 통째로 덮는다 | **유효** (국소) |
| `ℓ = 5` 의 경량 기하: `W2 = τ`(궤도 내부) · `W3a`(궤도 내부, phase +2) · `W3b`(궤도 변경, 공유 육각형 1) · `W3c`(궤도 변경, 육각형 서로소) | **유효** (국소, 720/720) |
| `ℓ < 5` 에서 네 경량 이동이 전부 궤도를 바꾼다 | **유효** — 다만 접두에는 `ℓ<5` 가 없다 |
| 궤도의 다섯 단어가 **서로 다른 다섯 육각형**에 있다 | **유효** (기하) |
| `τ`-run 구조 (run = 같은 궤도의 연속 pass) | **유효** |
| `D`-접두 회계: 떠난 궤도의 결손 합 ≤ `D` | **유효** (단조) |
| `W3c` 블록 사상 `D(u) = W3c(τ⁴u)` 의 **위수 4** | **유효** (순수 대수) |
| **보조정리 A**(120 pass ↔ 120 육각형 전단사) | **무효** — 120개 육각형을 전부 덮어야 성립한다 |
| **`Σ_h (m_h − 1) = 5k` 등식** | **부등식 형태로만 유효**: `EXC ≤ 5k = 5` (단조) |
| 종말 항등식 `L = 844+F+S+H` 등 | **접두에는 적용하지 않는다** |

## 3·4·5. 접두 예산과 `D = 4` (§3, §4, §5)

`k = 1`, `F = 1` 에서

    P = 121,  O = 25,  **D = 4**,  EXC = 5k = **5**,  L = 869 + N + H,
    N = e + x − f_out,   L ≤ 871 ⟺ **N + H ≤ 2**,   f_out ≤ min(2, 1+e)

에서 곧바로

> **`e + x + H ≤ 2 + f_out ≤ 4`**,  `x + H ≤ 3`,  `e ≤ 4`

즉 **walk 전체에 걸쳐 "예외 사건"은 최대 4 단위**다 (궤도 재방문 + `W3a` 점프 + 허브세).

`D = 4` 의 힘:

* 25개 궤도의 결손 합이 **4** 이므로 **적어도 21개 궤도가 full**(pass 5개)이다.
* full 궤도의 다섯 단어는 **서로 다른 다섯 육각형**에 있으므로 육각형 **5개를 통째로** 먹는다.
* `x = H = 0` 인 run 안의 걸음은 전부 `τ` 이므로 **완전한 5-pass run 은 첫 진입 단어로
  완전히 결정된다**. ⇒ **접두의 분기는 pass 마다가 아니라 run 마다 ~2(`W3b`/`W3c`)** 다.

`k=2` 의 `D=9`, `k=3` 의 `D=14` 와 비교하면 `D=4` 는 **훨씬 빡빡**하고, 그것이 아래
접두 유계 정리를 만든다.

## 6. Full-접두 연결자 분류 (§6)

`A` 안의 모든 pass 는 full 이므로 이음매의 `ℓ` 은 항상 **5** 다. 그 지점에서:

| 연결자 | 무게 | 궤도 | `ΔS` | `ΔH` | 예산 소비 |
|---|---|---|---|---|---|
| `W2 = τ` | 2 | **내부** (run 계속) | 0 | 0 | **없음** |
| `W3a` | 3 | **내부** (phase +2) | 1 | 0 | `x` 1 |
| `W3b` | 3 | 변경 (공유 육각형 1) | 1 | 0 | 없음 (`S` 만) |
| `W3c` | 3 | 변경 (육각형 서로소) | 1 | 0 | 없음 (`S` 만) |
| `W4_0` | 4 | **내부** (phase +3) | 1 | 1 | `x` 1 **+** `H` 1 |
| 나머지 무게-4 (12개) | 4 | 변경 | 1 | 1 | `H` 1 |
| `W5_0` | 5 | **내부** (phase +4) | 1 | 2 | `x` 1 **+** `H` 2 |
| 나머지 무게-5 (70개) | 5 | 변경 | 1 | 2 | `H` 2 |
| 무게-6 (461개) | 6 | — | 1 | 3 | `H` 3 |

> **`ℓ = 5` 에서 무게-2 는 언제나 궤도 내부(`τ`)다.** 따라서 접두 안의 **모든 궤도 변경
> 이음매는 비용 1 이상**이고, **자유 이음매(`f_out`)는 짧은 pass 에서만 나온다.**
>
> 접두에서 무거운 연결자를 하나 쓰면 `H` 예산(최대 3)이 즉시 깎이고, `W4_0`/`W5_0` 는
> `x` 까지 함께 깎는다 (`x + H ≤ 3` 이므로 `W5_0` 는 `x=1,H=2` 로 예산을 거의 다 쓴다).

## 7. 접두 정규형 (§7)

> **정규형.** `S₆` 좌곱이 720 단어에 **단순 추이적**이고 `σ`, `τ`, 550개 tail 전부와
> 교환하므로 **첫 진입 단어를 하나로 고정하는 것이 완전한 720배 축약**이다. 그 위에서
> 모든 유효한 full-pass 접두는
>
>     [완전한 5-pass τ-run] —(W3b|W3c)— [완전한 5-pass τ-run] —(W3b|W3c)— …
>
> 의 형태이고, 여기서 **벗어나는 것은 최대 4 단위**뿐이다:
>
> * run 결손 (5보다 짧은 run) — 떠난 궤도에 대해 합이 **`D = 4`** 이하
> * `e + x + H ≤ 4` (재방문 · `W3a` 점프 · 무거운 연결자)
>
> **all-light 를 가정하지 않았다** — 무게-4/5/6 연결자를 전부 단다.

## 8·11. 뿌리 가족과 무거운 뿌리 (§8, §11)

뿌리를 **`X` 직전 상태 + (`X` 로 들어오는 이음매, `X` 의 길이 `b`)** 로 잡았다
(= `X` 직후 상태와 동치). 열거기 `src/f1_k1_roots_123.c` 는

* 첫 pass 를 단어 0 으로 고정(§7 의 720배 축약),
* full pass 만 이어 붙이며 접두를 넓히고,
* **매 접두 상태에서** `X` 를 놓을 수 있는 모든 (이음매, `b`) 를 뿌리로 방출하고 멈춘다,
* `q = 0`(walk 이 짧은 pass 로 시작) 도 포함한다 — 역사적 `short_ell0..4` 5개가 여기 들어온다,
* **무게-4 13개 · 무게-5 71개 · 무게-6 461개를 전부** 단다 (라운드 121 정정 목록,
  와일드카드로 뭉치지 않았다).

프룬은 전부 정확(exact)하다: 육각형 단사 · 궤도 phase 단사 · `O ≤ 25` ·
`dcap = 4` · `EXC ≤ 5` · **신선 궤도 결손**(라운드 121 `fod`) · 잔여 pass 수용 가능성 ·
`cost + hub ≤ 26` · `e+x+H ≤ 4` · `x+H ≤ 3`.

> **접두 유계 정리 (전수).** 예외 예산을 고정한 **모든** 실행이 완주했고 최대 `q` 는
>
>     e = x = H = 0        q ≤ **46**  ( = NTAB[4] — 해석적 상한과 정확히 일치)

증명을 얻지 못했다.**

## 9·12. 뿌리 완전성과 개수 (§9, §12)

> ### 완전성 정리
>
> **정리.** NR6 아래 `F=1, k=1, L ≤ 871` 인 모든 walk 은, 첫 짧은 pass `X` 에서
> 위 13개 셀의 합집합에 속하는 뿌리에 **정확히 도달한다.**
>
> **증명 개요.**
> (i) 명제 1 로 `X` 앞의 pass 는 전부 full 이므로 walk 은 `A · X · …` 꼴이다.
> (ii) `L ≤ 871` 에서 `e + x + H ≤ 4` 가 유도되고(§3), 접두의 사용량은 전체 사용량 이하이므로
>      `(e_A, x_A, H_A)` 는 그 13개 극대 셀 중 하나에 **componentwise 지배**된다.
> (iii) `S₆` 좌곱이 720 단어에 단순 추이적이고 `σ`·`τ`·550개 tail 전부와 교환하므로
>      **첫 진입 단어 고정은 완전한 720배 축약**이다.
> (iv) 열거기의 프룬은 전부 **정확(exact)** 하다 — 육각형 단사 · 궤도 phase 단사 ·
>      `O ≤ 25` · `dcap = 4` · `EXC ≤ 5` · 신선 궤도 결손 · 잔여 pass 수용 가능성 ·
>      `cost + hub ≤ 26` — 실제 walk 의 가지를 자르지 않는다.
> (v) 13개 셀 실행이 **전부 `frontier empty` 로 종료**했다(캡 도달 0). ∎
>
> **크기.** 셀은 `≤` 상한이라 서로 겹치므로 서로 다른 뿌리 수는
> **`6.27×10¹⁰` 이상 `1.45×10¹¹` 이하**다. **완전하지만 작지 않다** —
> 뿌리를 **저장하지 않았고**(개수만 셌다) 이대로 완성 탐색을 걸 수는 없다.
> 남은 장애물은 정확히 이 크기다.

`b` 분포는 정확히 균등하다 — 어떤 셀에서도 뿌리 수가 `b = 1..5` 에서 같다.
`b` 는 접두와 독립인 자유 인자이므로 **뿌리 수 = (접두 상태 × `X` 로 들어오는 이음매) × 5** 다.

## 15. 양 끝 full 현상 — 거짓 기각 0 (§15)

라운드 122 의 `n=4` 전수 대조에서 `F=1` walk 5,764개 중 **4,139개가 첫 pass full**,
**2,667개가 양 끝 full** 이었다.

> 새 뿌리 구성은 그런 구조를 **받아들인다**: `q > 0` 가 1급 시민이고,
> `e=x=H=0` 만으로도 `q` 가 **1 부터 46 까지** 실제로 실현된다(접두 상태 3,425개).
> 역사적 모델이 `q = 0` 만 다뤘던 것과 대조된다. **거짓 기각 0.**

또한 열거기는 `q = 0` 가지를 **명시적으로** 포함하므로 역사적 short-first 도 잃지 않는다.
