## 1. `B_ii` 를 정확히 고정한다 (§1)

`k=3`, `F=1` 이므로 `P=121`, `O=24+k=27`, `D=5k−F=14`, `L=845+S+H`, `L≤871 ⟺ S+H≤26`.

| 기호 | 뜻 | `B_ii` 의 값 |
|---|---|---|
| `e` | 여분 run 수 `= r−O` | **2** |
| `x` | run **내부** 비용-1 이음매 수 | **0** |
| `f_out` | run **사이** 자유(무게-2) 이음매 수 | **2** |
| `H` | `Σ(ω−3)₊` | **0** |
| `r` | run 수 `= O+e` | **29** |
| `S` | `(r−1)+x−f_out` | **26** |
| `t` | 사슬 수 | **1** |
| `b` | 첫 짧은 pass 길이 | `1..5` |

`h*` 구조: 육각형 정확히 하나만 두 번 진입된다. walk 순서상 먼저 오는 짧은 pass 를
`X`(진입 `v`, 길이 `b`), 나중을 `Y`(진입 `σ^b v`, 길이 `6−b`) 라 한다.
나머지 119개 pass 는 길이가 정확히 6 이다.

`x=0` 이므로 **run 내부의 모든 걸음은 `τ`(phase +1)** 다. 따라서 각 run 은
`Z/5` 의 **연속 phase 호**다.

궤도 재방문은 정확히 둘이고 (`e=2`), 라운드 119 가 확인한 대로 그 둘은 `orb(X)` 와
`orb(Y)` 다 — **다른 25개 궤도는 run 이 정확히 하나씩**이다.

`orb(X)` 의 두 run:

    R_X^end   = X 에서 끝난다        phase 호 {ψ−t'+1, …, ψ},  t' = |R_X^end| ≥ 1
    R_X^start = τ(v) 에서 시작한다   phase 호 {ψ+1, …, ψ+s'},  s' = |R_X^start| ≥ 1

`orb(Y)` 의 두 run:

    R_Y^start = τ(σ^b v) 에서 시작   phase 호 {φ+1, …, φ+s},   s ≥ 1
    R_Y^end   = Y 에서 끝난다        phase 호 {φ−t+1, …, φ},   t ≥ 1

여기서 `ψ = phase(v)`, `φ = phase(σ^b v)` 다. 두 호는 각각 **`ψ`(resp. `φ`) 와 `ψ+1`
사이의 이음매에서 머리와 꼬리가 맞물리는** 상보 호이고, 서로소여야 하므로
`s'+t' ≤ 5`, `s+t ≤ 5`. 궤도 결손은 `5−s'−t'`, `5−s−t` 다.

## 2. `B_ii` 의 순서형 — 유한 목록으로 (§2)

`X`, `Y`, `R_X`(두 run), `R_Y`(두 run) 의 상대 순서로 가능한 것을 전부 센다.

* `X` 가 `Y` 보다 앞이다 (정의).
* 자유 후속 교차: `X → τ(entry_Y) ∈ orb(Y)`, `Y → τ(entry_X) ∈ orb(X)` (전수 3600/3600).
* run 은 **연속 pass 구간**이고 서로 겹치지 않는다 (maximality).
* 경로에는 순환이 없다.

`R_Y^start` 는 `X` 바로 다음 위치 `p+1` 에서 시작한다. `R_Y^end` 는 `Y`(위치 `q>p`)에서
끝난다. `B_ii` 는 이 둘이 **다른 run** 인 경우다. 서로 다른 run 은 서로소 구간이므로
`R_Y^end` 가 `p+1` 을 포함할 수 없고, 따라서 `R_Y^end` 는 `p+2` 이후에서 시작한다 —
즉 **`R_Y^start` 가 `R_Y^end` 보다 앞**이다. 같은 논증이 `orb(X)` 에도 적용되어
`R_X^end` 가 `R_X^start` 보다 앞이다. 순서형은 **정확히 하나** 남는다:

    Π₁ … [R_X^end … X] X [R_Y^start …] M [R_Y^end … Y] Y [R_X^start …] Π₂

`M`(가운데)은 **비어 있을 수 없다**: `R_Y^start` 와 `R_Y^end` 가 붙어 있으면 둘을 잇는
이음매가 궤도 내부가 되어 하나의 run 이 되므로 `B_ii` 가 아니다. 따라서 `|M| ≥ 1 run`.

## 3. 강제 거리 (§3)

    dist(X,Y) = q − p = s + |M| + t ≥ 1 + 1 + 1 = 3

`Φ` 로 `t ≥ 2` 를 가정해도 좋으므로(§8) **`dist(X,Y) ≥ 4`**. 위쪽은 강제되지 않는다 —
라운드 117 의 "간격 정확히 5" 는 `orb(Y)` 가 run 하나일 때(=`B_i`·케이스 C)의 결과이고
`B_ii` 에서는 살아남지 않는다. **이것이 `B_ii` 가 강제-블록 논증을 빠져나간 첫 번째
이유다.** 대신 §8 이 `p` 의 **위쪽 한계**를 준다.

## 4·5. 교차쌍 위상과 구간 모형 (§4, §5)

두 분할 궤도를 "첫 run 시작 ~ 둘째 run 끝" 구간으로 본다.

    I_X = [start(R_X^end), end(R_X^start)]
    I_Y = [start(R_Y^start), end(R_Y^end)] = [p+1, q]

§2 에서 `start(R_X^end) ≤ p` 이고 `end(R_X^start) ≥ q+1` 이므로

> **`I_Y ⊊ I_X` — 두 구간은 교차하지도 서로소이지도 않고 정확히 `Y` 가 `X` 안에
> **중첩(nested)** 된다.** 세 유형(서로소·중첩·교차) 중 **중첩만** 자유 후속 방정식과
> 양립한다.

그래서 §4 가 기대한 "금지된 순환" 은 **나오지 않는다** — 중첩은 경로에서 완전히
합법이다. 정직하게 말하면 **§4 의 예상은 빗나갔고, `B_ii` 의 장애물은 위상이 아니라
§8 의 대칭이었다.**

## 6. `B_ii` 내부의 phase 정합성 (§6)

`x=0` 이므로 네 개의 관련 단어가 전부 `v` 와 `b` 로 **정확히** 결정된다:

    exit(X)     = σ^{b−1} v                    entry(R_Y^start) = τ(σ^b v)
    exit(Y)     = σ^5 v                        entry(R_X^start) = τ(v)
    entry(R_X^end) = τ^{1−t'}(v)               entry(R_Y^end)   = τ^{1−t}(σ^b v)

phase 로는 `entry(R_Y^start) = φ+1`, `entry(R_X^start) = ψ+1`, `R_X^end` 는 `ψ` 에서
끝나고 `R_Y^end` 는 `φ` 에서 끝난다. **강제되는 단어·육각형·phase 충돌은 없다** —
`orb(X) ≠ orb(Y)` 는 항상 참이고(한 육각형은 서로 다른 6개 궤도를 만난다),
두 상보 호는 `s+t ≤ 5`, `s'+t' ≤ 5` 만 요구한다. **§6 이 기대한 해석적 폐쇄는
일어나지 않는다.**

## 7. `C1` 을 정확히 고정한다 (§7)

`e=1, x=0, f_out=2, H=1` → `r=28`, `S=25`, `S+H=26`, `t`(사슬)`=2`.

`orb(X)` 는 **항상** 두 run 을 갖는다(`R_X^end` 는 `X` 에서 끝나고 `R_X^start` 는 `Y`
뒤에서 시작하므로 다른 run). `e=1` 이 이것으로 소진되므로 **`orb(Y)` 는 run 이 하나**다.
따라서 라운드 117 의 강제 기하가 그대로 산다:

    X → (자유) → τ(σ^b v) → τ² → τ³ → τ⁴ → τ⁵ = σ^b v = Y      (간격 정확히 5)

즉 `X` 와 `Y` 사이는 `orb(Y)` 의 **완전한 5-pass `τ`-블록**이고 `orb(Y)` 의 결손은 0 이다.

무거운 이음매(무게 4, 정확히 하나)가 놓일 수 있는 곳:

| 위치 | 가능? | 근거 |
|---|---|---|
| 강제 `τ`-블록 **안** | **불가** | 블록의 이음매는 궤도 내부다. 궤도 내부 무게-4 이음매는 존재하지만(§9 정정) 그것은 **run 내부 비용-1 이음매**이므로 `x` 를 1 쓴다. 케이스 C 는 **`x=0`** 이다 |
| `X` 의 탈출 · `Y` 의 탈출 | **불가** | `f_out=2` 가 둘 다 자유(무게 2)로 강제한다 |
| `X` 보다 앞 | 가능 → **`C1`** | — |
| `Y` 보다 뒤 | 가능 → **`C2`** | — |

> **정정.** 라운드 119 §4 는 이 표의 첫 행을 "무게-4 이동 13/13 이 항상 궤도를 바꾸므로"

## 8. 무거운 변의 정규화 — **뒤집기 대칭** (§8, §10)

§8 이 요구한 "무거운 변에서 경로를 잘라 정규화하라" 의 답은 **자르기가 아니라
뒤집기**다.

### 8.1 사상

`ρ(w) :=` 글자를 뒤집은 단어. walk 을 pass 열 `(진입 u_i, 길이 m_i)` 로 볼 때

> **`Φ(walk) :=` pass 열을 뒤집고, 각 pass `(u, m)` 을 `(ρ(σ^{m−1}u), m)` 으로 보낸다.**

이것은 **초순열 문자열을 통째로 뒤집는 것**과 같다.

### 8.2 전수로 확인한 것 (`src/verify_f1_reversal_120.py`)

| | 확인 내용 | 규모 | 위반 |
|---|---|---|---|
| **A1** | `ρ∘σ = σ^{-1}∘ρ` | 720 | 0 |
| **A2** | 이음매 무게 보존 `ω(y,z) = ω(ρ(z), ρ(y))` | 517,680 쌍 | **0** |
| **A3** | `R := ρ∘σ⁵` 는 **대합**이고 `τ`-궤도를 궤도 위로 보낸다 | 144 궤도 | **0 흩어짐** |
| **A4** | `ρ` 는 육각형을 육각형 위로 보낸다 | 120 | 0 |
| **A5** | pass 상이 pass 다 | 4,320 | 0 |
| **R1** | full→full 이음매의 궤도 내부성 보존 | 12,240 | **0** |
| **R2** | full→short 이음매의 상은 **항상 궤도를 바꾼다** | 61,200 | **0** |
| **R3** | short→full 무게-2 이음매의 상은 **항상 `τ`(궤도 내부)** | 3,600 | **0** |

`A3` 이 핵심이다: `ρ` 단독은 궤도를 산산이 흩지만(궤도 상 크기 5), **`R = ρ∘σ⁵` 는
144개 궤도를 궤도 위로 정확히 보낸다.** 그래서 뒤집기는 `τ`-정련된 칸 분해까지
보존한다. `R∘R = id` 도 확인했다.

`R2` 는 **`n=6` 고유의 사실**이다. 그 밑에 깔린 census —
**`ℓ<5` 에서 17개 이동(경량 4 + 무게-4 13) 전부가 궤도를 바꾼다(0/720)** — 도 전수
확인했다. `n=4` 에서는 이 밑바탕 사실이 **거짓**이고, 그에 맞춰 `R2` 도 `n=4` 에서
**깨진다(173회)**. 즉 `n=4` 대조는 **`R2` 가 census 를 정확히 따라간다**는 것을
확인해 준다 — 우연이 아니다.

### 8.3 `Φ` 가 `B_ii` 와 `C1` 에 하는 일

`R1`–`R3` 만으로 전부 결정된다. 짧은 pass `X`(위치 `p`)·`Y`(위치 `q`)에 대해:

* `X` 의 **자유 탈출**(무게 2, `ℓ=b−1<5`) → 상은 `ℓ=5` 의 무게-2 = **`τ`(궤도 내부)**.
* `X` 로 **들어오는** 이음매 → 상은 `ℓ=b−1<5` 이므로 **항상 궤도를 바꾼다**;
  들어오는 이음매가 `τ`(즉 `t'≥2`)였으면 상은 **자유 inter-run 탈출**이 된다.
* `Y` 도 같다.

그래서 `Φ` 는 `X`·`Y` 의 역할을 **충실히 맞바꾸고**, 뒤집힌 walk 에서

    첫 짧은 pass = Φ(Y) (길이 6−b),   둘째 = Φ(X) (길이 b)     ⇒ **b ↦ 6−b**
    X 앞 pass 수 (p−1)  ↔  Y 뒤 pass 수 (121−q)                ⇒ **접두 ↔ 접미**

가 된다.

### 8.4 `C1` 은 이렇게 닫힌다

`C1` 의 하위경우는 `t' = |R_X^end|` 로 정확히 갈린다.

| `C1` 하위경우 | `Φ` 상의 자원 행 | 닫은 곳 |
|---|---|---|
| **`t' ≥ 2`** (`X` 로 들어오는 이음매가 `τ`) | `e=1, x=0, f_out=2, H=1`, `r=28`, **무거운 변이 둘째 짧은 pass 뒤** = **`C2`**, 분할 `6−b` | **라운드 119 `C2`, 5/5 UNSAT_COMPLETE** |
| `t' = 1` 이고 무거운 변이 **`X` 로 들어오는 이음매** | `e=0, x=0, f_out=1, H=1`, `r=27` | **라운드 118 `G6_H1_e0`, 5/5 UNSAT_COMPLETE** |
| `t' = 1` 이고 무거운 변이 그보다 앞 | `e=0, x=0, f_out=1, H=1`, `r=27` | **라운드 118 `G6_H1_e0`, 5/5 UNSAT_COMPLETE** |

`t'≥2` 는 `X` 로 들어오는 이음매가 궤도 내부라는 뜻이고, 무거운 이음매는 (`x=0` 이므로)
궤도를 바꿔야 하므로 그 이음매일 수 없다 — 두 열이 **서로소이고 전부**다.
`Φ` 는 대합이고 `C2`·`G6` 는 다섯 분할 전부에서 돌았으므로 `b ↦ 6−b` 도 덮인다.

> ### `C1` 폐쇄 → **케이스 C 폐쇄** (탐색 0 노드)

### 8.5 `B_ii` 에서 `Φ` 가 주는 것

`B_ii` 는 `Φ` 아래 **자기 자신으로** 간다. 경계 경우만 밖으로 나간다.

| `B_ii` 하위경우 | `Φ` 상 | 닫은 곳 |
|---|---|---|
| `t'=1, t≥2` | `e=1, x=0, f_out=1, H=0`, `r=28` | **라운드 118 `G2_e1_x0_f1_H0`** 5/5 |
| `t=1, t'≥2` | `e=1, x=0, f_out=1, H=0`, `r=28` | **라운드 118 `G2_e1_x0_f1_H0`** 5/5 |
| `t'=1, t=1` | `e=0, x=0, f_out=0, H=0`, `r=27` | **라운드 118 `G1_e0_H0`(행 `(0,0,0)`)** 5/5 |
| **`t'≥2, t≥2`** | **`B_ii`, `b ↦ 6−b`, 접두↔접미** | 이 라운드의 탐색 |

여기서 **정규형 세 개**가 나온다.

    seam   = 1   t' ≥ 2 그리고 t ≥ 2  — X·Y 로 들어오는 이음매가 둘 다 tau.
                 (경계 경우는 위 표대로 이미 닫혔다.)
    symcut = 1   접두 ≤ 접미, 즉 p−1 ≤ 121−q 를 가정한다.
                 (Φ 가 둘을 맞바꾸므로 walk 이나 그 상 중 하나는 반드시 만족한다.
                  b ↦ 6−b 도 함께 바뀌지만 다섯 분할을 전부 돌므로 덮인다.)

                 넘으면 X 를 놓을 자리가 없으므로 그 가지는 죽는다.

`seam` 은 `X`(그리고 `Y`)의 진입 단어를 **직전 pass 의 `τ` 로 강제**하므로 그 지점의

## 9. 무게-4 tail 13개의 분류 — 그리고 **라운드 118 census 정정** (§9)

> ### 정정 상자 — 라운드 118 §6 / 라운드 119 §4
>
> 라운드 118 은 **"무게-4 tail 13개가 13/13 항상 궤도를 바꾼다(720/720)"** 라고 기록했다.
> **이것은 틀렸다.** 엔진 자신의 표로 다시 센 결과:
>
> * **`W4_0`**(작용 `[4 5 1 2 3 0]`)은 `ℓ=5` 에서 **720/720 궤도를 바꾸지 않는다.**
>   그것은 진입 단어를 `τ³` 로 보내는 **궤도 내부** 무게-4 이동이다.
> * 나머지 **12개**는 모든 `ℓ` 에서 궤도를 바꾼다.
> * `ℓ<5` 에서는 **13개 전부** 궤도를 바꾼다 (0/720). 어느 `ℓ` 에서도 **출발 육각형으로
>   돌아오지 않는다** (13/13).
>
> 따라서 구조적 클래스는 **13개가 아니라 2개**다: `{W4_0}` 와 `{나머지 12}`.
>
> **엔진 영향.** 라운드 118·119 의 탐색기에는
> `/* every weight-4 move changes orbit */ if (same && hb) continue;` 가 있었고 이것은
> **불건전**했다 — 궤도 내부 무게-4 이동은 실은 `x` 를 1 쓰는 **run 내부 비용-1 이음매**다.
> 그러나 **실행된 모든 run(라운드 118 의 4그룹, 라운드 119 의 6분기)은 `xcap=0`
> 이거나 `hcap=0`** 이었다. `xcap=0` 이면 바로 다음 줄이 같은 가지를 어차피 버리고,
> `hcap=0` 이면 무게-4 후속이 아예 달리지 않는다. **따라서 어떤 결과도 영향받지 않았고
> 라운드 118·119 의 판정은 그대로 선다.** 라운드 120 엔진에서는 그 줄을 없애고
> `x` 회계가 처리하도록 했다 (`C2 b=1` 이 여전히 정확히 **1,053,024,770** 노드).

## 12. 라운드 119 의 접두 용량 회랑은 왜 아무 데서도 안 터졌나 (§12)

브리프가 지목한 네 후보 중 **육각형 접촉 상관**이 답이다. 그리고 그것을 정확히
붙잡는 새 불변량을 만들어 **측정**했다.

### 12.1 새 불변량 — 궤도-덮개 잉여

전수 확인된 기하: **궤도 하나는 정확히 5개 육각형을 만나고, 육각형 하나는 정확히
6개 궤도를 만난다.** `F=1` walk 의 진입 단어는 육각형마다 정확히 하나(`h*` 만 둘)이므로
**쓰인 궤도 집합이 120개 육각형을 전부 덮어야 한다.** `|Q| = O = 24+k` 이므로

    Σ_h m_h = 5·O,   m_h := #{쓰인 궤도 중 h 를 만나는 것} ≥ 1
    ⇒  EXC := Σ_h (m_h − 1) = 5·O − 120 = 5k        (k=3 이면 **정확히 15**)

`EXC` 는 궤도를 새로 열 때만 증가하므로 **`EXC ≤ 5k` 는 정확한 프룬**이다.
얼마나 빡빡한가: 무작위 27-궤도 집합의 잉여는 20,000 표본에서 **최소 34 · 중앙값 49**.
공허하지도 않다 — **24-궤도 정확 덮개가 실제로 존재**하고 거기에 궤도 3개를 더하면
잉여가 정확히 15 인 덮는 27-집합이 나온다(거짓 기각 0 대조).

### 12.2 정직한 계측 — 이 프룬은 거의 아무 것도 못 잘랐다

`C2 b=1` 에서 `exccap=15` 를 켜면 1,053,024,770 → **1,049,696,947** 노드. **0.3%.**

왜인가. 탐색기를 계측했더니 노드 질량이 **궤도 12–13개** 근처(대략 pass 55–60)에
있고 거기서 `EXC` 의 평균은 **7.4**, 최대 23 이다. 즉 탐색은 `EXC` 가 15 에 닿기
**훨씬 전에** 다른 이유로 죽는다. 게다가 항등식

    EXC = 5·orbits − (덮인 육각형 수)

때문에 `EXC ≤ 15` 는 라운드 118 의 `dcap`(떠난 궤도들의 결손 합 ≤ `D`)과 **거의 같은
정보**다 — 같은 관계 `5·O − P = D` 를 이분 그래프의 반대편에서 본 것이다.

> **결론(§12 에 대한 답).** 라운드 119 의 회랑이 못 잡은 좌표는 육각형 접촉 상관이
> 맞지만, **그 좌표를 정확히 붙잡아도 탐색은 줄지 않는다.** 이번 라운드에서 실제로
> 효과를 낸 것은 프룬이 아니라 **§8 의 대칭**이다. `exccap` 은 정확하므로 켜 둔 채
> 돌렸지만, 공로는 그쪽에 없다.

### 16.1 이음매 육각형 충돌 보조정리 (`b=1`·`b=5` 가 왜 얕은가)

`x=0` 이므로 full pass 에서 나가는 유일한 궤도 내부 이음매는 `τ` 다. 따라서

    t' ≥ 2  ⟹  X 직전 pass 의 진입 = τ^{-1}(v)
    t  ≥ 2  ⟹  Y 직전 pass 의 진입 = τ^{-1}(σ^b v)

한편 `X` 의 자유 탈출은 `τ(σ^b v)` 에서 run 을 열고 `Y` 의 자유 탈출은 `τ(v)` 에서 연다.
`h*` 를 빼면 육각형은 정확히 한 번씩만 진입되므로 이 네 단어의 육각형은 서로 달라야 한다.
**720 단어 전수**로:

> `hex(τ(σ⁵v)) = hex(τ^{-1}(v))` — **모든 v** ⟹ **`b=5` 에서 `t' ≥ 2` 는 불가능**
> `hex(τ(v)) = hex(τ^{-1}(σ¹v))` — **모든 v** ⟹ **`b=1` 에서 `t ≥ 2` 는 불가능**
> `b = 2,3,4` 에는 강제 충돌이 **없다**.

(대조: 한 궤도의 다섯 단어는 **다섯 개의 서로 다른 육각형**에 있다 — 720/720.)

그래서 `b=5` 의 `seam` 탐색에서는 `Y` 의 단어가 **후속으로 한 번도 제시되지 않고**
(계측: 30억 노드에서 0회, `seam=0` 이면 1,024만 회), 탐색은 `pmax` 선인 pass **59** 에서
멎는다. `b=1` 은 같은 충돌이 `Y` **뒤**에서 터지므로 조금 더 깊이 들어갔다 죽는다
(`sstate=2` 최대 pass 80). **두 경우 모두 `Φ` 상이 이미 닫힌 `G2`/`G1` 이므로
결과는 바뀌지 않는다** — 이 보조정리는 탐색이 얕은 것이 버그가 아님을 확인해 줄 뿐이다.

**`k>0` 인 실제 `F=1` `n=6` walk 은 저장소에 없다**(872 witness 는 `F=25`).
`n=6` 양성 대조는 만들 수 없었고 **정리로 대조를 생성하지 않았다.**
