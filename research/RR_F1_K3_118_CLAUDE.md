## 1. `(3,1)` 예산 — 완전한 유한 표 (§1)

`k = 3`, `F = 1`: `P = 121`, `O = 27`, `D = 5k − 1 = 14`, `L = 845 + S + H`,
`L ≤ 871 ⟺ S + H ≤ 26`.

라운드 116 의 회계 `S = (r−1) + x − f_out` 과 `r = O + e = 27 + e` 에서

    S = 26 + e + x − f_out,      H ≤ 26 − S = f_out − e − x.

라운드 117 의 **보조정리 E** (`f_out ≤ 1 + e`) 를 넣으면 `H ≤ 1 − x`, 따라서

> **`H ≤ 1`** 이고 **`x ≤ 1`**. `H = 1` 은 `x = 0` 이고 `f_out = 1 + e` 일 때만 가능하다.

`f_out ≤ 2` 까지 넣으면 자원 경우는 **정확히 7행**이다.

| `e` | `x` | `f_out` | `S` | `H ≤` | `r` | `t ≤` |
|---|---|---|---|---|---|---|
| 0 | 0 | 0 | 26 | 0 | 27 | 1 |
| 0 | 0 | 1 | 25 | **1** | 27 | 2 |
| 0 | 1 | 1 | 26 | 0 | 27 | 1 |
| 1 | 0 | 1 | 26 | 0 | 28 | 1 |
| 1 | 0 | 2 | 25 | **1** | 28 | 2 |
| 1 | 1 | 2 | 26 | 0 | 28 | 1 |
| 2 | 0 | 2 | 26 | 0 | 29 | 1 |

`H` 을 갈라 세면 **9개 하위경우**다 (`H=1` 은 두 행에서만 가능).

**숨은 여유 변수는 없다.** `e ≥ 3` 은 `H < 0` 으로 죽고, `x ≥ 2` 도 그렇다.

## 2. `H = 0` 과 `H = 1` 의 분리 (§2, §4)

* **`H = 0`**: `H ≥ t − 1` 에서 **`t = 1`** — walk 전체가 **하나의 all-light 121-pass 사슬**이고
  120개 joint 가 전부 무게 ≤ 3 이다. 라운드 117 `(4,1)` 과 **같은 형태**지만
  `O = 27`(28 아님), `D = 14`(19 아님), 그리고 `e ≤ 2`, `x ≤ 1` 이 새로 열린다 —
  **완화가 아니라 다른 문제다.**
* **`H = 1`**: `H = Σ(ω−3)₊ = 1` 이므로 **무게-4 joint 정확히 하나**이고 더 무거운 joint 는
  없다 (§2 의 물음에 대한 답: **그렇다**). 무게-4 는 경량이 아니므로 사슬을 가르고
  **`t = 2`** 가 강제된다. 그 joint 는 `S` 에 1, `H` 에 1 을 낸다.

## 3. 허브세-1 이동의 정확한 census (§6)

`max(ω−3,0) = 1` 인 indecomposable tail 은 **무게 4 뿐이고 정확히 13개**다
(엔진의 `tail_permutations(4)` 와 일치함을 확인).

720 단어 전수 — 13개 전부 균일하다:

| 성질 | 결과 |
|---|---|
| 궤도를 바꾸는가 | **13/13 이 항상 바꾼다** (720/720) → 무게-4 joint 는 **결코 run 내부가 아니다** |
| 출발 육각형으로 돌아오는가 | **13/13 이 항상 떠난다** (720/720) |
| 출발/도착 궤도의 공유 육각형 | **12개는 0**(육각형-서로소), **1개는 2** |

> 즉 "무거운 이동 하나"는 **와일드카드가 아니다** — 그것은 13개의 구체적 사상이고,
> 전부 inter-run 이며, 그중 12개는 `W3c` 와 같은 육각형-서로소 유형, 하나만
> **육각형 2개를 공유**한다 (`W3b` 가 1개를 공유하는 것과도 다르다).

**따름**: `H = 1` 의 무게-4 joint 는 `h*` 의 두 짧은 pass 사이의 강제 블록 안에 **놓일 수 없다**
— 그 블록의 joint 는 궤도 내부(τ)이기 때문이다.

## 4. 라운드 117 강제 기하가 `k = 3` 에서 살아남는 범위 (§11)

`f_out = 2` 이면 보조정리 E 로 `e ≥ 1` 이고, X(먼저 오는 `h*` pass)는 **항상 경우 (ii)** 다
(경우 (i) 은 Y 를 X 앞에 놓아 순서에 모순). 그 다음이 `k` 에 따라 갈린다.

| 하위경우 | Y 의 경우 | X–Y 간격 | 근거 |
|---|---|---|---|
| `(1,0,2)` (`e=1, x=0`) | **(i) 강제** | **정확히 5** | `e = 1` 이라 `orb(Y)` 는 run 이 하나뿐이고, `x = 0` 이라 블록이 순수 `τ`-블록 |
| `(1,1,2)` (`e=1, x=1`) | (i) 강제 | **4 또는 5** | 블록이 `W3a` 점프 하나를 쓸 수 있다 (`+1,+1,+2` → 4 pass) |
| `(2,0,2)` (`e=2, x=0`) | **(i) 또는 (ii)** | **강제되지 않는다** | `e = 2` 면 `orb(Y)` 도 두 번째 run 을 가질 수 있다 |

> **§11 의 답**: 강제 5-간격은 `e = 1, x = 0` 에서만 그대로 살아남는다.
> `x = 1` 은 간격을 `{4,5}` 로 넓히고, **`e = 2` 는 그것을 완전히 깬다** — `k=3` 이 새로 여는
> 자유가 정확히 이 두 가지다.

### 6.2 `H = 0` 이 `t = 1` 로 환원되는가 (§4)

**그렇다.** `H ≥ t − 1` 과 `H = 0` 에서 `t = 1` 이다. 따라서 `H = 0` 인 여섯 행은 전부
**all-light 121-pass 사슬** 문제이고, 라운드 117 `(4,1)` 과 **같은 형태**다.
다만 라운드 117 의 **완화판이 아니다** — `O` 와 `D` 가 더 빡빡해지는 대신(`27`/`14` 대 `28`/`19`)
`e ≤ 2`, `x ≤ 1` 이라는 **새 자유**가 열린다. 실제로 `e = 0` 행은 라운드 117 보다 **11배 싸고**
(`7.5×10⁸` 대 `8.5×10⁹` 노드), `e ≥ 1` 이면서 `x = 1` 또는 `e = 2` 인 행은 **훨씬 비싸다.**
