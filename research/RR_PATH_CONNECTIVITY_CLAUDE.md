## 1. 완성이 유도하는 대상 (§1)

라운드 93 에서 확인된 사실만 쓴다: 회전은 port 를 등록하지 않고 joint 는 정확히 1개
등록하므로 **pass 하나가 육각형 하나를 소비하고 진입 칸 하나만 등록**한다.

| | |
|---|---|
| 꼭짓점 | 미래 의무 = 빈 육각형 각각 1회 진입 (+ `r=0` 이면 fragment 수리 진입) |
| 유향 간선 | `x → y` ⟺ `x` 의 어떤 진입 후보에서 `σ^ℓ`+joint 가 `y` 의 어떤 진입 후보에 닿음 |
| 뿌리 | 현재 pass (엔드포인트 `p`, `ℓ=5`) |
| 유입 | 각 의무 정확히 1 |
| 유출 | 각 pass 정확히 1회 발사(마지막 pass 제외) |
| port 1회 사용 | 라운드 87, 이미 반영 |

`ℓ` 은 빈 육각형에서 5, fragment 수리에서 `5−c_f` 로 **강제**된다(라운드 90/91, 감사 완료).
**Hamilton 이라고 가정하지 않고** 유도했다 — 유입 1·유출 ≤1 에서 선택 간선이
(뿌리에서 나온 경로)+(사이클들)로 분해된다는 것까지만 쓴다.

## 2. 매칭과 경로의 차이 (§2)

엔진이 뒷받침하는 것만 채택한다.

| | 필요? | 근거 |
|---|---|---|
| A. 첫 의무를 뺀 모든 의무는 전임자 정확히 1개 | **예** | 진입은 joint target 1개 |
| B. 각 전임 사건은 후속을 최대 1개 공급 | **예** | pass 당 발사 1회 (라운드 87) |
| C. 현재 continuation 에서 도달 가능한 성분은 하나 | **예** | walk 은 하나의 시간 순서 |
| D. 뿌리와 분리된 유향 사이클은 불가능 | **예** | C 의 따름 |
| E. 독립 경로 성분 여러 개는 불가능 | **예** | 같은 이유 |
| F. 궤도 개방과 양립하는 위상 정렬 존재 | **예**, 단 라운드 92 의 `A`-rooted 생성 조건이 이미 강제 | §7 은 그 조건에 흡수된다 |

## 4. 양성 대조와 **규명되지 않은 비대칭** (§8)

| 대조 | 결과 |
|---|---|
| 실현된 등록 port 가 다른 등록 port 에서 `σ^ℓ`+joint 로 도달 | 상태당 도달 불가 **최대 1개**(= 최초 단어), 2개 이상인 상태 **0/6,396** |
| 층 A 와 B 의 위반 집합 일치 | 모든 쌍 |
| `c` 밴드별 거부율 | 1.1 %–5.4 %, 단조롭지 않음 |
| root 별 거부율 | 3.2 %–5.7 %, 고르다 |
| **`r` 별 거부율** | **`r=0` 0.7 % 대 `r=1` 37.8 %** |

> **`r=1` 비대칭은 이 라운드에서 해결하지 못했다.** `r=1` 은 fragment 가 이미 수리된 상태
> (그 육각형에 등록 port 가 2개)이고, §8 이 명시적으로 시험하라고 지목한 부류다.
>
> 가장 자연스러운 설명 — "cover 가 적어서 전부 실패하기 쉽다" — 은 **측정으로 기각된다**:
> `r=1` 상태의 통과 cover 는 중앙값 **7**, 평균 11.0 으로 `r=0`(중앙값 3, 평균 4.7)보다
> **많다**. 즉 더 많은 cover 를 갖고도 전부 실패한다.
>
> 쌍 수준에서는 두 부류 모두 A 와 B2 가 고루 발동한다
> (`r=0`: A 1,340 · B2 1,246 / `r=1`: A 1,288 · B2 229).
>
> 이 비대칭이 **구조적 사실인지 모델 결함인지 규명되기 전까지**, 잠정 228(그중 198 이
> `r=1`)을 원장에 반영하지 않는다.
