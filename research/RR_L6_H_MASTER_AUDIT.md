# H.master 독립 감사 — MASTER 길이 항등식

**대상 노드**  `H.master`
**감사 라운드**  160  **기반 커밋**  `16492af` (branch `round153-equality-coexistence`)
**산출물**  `r160/src/*.py`, `r160/certs/*.json`, 그리고 이 문서
**이 문서의 지위**  수리된 DAG(`r160/certs/dag_160.json`)의 `H.master.where`
가 가리키는 정본 감사 문서.  §2·§3·§14 가 정리와 증명이다.

이 감사는 `H.master` **하나만** 다룬다.  `H.samehex`, `H.incidence`,
`H.extract`, `H.envelope`, `H.tight`, `H.feas`, `H.models`, `H.catalogue`,
`H.wlog` 는 재감사하지 않고 **이미 인증된 의존**으로만 인용한다.

---

## 요약

* **항등식은 원시 단어 수준에서 재유도된다.**  `L = n + sum gaps` →
  간격 census → 조인트 비용 → **(FO)** → 변수 치환 → **MASTER**.
  모든 단계를 실제 덮개 **651 개**에서 문자 그대로 확인했고 **최대 절대 오차
  0**, 정수 상자 **470,596 사례**에서 대수적 불일치 0.
* **상수 867 은 맞춰 넣은 값이 아니다.**  일반형
  `CONST(n) = n! + (n-1)! + (n-2)! + n - 3` 이고 `n = 3,4,5,6` 에서
  **9, 33, 152, 867**.  알려진 최소 초순열 길이가 각각 `9 = 9+0`,
  `33 = 33+0`, `153 = 152+1`, `872 = 867+5` 로 맞는다.  상수와 그 네 개
  구성 요소를 `±1` 씩 흔드는 11 종 섭동이 **463 개 단어 전부에서 검출**된다.
* **`h` 가 아니라 `H` 다.**  `h != H` 인 단어 **166 개 전부**에서 `h` 를
  대입하면 항등식이 깨진다.  `h` 를 예산으로 넘기는 파일은 **전부 정리 경로
  밖**이다 (라운드 152 가 고친 그 버그의 잔재가 경로에 없다).
* **구(舊)표기 오염 0.**  정리 경로가 도달하는 33 개 파일에 `f_out`,
  `delta = F + e - ...`, `J = G - F`, abandonment 계열 어휘가 **하나도 없다**.
  현재 항등식에는 **`F` 가 아예 등장하지 않는다**.
* **결함은 메타데이터 하나.**  `what` 의 "every term >= 0" 는 `where` 가
  증명하지 않는다 — 네 비음성은 각각 `H.splice`, 궤도 크기, `H.samehex` +
  `H.incidence`, `H.extract` 에서 온다.  비파괴적으로 귀속을 고쳤다.

## Phase 0 — 대상 노드

```json
"H.master": {"status": "AUDITED_HAND_PROOF",
             "what":  "MASTER-142: L = 867 + k + Z + H + B*, every term >= 0",
             "deps":  [],
             "where": "src/l6_master_identity_144.py"}
```

* **직접 하류**: `C.census`, `T.ge872`.
* **전이 하류**: `C.census`, `E.enumeration`, `X.structure`, `X.exclusion`,
  `X.nolemmaE`, `X.controls`, `X.adversarial`, `T.ge872`, `T.eq872`.
* **최종 정리에서의 역할**: `t := L - 867 = k + Z + H + B*` 를 정의하고,
  네 항이 음이 아니므로 `L <= 871 ⟺ t <= 4` 가 되어 **유한한 좌표행 열거**가
  가능해진다 (`r152/src/rows152.py::rows(t)` 가 `k, Z, H, B*` 를 음이 아닌
  정수로 `t` 에 분할한다).  **항등식이나 비음성이 틀리면 열거가 행을 빠뜨려
  인구조사가 불완전해진다 — 불건전.**
* **정본 출처가 실제로 진술하는 것** (`src/l6_master_identity_144.py`):
  > `L = 844 + G + S + H` (FO) … Then MASTER-142: `L = 867 + k + Z + H + B*`.
  > This module proves that identity is an exact rearrangement of (FO), so it
  > carries **no extra hypothesis beyond the definitions of B\* and Z**.

  즉 그 파일은 **항등식**을 증명한다고 명시하고, 비음성은 "recovered
  definitions" 목록에 적어 둘 뿐 증명하지 않는다.

## Phase 2 — 첫 원리로부터의 재유도

`r160/src/master160.py` 는 `src/l6_master_identity_144.py`,
`src/l6_bookkeeping_144.py`, `src/l6_cleanroom_146.py` 를 **import 하지
않는다**.  pass 층만 라운드 156 의 독립 재구현에서 가져오고, 아래 다섯 단계를
각 단어에서 문자 그대로 검사한다.

**(W1) 단어 길이.**  고정 대표원은 **trim** 되어 있으므로 첫 선택 창이 위치
0 에서 시작하고 마지막 선택 창이 위치 `L - n` 에서 시작한다.  따라서

```
L = n + sum_{j=1}^{N-1} g_j ,      g_j = i_{j+1} - i_j = omega(q_j, q_{j+1}).
```

(검사: `sel[0][0] == 0`, `sel[-1][0] + n == len(W)`, `L == n + sum gaps`.)

**(W2) 간격 census.**  `g_j = 1` 은 정확히 pass **내부** 단계다 (다음 선택
창이 `sigma` 이동).  `N` 개 선택 창이 `P` 개 pass 로 분할되므로 pass 내부
단계가 `N - P` 개, 조인트가 `P - 1` 개이고

```
(N - P) + (P - 1) = N - 1 = #간격.
```

**(W3) 조인트 비용.**  모든 조인트는 `w >= 2` 이고
`w - 2 = [w >= 3] + (w - 3)_+` 이므로

```
sum_joints w = 2(P - 1) + S + H.
```

**(FO).**  (W1)–(W3) 을 합치면

```
L = n + (N - P) + 2(P - 1) + S + H = (n + N - 2) + P + S + H
  = (n + N + HEX - 2) + G + S + H.          (P = HEX + G)
```

`n = 6` 에서 괄호는 `6 + 720 + 120 - 2 = 844`.

**(변수 치환).**  정의에서
`G = Z + D2 + c` (∵ `Z = z - D2`, `z = G - c`),
`S = B* + O - 1 - D2 - c` (∵ `B* = blocks - (O - c)`, `blocks = S + 1 + D2`),
`O = ORB + k`.  대입하면

```
L = (n + N + HEX - 2) + (Z + D2 + c) + (B* + ORB + k - 1 - D2 - c) + H
  = (n + N + HEX + ORB - 3) + k + Z + H + B*.          MASTER
```

**결과** (`r160/certs/real_160.json`): 실제 덮개 **651 개**
(`n=3` 66 · `n=4` 407 · `n=5` 177 · `n=6` 1) 에서 위 모든 검사 위반 0,
`|L - MASTER|` 의 **최댓값 0**.  `n` 별 상수: **9 / 33 / 152 / 867**.

**대수 검증** (`r160/certs/symbolic_160.json`): `n = 3,4,5,6` 각각 정수 상자
117,649 사례, 합계 **470,596 사례**에서 (FO) `=` MASTER, **불일치 0**.
섭동 5 종 — 상수 `+1`, 상수 `-1`, `H` 자리에 `h`, `B*` 에서 `+1` 제거,
`G` 에서 `c` 제거 — **전부 불일치를 낸다**.

## Phase 3 — 상수 867

```
CONST(n) = n + (N - HEX) + 2*(HEX - 1) + (ORB - 1)
         = n + N + HEX + ORB - 3
         = n! + (n-1)! + (n-2)! + n - 3
```

| `n` | 첫 창 `n` | pass 내부 `N-HEX` | 최소 조인트 비용 `2(HEX-1)` | 변수 치환 `ORB-1` | 합 |
|---:|---:|---:|---:|---:|---:|
| 3 | 3 | 4 | 2 | 0 | **9** |
| 4 | 4 | 18 | 10 | 1 | **33** |
| 5 | 5 | 96 | 46 | 5 | **152** |
| 6 | 6 | 600 | 238 | 23 | **867** |

세 닫힌형이 `n = 3..9` 에서 일치한다.  **넷째 항만이 단어 길이 항이 아니다** —
`S` 를 `B*` 로 바꾸는 변수 치환이 `+(O - 1) = +(ORB + k - 1)` 을 내놓고,
그중 `k` 는 항으로 빠지고 `ORB - 1` 만 상수에 남는다.

**off-by-one 이 없음.**  가능한 오류마다 그 자리를 짚었다:

| 위험 | 어디서 막히는가 |
|---|---|
| 시작 창 오류 | (W1) 은 `n + sum gaps` 이고 첫 창이 `n` 글자를 통째로 기여한다.  이후 창은 `g` 글자씩만 더한다 — 중복 없음.  `sel[0][0] == 0` 을 검사한다. |
| 끝 창 오류 (trim) | `sel[-1][0] + n == len(W)` 를 검사한다.  trim 되지 않으면 `L > n + sum gaps` 이고 (FO) 는 항등식이 아니라 부등식이 된다 — 그래서 **고정 대표원 가정이 필수**다. |
| 더미 창 오류 | 더미 `*` 은 단어 위치가 아니라 `beta` 구성의 보조 원소이므로 (W1)–(FO) 에 들어가지 않는다. |
| 길이 대 간선 비용 off-by-one | `#간격 = N - 1 = (N-P) + (P-1)` 을 검사한다.  조인트 수가 `P` 가 아니라 `P - 1` 이라는 것이 `2(HEX-1)` 의 `-1` 의 출처다. |
| 초기 순열 이중 계수 | 위와 같음: `q_1` 은 `n` 글자, `q_j (j>=2)` 는 `g_{j-1}` 글자. |

**섭동 검출** (`r160/certs/constant_160.json`): 상수 `±1` 과 네 구성 요소
각각 `±1`, 그리고 (FO) 상수 `±1` — **11 종 전부가 463 개 단어 전부에서
검출**된다 (검출률 463/463).

**독립 앵커.**  상수는 알려진 최소 초순열 길이와 정확히 맞는다:

| `n` | 최소 길이 | `CONST(n)` | `t` |
|---:|---:|---:|---:|
| 3 | 9 | 9 | **0** |
| 4 | 33 | 33 | **0** |
| 5 | 153 | 152 | 1 |
| 6 | 872 | 867 | 5 |

`n = 3, 4` 에서 `t = 0` 인 단어가 저장소에 실재하므로 (경계 사례 8 개),
상수가 한 칸이라도 크면 그 단어들이 `t < 0` 을 갖게 되어 즉시 모순이다.

**경계 사례** (463 단어): `G = 0` 97 · `H = 0` 100 · `B* = 0` 170 ·
`k = 0` 12 · `S = 0` 24 · `c = 0` 411 · **`t = 0` (네 항 전부 0) 8** —
전부에서 항등식이 성립한다.

## Phase 4 — `k`

`k := O - ORB` 이고 `O` 는 **pass 진입점의 서로 다른 `tau`-궤도 수**다.
성분도, 순환도, pass 수도, 순수 `beta` 순환 수도 아니다 (`r160/src/master160.py`
가 `O = len(set(orbr))` 로 직접 센다).

**계수가 정확히 `+1` 인 이유.**  `S` 를 `B*` 로 바꾸는 치환에서 `-O` 가 들어오고
`O = ORB + k` 이므로 `-ORB - k` 가 된다.  `(FO)` 쪽에는 `k` 가 없으므로,
좌변을 맞추려면 MASTER 쪽에 `+k` 가 정확히 한 번 나타나야 한다.  계수를
`+2` 나 `0` 으로 바꾸면 위 섭동 실험처럼 항등식이 즉시 깨진다.

**`G` 와의 관계.**  `D_phi := (n-1)O - P = (n-1)k - G >= 0`.  `tau`-궤도는
원소가 `n-1` 개이고 pass 진입점은 서로 다른 선택 창이므로 한 궤도에 최대
`n-1` 개가 들어간다 — 이것이 `D_phi >= 0` 이다.  행 열거의
`k >= ceil(G/(n-1))` (`r152/src/rows152.py` 45–47 행) 이 바로 이 관계다.

## Phase 5 — `Z`

`Z := z - D2`, `z := G - c`.  `z = 2g + d` 이므로 `Z = 2g + d - D2`.

**`L` 에 대한 기여.**  `Z` 는 (FO) 의 `G` 를 통해 들어온다:
`G = Z + D2 + c` 이므로 `G` 한 단위가 `Z`, `D2`, `c` 중 정확히 하나에 속하고,
`D2` 와 `c` 는 `S -> B*` 치환에서 상쇄된다 (`+D2 + c` 와 `-D2 - c`).
남는 것이 `+Z` 다 — **누락도 이중 계수도 없다** (섭동 "G 에서 c 제거" 가
100,842/117,649 사례에서 깨지는 것이 그 확인이다).

**다른 자원과의 관계.**  `Qs <= Z` (∵ `Qs <= 2g - D2 <= 2g + d - D2 = Z`),
`e <= Z - Qs` (`H.envelope`, 라운드 158), `D2 = z - Z`.  이들은 `Z` 의
**소비처**이지 정의가 아니다.

## Phase 6 — `H` (그리고 `h` 가 아님)

`H := sum_joints max(w - 3, 0)` — **heavy 비용**.
`h := #{w >= 4}` — **heavy 개수**.  `1 <= h <= H` 이고 `w = 4` 인 조인트만
있으면 `h = H`, 무게 5 이상이 있으면 `h < H`.

**MASTER 가 쓰는 것은 `H` 다.**  (W3) 에서 `sum w = 2(P-1) + S + H` 이므로
무게 `w` 인 조인트는 길이에 `w` 를 기여하고, 그 초과분 `(w-3)_+` 가 정확히
`H` 에 들어간다.  `h` 를 쓰면 무게 5 이상 조인트마다 길이가 모자란다.

**실측** (`r160/certs/real_160.json`): `h != H` 인 단어 **166 개**, 그

## Phase 7 — `B*`

`B* := blocks - (O - c)`, `blocks := P - #(clean E 조인트) = S + 1 + D2`
(보조정리 F).  따라서 **닫힌형** `B* = S + 1 + D2 - O + c`.

* **양으로 기여하는 것**: `S` (유료 조인트), `D2` (dirty A), `c` (순수 순환),
  그리고 상수 `+1`.
* **빼는 것**: `O` (열린 궤도 수).
* **정확량인가 슬랙인가**: **슬랙**이다.  `H.extract` Claim 3 이
  `sum_i tok_i = B* - sigma` 를 주므로 `B* = sum_i tok_i + sigma` — 즉
  사슬들이 이미 연 궤도로 다시 들어가며 쓰는 **토큰 총량**에 사슬 간 궤도
  공유 `sigma` 를 더한 것이다.
* **절단/분할/반복과의 관계**: `blocks` 는 절단과 무관하게
  `P - cleanE` 이고 (clean E 간선은 절대 잘리지 않으므로 사슬로 쪼개도
  블록 수가 보존된다), `sigma >= 0` 이 사슬 간 궤도 공유를 잰다.
* **계수 `+1`**: `S` 가 (FO) 에 계수 `+1` 로 들어가고 `S = B* + O - 1 - D2 - c`
  이므로 `B*` 도 계수 `+1` 로 나온다.  `B*` 정의에서 `+1` 을 빼면 항등식이
  117,649 사례 **전부**에서 깨진다.

## Phase 14 — 종이 증명

> **MASTER 항등식 정리.**  `W` 를 `n` 글자 위의 고정 대표원 덮개라 하고
> `N = n!`, `HEX = (n-1)!`, `ORB = (n-2)!` 라 하자.  `P` 를 pass 수,
> `G = P - HEX`, `S = #{조인트 무게 >= 3}`, `H = sum (w-3)_+`,
> `O` 를 pass 진입점의 서로 다른 `tau`-궤도 수, `k = O - ORB`,
> `c` 를 순수 clean-E `beta` 순환 수, `D2` 를 type A 조인트 수,
> `z = G - c`, `Z = z - D2`, `blocks = P - #(clean E 조인트)`,
> `B* = blocks - (O - c)` 라 하자.  그러면
>
> `L = (n! + (n-1)! + (n-2)! + n - 3) + k + Z + H + B*`,
>
> `n = 6` 에서 상수는 `720 + 120 + 24 + 6 - 3 = 867` 이다.

**증명.**

*(i) 단어 수준.*  `W` 는 trim 되어 있으므로 첫 선택 창이 위치 0 에서
시작하고 마지막 선택 창이 위치 `L - n` 에서 끝난다.  따라서
`L = n + sum_{j<N} g_j`, `g_j` 는 연속한 선택 창 사이 간격이다.

*(ii) 간격 census.*  `g_j = 1` 은 정확히 pass 내부 단계이고, `N` 개 창이
`P` 개 pass 로 분할되므로 그런 단계가 `N - P` 개, 조인트가 `P - 1` 개다.

*(iii) 조인트 비용.*  `w >= 2` 이고 `w - 2 = [w>=3] + (w-3)_+` 이므로
`sum_joints w = 2(P-1) + S + H`.

*(iv) (FO).*  (i)–(iii) 에서
`L = n + (N-P) + 2(P-1) + S + H = (n + N + HEX - 2) + G + S + H`.

*(v) 치환.*  정의에서 `G = Z + D2 + c`, `S = B* + O - 1 - D2 - c`,
`O = ORB + k`.  (iv) 에 넣으면 `D2` 와 `c` 가 상쇄되고

```
L = (n + N + HEX + ORB - 3) + k + Z + H + B*.   ∎
```

> **비음성.**  `H >= 0` 은 정의상.  `G >= 0` 은 모든 육각형이 pass 를 가지므로.
> `tau`-궤도는 원소가 `n-1` 개이고 pass 진입점은 서로 다르므로
> `(n-1)O >= P`, 즉 `(n-1)k = (n-1)O - HEX >= P - HEX = G >= 0` 이라
> `k >= 0`.  `Z = 2g + d - D2` 이고 `D2 <= D2 + Qs <= R_int <= 2g` 이므로
> `Z >= d >= 0`.  `B* = sum_i tok_i + sigma` 이고 두 항이 음이 아니므로
> `B* >= 0`. ∎

때문에 수입이 기록되지 않아, 노드가 증명하지 않는 네 정리를 증명한 것처럼
보였다.  `what` 을 귀속대로 고치고 `derived_from` 에 기록했다.

### 수학적 결함 — **없음**
(FO) 와 치환, 상수, 계수, `H` vs `h`, 구표기 오염 — 어느 것도 결함이 없다.
이 감사가 새로 더한 것은 (a) 원시 단어에서의 단계별 재유도와 그 기계 검증,
(b) 상수의 **일반 `n` 닫힌형** `n! + (n-1)! + (n-2)! + n - 3` 과 네 구성
요소 분해, (c) 11 종 off-by-one 섭동이 전부 검출됨, (d) 비음성 네 개의
분리 증명과 하위 사실 제거 실험, (e) 역사적 두 형태의 대수적 동치와 현재형
과의 관계 정리, (f) 정리 경로 도달 집합에 구표기 오염이 0 임을 기계 확인한
것이다.

## 판정

* 항등식이 원시 단어 수준에서 첫 원리로부터 유도되었다 (§2, §14), 실제 덮개
  651 개에서 최대 절대 오차 0, 대수 상자 470,596 사례에서 불일치 0.
* 상수 867 이 네 구조적 출처로 분해되고 일반형
  `n! + (n-1)! + (n-2)! + n - 3` 으로 확인되었으며, 11 종 off-by-one 섭동이
  463 개 단어 전부에서 검출된다.  `n = 3, 4` 의 `t = 0` 단어가 독립 앵커다.
* `k`, `Z`, `H`, `B*` 가 정의되고 계수 `+1` 로 정확히 과금됨이 확인되었다.
* 요구되는 비음성 네 개가 **항별로 따로** 증명되었고, 하위 사실을 빼면
  각각 정확히 그 항이 무너진다.
* `H`/`h` 혼동이 배제되었다 — `h != H` 인 166 개 단어 전부에서 대입이
  깨지고, `h` 를 예산으로 넘기는 파일은 전부 경로 밖이다.
* 역사적 표기 오염이 배제되었다 — 경로 도달 33 개 파일에 구표기 0 건,
  현재 항등식에 `F` 없음.
* 하류 소비처 여섯 곳이 모두 같은 상수·항·계수·`H` 를 쓴다.
* 메타데이터 결함 M1 을 비파괴적으로 수리했고 불변 산출물 23 개의 `sha256`
  이 하나도 바뀌지 않았음을 확인했다.
