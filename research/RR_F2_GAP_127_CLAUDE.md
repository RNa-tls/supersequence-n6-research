**작성:** Claude 단독. **정리 라운드. 새 셀 폐쇄 없음, 두 원장 변경 없음.**
**라운드:** 127 (single-gap F = 2 free exit)
**원장:** INDEPENDENTLY AUDITED **4,782** · CLAUDE FULL-JOINT Q2 **6,396/6,396** — 변경 없음.
**라벨:** ROUND-127 PROVISIONAL · Claude 단독 · **독립 감사 없음** (Codex 쿼터 소진).

일반 `F = 2` 완성 스윕을 돌리지 않았고, `F ≥ 3` 으로 넘어가지 않았으며, 정리 A 를 전역으로
가정하지 않았고, 남은 경우가 해결되기 전에는 `f_out ≤ F + e` 를 쓰지 않았다.

---

> ### 라운드 128 정정 — 이 정리는 `G = 2` 의 정리다
>
> 이 문서의 "일반 `F = 2`" 는 전부 **`G = 2`**(다중도 초과 2)로 읽어야 한다.
> Codex 가 `F`(abandonment 수)와 `G`(`= P − 120`)의 동일시를 반증했기 때문이다.
>
> **정리 127.1 자체는 그대로 유효하다.**  그 증명은 `ν`-순환 구조 · 순서 보조정리 ·
> run 첫 pass 의 유일성 · 육각형의 여섯 단어가 여섯 궤도에 있다는 사실만 쓰고
> **abandonment 도 다중도 총합도 쓰지 않는다.**  정정된 이름은
> **"두 배진입 육각형 국소 보조정리"** — 서로 다른 두 육각형이 각각 정확히 두 번 진입되고
> 그 네 pass 가 전부 자유로 나가면 `e ≥ 2` 다.
>
> **철회하는 따름정리**(라운드 128 §17 에서 다시 쓴다):
> ~~"모든 일반 `F=2` 에서 `f_out ≤ F+e`"~~ → **`G = 2` 에서 `f_out ≤ G + e`**;
> ~~"정리 A 가 모든 `F=2` 에서 증명됐다"~~ → **`G = 2` 에서 증명됐다**;
> ~~"일반 `F=2` 는 `k` 칸이 넷"~~ → **`G = 2` 열이 넷**;
> ~~"일반 `F=2` 는 `H ≤ 3`"~~ → **`G = 2` 열이 `H ≤ 3`**.

## 1. 경우를 정의에서부터 펼친다 (§1)

반복 육각형을 `h`, `g` 라 하고 각각의 두 pass 를 **`ν`-순환 순서**로
`h1, h2` (`ν(h1) = h2`, `ν(h2) = h1`), `g1, g2` 라 하자.

**`f_out = 4` 의 정확한 뜻.**  `f_out` 은 `ω = 2` 인 **inter-run** 호의 개수다.
라운드 126 에 의해 (a) full pass 의 `ω=2` 후속 `τ(u)` 는 같은 궤도라 inter-run 이 될 수 없고,
(b) 짧은 pass 의 `ω=2` 후속은 언제나 궤도를 바꾸므로 inter-run 이다.  유형 B 의 짧은 pass 는
정확히 네 개이므로 `f_out ≤ 4` 이고, **`f_out = 4` ⟺ 네 pass 가 전부 자유 후속으로 나간다.**
특히 네 pass 중 어느 것도 walk 의 마지막 pass 가 아니다.

**`e = 1` 의 정확한 뜻.**  run 은 **같은 궤도의 극대 연속 pass 블록**이고
`e := r − O = Σ_q (runs(q) − 1)` 이다.  각 항이 음이 아니므로 `e = 1` 은
**정확히 한 궤도 `q*` 가 정확히 두 개의 run 을 갖고 나머지 궤도는 전부 run 이 하나**임을
뜻한다.  구현 약어가 아니라 이 정의만 쓴다.

## 2. 두 개의 자유 후속 2-순환 (§2)

라운드 126 의 보편 공식 — 진입 `u`, 길이 `len` 인 pass 의 자유 후속은 `τ(σ^{len}(u))`,
즉 **같은 육각형에서 순환적으로 다음 pass 의 진입 단어에 `τ` 를 적용한 것** — 을 단어 수준으로 쓴다.
`u_{h1}` 의 진입 단어를 `v`, `h1` 의 길이를 `b` 라 하면 `u_{h2} = σ^b(v)` 이고 `h2` 의 길이는 `6−b` 다.

    free(h1) = τ(σ^b(v))        = τ(u_{h2})   ∈ orb(u_{h2}) = orb(h2)
    free(h2) = τ(σ^{6−b}(σ^b v)) = τ(v) = τ(u_{h1}) ∈ orb(h1)
    free(g1) = τ(u_{g2}) ∈ orb(g2)
    free(g2) = τ(u_{g1}) ∈ orb(g1)

육각형의 여섯 단어는 **서로 다른 여섯 궤도**에 있으므로 `orb(h1) ≠ orb(h2)`, `orb(g1) ≠ orb(g2)`.
`τ` 는 크기 5 의 궤도에 자유롭게 작용하므로 `τ(u) ≠ u` — 자유 후속은 자기 자신이 아니다.

## 3. 왜 보조정리 E′ 만으로는 부족한가 (§3)

보조정리 E′ 는 "완전 자유 반복 육각형 하나마다 경우 (ii) 가 **적어도 하나**" 를 준다.
경우 (ii) 는 `orb(ν(p))` 에 run 이 둘 이상임을 **증명**하므로 분열 궤도를 하나 **요구**한다.

두 육각형이 각각 하나씩 요구하니 순진하게는 `e ≥ 2` 같지만, **두 요구가 같은 궤도로
충족될 수 있다** — `q*` 가 `h` 의 단어 하나와 `g` 의 단어 하나를 동시에 담으면 된다.
그것이 라운드 126 이 막지 못한 지점이고, **이 라운드의 핵심**이다.

**그리고 그 공유는 기하적으로 실제로 가능하다** (§7).  따라서 기하만으로는 닫히지 않는다.

## 4·5·6·7·8. 공유 가능성의 분류와 그 붕괴

### 4.1 `e = 1` 이면 육각형마다 경우 (ii) 는 **정확히 하나**

`h1`, `h2` 가 **둘 다** 경우 (ii) 이면 `orb(h2) = q*` 이고 `orb(h1) = q*` 인데
`orb(h1) ≠ orb(h2)` 이므로 모순.  보조정리 E′ 로 둘 다 경우 (i) 일 수도 없다.
따라서 **정확히 하나**다.  경우 (ii) 인 쪽을 `h1` 이라 이름 붙이면 (`ν` 가 2-순환이라
이름 교환은 대칭이다)

    orb(h2) = q*,   그리고 h2 는 경우 (i) 이므로 순서 보조정리로  h2 < h1.

`g` 도 같게 이름 붙이면 `orb(g2) = q*`, `g2 < g1`.
⟹ **`h2` 와 `g2` 가 둘 다 분열 궤도 `q*` 에 있다.**  이것이 §4 가 요구한 "공유" 의 정확한 형태다.

### 4.2 두 pass 는 `q*` 의 **서로 다른** run 에 있다

`A_h` := `h1` 의 자유 후속 `τ(u_{h2})` 가 시작하는 run.  `τ` 가 궤도를 보존하므로 `A_h` 는
`q*` 의 run 이고, `h1` 이 경우 (ii) 이므로 `A_h ≠ run(h2)`.  마찬가지로 `A_g ≠ run(g2)`.

`run(h2) = run(g2)` 라 하자.  `q*` 의 run 은 둘뿐이므로 `A_h` 와 `A_g` 는 **같은** 나머지 run 이고,
run 의 첫 pass 는 유일하므로 `τ(u_{h2}) = τ(u_{g2})`, 즉 `u_{h2} = u_{g2}`.
한 단어는 한 육각형에만 속하므로 `h = g` — 모순.

⟹ `R := run(h2)` 와 `R' := run(g2)` 가 `q*` 의 **두** run 이고 **`A_h = R'`, `A_g = R`** 다.

*(실측: `n = 6` 에서 기하 검사를 통과한 400개 국소 상태 전부에서 `τ(u_{h2}) ≠ τ(u_{g2})` 이므로
이 가지는 **언제나 공허하게 죽는다** — 즉 언제나 §4.2 의 결론에 도달한다.)*

### 4.3 교차 — 순서 모순 (§5, §10)

`h1` 은 자유로 나가므로 그 **바로 다음** pass 가 자유 후속 `τ(u_{h2})` = `A_h = R'` 의 첫 pass 다.
`g2 ∈ R'` 이므로

    h1 < start(R') ≤ g2   ⟹   **h1 < g2**.

대칭으로 `g1` 의 바로 다음 pass 는 `A_g = R` 의 첫 pass 이고 `h2 ∈ R` 이므로 **`g1 < h2`**.
§4.1 의 `h2 < h1`, `g2 < g1` 과 합치면

> **`g2 < g1 < h2 < h1 < g2`** — 선형 순서에서의 순환.  **모순.** ∎

### 4.4 순서 유형은 **전부** 지워진다 (§9)

이름 붙이기는 육각형마다 두 가지, 순서는 `4! = 24` 가지 — **96개 조합 전부**가 제약
`ci_h < cii_h`, `ci_g < cii_g`, `cii_h < ci_g`, `cii_g < ci_h` 를 위반한다 (실측 생존 **0**).

| 경우 (ii) 이름 | 제약 | 살아남는 순서 |
|---|---|---|
| `(h1, g1)` | `h2<h1`, `g2<g1`, `h1<g2`, `g1<h2` | **0** |
| `(h1, g2)` | `h2<h1`, `g1<g2`, `h1<g1`, `g2<h2` | **0** |
| `(h2, g1)` | `h1<h2`, `g2<g1`, `h2<g2`, `g1<h1` | **0** |
| `(h2, g2)` | `h1<h2`, `g1<g2`, `h2<g1`, `g2<h1` | **0** |

## 6. 전하(charge)의 단사성 (§6)

§6 이 요구한 강화는 "완전 자유 반복 육각형마다 **서로 다른** 분열 토큰이 필요하다" 였다.
**단사성을 가정하지 않았다** — 대신 §4 에서 **공유를 실제로 허용한 뒤** 그것이 순서 모순을
낳음을 보였다.  결과는 같지만 논증은 더 강하다: 단사성은 **결론**이지 가정이 아니다.

의존성 그래프 형태로 정확히 재면 (§11):

| 분열 토큰 수 | 만족 가능한 순서 | 판정 |
|---|---|---|
| **1** | **0 / 96** | **불가능** |
| 2 | 24 / 96 | 가능 — 예: `h2 < h1 < g2 < g1` |

> **분리된 2-순환 두 개에 필요한 최소 분열 run 수는 정확히 2 다.**
> 상한이 **tight** 하다 — `e = 2` 는 실제로 순서적으로 실현 가능하다.

## 7·8. 기하는 막지 않는다 (§7, §8)

궤도의 `n` 개 단어는 **서로 다른 `n` 개 육각형**에 있으므로 한 궤도는 한 육각형의 단어를
**최대 하나** 담는다.  그러나 서로 다른 두 육각형의 단어를 담는 것은 **가능하다**.

| `n` | 육각형 | 궤도 | 궤도가 만나는 육각형 수 | 궤도를 공유하는 육각형 쌍 | 한 쌍이 공유하는 궤도 최대 |
|---|---|---|---|---|---|
| 4 | 6 | 8 | 3 | 12 / 15 | 2 |
| 5 | 24 | 30 | 4 | 120 / 276 | 2 |
| **6** | **120** | **144** | **5** | **1,080 / 7,140** | **2** |

**즉 `q*` 가 `h` 와 `g` 의 단어를 동시에 담는 것은 기하적으로 전혀 문제가 없다.**
막는 것은 §4.3 의 순서다.

## 9. 정확한 국소 열거 (§12)

122-pass walk 을 열거하지 않았다.  국소 상태는 `(u_{h1}, b_h, u_{g1}, b_g, 경우 (ii) 이름)`
뿐이고, `S₆` 좌곱이 단순추이적이므로 `u_{h1}` 을 한 단어로 고정하는 것이 **완전 축약**이다.

| 단계 | `n = 4` | `n = 5` | `n = 6` |
|---|---|---|---|
| 원시 국소 상태 | 180 | 1,840 | **17,850** |
| 경우 (ii) 이름 붙이기까지 | 720 | 7,360 | **71,400** |
| **`q*` 공유** (기하 통과) | 72 | 192 | **400** |
| 자유 후속이 `q*` 에 착지 | 72 | 192 | **400** |
| `run(h2) = run(g2)` 로 죽음 | 0 | 0 | **0** (언제나 공허) |
| `q*` 의 서로 다른 두 run | 72 | 192 | **400** |
| **순서 제약 통과 (생존)** | **0** | **0** | **0** |

> **예외 설정은 존재하지 않는다.**  기하만으로는 400개가 살아남고, **순서가 400개를 전부 죽인다.**

## 12. 귀결을 정확히 다시 센다 (§15)

`f_out ≤ 2 + e` 와 `L = 869 + k + e + x + H − f_out ≤ 871` 에서

    k + e + x + H − f_out ≤ 2   그리고   f_out − e ≤ 2
    ⟹  **k + x + H ≤ 4**

이고 `F ≤ 5k` 에서 `k ≥ 1` 이므로:

| | 라운드 126 (무조건) | **라운드 127 (증명 후)** |
|---|---|---|
| `k` 범위 | `1 … 5` | **`1, 2, 3, 4`** |
| `F=2` 칸 수 | 5 | **4** |
| `max H` | 4 | **3** |
| `k + x + H` | ≤ 5 | **≤ 4** |
| 정리 A (`F=2`) | 미증명 | **증명됨** |

**표준 55칸 표와 정확히 일치한다.**  네 칸 `(1,2)·(2,2)·(3,2)·(4,2)` 가 다음 라운드의 대상이다 —
**이 라운드에서는 하나도 닫지 않았다** (§19).

## 13. 정리 A 의 상태 (§17)

| 범위 | 상태 |
