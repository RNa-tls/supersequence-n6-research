# H.fixedrep 독립 감사 — 고정 대표원 축약

**대상 노드**  `H.fixedrep`
**감사 라운드**  162  **기반 커밋**  `8396d05` (branch `round153-equality-coexistence`)
**산출물**  `r162/src/*.py`, `r162/certs/*.json`, 그리고 이 문서
**이 문서의 지위**  수리된 DAG(`r162/certs/dag_162.json`)의
`H.fixedrep.where` 가 가리키는 정본 감사 문서.  §1·§2·§21 이 정의와 종이 증명이다.

이 감사는 `H.fixedrep` **하나만** 다룬다.  `H.splice`, `H.master`,
`H.samehex`, `H.incidence`, `H.extract`, `H.envelope`, `H.tight`, `H.feas`,
`H.models`, `H.catalogue`, `H.wlog` 는 이미 인증된 의존으로만 인용한다.

---

## 요약 — 그리고 프롬프트 전제 하나의 정정

* **가장 먼저 밝혀야 할 것: 이 노드는 군 작용 정규화가 아니다.**
  `Phi` 는 단어를 **최대 중첩으로 다시 적고 trim 하는 재작성 연산**이다.
  기호 재라벨링도, 회전도, 켤레도, 좌/우 곱셈도 아니며 **길이를 줄일 수
  있다**.  따라서 프롬프트의 Phase 1·2·4·8·13·19 가 전제하는
  "군 `G`, 궤도, 횡단, 안정자, 켤레 `alpha' = pi alpha pi^{-1}`" 라는 틀은
  이 노드에 **적용되지 않는다**.  그 틀에 해당하는 것은 **별도 노드
  `H.wlog`**(좌 `S_n` 재라벨링)이며, 둘은 서로 다른 대상에 작용하고 **교환**
  한다 (§15).
* **보존되는 구조는 없다 — 보존될 필요도 없다.**  `Phi` 는 `beta`, `nu`,
  pass 분해, 심지어 **선택열 자체**를 바꿀 수 있다 (실측 169 사례).
  정규화가 넘겨주는 것은 **길이 하나뿐**이고, 하류가 쓰는 것도 그것뿐이다.
* **C3 다리는 실증적으로 닫혔다.**  고정 대표원이 **아닌** 덮개 **809 개**
  에서 **809 개 전부** C3 **만** 깨지고, 정규화 후에는 고정 대표원 조건과
  C3 와 다른 모든 절이 성립하며 덮개성과 `|W*| <= |W|` 가 유지된다.
* **전수 검증**: `n = 3` 길이 8–14 의 **모든 단어 7,171,173 개**를 열거해
  덮개 **43,242 개** 전부에서 T1–T6 위반 0 (최대 3 단계).
* **순환 없음**: `H.fixedrep` 의 증명은 splice 보조정리를 **하나도** 쓰지
  않으므로 `H.fixedrep -> C3` 는 일방향이다.
* **결함은 메타데이터 하나**: `what` 이 **존재성 절반만** 적어, 하류가 실제로
  소비하는 보조정리 5(b)(최단 연결자)와 5(c)(반복은 숨은 창)를 감춘다.
  비파괴적으로 고쳤다.

## Phase 1 — "고정 대표원" 의 정확한 정의

**고정되는 것은 단어의 철자법이다** — 첫 순열도, 첫 선택 창도, 알파벳
라벨링도, 회전도, 좌 `S_n` 작용도, 켤레류 대표도, `alpha`/`beta` 좌표도,
구별된 포트도 **아니다**.

덮개 `W` 에 대해 `q_1, …, q_N` (`N = n!`) 을 `n!` 개 순열의 **첫 출현**을
시간순으로 나열한 것, `i_1 < … < i_N` 을 그 위치, `g_j = i_{j+1} - i_j` 라 하고

```
omega(a, b) = min{ k in 1..n : a[k:] = b[:n-k] }      (없으면 n)
```

라 하자.  **정의**

```
Phi(W) := q_1  뒤에, 각 j >= 2 에 대해 q_j 의 마지막 omega(q_{j-1}, q_j) 글자를
          이어 붙인 단어.
```

> **`W` 가 고정 대표원이다  :⟺  `Phi(W) = W`.**

동치인 대수적 조건 (보조정리 5): `W` 는 trim 되어 있고
(`i_1 = 0`, `i_N + n = |W|`), **모든 선택 간격이 최대 중첩이다**:

```
g_j = omega(q_j, q_{j+1})   (j = 1..N-1).
```

**정본 출처**: `src/l6_fixed_representative_145.py` 10–30 행(정의),
118–124 행(`Phi` 구현), 145–176 행(`audit_fixed_point`).

## Phase 2 — 변환

`Phi` 는 **두 가지 일**을 한 번에 한다:

1. **trim** — `W` 를 `W_trim = W[i_1 : i_N + n]` 으로 자른다 (첫 선택 창
   앞과 마지막 선택 창 뒤의 글자를 버린다);
2. **재철자(re-spelling)** — 선택 창 열 `q_1..q_N` 을 **최대 중첩**으로 다시
   이어 붙인다.

**어느 것도 아니다**: 기호 재라벨링 · 좌 곱셈 · 우 곱셈 · 켤레 · 순환 이동 ·
뒤집기.  선택 창 **재색인**도 아니다 — 선택 창 열은 `W` 가 정하고 `Phi` 는
그것을 읽을 뿐이다.

두 단계는 각각 감사했다 (§4 trim 이 덮개를 잃지 않음, §5 재철자가 길이를
늘리지 않음).  `Phi` 는 **반복**되며(§3), 한 번으로 고정점에 닿지 않을 수
있다 — 실측 158 사례가 2 회 이상 필요했고 최대 3 회였다.

## Phase 3 — 존재성

> **보조정리 4.**  모든 덮개 `W` 에 대해 `m <= |W| - (n! + n - 1)` 인 `m` 이
> 있어 `W* = Phi^m(W)` 가 고정 대표원이고 `|W*| <= |W|` 다.

**증명.**  모든 덮개는 길이가 `n! + n - 1` 이상이다 (`n!` 개 첫 출현이 서로
다른 시작 위치를 요구하므로 마지막 시작 위치가 `>= n!-1`).  보조정리 3 으로
`Phi(V) != V` 이면 `|Phi(V)| <= |V| - 1` 이다 — 즉 **고정되지 않은 반복마다
길이가 정수 1 이상 줄어든다**.  보조정리 1 로 `Phi(V)` 는 다시 덮개이므로
반복이 영역을 벗어나지 않는다.  길이가 아래로 유계이므로 반복은 유한 번에
멈추고, 멈춘 곳이 고정점이다. ∎

**존재성 자체가 적재**임에 유의해 별도로 검증했다: `r162/src/exhaust162.py`
가 `n=3` 의 **모든 덮개 43,242 개**에서 반복이 종료하고 그 한계
(`|W| - (n!+n-1)`) 안에서 끝남을 확인한다 (최대 3 단계).  시작 배치에
제한을 두지 않았다 — 길이 8..14 의 **모든 단어**가 우주다.

## Phase 4 — 덮개성 보존

> `W` 가 `n!` 순열을 전부 덮으면 `Phi(W)` 도 덮는다.

**증명.**  `Phi(W)` 는 구성상 `q_1` 로 시작하고, `omega` 들의 부분합 위치에서
창이 정확히 `q_2, …, q_N` 이다.  따라서 `n!` 개 순열이 전부 창으로 나타난다. ∎

**trim 단계도 덮개성을 잃지 않는다.**  순열 창이 위치 `p < i_1` 에서
나타나면 그 순열의 첫 출현이 `<= p < i_1 = min_j i_j` 라 모순이다.
`p > i_N` 에서 나타나면 그 첫 출현 `i_j <= i_N` 이 `W_trim` 안에 있다. ∎

**군 작용이 아니므로 "대칭에 의해" 라고 말할 일이 없다.**  (좌 `S_n`
재라벨링이 창 위의 전단사를 유도해 덮개성을 보존한다는 것은 §15 에서 따로
증명한다 — 그것은 `H.wlog` 의 내용이다.)

실측: `r162/certs/real_162.json` 2,193 단어와
`r162/certs/exhaust_162.json` 43,242 덮개 전부에서 고정점이 덮개다.

## Phase 5 — 길이

**정리가 주장하는 것은 `|W'| = |W|` 가 아니라 `|W*| <= |W|` 다.**
실제로 2,193 단어 중 **2,162 개에서 길이가 엄격히 줄었다** (예: `n=4` 에서
60 → 33).

**증명 (보조정리 2).**  `|W_trim| = n + sum_j g_j <= |W|`,
`|Phi(W)| = n + sum_j omega_j`, 그리고 **`g_j >= omega_j` 가 항별로 성립**한다:
`g_j < n` 이면 두 창이 `n - g_j` 글자를 겹치므로
`q_j[g_j:] = q_{j+1}[:n-g_j]`, 즉 `omega_j <= g_j`; `g_j >= n` 이면
`omega_j <= n <= g_j`. ∎

**끝점 효과 점검**:

| 위험 | 판정 |
|---|---|
| 앞/뒤 trim | 덮개성을 잃지 않고 길이를 **줄이기만** 한다 (§4) |
| 선택 창 위치 | trim 은 모든 위치를 같은 양만큼 평행이동할 뿐 순서를 바꾸지 않는다 |
| 순환 단어 대 선형 단어 | **회전을 전혀 쓰지 않는다** (§14) |
| 더미 기호 `*` | `Phi` 층에는 `*` 이 없다 — 더미는 `beta` 구성에서만 나타나며 `Phi` 이후의 일이다 |
| 첫/마지막 간격 | 첫 창은 통째로 적고 마지막 창은 `omega` 만큼만 더한다; `|Phi(W)| = n + sum omega` 가 이를 정확히 센다 |
| 중첩 길이 | `omega <= n` 이고 고정점에서는 모든 간격이 `omega` 이므로 `<= n` |

길이를 **늘리는** 사례를 2,193 + 43,242 회 검사에서 하나도 찾지 못했다.

## Phase 6 — 선택 창은 보존되지 **않는다**

프롬프트는 보존을 전제하지만 **사실이 아니다**.  `Phi` 를 한 번 적용하면
선택열이 달라질 수 있다 — `Phi(W)` 안에서 어떤 순열이 지정된 자리보다
**앞선** 연결자 내부에서 먼저 나타날 수 있기 때문이다.  바로 그래서
`Phi` 를 **반복**해야 한다 (보조정리 4).

**실측**: 2,193 단어 중 **169 개에서 한 번의 `Phi` 가 선택열을 바꾸었고**,
158 개가 2 회 이상 반복을 필요로 했다.

따라서 올바른 서술은 다음과 같다:

> 선택 창·pass 분해·간격·조인트·`alpha`·`beta`·`nu` 는 **보존되지도
> 동변이지도 않는다**.  이들은 **고정점에서 새로 계산되는** 대상이고,
> 하류는 `W` 의 구조를 전혀 참조하지 않는다.

이것이 위험이 아닌 이유는 §10 의 전달 논증이 **길이만** 옮기기 때문이다.

## Phase 7 — 자원

| 자원 | 분류 | 근거 |
|---|---|---|
| `\|W\|` (길이) | **EQUALITY 아님, `<=` 로 전달** | 유일하게 전달되는 양 |
| `G`, `k`, `Z`, `H`, `B*`, `D2`, `Qs`, `R_int`, `g`, `c`, `d`, `S`, `P`, `O` | **NOT_USED_AFTER_NORMALIZATION** | 전부 `W*` 에서 **새로 계산**된다.  `W` 의 값은 어디에서도 쓰이지 않는다 |
| `a`, `bb`, `e`, `h` (사슬 예산) | **NOT_USED_AFTER_NORMALIZATION** | 절단 이후 개념이며 `W*` 에서만 정의된다 |
| 토큰 / 결손 | **NOT_USED_AFTER_NORMALIZATION** | 용량 모형 안의 양; `W` 와 무관 |
| `F`, `J` (구표기) | **해당 없음** | 현재 증명에 존재하지 않는다 (라운드 160 §10) |

**어떤 자원도 불변일 필요가 없다**는 것이 이 노드의 구조적 특징이다.
그래서 "자원이 바뀌면 하류가 왜 여전히 유효한가" 라는 질문은
"하류는 `W` 의 자원을 보지 않는다" 로 답해진다 (§10, §20 에서 기계 확인).

## Phase 8 — `alpha`/`beta` 변환 법칙

**켤레 법칙은 없다.**  `Phi` 는 군 원소가 아니므로 `alpha' = pi alpha pi^{-1}`
같은 식이 성립하지 않는다.  `W` 와 `W*` 는 길이도 선택열도 다를 수 있으므로
`alpha`, `beta`, `nu`, `T` 사이에 **자연스러운 대응이 없다** — `W*` 의 것들이
새로 정의될 뿐이다.  `beta`-성분의 대응도 없다.

**켤레 법칙이 성립하는 것은 좌 `S_n` 재라벨링**이고 그것은 `H.wlog` 다:
`pi` 가 알파벳을 재라벨링하면 창이 `pi` 로 옮겨가고 위치는 그대로이므로
선택열이 `pi` 로 옮겨간 같은 열이 되고, 그에 따라
`nu' = nu`, `alpha' = alpha`, `beta' = beta` (**지표가 같으므로 항등**) 이다.
이것을 §15 에서 증명·검증한다.

---

## Phase 9 — 육각형 / `tau` 기하

`Phi` 는 육각형·`sigma`·`tau`·clean-E·A/B 유형·순수 순환·`tau`-궤도를
**보존하지 않는다** (§6, §8).  이들은 `W*` 에서 새로 정의된다.
좌 `S_n` 재라벨링 아래에서는 전부 **동변**이다 (`sigma(pi w) = pi sigma(w)`,
`tau(pi w) = pi tau(w)`, 따라서 육각형·궤도·연결자 유형이 `pi` 로 옮겨간다) —
그러나 그것은 `H.wlog` 의 내용이고 `H.fixedrep` 에는 필요 없다.

## Phase 10 — C3 다리 (중심 의무)

**C3 의 정확한 진술** (라운드 161): 재배정된 간선은 완전 pass 끝점에서 나가는
**최단** 연결자다, 즉 `g_j = omega(end(v_{nu(i)}), q_{j+1})`.

**논리 사슬.**

1. 길이 `<= 871` 인 덮개 `W` 가 있다고 하자.
2. 보조정리 4 로 고정 대표원 `W*` 가 있고 `|W*| <= |W| <= 871`.
3. 보조정리 5(b) 로 `W*` 의 **모든 선택 간격이 `omega`** 다 — 이것이 C3 의
   가설 그 자체다.
4. 따라서 `W*` 에 splice 보조정리 A–F 전부(특히 C3), MASTER, 인구조사가
   적용되어 `|W*| >= 872` 다.
5. `|W*| <= 871` 과 모순.  그러므로 길이 `<= 871` 인 덮개는 **없다**.

**되돌림이 자명한 이유**: 4 에서 얻은 결론은 `W*` 의 **길이**에 대한 것이고,
2 가 `|W*| <= |W|` 를 주므로 `W` 의 길이에 대한 결론으로 바로 옮겨진다.
`W` 의 다른 성질은 전혀 필요하지 않다 — 이것이 §6·§7 의 "보존 불필요" 를
정당화하는 정확한 이유다.

**실증 (Phase 17 음성 대조)** `r162/certs/bridge_162.json`:

| | 값 |
|---|---:|
| 고정 대표원이 아닌 덮개 | **809** |
| 그중 **C3 가 깨진** 것 | **809** (전부) |
| 그중 C3 **말고** 깨진 절이 있는 것 | **0** |
| 정규화 후 고정 대표원 조건 성립 | **809** |
| 정규화 후 C3 및 모든 절 성립 | **809** |
| 정규화 후 덮개성 유지 · `\|W*\| <= \|W\|` | **809** |

예: `n=4` 에서 길이 60 → 33, 1 단계, 전(前) `{C3}` → 후(後) `{}`.

## Phase 11 — 한정사 감사

필요한 것은

```
forall W (덮개)  exists m  :  W* = Phi^m(W) 가 고정 대표원이고 |W*| <= |W|
```

이고, 인구조사는

```
forall W* (고정 대표원)  :  |W*| >= 872
```

다.  결합은 `forall W exists W* forall (W* 의 구조)` 이며 **존재 한정사를
가로지르는 전칭 한정사 이동이 없다**.  "하나의 `pi` 가 모든 대상에 동시에
통한다" 는 더 강한 형태는 **필요하지 않고 주장되지도 않는다** — `Phi` 는
`W` 마다 결정론적으로 자기 고정점을 만든다.

**고전적 실패 모드가 여기에 없는 이유**: 정규화의 선택이 이후 전칭 진술의
대상(`W*` 의 구조)을 정하지만, 그 전칭 진술은 **모든** 고정 대표원에 대해
증명되므로 어떤 선택이든 무방하다 (§12).

## Phase 12 — 유일성은 가정되지 않는다

고정 대표원은 **유일하지 않다**.  `n=3` 전수에서 덮개 43,242 개가
**서로 다른 고정 대표원 60 개**로 흘러갔고, 길이별 분포는
`9:6, 10:18, 12:12, 13:18, 14:6` 이다.

**유일성은 필요 없다**: 인구조사는 길이 `<= 871` 인 **모든** 고정 대표원의
좌표행을 배제하므로 어느 것이 선택되든 결론이 같다.

하류에서 "표준(canonical) 대표원" 을 암묵적으로 가정하는 곳이 있는지
검색했다 (§20): **없다**.  `Phi` 는 결정론적이지만 그 사실을 쓰는 곳도 없다.

## Phase 13 — 안정자

**군 작용이 아니므로 안정자 개념이 적용되지 않는다.**  대응하는 위험은
"여러 덮개가 같은 고정점으로 간다"(다대일) 인데, 이는 **무해**하다:
결론이 고정 대표원 전체에 대해 전칭이기 때문이다.  실측으로 43,242 → 60
의 강한 다대일이 일어나지만 아무 문제도 생기지 않는다.

좌 `S_n` 작용(H.wlog) 쪽의 안정자는 `Phi` 의 동변성(§15)과 무관하게
`H.wlog` 의 소관이다 — 이 감사는 그 노드를 건드리지 않는다.

## Phase 14 — 끝점 / 선형 단어

> **단어 회전은 전혀 쓰이지 않는다.**

`Phi` 는 (i) 앞뒤를 **자르고** (ii) 선택열을 **다시 적는다**.  시작 위치를
순환적으로 옮기지 않으며, 대상은 처음부터 끝까지 **선형 단어**다.
잘라내기는 덮개성을 잃지 않고(§4) 길이를 줄이기만 한다(§5).

`Phi` 가 시작 위치를 바꾸는 유일한 방식은 `i_1 > 0` 인 앞부분을 **버리는**
것이고, 그것은 길이를 줄이므로 허용된다.

## Phase 15 — `H.wlog` 와의 관계

| | `H.fixedrep` | `H.wlog` |
|---|---|---|
| 작용 대상 | **단어 `W`** | 용량 탐색 안의 **사슬 시작 포트** |
| 종류 | **재작성**(최대 중첩 재철자 + trim), 반복 | **좌 `S_n` 재라벨링** (군 작용) |
| 길이 | 줄일 수 있다 | 보존 |
| 단계 | 인구조사 **이전** (임의 덮개 → 고정 대표원) | 용량표 계산 **안** (시작 포트를 `123456` 으로) |

**같은 정규화를 두 번 적은 것이 아니고, 서로를 함의하지도 않는다.**
`H.wlog` 로 `H.fixedrep` 를 증명할 수 없다 (재라벨링은 길이를 줄이지
못하므로 비-고정 덮개를 고정 대표원으로 만들 수 없다).

**그러나 둘은 교환하며 동시에 부과할 수 있다.**

> **명제.**  모든 `pi in S_n` 에 대해 `Phi(pi . W) = pi . Phi(W)`.
> 따라서 `W` 가 고정 대표원 ⟺ `pi . W` 가 고정 대표원.

**증명.**  재라벨링은 위치를 바꾸지 않는 창 위의 전단사이므로 `pi.W` 의 창은
`W` 의 창에 `pi` 를 적용한 것이고, 순열 창 여부와 첫 출현 위치·순서가
그대로다.  따라서 `pi.W` 의 선택열은 `(pi q_1, …, pi q_N)` 이고 위치도 같다.
또 `a[k:] = b[:n-k] ⟺ (pi a)[k:] = (pi b)[:n-k]` 이므로
`omega(pi a, pi b) = omega(a, b)`.  두 사실을 `Phi` 의 정의에 넣으면
`Phi(pi.W) = pi.Phi(W)`. ∎

**검증** (`r162/certs/equivariance_162.json`): `n=3,4,5` 는 `S_n` **전수**,
`n=6` 은 표본 120 개 — 합계 **2,952 쌍에서 실패 0**.  위치 이동 0,
선택 창 재라벨링 불일치 0, 고정 상태 변화 0.

## Phase 19 — 군 작용 증명은 해당 없음

프롬프트가 요구하는 `(G, X, P, 횡단)` 형식은 이 노드에 **맞지 않는다**.
대응되는 올바른 추상 틀은 **정렬 종료(well-founded termination)** 다:

* 집합 `X` = `n` 글자 위의 덮개;
* 사상 `Phi : X -> X` (보조정리 1);
* 순위 함수 `|·| : X -> Z_{>= n!+n-1}`;
* `Phi(W) != W  =>  |Phi(W)| < |W|` (보조정리 2+3).

정렬 순위가 엄격히 감소하므로 모든 궤적이 고정점에 닿고, 그 고정점이
정규화된 부분집합 `Fix(Phi)` 의 원소다.  **"모든 궤도가 정규화된 부분집합을
만난다" 의 올바른 유사물은 "모든 `Phi`-궤적이 `Fix(Phi)` 에서 끝난다" 이며,
이는 추이성이 아니라 정렬성에서 나온다.**

가 있다.  이것은 **용량 퍼텐셜**이며 이 노드의 재작성 연산 `Phi` 와 아무
관계가 없다.  두 파일군은 겹치지 않으므로 증명에 영향이 없지만, 나중에
혼동하지 않도록 인증서에 `phi_name_collision` 으로 남겼다.

## Phase 21 — 종이 증명

> **고정 대표원 보조정리 (Fixed Representative Lemma).**
> `n >= 2`, `N = n!`.  `n` 글자 알파벳 위의 덮개 `W` 에 대해
> `q_1, …, q_N` 을 첫 출현 창, `i_1 < … < i_N` 을 그 위치,
> `g_j = i_{j+1} - i_j`, `W_trim = W[i_1 : i_N + n]`,
> `omega(a,b) = min{k in 1..n : a[k:] = b[:n-k]}` (없으면 `n`),
> `Phi(W) = q_1 · (q_2 의 마지막 omega(q_1,q_2) 글자) · … ·
> (q_N 의 마지막 omega(q_{N-1},q_N) 글자)` 라 하자.  그러면
>
> **(1)** `Phi(W)` 는 덮개다.
> **(2)** `|Phi(W)| <= |W_trim| <= |W|`.
> **(3)** `|Phi(W)| = |W|` 이면 `W = W_trim = Phi(W)`.
> **(4)** 어떤 `m <= |W| - (N + n - 1)` 에 대해 `W* := Phi^m(W)` 가
> `Phi(W*) = W*` 를 만족하고 `|W*| <= |W|`.
> **(5)** `Phi(W*) = W*` 인 `W*` 는 trim 되어 있고, 모든 선택 간격이
> `omega` 와 같으며, 선택되지 않은 모든 순열 창은 연결자 구간
> `[i_j, i_{j+1}+n-1]` 내부에 **엄격히** 들어 있는 **반복**이다.
>
> **따름정리.**  `min{ |W| : W 덮개 } = min{ |W*| : W* 고정 대표원 }`.
> 그러므로 **모든 고정 대표원에 대해 증명된 하한은 모든 덮개에 대한 하한이다.**

**증명.**
*(1)* 구성상 `Phi(W)` 의 창이 `omega` 부분합 위치에서 `q_1, …, q_N` 이다.
*(2)* `|W_trim| = n + sum g_j <= |W|`; `|Phi(W)| = n + sum omega_j`; 그리고
`g_j >= omega_j` — `g_j < n` 이면 두 창이 `n-g_j` 글자를 겹쳐
`q_j[g_j:] = q_{j+1}[:n-g_j]` 이므로 `omega_j <= g_j`, `g_j >= n` 이면
`omega_j <= n <= g_j`.
*(3)* 등식은 `|W_trim| = |W|` (즉 `W = W_trim`) 와 `sum g = sum omega` 를
강제하고, 항별 `g_j >= omega_j` 와 합쳐 **`g_j = omega_j <= n`** 을 준다.
모든 간격이 `<= n` 인 단어는 그 창 열과 간격으로 **완전히 결정**되고
(간격이 `n` 을 넘으면 결정되지 않는다 — 여기서는 넘지 않는다), 결정된 그
단어가 바로 `Phi(W)` 다.
*(4)* 덮개는 길이가 `N + n - 1` 이상이다 (`N` 개 첫 출현이 서로 다른 시작
위치를 요구하므로).  (3) 으로 `Phi(V) != V ⟹ |Phi(V)| <= |V| - 1` 이고
(1) 로 `Phi(V)` 가 다시 덮개이므로, 반복은 최대 `|W| - (N+n-1)` 회 만에
고정점에 닿는다.
*(5)* `W* = Phi(W*)` 이면 `|Phi(W*)| = |W*|` 이므로 (3) 의 증명이
`W* = W*_trim` 과 `g_j = omega_j` 를 준다.  마지막 절: 순열 창은 위치
`p in [i_1, i_N]` 에서 시작한다; `p = i_j` 면 선택창, 아니면 어떤 `j` 에 대해
`i_j < p < i_{j+1}` 이므로 연결자 구간 내부에 있고, 첫 출현 위치가 정확히
`{i_j}` 이므로 첫 출현이 아니어서 반복이다.
*(따름정리)* 모든 덮개에 (4) 를 적용하면 길이가 늘지 않는 고정 대표원이
있고, 고정 대표원 자신이 덮개다. ∎

> **C3 를 WLOG 로 가정해도 되는 이유.**  길이 `<= 871` 인 덮개 `W` 가
> 있다면 (4) 로 `|W*| <= 871` 인 고정 대표원이 있고, (5) 가 `W*` 의 모든
> 선택 간격이 `omega` 임을 주므로 splice 절 C3 의 가설이 충족된다.
> 따라서 구조층 전체가 `W*` 에 적용되어 `|W*| >= 872` 가 나오고 모순이다.
> 전달되는 것은 **길이뿐**이므로 `W` 의 어떤 구조도 보존될 필요가 없다. ∎
