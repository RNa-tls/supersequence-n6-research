## 1. successor-splicing 정리 — 형식적 서술

기하: `sigma` 는 여섯 자리 전체 회전(육각형 = `sigma`-순환, 6 창), `E = tau` 는 앞
다섯 자리 회전(궤도 = `tau`-순환, 5 원소).  단어를 첫/마지막 순열 창 밖에서 자른 뒤,
극대 pass 를 `(v_i, l_i)`, `i = 0..P-1` 로 시간순 색인한다.

**`nu`**:  `v_{nu(i)} = sigma^{l_i}(v_i)`.  완전 덮기가 각 육각형을 서로소 방향호로
분할하므로 이 pass 는 존재한다.  full pass 는 고정점.  비자명 `nu`-순환 = 갈라진
육각형.  `G = sum_h (m_h - 1) = 2` 이므로 **한 육각형이 세 겹(3-순환, Type A)**
이거나 **두 육각형이 두 겹씩(2-순환 둘, Type B)** 뿐이다.

**연산**:  모든 pass 를 **같은 진입 `v_i` 의 full pass** 로 바꾸고, 원래 조인트
`i -> i+1` 을 방향변 `nu(i) -> i+1` 에 **문자 그대로** 재배정한다.

**핵심 항등식** (이것이 전부를 떠받친다):

    sigma^(n-1)( v_{nu(i)} ) = sigma^(n-1)( sigma^(l_i)(v_i) )
                             = sigma^(l_i + n - 1)(v_i)
                             = sigma^(l_i - 1)(v_i)          (sigma^n = id)

즉 **full pass 로 바꾼 뒤의 마지막 창이 원래 조인트의 출처 창과 같다**.  따라서
끝점 쌍·덧붙는 실제 문자열·무게·중간 순열창 부재가 **모든 무게에서** 보존된다.

**부기**:  splice 후 모든 정점의 진입차수·진출차수 <= 1 이므로 그래프는 경로 하나와
서로소 순환들이다.  pass 진입 다중집합·궤도 합집합·`S`·`H` 는 이 단계에서 불변.
모든 weight-2 변은 이제 문자 그대로의 full-pass `E` 변 `v_{i+1} = E(v_{nu(i)})`.

**자름과 조각**:  heavy 변을 전부 자르고, heavy 없는 순환마다 원래 출처 색인이
가장 작은 유료 변 하나를 자른다(정준).  단일 경로 위상에서는 자유 `E`-블록을 경로
순서로 훑어 이미 본 육각형이 나오면 그 블록 앞의 유료 변을 자른다(<= 2 회).
어떤 자름도 자유 블록을 쪼개지 않는다.

**MASTER**:  `b_j = e_j + x_j`, `O_j` = 조각 `j` 의 등록 궤도 수,
`s = sum_j O_j - O'` (`O'` = 순수 자유 순환 제거 후 전역 궤도 수) 라 하면

    sum_j b_j + s = S + 1 - O + c            (MASTER)
    sum_j P_j = 122 - 5c,   sum_j D_j = 5k-2+5s,   m <= 3-c+h     (M139)

`S+H <= 25` 와 합쳐 `sum_j b_j + s <= 2-k+c-H =: B`, 그리고 좌변 비음성에서
`k+H <= 2+c <= 4`.

## 3. 다중 splice 합성 — CONFIRMED

**splice 자체에는 순서가 없다**: 모든 pass 를 동시에 full 로 바꾸는 하나의 전역
연산이지, 반복 적용되는 지역 수축이 아니다.  이것이 라운드 137 의 "정준 수축 순서"
난점을 통째로 없앤 부분이다.

순서가 문제될 수 있는 것은 이어지는 **자름**인데, 정리는 정준 규칙을 지정한다
(heavy 우선 → 최소 원래 출처 색인 → 경로 순서 훑기).  용량 논증이 실제로 요구하는
것은 조각 수 `m <= 3-c+h` 와 "자름이 자유 블록을 쪼개지 않는다" 둘뿐이고, 나는
1,510 개 컨트롤 전부에서 `m <= 3-c+h` 를 실측해 위반 **0** 을 얻었다.

위상 다섯 경우를 내 계산 `sigma_new = T . nu^{-1}` 로 재현했고 Astra 표와 성분
단위로 일치한다:

| 경우 | 순환 수 | 성분별 육각형 단순 |
|---|---:|---|
| A_F2 (시간순 3-순환) | 2 | 예 |
| A_F1 (역순 3-순환) | 0 (단일 경로) | 아니오 |
| B_disjoint | 2 | 예 |
| B_nested | 2 | 예 |
| B_crossing | 0 (단일 경로) | 아니오 |

**세분 불변성**(임의 pass 수로 가는 무제한 논증)을 균등 간격뿐 아니라 **무작위
비균등 위치 2,000 회**로 시험해 위반 **0**.  위상은 지지집합의 순환 순서에만
의존하므로 다섯 경우 표가 실제로 일반적이다.

## 4. 공유 궤도 회계 — CONFIRMED

`s` 는 가정되지 않고 **정의**된다: `s = sum_j O_j - O'`.  나는 1,510 개 컨트롤에서
조각별 궤도 집합을 내 기하로 직접 세어

* `s` 를 재계산해 기록과 **1510/1510 일치**,
* 조각별 `O_j` 를 재계산해 **전부 일치**,
* `O' = O - c` 를 독립 확인(순수 자유 순환 하나가 궤도 하나를 정확히 가져간다),
* `sum_j D_j = 5k-2+5s` 를 확인

했다.  "겹칠 때마다 5" 는 비형식 논증이 아니라 `D_j = 5O_j - P_j` 의 합에서
`sum_j O_j = O' + s` 를 대입한 결과다.  공유는 `S` 예산에서 지불되며(MASTER 의 좌변),
두 번 세어지거나 무시될 수 없다.

**순수 자유 순환의 구조**도 확인했다: 컨트롤 전체에서 819 개가 나왔고 **전부**
정확히 `n-1` 개 정점이 **단일 궤도** 안에 있다.  진입/진출차수 <= 1 이므로 그런
순환은 자동으로 성분 전체이고, 제거는 궤도 하나와 `n-1` 개 진입을 전역에서 없앤다.

## 5. 결함 회계 — CONFIRMED

`delta = F + e - f_out` 는 `(F, e, f_out)` 만의 함수이고, typed 분해
`delta = a + eta` 는 합을 보존한다(유료 상승 재진입이 같은 조인트에서 `a` 하나와
`eta` 하나를 내더라도 합은 `delta`).  108 개 typed 상태에서 항등식 위반 **0**.

행 공간에서 봉투 공간으로 가는 사상이 **항등식 하나**임을 유도했다:

    sum_j b_j + s = S + 1 - O + c = delta - F + x + c   <=   B = 2-k+c-H

`delta` 는 `(F,e,f_out)` 자리에, `x` 는 `S` 자리에, `H` 는 `L` 자리에 **서로 다른
항으로** 들어가므로 한 단위가 두 자리를 차지할 수 없다.  `k=1`·`k=2` 의 **모든
행 × 모든 c** 705 조합에서 위반 **0**.

## 6. x 회계 — CONFIRMED

전수 확인:

* full pass 의 `120` 은 **궤도 안**(위상 +2) — **720/720**;

## 9. 용량 모델 포함과 값 — CONFIRMED

**포함**.  splice 후 각 조각은 pass 가 전부 full, 무반복, 전부 경량이다.  이동

    tc = 1 (단일 경로) 이면 c = 0 강제;  tc = 3 (3-성분) 이면 c in {0,1,2}
    k in 1..4;  heavy multiset 은 H = sum(w-3) <= 3
    B = 2-k+c-H >= 0;   m = 3-c+h
    s in 0..B,  단 **m = 1 이면 s = 0 강제**;   b = B - s
    D_sum = 5k-2+5s;    required = 122-5c

`m=1 이면 s=0` 은 자명하다(조각이 하나면 두 조각에 걸친 궤도가 없다).  이 규칙이
없으면 `c=2` 에서 25 행이 나오고, 넣으면 **19** 행이 되어 Astra 와 맞는다.
합계 `8 + 11 + 19 = 38`, **모든 필드가 일치**(유일한 차이는 `[5,4]` vs `[4,5]`
표기 순서).  `k` 별 분포 24/10/3/1 도 일치.

**비중복성**: 38 행은 전부 서로 다른 완전 튜플이다.  `topology_components` 를 빼면
34 개 — `c=0` 인 네 행이 단일 경로/3-성분 두 위상 아래 각각 나타난다.  둘은 실제로
다른 배치이므로 "nonredundant" 는 이 의미에서 참이다.  보고서 본문 표가 9 행만
보이는 것은 `k=2` 의 두 위상 중복을 접어 쓴 것이며, JSON 은 10 행을 갖는다.

봉투가 **예산을 다 쓴** 형태(`b = B-s`)만 열거된 것도 건전하다: 실제 배치
`(s_act, b_act)` 에 대해 `s_env = s_act`, `b_env = B - s_act >= b_act` 인 봉투가
항상 있고 용량이 두 인자 모두에 단조이므로 그 봉투가 실제를 **지배**한다.

## 11. 등호 경우 E2 / E3 — CONFIRMED

38 개 중 **다섯** 행만 여유가 0 이다: `[4]` 짜리 셋(E2)과 `[4,4]` 짜리 둘(E3).

**열거 완전성을 먼저 증명했다.**  독립 재계산한 정확-결손 최대값 표
`[20,19,33,32,46,45,49,58,62,66,70,74,83,82]` (14,407,541 노드, 캡 없음) 로부터:

* 총결손 8 의 세 조각 최대도 **112 뿐이고 `(0,4,4)`/`(2,2,4)` 에서만** 달성.

즉 "전부 시험했다" 가 아니라 시험해야 할 것이 그것뿐임이 증명된다.

합법 weight-4 꼬리는 창마다 정확히 **13 개**(720/720 균일, 부분 합법 없음).

**E2**: 극값 사슬을 내가 전수 열거해 결손 4 에서 **1 개**(46 pass), 결손 9 에서
**12 개**(66 pass).  이음매 `2 순서 × 1 × 12 × 13 = **312**` 개, 생존 **0** —
전부 **육각형** 충돌(궤도 충돌이 아니라 문자 수준 충돌).

**E3**: 극값 사슬은 결손 0/2/4 에서 각각 1 개(20/33/46 pass).  6 개 순서분할 ×
13 = **78** 개 첫 이음매 중 70 충돌, **8 생존**.  그 8 개가 낳는 **104** 개 둘째
이음매가 **전부 충돌**, 최종 생존 **0**.

Astra 의 1/12, 312, 78·8, 104 와 **개수까지 정확히 일치**한다.

## 12. `(2,2)` 와 `(1,2)` 자원 공간 — CONFIRMED

우리 항등식만으로: `P = 120+G`, `O = 24+k`, `D = 5O-P`, `r = O+e`,
`S = (r-1)+x-f_out`, `L = 844+G+S+H`.  `G=2` 를 넣으면
`L <= 871  <=>  delta + x + H <= F + (2-k)`.
구조는 Type A(세 겹 육각형, `F in {1,2}`, `f_out <= 3`) 와 Type B(두 겹 둘, `F=2`,
`f_out <= 4`) 뿐이고 `e = f_out - F + delta >= 0` 이 `e` 를 자동으로 가둔다.

**`k=2`**: `P=122, O=26, D=8`, **73 개 행 / 78 개 heavy-refined 튜플**,
`q = delta+x+H` 히스토그램 **8/27/38**, `(delta,x,H)` 별 분해까지 Astra 표와
행 단위로 일치(8,8,5,8,5,5,11,7,7,9).

**`k=1`**: `P=122, O=25, D=3`, 길이 조건 `delta+x+H <= F+1`.  독립 유도 결과
**162 개 행 / 192 개 튜플**.  Astra 는 `k=1` 행을 열거하지 않고 봉투로 직행했으므로
이것은 감사가 새로 만든 정보다.  `k=1` 이 `k=2` 보다 두 배 이상 크다는 점에서
"마스터 정리가 `k=1..4` 로 서술되었으니 자동" 이라는 논법을 그대로 받지 않고
따로 확인할 이유가 있었다 — 확인 결과 **162 개 행 전부**가 봉투로 들어간다.
