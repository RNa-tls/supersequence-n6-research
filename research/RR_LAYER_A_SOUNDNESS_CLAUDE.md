## 1. 층 A 필요조건 (형식 진술, §1)

상태 `s`, 최종 cover `S` 에서 시작하는 모든 진짜 완성에 대하여:

* **정점** — 미래 pass 진입 의무. 빈 육각형 각각 1개, `r=0` 이면 fragment 수리 1개.
* **뿌리** — 현재 pass (엔드포인트 `p`).
* **진입 후보** — 그 육각형의 단어 중 **최종 궤도**(`open_orbits ∪ S`)에 속하는 것.
* **간선 `x → y`** — `x` 의 어떤 진입 후보에서 `σ^ℓ` 후 4개 joint 중 하나가 `y` 의 어떤
  진입 후보에 닿는다. `ℓ = 5`(fragment 수리만 `ℓ = 5 − c_f`).
* **부담** — *진짜 완성 ⟹ 뿌리가 모든 의무에 도달*. 그래프에 불가능한 간선이 더 있는 것은
  안전하고, **가능한 간선을 빠뜨리는 것만** 위험하다.

## 2. 사건 분류 — 표현되지 않는 중간 pass 는 존재할 수 없다 (§2)

핵심은 **개수 일치**다. 감사된 항등식 `121 − P = (빈 육각형) + (fragment)` 가 6,657 전부에서
성립하고, 미래 pass 시작 수는 정확히 `121 − P` 다. 모든 육각형은 pass 를 정확히 1회(fragment
육각형만 2회) 받고, 가득 찬 육각형은 이미 소진, 현재 육각형은 현재 pass 가 쓴다. 따라서

> **미래 pass ↔ 의무 정점은 전단사다.**

그러므로 `G5` 개방 · 이미 열린 궤도로의 `G5` · `E¹` · `E²` · 재진입 · fragment 수리 ·
`w2`/`w3` joint — **모든** 미래 매크로 사건은 "의무 → 의무"(또는 뿌리 → 의무) 전이다.
§2 가 지목한 위험한 경우 **C(정점 없는 중간 구간이 두 의무를 잇는다)는 발생할 자리가 없다.**
`E¹`/`E²`/재진입도 예외가 아니다 — 그것들 역시 하나의 pass 이고 곧 하나의 의무다.

## 4. `r=1` 수리 port 의 source 소진 (§4)

수리된 육각형의 두 등록 port `a`, `b` 는 **둘 다 이미 발사를 마쳤다**:
(i) 그 육각형은 가득 차 있고, (ii) 현재 육각형이 아니며(현재 육각형의 방문 칸은 1개),
(iii) 모든 pass 는 떠날 때 정확히 1개의 매크로 edge 를 발사하고, (iv) 각 port 는 1회만
발사한다(라운드 87, 감사됨). 아직 발사하지 않은 pass 는 **현재 pass 하나뿐**이다.
따라서 `a`, `b` 는 미래 source 가 될 수 없고, 라운드 94b 의 CONTROL R1-B 는 **의도적으로
불가능한 공급**을 넣은 것이다 — 거기서도 155/198 이 살아남았다는 사실은 그만큼 강한 증거다.

## 5. `G_MAX` — 그리고 이 라운드의 진짜 발견 (§9)

모든 의무에서 `ℓ = 0..5` 를 전부 허용하는 의도적 초과대근사로 재판정했다.

| 후보 폐쇄 228 | |
|---|---|
| 구제됨 | **227** |
| 여전히 도달 불가 | **1** |

> **payoff 전체가 `ℓ = 5` 제약 하나에 달려 있다.** `ℓ` 기하 불일치로 배제된 10,079 전임자가
> 정확히 `G_MAX` 가 되돌리는 것이다.

`ℓ=5` 는 추측이 아니라 감사된 단일 short pass 정리다(예산 `1−r`, Codex 확인). 빈 육각형에서
`ℓ<5` 로 떠나면 abandonment 이고 `F=2 > TARGET_F` 이며, `r=1` 이면 미래 `ℓ<5` 는 0개다.
그러나 **여유 마진이 전혀 없다** — 이 제약이 한 군데라도 틀리면 228 은 227 을 잃는다.
§9 의 지침대로 `G_MAX` 결과는 원장에 쓰지 않는다.

## 7. 하지 못한 것 (§5)

**실현 이력 컷 재구성은 불가능하다** — 아카이브에 보존된 것은 frontier 상태(접두)뿐이고
**리터럴 접미(완성)가 없다.** 새 탐색 없이는 ground-truth 접미를 얻을 수 없고 그것은 §12
금지다. 그래서 §5 의 "실제 접미로 검증" 은 **수행하지 못했으며**, 대체물(라운드 94b 의
등록 port 도달성 대조, 그리고 위 §3 의 전수 전임자 분류)만 있다. 이 공백은 그대로 보고한다.
