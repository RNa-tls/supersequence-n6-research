## 0. Codex 정정 2건 — 수용 및 기록

### (1) 2-예외 보조정리 증명 보강

라운드 85의 fragment-only 설명은 **"이중 pass 육각형이 정확히 fragment 하나"** 라는 연결을
명시하지 않아 불완전했다. 감사에서 수리된 논증을 앞으로 표준으로 삼는다:

> 각 pass 는 등록된 시작점을 정확히 하나 가지므로 **총 pass 수 = `P` = 121**. 육각형 120개가
> 각각 최소 1 pass 를 받으므로 잉여 pass 수 = `P − 120 = 1 = F`. 즉 **이중 pass 를 받는
> 육각형의 수는 정확히 `F` 개**이고 `F = 1` 이므로 정확히 하나이며, 그것이 abandonment 로
> 생긴 fragment 다. 여기에 무-abandonment / fresh-hexagon 구조(새 육각형에 든 pass 는
> `ℓ = 5` 로 채우고 나온다)를 결합하면 `ℓ < 5` 로 출발 가능한 매크로 간선은 현재 pass 와
> fragment 수리 pass 뿐 — **최대 2개**.

결론(`≤ 2`)과 라운드 85의 13개 폐쇄는 **변경 없음**. `P = 120 + F = 121` 형태를 모든 향후
참조에서 사용한다.

### (2) 최소 예외 히스토그램 정정

| | 0 | 1 | 2 | ≥3 |
|---|---|---|---|---|
| ~~라운드 85 (Claude)~~ | 6,396 | ~~147~~ | ~~101~~ | 13 |
| **감사 확정** | **6,396** | **231** | **17** | **13** |

**원인은 내 코드의 실제 버그다.** `x2_census.py` 의 `solve()` 가 `e <= maxexc` 인 첫 cover
해를 찾자마자 `return True` 로 중단하므로, 기록된 `st['minexc']` 는 *발견된 첫 해의* 예외
수이지 모든 cover 해에 걸친 최소값이 아니다. 그래서 1/2 구간이 과대평가됐다.

**폐쇄 판정에는 영향이 없다.** UNSAT 13개는 모든 cover 해를 완전 열거해 전부 `≥3` 임을
확인한 것이므로 유효하고, 독립 확인도 통과했다. 오류는 히스토그램의 1/2 분할에 국한된다.

## 1. 위상 표기 Z3 전이표 (§1)

노드는 `(궤도 q, 위상 f)` 720개. 착지 위상을 **궤도로 몫하지 않고** 보존한다.

| 관계 | 간선 | out-degree |
|---|---|---|
| **G5_phase** (`ℓ = 5`) | **1,440** | **2** (균일) |
| **Gshort_phase** (`ℓ < 5`) | 10,800 | 15 (균일) |

`ℓ = 5` 의 기하는 완전히 결정적이다: `w3:120` 은 **720/720 전부 같은 궤도**(= `E²`),
`w3:201` 과 `w3:210` 은 **720/720 전부 다른 궤도**. 그래서 `G5_phase` 의 out-degree 가
정확히 2다. `2 + 15 = 17` 로 라운드 84가 측정한 위상 수준 out-degree 17 과 일치한다.

## 2. Opening 직후 무엇이 남는가 (§2)

엔진에서 직접 확인:

```
joint target = (2,3,4,1,5,0)   착지 궤도 138, 착지 위상 2
새 endpoint  = joint target 그 자체        endpoint 위상 = 2
등록 여부    = True (착지 port 가 곧 등록 port)
```

> **Z3 opening 직후 위상 자유도는 전혀 없다.** 착지 port = 등록 port = 현재 위상.

## 3. 국소 위상 수리 폐포 (§3)

`ℓ = 5` 의 같은 궤도 이동은 정확히 둘뿐이다:

| 이동 | 위상 변화 | 빈도 | 비용 |
|---|---|---|---|
| `E¹` (`w2:10`) | **+1** | 720/720 | `ΔNdef = ΔΦ = ΔO = ΔF = 0` |
| `E²` (`w3:120`) | **+2** | 720/720 | `ΔNdef = +1` (`R_cap` 예산) |

**`E¹` 하나만으로 5-주기 전체가 생성된다.**

건전성을 위해 `E¹` 의 적법성을 과대근사해야 한다: `ℓ = 5` 조건은 라운드 85 보조정리에 의해
자동 만족되고(미래의 모든 pass 는 fresh 육각형에 진입한다), target 미방문은 반증할 수 없으므로
참으로 간주해야 한다. 게다가 `E¹` 은 `P` 를 1 소비할 뿐인데, 최종 25궤도 × 5 port 중 121개가
등록되므로 **궤도당 평균 4.84 port 가 등록된다** — 궤도 안에서 위상을 옮기는 것은 사치가
아니라 정상적인 진행이다.

> **결론: 국소 수리 폐포 = 5개 위상 전체. 위상 상관은 완전히 소실되고 관계는 궤도 수준
> 자유도로 붕괴한다.**

## 6. 적대적 천장 측정 (§6)

라운드 82와 같은 방식으로, 결론을 내기 전에 방향의 최대치를 잰다. 국소 수리를 **전면 금지**한
(명백히 UNSOUND한) 가정 — `A` 의 시작 위상만 자유로 두고 연쇄 내부는 착지 위상 고정:

| | |
|---|---|
| SAT | **6,639** |
| UNSAT (coverability) | 8 |
| UNSAT (forced excess) | 10 |
| **닫히는 총계** | **18 (0.27 %)**, 전부 `c = 5` 밴드 |

도달 candidate 비율: **6,570 상태(98.7 %)에서 100 %** 도달. `G5_phase` 의 out-degree 가

> **따라서 전역 occupancy 를 추가해 `E¹` 붕괴를 막더라도, 이 방향(위상 연쇄 + cover)의

## 9. 구조적 진단

위상만으로는 부족하고, `E¹` 을 막으려면 **어느 port 가 이미 방문됐는지에 대한 전역
occupancy** 가 필요하다. 그러나 천장 측정이 보여주듯 그것을 넣더라도 이 조합에서는
**18개(0.27 %)가 상한**이다. 따라서 전역 occupancy 추적(720개 방문창)은 이 방향에서는
정당화되지 않는다 — 비용은 크고 상한은 0.3 % 미만이다.

살아남는 지배적 이유는 라운드 81 이후 계속 같다: **slack-cover 는 어떤 `K`-부분집합이
가능한지를 제약할 뿐 개별 궤도의 사용 가능 여부는 거의 제약하지 않으며**, 그래서 어떤
위치 정보를 붙여도 도달 가능한 궤도 중 하나는 거의 항상 유효한 cover 에 속한다.

**이 프로젝트는 `L₆ ≥ 872` 를 증명하지 않았으며, 여기의 어떤 내용도 그에 관한 주장이 아니다.**
