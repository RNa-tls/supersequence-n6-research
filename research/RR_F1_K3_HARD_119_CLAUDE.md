# 라운드 119 — `(3,1)` hard three: 구조로 여섯 분기로 쪼개고 넷을 배제한다

**작성:** Claude 단독. **정리 라운드 + 유한 전수 탐색. 두 원장 변경 없음.**
**라운드:** 119 (hard-three completion)
**원장:** INDEPENDENTLY AUDITED **4,782** · CLAUDE FULL-JOINT Q2 **6,396/6,396** — 변경 없음.
**라벨:** ROUND-119 PROVISIONAL · CLAUDE 단독 · **독립 감사 없음** (Codex 쿼터 소진).

`(2,1)`·`(1,1)` 로 넘어가지 않았고, 라운드 118 이 이미 닫은 하위경우는 다시 돌리지 않았다.

---

## 0. 결과

> **`(3,1)` 은 여전히 열려 있다.** 그러나 라운드 118 이 남긴 **세 하위경우**를 구조로
> **여섯 분기**로 쪼갰고, 그중 **넷을 전수로 배제**했다.
>
> * **케이스 A (`e=1,x=1,f_out=2,H=0`) 는 완전히 닫혔다** — 두 분기 `A4`·`A5` 모두, 다섯 분할 전부.
> * 케이스 B 는 `B_i` 가 닫히고 **`B_ii` 하나만** 남았다.
> * 케이스 C 는 `C2` 가 닫히고 **`C1` 하나만** 남았다.
>
> 즉 미해결 부분이 **3개 하위경우 → 2개 명명된 구조 분기**로 줄었다.
> **칸 폐쇄는 없다. Claude 가 닫은 바깥 칸은 6/55 그대로다.**

## 1. 세 케이스를 고정한다 (§1)

라운드 118 의 자원 표에서 다시 유도한다 (`P=121`, `O=27`, `D=14`, `L=845+S+H`,
`S = 26+e+x−f_out`, 보조정리 E `f_out ≤ 1+e`).

| 케이스 | `e` | `x` | `f_out` | `H` | `S` | `r` | `t` | `b` | X–Y 순서 |
|---|---|---|---|---|---|---|---|---|---|
| **A** | 1 | 1 | 2 | 0 | 26 | 28 | 1 | 1..5 | X 가 항상 먼저 |
| **B** | 2 | 0 | 2 | 0 | 26 | 29 | 1 | 1..5 | X 가 항상 먼저 |
| **C** | 1 | 0 | 2 | 1 | 25 | 28 | 2 | 1..5 | X 가 항상 먼저 |

`S+H ≤ 26` 을 셋 다 등호로 만족한다. **빠진 자원 행은 없다** — 라운드 118 의 7행 중 나머지
넷은 이미 `UNSAT_COMPLETE` 다.

`X` 는 walk 순서상 먼저 오는 `h*` pass(진입 `v`, 길이 `b`), `Y` 는 나중(진입 `σ^b(v)`,
길이 `6−b`)이다. 세 케이스 모두 `f_out = 2` 이므로 **두 짧은 pass 가 모두 자유 호로 나간다**.
따라서 보조정리 E 의 논증이 그대로 적용되어 **X 는 항상 경우 (ii)** 다
(경우 (i) 은 Y 를 X 앞에 놓아 순서에 모순).

## 2. 케이스 A — `A4` / `A5` (§2)

`Y` 는 경우 (i) 로 강제된다 (`e=1` 이라 `orb(Y)` 는 두 번째 run 을 가질 수 없다).
그러면 `orb(Y)` 의 run 이 `τ(entry_Y)` 에서 시작해 `Y` 에서 끝난다. phase 는
`p+1` 에서 `p` 까지 **+4** 만큼 나아가야 하고, 걸음은 `τ`(+1) 과 `W3a`(+2, 비용 1)뿐이다.
`a` 번의 +1 과 `j` 번의 +2 로 `a + 2j = 4`, 블록의 pass 수는 `a+j+1`, 그리고 `x = 1` 이므로 `j ≤ 1`.

| | `j` | `a` | 블록 pass 수 | X–Y 간격 |
|---|---|---|---|---|
| **A5** | 0 | 4 | 5 | **5** |
| **A4** | 1 | 2 | 4 | **4** |

**두 가지가 전부다** (`j=2` 는 `x=1` 을 넘는다).

* **A4** — 유일한 `W3a` 점프가 **블록 안**에 있다. `+2` 가 세 걸음 중 어디에 오는지에 따라
  블록의 phase 열은 `(+1,+1,+2)`·`(+1,+2,+1)`·`(+2,+1,+1)` **세 가지**뿐이다.
  점프가 여기서 소진되므로 **walk 의 나머지는 `x = 0`** 이다.
  재방문되는 궤도는 `orb(X)` 다 (`e=1` 의 유일한 여분 run).
* **A5** — 블록은 순수 `τ`-블록(5 pass)이고 **점프는 반드시 블록 밖**에 있다.

탐색기에서 A4 는 `ygap = 4`, A5 는 `ygap = 5` + `bforce`(블록 이동을 `τ` 로 강제)로 넣는다.

## 3. 케이스 B — `B_i` / `B_ii` (§3)

`orb(X)` 는 언제나 두 run 을 갖는다 — `R_X^end`(X 에서 끝남)와 `R_X^start`(`τ(entry_X)` =
Y 의 자유 후속에서 시작). `R_X^start` 는 Y 뒤에서 시작하고 `R_X^end` 는 X 에서 끝나므로
**둘은 언제나 서로 다른 run** 이다.

`Y` 가 경우 (i) 인지 (ii) 인지로 갈린다.

* **B_i — `Y` 경우 (i)**: `orb(Y)` 의 run 하나가 `τ(entry_Y)` 에서 `Y` 까지 이어진다.
  `x = 0` 이므로 순수 `τ`-블록, **간격 정확히 5**. 남은 `e` 한 단위는 어디든 갈 수 있다.
* **B_ii — `Y` 경우 (ii)**: `orb(Y)` 도 두 run 을 갖는다. `orb(X)` 와 합쳐 `e = 2` 가 **정확히**
  소진되므로 **다른 모든 궤도는 run 이 하나뿐**이다.

**B_ii 의 순서형은 유일하다.** `R_Y^start` 는 X 바로 뒤(위치 `p+1`)에서 시작하고
`R_Y^end` 는 `Y`(위치 `q > p`)에서 끝난다. 둘이 다른 run 인데 `R_Y^end` 가 `p+1` 보다 앞에서
끝난다면 `q ≤ p` 가 되어 모순이므로 **`R_Y^end` 는 `R_Y^start` 뒤**다. 따라서

    [R_X^end … X]  X  [R_Y^start …]  …  [R_Y^end … Y]  Y  [R_X^start …]

**순환 패턴은 경로에서 불가능하므로** 이 하나뿐이다(§3 이 요구한 path-ordering 제거).

여기서 두 개의 **강제 신선도**가 따라 나온다.

> `orb(Y)` 의 run 은 정확히 둘(`R_Y^start`, `R_Y^end`)이므로 **`orb(Y)` 는 X 이전에 방문될 수
> 없다** — 즉 **X 의 자유 후속은 반드시 신선한 궤도로 들어간다.**
> 같은 이유로 `R_X^end` 는 `orb(X)` 의 첫 run 이다.

탐색기에 `revonly`(두 번째 run 을 `orb(X)`·`orb(Y)` 로 제한)와 `yfresh`(X 의 자유 후속이
신선한 궤도로 들어가야 함)로 넣었다.

## 4. 케이스 C — 무거운 변은 어디에 있을 수 있는가 (§4, §5)

`C` 는 `e=1, x=0, f_out=2, H=1` 이므로 라운드 117 의 강제 기하가 그대로 살아 있다:
**X–Y 간격은 정확히 5** 이고 그 사이는 `orb(Y)` 의 완전한 `τ`-블록이다.

무게-4 변 하나가 어디에 올 수 있는지 정확히 따진다.

| 위치 | 가능한가 | 근거 |
|---|---|---|
| 강제 `τ`-블록 **안** | **불가** | 블록의 joint 는 궤도 내부인데 **무게-4 이동은 13/13 이 항상 궤도를 바꾼다**(라운드 118 census, 720/720) |
| **X 의 탈출** | **불가** | `f_out = 2` 가 X 의 탈출을 자유(무게 2)로 **강제**한다 |
| **Y 의 탈출** | **불가** | 같은 이유 |
| **X 로 들어오는 joint** | 가능 | X 앞 영역에 속한다 |
| X 앞 (그 외) | 가능 | — |
| Y 뒤 | 가능 | — |

> 따라서 영역은 **정확히 둘**이다: **`C1` = 무게-4 변이 X 보다 앞**, **`C2` = Y 보다 뒤**.
> 이것을 DFS 매 노드에서 13개 tail 을 다는 대신 **탐색 전 조건**으로 넣는다(§5).

## 5. 새로 넣은 정확한 프룬 (§6, §7)

라운드 118 의 `dcap` 은 **한쪽** 프룬이다 — "이미 떠난 궤도들의 결손 합 ≤ `D`".
`O = 27` 이 **정확히** 고정이므로 반대쪽도 강제된다.

> ### 접두 용량 하한
>
>     남은 pass = 121 − passes
>     담을 자리 =   (5 − |현재 궤도의 사용 phase|)              현재 run 연장
>                 + 5 · (27 − orbits)                          아직 안 쓴 궤도
>                 + (떠난 궤도 결손 중 큰 것 `ECAP − rev` 개)   재방문으로 회수
>
> 남은 pass 가 이보다 크면 **어떤 실제 walk 도 될 수 없다.**

정확한 상한이므로 실제 walk 의 가지는 자르지 않는다. `dcap` 과 합쳐 **양쪽 회랑**이 된다.

**정직한 측정.** 이 프룬은 **이미 닫힌 실행들의 노드 수를 하나도 바꾸지 않았다** —
라운드 117 `(4,1)` 하위경우 A `b=1` 은 여전히 정확히 **8,538,340,341** 노드,
라운드 118 `G1 b=1` 은 **750,682,008**, `G3 b=1` 은 **976,708,569** 다. 그 탐색들이 죽는
지점에서는 회랑이 이미 닫혀 있기 때문이다. **이번 라운드에서 실제로 효과를 낸 것은
프룬이 아니라 §2–§4 의 구조 분기다.**

| 분기 | 자원 | 구조 | 왜 남았는가 |

| **`B_ii`** | `e=2, x=0, f_out=2, H=0` | `orb(X)`·`orb(Y)` 만 두 run, 순서형 유일, `orb(Y)` 는 X 시점에 신선 | `revonly` + `yfresh` 를 넣고도 `b=1` 에서 **3×10¹⁰ 노드 초과** |

## 8. 시도했지만 효과가 없었던 것 (정직한 기록)

* **접두 용량 하한**(§6/§7) — 정확하지만 닫힌 실행의 노드 수를 전혀 바꾸지 못했다(§5).
* **세그먼트 용량 상한의 해석적 사용**(§12 가 제안한 "무거운 변이 용량을 최대 `C` 만큼 올린다")
  — 라운드 115 표로 계산하면 `C` 의 다섯 조각 상한이 `BESTSEG[5][19] ≈ 217 ≥ 121` 이라
  **해석적으로 닫히지 않는다.** 케이스 A·B 도 마찬가지다.
* **추가 대칭**(§11) — `S₆` 좌곱이 720 단어에 단순 추이적이므로 첫 진입 단어 고정이 이미
  완전한 축약이다. X↔Y 교환은 walk 순서가 구별하므로 대칭이 아니고, `b ↔ 6−b` 는 이동 집합이
  역방향 대칭이 아니라 대칭이 아니다. **증명된 자기동형은 더 찾지 못했다.**
* **메모/우세**(§10) — 미래 가능성에 영향을 주는 좌표(사용 육각형 120비트 + 궤도별 phase)가
  상태 그 자체라 압축이 되지 않는다. **옛 spent-only 메모 버그를 되풀이하지 않기 위해
  불완전한 키는 쓰지 않았다.**
