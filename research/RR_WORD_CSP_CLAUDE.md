## 1. W-A 생존 모집단 재구성 (§1)

라운드-100 아카이브의 19,176 쌍에서 W-A 통과분만 다시 셌다(옛 `UNIQUE_PATH` 수치는 쓰지 않는다).

| | |
|---|---|
| W-A 통과 (상태, cover) 쌍 | **15,781** |
| W-A 통과 상태 | **4,230** |
| cover 수 히스토그램 | `1`: **1,259** · `2–5`: 2,164 · `6–20`: 771 · `>20`: 36 (최대 93) |

라운드 98 의 `UNIQUE_PATH` 1,112 와 다르다 — 그때는 W-A 이전 기준이었고, W-A 가 cover 를
개별적으로 지우면서 유일-cover 상태가 1,259 로 **늘었다**.

## 2. 정련된 간선 관계 (§2)

정점을 `(의무 h, 구체 진입 단어 u)`, 간선을

```
(h,u) → (h',v)   ⟺   v = WORD_NEXT(u, ℓ(h), h')
```

로 둔다. `WORD_NEXT` 가 부분 함수(라운드 99/100, 구조적 증명)이므로 **후속 의무를 고르면
구체 단어가 결정된다** — 단어 위의 분기는 없다. 아직 "육각형당 단어 하나" 를 전역으로 강제하지
않는다.

## 3. 도메인 크기 census (§9) — 이 라운드의 핵심 측정

W-A 통과 15,781 쌍의 모든 의무(총 **1,697,539**개)에 대해:

| `|C(h)|` | 1 | 2 | 3+ |
|---|---|---|---|
| 개수 | **1,645,277** | 52,262 | **0** |
| 비율 | **96.92 %** | 3.08 % | 0 |

**최댓값이 2다.** 의무마다 진입 단어 후보가 하나 아니면 둘뿐이다. 쌍당 비-singleton 의무는
평균 **3.3개**(107–108개 중)이고, **모든 의무가 singleton 인 쌍은 233개(1.5 %)** 다.

이것이 이 라운드의 방향을 결정했다 — 도메인이 이미 거의 결정돼 있으므로 CSP 전파가 지울
것이 거의 없다.

## 4. W-C — 호 일관성 (§4, §5)

삭제·거부 규칙과 근거:

| 규칙 | 내용 | 근거 |
|---|---|---|
| **(P)** | `u ∈ C(h)` 가 ROOT 직행도 아니고 살아 있는 어떤 `(h',u')` 에서도 `WORD_NEXT(u',ℓ(h'),h)=u` 가 아니면 **삭제** | 완성 경로에서 `h` 는 정확히 한 번 진입되고 그 진입은 ROOT 또는 다른 의무에서 온다 |
| **(S)** | 후속이 전혀 없는 의무가 **2개 이상**이면 거부 | terminal 은 전역에서 하나 (라운드 96 §3 의 전역 허용량) |
| **(R)** | 살아 있는 도메인만으로 재도달성이 깨지면 거부 | 경로는 ROOT 에서 이어진다 |
| **(E)** | `C(h) = ∅` 이면 거부 | 진입 단어가 없다 |

개별 단어를 후속 부재로 지우지는 **않는다** — terminal 이 누구인지 모르기 때문이다. 이것이
§5 가 요구한 "ROOT 와 terminal 의 자유도를 정확히 존중" 이다.

고정점까지 반복. 전수 결과:

| | |
|---|---|
| 쌍 PASS | **15,776** |
| 쌍 FAIL | **5** — 전부 `W_C_TWO_TERMINALS` (규칙 S) |
| **상태 폐쇄** | **0** |
| AC 삭제 수 분포 | `0`: **14,377** · `1`: 1,195 · `2`: 139 · `3`: 70 |
| 고정점 이후 도메인 | `1`: 1,646,425 · `2`: 50,574 (시작값 1,645,277 / 52,262) |

즉 **91 % 의 쌍에서 전파가 아무것도 지우지 못한다.** 규칙 (P) 는 1.7M 후보 중 약 1,688개
(0.1 %)만 제거했고, 그 결과 새로 발동한 (S) 가 5쌍을 잡았을 뿐이다.

## 5. W-D — 정련된 Hall 매칭 (§6)

의무는 정확히 한 번 발사하므로 "각 의무를 **서로 다른** 전임자(다른 의무 또는 ROOT)가 공급"
해야 한다. 살아남은 도메인으로 이분 그래프를 만들고 완전 매칭을 요구했다.

**쌍 실패 0.** 라운드 95 에서 차수 완화(C1/C2)가 공허했던 것과 같은 이유다 — 공급자 수가
수요보다 크고 ROOT 가 널리 닿아 증가 경로가 언제나 존재한다.

## 7. `r=0` / `r=1` 비교 (§10)

라운드 100 은 `r=0` 의 fragment 가 `ℓ = 5−c_f` 로 출발하는 **중계기**임을 밝혔다. W-A 를
통과한 뒤에는 그 효과가 **거의 사라진다**:

| | 쌍 | 평균 도메인 | 비-singleton 의무/쌍 | 도달 단어 / 후보 단어 |
|---|---|---|---|---|
| `r=0` | 15,512 | 1.031 | 3.32 | 111.8 / 110.9 |
| `r=1` | 269 | 1.024 | 2.60 | 109.9 / 109.6 |

**W-A 가 `r` 비대칭을 이미 소비했다.** 살아남은 `r=1` 269쌍은 구조적으로 `r=0` 과 구별되지
않는다.
