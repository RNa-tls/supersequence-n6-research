## 1. `delta = a + eta` 의 독립 재유도 (§1)

```
f_out = #(자유 상승) + #(자유 하강)
#상승 = F = 2  ⇒  #(자유 상승) = 2 − a   (a := 비자유 상승 수)
자유 하강은 서로 다른 반복 run 을 열므로  d := #(자유 하강) ≤ e;   eta := e − d ≥ 0
⇒ delta = F + e − f_out = 2 + e − (2 − a) − d = **a + eta**
```

`delta = 1` ⇒ `(a, eta) = (1,0)` = **M**, 또는 `(0,1)` = **R**.
`M` 은 `e = d ≤ #하강` 이라 `e ≤ 1`(A)·`e ≤ 2`(B); `R` 은 `d = e−1` 이라 `e ≤ 2`(A)·`e ≤ 3`(B).
전수하면 행별 메커니즘이 **A/e0 M · A/e1 M|R · A/e2 R · B/e0 M · B/e1 M|R · B/e2 M|R ·
B/e3 R** 로 받아들여진 상태와 **정확히 일치**한다 (독립 재현).

## 2. 정리 I — 이동-궤도 의미론 (§2 의 국소 정규형의 핵심)

> 진입 `u`, 길이 `ℓ` 인 pass 에서 **`M2` 와 `M3a` 는 둘 다 `orb(σ^ℓ u)`** (= `ν`-목표 궤도) 로
> 가고, **`M3b`/`M3c` 는 제3의 궤도**로 간다.

`ℓ = 6` (full pass) 이면 `ν`-목표가 자기 궤도이므로 **`M3a` 는 intra-run `x`-호**이고
`x = 0` 이면 **금지**된다.  따라서

> **full pass 의 유료 탈출은 언제나 `M3b`/`M3c`, 즉 라운드 115 의 경량 연결자다.**

이것이 이 라운드 전체의 지렛대다.  `n = 4` 에서도 그대로 성립한다 (숨은 `n=6` 가설 없음).

## 3. 정리 II — 위상 오프셋

> **`M2` 는 `phase(entry(ν(p))) + 1`, `M3a` 는 `+ 2` 에 착지한다** — 모든 단어, 모든 길이에서.

## 4. 정리 III·따름정리 IV — `M3a` 축약과 `M-off-target` 의 정확한 특징

`M3a` 는 `+2` 에 착지하므로 `τ`-사슬로 `ν(p)` 까지 3 걸음, 즉 run 이 **4 pass** 다.
블록은 `p` + 4 pass = **5 pass** 이고 한 pass `(v, a+b)` 로 축약된다:

```
ΔP = −4,  ΔO = −1,  ΔS = −1,  ΔH = 0,  ΔD = −1      (위상 φ+1 이 영구 미사용으로 남는다)
```

`n = 6` 3,600 사례 · `n = 4` 72 사례 **위반 0**.  이는 라운드 135 의 `u` 를 독립 재유도한다:
**`u` = `M3a` 형 축약의 수**.

> **따름정리 IV.**  유료 상승 탈출이 축약을 만들지 **못하는** 것은 그것이 `M3b`/`M3c` 일
> 때뿐이다.  즉 `M-off-target` ⟺ **비자유 상승이 `M3b`/`M3c` 로 나간다.**

## 5. 정리 V — 사슬 용량 증가와 궤도 도달

전수(캡 없음) 셀에서 **`N*(b,0,s) = N*(0,0,s) + 15b`** (궤도 +3, run +4 per token):

| `s` | `b=0` | `b=1` | `b=2` | `b=3` |
|---|---|---|---|---|
| 6 | 49 | 64 | 79 | 94 |
| 9 | 66 | 81 | 96 | — |
| 13 | 83 | 98 | — | — |

`s = 13` 에서 순수 경량 사슬은 **`19 + 3b` 궤도**까지만 닿는다.  대상은 **27 궤도**이므로
`e ≤ 2` 인 행은 **순수 사슬일 수 없다** — 짧은 pass 연결자가 구조적으로 필수다.

## 6. 정직한 음성 결과 — 잘라내기+용량은 원리적으로 불가능 (§10)

전수 셀로 계산한 **천장표** (`Σ N*(0,0,s_i)`, `b = 0`):

| 결손 \ 사슬 수 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 13 | 83 | **112** | 138 | 158 | 178 |
| 15 | 96 | **120** | 150 | 171 | 191 |

* **축약 두 번** (짧은 pass 가 전부 사라짐) → 사슬 1 개, 필요 112, 천장 83 ⇒ **모순** ✓
  (라운드 135 의 `H=0` 경우를 독립 재현).
* 2 사슬·결손 13 의 천장이 **정확히 112** — 라운드 135 가 `H=1` 에서 이음매 논증을 써야
  했던 이유를 독립적으로 설명한다.
* **축약 한 번** → 짧은 pass 둘이 남아 자르면 ≥2 사슬, 필요 115, 천장 **120**(2 사슬)·
  **150**(3 사슬) ⇒ **모순이 나올 수 없다.**

> **결론: `delta = 1` 행은 “더 좋은 자르기” 로는 닫히지 않는다.  두 번째 축약이 없으면
> 잘라내기 노선 자체가 죽는다.**  이것이 이 노선을 버리고 §12 로 간 이유다.

## 7. 정리 VI — 한-결함 사슬 용량 배제 (이 라운드의 주 결과)

자르지 않고 **모델을 넓힌다**.  `chain_capacity_115.c` 에 **겹친 육각형 하나**(짧은 pass 쌍)를
더한 탐색기 `N1*(b,g,s)` 를 만들었다 (`src/chain_capacity_g1_137.c`).  짧은 pass 의미론은
정리 I·II 에서 **정확히** 온다.  run 확장은 원본과 같은 완화라 결과는 **참된 상한**이다.

* **컨트롤**: 결함을 끄면 라운드 115 를 **노드까지** 재현 (`s=9` 469,852 · `s=13` 14,407,541).
* **측정**: 겹친 육각형 하나가 **+20 pass / +4 궤도**를 산다 (`b` 토큰의 +15/+3 보다 크다).

| 셀 | `N*` | `N1*` |
|---|---|---|
| `(0,0,4)` | 46 | **66** |
| `(0,0,6)` | 49 | **69** |
| `(0,0,9)` | 66 | **86** |
| `(0,0,12)` | 83 | **99** |
| `(0,0,13)` | 83 | **102** |
| `(1,0,6)` | 64 | **84** |

축약을 **한 번** 하면 대상은 `P' = 117`, `O' = 26`, `D' = 13`, `H' = 0` 이고 짧은 pass 가
정확히 둘 남는다.  정리 I 로 그 대상의 모든 joint 가 한-결함 모델의 이동이므로 대상은
예산 `(b', 0, 13)` 짜리 **사슬 하나**이고

```
117 = P'  ≤  N1*(b', 0, 13),      N1*(0,0,13) = 102  (전수, 캡 없음, 4,121,832,039 노드)
```

**`102 < 117` ⇒ `b' = 0` 인 배치는 전부 불가능하다.**

### `b'` 의 정확한 값

정리 I 때문에 축약 뒤 닫는 pass 자리에는 진입 `entry(opener)` 인 **full** pass 가 놓이므로
`M2`/`M3a` 가 **자기 궤도**로 간다:

| 닫는 pass 의 탈출 | run 변화 | `x'` | `b'` |
|---|---|---|---|
| `M2` (자유) | `r → r−2` | 0 | `e − 1` |
| `M3a` | `r → r−2` | 1 | `e` |
| `M3b`/`M3c` | `r → r−1` | 0 | `e` |

### 축약이 반드시 존재하는가

* **`e = 0`** — 반복 run 이 없으므로 **lock 이 깨질 수 없다**.  축약 존재 **무조건**.
* **메커니즘 `R`** — 상승 둘 다 자유, `eta = 1` 이라 lock 은 많아야 하나 깨진다.  **무조건**.
* **`M` 이면서 `e ≥ 1`** — 자유 상승이 하나뿐이라 보장되지 않는다 (유일한 빈틈).

### 제거 결과

| 배치 | `b'` | 판정 |
|---|---|---|
| `A/e0` (M, 닫는 탈출은 `M3b/M3c` 강제) | 0 | **제거 (무조건)** |
| `B/e0` (M, 동일) | 0 | **제거 (무조건)** |
| `A/e1` R, 닫는 탈출 `M2` | 0 | **제거 (무조건)** |
| `B/e1` R, 닫는 탈출 `M2` | 0 | **제거 (무조건)** |
| `A/e1`·`B/e1` M, 닫는 탈출 `M2` | 0 | 제거 — 단 lock 성립 조건부 |
| 나머지 20 배치 | ≥1 | 이 상한이 닿지 않는다 |

> **`A/e=0` 과 `B/e=0` 은 완전히 사라진다.  7 행 → 5 행.**

## 8. 등호 — 다음 단계의 정확한 표적 (§11)

`b` 토큰 법칙은 한-결함 모델에서도 **두 번** 확인된다 —
`N1*(1,0,6) = 84 = 69 + 15` (338,860,753 노드) 과 `N1*(1,0,9) = 101 = 86 + 15`
(6,572,464,021 노드), 둘 다 `capped = false`.  따라서

```
N1*(1,0,13)  =  102 + 15  =  **117**   (예측)   vs   필요 117
```

즉 `b' = 1` 배치는 **정확히 등호**에 걸린다.  라운드 135 가 `46 + 66 = 112` 에서 했던 것처럼
**극값 증인만 열거해 이음매/경계 조건이 이어질 수 있는지** 보는 것이 정확한 다음 단계다.
`N1*(1,0,13)` 의 전수 계산은 약 `2×10^11` 노드로 추정되어 이 라운드에서 돌리지 않았다 —
**예측이지 증명이 아니다.**
