## 1. 보편 자유-이탈 정리 — 형식적 서술과 증명 감사

### 1.1 정의 (보고서 §1 에서 복원, 이 프롬프트에서 추론하지 않음)

pass 는 극대 회전 run `(v_i, l_i)`, `l_i` 는 **순열 창의 개수**.  `sigma` 는 여섯
자리 전체 회전(육각형 = `sigma`-순환), `E` 는 앞 다섯 자리 회전(궤도 = `E`-순환,
포트 다섯 개).  **`S` 는 유료 조인트(무게 >= 3) 의 개수**이며 옛 strand 관습이
아니다(그쪽은 `S+1`).  `H = sum max(w-3,0)`.  **run 은 같은 `E`-궤도에 있는 pass
진입의 극대 연속열**이고, `r` 개 run 과 `O` 개 궤도에 대해 `e = r-O` 가 **반복
run 개시 사건**의 수다.  `x` 는 **유료 run-내부 조인트**(따라서 유료 조인트가
run 을 끊지 않는다), `f_out` 은 자유(무게 2) run-간 이탈의 수.  그러면

    S = O + e - 1 - f_out + x.

`G = P - 120 = sum_h (m_h - 1)` 는 다중도, `F` 는 abandonment, `J = G - F`.

> **감사 중 자기 정정**: 나의 초판 파서는 (i) run 을 유료 궤도-내부 조인트에서
> 끊었고, (ii) `G` 를 완전 덮기 가정으로 계산했다.  둘 다 정의 오독이었다.
> 위 정의대로 고치자 Astra 의 모든 값과 정확히 맞았다.  그 전에 돌린 census 는
> 폐기하고 다시 돌렸다.  위 항등식 `S = O+e-1-f_out+x` 를 내부 정합 검사로
> 넣었고 29,255 단어에서 위반 0 이다.

### 1.2 정리

`nu` 를 `v_nu(i) = sigma^(l_i)(v_i)` 로 정의한다.  완전 덮기·무반복 때문에 각
육각형의 pass 들이 그 방향 순환을 분할하므로 `nu` 는 full pass 를 고정하고 갈라진
육각형마다 길이 `m_h` 순환 하나를 갖는다.  시간순 오름 `i < nu(i)` 이 곧
abandonment 이고 `F = #오름`, `J = sum_split_h (d_h - 1) >= 0`.

**가설**: 무반복 순열 단어이며 자기가 건드린 회전류를 **완전히** 덮을 것.
`G` 에 대한 제한은 **없다**.  `x` 는 정리 서술에 **등장하지 않는다** (감사 확인:
아래 §1.4 의 전수 시험이 `x` 를 전혀 쓰지 않는다).  720 순열 전체에의 적용만이
`NR6` 조건부다.

**핵심 항등식 (2.1)**: 무게-2 조인트에서 문자 출처 `p' = sigma^(l_i-1)(v_i)` 의
표적은

    target = E(sigma(p')) = E(v_nu(i)).

따라서 표적 **궤도**는 `orb(v_nu(i))` 다.

**증명 구조** (두 개의 단사):

* full pass (`nu(i)=i`) 의 자유 조인트는 표적이 `E(v_i)`, 즉 **같은 궤도**이므로
  run 내부다 — `U` 에 들어가지 않는다;
* 짧은 pass 의 **오름** 자유이탈은 그 자체로 오름이므로 `A` 로 단사;
* 짧은 pass 의 **내림** 자유이탈 `i` 는 표적 궤도가 pass `nu(i) < i` 에서 이미
  열렸으므로 진입 `i+1` 이 **반복 run 개시**다.  `i |-> i+1` 은 단사이고 상은
  `Rpt` 안에 있다.

`U` 의 원소는 오름 아니면 내림이므로

    f_out = |U ∩ A| + |U \ A| <= |A| + |Rpt| = F + e,
    delta := F + e - f_out = a + eta >= 0,   a = |A\U|,  eta = |Rpt\Ord|.   (2.2)

### 1.3 항등식 (2.1) 의 독립 확인

`p'` 에서 나가는 **합법** 무게-2 표적이 유일하며 정확히 `E(sigma(p'))` 인가를
`n = 4, 5, 6` 의 **모든 창**(24+120+720 = 864 개)에서 전수 확인했다. 실패 **0**.
이것이 정리의 급소이고, 나머지는 순수 계수다.

### 1.5 단사의 직접 해부 (§5-§8)

29,255 단어 전부를 열어 다음을 **문자 수준에서** 확인했다 (실패 **0**):

* 모든 내림 자유이탈에서 표적 궤도가 정확히 `orb(v_nu(i))` 이고 `nu(i) < i` 이므로
  **이미 열려 있다**;
* `i |-> i+1` 이 매 단어에서 **단사**이고 상이 `Rpt` 안에 있다;
* full pass 의 자유 조인트가 run-간으로 잘못 계상되는 일이 **한 번도 없다**;
* 오름 자유이탈 수 `<= F`, 내림 자유이탈 수 `<= e`.

**§6/§7 (가장 어려운 경우) 이 실제로 시험되었다**: 내림 의무가 **서로 다른 두 개
이상의 육각형**에서 나오는 단어가 **6,195** 개, **세 개 이상**에서 나오는 단어가
**1,563** 개 (최대 5 개 육각형).  충돌도 이중 계수도 **0**.

이유는 구조적이다: 사상 `i |-> i+1` 은 **육각형을 전혀 참조하지 않는다**.  서로
다른 자유이탈은 서로 다른 `i` 이므로 서로 다른 `i+1` 을 주고, 한 사건이 두 의무를
갚는 일은 일어날 수 없다.  Hall 조건이 자명하게 성립한다는 Astra 의 서술과 같다.

### 1.6 구 정리와의 비교 (§10)

옛 정리는 `G <= 2` 에서 `f_out <= G+e+x`.  `F <= G` 이고 `x >= 0` 이므로
`f_out <= F+e` 는 **엄격히 더 강하다**.  기존 감사 예시와의 모순은 없다:
29,255 단어에서 구 정리 위반도 **0** 이다.

### 1.7 Astra 가 스스로 반증한 강화들 — 재현 확인 (§3)

감사자로서 Astra 가 한계를 정직하게 기록했는지 확인했다.

* `delta >= J` 는 **거짓**이다.  Astra 가 제시한 단어
  `012301202130210312032102031023103201320` 에서 내 파서가 아홉 개 필드를
  **전부 재현**한다: `(G,F,J,e,x,S,H,delta,f_out) = (3,2,1,2,1,2,2,0,4)`,
  즉 `delta = 0 < 1 = J`.  더구나 이것은 일회성이 아니라 **29,255 중 22 개**
  단어에서 실패한다.  정리 A 자체는 그 단어들에서도 성립한다.
* 무자격 `delta >= q+s` 도 거짓이며, 정정형 `(3.1) delta >= q+s-o-z` 만 성립한다.
  Astra 는 이것을 `G3` 폐쇄에 **쓰지 않고** §6 의 자유-블록 항등식을 쓴다 —
  감사 확인 결과 실제로 그렇다.

## 4. 일반 successor-splicing (§16-§20)

**끝점 항등식**은 `sigma^n = id` 하나만 쓰는 기호 항등식이다:

    sigma^-1(v_nu(i)) = sigma^-1(sigma^(l_i)(v_i)) = sigma^(l_i-1)(v_i).

유한 검사에 의존하지 않지만, `n = 4,5,6,7` 의 모든 순열 × 모든 pass 길이
**40,296** 개에서 전수 확인했다 (실패 0).  조인트 전체(무게·꼬리·중간창)의 보존도
**40,788** 개 삼중항에서 확인 (실패 0).

**합성** (§19): splice 는 모든 pass 를 동시에 full 로 바꾸는 **하나의 전역 연산**
이므로 splice 순서라는 것이 없다.  순서가 문제될 수 있는 것은 이어지는 자름인데,
정리는 정준 규칙(모든 heavy 변 → heavy 없는 순환마다 최소 출처 색인의 유료 변 →
경로 순서로 자유 블록을 훑어 육각형 반복 직전에서 자름)을 지정하고, 필요한 것은
조각 수 상계뿐이다.  41 개 지지 × 모든 `(c,h)` 416 조합에서

    m <= K - c + h + R <= G + 1 - c + h

위반 **0**.  `c <= K-1` 은 더미를 담은 성분이 결코 순수 자유 순환이 아니라는 데서
따른다.

**육각형 다중도** (§20): 자유 변은 문자 그대로 `E`-단계이고 진입/진출 차수가 최대
1 이므로 순수 자유 순환은 성분 전체이며 한 궤도의 `n-1` 포트를 정확히 지난다.
진입 유일성 때문에 그 궤도는 다른 곳에 없고, 제거는 궤도 하나와 `n-1` 개 진입을
전역에서 없앤다.  (라운드 139 감사에서 이 구조를 819 개 순수 자유 순환에서 실측해
전부 확인해 두었다.)

## 5. 공유 궤도 회계 (§21-§24)

`s = sum_j O_j - O' = sum_Q (그 궤도를 담은 조각 수 - 1)` — **사밀성을 요구하지
않고 공유를 그대로 들고 간다**.  대수 검증(4,950 조합 + 항등식 연쇄) 결과 위반 0:

    sum_j b_j + s = S + 1 - O + c = delta - F + x + c,
    sum_j P_j = 120 + G - 5c,
    sum_j D_j = 5k - G + 5s,
    L <= 871  =>  sum_j b_j + s <= 4 - G - k + c - H.

**세 조각 이상 공유** (§22): 궤도가 `t` 개 조각에 나타나면 `s` 에 `t-1`,
`sum_j O_j` 에 `t`, `sum_j D_j` 에 `5(t-1)` 을 기여한다.  `t >= 3` 도 같은
선형식이므로 예외 취급이 필요 없다.

**이중 계수 없음** (§24): `delta` 는 `(F, e, f_out)` 만의 함수이고 `x` 는 `S` 에,
`H` 는 `L` 에 별도 항으로 들어간다.  `sum b_j + s = delta - F + x + c` 에서 셋이
서로 다른 자리를 차지하므로 한 단위가 두 번 세어질 수 없다.

## 6. 용량 모델 포함과 값 (§25-§28)

**포함** (§26).  splice 후 각 조각은 pass 가 전부 full, 무반복, 전부 경량이다.
이동 분류를 전수 확인한 결과 합법 무게-2 는 `tau` **하나뿐**, 합법 무게-3 은
`120`(궤도 안), `201`, `210`(궤도 밖) **셋뿐**이고 `012`/`021`/`102` 와
`w2/(0,1)` 은 **0/720** 으로 불법이다(중간 창이 순열).  `N*(b,0,d)` 는 임의의
비-`E` 위상 점프와 같은 궤도로의 재진입까지 허용하므로 이들을 **모두 포함하는
완화**이며, 조각의 결손은 **실제 `D_j`** 이므로 사밀성 가정이 부과되지 않는다.

**봉투 표** (§28).  내 열거 규칙

    K in {2,4} (K = G+1 mod 2),  0 <= c <= K-1,  B = 1-k+c-H >= 0,
    m = 4-c+h,  s in 0..B (m=1 이면 s=0),  b = B-s,
    D_sum = 5k-3+5s,  P_req = 123-5c

로 **정확히 40 개** 봉투가 나오고 `k` 별 **26 / 10 / 3 / 1**, **37 strict +
3 equality + 0 open** — Astra 주장과 완전히 일치한다.

## 7. 긴축 칸 `(4,3)` 과 나머지 세 칸 (§33-§37)

따라서 `N*(0,0,17) = 103 < 108` 이고 여유는 **5** 다.  `(4,3)` 은 봉투가 하나뿐이고
그 하나가 엄격히 닫히므로 **칸 전체가 닫힌다** — 표본이 아니라 봉투 강제에 의한
폐쇄다.  덤으로 이 계산은 상속 값 `N*(0,0,18) = 103` 과도 정합한다 (`C0` 는 비감소

이유는 그때는 이미 닫힌 칸의 회수에만 쓰였기 때문이고, 이번에는 하중이 실려

스물여섯 봉투.  독립 생성한 **516 행 전부**가 봉투로 사상됨을 확인했다 —
`(행, K, c, heavy)` 조합 **1,730 개 전부 사상, 탈출 0** (§41).  사상 규칙은
`need = delta-F+x+c = sum b_j + s <= B` 이고, 예산을 다 쓴 봉투 `(s_act, B-s_act)`
가 실제 배치를 지배한다 (용량이 `b` 와 결손 둘 다에 단조 비감소).

**`k` 누락 없음** (§37): `L <= 871` 에서 `k <= 4`, `D >= 0` 에서 `5k >= G = 3`

## 8. 등호 경우 — 유일한 비-엄격 지점 (§29-§32)
