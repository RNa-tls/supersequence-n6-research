### (B) 나쁜 쪽 — **서술되지 않은 가정을 하나 찾았다**

> **모델의 의무 그래프는 네 개의 최소 weight joint (`T1` weight 2, `T2/T3/T4` weight 3) 로만
> 호를 만든다. 그러나 엔진의 이동 집합은 weight 1–6 의 550개다.**
> weight ≥ 4 인 joint 도 한 의무의 배정 단어에서 **다른 의무의 배정 단어로 곧장 갈 수 있다.**
> 실제로 갈 수 있다 — 실측: 배정 1,030개를 훑어 **생략된 호 12,062,293개**
> (예산 비용 2: 461,531 · 3: 1,834,759 · 4: 9,766,003). 배정 하나당 평균 **448개의
> 비용-2 호**가 모델에 빠져 있다 (모델이 가진 호는 배정당 약 300개다).

**왜 문제인가.** 배제(UNSAT) 논증에서 호를 빼면 **거짓 UNSAT** 이 날 수 있다. 예산 정리는
weight ≥ 4 joint 를 금지하지 않는다 — 그것들은 **더 비쌀 뿐**이다:

    cost(w) = [w ≥ 3] + max(w − 3, 0)      w=2 → 0 · w=3 → 1 · w=4 → 2 · w=5 → 3 · w=6 → 4

`B ≈ 21` 이고 미래 joint 가 107–108 개이므로, 예를 들어 weight-4 joint 10 개(비용 20)와
나머지 전부 무료인 완성은 **예산 안에 있다.** 따라서 예산만으로는 배제되지 않는다.

**그러나 결론의 상당 부분은 살아남는다.** 뿌리 성분 하한은 오직 두 가지에만 의존한다.

1. **비용-0 호는 `T1` 뿐이다** — 전체 550개 이동 집합에서도 그렇다. 비용 0 인 joint 는
   `cost(ω) = 0` 곧 `ω = 2` 뿐인데, **weight-2 indecomposable tail 은 정확히 하나**이고
   그것이 `T1` 이다 (weight 별 개수 `1, 1, 3, 13, 71, 461`).
2. **비용 0 이 아닌 호는 비용이 ≥ 1** — 정의에서 자명하다.

보조정리 7 의 계수는 "무료가 아닌 호의 **개수** ≥ `c(R) − 1`" 이고, 각각이 비용 ≥ 1 이므로
**총비용 ≥ `c(R) − 1`** 이다. 이 논증은 무거운 호를 넣어도 그대로다.

> **그래서 결론을 두 조각으로 나눠 서술한다.**
>
> | | 상태 | 지위 |
> |---|---|---|
> | **모든 cover 가 뿌리 성분 하한만으로 닫힌 상태** | **5,043 / 6,396** | **joint weight 제한과 무관하게 배제** |
> | 적어도 한 cover 가 분기 탐색으로만 닫힌 상태 | **1,353 / 6,396** | **weight ≤ 3 joint 가정에 조건부** |
>
> (라운드-106 모집단 4,232 상태 기준으로는 **3,467 robust / 765 conditional**.)

이 사실은 라운드 106 의 인증서를 **무효화하지 않는다.** 인증서가 계산한 것은 여전히 참이다 —
다만 그것이 배제하는 대상이 "완성 전부" 가 아니라 "**weight ≤ 3 joint 만 쓰는 완성**" 이라는
것이 이제 명확해졌다. 아래 §15 의 정리 서술에 **가설 (H5)** 로 명시한다.

## 1. 정의 (구현 용어 없이)

**D1 (단어).** `Σ = {0,…,5}` 의 순열을 길이 6 문자열로 쓴 것. `|W| = 720`.

**D2 (회전 `σ`, 육각형).** `σ(w₀…w₅) = w₁w₂w₃w₄w₅w₀`. `⟨σ⟩` 궤도가 **육각형** — 120개, 크기 6.

**D3 (궤도 `τ`).** `τ(w₀…w₅) = w₁w₂w₃w₄w₀w₅` (앞 다섯만 회전). `⟨τ⟩` 궤도가 **궤도** —
144개, 크기 5, 안의 위치가 **phase ∈ {0,…,4}**. 한 육각형의 여섯 단어는 **서로 다른 여섯
궤도**에 있다 (120/120 확인).

**D4 (이동과 weight).** `u → v` 이동의 **weight** `ω` 는 새로 덧붙는 글자 수. `ω = 1` 은
정확히 `v = σ(u)` 이고 **회전**이라 한다. `ω ≥ 2` 를 **joint** 라 한다. 중간에 순열 창을
만들지 않는(indecomposable) 이동은 weight 별로 `1, 2, 3, 13, 71, 461` 개, 합 **550**개다.

**D5 (pass).** `ℓ ≥ 0` 개의 연속 회전과 **정확히 하나의 joint** 로 이루어진 극대 블록.
`ℓ` 이 그 pass 의 **회전 길이**.

**D6 (계수기).** 부분 walk 을 따라 누적한다.
* `S` — weight `≥ 3` 이동의 개수
* `F` — **abandonment** 개수. joint 직전 커서 `p` 에 대해 `σ(p)` 가 미방문이면 그 joint 는
  abandonment
* `O` — 적어도 한 단어가 방문된 궤도의 개수
* `H` — joint 에 대한 `Σ max(ω − 3, 0)`
* `Ndef := S + F − O`

**D7 (목표).** 완성은 720 단어를 모두 방문하고 `F = 1`, `O = 25`, `Ndef + H ≤ 3` 을 만족한다.
(원 목표의 `P = 121`, `D = 4` 는 **쓰지 않는다** — 조건을 덜 쓰는 쪽이 필요조건으로 약해서
안전하다.)

**D8 (joint 의 예산 비용).** `cost(ω) := [ω ≥ 3] + max(ω − 3, 0)`.
값: `ω=2 → 0`, `3 → 1`, `4 → 2`, `5 → 3`, `6 → 4`. `cost` 는 그 joint 가 `Ndef + H` 에
더하는 양이다 (D6 에서 직접).

**D9 (의무).** 아직 한 단어도 방문되지 않은 육각형(**빈 육각형**) 하나하나의 진입. 완성은 각
빈 육각형을 정확히 한 번 진입한다(보조정리 1).

**D10 (fragment).** 방문 단어가 `1 ≤ c_f ≤ 5` 개인 육각형. 많아야 하나이며 고정된 진입
단어에서 `ℓ = 5 − c_f` 회전으로 수리한다. 이것도 의무 하나로 센다. `r = 0` 은 있는 상태,
`r = 1` 은 없는 상태.

**D11 (ROOT).** 상태의 현재 커서 단어 `p`. 미래의 첫 pass 는 `p` 에서 `ℓ = 5` 로 시작한다.

**D12 (구체 진입 단어와 도메인).** cover 가 미래에 열릴 궤도 집합을 고정하면
`C(h) = {w ∈ h : orbit(w) 가 열려 있음}`. 실측 `|C(h)| ≤ 2` (§11).

**D13 (joint target `T1…T4`).** `y = σ^ℓ(x)` 에서

    T1(y) = y₂y₃y₄y₅y₁y₀   (ω = 2, cost 0)
    T2(y) = y₃y₄y₅y₁y₂y₀   (ω = 3, cost 1)
    T3(y) = y₃y₄y₅y₂y₀y₁   (ω = 3, cost 1)
    T4(y) = y₃y₄y₅y₂y₁y₀   (ω = 3, cost 1)

이 네 개가 **weight ≤ 3 인 joint 의 전부**다 — indecomposable tail 의 weight 별 개수가
`1, 1, 3, 13, 71, 461` 이므로 weight-2 는 하나(`T1`), weight-3 은 셋(`T2/T3/T4`)이다.
`G_light` 의 호는 정확히 이 넷에서 나온다.

**D14 (비싼 joint 수 `E`).** 미래 구간에서 weight `≥ 3` 인 joint 의 개수. 모든 미래 joint 의
weight 가 ≤ 3 이면 `Σ cost = E` 다.

**D15 (`K`, 예산 `B`).** `K := 25 − O`, `B := 3 + K − Ndef − H`.
아카이브 6,396 상태는 전부 `F = 1`, `H = 0`, `Ndef = 0` 이므로 **`B = 3 + K`**,
`O ∈ [3,10]` 에서 **`B ∈ [18,25]`**.

**D16 (고정 단어 배정).** 각 의무 `h` 에 `A(h) ∈ C(h)` 를 하나씩 고르는 함수.

**D17 (비용 그래프).** 정점 = 의무. `h → g` 호는 `σ^{ℓ_h}(A(h))` 에서 하나의 joint 로
`A(g)` 에 닿을 때 존재하고, 비용은 `cost(ω)`. ROOT 에서 나가는 호도 같은 규칙(`ℓ = 5`).
**`G₀`** = 비용 0 인 호만 남긴 부분 그래프.
**`G_light`** = 비용 ≤ 1 인 호만 남긴 부분 그래프 — **인증서가 실제로 탐색한 그래프**.

**D18 (`R`, `c(R)`).** `R` = 아직 방문하지 않은 의무 집합. `c(R)` = `G₀|_R` 의 **약연결 성분**
개수 (방향 무시).

## 4. 보조정리 3–4 — `T1` 결정성과 비용-0 유출 차수

> **보조정리 3.** 구체 진입 단어 `u` 와 강제된 `ℓ` 에서 그 pass 의 **무료** joint target 은
> 문자열 하나 `T1(σ^ℓ(u))` 다.

**증명.** `σ^ℓ(u)` 는 `u, ℓ` 로 결정되는 문자열이고 `T1` 은 그 글자의 자리바꿈이다.
무료 joint 는 `cost(ω) = 0` 곧 `ω = 2` 뿐이고, weight-2 indecomposable tail 은 **정확히
하나**다. ∎

> **보조정리 4.** 고정 배정 `A` 에서 `G₀` 의 모든 정점 `v` 는 `outdeg_{G₀}(v) ≤ 1`.

**증명.** 보조정리 3 으로 무료 target 은 단어 `t` 하나. `A` 는 함수이고 의무들의 육각형은
서로소이므로 `A(g) = t` 인 의무 `g` 는 많아야 하나. ∎

**의무 표현 중복이 두 개의 무료 후속을 만들 수 없는 이유.** `T1…T4` 는 **서로 다른 네
육각형**에 있고 어느 것도 출발 육각형이 아니다 (라운드-99 기하 정리 — 구조적 증명:
`y₅` 의 상은 결코 `y₀` 가 아니고, `T1` 은 `y₁→y₀` 인데 `T2` 는 `y₁→y₂`, `{T1,T2}` 는
`y₅→y₁` 인데 `{T3,T4}` 는 `y₅→y₂`, `T3` 는 `y₂→y₀` 인데 `T4` 는 `y₂→y₁`). 4,320/4,320 확인.

> 유한 인증서는 **검증**으로만 인용한다: 정적 19,863,503 · 동적 73,435,904 확인, 위반 0.

## 5. 보조정리 5 — `ΔF = 0` (**간단해졌다**)

> **보조정리 5.** 아카이브의 모든 상태에서 임의의 완성은 `ΔF = 0` 을 만족한다.

**증명.** `F` 의 갱신은 joint 마다 `+[abandonment] ∈ {0,1}` 이므로 **단조 증가**한다.
아카이브 6,396 상태는 전부 `F = 1` 이고 목표는 `F_final = 1` 이다. `1 ≤ F_final = 1`
이므로 `ΔF = 0`. ∎

> **정정 상자.** 라운드 104 의 "`ℓ<5` 면 abandonment 없음" 은 **거짓**(라운드 105 반증).
> 라운드 105/106 의 조각 기하 서술(`r=0` 5,732/5,732)은 **참이지만 이제 불필요**하다 —
> 정합성 확인의 지위로 내려간다. 두 문장 다 지우지 않고 이 상자와 함께 보존한다.

## 6. 보조정리 6 — 예산 정리 (완전한 기호 증명)

**사건표** (D6 의 정의에서 직접).

| 미래 이동 | `ΔS` | `ΔH` | `ΔF` | `ΔO` | `cost` |
|---|---|---|---|---|---|
| 회전 `ω = 1` | 0 | 0 | 0 | 0 | — |
| joint `ω = 2` | 0 | 0 | `[aband.]` | 0/1 | **0** |
| joint `ω = 3` | 1 | 0 | `[aband.]` | 0/1 | **1** |
| joint `ω = 4` | 1 | 1 | `[aband.]` | 0/1 | **2** |
| joint `ω = 5` | 1 | 2 | `[aband.]` | 0/1 | **3** |
| joint `ω = 6` | 1 | 3 | `[aband.]` | 0/1 | **4** |

**(a) 정확한 항등식.** `Ndef = S + F − O` 이므로

    Δ(Ndef + H) = ΔS + ΔF − ΔO + ΔH = Σ_{미래 joint} cost(ω) + ΔF − ΔO.

* `ΔS + ΔH = Σ cost(ω)` — 표의 마지막 열이 `[ω≥3] + max(ω−3,0)` 이다.
* `ΔF = 0` — 보조정리 5.
* `ΔO = K` — `O_final = 25` 가 목표이므로 순변화는 정확히 `25 − O = K` (단조성 불필요).

    ⇒  final(Ndef + H) = current(Ndef + H) + Σ cost(ω) − K.        (**정확한 항등식**)

**(b) 목표 부등식.** `final(Ndef + H) ≤ 3` 이므로

> **보조정리 6 (예산).** 목표를 만족하는 임의의 완성은
> **`Σ_{미래 joint} cost(ω) ≤ B := 3 + K − Ndef − H`** 를 만족한다. ∎

**(c) 인증서가 실제로 쓴 형태와의 관계.** 모든 미래 joint 의 weight 가 ≤ 3 이면
`Σ cost = E` 이므로 `E ≤ B` 다. 이것이 라운드 104–106 이 쓴 형태이고, 그 형태는 **(H5) 가설
아래에서만** 보조정리 6 과 같다.

| | 지위 |
|---|---|
| `Δ(Ndef+H) = ΔS + ΔF − ΔO + ΔH` | **정확한 항등식** |
| `ΔS + ΔH = Σ cost(ω)` | **정확** (사건표) |
| `ΔF = 0` | **정확** (보조정리 5) |
| `ΔO = K` | **정확** (목표 `O = 25`) |
| `Σ cost ≤ B` | **정확한 필요조건** |
| `Σ cost = E` (즉 `E ≤ B`) | **(H5) 가설 필요** — weight ≥ 4 joint 가 없어야 성립 |

라운드 104/105 는 `ΔH ≥ 0` 을 `= 0` 으로 놓는 것을 "낙관적 완화" 라고 불렀다. 정확히 말하면
그 완화는 **weight ≥ 4 joint 를 아예 배제한 것**과 같고, 그것이 (H5) 다.

이 절의 증명에는 **어떤 경험적 trace 도 들어가지 않는다.**

## 7. 보조정리 7 — 제한 성분 하한 (독립 그래프 정리)

> **보조정리 7.** 유향 그래프의 각 호에 **비음 정수 비용**이 붙어 있고, 비용 0 인 호들의 부분
> 그래프를 `G₀` 라 하자. `R` 은 정점 부분집합, `x ∉ R` 은 현재 정점, `c(R)` 은 `G₀|_R` 의
> 약연결 성분 수다. `x` 에서 출발해 `R` 의 모든 정점을 **정확히 한 번씩** 지나는 임의의 경로의
> 총비용은 최소
>
> * `c(R) − 1` — `x` 에서 `R` 로 가는 비용-0 호를 그 경로가 쓸 수 있을 때
> * `c(R)` — 그렇지 않을 때
>
> 이다.

**증명.** 경로는 진입 호 1개와 내부 호 `|R| − 1` 개로 이루어진다. 내부 호 중 비용 0 인 것의
집합을 `F`, `y = |F|` 라 하자.

1. `F` 는 단순 경로의 부분집합이므로 **선형 숲**이고, `R` 위에 만드는 성분은 `|R| − y` 개다.
2. `F ⊆ G₀|_R` 이므로 `F` 의 성분은 `G₀|_R` 의 약연결 성분을 **세분**한다.
3. 경로가 `R` 을 전부 덮으므로 `|R| − y ≥ c(R)`, 즉 `y ≤ |R| − c(R)`.
4. 비용 0 이 아닌 내부 호는 `(|R| − 1) − y ≥ c(R) − 1` 개이고 **각각 비용 ≥ 1** 이므로
   총비용 ≥ `c(R) − 1`.
5. 진입 호가 비용 ≥ 1 일 수밖에 없으면 1 이 더해져 `c(R)` 이 된다. ∎

> **주의.** 4단계를 "비용-1 호의 개수" 가 아니라 "**비용 ≥ 1 인 호의 개수**" 로 쓴 것이
> 중요하다. 그래서 이 보조정리는 무거운 joint (비용 2·3·4) 를 넣어도 **그대로 성립**한다.
> §0-B 의 robust/conditional 분할이 여기서 나온다.

**경계 사례.**
* **`G₀` 의 순환.** 무방하다. 논증은 `G₀` 의 구조가 아니라 경로가 실제로 쓴 `F` 만 본다.
  `F` 는 경로의 부분집합이라 언제나 무순환이다. (실제 인스턴스의 `G₀` 는 함수형이라 성분마다
  순환이 많아야 하나 있다 — 라운드 104 가 잰 "고리 약 17개".)
* **쓸 수 있는 비용-0 호를 안 쓰는 경우.** 하한이므로 손해 없다.
* **ROOT / 현재 정점 `x`.** `R` 에 포함하지 않으며 `c(R)` 계수에서도 제외한다.
* **terminal.** 따로 두지 않는다. 경로의 마지막 정점이 terminal 이고 계수는 그것에
  의존하지 않는다.

### 왜 유출 차수 가설이 필요한가 (라운드 105 반례 보존)

**보조정리 7 자체는 가설을 쓰지 않는다.** 가설이 필요한 것은 **구현이 계산하는** `ĉ(R)` 이다.
구현은 정점마다 비용-0 후속을 하나만 병합하므로, 후속이 둘 이상이면 `ĉ(R) > c(R)` 가 되어
하한이 참값을 넘을 수 있다.

> **보존된 최소 반례** (`outputs/rr_outdegree_counterexample.json`, 손 검증 가능).
> 정점 `{0,1,2,3}`, 비용-0 호 `0→3`, `2→1`, `2→3`, `3→2`, 비용-1 호 없음, ROOT 는 정점 `0`
> 으로 **비용 0** 진입.
> * 정점 `2` 의 비용-0 유출 차수 **2** — 가설 위반.
> * 참 약연결 성분 1개 → `c = 1`, 보조정리 7 의 하한 **0**.
> * 구현의 병합 → `ĉ = 2`, 하한 **1**.
> * 실제 경로 `ROOT → 0 → 3 → 2 → 1` 의 총비용 **0**.
> * 따라서 구현의 하한 `1 > 0` 은 **불건전**.

> **보조정리 4′.** `outdeg_{G₀}(v) ≤ 1` 이면 `ĉ(R) = c(R)`. 보조정리 4 가 이를 보장한다.

## 8. 보조정리 8 — 동적 가지치기 정리

부분 경로가 정점 `x` 에 있고 지금까지 총비용 `cost_used` 를 썼으며 남은 의무가 `R` 일 때

    L2(x, R) := ĉ(R) − 1   ( x 에서 R 로 가는 비용-0 호가 있을 때 )
                ĉ(R)       ( 없을 때 )

> **보조정리 8.** `cost_used + L2(x, R) > B` 이면 이 탐색 노드 아래에 목표를 만족하는 완성이
> **하나도 없다** — 이동 집합을 전체 550개로 넓혀도 그렇다.

**증명.** 이 노드 아래의 완성은 `R` 을 정확히 한 번씩 덮는 경로로 이어진다. 보조정리 4+4′ 로
`ĉ(R) = c(R)`, 보조정리 7 로 나머지 구간의 총비용 ≥ `L2(x,R)`. 따라서 그 완성의 총비용은
`> B` 이고 보조정리 6 에 모순. ∎

도달성 가지치기도 같은 형태다: `R` 의 어떤 의무가 `x` 에서 도달 불가능하면 그 의무를 진입하는
pass 가 없으므로 완성이 없다. **단, 도달성은 `G_light` 에서 판정하므로 (H5) 에 의존한다.**

## 9. 정리 A — 탐색 완전성 (`G_light` 안에서)

DFS 의 상태는 (현재 정점 `x`, 남은 집합 `R`, 쓴 비용 `cost_used`) 이고 가지치기는 셋뿐이다.

1. `R` 안에 `x` 에서 도달 불가능한 정점이 있으면 자름 — 필요조건.
2. `cost_used + L2(x,R) > B` 이면 자름 — 보조정리 8.
3. 메모: 같은 `(x,R)` 에서 이전에 **더 적거나 같은** 비용으로 실패했으면 자름 — 남은 문제가
   `(x,R)` 과 남은 예산에만 의존하고 예산이 단조이므로 **정확한 지배**다.

**휴리스틱 가지치기는 없다.**

> **정리 A.** 고정된 (상태, cover, 배정) 에서 **`G_light` 의 호만 쓰는** 임의의 완성 `π` 에
> 대해, DFS 는 `π` 에 대응하는 분기를 따라 내려가고 그 분기는 잘리지 않는다.

**증명 (길이 귀납).** `π` 는 보조정리 1 로 의무 열 `h₁,…,h_m` 을 준다. 길이 `k` 접두가 노드
`(h_k, R_k, cost_k)` 에 대응한다고 하자.
* `π` 는 `h_k → h_{k+1}` pass 를 갖는다. 보조정리 2 로 `ℓ` 이 강제되고, 진입 단어는 `A(h_{k+1})`
  이다. 그 이동이 `G_light` 안에 있다는 가정에서 DFS 의 분기 목록에 반드시 들어 있다.
* `cost_{k+1}` 은 `π` 가 실제로 쓴 비용과 같다.
* 규칙 1 은 발동하지 않는다 — `π` 가 `R_{k+1}` 을 전부 진입하므로 전부 도달 가능하다.
* 규칙 2 는 발동하지 않는다 — 보조정리 8 의 대우.
* 규칙 3 은 발동하지 않는다 — `π` 가 있으면 그 실패가 애초에 일어날 수 없다.

따라서 `k = m` 까지 진행되어 완성에 도달한다. 대우로, DFS 가 `UNSAT` 이면 **`G_light` 안에는**
그런 `π` 가 없다. ∎

> **정리 A 가 말하지 않는 것.** `G_light` 밖의 호(무거운 joint)를 쓰는 완성에 대해서는
> 아무 말도 하지 않는다. 그것이 §0-B 의 (H5) 다.

**캡.** 노드 캡에 걸리면 DFS 는 `UNKNOWN` 을 반환하며 이는 `UNSAT` 이 **아니다.**
인증서·최소 사슬·비-Hall 세 실행 모두 캡 도달 **0**.

## 10. 정리 B — 유한 열거 완전성

    상태 s 가 불가능 ⟺ s 의 **모든** 관련 cover 가 불가능
    cover c 가 불가능 ⟺ c 의 **모든** 구체 배정이 불가능
    배정 A 가 불가능 ⟺ 가중 정확 탐색이 허용된 rooted 경로를 **하나도** 찾지 못함

* **cover 단위 ∀** — 완성은 미래에 열릴 궤도 집합을 하나 고르고, 그것은 열거된 cover 중
  하나여야 한다 (H1). 따라서 상태 폐쇄는 **모든** cover 의 실패를 요구한다.
* **배정 단위 ∀** — 완성은 각 의무의 실제 진입 단어를 주고 그 단어는 `C(h)` 안에 있어야
  한다. 따라서 완성은 열거된 배정 중 정확히 하나에 대응한다.
* **경로 단위** — 정리 A.

> **과거 버그에 대한 방어.** 라운드 94 에 실제로 `any(cover fails)` 로 상태를 닫는 버그가
> 있었다. 인증기·검증기 모두 상태 판정을 `all(v == "FAIL")` 로만 계산하고, `UNKNOWN` 은
> 절대 `FAIL` 로 취급하지 않는다 (`FAIL` 은 `alive == 0 and unknown == 0` 일 때만).
> 회귀 테스트가 이를 고정한다.

## 14. 가장 약한 고리 — **테스트 양이 아니라 수학적 취약성**

| 순위 | 주장 | 취약성 근거 |
|---|---|---|
| **1** | **(H5) — 미래 joint 가 전부 weight ≤ 3 이다** | **서술된 적이 없는 가정**이다. 반증되면 뿌리 하한으로 닫히지 않은 **1,353 상태**의 폐쇄가 즉시 무효가 된다. 실측으로 생략된 호가 배정당 수백 개 존재한다. 예산 정리는 이것을 배제하지 **않는다** |
| 2 | **pass ↔ 의무 완전성** (보조정리 1) | 틀리면 정점 집합 자체가 틀린다. 감사됐지만 파급이 최대 |
| 3 | **`ℓ` 강제** (보조정리 2) | `ℓ` 이 다르면 target 사중조가 통째로 바뀐다 |
| 4 | **예산 상수** (`Ndef+H ≤ 3`, `O = 25`, `Ndef = S+F−O` 부호) | 결론이 이 부등식 하나를 통과한다. 다만 라운드-107 재계산으로 **`B+1` 과 `B+2` 에서도 잔여 0** 임이 확인돼 여유가 **적어도 2** 는 있다 — 라운드 106 이 "여유 0" 이라 적은 것은 캡 인공물이었다 |
| 5 | **성분 규약 (ROOT / terminal)** | `c` 대 `c−1` 한 칸 차이. 다만 4번과 같은 이유로 여유가 확인됐다 |
| 6 | fragment `ΔF = 0` 기하 | **이제 하중을 지지하지 않는다** (보조정리 5 가 대체) |

> **미래의 독립 감사자가 가장 먼저 공격해야 할 단 하나의 주장:**
>
> **(H5) — 의무 그래프가 weight ≤ 3 joint 만으로 만들어져도 되는가.**
>
> 이유: (i) 이것은 **증명된 적도, 서술된 적도 없다.** (ii) 반례가 존재할 여지가 실측으로
> 확인됐다 — 무거운 joint 로만 닿는 (의무→의무) 호가 배정 하나당 수백 개다. (iii) 다른
> 항목들은 틀리면 결과를 **약하게** 만들지만, (H5) 가 틀리면 1,353 상태의 폐쇄가 **거짓**이
> 된다. (iv) 반대로 (H5) 가 Q2/Area-A 슬랩 정의(`H = 0` 유지)에서 이미 따라 나온다면, 그
> 사실을 한 줄로 인용하는 것만으로 전체 결론이 무조건부가 된다 — **비용 대비 가치가 가장
> 큰 확인**이다.

## 15. 논문 형식의 잠정 정리

> **THEOREM 1 (unconditional-in-joint-weight partial exclusion).**
> Assume **(H1)** the Round-92/93c archive enumerates every state of the Q2/Area-A residual
> slab together with, for each state, every admissible future orbit-opening cover;
> **(H2)** the pass ↔ obligation bijection of Round 93; **(H3)** the ℓ-forcing rule of
> Rounds 90/91; **(H4)** the counter semantics of Definition D6 and the target of D7.
>
> Then **5,043 of the 6,396 archived states admit no completion satisfying the target
> resource constraints**, *whatever joint weights the completion uses*.
>
> **Proof.** For each such state and each of its covers and each concrete word assignment,
> the zero-cost graph `G₀` consists exactly of the `T1` arcs (Lemma 3), so its weak-component
> count `c` is independent of which heavier joints exist. Lemma 7 — stated for arbitrary
> non-negative arc costs — gives total future cost `≥ c − 1`, and Lemma 6 gives total future
> cost `≤ B`. The finite certificate records `c − 1 > B` for every cover of every one of
> those states. ∎

> **THEOREM 2 (conditional Q2 exclusion).**
> Assume (H1)–(H4) and additionally
> **(H5)** every future joint has weight at most 3 (equivalently, `H` stays 0).
>
> Then **no state of the archive admits a completion satisfying the target resource
> constraints**.
>
> **Proof.**
> *Lemma 3* fixes a single free (weight-2) joint target per obligation and entry word;
> *Lemma 4* deduces `outdeg_{G₀} ≤ 1` and *Lemma 4′* makes the computed component count exact.
> *Lemma 5* gives `ΔF = 0` from monotonicity of `F` and the target `F = 1`.
> *Lemma 6* gives the exact identity `final(Ndef+H) = current(Ndef+H) + Σ cost(ω) − K` and the
> necessary condition `Σ cost(ω) ≤ B = 3 + K − Ndef − H`; under (H5) this reads `E ≤ B`.
> *Lemma 7* bounds the remaining cost below by the zero-cost weak-component count, *Lemma 8*
> turns that into the pruning rule, and *Theorem A* shows the depth-first enumeration over the
> weight-≤3 arc set is complete under that rule alone.
> *Theorem B* fixes the quantifier nesting: a state is excluded iff **every** cover is
> excluded, a cover iff **every** concrete assignment is, an assignment iff the exhaustive
> weighted search finds no permitted rooted path.
> The **finite certificate** discharges the enumeration: 90,396 state–cover pairs, 707,007
> concrete assignments, all UNSAT, 0 UNKNOWN, 0 cap hits, 0 surviving states; the Round-106
> sub-population was independently replayed by a second implementation. ∎

> **지위.** 정리 1 은 (H1)–(H4) 조건부이고 joint weight 제한에 **의존하지 않는다.**
> 정리 2 는 추가로 **(H5) 조건부**이며, (H5) 는 이 문서가 증명하지 못한다.
> 두 정리의 결론은 **Q2/Area-A 잔여 슬랩에 대한 배제**이지 그 이상이 아니다.
