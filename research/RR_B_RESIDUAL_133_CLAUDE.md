## 0. 이 라운드가 답한 질문

라운드 132 는 `B_e1_b11_P1b` 를 **30,124,862,589 노드**로 닫았다.  이 라운드의 목표는
빠른 DFS 가 아니라 **“그 300억 노드짜리 클래스가 결국 왜 죽는가”** 를 설명하는 정리였다.
답을 찾았다 — 그리고 동시에, 그 답이 **왜 전체를 닫지는 못하는지**도 측정으로 확정했다.

## 1. 정리 133.1 (블록 충돌) — 이 라운드의 주 결과

β 둥지와 모형 T 에서는 `opener₁` 의 진입 단어가 `opener₀` 의 것으로부터 **완전히 결정**된다:

```
β  :  entry(opener₁) = τ^u(σ^{b₀}(v₀)),   u ∈ {1,2,3,4}
T  :  entry(opener₁) = τ^r(v₀),           r ∈ {1,2,3,4}
```

따라서 블록 전체의 pass 열이 `(v₀, b₀, b₁, u|r, ℓ)` 만으로 정해진다
(`ℓ` = `opener₀` 로 끝나는 `Q₀` run 의 길이 — 그 run 의 앞 `ℓ−1` pass 도 `τ^{-j}(v₀)` 로 강제된다).

> **정리 133.1.**  강제된 블록의 pass 열이 유형 B 의 육각형 다중도
> (`h₀`, `h₁` 만 정확히 두 번, 나머지 육각형은 정확히 한 번) 를 깨거나 한 궤도의 슬롯 5개를
> 넘겨 쓰면, 그 `(b₀, b₁, u|r, ℓ)` 배치는 **탐색 없이 불가능**하다.

`S₆` 는 단어에 단순추이적으로 작용하므로 살아남는 집합은 `v₀` 와 **무관**하다 — `v₀` 를
네 개(0, 17, 203, 555) 바꿔 확인했고 전부 동일했다.

| 갈래 | 살아남는 분할 | 살아남는 `(b₀,b₁,·,ℓ)` 배치 | 죽는 분할 |
|---|---|---|---|
| `B/e=1` P1-β | **15 / 25** (1.67×) | **234 / 500** (2.14×) | `b₁ ∈ {1,5}` 전부 |
| `B/e=2` D-β₀ | **12 / 25** (2.08×) | **153 / 500** (3.27×) | `b₀ = 1` 전부, `b₁ ∈ {1,5}` 전부 |
| `B/e=2` 모형 T | **16 / 25** (1.56×) | **114 / 500** (4.39×) | `b₀ = 1` 전부, `b₁ = 5` 전부 |

**α 계열(P0, P1-α, D-α)에는 적용되지 않는다** — 두 잠긴 매크로 사이에 자유 간격이 있어
`opener₁` 의 단어가 결정되지 않기 때문이다.  이것이 이 정리의 정확한 한계다.

### 300억 노드 클래스의 설명

`B_e1_b11_P1b` 는 `(b₀, b₁) = (1, 1)` 이고 `b₁ = 1` 이므로 정리 133.1 로 **한 줄에 죽는다.**
계측 실행이 이를 직접 확인한다: 그 클래스에서 20억 노드를 돌리는 동안
**짧은 블록을 끝까지 놓은 상태가 단 하나도 없었다** (`block_exit_raw = 0`).
라운드 132 의 300억 노드는 전부 **결코 블록을 완성할 수 없는 접두사**를 세는 데 쓰였다.

### 양성 대조 (§14)

정리를 그 클래스의 경험적 성질에서 끌어내지 않았다 — 독립적으로 증명하고,
합법 `n = 4` β walk **16개 전부**에 대해 술어가 참임을 확인했다 (**거짓 기각 0**).
