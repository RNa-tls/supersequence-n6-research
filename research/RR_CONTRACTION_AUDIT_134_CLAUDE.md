**감사가 찾아낸 진짜 결함 하나**: Astra 의 진술은 **`T₀ ≠ T₁`** (두 잠긴 run 이 같은 궤도를

하나에 들어가려면 pass 열 개가 필요하다), **명시되어야 한다.**  이 감사가 그 증명을 채웠다.

## 1. 정의 (§1) — 소스에서 되찾음

`src/verify_f2_structure_126.py`(기하), `src/chain_capacity_115.c`(라운드 115 모델),
`src/f0_column_115.py`(`N*` 호출), `src/g2_cell_132.c`(유형 B 엔진) 에서 되찾았다.
핵심은 **locked block 의 정의를 “lock 이 성립한다”가 아니라 *모양*으로** 잡는 것이다:

> **locked block** = 짧은 pass `(v, b)` 뒤에 `orb(σ^b(v))` 의 다섯 phase 를 **전부** 채우는
> pass 다섯 개가 오고 그 마지막이 `(σ^b(v), 6−b)` 인 6-pass 모양.

이 구분이 결정적이다 — β 의 **바깥** 블록은 lock 이 **깨졌는데도** 안쪽 축약 뒤 이 모양을
갖는다.

## 2. 축약 보조정리 (§2·§3·§4·§5) — **CONFIRMED**

> **보조정리.** locked block 을 full pass `(v, 6)` 로 바꾸면 진입 단어가 `v` 로, 탈출 단어가
> `σ^5(v)` 로 **같고**, `P → P−5`, `O → O−1` 이며 `D = 5O − P`, `S`, `H` 는 **불변**이다.

증명 요소: 블록의 여섯 pass 가 덮는 단어는 `h_X` 의 여섯 단어(= opener + closer)와 `T_X` 의
네 full pass 이고, 탈출 단어는 `σ^{(6−b)−1}(σ^b(v)) = σ^5(v)` 로 `b` 와 무관하다.  블록
내부 joint 다섯 개는 **전부 `ω = 2`** 이므로 `S`, `H` 가 안 변한다.  `T_X` 는 다섯 phase 가
전부 차 있어 다른 run 이 들어올 수 없으므로 통째로 사라져 `O` 가 정확히 1 준다.
`D` 는 `5(−1) − (−5) = 0` 으로 자동 불변.

**검사**: `n = 6` 의 **3,600** 블록(720 단어 × 5 분할) 전부, `n = 4` 의 **72** 블록 전부 —
**위반 0**.

### 외부 joint 보존 (§4) — **CONFIRMED**

`ω(a,b)` 와 `legal_joint(n,a,b,m)` 은 **순서쌍 `(a,b)` 만의 함수**이고 축약은 두 경계 단어를
글자 그대로 보존하므로, 무게 변화·중간 순열 생성·genuine/nongenuine 전환·두 joint 병합이
**전부 불가능**하다.  실제 문맥을 붙인 **4,800** 개 이음매 replay(앞 full pass + 블록/대체 +
네 가지 후속 이동 M2/M3a/M3b/M3c) 에서 두 이음매의 무게와 문자열이 전부 동일했다.

### 중복 불가 (§5) — **CONFIRMED**

육각형 다중집합이 진부분집합이 되므로(그 위에 `h_X` 가 2회 → 1회) **새 중복이 생길 수
없다.**  역방향 우려 — 다섯 pass 를 지워 라운드 115 모델이 요구하는 조건이 깨지는가 — 도
§12 에서 항목별로 확인했다.

## 5. 전달 사슬 항등식 (§10) — **CONFIRMED**

joint 세기만으로 유도된다 — **부분 사슬에서도 성립하고 끝점 보정항이 없다**:

```
joints = P'−1,  inter-run = r'−1,  intra-run = P'−r'
S' = (r' − 1 − f_out') + x'
축약 후 pass 가 전부 full 이고 full pass 의 ω=2 후속은 τ(entry) 로 **같은 궤도** ⇒ f_out' = 0
r' = O' + e'   ⇒   S' = O' − 1 + e' + x'
25 = 26 − 1 + e' + x'   ⇒   e' + x' = 0   ⇒   e' = x' = 0     (둘 다 ≥ 0)
```

`x' ≥ 1` 이었다면 `e' = −x' < 0` 이라 불가능하므로 결론은 어느 쪽으로도 성립한다.

## 6. 라운드 115 포함 (§11·§12) — **CONFIRMED** (두 번째 하중 지점)

`src/chain_capacity_115.c` 의 **원본** 정의:
`N*(b,g,s)` = 예산 `(b,g,s)` 에서 **사슬 하나**가 가질 수 있는 최대 pass 수.
`b` = 국소 `e + x`, `g` = 다른 사슬로 넘기는 미완성 궤도 토큰(풀 `2e`),
`s` = 영구 미사용 phase (`feasible()` 은 `Σ_건드린궤도 결손 ≤ s`).
**사슬 = 경량 연결자 `W3b`/`W3c` 로만 이어진 극대 run 열.**

이 라운드의 **결정적 사실**:

| 이동 | ω | pass 궤도와 같은가 | 720 단어 중 |
|---|---|---|---|
| `M2` | 2 | **같다** | 720 |
| `M3a` | 3 | **같다** | 720 |
| `M3b` | 3 | 다르다 | 720 |
| `M3c` | 3 | 다르다 | 720 |

`W3b = M3b`, `W3c = M3c` 이고 빠진 `M3a` 는 **항상 같은 궤도**다 — 즉 `M3a` 는 run **내부**
`ω=3` 호(= `x`-호)일 뿐 inter-run 연결자가 **될 수 없다.**  그러므로 라운드 115 의
두-연결자 모델은 **완전하고**, 축약 결과물은 `x' = 0` 이라 `M3a` joint 를 하나도 갖지
않아 `ω=3` joint 25 개가 전부 사슬 연결자다 ⇒ **112 pass 전체가 사슬 하나**다.

포함 검사표(전 항목 만족):

| 가설 | 만족 | 근거 |
|---|---|---|
| 모든 pass 가 full (육각형당 단어 하나) | ✓ | 축약 후 112 pass / 112 육각형 |
| 두 단어가 같은 육각형에 없음 | ✓ | 축약은 제거뿐 — 중복 생성 불가 |
| run = 한 궤도 안의 극대 연속 구간 | ✓ | 축약이 바꾸지 않는다 |
| 사슬 = `W3b`/`W3c` 로만 이어진 run 열 | ✓ | 위 `M3a` 사실 |
| `b = e + x = 0` | ✓ | 항등식이 강제 |
| `g = 0` (풀 `2e`) | ✓ | `e' = 0` |
| `Σ 결손 ≤ s` | ✓ | `130 − 112 = 18 ≤ 20` |
| **사슬 단위 상한이지 완전 덮개 조건이 아님** | ✓ | `chain_capacity_115.c` 는 120 pass 를 **요구하지 않는다** — 부분 대상에 완전성 조건을 들여오지 않는다 |
| `S₆` 로 시작 단어 고정 | ✓ | 재명명이 `σ, τ, W3b, W3c` 와 가환이고 단어에 추이적 |
| 모델이 현실의 **완화**(⇒ 상한 유효) | ✓ | run 확장이 임의 미사용 phase 로 가능하고 joint 합법성을 검사조차 하지 않는다 |
| `s = 20` 이 결손 18 짜리 대상에 허용 | ✓ | `feasible` 은 `≤ SCAP` 으로 단조 |

## 10. 반례 탐색 (§18)

* **유일한 진짜 위험**: 축약은 pass 의 궤도를 `T_X` 에서 `orb(v)` 로 바꾸므로 블록 **뒤**
  joint 의 run 내/외 분류가 바뀔 수 있다.  이것이 바로 `f_out' = 0` 을 만드는 현상이고,
  항등식을 **축약 결과물 자체에서** 유도했으므로 이미 반영되어 있다.  재분류된 joint 가
  `M3a` 라면 `x' ≥ 1` 이 되는데 그러면 `e' = −x' < 0` 이라 그런 walk 은 **존재하지 않는다.**
* **가짜 블록**(궤도 다섯 phase 를 다 채우지 않는 6-pass 덩어리)은 축약 시 `O` 가 1 이
  아니라 0 만큼 줄어 `D` 를 깨뜨릴 수 있다 — 그러나 잠긴 run 은 정의상 `τ^1(c) … τ^5(c)`
  라 항상 다섯 phase 를 채운다 (3,600 사례 확인).
