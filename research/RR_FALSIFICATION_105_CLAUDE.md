## 1. 성공한 공격 — `L2 = c − 1` 은 그대로는 거짓 (§7, §8)

무작위 0/1 유향 그래프에 대해 **모든 rooted Hamilton 경로를 전수 열거**해 참 최소 비용
`C*` 를 구하고 솔버 판정과 대조했다.

| | |
|---|---|
| 검사한 (그래프, `B`) 쌍 | **42,052** (UNKNOWN 0) |
| 비용-0 유출 차수 ≤ 1 로 제한한 절반 | **불일치 0** |
| 제한 없는 절반 | **불일치 111** — 전부 `솔버 UNSAT / 실제 SAT` |

원인은 구현이 아니라 **서술**이다. 성분 병합이 각 정점의 비용-0 후속을 **하나만** 보므로,
어떤 정점이 비용-0 후속을 둘 이상 가지면 성분 수가 **과대계수**되고 하한이 부풀어
**불건전**해진다.

> **정정된 서술.** *각 정점의 비용-0 유출 차수가 ≤ 1 인 그래프에서* 남은 집합 위의 비용-0
> 약연결 성분이 `c` 개면 남은 경로는 비용-1 호를 `≥ c − 1` 개 쓴다.
> (증명: 쓰인 비용-0 호는 선형 숲을 이루고 그 성분이 약연결 성분을 세분하므로
> `|rem| − y ≥ c`, 따라서 내부 비용-1 호 `≥ (|rem|−1) − (|rem|−c) = c − 1`. ∎)

**전제 검증.** 실제 기하에서는 `T1` 이 유일한 비용-0 target 이므로 전제가 성립해야 한다.
확인했다 — **173,409 배정 전수에서 최대 비용-0 유출 차수 1, 위반 0.**
`probe_rr_weighted_path.py` 에 `assert` 와 주석으로 명시했다.

## 2. `ΔF = 0` — 일반 명제로는 틀렸고, 모델 안에서는 참 (§2)

라운드 104 는 "회전 뒤 σ-후속이 이미 방문됐으므로 abandonment 없음" 이라고만 적었다.
엔진 전수 스캔은 그것이 **일반적으로 거짓**임을 보여 준다:

| `ℓ` | abandonment=True | abandonment=False |
|---|---|---|
| 0 | 148,825 | 0 |
| 1 | 148,496 | 0 |
| 2 | 148,273 | 0 |
| 3 | 148,102 | 0 |
| 4 | 147,721 | 0 |
| **5** | **0** | **147,782** |

즉 `ℓ < 5` 는 임의의 시작점에서 **항상** abandonment 를 일으킨다. 모델이 쓰는 `ℓ<5` 는
fragment 수리뿐이므로 그 경우만 따로 검증해야 한다 — **`r=0` 상태 5,732개 전부에서**
조각 진입 단어에서 `ℓ = 5−c_f` 회전한 뒤의 σ-후속이 **이미 방문된 칸**이었다
(`c_f` 별 1,487 / 1,562 / 1,323 / 915 / 445, 예외 0).

> **정정된 서술.** `ΔF = 0` 은 `ℓ<5` 의 일반 성질이 아니라, **fragment 수리 회전이 조각의
> 이미 방문된 부분의 경계에서 끝난다**는 기하적 사실에서 나온다.

## 3. `H` 와 `ΔO` (§3, §5)

엔진에서 직접 읽은 갱신표:

`dH = max(w−3,0) ≥ 0` 이므로 **`H` 는 결코 감소하지 않는다** — §3 의 답은 **A**, 따라서
