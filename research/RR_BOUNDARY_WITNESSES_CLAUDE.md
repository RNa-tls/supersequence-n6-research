## 4. 가장 작은 빠진 제약 (§8)

> **SHORT-PASS LOCALITY.** `ℓ < 5` 인 매크로 edge 는 **그 시점에 이미 방문 칸이 있고 아직
> 가득 차지 않은 육각형**에서 출발해야 한다. `F = 1 = TARGET_F` 와 pass 계수 항등식 아래에서
> 그런 육각형은 fragment 뿐이며, 그때 시작 칸은 `v_{c_f}` 로, 회전 길이는 `5 − c_f` 로
> **유일하게 결정**된다.

이것이 이번 부검의 **주 산출물**이며, 네 상태의 폐쇄가 아니다. 현재 모델과의 차이는
정확히 하나 — 라운드 88/90 의 결합 조건은 short edge 를 **개수**로만 세고, 이 제약은 그것을
**자리**로 센다.

**감사 대기.** 이 제약은 라운드 90 에서 4개 폐쇄에 실제로 쓰였고 Codex 가 재현하지 못한
부분이다. 따라서 이번 라운드에서는 **원장을 움직이는 데 쓰지 않는다.** Codex 의 독립 감사를
받은 뒤에만 폐쇄 근거로 승격한다. 감사가 봐야 할 지점은 셋이다.

1. pass 가 한 육각형 안의 연속 구간을 방문한다는 것(σ 가 육각형 내부 6-순환).
2. `F = TARGET_F` 에서 abandonment 금지 ⟹ 출발 칸 `w` 는 `σ(w)` 방문 필요.
3. 120 육각형 · `P = 121` ⟹ 정확히 한 육각형만 2 pass, 그것이 fragment.

## 5. 121 / 125 port 등록 좌표의 정체 (§10)

조심스럽게 유도한 결과, 이 관찰은 **새 좌표가 아니다.**

`ORBIT_PHASE` 는 720 단어 ↔ 144 궤도 × 5 위상의 전단사이므로 port 하나가 단어 하나다.
`P = Σ popcount(orbit_masks)` 는 **pass 시작(= joint target)으로 등록된 port 수**이고,
`D = Σ (5 − popcount)` 는 열린 궤도의 **미등록 port 수**다. 잔여 전체에서

    D == 5·O − P        (6,657 / 6,657, 위반 0)

이 성립하고 `TARGET_D = 4`, `TARGET_O = 25`, `TARGET_P = 121` 이므로 "최종 125 port 중
121 등록, 미등록 4" 는 **정확히 `D_final = 4`** 이다. 엔진은 이미 `arithmetic_D_reachable`
로 이 좌표를 가지치기에 쓰고 있다.

주의해서 구분해야 할 것: **등록 port ≠ 방문 window**. 최종적으로 720 단어가 모두 방문되므로
미등록 4개도 방문은 된다(회전 구간 내부로). 따라서 "선택된 궤도의 모든 port 가 방문돼야
한다"는 명제는 참이지만 **등록에 대해서는 거짓**이며, 여기서 얻을 수 있는 것은 등록 계수뿐이다.

새로울 수 있는 것은 계수가 아니라 **경로 버전** — 미래 walk 이 최종 25궤도의 125 port 중
121 개를 하나의 경로로 지나야 한다는 조건이다. 라운드 90 에서 관대한 port 관계(out-degree
24)로 유입차수 0 검사와 SCC 응축 검사를 해봤고 19개 모두 **강연결**이라 폐쇄 0 이었다.
회전 run 의 window 소비를 넣지 않으면 이 방향은 열리지 않는다.
