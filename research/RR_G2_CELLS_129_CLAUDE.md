## 1. `G = 2` 항등식 재유도 (§1)

`F` 대입 없이 처음부터.

    G = 2
    P = 120 + G = **122**
    L = 844 + G + S + H = **846 + S + H**          L ≤ 871 ⟺ **S + H ≤ 25**
    D = 5O − P = 5(24+k) − 122 = **5k − 2** ≥ 0    ⟹ **k ≥ 1**
    N = S + G − O = **S − 22 − k**
    r = O + e = 24 + k + e
    S = (r − 1) + x − f_out = **23 + k + e + x − f_out**
    L = 867 + k + G + e + x + H − f_out = **869 + k + e + x + H − f_out**
    **L ≤ 871 ⟺ k + e + x + H − f_out ≤ 2**
    run 결손 = 5r − P = **5k + 5e − 2 = D + 5e**

`S = (r−1) + x − f_out` 의 유도는 `F` 도 `G` 도 쓰지 않는다 (라운드 126 §7):
full pass 의 `ω=2` 탈출 `τ(u)` 는 같은 궤도라 inter-run 이 아니고, 짧은 pass 의 `ω=2` 탈출은
언제나 inter-run 이므로 `#{inter-run, ω=2} = f_out` 이다.

## 2. `G = 2` 안의 프로젝트 `F` (§2)

라운드 128: `J = G − F = Σ_h (d_h − 1)` 이고 `abandonment(p) ⟺ p < ν(p)` 이므로
**`F` = `ν`-상승의 개수**다.

* **유형 B** — `ν` 가 길이 2 인 순환 둘.  선형 순서 위의 2-순환은 상승과 하강이 **정확히
  하나씩**이므로 `d_h = 1` 이 두 육각형 모두에서 **강제**된다 ⟹ `J = 0` ⟹ **`F = 2` 필연.**
* **유형 A** — `ν` 가 길이 3 인 순환 하나.  `d ∈ {1,2}` ⟹ `J ∈ {0,1}` ⟹ **`F ∈ {1,2}`.**

## 5. 내부 `F` 는 **국소 순서만으로** 결정된다 (§5)

유형 A 의 세 pass `p₀ → p₁ → p₂ → p₀` (`ν`) 의 walk 순서 6가지를 전수하면:

| walk 순서 | 상승 | `F` | `d` | `J` |
|---|---|---|---|---|
| `p₀ p₁ p₂` | 2 | **2** | 1 | 0 |
| `p₁ p₂ p₀` | 2 | **2** | 1 | 0 |
| `p₂ p₀ p₁` | 2 | **2** | 1 | 0 |
| `p₀ p₂ p₁` | 1 | **1** | 2 | 1 |
| `p₁ p₀ p₂` | 1 | **1** | 2 | 1 |
| `p₂ p₁ p₀` | 1 | **1** | 2 | 1 |

> **`F = 2` ⟺ walk 순서가 `ν`-순서의 순환 회전, `F = 1` ⟺ 역순환.**
> `F` 는 세 짧은 pass 의 상대 순서**만**으로 결정된다 — 다른 정보가 필요 없다.

`n = 4` 전수에서 이 규칙은 **1,184/1,184 정확**하다 (§14).

## 6·12·13. 자유 탈출 상한 (§6, §12, §13)

**일반 상한**: `ω = 2` 인 inter-run 호는 짧은 pass 에서만 나오므로 **`f_out ≤ G + m`**
(유형 A 3, 유형 B 4).

**보조정리 E′** (라운드 126): 다중 진입 육각형의 pass 가 **전부** 자유로 나가면 `e ≥ 1`.

### 유형 A (§12)

* 일반: `f_out = 3` ⟹ 세 pass 전부 자유 ⟹ E′ ⟹ `e ≥ 1` ⟹ **`f_out ≤ 2 + e`.**
* **더 강한 상한 `f_out ≤ F + e` (정리 129.1)** — 위 §0 의 증명.
* **더 강한 *일반* 상한은 없다.**  `e = 1` 이면 세 목표 궤도가 서로 달라 경우 (ii) 가 많아야
  하나이고, 남은 둘이 경우 (i) 이면 `p₂ < p₃ < p₁` 이 되어 **모순이 생기지 않는다.**
  실제로 `n = 4` 에 `유형 A, f_out = 3, e = 1` 이 30개 존재한다(전부 `F = 2`).
  ⟹ 이 방향에서 유형 A 전용의 추가 강화는 **없다** (정직한 음성 결과).

### 유형 B (§13) — 정확한 자유 탈출 표

| `f_out` | 강제되는 `e` | 근거 |
|---|---|---|
| 0, 1, 2 | `≥ 0` | 없음 |
| **3** | **`≥ 1`** | 비둘기집으로 어느 한 육각형이 완전 자유 ⟹ E′ |
| **4** | **`≥ 2`** | 라운드 127 순서 정리 |

`n = 4` 실측 최소 `e`: `f=0,1,2 → 0`, **`f=3 → 1`**, **`f=4 → 2`** — 표와 **정확히 일치하고 tight**.

## 7. 정리 A 와 master 부등식 (§7)

`S = (r−1) + x − f_out`, `r = O + e` 를 넣으면 `O ≤ 1 + S + G ⟺ f_out ≤ G + e + x` 이고,
`f_out ≤ G + e` 가 이를 함의한다 ⟹ **`G = 2` 에서 정리 A 성립.**

    k + e + x + H − f_out ≤ 2   그리고   f_out − e ≤ G = 2
    ⟹ **k + x + H ≤ 4**   (실측 최대 = 4 ✓)

내부 정밀화 (정리 129.1): `f_out − e ≤ F` 이므로 **`k + x + H ≤ 2 + F`**:

| 모형 | `k + x + H` 상한 | 실측 최대 |
|---|---|---|
| A / `F = 1` | **3** | 3 ✓ |
| A / `F = 2` | 4 | 4 ✓ |
| B / `F = 2` | 4 | 4 ✓ |

## 8·9. 실현 가능한 `k` 와 최대 `H` (§8, §9)

`D = 5k − 2 ≥ 0 ⟹ k ≥ 1`; `k + x + H ≤ 4` 와 `H, x ≥ 0 ⟹ k ≤ 4`.
⟹ **`k ∈ {1, 2, 3, 4}` — `G = 2` 열은 정확히 네 칸.**

`H ≤ 4 − k − x ≤ 3` 이고 `H = 3` 은 `k = 1, x = 0` 에서만 — **`max H = 3`**.
(라운드 126 산문에서 물려받지 않고 정정된 예산에서 다시 유도했다.)
