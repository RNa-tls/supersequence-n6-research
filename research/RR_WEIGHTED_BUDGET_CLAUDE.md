## 1. 예산 정리 (§0) — 사건 종류별로 다시 유도

미래 구간의 각 pass 는 `ℓ` 회전(weight 1) + joint 하나다. 엔진의 갱신은

```
dS = [weight ≥ 3]      dH = max(weight − 3, 0)      dF = [abandonment]
```

| 항 | 값 | 근거 |
|---|---|---|
| `ΔF` | **0** | `ℓ=5` pass 는 회전 뒤 커서의 σ-후속이 진입 단어라 **이미 방문**됨 → abandonment 없음. fragment 수리(`ℓ=5−c_f`)도 σ-후속이 이미 방문된 칸. 22개 재생 trace 에서 `abandonment=True` 가 **한 번도** 나오지 않았다 |
| `ΔS` | **`E`** = weight-3 joint 개수 | `T1` 최소 weight 2, `T2/T3/T4` 최소 weight 3 |
| `ΔH` | **0** | 위 네 target 의 **최소** weight 가 2 또는 3 이므로 `max(w−3,0)=0`. 같은 target 에 weight-6 tail 도 있으므로 실제는 더 비쌀 수 있으나 **더 싸지지 않는다** — 하한이라 필요조건으로 안전 |
| `ΔO` | **`K`** | 완성 시 `O = 25`, `K = 25 − O_now` |

`Ndef = S + F − O` 이므로

```
final(Ndef + H) = current(Ndef + H) + E − K
```

이고 `final(Ndef+H) ≤ 3` 에서

> **`E ≤ B := 3 + K − Ndef − H`.**

**§3 검증:** 22개 증인 전부에서 `E − B = final(Ndef+H) − 3` 이 **정확히** 성립한다
(`identity_holds: true`). 즉 이 항등식은 literal 엔진의 실제 최종 상태와 맞물린다.

전형값: `B` 중앙값 **21**, 범위 18–24. 미래 pass 는 107–108개다.

## 2. 비용과 가중 경로 조건 (§1)

구체 배정 그래프의 간선에 `cost = 0`(`T1`) / `1`(`T2/T3/T4`) 를 붙인다. genuine 완성은

> **총비용 ≤ `B` 인 rooted Hamilton 경로**

를 유도한다. 위반은 폐쇄 근거다.

## 3. 값싼 하한 두 개 (§4, §10, §12)

| 하한 | 정의 | payoff |
|---|---|---|
| `L1` 비용-0 매칭 결손 | `(m+1) − ν0`, `ν0 = |서로 다른 비용-0 target| + 1` | 중앙값 **6** 대 `B` 21 — **폐쇄 0** |
| `L2` **비용-0 성분** | 남은 의무 위 비용-0 호의 약연결 성분 수 `c` 에서 `c − 1` | 중앙값 **23** 대 `B` 21 — **여기가 물었다** |

`L2` 의 증명: 남은 집합 `rem` 위의 경로는 `|rem|−1` 개의 내부 호를 쓰고, 그중 비용-0 호들은
선형 숲을 이루며 그 성분은 약연결 성분을 **세분**한다. 선형 숲의 성분 수 `|rem| − y ≥ c`
이므로 `y ≤ |rem| − c`, 따라서 내부 비용-1 호는 `≥ c − 1` 개다. 현재 정점에서 비용-0 로
나갈 수 없으면 진입 호도 비용 1 이므로 `≥ c`. ∎

## 4. 기전 — **`T1` 사슬은 길지 않고 고리가 많다** (§9, §11)

독립 계수 코드(DFS 없이, `probe_rr_weighted_path` 미사용)로 다시 셌다:

| | |
|---|---|
| 유효한 비용-0(`T1`) 호 비율 | **93.9 %** — 의무 107개 중 약 100개가 `T1` 후속을 갖는다 |
| 그런데 비용-0 **성분 수** | 중앙값 **24** (22–27) |
| 뿌리에서 이미 `c − 1 > B` 인 쌍 | **11,300 / 15,781** |

100개의 호가 107개 정점을 겨우 24개 성분으로만 묶는다는 것은, 그 함수형 그래프에
**고리가 약 17개** 있다는 뜻이다. 경로는 고리를 완주할 수 없으므로 고리마다 끊어야 하고,
그 끊음이 전부 비용 1 이다. **`T1` 간선이 국소적으로는 풍부한데 전역적으로는 쓸 수 없다** —
라운드 103 이 "단순 계수로는 안 잡힌다" 고 한 이유가 이것이다.

## 7. **이 결과를 무효화할 수 있는 것들** — 반드시 함께 읽어야 한다

1. **`ΔH = 0` 가정.** 각 target 에 대해 **최소 weight** 를 썼다. 실제 walk 이 같은 target 에
   weight-6 tail 을 쓰면 비용이 커질 뿐이므로 하한으로는 안전하지만, 만약 어떤 target 에
   **weight 2 보다 싼 경로**가 있다면 무효다 (현재 기하로는 없다).
2. **`ΔO = K`.** 완성이 정확히 `K` 개의 새 궤도를 연다는 것. `TARGET_O = 25` 에서 나온다.
3. **pass ↔ 의무 전단사.** 라운드 93 에서 감사된 사실. 미래에 의무 밖의 pass 가 가능하면 무효.
4. **`ℓ` 강제.** 라운드 90/91. 모든 `ℓ` 을 허용하면 라운드 99 이후의 모든 층이 무효가 된다.
5. **양성 대조가 약하다 (§16).** 표본 400쌍에서 실제 경로가 나온 것은 **3개뿐**이고, 그 3개는
   `B = 실제 비용` 에서 **전부 SAT**(거짓 UNSAT 0)이었다. 그러나 *목표 슬랩에 도달하는*
   합법 완성은 아카이브에 하나도 없으므로 **진짜 양성 대조는 존재하지 않는다.** 이것이 이
   라운드의 가장 큰 잔여 위험이다.

> **따라서 "Q2 잔여가 0 이 됐다" 고 주장하지 않는다.** 주장하는 것은:
> *감사된 pass 모델 · `ℓ` 강제 · 단어 배정 틀 안에서, 남은 4,230 상태 전부가 `N+H` 예산을
> 만족하는 rooted Hamilton 경로를 갖지 못한다*는 것이고, 그것도 **Claude 단독 계산**이다.
