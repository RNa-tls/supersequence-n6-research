## 0. 결과

> ### 정리 (`F = 0` 열 배제)
> **NR6 아래에서, `F = 0` 인 모든 walk 은 `L ≥ 872` 다.**
> 즉 길이 ≤ 871 인 초순열은 `k = 0,1,2,3,4` 어느 칸에도 존재할 수 없다.
>
> 동치인 tradeoff 형태:
> **`H + k + e + x ≥ 5`** (`e = r − O`, `x` = run 내부 비자유 호).
> 특히 브리프 §11 이 목표로 삼은 **`H + k ≥ 5`** 가 따라 나온다.
>
> **55칸 중 `F = 0` 열의 5칸이 모두 닫혔다.** 라운드 114 가 닫은 `(0,0)` 에 더해
> **`(1,0)`, `(2,0)`, `(3,0)`, `(4,0)` 이 새로 닫혔다.** 남은 칸은 **50칸**이며 모두 `F ≥ 1` 이다.

**이 라운드가 라운드 114 에 대해 발견한 것도 함께 적는다** — §7.4 의 정정 상자를 보라.
라운드 114 의 **결론은 옳다.** 그러나 그 계산 모델의 **부과 규칙이 실제보다 엄격했고**,
정정된(더 관대한) 규칙에서는 라운드 114 의 *궤도 세기* 논증이 `(k,e,x,t) = (0,3,0,2)`
하위경우를 더 이상 닫지 못한다. 이 라운드의 **pass 세기** 논증이 그것을 닫는다.

## 1. `F = 0` 의 정확한 구조 (§1)

정의만으로 다시 유도한다. `P` = pass 수, `O` = 진입 단어가 만나는 서로 다른 E-궤도 수,
`k := O − 24`, `D := 5O − P` (역사적 정의), `F` = abandonment 수.

* `P = 120 + F` 이므로 **`F = 0 ⟹ P = 120`.**
* `O = 24 + k` 는 `k` 의 정의다.
* `D = 5O − P = 5(24+k) − 120 = **5k**` (일반형 `D = 5k − F` 의 `F=0` 경우).

### 1.1 보조정리 A — **pass ↔ 육각형 전단사** (새 결과)

> **`F = 0` 인 NR6 walk 에서 모든 pass 는 육각형 하나를 통째로 쓸고(순열 6개),
> 120개 pass 는 120개 육각형과 전단사 대응한다.**

**증명.** pass 는 극대 회전 런이므로 한 육각형 안에 있고, `σ` 의 위수가 6 이며 NR6 는 순열
재방문을 금하므로 pass 의 길이는 ≤ 6 이다. `F = 0` 이면 pass 는 정확히 120개이고 순열은 720개
이므로 `Σ(pass 길이) = 720 ≤ 6·120 = 720` — 등호이므로 **모든 pass 의 길이가 정확히 6**,
즉 각 pass 가 육각형 하나를 통째로 덮는다. 두 pass 가 같은 육각형에 있으면 순열이 반복되므로
불가능하다. 따라서 전단사다. ∎

이것이 라운드 113/114 가 쓰던 **궤도 수준** 서술("덮개의 24궤도가 쌍마다 육각형-서로소")의
정확한 일반화다. `k > 0` 에서는 궤도들이 육각형을 공유할 수 있지만, **사용된 단어**는 절대
육각형을 공유할 수 없다. 이 라운드의 모든 탐색은 이 **하드 제약**을 그대로 쓴다.

*이 저장소의 greedy 873 에서 직접 확인했다: pass 길이 집합 `{6}`, 진입 육각형 **120개 서로 다름**.*

### 1.2 `D` 의 조합적 의미 — §1 의 물음에 대한 답: **그렇다**

전수 계산: **모든 궤도는 정확히 5개의 서로 다른 육각형을 만나고(144/144), 모든 육각형은
정확히 6개의 서로 다른 궤도를 만난다(120/120).**

`F = 0` 이면 120개 육각형이 **전부** 덮이므로 (보조정리 A)

    Σ_h (mult(h) − 1) = 5O − 120 = 5k = D.

> **`F = 0` 에서 `D` 는 정확히 선택된 궤도족의 육각형 초과 접촉 총량이다.**
> 즉 `k` 는 라운드 114 가 쓴 **24-궤도 정확 덮개로부터의 이탈량**을 정확히 잰다.
> (일반 `F` 에서는 초과 접촉이 여전히 `5k` 인 반면 `D = 5k − F` 이므로 **둘이 갈라진다** —
> 이 동일시를 `F > 0` 으로 옮기지 않는다.)

## 4. `W3b` 자유의 정확한 특성화 (§4)

전수 계산 결과 궤도 수준 `W3b` 디그래프는 극히 규칙적이다.

## 5. 결함 자원 — **"이동 하나당 토큰 하나"는 거짓이다** (§5)

브리프 §5 는 "토큰 하나당 이동 하나를 증명 없이 가정하지 말라"고 했다. 실제로 거짓이다.

육각형 `h` 에 선택된 궤도가 `m` 개면 그 육각형의 결함은 `m − 1` 이지만, §4 의 1-정규성 때문에
**양 끝이 모두 선택된 `W3b` 호는 최대 `m` 개**다. 따라서

    사용 가능한 W3b 연결자 수  ≤  Σ_{h: m_h ≥ 2} m_h  ≤  10k,

즉 결함 예산 `5k` 의 **두 배**까지 갈 수 있다. `m = 6` 인 육각형 하나는 결함 5 를 쓰면서
`W3b` 호 6개를 지탱한다. **하나의 중첩 자원이 여러 `W3b` 사용을 지탱할 수 있다.**

> 그러므로 `W3b` 사용을 `5k` 에 직접 부과하는 논증은 **세울 수 없다.**
> 대신 이 라운드는 **보조정리 A 의 단어 수준 육각형 단사성**을 자원으로 쓴다 —
> 그것은 예산이 아니라 **하드 제약**이고, 궤도 수준 중첩 회계보다 훨씬 강하다.

## 6. `k = 0` 강성의 대수적 이유 (새 관찰)

`σ, τ, W3a, W3b, W3c` 는 전부 **위치 치환에 의한 오른쪽 곱셈**이다. 단어를 `S₆` 의 원소로 보면

* 육각형 = `⟨σ⟩` 의 왼쪽 잉여류 (크기 6),
* E-궤도 = `⟨τ⟩` 의 왼쪽 잉여류 (크기 5),
* 모든 이동 = 고정 원소에 의한 오른쪽 곱셈.

`s = 0`(모든 run 이 완전한 5-phase 블록)이면 탈출 단어가 `τ⁴(진입)` 으로 강제되므로 사슬은
결정적 사상 `D(u) = W3c(τ⁴u)` 를 따른다. 전수 계산:

> **`D` 는 720 단어 전부에서 위수 4 다** (`D⁴ = id`, 분포 `{4: 720}`).

그래서 블록 사슬은 정확히 궤도 4개 뒤에 **자기 자신으로 되돌아온다** — 라운드 113 의
`M(0) = 4` 와 라운드 114 의 `M*(0) = 4` 가 이것이다. **`k > 0` 이 깨는 것은 바로 이 강성**이다:
shortfall 이 생기면 탈출 phase 를 고를 수 있어 `D` 의 결정성이 사라진다.

## 7. 일반화된 사슬 용량 — **궤도가 아니라 pass 를 센다** (§7)

### 7.1 정확한 회계 (§8, §11)

`F = 0` 이면 `L = 844 + S + H`. 자유 호(`τ`)는 궤도를 바꾸지 않으므로 전부 run 내부이고,
run 내부 호는 `120 − r` 개이므로 라운드 114 와 같이

    S = (r − 1) + x,        H ≥ t − 1,        r ≥ O = 24 + k,   e := r − O

    ⇒  cost = S + H ≥ 22 + k + e + x + t.

> **`L ≤ 871 ⟺ cost ≤ 27 ⟺ k + e + x + t ≤ 5`.**
> `t ≥ 1` 이므로 `k + e + x ≤ 4`, 그리고 `H ≥ t − 1` 에서 **`H + k + e + x ≤ 4`** 가
> `L ≤ 871` 의 필요조건이다. 이 라운드는 그것이 **불가능**함을 보인다.

### 7.2 왜 pass 인가

라운드 114 는 사슬별 **궤도 수**를 세고 `Σ d_i ≥ O` 를 썼다. 그런데 궤도는 여러 사슬에 걸칠 수
있어 `Σ d_i` 가 `O` 를 넘을 수 있다 — 부등식이 헐거워진다. 반면 **pass 는 사슬들을 정확히
분할한다**:

    Σ_i (사슬 i 의 pass 수) = 120   (정확히, 보조정리 A 로 육각형 120개와 같다).

그래서 이 라운드는 `N*(b,g,s)` = **한 사슬이 가질 수 있는 최대 pass 수**를 쓴다.

### 7.3 사슬별 예산과 그 전역 풀

사슬 `i` 에 대해 `ρ_i` = run 수, `d_i` = 서로 다른 궤도 수, `x_i` = run 내부 비자유 호 수.
궤도 `q` 가 `c_q` 개 사슬에 `t_q` 개 run 으로 나뉘면 `Σ_q (t_q − 1) = e` 이고, 이를
`y := Σ_i (ρ_i − d_i)` 와 `h := Σ_q (c_q − 1)` 로 쪼개면 **`h + y = e`**.

| 자원 | 정의 | 전역 풀 |
|---|---|---|
| `b_i` | 사슬 안의 여분 run + run 내부 비자유 호 | `Σ b_i ≤ y + x` |
| `g_i` | 미완성 궤도를 다른 사슬로 넘기는 사건 | `Σ g_i ≤ 2h` |
| `s_i` | 영구히 쓰이지 않는 phase (`Σ_q (5−|B_q|) = 5k`) | `Σ s_i ≤ 5k` |

`Σ g_i ≤ 2h` 의 증명: `c_q ≥ 2` 인 궤도는 `c_q` 개 사슬 모두에서 미완성으로 보이지만 실제
비용은 `c_q − 1` 이다. `c_q ≤ 2(c_q − 1)` 이므로 사건 총수 `Σ_{c_q≥2} c_q ≤ 2Σ(c_q−1) = 2h`. ∎
**`t = 1` 이면 넘길 상대가 없으므로 `h = 0`, 따라서 `g = 0`.**

### 7.4 정정 상자 — 라운드 114 의 부과 규칙

> **정정 (라운드 114 §3–§4).**
> 라운드 114 의 계산 모델은 **매 시점 미완성인 모든 궤도에 예산 `B = e+x` 를 1씩 부과**했다.
> 그러나 라운드 114 자신의 telescoping 항등식 `Σ(a_i−1) + (c_q−1) = t_q−1` 은 **쪼개진 궤도마다
> 사슬 하나를 무부과로 남긴다.** 따라서 그 모델은 `e ≥ 1` 에서 **실제보다 엄격**했고,
> `M*(B) = 3B + 4` 는 참된 사슬 용량의 **과소 평가**다.
>
> **라운드 114 의 결론(`(k,F)=(0,0)` 폐쇄)은 그대로 성립한다** — 이 라운드가 정정된(더 관대한)
> 모델로 다시 계산해 `k = 0` 의 **50개 하위경우 전부**를 닫았다(최악 116 pass < 120).
> 다만 **정정된 모델에서 라운드 114 의 *궤도 세기* 논증은 더 이상 충분하지 않다**:
> `(k,e,x,t) = (0,3,0,2)`, `h = 3` 에서 궤도 상한은
> `Σd_i ≤ (4+3g₁) + (4+3g₂) = 8 + 3·6 = 26 ≥ 24` 라 모순이 나오지 않는다.
> **pass 상한은 나온다**: `Σ N*(0,g_i,0) ≤ 96 + 20 = 116 < 120`.
> 라운드 114 문서는 지우지 않았다. 위 사실이 그 문서의 §3–§4 에 대한 정정이다.

## 11. 반증 시도 (§15)

세 수준을 분리해 찾았다.

* **A (궤도 덮개 배치)**: `H + k ≤ 4` 를 허용하는 산술적 배치는 **존재한다** —
  `(k,e,x,t)` 91개 중 `k+e+x+t ≤ 5` 인 것 전부가 그렇다. 즉 산술만으로는 죽지 않는다.
* **B (phase 정합 run 경로)**: 사슬 용량 상한이 88개를 죽이고, 3개(R1–R3)가 **정확히 경계**에서
  살아남는다. R3 의 `(s₁,s₂) ∈ {(4,11),(7,8)}` 이 `120 = 120` 으로 딱 맞는 것을 보존해 둔다 —
  **가장 작은 B-수준 근접 반례**이며, 사슬별 상한만으로는 배제되지 않는다.
* **C (실제 NR6 walk)**: 결합 탐색이 R1–R3 를 전수로 죽인다. **C-수준 반례는 없다.**

`H + k ≤ 4` 를 만족하는 기하학적으로 유효한 `F = 0` 배치는 찾지 못했다.
