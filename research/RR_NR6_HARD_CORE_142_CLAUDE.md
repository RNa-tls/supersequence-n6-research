# NR6 하드 코어 — 덮는-walk 재정식화, 결함 항등식, 그리고 순환성의 정체

이 라운드는 라운드 141 의 서술을 다듬지 않는다.  대상을 처음부터 다시 세우고,
그 위에서 **무엇이 실제로 남은 문제인지**를 정확히 규명한다.

> `NR6` 는 **증명되지도 반증되지도 않았다.**  이 프로젝트는 `L6 >= 872` 를
> 증명하지 않았다.  아래 결과는 전부 무조건적(unconditional)이며 바깥 55/55
> 정리를 전제하지 않는다.

## 1. 정확한 대상 — 덮는-walk 재정식화

`CG_n` 을 `n!` 개 순열 위의 유향그래프로 두되, 변 `(p,q)` 는 최대겹침 철자
`p·(q 의 끝 w 글자)` 의 **내부에 순열 창이 없을 때**(= CLEAN) 만 넣는다.
무게 `w(p,q) = n - maxoverlap`.

**보조정리 1.1 (기하).**  `n=3,4,5` 전수 확인:
삼각부등식이 성립하고, `w(a,c)+w(c,b)=w(a,b)` 인 것과 `c` 가 `(a,b)` 의
transit 인 것이 **동치**이며(측지 유일성), 모든 변은 자기 transit 사슬을
무게가산적으로 clean 부분변으로 분해한다.  `n=6` 의 clean 밖차수는 무게별
`1,1,3,13,71,308` (합 397) 이다.

**정리 1.2 (재정식화).**  다듬은 단어 `X` 를 그 순열 창 열로 읽으면 `CG_n` 위의
**walk** 이고 `|X| = n + (walk 무게)`.  역도 성립.  따라서

| 대상 | walk 표현 |
|---|---|
| 덮는 단어 | 덮는 walk |
| 창이 정확히 `n!` 개 (= `NR_n`) | **해밀턴 경로** |
| `L_n` | `n + minHam` |
| 최소 `NR_n` 길이 | `n + minCleanHam` |

`minHam` 은 거리 `w` 에 대한 해밀턴 순서의 최소 비용이다(임의의 덮는 walk 은
첫-출현 순서로 비용을 늘리지 않고 축약되고, 해밀턴 순서의 측지 철자는 같은
비용의 덮는 walk 이므로 둘은 같다).  그러므로

> **`NR_n` (문턱형) 은 정확히 `minHam = minCleanHam` 이고,
> 바깥 55/55 정리는 정확히 `minCleanHam_6 >= 866` 이다.**

`w(p,q) > n` 인 연결자(잡문자 삽입)는 최소 단어에 나타날 수 없다: 측지로
바꾸면 길이가 줄고 덮개는 늘기만 한다.  따라서 위 모형은 완전하다.

## 2. 결함 항등식 — 하나의 예산

`M = n! + R` 을 순열 창 **출현** 수(`R` = 반복), `P` 를 극대 `sigma`-run 수라
하자.  walk 은 `M-1` 개 변을 갖고 그중 `M-P` 개가 `sigma` 단계이므로
`P-1` 개가 non-sigma 다.  그러면

    L = n + (M-P) + sum_{non-sigma} w
      = (n + n! + (n-1)! - 2)  +  D,

    D := R + Xrun + Hvy,
    Xrun := P - (n-1)! >= 0,        Hvy := sum_{non-sigma} (w-2) >= 0.

기준값 `n + n! + (n-1)! - 2` 는 `n=3:9, n=4:32, n=5:147, n=6:844`.
모든 `sigma`-류가 run 을 하나는 가져야 하므로 `P >= (n-1)!`, 즉 `Xrun >= 0`.

| n | 기준 | 실제 `L_n` | `minD` |
|---:|---:|---:|---:|
| 3 | 9 | 9 | 0 |
| 4 | 32 | 33 | 1 |
| 5 | 147 | 153 | 6 |
| 6 | 844 | 872 (상계) | **28 이어야 함** |

> **따라서 `L6 >= 872` 는 정확히 `D >= 28` 이다.**  고전 하계 867 은 `D >= 23`.
> 바깥 55/55 정리는 **`R = 0` 인 walk 에 대해 `D >= 28`** 이라는 뜻이다.

`L <= 871` 이면 `R + Xrun + Hvy <= 27`: 반복·여분 run·변 무게가 **하나의
예산**을 나눠 쓴다.  무게-6 변은 4 를 먹으므로 반복 `R` 개인 후보는 무게-6 변을
`(27-R)/4` 개까지만 가질 수 있다.

이 항등식은 라운드 141 의 typed-event 유도(REPEAT-CREDIT)보다 훨씬 짧게 같은
반복 상계를 준다: `R <= L - n - n! - (n-1)! + 2`, 즉 `n=6, L=871` 에서
**`R <= 27`** (라운드 141 과 일치), `L=867` 에서 23, `n=5,L=153` 에서 6,
`n=4,L=33` 에서 1, `n=3,L=9` 에서 0.

## 3. ARC 보조정리 — 반복은 반드시 run 끝점에 드러난다

**보조정리 3.1.**  육각형(= `sigma`-류, 크기 `n`) `h` 의 출현 수가 `n` 을 넘으면,
`h` 안의 어떤 run 은 **중복 덮인 끝점**을 갖는다.

*증명.*  모든 run 끝점이 1 중이라 하자.  중복 정점 `v` 는 자기를 담은 모든 run
의 **내부**에 있으므로 두 run `R1, R2` 의 내부에 있다.  `v` 에서 `R1` 안을 따라
`R1` 의 끝 `b` 까지 간다.  `R2` 가 그 구간을 다 덮으면 `b` 가 2 중이 되어 모순.
그러므로 `R2` 는 `b` 이전에서 끝나고, 그 끝점이 `R1` 내부에 놓여 2 중이 된다 —
끝점이 1 중이라는 가정과 모순. ∎

반복을 가진 walk **5,082 개**에서 위반 0 으로 확인했다.

## 4. TRIM 이분법 — plateau 의 정확한 정체

`a` 를 중복 덮인 run 끝점, `a' = sigma^{-1}(a)` 를 walk 상의 직전 정점,
`z` 를 직후 정점이라 하자.  `a` 를 빼는 것(TRIM)은 덮개를 보존하고 무게를
`w(a',z) - 1 - w(a,z) <= 0` 만큼 바꾼다.

**정리 4.1 (TRIM 이분법).**  `(a,z)` 가 clean 이면

    w(a,z) = n      =>  w(a',z) <= n < n+1  =>  a 는 (a',z) 의 transit 이 아님
                        => **자유**: 단어가 실제로 짧아진다.
    w(a,z) <= n-1   =>  w(a',z) = w+1 정확  =>  a 가 (a',z) 의 transit
                        => **막힘**: 조작은 단어에 대해 문자 그대로 **no-op** 다.

`n=3,4,5,6` 전수 확인, 위반 **0**.  `n=6` 에서는 정점마다 막힌 출구 **89** 개
(무게 1..5), 자유 출구 **308** 개 (무게 6); 앞방향/뒤방향이 동일하다.

**이것이 "plateau" 의 정체다.**  막힌 경우 `a'→a→z` 와 `a'→z` 는 **같은 단어**를
철자한다 (후자는 `a` 를 transit 으로 갖는 dirty 변).  즉 국소 교환은 단어를
바꾸지 못한다.  라운드 141 이 관찰한 "동일 길이 재배치 plateau" 는 대부분
**단어를 보존하는 부기(bookkeeping) 변경**이다.

따름: `L <= 871` 인 최소 반례에서는 모든 중복 덮인 run 끝점의 출구(및 시작점의
입구) 무게가 `<= 5` 여야 한다.  §2 에 의해 무게-6 변은 어차피 `(27-R)/4` 개
이하다.

## 5. 전수 계산 — `n <= 5` 완전 해결

`src/nr_clean_walk_142.c`.  가지치기: 남은 무게 `>= u + (미덮힌 arc 총수)
- [sigma(현재)가 미덮힘]`.  건전성: clean 변 하나는 출현을 정확히 하나 더하므로
남은 변 `>= u`; 무게 `>=` 변수 + non-sigma 변수; 여기서부터의 run 수
`=` non-sigma 수 `+1`; run 은 한 육각형의 연속 구간만 덮으므로 두 arc 를 잇는

| 분해 `(R, Xrun, Hvy)` | 개수 | `P` | 무게 히스토그램 |

양성 통제: 표준 재귀 구성이 주는 길이-153 단어를 첫 창이 항등원이 되도록
값-재명명하면 이 8 개 중 하나와 **문자 그대로 일치**한다.  또한 값-재명명이
120 개 순열 위에 단순추이적이므로 첫 창 고정은 재명명류마다 대표를 정확히
하나 고른다 — 따라서 **최소 길이 `n=5` 초순열은 재명명을 무시하면 정확히 8 개**다
(반전 대칭은 몫으로 취하지 않았다).

**반복 벌점 법칙 (관측).**  `minD(R>=1) = minD(R=0) + 1` 이 `n=3`, `n=4` 의
시험한 **모든** 길이에서 성립하고, `n=5` 에서도 `minD(R>=1) >= 7 = 6+1` 이
확인된다.

## 6. 반복이 무엇을 사는가 — 메커니즘

`tau`-사슬(무게-2 연결자로 이어진 run 열)은 **`E` 의 위수 `n-1` 을 넘지 못한다**:
길이 `n` 인 full run 의 `tau` 출구는 진입 궤도의 위상을 1 올리므로 `n-1` 번 뒤에
진입이 반복된다.  그래서 clean 구조는 `(n-2)!-1` 개의 무게 `>=3` 변을 강제받고,
이것이 고전 하계다.

**반복은 이 제약을 우회한다.**  run 을 감으면(길이 > 육각형 크기) 출구가
`E(sigma^j v)` 로 **궤도를 옮겨** 사슬을 계속 이어 갈 수 있다.

`n=4, L=35` 에 `(R,Xrun,Hvy) = (3,0,0)` 인 walk 이 **정확히 2 개** 있다:

    01230120312013201321032102310213021
    01230120312013201302130210321023102

둘 다 `P = 6` (육각형마다 run 하나), 연결자 5 개가 **전부 무게 2**, run 길이는
`[4,4,6,5,4,4]` / `[4,4,5,6,4,4]` — 즉 두 run 이 감긴다.  무거운 변을 하나도
쓰지 않고 결함을 **전부 반복으로** 지불한 실물이다 (`D = 3`, 반면 clean 최소는
`D = 1`).

이것이 위험한 구조의 원형이고, 동시에 `n<=5` 에서는 **항상 손해**임이 전수로
확인된다.

## 7. 순환성 — 라운드 141 의 남은 보조정리에 대하여

라운드 141 은 남은 틈을 "길이 `<=871` 인 반복 고정점의 plateau 탈출"로 세웠다.
바깥 정리(길이 `<=871` 인 `NR6` 단어 없음)를 주면:

* 탈출 보조정리 ⟹ 길이 `<=871` 단어가 있으면 `NR6` 단어가 나와 모순 ⟹ `L6>=872`.
* `L6>=872` ⟹ 길이 `<=871` 단어가 **아예 없으므로** 보조정리는 **공허하게 참**.

> **즉 그 보조정리는 목표 정리와 논리적으로 동치다.**  작은 기술적 틈이 아니라
> `L6 >= 872` 를 다시 쓴 것이다.  국소 교환으로 그것을 증명하려는 시도는
> (추측상 존재하지 않는) 대상을 다뤄야 하므로 본질적으로 순환이며, 성공하더라도
> 증명은 "공허성"을 확립하는 실질 논증을 반드시 포함해야 한다.

**해법: 길이 제한을 떼라.**  다음은 공허하지 않다.

> **NR-UNIVERSAL(n).**  모든 덮는 walk `W` 에 대해, 반복 없는 덮는 walk `W'` 로
> `무게(W') <= 무게(W)` 인 것이 존재한다.  동치로 **`minD(R=0) = minD`**.

이 명제의 정의역(반복 있는 walk)은 **비어 있지 않다** — `n=4` 에서만도 반복
walk 이 수천 개다.  그러므로 직접 증명하거나 반증할 수 있다.  그리고

    NR-UNIVERSAL(6)  +  바깥 55/55 정리   ==>   L6 >= 872.

**검증**: `NR-UNIVERSAL` 은 `n=3,4,5` 에서 위 전수 계산으로 **참**이다.

동등하게 유용한 절반만 떼면:

> **반복 벌점 목표.**  `n=6` 의 모든 덮는 walk 이 `R >= 1` 이면 `D >= 28`.

바깥 정리가 `R = 0` 쪽을 이미 준다.  이 명제도 정의역이 비어 있지 않다.

## 7bis. 바깥 증명에서 no-repeat 이 **실제로** 쓰이는 단 한 자리

임의의 덮는 단어 `X` 에서 각 순열의 **첫 출현**을 고르면, 위치 순서로 해밀턴
순서 `v_0..v_{n!-1}` 가 되고 `X` 의 첫-출현 측지 사영이 바로 그 철자다.
이 **선택된** 구조에 대해 다음이 성립한다 (증명 + 전수 확인).

**(H1) 선택된 pass 는 언제나 모든 육각형을 분할한다.**  각 순열은 정확히 한 번
선택되므로 육각형(크기 `n`)은 선택 출현을 정확히 `n` 개 갖는다.  간격 1 은
`sigma` 이므로 pass 는 한 육각형 안의 호이고, 선택 출현이 서로 달라 호들은
그 `n`-순환을 **분할**한다.  **단어에 반복이 있어도 그렇다.**

**(H2) 따라서 `nu` 는 언제나 잘 정의된 pass 치환이다.**  `sigma^{l_i}(v_i)` 는
pass `i` 의 호 바로 다음 정점이고, 호들이 순환을 분할하므로 그것은 같은
육각형의 다른 pass 의 **진입**이다.

**(H3) 자원 항등식이 그대로 성립한다.**
`L = (n! + (n-1)! + n - 2) + G + S + H`, `G = P-(n-1)!`,
`S = #(무게>=3 조인트)`, `H = sum (w-3)_+`.

전수 확인: 반복을 가진 walk **n=4 에서 5,081 개, n=3 에서 1 개** 전부에서
H1, H2, H3 가 **100% 성립**한다.

> **즉 바깥 프레임워크의 부기(bookkeeping)는 반복을 견딘다.**  `no-repeat` 가
> 소비되는 첫 자리는 라운드 140 §2 의 등식
> `무게-2 조인트의 표적 = flip(p') = E(sigma(p'))`
> 이다.  이것은 무게-2 조인트가 **clean 후계자 `tau(p)`** 일 때만 옳다.
> 반복이 있는 단어는 **dirty 무게-2 변 `p -> sigma^2(p)`** 를 쓸 수 있고, 그
> 표적은 `E(sigma(p))` 가 아니며 같은 육각형에 머문다.

`n=4` 의 반복 walk 5,081 개 중 dirty 무게-2 조인트를 실제로 쓰는 것은 **309 개**
뿐이다 (dirty 조인트를 하나라도 쓰는 것은 4,895 개).  따라서 대다수의 반복
walk 은 이 첫 장애를 통과한다.

**단서 (과장 금지).**  나는 no-repeat 이 소비되는 **첫** 자리를 특정하고 부기가
살아남음을 확인했을 뿐이다.  바깥 증명의 **모든** 단계(특히 splicing 뒤의 용량
포함 단계 — 사슬의 육각형 단순성과 경량 연결자 `201/210` 분류)가 dirty 조인트
아래에서도 성립하는지는 **감사하지 않았다**.  `sigma^3` 같은 dirty 무게-3 변은
육각형 안에 머물러 사슬의 육각형 단순성을 깨므로, 최소한 자름 비용이 는다.
따라서 이 절은 "바깥 정리가 반복에도 적용된다" 는 주장이 **아니라**, 확장을
시도할 때 실제로 다뤄야 할 지점이 어디인지에 대한 정확한 지도다.

## 8. 무엇이 남았는가

`n<=5` 에서 `NR-UNIVERSAL` 이 참인 **이유**는 전수 계산이지 구조 논증이 아니다.
내가 찾은 국소 도구들 — ARC 보조정리, TRIM 이분법 — 은 반복이 반드시 run 끝점에
드러남을 보장하지만, 그 끝점의 출구 무게가 `n` 일 때만 단어를 줄인다.  §2 에
의해 그런 변은 예산상 극히 드물다.  따라서 **국소 이동만으로는 닫히지 않는다**
는 것이 (이제) 정확히 증명된 사실이다.

§7bis 는 두 번째 구체적 경로를 준다: 바깥 증명을 dirty 조인트까지 확장하되,
먼저 **무게-2 dirty 조인트(`sigma^2` 변)** 만 배제하면 되는지 확인하는 것.

남은 실질 과제는 §6 의 교환율을 정량화하는 것이다: 감긴 run 하나가 사는
"사슬 연장"의 값이 그 반복 비용보다 **엄격히 작다**는 것.  `n=3,4` 에서는
벌점이 정확히 `+1` 이고 `n=5` 에서도 `>= +1` 이다.
