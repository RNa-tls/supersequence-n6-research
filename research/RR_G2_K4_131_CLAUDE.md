## 2. 정리 131.1 — 다섯 하위경우를 한꺼번에 강제하는 정리 (§2·§3·§5)

### 보조정리

* **131.L1 (자유 탈출의 목표 궤도).**  라운드 126 §5 의 자유 후속 공식
  `free(p) = τ(σ^{len}(entry(p))) = τ(entry(ν(p)))` 로부터, 짧은 pass `p` 가 `ω = 2` 로
  나가면 새 run 은 궤도 `Q(p) := orb(entry(ν(p)))` 안에서 열리고 그 run 의 τ-사슬에서
  `ν(p)` 는 **시작 슬롯 + (n−2)** 칸, 즉 τ-순환의 바로 앞 칸에 있다.
  (full pass 의 자유 후속은 `τ(entry(p))` 로 **같은 궤도**이므로 inter-run 이 아니다.
  따라서 `f_out` = `ω = 2` 로 나가는 **짧은** pass 의 수.)
* **131.L2 (하강 ⇒ 반복 run).**  자유 탈출 시점에 `ν(p)` 가 이미 놓였으면
  (`p > ν(p)`, `ν`-하강) `ν(p) ∈ Q(p)` 이므로 `Q(p)` 는 이미 방문된 궤도이고 새 run 은
  **반복 run** 이다.  서로 다른 하강은 서로 다른 run 을 열므로 `#(자유 하강) ≤ e`.
* **131.L3 (깨진 lock ⇒ 반복 run).**  상승 `p` 의 자유 후속이 연 run 이 `ν(p)` 를 담지
  못하면 `ν(p)` 는 `Q(p)` 의 뒤 run 에 있으므로 `Q(p)` 는 run 을 둘 이상 갖는다.

### 정리 131.1

`ν`-상승은 전부 짧은 pass 이고 `F` 개뿐이므로 `f_out = #(자유 상승) + #(자유 하강)
≤ F + e` — 이것이 정리 129.1 의 **재증명**이다.  `(k,G) = (4,2)` 에서는
`f_out = e + 2 = F + e` 로 **등호**이므로 사슬 `e + F ≤ F + #(자유 하강) ≤ F + e` 가 전부
등호가 되고:

* **(a)** `ν`-상승인 짧은 pass 는 **전부** 자유 탈출한다;
* **(b)** 자유 하강은 **정확히 `e` 개**이고 그것들이 여는 `e` 개의 반복 run 이
  **모든** 반복 run 이다.  따라서 **`ω ≥ 3` joint 는 반복 run 을 열 수 없고**, 반복
  궤도는 `{orb(entry(ν(d))) : d 자유 하강}` 으로 **핀**된다;
* **(c)** 상승 `p` 의 국소성 lock 은 **`Q(p)` 가 (b) 의 반복 궤도 중 하나일 때만**
  깨질 수 있다.

### ⚠ 라운드 131 내부 정정 (지우지 않고 남긴다)

이 라운드의 **초안은 (c) 를 “lock 은 하나도 깨지지 않는다” 로 적었다.**  `n = 4` 전수가
이를 **반증했다**: 등호 `f_out = F + e` 를 만족하는 walk 1,734 개 중 **288 개가 lock 을
깬다.**  세는 논법만으로는 배제할 수 없다 — 깨진 lock 이 요구하는 반복 run 과 자유
하강이 여는 반복 run 이 **같은 run 일 수 있기** 때문이다.  위 (c) 가 정확한 형태이며,
엔진에는 (c) 의 **조건부** 형태만 넣었다.

### `n = 4` 전수 검증 (§11)

합법 `n = 4` walk **29,255** 개 전부에서 131.L1·131.L2·131.L3 과 (a)(b)(c) 를 검사했다:
**위반 0**.  부수 따름정리도 검사했다 — `e = 0 ⇒ 깨진 lock 없음`, `유형 A ⇒ 깨진 lock
없음` (유형 A 등호 walk 90 개).  한 육각형의 `n` 개 단어가 `n` 개의 서로 다른 궤도에
있다는 기반 사실은 `n = 4, 5, 6` 에서 확인했다.

## 3. 하위경우별 lock 성립표 (§5·§14·§15)

반복 궤도는 `{orb(entry(ν(d)))}`, 상승 `a` 의 lock 궤도는 `Q(a) = orb(entry(ν(a)))` 이다.
`ν(a)` 와 `ν(d)` 가 **같은 육각형의 다른 단어**이면 두 궤도는 다르고 lock 은 성립한다.

| 하위경우 | 반복 궤도 | opener₀ / arc0 lock | opener₁ / arc1 lock | 갈래 |
|---|---|---|---|---|
| `A/e=0` | 없음 | 무조건 | 무조건 | 1 |
| `A/e=1` | `orb(entry(arc0))` | **무조건** | **무조건** | 1 |
| `B/e=0` | 없음 | 무조건 | 무조건 | 1 |
| `B/e=1`, closer₀ 자유 | `orb(entry(opener₀))` | **무조건** | 실행 중 판정 | 1 |
| `B/e=1`, closer₁ 자유 | `orb(entry(opener₁))` | **α/β 분기** | 무조건 | 2 |
| `B/e=2` | `orb(entry(opener₀))`, `orb(entry(opener₁))` | **α/β 분기** | 실행 중 판정 | 2 |

`A/e=1` 이 무조건인 이유: `entry(arc0), entry(arc1), entry(arc2)` 는 같은 육각형 `h*` 의
서로 다른 세 단어이므로 세 궤도가 전부 다르고, 유일한 반복 궤도 `orb(entry(arc0))` 는
두 lock 궤도 `orb(entry(arc1))`, `orb(entry(arc2))` 와 다르다.
**이로써 라운드 130 이 `A/e=1` 에 쓴 lock 이 사후적으로 정당화된다.**

**α/β 분기**는 배타적일 필요 없이 **망라적**이면 된다:
α = opener₀ 의 lock 이 성립하는 walk (lock 을 걸고 탐색),
β = 깨지는 walk — 이때 `orb(entry(opener₁)) = Q(opener₀)` 가 **필요조건**이므로 그 등식을
강제해 탐색한다.

## 4. `A/e=1` 의 완전 강제 (§3·§4·§6·§7)

호를 walk 순서로 `arc0 < arc1 < arc2` 라 하면 내부 `F = 2` 는 `ν` 가 **순환 회전**
`arc0 → arc1 → arc2 → arc0` 임과 동치이다 (라운드 129).  상승은 `arc0, arc1`, 하강은
`arc2` — **유일**하다.  정리 131.1 로:

* **§2 경우 (i)/(ii) 패턴** — 경우 (i)(=상승, lock) 은 정확히 둘 `{arc0, arc1}`,
  경우 (ii)(=하강, 반복 run) 은 정확히 하나 `arc2`.  **관측이 아니라 증명이다.**
* **§3 분열 궤도의 핀** — 반복 궤도는 `Q₂ = orb(entry(ν(arc2))) = orb(entry(arc0))`.
  `e = 1` 이므로 **유일한 분열 궤도**.  첫 run `R₁` 은 `arc0` 에서 **끝나고**, 둘째 run
  `R₂` 는 `arc2` 의 자유 탈출이 여는 것으로 슬롯 `orbph(entry(arc0)) + 1` 에서
  **시작**한다.  위상 관계는 `entry(R₂ 첫 pass) = τ(entry(arc0))`, 육각형 관계는
  `entry(arc0), entry(arc1), entry(arc2)` 가 `h*` 의 `σ`-절단 `l0, l1, l2` 로 정해진다.
* **§4·§5 순서** — `arc0` 의 lock 은 `Q₀ = orb(entry(arc1))` 의 **유일한** run 을 열고 그
  run 은 `arc1` 에서 끝난다.  `x = 0` 이라 run 안의 joint 는 전부 `ω = 2`(=τ)이고
  `entry(arc1)` 은 시작 슬롯의 τ-이전 칸이므로 그 run 은 **정확히 5 pass**(full 4 + arc1)
  이다.  같은 논법이 `arc1 → arc2` 에도 걸린다.  따라서 **엄밀 부등식이 아니라 등식**:

  ```
  pos(arc1) = pos(arc0) + 5,     pos(arc2) = pos(arc0) + 10,
  R₂ 시작   = pos(arc2) + 1
  ```

  `arc0` 직후 **10 pass 가 완전히 결정**되고 그 구간의 joint 는 전부 `ω = 2`(비용 0)이다.
* **§6 유일 재방문의 기하** — `R₁` 은 `Q₂` 의 슬롯 `[s₀−a+1 … s₀]`, `R₂` 는
  `[s₀+1 … s₀+b]` (`s₀ = orbph(entry(arc0))`).  둘은 겹칠 수 없어 `a + b ≤ 5` 이고
  합쳐서 τ-순환의 **연속 구간**이다.  와일드카드 없이 이것이 **전부**이다.
* **§7 interval model** — 위로부터 order type 은 **정확히 하나**:
  `… R₁(arc0 로 끝) │ S₁(full 4 + arc1) │ S₂(full 4 + arc2) │ R₂ …`.
  세 자유-탈출 의무는 단일 gap 과 **양립한다** (모순이 나오지 않는다).

### §8·§9 국소 열거와 분할 축소 — 정직한 음성 결과

order 증명은 `A/e=1` 을 **해석적으로 닫지 못했다** (order type 이 모순 없이 하나 존재).
그래서 §8 의 국소 열거는 `src/verify_g2_machine_131.py` `synthetic_ae1_block()` 로
`n = 6` 실기하 위에서 10 분할 전부에 대해 위 강제 구조를 **합성**해 확인하는 데 썼다
(전부 일관).  **§9: 핀된 분열-궤도 정리는 10 개 분할 중 어느 것도 죽이거나 묶지 않는다.**
증명되지 않은 대칭은 쓰지 않았으므로 **살아남는 분할 집합은 10 개 전부**이다.

## 5. `B/e=1`·`B/e=2` 의 구조 (§13·§14·§15·§16)

두 육각형 `g, h` 가 각각 두 번 진입.  walk 순서로 opener 가 상승, closer 가 하강이고
`F = 2` 는 항상 성립한다.

* **`B/e=1`** — `f_out = 3`.  정리 131.1(a) 로 **두 opener 는 반드시 자유**, (b) 로
  closer 중 **정확히 하나**가 자유.  라운드 130 이 돌린 네 갈래 중 **opener 를 비자유로
  둔 두 갈래는 정리로 공집합**이다.  §16 의 정규 패턴표:

  | 패턴 | 자유 sid | REVSPEC | LOCKSPEC | 분열 궤도 | α/β |
  |---|---|---|---|---|---|
  | closer₀ 자유 | 0, 1, 2 | `0b0010` | `0b0101` | `orb(entry(opener₀))` | 불필요 |
  | closer₁ 자유 | 0, 2, 3 | `0b1000` | `0b0101` | `orb(entry(opener₁))` | 필요 |

  런 수: **100 → 75** (25 분할 × (1 + 2)).
* **`B/e=2`** — `f_out = 4`, 넷 다 자유 (라운드 127 의 “넷 다 자유 ⇒ e ≥ 2” 가 여기서
  tight).  두 closer 가 각각 반복 run 을 연다.  **§13 의 질문 — 두 겹친 육각형이 반드시
  서로 다른 분열 궤도에 청구되는가 — 는 증명되지 않았다.**  `orb(entry(opener₀))` 와
  `orb(entry(opener₁))` 가 같아도 그 궤도가 run 셋을 갖는 배치가 조합적으로 모순되지
  않는다.  **따라서 배정을 핀하지 않았다** (핀하면 건전성을 잃는다).
  런 수: **25 → 50** (α/β 분기; 라운드 130 은 lock 자체가 없었다).
### §14 `B` 의 order type 정리 (새 결과)

`x = 0` 이라 run 안의 joint 는 전부 `ω = 2`(=τ)이고 짧은 pass 의 `ω = 2` 후속은 궤도를
바꾸므로 **짧은 pass 는 언제나 자기 run 의 마지막 pass** 이다.  따라서 **lock 이 걸린 run
안에는 다른 짧은 pass 가 들어갈 수 없다.**  두 opener lock 이 성립하는 갈래(α)에서는 walk
순서가 **하나로 확정**된다:

```
opener₀  <  closer₀ = opener₀ + 5  <  opener₁  <  closer₁ = opener₁ + 5
```

`closer₀` 와 `opener₁` 사이의 pass 는 **전부 full** 이고, 두 반복 run 은 각각 `closer₀`,
`closer₁` 의 자유 탈출이 **바로 뒤에서** 열며 궤도는 `orb(entry(opener₀))`,
`orb(entry(opener₁))` 이다.  `B/e=1` 의 α 갈래도 같은 사슬을 따르고 반복 run 만 하나다.

`n = 4` 검증 (`x = 0` 등호 walk 27개 = 유형 A 2 + 유형 B 25): **위반 0**.
lock 패턴 census — 둘 다 성립 `e=0` 7 · `e=1` 2, `opener₀` 만 깨짐 `e=1` 14 · `e=2` 2.
그리고 **`opener₀` 의 lock 이 깨진 16개 전부**에서 자유 closer 가 `closer₁` 이고
`orb(entry(opener₁)) = orb(entry(closer₀))` 이다 — 엔진의 **β 갈래 필요조건과 정확히
일치**한다.

**§14 의 분할 축소는 여전히 없다.** order type 은 하나로 확정되지만 25 개 분할 모양
`(b₁, b₂)` 는 그 정리와 독립이라 하나도 죽지 않는다.  증명 없는 축소는 쓰지 않는다.

## 6. 엔진 (§10·§18)

`src/g2_cell_131.c` — 라운드 130 의 **수정 후** 엔진(모든 pass 가 육각형 마스크를 세운다)
에서 갈라져 나왔고 새 규칙 셋을 넣었다.

1. **`REVSPEC`** (정리 131.1(b)) — 반복 run 은 **지정된 자유 `ν`-하강의 `ω = 2` 탈출**만
   열 수 있다.  `REVSPEC < 0` 이면 규칙이 꺼져 라운드 130 동작을 그대로 재현한다.
2. **조건부 `LOCKSPEC`** (정리 131.1(c)) — 상승 lock 은 목표 궤도가 *알려진* 반복 궤도와
   다를 때만 건다.  판정 불가한 유일한 자리(유형 B opener₀, opener₁ 미배치)는
   **`LOCK0MODE` 의 α/β** 가 망라적으로 덮는다.
3. **잎 검사** — `#반복 run = e` 이고 `r = O + e`.

**§18 탐색 안전.**  `TARGET = 122`, `k = 4`, `G = 2`, `D = 18`, `XCAP = 0`, `HCAP = 0`,
`HW = 0`(무거운 전이 없음), `S = 25`, `N = −1`, 정확한 `e`, 정확한 `f_out = e + 2`.
**모든 pass 가 육각형 마스크를 세운다**는 불변식에는 전용 검사를 붙였다 —
`-DCHECKMASK` 빌드가 매 노드에서 `#진입 육각형 = passes − 재진입` 을 확인하고,
세 설정 × 2×10⁷ 노드에서 **위반 0**, 그리고 소스 수준 검사가 마스크 설정이
`completes` 같은 조건 아래 들어가지 않았음을 확인한다 (`tests/test_g2_k4_131.py`).

## 8. 파일럿과 장기 실행 계획 (§12·§20)

측정 속도: **약 9×10⁶ 노드/초**.

### `A/e=1` (§12)

| | 라운드 130 | 라운드 131 |
|---|---|---|
| 분할 `l114` 노드 | 17,038,540,046 | **12,981,632,834** |
| 벽시계 | 1,926.8 s | **1,460 s** |
| 최대 pass | 102 | **101** |
| 판정 | UNSAT_COMPLETE | UNSAT_COMPLETE |
| **축소 인자** | — | **1.31×** (노드), 1.32× (시간) |

라운드 130 의 “4×10¹⁰ 파일럿이 안 끝났다” 는 기록은 라운드 130 스윕이 실제로는
`A/e=1` 분할을 3×10¹⁰ 캡 아래에서 **끝내고 있었다**는 사실로 이미 갱신되었다
(라운드 130 스윕은 `A/e=1` 5/10 까지 진행한 채 정지되었고 그 5 개는 전부
UNSAT_COMPLETE 였다).  **노드 캡을 올려서 얻은 것이 아니다** — 캡은 그대로 두고
반복-run 핀으로 노드 자체를 줄였다.

### `B` 파일럿 — 정직한 음성 결과

6×10⁹ 노드 캡의 파일럿은 **셋 다 캡에 걸렸다** (전부 `UNKNOWN_CAP`, 절대
`UNSAT` 이 아니다):

| 파일럿 | 노드 | 초 | 판정 |
|---|---|---|---|
| `B_e2_b11` α | 6,000,000,178 | 667 | UNKNOWN_CAP |
| `B_e2_b11` β | 6,000,000,138 | 829 | UNKNOWN_CAP |
| `B_e1_b11` closer₀ | 6,000,000,115 | 624 | UNKNOWN_CAP |

즉 `B/e=1` 과 `B/e=2` 는 한 런당 6×10⁹ 노드로는 끝나지 않는다.  `A` 에서 `e = 0 → 1` 이
0.68×10⁹ → 13×10⁹ (≈19×) 였던 것을 그대로 옮기면 `B/e=1` 은 런당 3×10¹⁰ 급,
`B/e=2` 는 그보다 훨씬 크다.  75 + 50 런이면 **수백 시간** 규모이고, 이 라운드의
계산 예산으로는 닫을 수 없다.

### 실행 계획

1. **`A/e=1`** — 10 분할, 런당 캡 3×10¹⁰ (파일럿 1.3×10¹⁰ 의 2.3배 여유),
   예상 벽시계 **약 4.1 시간**.  실행함.
2. **`B/e=2`**, 3. **`B/e=1`** — 구조적으로는 줄었지만(50, 75 런) 계산으로는 열려 있다.
   결과는 `UNKNOWN`으로만 보고하고 **절대 `UNSAT` 로 승격하지 않는다.**

## 9. 이 라운드가 **하지 않은** 것

* `(3,2)` 로 넘어가지 않았다.  `G ≥ 3` 을 시작하지 않았다.
* `A/e=0` · `B/e=0` 을 재실행하지 않았다 — **회귀 대조로 각각 한 분할씩만** 돌렸다.
* **`A/e=1` 의 노드 캡을 올리지 않았다.**
* 증명되지 않은 대칭으로 분할을 묶지 않았다 (`A/e=1` 10 개, `B` 25 개 전부 살아 있다).
* `B/e=2` 의 두 분열 궤도가 서로 다르다고 **가정하지 않았다** (증명 못 했다).
* 캡/타임아웃을 `UNSAT` 로 승격하지 않았다.
