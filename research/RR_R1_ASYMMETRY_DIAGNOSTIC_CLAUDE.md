## 1. §9 귀속 — 원인은 B2 가 아니라 층 A 였다

| | 층 A 만 | B2 만 | 둘 다 | SAT |
|---|---|---|---|---|
| `r=0` | 6 | **23** | 1 | 4,476 |
| `r=1` | **190** | 1 | 7 | 326 |

**r=1 폐쇄 198 중 190 이 순수 층 A(뿌리 도달 불가)** 다. 즉 의심스러운 집중은 §4 가 지목한
sink-SCC 투영 보조정리 때문이 **아니다**. 반대로 `r=0` 의 30개는 대부분 B2 다.

이는 소트프트한 위안이 아니라 검증 대상의 이동을 뜻한다 — B2 의 투영 논증보다 **층 A 의
간선 관계 완전성**이 핵심이다.

### 층 A 의 필요성 자체는 투영 문제가 없다

미래 pass 는 빈 육각형 각각 1회(+`r=0` 이면 fragment 1회)로 **정확히** 대응되고, 미래 매크로
edge 는 pass 시작에서 pass 시작으로만 간다. 그래서 의무 그래프는 실제 미래의 **투영이 아니라
동형**이며, 실제 완성은 뿌리에서 모든 의무를 지나는 경로다. 중간에 생략되는 "이미 지나간
꼭짓점" 이 없으므로 §4 가 경고한 투영 붕괴가 발생할 자리가 없다.
(같은 이유로 B2 도 이 표현에서는 건전하다.)

남는 위험은 하나뿐 — **간선 관계가 빠짐없이 열거되는가.** 실현 이력 대조(등록 port 중 다른
등록 port 에서 `σ^ℓ`+joint 로 도달 불가한 것은 상태당 최대 1개 = 최초 단어, 2개 이상인 상태
**0/6,396**)가 이를 뒷받침하지만, 이것이 r=1 을 특별히 겨냥한 반증 시도는 아니다.

## 2. 기전 실험 — fragment 꼭짓점이 원인의 일부다

`r=0` 상태에서 **fragment 꼭짓점과 그 간선만 제거**하고 다시 판정했다. fragment 수리 edge 는
`ℓ = 5−c_f` 라는 **다른 회전 오프셋**을 쓰므로, `ℓ=5` 간선이 닿지 못하는 곳을 이어 준다.

| `r=0` SAT 4,476 개에서 fragment 꼭짓점 제거 | |
|---|---|
| 여전히 SAT | 4,069 |
| **폐쇄로 전환** | **407 (9.1 %)** |

즉 `r=0` 의 거부율은 0.7 % → **9.1 %** 로 오른다. `r=1` 의 37.8 % 와 같은 방향이지만
**같은 크기가 아니다.** fragment 꼭짓점의 추가 연결성은 비대칭의 **약 4분의 1**만 설명한다.

## 3. §6 CONTROL R1-B — 초관대 수리-육각형 연결자

수리된 육각형의 **두 등록 port 모두**에 `ℓ = 0..5` 의 가능한 모든 joint target 을 부여해
뿌리에 붙였다(시간 양립성 무시 — 의도적으로 **불건전한** 과대근사).

| `r=1` 폐쇄 198 | |
|---|---|
| 구제됨 | **43** |
| 그래도 폐쇄 | **155** |

**155/198 은 의도적으로 불건전한 완화에서도 살아남는다.** 구조적 신호에 무게가 실린다.
다만 43개가 구제된다는 사실은 이 폐쇄들이 수리-육각형 표현에 **민감**하다는 뜻이기도 하다.

한편 모델 자체에서는 두 등록 port `a`, `b` 가 **둘 다 이미 발사를 마쳤다**: 수리된 육각형은
가득 차 있고, 현재 육각형이 아니며(현재 육각형은 방문 칸 1개), 매 pass 는 떠날 때 발사하고
각 port 는 1회만 발사한다(라운드 87). 따라서 둘 다 미래 source 가 될 수 없다 — R1-B 는
그래서 불건전하다.
