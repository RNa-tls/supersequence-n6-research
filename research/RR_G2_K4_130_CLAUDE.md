## 2. 유형 A / `F = 1` 은 `k = 4` 에 존재하지 않는다 (§2)

정리 129.1 의 귀결 `k + x + H ≤ 2 + F` 에 `F = 1` 을 넣으면 `k + x + H ≤ 3` 이므로
`k = 4` 는 불가능하다.  전수 유도에서도 유형 A/`F=1` 의 기여는 **0** 이다.
따라서 남는 내부 모형은 **A/F=2 와 B/F=2** 둘뿐이다.

## 3. 자유 탈출 구조 (§3) — 그리고 그것이 **강제 패턴**이 된다

`f_out = e + 2` 이고 짧은 pass 는 3개(A) 또는 4개(B) 다.

| 하위경우 | 짧은 pass | 자유 | 비자유 |
|---|---|---|---|
| A / `e=0` | 3 | **2** | 1 |
| A / `e=1` | 3 | **3** | 0 |
| B / `e=0` | 4 | **2** | 2 |
| B / `e=1` | 4 | **3** | 1 |
| B / `e=2` | 4 | **4** | 0 |

### 3.1 `e = 0` 이면 어느 pass 가 자유인지까지 강제된다

`e = 0` 이면 **분열 궤도가 없다**.  자유 탈출이 경우 (ii) 이려면 목표 궤도에 run 이 둘
있어야 하므로, **모든 자유 탈출은 경우 (i)** 이고 경우 (i) 는 `p < ν(p)`, 즉 **`ν`-상승**이다.
`F = 2` 이므로 상승은 **정확히 둘**이다.

* **A / `e=0`** — walk 순서가 `arc0 < arc1 < arc2` (`F = 2` ⟺ `ν`-순서) 이므로 상승은
  `arc0`, `arc1` 이다.  ⟹ **`arc0`·`arc1` 이 자유이고 `arc2` 는 절대 자유일 수 없다.**
* **B / `e=0`** — 각 2-순환의 상승은 walk 에서 먼저 오는 pass, 즉 슬롯을 **여는** pass 다.
  ⟹ **두 opener 가 자유, 두 closer 는 비자유.**

### 3.2 유형 A / `e=1` 도 완전히 강제된다

`f_out = 3` 이라 세 arc 이 전부 자유다.  경우 (ii) 는 목표 궤도가 셋 다 다르고 분열 궤도가
하나뿐이라 **많아야 하나**이며, `#경우(ii) ≥ f_out − F = 1` 이므로 **정확히 하나**다.
경우 (i) 는 상승뿐이라 `{arc0, arc1}` ⟹ **경우 (ii) = `arc2`.**

### 3.3 `B / e=1` 과 `B / e=2` 는 강제되지 않는다 — 정직하게 나눈다

`B / e=1` 은 넷 중 셋이 자유인데 **어느 것이 비자유인지 강제되지 않으므로 네 갈래로
나눠** 각각 정확히 돌린다.  `B / e=2` 는 넷 다 자유지만 opener 가 경우 (ii) 일 수도 있어
**국소성 lock 이 증명되지 않는다** — 쓰지 않는다.

## 4·5. 국소성 lock — 경우 (i) 의 구조적 귀결 (§4, §5)

경우 (i) 인 자유 pass `p` 의 후속 `τ(entry(ν(p)))` 는 **`ν(p)` 를 담는 바로 그 run** 을 연다.
`τ` 가 궤도에 고정점 없이 작용하므로 `ν(p)` 는 그 run 의 첫 pass가 아니고, run 은 최대 5
pass 이므로

> **`p` 의 자유 탈출 직후부터 `ν(p)` 가 놓일 때까지 walk 은 그 궤도를 떠날 수 없고,
> `ν(p)` 는 5 pass 안에 나타난다.**

이 lock 을 **증명된 곳에만** 건다: `A/e=0`(arc0·arc1), `B/e=0`(두 opener),
`A/e=1`(arc0·arc1).  `B/e=1`·`B/e=2` 에는 걸지 않는다.

**실측 효과** (`A/e=0`, 분할 `(1,1,4)`, 캡 2×10⁹):
강제 패턴 없이 **캡 도달** → 강제 패턴만 **1.31×10⁹ 완주** → lock 까지 **6.81×10⁸ 완주**.

## 6·7. `H = 0` 과 `x = 0` 의 구조적 귀결 (§6, §7)

`H = 0` 이 **정확**하므로 이 칸에는 무게 4/5/6 이음매가 **존재할 수 없다** — 엔진은
`M4`·`M5`·`M6` 를 **어디에서도 제공하지 않는다** (`HW = 0`, `HCAP = 0`).
남는 것은 `ω ∈ {2,3}`, 즉 `W2`(자유) 와 `W3a`/`W3b`/`W3c` 넷뿐이다.

`x = 0` 이 **정확**하므로 **궤도 내부 비용-1 이음매가 하나도 없다.**  `ℓ = 5` 에서 궤도
내부인 비용-1 이동은 `W3a` 하나이므로, 실질적으로 **full pass 뒤의 `W3a` 가 전면 금지**된다
(짧은 pass 뒤의 `W3a` 는 궤도를 바꾸므로 inter-run 이고 허용된다).  엔진은 이를 분류에
의존하지 않고 `same && c == 1 ⟹ x++ > XCAP = 0` 로 **직접** 거부한다.

## 8·9. 엔진 (§8, §9)

`src/g2_cell_130.c` — 라운드 125 엔진의 **일반 부품은 그대로**, 짧은 pass 상태 기계만
새로 썼다.  `G = 1` 의 `sstate 0→1→2` 기계를 `G = 2` 에 억지로 끼우지 않았다.

| 그대로 재사용 | 새로 씀 |
|---|---|
| `build()` 기하 (`hexid`/`orbid`/`phse`/`SIG`/`hlo,hhi`) | `#define TARGET 122` |
| 경량 이동표 `M2`·`M3a`·`M3b`·`M3c` | 유형 A: **3-호 기계** (한 육각형, `ν` 순서) |
| `EXC` 궤도-덮개 초과 · `fod` 신선-궤도 결손 | 유형 B: **독립 2-호 슬롯 기계 둘** (서로 다른 육각형) |
| `NTAB`/`BESTSEG` · `capacity_ok`/`dcommitted`/`dfeasible` | `FREESPEC`/`FREEON` 강제 자유 패턴 |
| 캡/UNKNOWN 의미론 | `LOCKSPEC` 국소성 lock |

**유형 A 기계**: 세 호는 `(w, ℓ0)`, `(σ^{ℓ0}(w), ℓ1)`, `(σ^{ℓ0+ℓ1}(w), ℓ2)` 이고
`ℓ0+ℓ1+ℓ2 = 6`.  `F = 2` ⟺ 세 호가 walk 에서 **정확히 그 순서**로 나타나므로
(라운드 129), 기계는 `ν` 순서만 허용한다 (`AORDER = 1`).

**유형 B 기계**: 슬롯 둘.  각 슬롯은 **신선한 육각형**에서 `(v, b)` 로 열리고 짝
`(σ^b(v), 6−b)` 로 닫힌다.  끼워넣기를 허용한다.

**모든 pass 는 자기 육각형을 "진입됨" 으로 표시**하고(그래야 나중 full pass 나 새 슬롯이
그 육각형에 못 들어간다), **markhex 는 그 육각형의 마지막 호에서만** 부른다(그때 비로소
육각형이 완전히 소진되어 신선 궤도를 막기 때문).  이 두 가지를 분리하지 않은 초판은
**불건전**했고, 아래 §13 의 재현 대조가 그것을 잡아냈다.

## 10. 분할 모양 (§10)

* **유형 A**: `(ℓ0, ℓ1, ℓ2)` 순서 있는 분해 **10가지**.
* **유형 B**: `(b₁, b₂) ∈ {1..5}²` **25가지** (`b₁` 은 먼저 열리는 육각형의 분할).

정준화는 **증명된 대칭으로만** — `S₆` 좌곱으로 walk 의 첫 진입 단어를 고정하는 것뿐이다.
반전 `Φ` 접기는 이 칸에서 증명되지 않아 **하지 않았다** (§16).
`k = 4` 의 자원 제약은 어떤 분할도 죽이지 않으므로 35가지가 전부 남는다.

**최종 실행 수**: `A_e0` 10 + `A_e1` 10 + `B_e0` 25 + `B_e2` 25 + `B_e1` 25×4 = **170**.

## 11. 용량 경계 (§11)

`D = 18` 은 `G=1` 열의 `k=4`(`D=19`) 와 거의 같고 `(1,1)`(`D=4`) 보다 훨씬 느슨하다.
run 결손은 `5r − P = 5(28+e) − 122 = 18 + 5e` 라 조각 용량 프룬이 약하다 —
**`k = 4` 에서는 해석적으로 죽는 행이 하나도 없다**(라운드 129 와 일치).
예상대로 `D = 18` 만으로는 힘이 없고, 실제 절감은 §3–§5 의 강제 패턴과 lock 에서 온다.
