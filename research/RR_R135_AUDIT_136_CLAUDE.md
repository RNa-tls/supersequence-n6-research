## 1. 자원 표 재유도 (§1) — **CONFIRMED**


## 2. 부분 회전-호 축약 (§2·§3·§4) — 보조정리 **CONFIRMED**, 정의 복구 **불가**

라운드 134 의 보조정리는 대체물이 **full pass** 인 경우였다.  `(3,2)` 의 유형 A 는 육각형이
**세 번** 들어와 축약을 두 번 해야 하고 **중간 대체물이 길이 `l₀+l₁ < 6` 인 부분 호**다 —
그래서 일반화가 **실제로 필요**하다.  내가 처음부터 세워 증명한 형태:

> **보조정리 (부분 회전-호 축약).**  pass `(v, a)` 다음에 `orb(σ^a v)` 의 다섯 phase 를
> 전부 채우는 pass 다섯이 오고 그 마지막이 `(σ^a v, b)` 인 6-pass 덩어리를 **하나의 pass
> `(v, a+b)`** 로 바꾸면 (`a,b ≥ 1`, `a+b ≤ 6`), 진입 `v` 와 탈출 `σ^{a+b−1}(v)` 가 글자
> 그대로 보존되고 `P → P−5`, `O → O−1`, `D`·`S`·`H` 불변.  `a+b = 6` 이면 라운드 134.

`n = 6` 실기하 **10,800** 사례(720 단어 × 15 개 `(a,b)`) 전부 **위반 0**.
검사 항목: 진입·탈출 보존, external joint 무게(경계 단어 쌍만의 함수), 내부 joint 다섯이
전부 `ω=2`, 육각형 다중도, 궤도 점유(잠긴 run 이 다섯 phase 를 채움), `T ≠ orb(v)`.

* **유형 A (§3)** — 두 잠긴 run 은 `orb(σ^{l₀}v)` 와 `orb(σ^{l₀+l₁}v)` 로 **한 육각형의 서로
  다른 단어**라 궤도가 다르고 `orb(v)` 와도 다르다 ⇒ 숨은 겹침이 없고 `O` 가 정확히 2 준다.

* **유형 B (§4)** — β 는 **inner-first 가 강제**된다(라운드 134 감사에서 확인): 안쪽을

> **주의.** Astra 의 *실제* 진술을 볼 수 없었으므로, 내가 증명한 것은 “주장을 떠받치기에

## 5. `H = 1` 논증 (§8–§12) — **전부 CONFIRMED**

* **§8 유일 무거운 joint.**  `H := Σ (ω−3)₊`.  합이 1 이면 항이 정확히 하나, 값 1, 즉
  `ω = 4`.  무게 5·6 은 2·3 을 내고, 무거운 joint 둘이면 합이 `≥ 2`, 그리고 `H` 는 joint 위의
  합이라 끝점 보정항이 없다.
* **§9 두 경량 사슬.**  유일한 무게-4 joint 에서 자르면 조각 둘.  이 행들은 `e' = x' = 0`
  이므로 `b = 0`, `g` 풀은 `2e' = 0` ⇒ **두 사슬은 궤도를 공유할 수 없다.**
* **§10 등호 분류.**  `d₁ + d₂ = 13` 의 14 가지 분할 전부를 계산하면
  `max Σ N*(0,0,dᵢ) = 112` 이고 **`(4,9)` 와 `(9,4)` 에서만** 달성된다
  (`46 + 66 = 112`).  필요치가 정확히 112 이므로 **두 사슬 모두 극값**이어야 한다.
  쓰인 셀은 전부 `capped=false`.
* **§11 극값 사슬 census.**  라운드 115 모델을 **파이썬으로 독립 재구현**해
  `N*(0,0,4) = 46`, `N*(0,0,9) = 66` 을 재현했고 **노드 수까지 C 와 일치**(3,555 / 469,852).
