## 1. 전제와 재유도

라운드 142 Route B 의 **정의**(선택 pass, `P=120+G`, `O=24+k`, `S`=유료
조인트 수, `H=sum (w-3)+`, `z=G-c=2g+d`, `Z=z-D2`, `B*=sum b_j+s`)는
저장소에서 복원했다.  그 위에서:

**(FO)** 를 순수 계수로 다시 얻는다.  선택된 창 720 개 중 `720-P` 개는 pass
내부 회전(문자 1 개), `P-1` 개는 조인트(문자 `w` 개)이고
`sum_joints w = 2(P-1) + S + H` 이므로

    L = 6 + (720-P) + 2(P-1) + S + H = 844 + G + S + H.

**MASTER-142** 는 `G = Z+D2+c` 와 `S = B*+O-1-D2-c` 를 (FO) 에 대입한 것일
뿐이다 (15,625 조합 검산, 불일치 0).  따라서 **오른쪽에 양의 항을 더해
강화할 수 없다** — 라운드 143 자신의 `threshold_closure:
NOT_ESTABLISHED_BY_ARITHMETIC` 경고와 같은 결론이다.

**접합 정리의 독립 증명** (`src/l6_incidence_144.py`).  원소는 `P` 개의
선택 pass 와 더미 하나, 총 `n = 121+G`.  `alpha = nu`(더미 고정)의 순환은
정확히 120 개 육각형(+더미)이므로 `c(alpha) = 121`,
`sum_h (m_h-1) = G`.  `T` 는 시간순 `n`-순환, `beta = T alpha^{-1}`.

* 부호: `sgn(alpha) = (-1)^G`, `sgn(T) = (-1)^{n-1}`, `sgn(beta) = (-1)^{n-K}`
  에서 `K = G+1 (mod 2)`.
* 경계: `T = beta alpha` 가 `n`-순환이므로 `<alpha,beta>` 는 추이적이고,
  육각형 121 개와 `beta` 성분 `K` 개를 잇는 이분 그래프는 **연결**이다.
  연결 이분 그래프는 변이 `121+K-1` 개 이상이고, 원소를 (육각형, 성분) 쌍으로
  세면 `121+G = E + R_int >= 121+K-1 + R_int`, 즉

      K + R_int <= G + 1.

  `R_int` 는 정의상 **성분 내부** 중복 육각 초과분이므로 다른 해석의 여지가
  없다.  추상 무작위 사례 6,000 개에서 위반 0.

## 2. 시그마 결손 정리 — 독립 증명 (GOAL A)

정리.  진입 포트가 모두 다른 스플라이스 경로에서 `A` 개의 시그마 간선,
`Q` 개의 열린 궤도, `P` 개의 포트, `D = 5Q-P`, 이미 열린 궤도로의 비-E 진입
`b` 개에 대하여 `D + 5b >= A`.

증명 세 단계 (`src/l6_sigma_deficit_144.py`):

1. **변환 항등식** `E^{-1} sigma = sigma^{-1} E` (720/720).
2. **누락 동반 포트의 전파**.  길이 5 의 E-run 이 `s` 에서 시작해 `E^4(s)` 로
   끝나면 다음 run 의 누락 포트는 `sigma^{-1}(s)`, 육각형 `h(s)`.  길이 4 run
   이 이어지는 동안 이 육각형이 보존되고, 다시 길이 5 run 이 오면 그 다섯째
   진입이 **E 간선으로** 이미 쓴 육각형에 들어간다 — 금지.  따라서
   `5,4,...,4,5` 는 불가능.  전수 확인 6,480 사례, 위반 0.
3. **군집 계수**.  시그마로만 이어진 극대 군집에서 `s >= f-1`, 따라서
   `sum (5-r_i) >= m-1`; 군집마다 합하면 `Delta >= A`.

**예리성**: `(5,4) -> (A,b,D) = (1,0,1)`, `(5,3,5) -> (2,0,2)`, 둘 다 여유 0.
따라서 `b=0` 에서 `D >= A` 를 균일하게 강화할 수 없다.

**한계**: 적대적 무차별 탐색은 6천만 노드에서 **CAP** — UNKNOWN_CAP 이며
전수성 주장이 아니다.  정리 자체는 위 손 증명으로 성립한다.

판정: **CLAUDE_SIGMA_DEFICIT 확인.**  다만 이 정리만으로는 870/871 의 어떤
행도 닫히지 않는다 (§6 의 폐쇄는 이 정리를 **쓰지 않는다**).

## 3. 조인트 목록과 부분 pass — 모형의 기반

`end(v) = sigma^{-1}(v)` 에서 나가는 최단 조인트를 720x720 쌍의 문자열 겹침과
숨은 순열 창 탐지만으로 다시 만들었다.  모든 `v` 에 대해 정확히

| 무게 | 표적 | 이름 |
|---|---|---|
| 2 | `E(v)` | 자유 (같은 궤도, 위상 +1) |
| 2 | `sigma(v)` | **A** dirty (같은 육각형) |
| 3 | `E^2(v)` | `120`, 유료, 같은 궤도 위상 +2 |
| 3 | 두 개 | `201`, `210`, 유료, 교차 궤도 |
| 3 | `E(sigma v)` | **C** 혼합 |
| 3 | `sigma(E v)` | **D** 혼합 |
| 3 | `sigma^2(v)` | **B** dirty (같은 육각형) |

이고 다른 것은 없다 (720/720).  대수적으로 만든 사상과 정확히 일치.

**부분 pass 가 모형을 깨지 않는 이유.**  포트 `v`, pass 길이 `l` 의 조인트
출발점은 `sigma^{l-1}(v) = sigma^{-1}(u)`, `u = sigma^l(v)` 이므로 **모든
조인트는 같은 일곱 사상을 `u` 에 적용한 것**이다.  전수 확인: `l < 6` 인 pass
의 깨끗한 `w in {2,3}` 후속은 **하나도 같은 궤도에 있지 않고** (각 `l` 마다
720+2160 개 전부 교차 궤도), `l = 6` 에서만 `E` 와 `120` 이 같은 궤도다.
이것이 라운드 142 successor splicing(`nu(i) -> i+1` 재배정)이 full-pass
모형을 정당화하는 기하학적 이유이며, 나는 그것을 가정이 아니라 계산으로
확인했다.

## 4. 세 개의 손 보조정리 — 전부 독립 확인

* **동반 육각**: `orb(v)` 와 `orb(sigma v)` 는 정확히 `{h(v), h(Ev)}` 를
  공유한다 (720/720).  A 이음매의 양쪽 clean-E 블록이 **둘 다 꽉 찬 5 포트**면
  두 조각이 공통 육각형 둘을 모두 포함하므로 경계 육각형 **외에** 반복이 하나
  더 필요하다.
* **혼합 그림자**: C 간선의 그림자 `sigma(v)` 는 표적 궤도에 있고 육각형이
  `h(v)`; D 간선의 그림자 `E(v)` 는 출발 궤도에 있고 육각형이 표적과 같다.
  둘 다 단사이고 교차 충돌 `sigma(v)=E(u)` 는 `sigma^2(v)` 가 `h(v)` 에 놓여
  육각 단순성을 깨므로 불가능 (720/720).  ⇒ **조각당 혼합 간선 <= D_j**.
* **좌 `S6` 대칭**: 값 치환 작용은 위치 회전과 가환이므로 `E, E^2, sigma,
  sigma^2, 201, 210, C, D` 모두와 가환이고 720 포트 위에서 추이적이다
  (720 원소 전부 확인).  따라서 **시작 포트 고정은 증명된 축약**이지 가정이
  아니다.

## 5. 두 개의 용량 모형

### 5.1 조각(끝점 표시) 모형

`C(b,D,mask)` = 육각 단순 full-pass 사슬의 최대 포트 수.  `mask` 는 첫/마지막
clean-E 블록이 **부분(5 포트 미만)이어야** 하는지를 기록한다.

* `src/l6_marked_capacity_144.py` — 파이썬, `tau`/`sigma` 로 대수적 사상, dict
  위상 마스크, 히스토그램에서 결손 재계산.
* `src/l6_marked_capacity_144.c` — C, 기하를 **문자열 겹침 스캔으로만** 유도,
  평면 배열·증분 결손.  `b=0,dmax=10` 에서 노드 **13,780,945** 로 파이썬과
  값·노드 수까지 일치.
* `src/l6_marked_capacity_pruned_144.c` — 두 개의 건전한 가지치기를 추가.
  **(S) 접미사 경계**: 노드의 현재 결손 `dc`, 남은 토큰 `t` 에서 나머지를 그
  자체로 사슬로 보면 `D_S = D_fin - dc + 4 + 5r`, `r <= t` 이므로
  `D_S <= DMAX - dc + 4 + 5t`, 따라서 총 포트 `<= P + U(t, DMAX-dc+4+5t) - 1`.
  **(B) 최고기록**.  `b=0,dmax=12` 에서 무가지치기 115,757,562 노드 대신
  883,170 노드로 **같은 값**.

주요 값 (전수, capped=false):

| D | 0 | 1 | 2 | 4 | 6 | 8 | 10 | 12 | 14 | 17 | 20 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `C(0,D,--)` | 20 | 20 | 33 | 46 | 49 | 62 | 70 | 83 | 96 | 103 | **106** |
| `C(0,D,부분·-)` | **불가** | 19 | 19 | 32 | 45 | 57 | 65 | 73 | 82 | 95 | 105 |
| `C(0,D,부분·부분)` | **불가** | 4 | 18 | 31 | 44 | 47 | 60 | 68 | 81 | 94 | 101 |

무표시 열은 옛 `N*(b,0,D)` 표를 칸마다 재현한다.  **`C(0,0,부분)=불가능`** 이
결합 논증의 심장이다: `b=0,D=0` 에서는 모든 궤도가 완전히 덮이므로 clean-E
블록이 부분일 수 없다.

행 평가는 조각 경로 위의 DP 로 하고, 제약된 이음매의 위치는 (완화이므로)
적대적으로 고른다.  `nmark = max(0, max(0,D2-d) - max(0,Z-Qs))`.

### 5.2 결합 사슬 모형 — 이중 계산의 제거

조각을 따로 가격 매기는 대신 **베타 성분 전체**를 한 번에 탐색한다.  유지된
A/B dirty 간선을 사슬 안에 남기고, 이미 쓴 육각형에 착지할 수 있는 것은

* A/B 간선의 표적(그 육각형이 **곧** 출발점의 육각형), 또는
* 반복 여유에서 값을 치른 **추가 충돌**

뿐이다.  그러면 동반 육각 보조정리를 손으로 부과할 필요가 없다: A 이음매 앞
블록이 꽉 차 있으면 `E(v)` 가 이미 점유되어 다음 궤도의 포트
`sigma^{-1}(E v)` 가 같은 육각형이므로 탐색기가 **자동으로** 막는다.
(`amax<=4`, `D<=5` 에서 용량이 `20,20,33,33,46,46` 로 **전혀 늘지 않는** 것이
그 직접 귀결이다.)

행 하나의 예산:

    사슬 수          = d + 1 + h        (더미 성분 + d 개의 순환, 그리고 h 개 heavy cut)
    sum 결손         = 5k - G + 5s
    sum 토큰         = B* - s
    sum A <= D2,  sum B <= Qs
    sum A + sum B + sum 추가충돌 <= R_int <= 2g
    추가충돌 <= max(0, Z - Qs)
    필요 포트        = 120 + G - 5c

`s` 의 해석은 조각 모형의 "조각 간 궤도 공유"에서 "사슬 간 궤도 공유"로
바뀌지만 `T + s = B*`, `sum D = 5k-G+5s` 는 그대로다 (보고서 §6 유도).
`추가충돌 <= Z-Qs` 는 `2g = D2+Z-d` 와 순환 개방 `x+y <= d` 에서 나온다.

> **자기 정정.**  이 모형의 첫 판은 A/B 표적에서만 육각 재방문을 허용했다.
> 그것은 완화가 아니라 **과도한 제약**이었고 `Z > Qs` 행에서 건전하지 않았다
> (조각 분해는 보통의 육각 충돌에서도 자른다).  추가 충돌 예산을 도입해
> 고쳤고, 고친 뒤에도 867..870 의 결론은 그대로였다.

   `sum P_j`, `sum D_j`, `sum b_j`, `SAME-HEX`, 접합 정리)를 전제로 한다.
   접합 정리는 이 라운드에서 독립 증명했고, 나머지는 라운드 139/140 감사에서
   확인한 것을 재사용했다 — **전부를 이 라운드에서 다시 감사하지는 않았다.**
3. 시그마 결손 정리의 적대적 무차별 탐색은 **CAP** 되었다 (UNKNOWN_CAP).
   정리 자체는 손 증명으로 성립하고, §6 의 폐쇄는 그 정리를 쓰지 않는다.
4. 용량 모형은 **완화**다.  외부 그림자/이력 제약을 풀었으므로 최대를
   달성하는 사슬이 실제 덮개로 들어올린다는 주장은 하지 않는다.  여기서
   "생존" 은 실현 가능성의 증거가 아니다.
5. Phase 5 가 요구한 **균일한 master 부등식**(예: `k+Z+H+B* >= 5`)은 얻지
   못했다.  사슬당 궤도 수의 손 경계 `O <= f(D)` 가 있으면 따라 나오지만
   나는 그 손 경계를 갖고 있지 않다 — 지금 있는 것은 전수 표뿐이다.
6. `NR6` 는 쓰이지 않았고, 여전히 미증명이다.
