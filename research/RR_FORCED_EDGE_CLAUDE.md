## 1. 규칙과 그 근거 (§1, §3, §8)

라운드 93–96 에서 확립된 것만 쓴다. genuine 완성은 `{root} ∪ 의무` 위의 **뿌리 달린 유향
Hamilton 경로**이므로 차수는 다음으로 고정된다.

| | 유입 | 유출 |
|---|---|---|
| ROOT (현재 pass) | 0 | 1 |
| terminal 아닌 의무 | 1 | 1 |
| terminal (**전역에서 정확히 1개**) | 1 | 0 |

| 규칙 | 내용 | 근거 |
|---|---|---|
| **R1** | `|in(v)| = 1` 이면 그 간선은 강제 | `v` 의 유입은 terminal 선택과 무관하게 정확히 1 |
| **R2** | 강제 `u→v` 가 정해지면 `u` 의 다른 유출·`v` 의 다른 유입을 삭제 | `u` 는 유출 ≤ 1, `v` 는 유입 = 1 |
| **R3** | `|in(v)| = 0` → 모순 | 유입 1 위반 |
| **R4** | 유출 0 인 정점 ≥ 2 → 모순, ROOT 유출 0 → 모순 | terminal 은 **전역 허용량 1** (§3 의 방법 B) |
| **R5** | 강제 간선이 ROOT 를 포함하지 않는 **진부분** 사이클을 이루면 모순 | 경로는 정점을 재방문하지 않는다 |

**임의 가지치기는 하나도 쓰지 않았다** (§8). 삭제되는 간선은 전부 R2 에서만 나오고, 그
삭제의 인증서는 "어떤 강제 간선 때문인가" 다. `len(cycle) < |의무|` 조건 때문에 R5 는
전체를 도는 강제 사이클(= 아직 terminal 이 정해지지 않은 정상 상태)을 오탐하지 않는다.

**D4b 축약의 건전성.** 강제 간선 `u→v` 는 어떤 rooted Hamilton 경로에서도 연속으로 쓰인다.
따라서 강제 사슬을 한 정점으로 축약한 `G'` 에도 rooted Hamilton 경로가 있어야 하고,
라운드 96 의 `c(U(G') − S) ≤ |S| + 1` 이 그대로 필요조건이다. 축약은 **정점 수를 줄여
분리자 조건을 더 자주 발동시킨다** — 실제로 쌍 실패가 446 → 714 로 늘었다.

## 6. 왜 D4 가 거의 물지 않는가 (§13)

전수 19,955 쌍의 유입 차수를 셌다 (`outputs/rr_forced_edge_pilot_claude.json`
→ `graph_diagnostic`).

| | |
|---|---|
| 의무 수 `m` | 107 (9,497 쌍) · 108 (10,458 쌍) |
| 의무 유입 차수 분포 | `1`: 64,946 · `2`: 654,779 · **`3`: 1,367,802** · `4`: 25,971 · `5`: 25,601 · `6`: 6,544 |
| 쌍당 유입 1 의무 (평균) | **3.25 / 107** |
| 유입 1 의무가 **하나도 없는** 쌍 | **145** — 전파의 시작점이 아예 없다 |
| 유입 1 의무 비율 ≤ 10 % 인 쌍 | 18,986 / 19,955 |

전형적인 의무는 전임 후보를 **3개** 갖는다. R1 은 유입이 1로 떨어져야 발동하는데, 그런
의무가 100개 중 3개뿐이고 R2 연쇄가 그 3개에서 멀리 퍼지지 못한다. **차수 여유가 이렇게
크면 강제 전파는 원리적으로 약하다** — 값싼 다항 장애물 계열이 여기서 끝난다는 라운드 96 의
진단과 같은 결론이다.

## 7. 정확 Hamilton 파일럿 (§14) — 캡 도달은 UNSAT 이 아니다

`UNIQUE_AB` cover 에만, 건전한 가지치기 둘(남은 의무의 현재 정점 도달성 + 남은 부분그래프의
유출 0 정점 ≤ 1)만 붙인 완전 DFS.

| 노드 캡 | 시행 | **UNSAT(완전 탐색)** | UNKNOWN(캡) | SAT |
|---|---|---|---|---|
| 200,000 | 60 | **1** | 59 | **0** |
| 3,000,000 | 12 | **4** | 8 | **0** |

결정된 4개의 탐색 비용: 189,436 · 233,914 · 1,055,328 · 2,055,925 노드(10–97초). UNKNOWN 은
3M 캡에서 95–144초. **SAT 은 하나도 나오지 않았다** — 그러나 이것은 증거가 아니라 캡의
그림자이므로 어떤 결론도 끌어내지 않는다.

파일럿 UNSAT 4개(`6273274c` `cca008e3` `7921d0cb` `714d11e1`)는 **D1·D4b 폐쇄 8개와
교집합이 없다.** 즉 정확 조건은 값싼 조건들보다 **엄격히 더 많이** 잡는다.

이것이 라운드 94 와 달라진 지점이다. 라운드 94 층 C 는 200k 캡에서 **427/427 UNKNOWN** 이었다.
차이는 (i) 입력이 A+B2 를 통과한 쌍으로 좁혀졌고, (ii) 매칭이 아니라 도달성·terminal
가지치기를 단 DFS 라는 점이다.

**1,069개 `UNIQUE_AB` 쌍 중 12개만 시도했다. 전수 아니고, 소진 아니다.**
