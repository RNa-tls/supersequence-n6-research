## 2. `J = G − F` 의 구조적 정체 (§2)

라운드 126 이 증명한 대로 pass `p` 의 탈출 단어의 회전 후속은 **같은 육각형에서 순환적으로
다음 pass 의 진입 단어**다: `σ(exit(p)) = entry(ν(p))`.  그러므로 abandonment 의 정의는

> **abandonment(p) ⟺ `entry(ν(p))` 가 그 시점에 미방문 ⟺ `p < ν(p)` (walk 순서)**

가 된다.  walk 의 마지막 pass 는 탈출 joint 가 없지만 뒤에 아무 pass 도 없어 `p < ν(p)` 가
성립할 수 없으므로 **경계 예외가 없다.**  따라서

    F = #{p : p < ν(p)} = ν-상승의 총 개수
    m_h := e_h,  d_h := h 의 ν-순환에서 하강 수  ⇒  상승 수 = m_h − d_h
    F = Σ_h (m_h − d_h) = P − Σ_h d_h,   G = P − n!/n
    **J = G − F = Σ_h d_h − n!/n = Σ_h (d_h − 1) ≥ 0**

`d_h ≥ 1` 인 이유: 순환을 따라 전부 상승이면 `p < ν(p) < … < p` 라 모순이다.
`m_h = 1` 이면 `ν(p) = p` 라 상승 0, `d_h = 1`.

**따라서 `J` 는 "abandonment 없는 재진입" 도 "다른 종류의 pass 분할" 도 아니다.
`J` 는 한 육각형의 `ν`-순환이 walk 순서에 대해 **여러 번 되감기는** 횟수다.**
`m_h = 2` 면 상승/하강이 정확히 하나씩이라 되감기가 하나뿐이고 기여가 0 이다.
**되감기가 둘 이상이려면 순환 길이가 3 이상, 즉 `e_h ≥ 3` 이어야 한다.**

## 7. `F = 1` 열 감사 (§7) — 최우선

> **정직한 이름: `(k, G) = (1, 1)` 이 닫혔다.**  260 실행 · 전부 `UNSAT_COMPLETE` ·

## 10. 라운드 123 의 Codex 확인 범위 (§10)

Codex 가 확인한 first-short root cover 정리는 라운드 123 이 쓴 가정 아래의 것이고,

## 11. Q2 의 지위 (§11)

레거시 엔진은 받아들이는 조건으로 **`state.F == TARGET_F == 1` 과 `state.P == TARGET_P == 121`
을 둘 다** 요구한다.  `P = 121 ⟺ G = 1` 이고 `G = 1 ⟹ F = 1` 이므로 두 조건은 **같은 집합**을
정의한다.

> **Q2 는 `G = 1` 모델이다.**  이것은 역사적 프로그램을 **더 선명하게** 만든다 —
> `P=121, O=25, D=4` 라는 상수들이 전부 `G = 1` 의 직접 귀결이기 때문이다
> (`D = 5k − G = 5 − 1 = 4`).
>
> **6,396/6,396 인증서의 범위는 숫자로는 변하지 않는다.**  그 인증서가 배제하는 것은
> 여전히 정확히 그 6,396개 인코딩된 상태의 완성이다.  바뀌는 것은 그 population 을
> 부르는 **이름**이다: "일반 `F = 1`" 이 아니라 **`G = 1`** 이다.

## 12. 정리 A 재유도 (§12)

`S = (r−1) + x − f_out`, `r = O + e` 를 넣으면 임의의 `X` 에 대해

    O ≤ 1 + S + X   ⟺   f_out ≤ X + e + x

다.  **슬랩 표가 필요로 하는 것은 길이 항등식과 같은 `X`, 즉 `X = G` 다.**
`F`-형은 `F ≤ G` 이므로 **더 강한** 진술이고, 표를 세우는 데 필요하지도 않으며
일반적으로 참인지도 알려져 있지 않다.

| 범위 | `O ≤ 1 + S + G` 의 상태 |
|---|---|
| `G = 0` | 자명 (짧은 pass 가 없어 `f_out = 0`) |
| `G = 1` | **증명됨** (라운드 117 보조정리 E: `f_out ≤ 1 + e`) |
| `G = 2` | **증명됨** (라운드 126 유형 A + 라운드 127 유형 B: `f_out ≤ 2 + e`) |
| `G ≥ 3` | **미증명 — 경험적** |

## 13. `N` 재검토 (§13)

`L = 844 + G + S + H` 가 `L = 868 + (k + N + H)` 와 같으려면 `G + S = O + N`, 즉
**`N = S + G − O`** 여야 한다.  옛 `N = S + F − O` 는 `J = 0` 일 때만 같다.

`N` 의 사용처를 추적하면: 라운드 110 의 슬랩 유도(위에서 정정), `F=0`/`F=1` 열 유도
(`G = 0`/`G = 1` 이라 `J = 0` — **영향 없음**), 그리고 Q2 아카이브의 `Ndef` 필드.
아카이브는 `G = 1` population 이므로 **그 안에서는 두 정의가 같다.**

> 다만 **부분 상태(partial state)의 `Ndef` 회계는 별도 문제**다.  부분 walk 에서는 아직
> 진입되지 않은 육각형이 있어 `G = P − 120` 이 성립하지 않는다.  이 라운드는 그 회계를
> 재검토하지 **않았다** — 열어 둔 항목으로 명시한다.

## 14. `J` 의 비용 (§14)

`J` 는 `L = 844 + G + S + H` 에 **나타나지 않는다** — 한 단위의 `J` 가 그 자체로 길이를
소모하지는 않는다.  구제는 길이 벌점이 아니라 **다중도 요구**에서 온다:

    d_h − 1 ≤ e_h − 2  ⟹  **J ≤ G − m**  (m = 다중 진입 육각형 수)  ⟹  **F ≥ m**
    **J > 0 ⟹ 어떤 육각형이 세 번 이상 진입된다 ⟹ G ≥ 2**

> **`G ≤ 1` 영역에서는 `J ≡ 0` 이므로 `F = G` 가 자동이다.**
> 라운드 115–125 가 돈 영역이 정확히 그것이므로, **그 라운드들은 이름 말고는 아무것도
> 영향받지 않는다.**

`n = 4` 전수(29,255 walk)에서 `F ≤ G` · `F = 0 ⟺ G = 0` · `G ≤ 1 ⟹ F = G` ·
`모든 e_h ≤ 2 ⟹ F = G` · `J > 0 ⟹ 어떤 e_h ≥ 3` · `F ≥ m` · `J ≤ G − m` **전부 위반 0**.
