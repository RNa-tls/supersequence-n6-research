# Start here

**[`SUPERPERMUTATION_N6_MASTER_STATUS.md`](SUPERPERMUTATION_N6_MASTER_STATUS.md)**
is the recommended starting point for understanding this project's current
status. It is a single authoritative entry point that lets a new
researcher understand where this project stands without reconstructing
dozens of individual round reports manually.

It covers, in logical (not just chronological) order: the global n=6
minimal-superpermutation problem and this project's coordinate system; the
foundational proved results; a dedicated catalog of every historical claim
that was later invalidated or corrected (so old reports can't be mistaken
for current truth); the full logical reduction chain of the "RR-short"
search program; the strongest current result (the `short_ell2_r1_37` T4
theorem) and the generic VNTS lemma behind it; an evidence-grading
taxonomy applied throughout; a quantitative ledger of the major
computational runs; an explicit "what is proved / what is NOT proved"
split; ranked open problems; a conservative list of contributions that
appear original within this project; a reproducibility map; and a
chronological appendix.

A compact machine-readable mirror of the same content is at
[`../outputs/superpermutation_n6_master_status.json`](../outputs/superpermutation_n6_master_status.json).

**Read the master status document's own source-of-truth policy** (its
first section) before citing any number from it: the individual machine
certificates under `outputs/*.json` and their verifier scripts under
`src/*.py` remain the authoritative source for exact counts, not this
index.

Individual round reports (`research/RR_*.md`, `research/J_*.md`, and
similar) remain in this directory and are still useful for the full
detail behind any specific claim — the master status document's
reproducibility map (its §14) links to the right ones for each major
result. But they should not be read cold, in isolation, or assumed to
reflect current status: several were later corrected (see the master
document's §5).
