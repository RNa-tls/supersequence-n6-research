## 1. 정확한 비용 회계 (§9, §10)

`(k,F) = (0,0)` 이면 entry 120개 = 포화된 24개 궤도(라운드 113 보조정리 A), `L = 844 + S + H`.

* **run** = 한 E-궤도에서 나온 극대 연속 entry 구간. `r` = run 수, `e := r − 24`.
* 자유 호(무게 2 = `τ`)는 궤도를 바꾸지 않으므로 **전부 run 내부**다. run 내부 호는 정확히
  `120 − r` 개이므로
  > **`S = (r − 1) + x`**, `x` = run 내부의 **비자유** 호 개수 (`W3a` 또는 궤도내 무거운 이동).
* `t` = 모두 경량인 연결자로 이어진 **극대 사슬** 수 → 무거운 연결자 `≥ t − 1` → `H ≥ t − 1`.

> **`cost = S + H ≥ (r−1) + x + (t−1) = 22 + e + x + t`.**
> `L ≤ 871 ⟺ cost ≤ 27 ⟺` **`e + x + t ≤ 5`.**

`r` 별 요구량 (라운드 113 이 `r = 24` 만 다뤘던 이유가 여기서 분명해진다):

| `r` | `e` | `S ≥` | 필요한 `H` | 필요한 `e+x+t` |
|---|---|---|---|---|
| 24 | 0 | 23 | ≥ 5 | ≥ 6 |
| 25 | 1 | 24 | ≥ 4 | ≥ 6 |
| 26 | 2 | 25 | ≥ 3 | ≥ 6 |
| 27 | 3 | 26 | ≥ 2 | ≥ 6 |
| 28 | 4 | 27 | ≥ 1 | ≥ 6 |
| ≥29 | ≥5 | ≥28 | 0 | 자명 |

**모든 `r` 에서 요구는 하나로 통일된다: `e + x + t ≥ 6`.**

## 3. `M*(B)` — phase 상관을 지우지 않은 사슬 용량 (§5, §7)

> **정의.** `M*(B)` = 결합 예산 `B` (= 그 사슬에 부과된 여분 run + 사슬 안의 비자유 run 내부 호)
> 로 **하나의 all-light 사슬**이 덮을 수 있는 **서로 다른** E-궤도의 최대 수.

모델은 `(궤도, 사용된 phase 집합, 현재 phase)` 를 유지한다 — **phase 를 몫으로 지우지 않는다.**
run 은 임의의 미사용 phase 로 이동할 수 있고 `+1`(τ)은 무료, 그 외는 1 을 낸다. 새 궤도는
사슬 안의 기존 궤도와 육각형-서로소여야 한다. 미완성 궤도는 나중에 run 이 하나 더 필요하므로
예산 1 을 부과한다.

**`S₆` 재라벨 대칭**이 `σ, τ, W3c` 와 교환하고 720 단어에 **추이적**이므로 시작 단어 하나로
충분하다 (서로 다른 시작점이 같은 값을 준다는 것도 확인했다).

| `B` | **`M*(B)`** | `3B+4` | 탐색 노드 | 캡 도달 |
|---|---|---|---|---|
| 0 | **4** | 4 | 20 | 없음 |
| 1 | **7** | 7 | 733 | 없음 |
| 2 | **10** | 10 | 18,970 | 없음 |
| 3 | **13** | 13 | 326,835 | 없음 |
| 4 | **16** | 16 | 4,469,954 | 없음 |

> **`M*(B) = 3B + 4`** — 전수, 캡 도달 0. 여분 run 하나가 사는 것은 **정확히 궤도 3개**다.
> (`B = 0` 은 라운드 113 의 `M(0) = 4` 를 재현한다.)

## 4. 할당 논증 (§8)

**예산은 이중 계상되지 않는다.** 궤도 `q` 가 `c` 개 사슬에 걸쳐 `a_1,…,a_c` 개의 run 을 가지면
사슬별 부과의 합은 `Σ(a_i − 1) + (c − 1) = t_q − 1` 로 **정확히** 전역 여분 run 과 같다.
따라서 `Σ B_i = e + x =: B`.

24개 궤도가 **모두** 어떤 사슬엔가 나타나야 하므로

    24 ≤ Σ d_i ≤ Σ (3 B_i + 4) = 3B + 4t
    ⇒  t ≥ (24 − 3B)/4
    ⇒  B + t ≥ B + (24 − 3B)/4 = (24 + B)/4 ≥ 6      (모든 B ≥ 0)

| `B` | `t ≥` | `B + t ≥` |
|---|---|---|
| 0 | 6 | **6** |
| 1 | 6 | 7 |
| 2 | 5 | 7 |
| 3 | 4 | 7 |
| 4 | 3 | 7 |
| ≥5 | 1 | **≥ 6** (자명) |

> **따라서 `e + x + t ≥ 6`, 즉 `cost ≥ 28`, 즉 `L ≥ 872`.** ∎
>
> `B = 0` 에서 등호 `B + t = 6` 이 성립한다 — 하한은 **빠듯**하다.

## 5. 양성 대조 (§12) — 거짓 기각 0

이 저장소의 greedy 873 을 모델에 넣으면:

| | 값 |
|---|---|
| `r`, `e`, `x`, `t`, `B` | 24, 0, 0, **6**, 0 |
| 모델 예측 `cost ≥ 22 + e + x + t` | **28** |
| 실제 `cost = S + H` | **29** |
| 실제 `L` | **873 ≥ 872** ✔ |
| 사슬당 궤도 수 | `24 / 6 = 4 = M*(0)` ✔ |

**거짓 기각 0.** 그리고 이 walk 은 `B + t = 6` 이라는 **극단 경우**에 정확히 앉아 있다.

## 6. 반례 탐색 (§13)

`M*(B)` 를 확정한 탐색은 **전수이며 캡에 걸리지 않았다.** 정리가 `e + x + t ≥ 6` 을 강제하므로
`(k,F)=(0,0)`·`r ∈ 25..28`·`L ≤ 871` 인 phase-유효 배치는 **존재하지 않는다.**
하한은 달성되지만(greedy 873) 위반되지 않는다.
