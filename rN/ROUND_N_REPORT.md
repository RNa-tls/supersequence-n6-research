## 0. 결론 요약 (최종 갱신은 §F)

* **새 기록 없음.** 최선은 여전히 L = 46185 (J = 100)이다.
* **J ≤ 99의 존재 여부**
  * 단일 개방 모형(각 trail 한 조각): SAT 결정 문제로 부호화하고 46185로 부호화를 검증했다. 결정 결과는 §14와 §F에 적는다.
  * 전체 가족(다중 개방·다중 방문): **미해결.** 엄밀한 하한은 여전히 판본 0 고정 시작점에서 J ≥ 65이다. 대신 46185 근방에서 "모든 개방 패턴 + 판본 자유"의 정확한 창(window) 재최적화가 97개 창 모두에서 개선 없음을 증명했다(§13).
* **이번 라운드의 새 엄밀 결과**(계산 증명 + 검사 가능한 자료)
  1. J 항등식의 7가지 형태를 두 46185 단어에서 항별로 재검증했다(§1).
  2. 영-초과 그래프 G0의 **STD/ROT 분리 정리**: chain 진입 노드 수준에서 표준 진입(p1)과 회전 진입(p≥2)은 G0 호로 서로 이어지지 않는다(A 안의 예외 24개 제외). 회전 세계는 길이 ≤ 6의 경로·순환(가상 3-사이클)으로만 이루어진다(§6).
  3. **φ 성분 정리**: 24개 φ는 이상 연결 그래프에서 C1, C2(각각 3-큐브 + 잎 3개, 11개)와 고립된 φ0, φ14로 나뉜다. 서로 다른 성분 사이의 모든 run 전이는 **w ≥ 5**이다(판본 혼합 포함, run 수준 전수). 따라서 성분을 바꾸는 직접 연결은 항상 e ≥ 2이다(§6–7).
  4. **기호적 ≤ 5 정리(φ 사슬)**: φ–φ 이상 연결 1320개는 모두 틀(frame)의 인접 호환이다. 같은 선택지에서 이어지는 두 이상 연결은 같은 기호를 같은 방향으로 민다(480쌍 전수). 그래서 이상 사슬은 한 4-사이클 안에 있고 trail은 5개를 넘지 못한다(§6).
  5. **성분 경로 덮개 정리**: C1을 경로 c개로 덮는 최소 내부 초과는 PC(c) = C(6−c, 2) = 10, 6, 3, 1, 0 (c = 1..5)이다(§7).
  6. **절단 전하 보조정리**: A의 모든 단일 조각 개방 8064개에서 IN + OUT ≥ 1이다. 즉 A 하나를 φ 사이 다리로 쓰면 β-단위로 항상 ≥ 3이 든다(§4).
  7. **E ≥ 48**: 판본을 어떻게 섞어도 가중치 2 전이는 같은 trail·같은 판본 안에서만 생긴다(§1).
  8. **φ 단일 방문 목록(정확)**: φ 하나의 42 × 42 (진입, 진출) 쌍 모두에 대해 내부 비용 κ를 정확히 계산했다. 단일 조각 밖에 κ = 1인 새 쌍이 12개 있다. 이것을 넣은 확장 모형 M2-φ의 LP 값도 16.111로 같다(§5).
  9. Lean 신뢰 핵심 `rN/lean/LinkingCore.lean`(sorry·admit 없음, 공리 propext·Quot.sound뿐)(§16).

## 1. J 항등식 감사 (§1)

`rN/src/audit_identity.py`는 원시 단어 문자열과 가족 JSON만 읽는다. 다음 7가지 형태를 독립적으로 계산하고 모두 같은지 확인한다.

| 형태 | 식 | 46185 | 46185_b |
|---|---|---|---|
| (R) run 수준 | J = Σ_t (w_t − 2) − 719 | 100 | 100 |
| (Q) 4chan | J = (q − 720) + #(w ≥ 4) + Σ_{w≥4}(w − 4) | 100 | 100 |
| (C) chain | J = 48 + (q − 768) + Σ_{비F}(w − 3) | 100 | 100 |
| (P) 조각 | J = 48 + [c₀ = 2] + Σ_{k≥1} β_k, β_k = w_k − c_k | 100 | 100 |
| (E) 초과 | J = 48 + (P − 1) + [c₀ = 2] + Σ e_k | 100 | 100 |
| (V) 방문 | J = 48 + κ(v₁) + Σ_{v≥2}(w_in(v) − 3 + κ(v)) | 100 | 100 |
| (S) 구간 | J = 48 + (S − 1) + splits + Σ_연결 (w − 4) | 100 | 100 |

* 공통 자료: q = 774, E = 54, τ − 1 = 28, λ = 18, 조각 30, 방문 30, G0-구간 29, 분할 6.
  * 절단: F-단계 6, 연결(link) 24. 경계 무게 분포: 3 ×1, 4 ×15, 5 ×8, 6 ×5.
  * e 분포: 0 ×12, 1 ×11, 2 ×6 → Σe = 23.
* 46185_b는 판본 1을 trail 8개(3, 4, 16, 17, 19, 20, 21, 26)에 쓴다. 그래도 모든 항이 같다.
* 각 개방의 효과(chain 수 기준, 정확).
  * **F-단계 절단**: chain 하나가 둘로 나뉜다. ΔE = +1, 조각 +1, 진입점은 chain 중간, 진출점은 그 앞 run이다.
  * **연결(link) 절단**: ΔE = 0, 조각 +1, 진입점은 chain 시작(p1), 진출점은 앞 chain의 끝(p7 또는 짧은 chain의 끝)이다.
  * **w = 2 경계(감싸기)**: ΔE = −1이다. 회전된 full chain(7-순환)에서만 생긴다.
  * **경계 초과** e = w − c_next − 1: 연결 절단으로 들어가면 w − 4, F-단계로 들어가면 w − 3이다.
* **E ≥ 48 (전체 가족)**: `w2mixed` 검사 결과는 다음과 같다(모든 판본 조합).
  * 가중치 2 전이: trail F-단계 8544, 감싸기 1200, 같은 trail의 다른 판본 816, 대상 없음 240.
  * 서로 다른 trail 사이의 가중치 2 전이는 0개이다.
  * 그러므로 단어의 chain 수 q ≥ 768이고, 따라서 E ≥ 48이다.
* 자료: `rN/certs/audit_superperm8_46185.json`, `audit_superperm8_46185_b.json`(조각별 표 포함).

## 2. 94 → 100 간극의 분해 (§2)

* **LP 해부**(`lp_anatomy.json`). 단일 개방 LP(16.111)와 46185(23)를 같은 경계 범주로 나누어 비교했다.

| 범주 | LP | 46185 | 차이 |
|---|---|---|---|
| C1·C2 내부 (φφ 같은 성분) | 7.315 | 7 | −0.315 |
| A 관련 (φ→A, A→φ, A→A) | 4.211 | 10 | **+5.789** |
| C1↔C2 직접 | 2.000 | 2 | 0 |
| φ0/φ14 경계(A 제외) | 2.585 | 4 | +1.415 |
| 합 | 16.111 | 23 | 6.889 |

* **해석**: 빠진 6.9 단위 가운데 5.8은 A-다리, 1.4는 φ0/φ14 연결에서 나온다. 성분 내부는 LP가 오히려 0.3 비싸다.
  * A-다리의 바닥값은 절단 전하 보조정리로 다리마다 ≥ 1이다.
  * 그러나 다리 비용 1이 가능한 (진출, 진입) 쌍은 φ 선택지 쌍 406만 개 중 1740개뿐이다. 그 진출은 1692개가 F-단계 선택지이다(나머지 48개는 C1↔C2 연결-연결 쌍).
  * LP는 이런 드문 쌍과 A–A 블록(τ₂ = 0인 쌍 84개)을 분수로 섞어 다리당 ≈ 0.97을 얻는다. 46185의 다리 평균은 1.67이다.
* **완화 사슬**(같은 모형에서 제약을 추가하며 LP 값을 측정).
  * 경로 덮개 절단(성분 C1, C2): 16.143.
  * 성분별 run 수 고정: (r1, r2) = (4, 4)는 17.0, (3, 3)은 16.2.
  * A 배치 고정(단일 다리 6개, 끝 블록 없음, Round M): 17.0.
  * **trail 순서 고정**: LP가 정확해진다. 층별 DAG의 최단경로 LP는 전단모듈러이므로 46185의 순서에서 정확히 23이다.
* **결론**: 간극은 전부 "trail 순서의 분수 혼합"에서 나온다. 순서를 고정하면 선택지 정수성 간극은 0이다.
  * 그 안에서 가장 큰 원천은 A-다리의 끝점 양립성(5.8)이다.
  * 다음은 φ0/φ14 연결(1.4)이다. 이 둘은 이상 연결이 전혀 없는 고립 φ이다.
