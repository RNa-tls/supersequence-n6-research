## 2. φ-사이클 집합 정리와 {a,b}-시스템

**정리 P (모든 n ≥ 4).** g[n−1] = a, g[n−2] = b, C = g[0..n−3]의 순환 배열이라 하자. 그러면

    {class(g φ^k F^i)} = P({a,b}, C) := { a와 b를 지우면 C가 되는 순환어 }

이고, 그 크기는 (n−2)(n−1)이다.

* 증명:
  * φ는 위치 0..n−3을 회전하고 n−2, n−1을 고정한다. 따라서 φ^k는 C 안에서 b의 삽입 위치(n−2가지)를 모두 돌린다.
  * F^i는 위치 0..n−2를 회전한다. 따라서 a의 삽입 위치(n−1가지)를 모두 돌린다.
  * 서로 다른 (b-위치, a-위치)는 서로 다른 순환어를 준다.
  * 그러므로 정확히 (n−2)(n−1)개이며, 집합은 C로 결정된다. ∎
* 따름정리: 쌍 {a,b}를 고정하면 (n−3)!개의 P(C)가 모든 클래스를 분할한다. 이것이 표준 구성(φ-사이클 (n−3)!개)이다.

**보조정리 C.** 특수 기호(위치 n−1)가 a인 chain s, sF, …, sF^{ℓ−1}에서 F는 위치 0..n−2의 순환 순서를 보존한다. 따라서 모든 클래스가 같은 P({a,b},C)에 속한다. b에 대해서도 같다. ∎

**보조정리 T (bac 전이 = 인접 교환).**

* s′ = s∘F^ℓ∘φ는 순환열 D = (s₀..s_{n−2})에서 인접한 쌍 (s_{ℓ−1}, s_ℓ)를 교환한다. 새 시작점은 s_{ℓ+1}이다.
* full chain 뒤의 φ에서는 위치 n−2의 기호(pivot)가 고정되고, 다음 기호가 그것을 넘어간다.
* pivot이 b이면 C는 그대로이다(표준 φ-사이클).
* pivot이 b가 아니면 C가 인접 전치 하나만큼 바뀐다.

(`bundle_coords.py`, `bundle_cycle.py`, `bundle_grid.py`)

**46188의 해부**(계산, 정확).

* 모든 chain의 C는 상수이다.
* 각 긴 trail은 정확히 16개 P(C)의 합집합이다.
* 96개 번들 C와 24개 자유 C는 서로소이고, 합쳐서 120개 전부이다.
* 각 긴 trail은 C₀→…→C₁₅→C₀라는 16-순환을 5바퀴 돈다(104 chain 중 80개의 C-변화).
* 16-순환은 4분기로 나뉜다. 각 분기에서 기호 하나가 4칸 이동한다. 예를 들어 trail 0에서는 (43)(41)(45)(46) | (56)(54)(52)(53) | (23)(25)(21)(26) | (16)(12)(14)(13)이다.

## 3. 번들: 허브/일반 구조와 절약 공식

**허브 C**(번들 A에서 4개, 각 X-음절에 하나). P(C)의 6×7 격자(b-슬롯 × a-위치)는 다음과 같이 덮인다.

* b-슬롯 1..5: a5-chain 5개. 각각 a-열 1..4를 덮는다.
* b-슬롯 0: a4-chain 1개.
* 빈 a-열 0과 5: b-chain 2개(b7, b6).

chain 수는 8 = (n−2) + 2이다.

**일반 C**(12개). full a-chain 6개가 서로 다른 시점에 방문해 덮는다.

**절약 공식.** k개 배열, d개 허브를 가진 번들의 chain 수는 k(n−2) + 2d이다. 같은 k개를 자유 φ-사이클로 덮으면 비용이 k(n−1)이다. 따라서

    절약 = k(n−1) − (k(n−2) + 2d + 1) = k − 2d − 1.

* A: 16 − 8 − 1 = 7.
* B: 12 − 8 − 1 = 3.
* 둘 다 실측값과 일치한다.

## 6. 일반 n의 대수 (§7–8)

`syllable_algebra.py`에서 n = 5..14에 대해 검증한 항등식:

* g_σ := F⁻¹∘T_σ로 두면 π(ℓ,σ) = F^ℓ∘g_σ이다.
* g_bac = φ (앞 n−2 자리 회전).
* g_cba = κ = (0 1 … n−3 n−1 n−2)는 **n-순환**이다.
* S_r = F⁻²φ^{r+1}.
* X_r = F⁻²κF⁻¹φκF⁻³φ^{r+1}.

**정리 (S_{n−4}의 위수).**

* N = n−1로 둔다. a_n = F⁻²φ⁻¹은 위치 0..n−2 위에서 "i ↦ i−3 (mod N)" 다음에 값 n−5와 n−4를 교환하는 것과 같다.
* gcd(3,N) = 1이면 N-순환이 길이 d와 N−d로 갈라진다. 여기서 d ≡ −3⁻¹ (mod N)이다.
* 3 | N이면 N/3-순환 셋 중 둘이 합쳐져 순환형이 (2N/3, N/3)가 된다.
* 따라서 ord(a_n) = lcm(d, N−d) 또는 2N/3이다.
* n = 5..14의 모든 계산값과 일치한다. n=8에서는 (5,2)이고 위수 10이다.
