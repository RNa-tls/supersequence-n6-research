## 2. r=0 최적화의 정확한 정식화 (§1–2)

**정의.**

* **r=0 경로**: 모든 순환 클래스가 n개 순열의 단일 run(cost-1 연결 n−1개)으로 방문되는 경로. 클래스 c의 run 시작을 s_c로 쓴다.
* 클래스 사이 연결 비용은 c = cost(R⁻¹s, s′) ≥ 2이다.
* **c = 2 ⇔ s′ = F(s)** (F = 앞 n−1 자리 회전; R(s)는 같은 클래스라 제외된다).
* **chain**: cost-2 연결의 극대 열 = 블록 s⟨F⟩의 F-호 {s, sF, …, sF^{ℓ−1}}, 1 ≤ ℓ ≤ n−1. ℓ = n−1이면 **full**이다. 같은 블록에 여러 chain이 있어도 된다.
* **cost-3 후속**: chain의 마지막 시작이 x일 때 t = (x₂..x_{n−2}, σ(x₀,x₁,x_{n−1}))이다. σ는 6가지이고, cab = R²x는 같은 클래스이므로 제외된다.
* **trail**: cost-3 연결로 이어진 chain의 극대 열.
* **chain 점수** = ℓ − (n−2). **trail 점수** v = chain 점수의 합. 이것은 r178의 v = rows − charge와 일치한다.
* **정확 분할**: 모든 클래스가 정확히 한 chain에 속하는 것. r=0이면 자동으로 성립한다.
* **전역 서로소성**: 서로 다른 chain의 클래스가 겹치지 않는 것.

**정리 1 (r=0 길이 항등식, 양방향).**

* (A) 클래스 열 s_1, …, s_HEX(각 클래스 하나)와 그 연결 비용 c_i가 주어지면, 최대 중첩 연결로 만든 단어는 모든 순열을 포함한다. 그 길이는 n + (n−1)·HEX + Σc_i이다.
* (B) 모든 r=0 경로는 이런 열이다.
* (A)와 (B)에서 다음이 나온다.

      L = CONST − ORB + q + Σ_{c≥4}(c−3) = CONST − ORB + q + η + E5.

* 증명: 한 클래스 run의 비용은 n−1이다. 연결은 HEX−1개이다. cost-2 연결은 chain 내부에 HEX−q개 있다. 나머지 q−1개 연결은 cost ≥ 3이다. 이를 합하면 Σc = 2(HEX−1) + (q−1) + Σ_{c≥4}(c−3)이다. ∎
* 산술 핵심(Σc = 2·len + #{c≥3} + Σ(c−3)⁺와 최종 항등식)을 **Lean 4로 형식화**했다(`rI/lean/R0Identity.lean`). sorry/admit/axiom 없이 컴파일된다.

**점수와의 관계.**

* Σℓ = HEX이므로 Σv = HEX − (n−2)q이다. 따라서 **점수 최대화 ⇔ chain 수 q 최소화**이다.
* q ≥ ORB이고, 등호는 모든 chain이 full일 때이다.
* 고전 재귀 구성이 이 등호를 실현한다. 그러므로 S(n) := max Σv = ORB이다(자명).
* 길이는 q만이 아니라 trail 사이 연결에도 의존한다. 정확한 목적함수는 다음과 같다.

      Φ := q + Σ_{trail 사이}(c−3),   L_r0(n) = CONST − ORB + min Φ,
      ⇔ W := Σ_trail (v_i − (n−2)) − (n−2)E5 최대화,  L = f(n) − W/(n−2).

**W의 해석.**

* trail 하나는 "n−2"의 기준값을 빚진다.
* φ-사이클(n−2개 full chain, v = n−2)은 W에 0을 기여한다. 표준 구성은 W = 0, 즉 L = f(n)이다.
* 46188에서 긴 trail 하나는 +42를 기여한다. 이는 φ-사이클 16개를 104 chain짜리 trail 하나로 합친 효과이다. trail 15개를 절약하고 chain 8개를 더 쓰므로, 길이 단위로 순 7이다.
* 남은 3조각은 −12, E5는 −144를 기여한다.
* 합: W = 252 − 12 − 144 = 96이므로 L = f − 16이다.

## 3. 긴 trail 하나의 완전 해독 (§3)

상태는 chain 시작 순열 s이다. 각 단계는 **위치 순열의 오른쪽 작용**이다. 즉 s_{j+1} = s_j ∘ π(ℓ_j, σ_j)이고, π(ℓ, σ) = F^{ℓ−1} ∘ T_σ이다.

여기서 다음을 쓴다(`decode_long.py`, `certs/decode_long46188.json`).

* T_σ = (2, …, n−2, σ).
* φ := π(n−1, bac)는 앞 n−2 자리의 회전이고, 위수는 n−2이다.
* 일반적으로 π(ℓ, bac) = F^{ℓ} ∘ φ이다(F^{n−1} = id).

trail 0의 26-글자 주기(특수 기호는 마지막 자리, F가 고정)는 다음과 같다.

    5b 7b 7b 7b | 5b 7b 7b 7b 7b | 5c 6b 7c 4b 7b 7b 7b 7b | 5b 7b 7b 7b | 5b 7b 7b 7b 7b

여기서 b = bac, c = cba이다.

이를 음절로 쓰면 **S₃ · S₄ · X₄ · S₃ · S₄**이다. 각 음절은 다음과 같다.

* S_r = (n−3, bac)(n−1, bac)^r
* X_r = (n−3, cba)(n−2, bac)(n−1, cba)(n−4, bac)(n−1, bac)^r

**주기 원소.**

* Π = π₁∘…∘π₂₆ = [2,5,6,3,0,1,4,7] (한 줄 표기, (s∘Π)[i] = s[Π[i]]).
* 순환 분해는 (0 2 6 4)(1 5)(3)(7)이다. **위수는 4이다.**
* 시작 s₀ = (5,6,2,7,4,3,1,0)에서 대응하는 기호 재명명은 τ = s₀Πs₀⁻¹ = [0,4,1,6,5,2,3,7]이다.

**행 통계.**

* chain 길이 합은 주기당 168이고, 4주기에서 672 클래스이다.
* 점수는 주기당 19·(+1) + 5·(−1) + 0 + (−2) = 12이고, 4주기에서 48이다.
* 특수 기호는 대부분 0이다. cba가 두 번 나오는 X 음절에서 2행 동안 특수 기호가 7로 바뀐다.

**6개 긴 trail은 모두 같은 순환어의 회전(위상)이다.**

trail 0의 단어를 기준으로 한 회전량은 다음과 같다(경로상 첫 행 기준).

* trail 0, 2, 4: 회전 0
* trail 1, 5: 회전 22
* trail 3: 회전 4

각 trail의 Π는 이 회전에 대응하는 켤레(conjugate)이다.

## 4. 26행 주기 정리 (§4)

**정리 2.** ω를 위의 26-글자 순환어라 하자. 임의의 시작 s에 대해 trail T(s) = (s·P_j)_{j<104}를 생각한다. 여기서 P_j는 ω⁴의 접두사 곱이다.

* (a) s·P_{j+26} = (sΠ)·P_j이다. 즉 26단계 뒤의 상태는 같은 구조형이다. 변환은 위치 순열 Π의 오른쪽 작용이고, 기호로는 τ_s = sΠs⁻¹이다.
* (b) Π⁴ = id이므로 s·P₁₀₄ = s이다. trail은 정확히 104행 뒤에 닫힌다.
* (c) 클래스 집합 C(ω⁴) = {P_j F^i ⟨ρ⟩ : j < 104, i < ℓ_j}는 서로 다른 672개의 ⟨ρ⟩-좌잉여류로 이루어진다. 따라서 모든 s에 대해 T(s)는 유효한 trail이다.
* (d) Π·C = C이다. 따라서 τ_s는 T(s)의 클래스 집합을 보존한다(위수 4).

**증명.**

* (a): ω가 26-주기이므로 접두사 곱이 P_{26+j} = Π·P_j를 만족한다.
* (b): Π의 순환형이 (4,2,1,1)이다.
* (c): 클래스 s·g⟨ρ⟩는 s에 왼쪽 곱으로 의존하므로, 서로 다름은 s와 무관하다. 그러므로 S₈ 안에서 104·7개 이하의 원소를 정확히 계산하면 증명이 된다. 이는 시뮬레이션이 아니라 특정 유한군 명제의 검증이다.
* (d): (a)와 (b)에서 나온다.

∎ 일반 n으로의 확장은 §7을 보라.

## 5. 왜 6개인가 (§5)

`symmetry46188.py`는 S₈의 40320개 기호 재명명을 전수 조사했다.

* 긴 trail 0의 클래스 집합의 안정자는 위수 8이다. ⟨τ⟩ ≅ C₄와 (0 7)의 곱 C₄ × C₂이다.
* 클래스 집합을 다른 긴 trail로 보내는 재명명은 48개(= 6 × 8)이다. 이 집합은 **군이 아니다**.
* 긴 trail 합집합의 안정자와 분할 전체의 안정자는 같다. 위수는 12이다. 비가환이고, 중심의 위수는 2이며, 원소 위수 분포는 1¹·2⁷·3²·6²이다. 따라서 **D₆ ≅ S₃ × C₂**이다.
* 6개 긴 trail 위의 작용은 추이적이고, 점 안정자는 중심 ⟨(0 7)⟩이다. 따라서 **S₃가 6개 trail 위에 정칙 작용**한다.
* 24개 φ-사이클의 궤도 크기는 2, 2, 2, 6, 6, 6이다.

**결론.**

* 6은 "S₃의 정칙 궤도 하나"이다.
* n=8에서는 3! = n−2라서 두 해석을 구분할 수 없다. 따라서 **six = n−2는 구조적으로 증명되지 않았다**.

## 8. 고점수 주기 trail의 분류 / 최대 평균 사이클 (§9–10, §25)

**Lemma R (full-chain 강성, 모든 n ≥ 5, 기호적 증명).**

full chain이 s = (s₀..s_{n−1})에서 시작하고 마지막 시작이 x = F⁻¹s라 하자. cost-3 후속 t를 σ별로 보면 다음과 같다.

* abc: t = sF이다. 이미 사용한 클래스이다.
* acb: t = R(s)이다. s의 클래스이다.
* cab: t = R²x이다. x의 클래스이다.
* bca: t = (s₁..s_{n−3}, s₀, s_{n−1}, s_{n−2})이다. tF^{n−3}의 순환어가 sF의 순환어와 같다(직접 계산).
* cba: tF^{n−3} ~ s이고 tF^{n−2} ~ sF^{n−2}이다.
* bac (= φ): 특수 기호 s_{n−1}이 같으므로, 교차 정리에 의해 블록이 서로소이다.

따라서 full chain 다음 chain은 φ로 이어지거나, bca/cba이면서 길이가 ≤ n−3이다. `rigidity.txt`는 n=5..12에서 이 충돌 위치가 n에 대해 균일함을 확인한다.

**따름정리.**

* 연속한 full chain은 φ-경로이다. 그 길이는 ≤ n−2이다(φ^{n−2} = id).
* n−2개 다음의 bac는 첫 블록으로 돌아가 충돌한다.
* full chain만으로 된 trail의 최대 길이는 n−2이다. n=5..9에서 전수 DFS 노드 수는 5(n−2)+1로 일치한다(`fulltrail_dfs.txt`).

**자동자 하한.**

* trail은 국소 유효성(직전 w개 chain과 클래스가 겹치지 않음)과 Lemma R 카운터를 만족하는 문자열이다.
* 이것은 완화(relaxation)이며 시작점과 무관하다(왼쪽 작용).
* β* = min (k+1)/Σℓ를 매개변수 최단경로(Bellman–Ford)로 구했다. 이분 탐색 후 **유리수 β를 정수 연산으로 재검증**했다.
* 이로부터 Σ_trail (k_i+1) ≥ β*·HEX이고, L_r0 ≥ CONST − ORB − 1 + ⌈β*·HEX⌉이다.

| n | w=1 β | w=2 β | (w=3) | L_r0 하한 | CONST | f(n) | 알려진 r=0 최선 |
|---|---|---|---|---|---|---|---|
| 5 | 3/11 | 3/10 | 3/10 | **153** | 152 | 153 | 153 (재귀) → **L_r0(5)=153** |
| 6 | 4/19 | 2/9 | 2/9 | 869 | 867 | 872 | 873 (재귀) |
| 7 | 5/29 | 5/28 | 5/28 | 5892 | 5884 | 5907 | 5913 (재귀) |
| 8 | 6/41 | 3/20 | [W8] | 46120 | 46085 | 46204 | **46188** |

* Lemma R 카운터가 없으면 β = 1/(n−1)(자명)이다. 강성 보조정리가 하한의 핵심 재료이다.
* CP-SAT 일반화 ATSP(cost 상한 K=4 완화)는 n=5에서 153을 확인했다. n=6에서는 1500초 안에 하한 842에 그쳤다. 자동자 하한보다 약하다.

## 9. 전역 packing (§11–13, §16–18)

**모델**(`packing.py`):

* 닫힌 trail 모양 C의 왼쪽 평행이동 g·C(g ∈ S_n, 클래스 집합으로 중복 제거)와 φ-사이클을 쓴다.
* 정확 덮개 Σx_i v_i = 1을 만족해야 한다.
* 목적함수는 Φ_core = Σ(chains+1)의 최소화이다.
* 하한은 L ≥ CONST − ORB − 1 + Φ_core이고, 모든 연결이 cost 4이면 등호가 성립한다.

**n=8 결과.** [P8]

**23개 φ-사이클과 남은 3개 trail(§16–18).**
