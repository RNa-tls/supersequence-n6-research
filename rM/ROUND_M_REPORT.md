## 0. 표기와 항등식

* r=0 항등식(Round I, Lean `R0Identity`): `L = 45364 + q + τ + λ = 46085 + E + (τ − 1) + λ`, `E = q − 720`.
* **run 수준 항등식**: run = 시작 순열 s의 왼쪽 회전 8개. 연속한 run s → t의 비용은 `w(last(s), t)`이다(`last(s) = s₇ s₀…s₆`).
  * `L = 8 + 7·5040 + Σ(run 사이 무게) = 35288 + cost`, `J = cost − 10797`.
  * 시작점을 고정하면 **모든 개방 패턴**(개방 수, 조각, 순서, 감싸는 F-단계)이 5040-run 해밀턴 경로 하나로 표현된다. 절단은 "쓰지 않은 순환 변"일 뿐이다.
* **가족 절단 항등식**(Lean `family_cut`): 닫힌 trail들의 순환 변 다중집합에서 절단 변을 빼고 경계를 더한 것이 경로의 단계이다.

      L = 8 + Σ_T (9|T| + k_T) + Σ_경계 w_b − Σ_절단 w_c      (46187 가족: 46136 + Σ w_b − Σ w_c)

* **chain 수 항등식**(Lean `chains_identity`): `q = Σ k_T + #(F-단계 절단) − #(w=2 경계)`. 따라서 개방의 ΔE는 정확히 다음과 같다.
  * F-단계 절단: +1.
  * cost-3 절단: 0.
  * w=2 경계(감싸기 F-단계): −1.
* **결합 목적함수**(Lean `joint_J`, `joint_J_pieces`). 조각이 P개이고 첫 조각의 절단 무게가 c₀일 때:

      J = E₀ + #(F-단계 절단) + Σ_b (w_b − 3)
        = E₀ + (P − 1) + [c₀ = 2] + Σ_{k≥1} e_k,     e_k = w_k − c_k − 1   (다음 조각의 절단 무게 c_k).

  * 46187 가족: E₀ = 48. 단일 개방(P = 30)이면 `J = 77 + [c₀ = 2] + Σ e_k`이다.
  * 46185(두 단어 모두): e = 0이 12개, 1이 11개, 2가 6개이다. Σe = 23, c₀ = 3이므로 J = 100이다(Lean `record_46185`).
  * 단편화는 단조 벌점이 아니다: F-단계 절단은 ΔE = +1이지만 그 조각의 끝점을 바꿔 e를 줄일 수 있다. 46185는 이것으로 46187보다 2를 벌었다.

### 3.2 run 수준: Held–Karp 하한 (§6, §23)

* `hk_bound.py`: 차수 등식 + 부분경로 제거(SEC) LP를 내부점법으로 풀었다.
  * SEC 분리는 정확하다. 대칭화한 지지 그래프에서 x ≥ 1 변을 수축(안전)한 뒤, 깊이 노드에서 모든 노드로 최대 흐름을 구했다.
  * 수렴 값: LP = 10861.88, 절단 823개.
* **인증서**: `rM/certs/hk_46185_cert.npz`.
  * 쌍대값은 2⁻²⁰ 단위로 반올림하고, 정수 연산으로 **모든 N² 호**의 축소 비용을 계산한다.
  * 음의 축소 비용은 x ≤ 1로 보정한다.
  * 검사기 `hk_check.py`(독립 구현): 하한 10861.88 → cost ≥ 10862 → **L ≥ 46150, J ≥ 65**.

  * 인증서의 절단 823개를 46185와 46185_b 모두가 만족한다(최소 절단 값 1, 위반 0). 46185_b는 시작점이 달라서 클래스 집합 명제로 시험했다.

  * 쌍대값 1.5배·잡음·y 두 배: 하한이 떨어지고 여전히 유효하다.

## 6. 가까운 패킹 (§11–14, §22)

* **절약 형식**: `J = 119 − Σ_T s_T + Λ`, `s_T = |T|/6 − (k_T + 1)`, Λ = 연결 초과.
  * A/B/φ 번들 패킹의 최대 절약은 42이다(Round K, 전수). 따라서 그런 패킹은 J ≥ 77 + Λ이고, J ≤ 99에는 Λ ≤ 22가 필요하다.
  * 46185는 Σs = 37(F-단계 개방 6 + 합친 φ-trail 하나)이고 Λ = 18이다.
* **5A + 40φ**(A 하나를 φ-사이클 16개로 해체; A는 φ-집합 정확히 16개를 덮는다): Σs = 35이므로 J ≥ 84 + Λ이다.
  * trail 45개를 이어야 하고, (S4)에 따라 φφ 연결은 대부분 e ≥ 2이다. 더 나빠진다.
* **반-번들 / S4¹⁰ / 1218-trail**: Round L의 정확한 수리 하한이 그대로 적용된다.
  * S4¹⁰ 12-패킹은 여집합이 chain ≥ 240을 요구하므로 불가능하다.
  * 1218-trail은 E ≥ 12 + 48/7이다.
  * 이번 라운드에는 새 엄밀 판정을 더하지 않았다.
* **세계 선택(§14).** 판본 선택 GTSP와 두 세계 GTSP(클래스마다 세계 0/7 자유) LKH에서도 46185 아래로 내려가지 않았다(탐색이지 증명이 아님).
* **열 생성(§12)**: 가격 문제는 "일관된 개방 선택지로 이루어진 열린 trail" 하나이다. 단일 개방 LP가 바로 그 마스터의 한 형태이다(열 = 개방 선택지). 다중 개방 열로 넓히는 일은 하지 않았다.
* **더 나은 패킹에 필요한 정량 조건(§22).** 46185를 이기려면 Σ_T s_T − Λ ≥ 20이 필요하다(46185: 19). 즉 둘 중 하나이다.
  * A/B/φ 안에서는 절약 42를 거의 지키면서 연결 초과를 22 이하로 낮춰야 한다. 그런데 (S5)의 A 전이 ≥ 1과 (S4)의 φφ 비용이 이를 막는 주 원인이다.
  * 그 밖에서는 절약 밀도가 A(7/672)보다 높은 trail 묶음이 필요하다. 그 수리 단편화가 절약 증가분보다 작아야 한다.
