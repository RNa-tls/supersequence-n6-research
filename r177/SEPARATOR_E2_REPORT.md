**유용한 사실 (정의에서 바로 나옴).**
- 길이 ℓ ≥ 2인 row는 위치 0과 ℓ−1을 반드시 보므로 charge ≤ n−3입니다.
- 길이 1인 row의 charge는 정확히 n−2입니다.
- 따라서 **charge ≥ n−2 ⇔ 길이 1**이고, charge의 최댓값은 n−2입니다.

## 2. 정확한 진술

- **최대 full-row 구간**: trail에서 연속한 full row(길이 n−1, 생략 없음)들의 목록으로, 더 늘릴 수 없는 것.
- **이웃**: 구간 바로 앞 row x와 바로 뒤 row y. 최대성에 의해 둘 다 full이 아닙니다.
- **trail 조건**: 이웃과 구간 전체를 포함한 목록이 `ModelTrail`입니다. 즉 모든 row가 Admissible이고, 연속 쌍이 호환이고, 모든 쌍의 block이 다르고 visible 육각형 집합이 서로소입니다. 생략 위치와 틀은 R175/R176의 규약을 따릅니다.
- **E2 (제안된 진술):** n ≥ 6에서 x, y의 charge가 모두 ≥ 2이면 구간 ≤ n−4.
- **E2\* (정정된 정리):** n ≥ 5에서 x, y의 **길이가 모두 ≥ 2**(동치로 charge ≤ n−3)이면 구간 ≤ n−4. charge 하한은 필요 없습니다(charge 1 이웃도 포함).

## 3. 가상 반례의 해부와 아홉 경우

- Lemma E에 의해 구간 R은 ≤ n−3이므로, 남은 경우는 |R| = n−3뿐입니다.
- Lemma F와 relabelling에 의해 `R = p, φp, …, φ^{n−4}p`, `p = c₁…cₙ`로 둘 수 있습니다.
- 기호를 `C = c₁…c_{n−4}` (n ≥ 5에서 비어 있지 않음), `v = c_{n−3}`, `e = c_{n−2}`, `a = c_{n−1}`, `s = cₙ`로 둡니다.

**차지한 틈과 덮이지 않은 block.**
- R의 틀은 E = ⟨C v e⟩, 쌍 {a, s}, special s이고, 틈 `c₁, …, c_{n−3}`을 차지합니다. **빠진 틈은 e 하나**입니다.
- Lemma C에 의해 R은 `𝔉 ∖ B*`를 덮습니다. `B* = (⟨C v a e⟩, s)`는 빠진 틈의 block입니다.
- 따라서 이웃이 쓸 수 있는 𝔉의 육각형은 **B*의 n−1개뿐**입니다.

**경계 상태의 가능성 (정의에서 유도).**
- x의 마지막 상태는 `l = l₁l₂ C v lₙ`, `{l₁,l₂,lₙ} = {e,a,s}`입니다. 그 육각형 ⟨C v lₙ l₁ l₂⟩는 𝔉에 속하고(Lemma B2), 보이므로(B3) B*에 있어야 합니다.
  - 즉 `(lₙ,l₁,l₂)`에서 s를 지우면 (a, e)가 되어야 합니다.
  - 세 가지 경우: **X1** `= a e C v s`, **X2** `= s e C v a`, **X3** `= e s C v a`.
- y의 첫 상태 `e C t₁t₂t₃`(`{tᵢ} = {v,a,s}`)도 B*에 있어야 합니다. 즉 `(t₁,t₂,t₃)`에서 s를 지우면 (v, a)입니다.
  - 세 가지 경우: **Y1** `= e C v a s`, **Y2** `= e C v s a`, **Y3** `= e C s v a`.

**block과 강제 은닉 수 (Lemma U).**

| 경우 | 이웃 row의 block (W, special) | R의 row와 공통 육각형을 갖는 상태 수 | 따라서 |
|---|---|---|---|
| X1, Y1 | (⟨C v a e⟩, s) = **B\*** | 0 (special 같고 W 다름) | 제약 없음 |
| X2, Y2 | (⟨s e C v⟩, a) — **X2와 Y2는 같은 block** (⟨s e C v⟩ = ⟨e C v s⟩) | n−3 | charge ≥ n−3 |
| X3 | (⟨e s C v⟩, a) | n−2 | charge = n−2 (길이 1) |
| Y3 | (⟨e C s v⟩, a) | n−2 | charge = n−2 (길이 1) |

*은닉 수의 증명 (X2).*
- `W∖s = ⟨e C v⟩ = E`이므로 이웃은 R과 같은 틀에 있고, special은 반대(a), 틈은 e입니다.
- R의 각 row(틈 `g ≠ e`, special s)와는 Lemma U에 의해 공통 육각형이 **정확히 하나**입니다: `E + (e 앞에 s) + (g 앞에 a)`.
- full row는 이것을 보므로 이웃이 숨겨야 합니다. g마다 다른 육각형이므로 n−3개를 숨깁니다.

*은닉 수의 증명 (X3, Y3).*
- 이웃의 틈이 R의 틈 하나(c₁ 또는 v)와 **같습니다.**
- 그 row와는 공통 육각형이 두 개이고(Lemma U, 같은 틈), 나머지 n−4개 row와는 하나씩이므로 합계 n−2입니다.
- visible 상태가 1개만 남으므로 길이 1 row입니다.

**아홉 쌍.**

| 쌍 | 판정 | 이유 (모든 n ≥ 5) |
|---|---|---|
| (X1, Y1) | **불가능** | 두 이웃이 같은 block B* |
| (X2, Y2) | **불가능** | 같은 block ⟨s e C v⟩ = ⟨e C v s⟩, special a |
| (X1, Y2) | **불가능** (charge 무관) | x의 마지막 상태와 y의 첫 상태의 육각형이 같음: ⟨a e C v s⟩ = ⟨e C v s a⟩ = K₂. 둘 다 반드시 보임(B3) |
| (X2, Y1) | **불가능** (charge 무관) | 같은 이유로 ⟨s e C v a⟩ = ⟨e C v a s⟩ = K₁ |
| (X1, Y3) | y가 길이 1 | 실현됨 (§5 반례) |
| (X2, Y3) | x charge ≥ n−3, y 길이 1 | 실현됨 (탐색) |
| (X3, Y1), (X3, Y2), (X3, Y3) | x가 길이 1 | 실현됨 (탐색) |

모든 칸은 기호적으로 결정됩니다. `nine177.py`는 주장 (1)–(5)를 n = 5..14에서 두 검증기로 확인했습니다(`certs/nine_177.json`).

## 4. 정리 E2\* (증명)

**정리 E2\*.** n ≥ 5이고, 최대 full-row 구간의 두 이웃이 모두 길이 ≥ 2이면 구간은 ≤ n−4개입니다.

*증명.*
- |R| = n−3이라고 가정합니다.
- 길이 ≥ 2이므로 x ∉ X3, y ∉ Y3입니다(§3 표).
- 따라서 (x, y) ∈ {X1, X2} × {Y1, Y2}이고, 네 쌍 모두 불가능합니다(§3). ∎

- **등호 성립:** 구간 n−4가 (charge 2, charge 2) 이웃과 함께 실현됩니다(R176 `interior176`, n = 6..9, 예: charge 쌍 (2,2)).
- **제한판 비교:** "양쪽 이웃 charge 정확히 2"만의 판(R176의 E2(2,2))은 E2\*의 특수한 경우입니다. 증명이 더 쉬워지지는 않습니다. 같은 네 쌍 논증을 그대로 씁니다.

## 5. 반례 (제안된 E2는 거짓, 모든 n ≥ 5)

- **x**: start `C v a e s`, 길이 n−2(loop), 생략 {n−4} → charge 2
- **R**: `p, φp, …, φ^{n−4}p` (full row n−3개)
- **y**: start `e C s v a`, 길이 1 → charge n−2

*증명.*
1. **호환.**
   - x는 loop이므로 `β(x) = α(x.start) = C v = α(p)`.
   - `β(φ^{n−4}p) = e C = α(y.start)`.
2. **x는 B\*의 row입니다.**
   - x.start = F(B*의 전방 start `e C v a s`)입니다.
   - x의 위치 0..n−3은 B*의 위치 1..n−2에 해당하고, 생략한 n−4는 B*의 위치 n−3입니다.
   - x는 special s이고 W가 R과 다르므로 R과 서로소입니다(Lemma U).
3. **y.**
   - y는 Y3 경우이고, 하나뿐인 상태의 육각형 `⟨e C s v a⟩`는 B*의 위치 n−3입니다. 이 육각형은 R의 어느 block에도 속하지 않습니다(R의 row는 special s이고 `⟨e C s v a⟩∖s = W* ≠ W_r`).
   - x는 바로 그 위치를 숨깁니다. 따라서 x와 y는 서로소이고, block도 모두 다릅니다. ∎
- **결과:** 최대 full 구간 R의 길이는 n−3 > n−4이고, 양쪽 이웃 charge는 2와 n−2(≥ 2)입니다.
- **검증:**
  - A, B 모두 n = 5..14에서 통과했습니다.
  - 변형 7종은 모두 거부됐습니다: 생략 제거, 생략 이동, y 길이 2, y를 Y1·Y2로, x start 한 칸 이동, R을 n−2로 연장.
- 두 검증기 각각으로 **이웃 charge를 제한하지 않은 전수 탐색**을 했습니다(n = 5..8, `e2search177.py`).
  - 적법한 `x R y`는 n = 5, 6, 7, 8에서 13, 21, 37, 69개이고, A와 B의 결과가 완전히 같습니다.
  - **모든 경우에 한쪽 이웃이 길이 1**이고, 경우는 (X1,Y3), (X2,Y3), (X3,·)뿐입니다. §3의 예측과 정확히 같습니다.
- R176이 본 "n = 5 예외"(charge 3 이웃)는 n = 5에 특유한 현상이 아닙니다. 모든 n에 나타나는 **길이 1 이웃** 현상의 n = 5 사례입니다(3 = n−2).

## 6. 두 함의의 감사

- **R176 "n ≥ 9: E2 ⇒ C1".** 함의 자체는 옳습니다. 그러나 전제 E2가 거짓이므로 결론을 얻는 데 쓸 수 없습니다.
- **R176 "n ≥ 11: E2(2,2) ⇒ C1".** 옳습니다.
  - 길이 1 분리자의 charge n−2가 주는 여유는 `(n−3)(n−4)/2`입니다.
  - 그 밖의 charge ≥ 3 분리자도 `(n−3)(c−2)/2`의 여유가 있어 이웃의 부족분을 메웁니다.
- 이번 라운드는 E2\*에 새 보조정리 E1, K를 더해 이것을 **n ≥ 6**으로 개선합니다(§7).

## 7. C1의 증명 (모든 n ≥ 6, 모든 g)

**보조정리 E1.** 최대 charge ≤ 1 구간 U에 charge-1 row가 정확히 하나이면 |U| ≤ n−2입니다.
- *증명.* R175 보조정리 3, 5에 의해 U는 `L^{c₀} (long)^k L^{c₁}` 꼴입니다.
  - charge-1 row가 loop z이면, 그것은 끝에 있고 나머지는 full 구간 R입니다. R은 z와 이웃하므로 Lemma E에 의해 |R| ≤ n−3, 따라서 |U| ≤ n−2입니다.
  - 표시된 long row이면 U는 long 블록 하나이므로 ≤ n−2입니다(R175 보조정리 5). ∎

**보조정리 K.** n ≥ 5에서, n−2개(모든 틈)의 long row로 된 블록에 표시가 정확히 하나이면, 그 블록은 양쪽 모두에 이웃을 가질 수 없습니다. 이웃의 charge와 무관합니다.
- *증명.*
  1. **special은 모두 같습니다.**
     - special이 다른 두 비표시 row는 틈이 다르므로 공통 육각형 하나를 둘 다 봅니다(Lemma U). 따라서 special이 다른 쌍에는 반드시 표시 row M이 들어 있습니다.
     - 그러면 M만 special이 다르고, M은 나머지 n−3개 row와의 공통 육각형(M의 서로 다른 위치 `d(g_M, g_r)`)을 모두 숨겨야 합니다.
     - M이 숨길 수 있는 것은 하나뿐이므로 n−3 ≤ 1, 즉 n ≤ 4가 되어 모순입니다.
  2. 따라서 블록은 𝔉 중 M이 숨긴 육각형 h₀ 하나만 빼고 모두 덮습니다.
  3. 앞 이웃의 마지막 상태와 뒤 이웃의 첫 상태는 모두 𝔉에 속하고(Lemma B, start만 쓰는 일반형) 보이므로(B3), 둘 다 h₀여야 합니다. 그러면 두 이웃이 충돌합니다. ∎

**정리 (C1).** n ≥ 6이면, 모든 g에 대해 marked-row 모형에서 `M_n(g) ≤ (n−2) + (n−3)g/2`입니다. 정수로는 `⌊(n−2) + (n−3)g/2⌋`.

*증명.* charge ≤ g인 trail을 잡습니다. 표기는 다음과 같습니다.
- 분리자: charge ≥ 2인 row h개(charge c_σ).
- 최대 charge ≤ 1 구간: `U₀, …, U_h` (빈 구간 허용). `c_U`는 U의 charge입니다.
- `s_U`: U에 이웃한 분리자 수. `Σ s_U = 2h`입니다.

**h = 0인 경우.**
- c = 0이면 ≤ n−2 (R174 2(e)).
- c = 1이면 ≤ n−2 (E1).
- c ≥ 2이면 ≤ n−1 (R175 정리 B) ≤ C1.

**h ≥ 1인 경우.**
- `ℓ_U := (n−2) − |U| + ((n−3)/2)c_U`로 정의합니다.
- row 수 = `Σ|U| + h`이므로, 대수 계산에 의해 C1은 다음과 **동치**입니다.
  - `Σ_U ℓ_U ≥ Σ_σ d(c_σ)`, 여기서 `d(c) := (n−1) − (n−3)c/2`.
  - `2 − d(c) = (n−3)(c−2)/2 ≥ 0`입니다.

**구간별 하한 (n ≥ 6).**

| 구간 | ℓ_U 하한 | 근거 | 부족분(s_U 대비) |
|---|---|---|---|
| 빈 구간 | n−2 ≥ 2 | 정의 | 없음 |
| c=0, s=1 (양 끝 구간) | ≥ 1 | Lemma E | 없음 |
| c=0, s=2, 두 이웃 모두 길이 ≥ 2 | ≥ 2 | **E2\*** | 없음 |
| c=0, s=2, 이웃 중 길이 1 있음 | ≥ 1 | Lemma E | ≤ 1 → 길이 1 이웃에 부과 |
| c=1 | ≥ (n−3)/2 | **E1** | n ≥ 7이면 없음 |
| c=1, s=2, n = 6 | loop 경우: R 쪽 이웃 길이 ≥ 2이면 \|U\| ≤ n−3 (E2\*), 아니면 부족분 ≤ 1/2를 그 길이 1 이웃에 부과. 표시 경우: 완전 블록은 **K**에 의해 불가능하므로 \|U\| ≤ n−3 | E1, E2\*, K | 위와 같음 |
| c ≥ 2 | ≥ (n−3)c/2 − 1 ≥ n−4 ≥ 2 | 정리 B | 없음 |

**합산.**
- 부족분은 **길이 1 분리자에만** 부과됩니다. 각 분리자는 양쪽에서 최대 1씩, 합계 ≤ 2를 받습니다.
- 길이 1 분리자의 charge는 n−2이므로 여유 `2 − d = (n−3)(n−4)/2 ≥ 3`입니다(n ≥ 6).
- 따라서 `Σℓ_U ≥ 2h − D ≥ 2h − Σ_σ (2 − d(c_σ)) = Σ_σ d(c_σ)`입니다. 여기서 D는 부족분의 합입니다.
- 각 이웃 관계(구간–분리자 한 쪽)는 한 번씩만 셉니다. 한 분리자의 왼쪽과 오른쪽 구간은 서로 다른 구간이므로 이중 계산이 없습니다.
- 등식 변환은 유리수 산술이므로 g의 홀짝과 무관합니다. 실제 charge가 예산보다 작아도 우변이 g에 대해 증가하므로 성립합니다. ∎

**대조 (증명의 단계로 쓰지 않음).**
- 외부 Lean 인증 `capTab` (n = 7, g ≤ 36): 모든 g에서 C1 = 5 + 2g 이하이고, g = 0, 2, 4에서 등호입니다.
- R176 marked 값(n = 5..8, g ≤ 2~3): 모두 C1 이하입니다.
- 등호 사례: `M_n(2) = 2n−5 = C1(2)`.

## 8. 작은 n

- **n = 5.**
  - E2\*는 성립합니다(구간 ≤ 1).
  - C1(`M_5(g) ≤ 3 + g`)은 **미증명**입니다. 길이 1 분리자의 여유가 1뿐이라, c_U ∈ {1,2}, s = 2인 구간의 부족분을 charge 2 분리자가 메우지 못합니다.
  - 수치 대조(반증 목적, 증명 아님): marked `M_5(g)` = 3, 3, 5, 5, 6, 6, 7 (g = 0..6)는 모두 3 + g 이하입니다(`certs/capA_larger_g.log`).
- **n = 6, 7, 8.** 위의 일반 증명에 포함됩니다. n = 6은 보조정리 K가 필요한 유일한 경우입니다.
  - n = 7은 외부 인증 표(g ≤ 36)와 일치합니다.
  - n = 6, 8에는 인증된 표가 없고, 증명이 표에 의존하지도 않습니다.
  - 반증 목적의 수치 대조: marked `M_6(g)` = 4, 4, 7, 7, 10, 10 (g = 0..5)는 C1 = 4, 5.5, 7, 8.5, 10, 11.5 이하이고, g = 0, 2, 4에서 등호입니다.

## 9. 보편 superpermutation 하한까지 남은 가정

- 무조건 일반 하한은 여전히 **Liu**입니다.

## 10. 다음 수학적 의무

**Bridge(n)을 일반 n의 정리로 증명하는 것**입니다. 즉 외부 `CoarsenBridge.lean`의 n = 7 reduction을 n에 대한 명제로 바꾸는 일입니다.
- 결론은 다음과 같습니다: defect D인 정규화 route마다 `(m, a, b, η, r)`가 존재하고, `a ≤ r ≤ (n−1)m`이며, 다음 조건의 `CoarsenedInstance`가 존재한다.
  - row 수 `ORB + m − r + a`
  - trail 수 ≤ `η + 1 + b`
  - 총 charge ≤ `(n−1)m − r`
- R174는 이 reduction이 상수 치환만으로 n = 6에서 n = 7로 옮겨졌음을 확인했습니다.
- 이것이 증명되면 capacity 쪽(C1, 모든 n ≥ 6)은 이미 증명되어 있으므로, Liu를 넘는 무조건 일반 하한이 나옵니다.
