## 1. 다중 개방 길이 항등식 (항목 1)

### 1.1 정의

* 각 trail T에 판본 v_T 하나를 고르고, 그 판본 순환에서 절단 위치 집합 C_T ≠ ∅를 고른다.
  * 조각은 이웃한 두 절단 사이의 구간이다.
  * T의 조각 수는 k_T = |C_T|이고, 전체 조각 수는 P = Σ k_T이다.
* 경로(route)는 P개 조각의 일렬 배열이다. 같은 trail의 조각이 이웃해도 된다.
* **경계 b**는 이웃한 두 조각 사이이다.
  * 앞 조각의 진출 run을 x, 뒤 조각의 진입 run을 y라 하면 결합 가중치는 w_b = w(last(x), y)이다.
* **절단 선택지**: 절단 위치 a는 단일 개방 선택지 T(a)와 같다. 진입은 run a, 진출은 run a−1, cut은 c(a)이다.
  * 조각 [a, b)의 진입 선택지는 T(a), 진출 선택지는 T(b)이다.
* 방문 안의 경계를 **도약**이라 한다(같은 trail). 방문 사이의 경계는 다른 trail 사이 경계이다.
* 계측된 사실:
  * 서로 다른 trail 사이의 e는 모두 ≥ 0이다. 따라서 w ≥ 3이고, 사슬 시작으로 들어가면 w ≥ 4이다.
  * 판본 두 개의 내부 결합 가중치 합은 trail마다 같다. 전체 합은 10848이다(`family_struct.json`).

### 1.2 항등식

**정리 Q1 (다중 개방 항등식).** 모든 다중 개방 경로에 대해 다음이 성립한다.

* (I1) L = 35288 + 10848 − Σ_{절단} c + Σ_{경계} w
  * 35288 = 8 + 7·5040이다.
  * 절단마다 판본 결합 하나가 빠지고, 경계마다 결합 하나가 더해진다.
* (I2) J = L − 46085 = 48 + [c₁ = 2] + Σ_b (w_b − c_{b+1})
  * 같은 값의 다른 표현: 48 + #(c = 2) + Σ_b (w_b − 3).
* (I2′) 선택지 초과량 e_b = w_b − c_{b+1} − 1로 쓰면 다음과 같다.
  * J = 48 + (P − 1) + [c₁ = 2] + Σ_b e_b
  * G = J − 77 = (P − 30) + [c₁ = 2] + Σ_b e_b
* (I3) **방문 형식.** G = (V − 30) + [c₁ = 2] + Σ_{trail 사이 경계} e + Σ_{도약} E′
* (I4) **사슬 형식.** q를 w2 선분 수라 하면 J = 48 + (q − 768) + Σ_{w2가 아닌 결합} (w − 3)이다.
  * 768은 30개 판본 순환의 사슬 수 합 24·6 + 6·104이다.
* (I5) **단일 방문 형식.** trail 하나(판본 고정, run m개)를 한 번에 도는 방문을 run 경로로 보면 κ = [mid(진입)] + Σ_도약 E′ = W(경로) − Σ_k c_k + 3이다.
  * W는 m − 1개 결합 가중치의 합이다. 자연 결합은 E′ = 0이다.
* 증명.
  * (I1)은 단어 길이 공식이다. 첫 run은 15글자, 이후 run은 결합 w + 7글자를 더한다.
  * (I2)–(I5)는 (I1)의 대수적 재배열이다. Lean `J_identity`, `J_c2form`.
* 수치 검사.
  * 무작위 다중 개방 30개(조각 46–76개, 가상 순환 3–8개)에서 (I1)–(I3)가 실제 단어 길이와 모두 일치했다(`identity_check.json`).
  * 새 46183 단어에서도 일치한다: P = 31, [c₁ = 2] + Σe = 20, G = 1 + 20 = 21.

### 1.3 가상 덮개, 괄호, 실현 가능성

* 절단 선택지를 꼭짓점으로, 경계(진출 선택지 o → 진입 선택지 o′)를 비용 e(o → o′)의 변으로 둔다.
* 꼭짓점마다 들어오는 변과 나가는 변이 각각 ≤ 1개이다. 그래서 덮개는 **경로 하나와 서로소인 순환들**로 갈라진다.
* **정리 Q2 (순환 수).**
  * 경로가 실현되려면 π̂∘σ가 P-순환 하나여야 한다.
    * π̂: 경로를 닫은 덮개 순열.
    * σ: 각 trail 절단의 순환 후속.
  * σ는 호환 P − 30개의 곱이고, 호환 하나는 순환 수를 1만큼 바꾼다. 그래서 순환 수 c는 c ≤ P − 30이고 c ≡ P − 30 (mod 2)이다.
  * 각 순환에는 조각이 ≥ 2개인 trail의 꼭짓점이 있고, 그 trail의 꼭짓점은 순환 밖에도 있다.
* **괄호 그림.** trail S를 두 조각 [a, b), [b, a)로 나누면, 단어에서 두 조각 사이에 놓인 구간 Z′가 덮개의 순환 Z = (S(b), Z′)가 된다.
  * 서로 겹치지 않거나 포개진 괄호는 순환이 된다.
  * 엇갈린 괄호는 경로를 다시 잇는다(c = 0).
  * 괄호 전체는 바깥에서 보면 선택지 S(a)처럼 행동한다. 진입은 run a, 진출은 run a−1이다.
* **run 수준 동치.** 판본 벡터를 고정하면 다중 개방 단어는 5040개 run의 해밀턴 경로 전체와 같다.
  * 그러므로 다중 개방 전체는 판본 일관 run 수준 ATSP 2³⁰개의 합집합이다.

### 2.2 방문 보조정리와 전하 정리

**보조정리 Q3.** 한 방문의 조각을 f₁, …, f_s라 하자. mid(f)는 조각 f가 사슬 내부에서 시작한다는 뜻이다. 그러면

    κ(v) := [mid(f₁)] + Σ_{도약} E′  ≥  [mid(f_s)]  ≥  0,      Σ_{도약} E′ ≥ −1.

* 증명: mid 조각으로 들어가는 도약은 w ≥ 3이다(w = 2는 자연 재결합).
* 사슬 시작으로 들어가는 도약은 w ≥ 2이고, w = 2(감싸기)는 바로 앞 조각이 같은 사슬 내부에서 시작할 때만 가능하다.
* 따라서 도약 항 ≥ [mid(f_i)] − [mid(f_{i−1})]이고, 합은 망원급수가 된다(Lean `visit_kappa_ge_last` 등).

**정리 Q5 (전하).** χ(v₁) = κ(v₁), χ(v) = e_in(v) + 1 + Σ_{v의 도약} E′ (v ≥ 2)로 두면 다음이 성립한다.

    G = Σ_v χ(v) − 29,   χ(v) ≥ 0.

* χ(v) = 0(v ≥ 2)은 **회전형 방문**뿐이다. 조건은 다음과 같다.
  * e_in = 0이다.
  * mid 조각으로 시작한다.
  * 첫 도약이 감싸기이다.
  * 나머지 도약은 E′ = 0이다.
* 새 46183 단어는 회전형 방문을 쓰지 않는다. 방문 31개 모두 χ ≥ 1이고, 이득은 e들이 줄어든 데서 나온다(§6.1).

## 3. A 분할 상태의 완전 분류 (항목 3)

* **조각 상태.** A trail의 조각은 판본 순환의 임의 구간 [a, b)이다.
  * 상태는 (진입 선택지 T(a), 진출 선택지 T(b))로 완전히 정해진다. 내부 비용은 0이다.
  * 판본마다 672²가지이다.
  * 새 46183 단어가 실제로 쓰는 A 분할 상태: trail 22 판본 0의 (T(213), T(16))과 (T(16), T(213))이다. 길이는 475 run과 197 run이다.
* **도약의 완전 목록**(판본마다 672 × 672 쌍 전수, `same_trail_jumps.json`, `a_structure.json`).

## 9. 일반 분할 전하 정리 (항목 9)

**정리 Q5.** 이 가족의 모든 다중 개방 단어에 대해 다음이 성립한다.

    J = 77 + G,    G = Σ_{방문 v} χ(v) − 29,
    χ(v₁) = κ(v₁) ≥ [mid(마지막 조각)] ≥ 0,
    χ(v) = e_in(v) + 1 + Σ_{도약} E′ ≥ e_in(v) ≥ 0   (v ≥ 2).

* 덮개 형식: G = (P − 30) + [c₁ = 2] + Σ_{덮개 변} e. 변의 e는 trail 사이에서 ≥ 0, 감싸기 −2, 사슬 시작 w3 도약 −1이다.

  * 조각 2개 분할(괄호 하나): G = 1 + F_J + β. 새 기록은 1 + 18 + 2 꼴이 아니라 1 + 19 + 1이다(경로 19, 순환 1).

### 11.1 오류와 정정

3. **패턴 해석 오류.**
   * 탐색(`ckT_search.c`)은 φ 토큰을 trail id(0–27)로 쓴다.
   * 그런데 평가기 세 개(`split_eval.c`, `excise_eval.c`, `skip_eval.c`)는 이것을 φ 목록의 첨자로 읽어 한 번 더 바꿨다.

   * 고친 것:
     * 토큰을 trail id로 읽는다.
     * 펼친 수열마다 30 trail의 순열인지 검사하고, 아니면 멈춘다.
     * 탐색이 실제로 쓴 패턴으로 종단 시험을 한다(G = 23 증인 → G = 23, G = 26 절제 → G = 26).
   * 새 기록은 고친 평가기로 찾았고, 찾은 코드와 독립인 재구성과 검사기로 확인했다.
4. (Round Q 초기) `order_excise.c`의 회전 사슬 첨자 오류. 독립 재구성으로 잡았다.

  * 새 단어 자체는 검사기 5개와 독립 재구성으로 확인했다.
