## 1. 다중 개방 길이 항등식 (항목 1)

### 1.1 정의

* 각 trail T에 판본 v_T 하나를 고르고, 그 판본 순환에서 절단 위치 집합 C_T ≠ ∅를 고른다.
  * 조각은 이웃한 두 절단 사이의 구간이다.
  * T의 조각 수는 k_T = |C_T|이고, 전체 조각 수는 P = Σ k_T이다.
* 경로(route)는 P개 조각의 일렬 배열이다. 같은 trail의 조각이 이웃해도 된다.
* **경계 b**는 이웃한 두 조각 사이이다.
  * 앞 조각의 진출 run을 x, 뒤 조각의 진입 run을 y라 하면 결합 가중치는 w_b = w(last(x), y)이다.
* **절단 선택지**: 절단 위치 a는 단일 개방 선택지 T(a)와 같다. 진입은 run a, 진출은 run a−1, cut은 c(a)이다.
  * 조각 [a, b)의 진입 선택지는 T(a), 진출 선택지는 T(b)이다.
* **방문(visit)**: 같은 trail 조각이 연속한 최대 묶음이다.
  * 방문 안의 경계를 **도약(jump)**이라 한다(같은 trail).
  * 방문 사이의 경계는 다른 trail 사이 경계이다.
* 계측된 사실:
  * 서로 다른 trail 사이의 e는 모두 ≥ 0이다. 따라서 w ≥ 3이고, 사슬 시작으로 들어가면 w ≥ 4이다.
  * 판본 두 개의 내부 결합 가중치 합은 trail마다 같다. 전체 합은 10848이다(`family_struct.json`).

### 1.2 항등식

**정리 Q1 (다중 개방 항등식).** 모든 다중 개방 경로에 대해 다음이 성립한다.

* (I1) L = 35288 + 10848 − Σ_{절단} c + Σ_{경계} w
  * 35288 = 8 + 7·5040이다.
  * 절단마다 판본 결합 하나가 빠지고, 경계마다 결합 하나가 더해진다.
* (I2) J = L − 46085 = 48 + [c₁ = 2] + Σ_b (w_b − c_{b+1})
  * 같은 값의 다른 표현: 48 + #(c = 2) + Σ_b (w_b − 3).
* (I2′) 선택지 초과량 e_b = w_b − c_{b+1} − 1로 쓰면 다음과 같다.
  * J = 48 + (P − 1) + [c₁ = 2] + Σ_b e_b
  * G = J − 77 = (P − 30) + [c₁ = 2] + Σ_b e_b
  * 단일 개방(P = 30)이면 G = F이다.
* (I3) **방문 형식.** V를 방문 수, E′ = w − c(머리)라 하면 다음과 같다.
  * G = (V − 30) + [c₁ = 2] + Σ_{trail 사이 경계} e + Σ_{도약} E′
* (I4) **사슬 형식.** q를 w2 선분 수라 하면 다음과 같다.
  * J = 48 + (q − 768) + Σ_{w2가 아닌 결합} (w − 3)
  * 768은 30개 판본 순환의 사슬 수 합 24·6 + 6·104이다.
* 증명.
  * (I1)은 단어 길이 공식이다. 첫 run은 15글자, 이후 run은 결합 w + 7글자를 더한다.
  * (I2)–(I4)는 (I1)의 대수적 재배열이다. Lean `J_identity`, `J_c2form`.
* 수치 검사(`identity_check.json`). 무작위 다중 개방 30개(조각 46–76개, 가상 순환 3–8개)에서 (I1)–(I3)가 실제 단어 길이와 모두 일치했다.

### 1.3 가상 덮개와 실현 가능성

* 절단 선택지를 꼭짓점으로 둔다.
* 경계 (진출 선택지 o → 진입 선택지 o′)를 변으로 둔다. 그 비용이 e(o → o′)이다.
* 모든 꼭짓점은 들어오는 변과 나가는 변이 각각 ≤ 1개이다. 따라서 덮개는 **경로 하나와 서로소인 순환들**로 갈라진다.
* **정리 Q2 (순환 수).**
  * 덮개의 순환 수는 P − 30 이하이다.
  * 각 순환에는 조각이 ≥ 2개인 trail의 꼭짓점이 있고, 그 trail의 꼭짓점은 순환 밖에도 있다.
* 증명.
  * 경로가 실현되려면 π̂∘σ가 P-순환 하나여야 한다.
    * π̂: 경로를 닫은 덮개 순열.
    * σ: 각 trail 절단의 순환 후속.
  * σ는 호환(transposition) P − 30개의 곱이다. 호환 하나를 곱하면 순환 수는 1만큼 변한다.
  * 그러므로 (1 + #순환) − (P − 30) ≤ 1이다.
  * 연결성이 필요하므로 둘째 명제가 나온다.
* **엇갈린 다리(Round P §27의 일반화).**
  * 같은 trail 조각 사이에 도약이 없으면, k조각 trail의 기여는 Σ_i B_T(y_i → x_{i−1}; a_i) + (k − 1)이다.
  * 절단 선택지 T(a_i)는 조각 i 앞 간격의 진출 y_i에서 들어와, 조각 i−1 뒤 간격의 진입 x_{i−1}로 나간다.
  * k = 2이면 Round P의 "엇갈린 두 다리 + 1"이다.
* **run 수준 동치.** 판본 벡터를 고정하면 다중 개방 단어는 5040개 run의 해밀턴 경로 전체와 같다.
  * 시작점은 그 판본 벡터가 정한다(Round M의 run 수준 모형).
  * 어떤 해밀턴 경로든 판본 순환에서 연속한 최대 구간으로 자르면 조각들이 된다.
  * 그러므로 "다중 개방 전체"는 판본 일관 run 수준 ATSP 2³⁰개의 합집합이다.
  * Round M의 HK 하한이 J ≥ 65(판본 0 시작점)에 머문 바로 그 모형이다.

## 2. 분할 벌점·이득 정리 (항목 2)

### 2.1 벌점과 이득의 정확한 장부

(I3)에서 G의 각 항은 다음과 같이 매겨진다.

| 항 | 값 | 비고 |
|---|---|---|
| 추가 방문 1개 | **+1** | V − 30 |
| trail 사이 경계 | e ≥ 0 | 계측 |
| 도약: w2 감싸기 C_end → C_start (사슬 시작으로) | **E′ = −1** | 판본마다 φ 6개, A 76개 |
| 도약: 사슬 시작으로 가는 w3(감싸기 아님, 비자연) | E′ = 0 | φ 6개, A 80 + 8(대체 연결)개 |
| 도약: 자연 재결합 b−1 → b | E′ = 0 | 절단이 없는 것과 같다 |
| 그 밖의 모든 도약 | E′ ≥ 1 | 판본마다 672²개 쌍 전수 |

### 2.2 방문 보조정리 (감싸기 보상)

**보조정리 Q3.** 한 방문의 조각을 f₁, …, f_s라 하자. mid(f)는 조각 f가 사슬 내부에서 시작한다는 뜻이다(c = 2). 그러면

    κ(v) := [mid(f₁)] + Σ_{도약} E′  ≥  [mid(f_s)]  ≥  0,      Σ_{도약} E′ ≥ −1.

* 증명: mid 조각으로 들어가는 도약은 w ≥ 3이다(w = 2는 자연 재결합).
* 사슬 시작으로 들어가는 도약은 w ≥ 2이고, w = 2(감싸기)는 바로 앞 조각이 같은 사슬 내부에서 시작할 때만 가능하다.
* 따라서 도약 항 ≥ [mid(f_i)] − [mid(f_{i−1})]이고, 합은 망원급수가 된다.
* Lean `visit_kappa_ge_last`, `visit_kappa_nonneg`, `visit_jumps_ge_neg_one`.

**따름정리 Q4 (방문 전하).** 방문마다 전하 χ를 다음과 같이 정한다.

* 첫 방문: χ(v₁) = κ(v₁)
* 나머지 방문: χ(v) = e_in(v) + 1 + Σ_{v의 도약} E′

그러면

    G = Σ_v χ(v) − 29,   χ(v) ≥ 0,

이다. 첫 방문이 아닌 v에서 χ(v) = 0이 되는 것은 다음 조건이 모두 성립할 때뿐이다.

* e_in(v) = 0
* v가 mid 조각으로 시작한다.
* 첫 도약이 감싸기이다.
* 나머지 도약의 E′가 모두 0이다.

이런 방문을 **회전형 방문**이라 부른다. 단일 개방에서는 모든 방문이 χ = e + 1 ≥ 1이다.

### 2.3 등호: 회전 사슬 절제 (벌점 0인 분할)

* 구성: trail T의 한 판본에서 완전 사슬 C(7 run, w2 감싸기)와 C 내부 run a₁을 고른다.
  * V1 = a₁ … C_end, C_start … a₁−1. 감싸기 1회. 진입 a₁, 진출 a₁−1이므로 선택지 T(a₁)과 같은 비용이다.
  * R = T − C. 판본 순서의 조각 하나로, 진입 선택지는 T(N_start), 진출 선택지는 T(C_start)이다.
* 장부: 추가 방문 +1, 감싸기 −1. 따라서 **순 벌점 0**이다.
  * G의 변화는 정확히 R을 끼운 간격의 삽입 비용 e(p → T(N_start)) + e(T(C_start) → n) − e(p → n)이다(Lean `zero_penalty_rotation`).
* **실제 단어로 확인.**
  * 단어 a에서 A trail 8의 첫 완전 사슬을 회전해 제자리에 두고, 나머지 665 run을 간격 5에 옮겼다.
  * 결과 단어의 길이는 **46184**이고, 다중 개방이다. 40320개 순열이 모두 나타난다(`minicheck.py`, `rQ/records/multiopen_46184_excision_A8.txt`).
  * 단어 a의 절제 이웃 8400개 중 Δ = 0인 것은 95개이고, Δ < 0인 것은 없다.
* 따라서 **"추가 절단마다 벌점 ≥ 1"이라는 정리는 거짓**이다.
  * 이 가족의 다중 개방에는 등호 분할이 대량으로 있다.
  * 46184 단어는 단일 개방 해 24개 순서 말고도 많다.
* Round P의 "split A = 엇갈린 다리 + 1"은 **조각 2개 분할**에서는 맞다.
  * 조각이 2개이면 도약이 생길 수 없다. 두 조각이 이웃하면 자연 재결합이 되기 때문이다.
  * 조각이 3개 이상이면 감싸기가 그 +1을 되돌려 줄 수 있다.

## 3. A 분할 상태의 완전 분류 (항목 3)

* **조각 상태.** A trail의 조각은 판본 순환의 임의 구간 [a, b)이다.
  * 상태는 (진입 선택지 T(a), 진출 선택지 T(b))로 완전히 정해진다. 내부 비용은 0이다(판본 결합만 쓴다).
  * 판본마다 672² 가지이다. 이 집합은 줄일 수 없다: 각 (a, b)마다 그것만 쓰는 엇갈린 다리가 있다.
* **도약의 완전 목록.**
  * 판본마다 672 × 672 run 쌍을 전수했다(`same_trail_jumps.json`, `a_structure.json`). 12개 A 판본이 모두 같은 통계이다.
  * E′ ≤ 0인 도약은 다음뿐이다.
    * 감싸기 76개(E′ = −1). 76개 완전 사슬마다 하나이다.
    * 사슬 시작으로 가는 w3 도약 88개(E′ = 0).
      * 비사슬끝 run → 사슬 시작: 80개
      * 사슬 끝 → 다른 사슬 시작, 곧 대체 연결(gadget 자리): 8개
    * 자연 재결합.
  * 나머지 모든 도약은 E′ ≥ 1이다.
  * 짧은 사슬(20×5, 4×4, 4×6)에는 감싸기가 없다(완전 사슬이 아니다).
* **파레토 관련 방문 유형(A).** 보조정리 Q3과 위 목록에서 κ ≤ 0인 다조각 방문은 다음 꼴의 조합뿐이다.
  1. 완전 사슬 회전: [a₁, C_end] + 감싸기 + [C_start, a₁−1]. κ = 0이고, 진입·진출 모두 T(a₁)이다.
  2. w3 사슬 시작 도약으로 구간 하나를 건너뛰기. κ = 0이고, 건너뛴 구간은 따로 방문해야 한다.
  3. 대체 연결 8개로 사슬 순서를 바꾸기. κ = 0이다.
* **단일 방문 재경로(A)의 지배 여부.**
  * trail 1 판본 0에서 모든 (진입 y, 진출 x) 쌍의 slack을 계산했다(`dominance.c`). 이웃 진입 프로필 802개, 진출 프로필 794개이다.
  * slack 분포는 0..6이다(0: 3040쌍, 1: 11448, …, 6: 59432).
  * 일반 지배를 증명하려면 slack ≥ 1인 쌍마다 κ_A(y, x) ≥ slack을 보여야 한다.
    * 672 run의 정확 κ 목록은 계산 비용 때문에 만들지 못했다(`visit_A.c`는 KMAX ≥ 3에서 너무 느리다).
    * 그래서 **일반 A 재경로는 미결**이다.
  * **회전형 재경로는 모두 지배된다**(정리, 계산).
    * 유형 1의 회전 사슬 하나에 나머지를 붙여 trail 전체를 한 번에 도는 두 형태를 보았다.
    * C 다음 사슬 시작으로 가는 w3 도약이 그 자리에 없어서 κ = 1..5이다.
    * 12 판본 × 912개를 `dominance.c`(두 판본 경쟁자)로 점검했다. 지배되지 않는 것은 0개이다(`rotation_reroute_kappa.py`, `dominance_single_visits.json`).
  * 회전 사슬이 **별도 방문**이 되는 경우(§2.3)는 재경로가 아니라 분할이다. §6의 절제 정리로 다룬다.

## 4. φ 분할 정리 (항목 4)

### 6.2 조각 2개 분할(trail 하나, 정확히 두 조각): 전역으로 닫음

**재정식화(정리 Q6).** 분할 trail S의 두 꼭짓점 S(a) ∈ P, S(b) ∈ Z를 생각한다.

* 덮개는 경로 P와 순환 Z 하나이다(정리 Q2).
* Z에서 S(b)를 지우고 Z − S(b)를 P 뒤에 붙이면, trail 30개가 정확히 한 번씩 나오는 수열 Σ가 된다.
  * P의 끝과 Z − S(b)의 첫 원소 사이를 **이음매**(junction)라 한다. 이음매에는 변이 없다.
* 그러면

      G = 1 + F_J + β,   F_J = [c(Σ₁) = 2] + Σ_{이음매를 뺀 Σ의 변} e,   β = e(Σ_끝 → S(b)) + e(S(b) → 이음매 다음) ≥ 0

  이고, 이 대응은 전단사이다(S ∈ P, b ≠ a, 같은 판본). Lean `single_split_decomposition`.
* 따라서 G ≤ 21이려면 F_J ≤ 20이어야 한다.

**계산.**

* HT(S, t, c): 이음매가 아직 없는 상태에서 "이음매를 포함하는 나머지"의 완화(A 정체성 자유) 최소이다.
  * ckB의 H에 JUMP 항을 더한 역방향 DP이다(`ckT.c`).
  * JUMP = 끝 사슬 a₁ + 자유 시작 경로 표 PLf[남은 φ][c − a₁].
  * 완화 근 값은 **16**이다(이음매가 시작 사슬 안이면 20). 곧 G ≥ 17은 완화만으로 나온다.
* 신원 인지 전진 탐색(`ckT_search.c`): 상태는 (S, t, M, J)이다.
  * J = 0이면 HT, J = 1이면 H로 가지친다.
  * 이음매 전이는 끝 사슬 D1(정확) + 자유 시작 사슬 D2(정확)이고, 대기 상태(S, M′)를 거친다.

## 9. 일반 분할 전하 정리 (항목 9)

**정리 Q5.** 이 가족의 모든 다중 개방 단어에 대해 다음이 성립한다.

    J = 77 + G,    G = Σ_{방문 v} χ(v) − 29,
    χ(v₁) = κ(v₁) ≥ [mid(마지막 조각)] ≥ 0,
    χ(v) = e_in(v) + 1 + Σ_{도약} E′ ≥ e_in(v) ≥ 0   (v ≥ 2).

* χ(v) ≥ 1이 깨지는 것은 회전형 방문뿐이다. 이때 감싸기 1회가 추가 방문 벌점 1을 상쇄한다.
* 덮개 형식으로도 같다: G = (P − 30) + [c_s = 2] + Σ_{덮개 변} e. 변의 e는 trail 사이에서 ≥ 0, 감싸기 −2, 사슬 시작 w3 도약 −1이다.
* 특수한 경우:
  * 단일 개방: χ = e + 1, G = F.
  * 조각 2개 분할: G = 1 + 경로 비용 + 순환 비용(엇갈린 다리).
  * 회전 사슬 절제: G = G(제자리 선택지 T(a₁)) + R의 삽입 비용.
* Lean: §1–4의 대수와 Q3을 형식화했다. 계측 사실(e ≥ 0, 도약 목록)은 표로 남긴다.
