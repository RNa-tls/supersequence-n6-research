## 1. 다중 개방 길이 항등식 (항목 1)

### 1.1 정의

* 각 trail T에 판본 v_T 하나를 고르고, 그 판본 순환에서 절단 위치 집합 C_T ≠ ∅를 고른다.
  * 조각은 이웃한 두 절단 사이의 구간이다.
  * T의 조각 수는 k_T = |C_T|이고, 전체 조각 수는 P = Σ k_T이다.
* 경로(route)는 P개 조각의 일렬 배열이다. 같은 trail의 조각이 이웃해도 된다.
* **경계 b**는 이웃한 두 조각 사이이다.
  * 앞 조각의 진출 run을 x, 뒤 조각의 진입 run을 y라 하면 결합 가중치는 w_b = w(last(x), y)이다.
* **절단 선택지**: 절단 위치 a는 단일 개방 선택지 T(a)와 같다. 진입은 run a, 진출은 run a−1, cut은 c(a)이다.
  * 조각 [a, b)의 진입 선택지는 T(a), 진출 선택지는 T(b)이다.
* 방문 안의 경계를 **도약**이라 한다(같은 trail). 방문 사이의 경계는 다른 trail 사이 경계이다.
* 계측된 사실:
  * 서로 다른 trail 사이의 e는 모두 ≥ 0이다. 따라서 w ≥ 3이고, 사슬 시작으로 들어가면 w ≥ 4이다.
  * 판본 두 개의 내부 결합 가중치 합은 trail마다 같다. 전체 합은 10848이다(`family_struct.json`).

### 1.2 항등식

**정리 Q1 (다중 개방 항등식).** 모든 다중 개방 경로에 대해 다음이 성립한다.

* (I1) L = 35288 + 10848 − Σ_{절단} c + Σ_{경계} w
  * 35288 = 8 + 7·5040이다.
  * 절단마다 판본 결합 하나가 빠지고, 경계마다 결합 하나가 더해진다.
* (I2) J = L − 46085 = 48 + [c₁ = 2] + Σ_b (w_b − c_{b+1})
  * 같은 값의 다른 표현: 48 + #(c = 2) + Σ_b (w_b − 3).
* (I2′) 선택지 초과량 e_b = w_b − c_{b+1} − 1로 쓰면 다음과 같다.
  * J = 48 + (P − 1) + [c₁ = 2] + Σ_b e_b
  * G = J − 77 = (P − 30) + [c₁ = 2] + Σ_b e_b
  * 단일 개방(P = 30)이면 G = F이다.
* (I3) **방문 형식.** G = (V − 30) + [c₁ = 2] + Σ_{trail 사이 경계} e + Σ_{도약} E′
* (I4) **사슬 형식.** q를 w2 선분 수라 하면 J = 48 + (q − 768) + Σ_{w2가 아닌 결합} (w − 3)이다.
  * 768은 30개 판본 순환의 사슬 수 합 24·6 + 6·104이다.
* (I5) **단일 방문의 해밀턴 경로 형식.** trail 하나(판본 고정, run m개)를 한 번에 도는 방문을 run 경로로 보면 다음과 같다.
  * κ = [mid(진입)] + Σ_도약 E′ = W(경로) − Σ_k c_k + 3
  * 여기서 W는 m − 1개 결합 가중치의 합이다. 자연 결합은 E′ = 0이다.
* 증명.
  * (I1)은 단어 길이 공식이다. 첫 run은 15글자, 이후 run은 결합 w + 7글자를 더한다.
  * (I2)–(I5)는 (I1)의 대수적 재배열이다. Lean `J_identity`, `J_c2form`.
* 수치 검사(`identity_check.json`). 무작위 다중 개방 30개(조각 46–76개, 가상 순환 3–8개)에서 (I1)–(I3)가 실제 단어 길이와 모두 일치했다.

### 1.3 가상 덮개와 실현 가능성

* 절단 선택지를 꼭짓점으로, 경계(진출 선택지 o → 진입 선택지 o′)를 비용 e(o → o′)의 변으로 둔다.
* 꼭짓점마다 들어오는 변과 나가는 변이 각각 ≤ 1개이다. 그래서 덮개는 **경로 하나와 서로소인 순환들**로 갈라진다.
* **정리 Q2 (순환 수).**
  * 덮개의 순환 수는 P − 30 이하이다.
  * 각 순환에는 조각이 ≥ 2개인 trail의 꼭짓점이 있고, 그 trail의 꼭짓점은 순환 밖에도 있다.
* 증명.
  * 경로가 실현되려면 π̂∘σ가 P-순환 하나여야 한다. π̂는 경로를 닫은 덮개 순열이고, σ는 각 trail 절단의 순환 후속이다.
  * σ는 호환 P − 30개의 곱이다. 호환 하나를 곱하면 순환 수는 1만큼 변한다.
  * 그러므로 (1 + #순환) − (P − 30) ≤ 1이다. 연결성이 필요하므로 둘째 명제가 나온다.
* **run 수준 동치.** 판본 벡터를 고정하면 다중 개방 단어는 5040개 run의 해밀턴 경로 전체와 같다.
  * 그러므로 "다중 개방 전체"는 판본 일관 run 수준 ATSP 2³⁰개의 합집합이다.
  * Round M의 HK 하한이 J ≥ 65(판본 0 시작점)에 머문 바로 그 모형이다.

### 2.2 방문 보조정리 (감싸기 보상)

**보조정리 Q3.** 한 방문의 조각을 f₁, …, f_s라 하자. mid(f)는 조각 f가 사슬 내부에서 시작한다는 뜻이다(c = 2). 그러면

    κ(v) := [mid(f₁)] + Σ_{도약} E′  ≥  [mid(f_s)]  ≥  0,      Σ_{도약} E′ ≥ −1.

* 증명: mid 조각으로 들어가는 도약은 w ≥ 3이다(w = 2는 자연 재결합).
* 사슬 시작으로 들어가는 도약은 w ≥ 2이고, w = 2(감싸기)는 바로 앞 조각이 같은 사슬 내부에서 시작할 때만 가능하다.
* 따라서 도약 항 ≥ [mid(f_i)] − [mid(f_{i−1})]이고, 합은 망원급수가 된다.
* Lean `visit_kappa_ge_last`, `visit_kappa_nonneg`, `visit_jumps_ge_neg_one`.

**따름정리 Q4 (방문 전하).** 방문마다 전하 χ를 다음과 같이 정한다.

* 첫 방문: χ(v₁) = κ(v₁)
* 나머지 방문: χ(v) = e_in(v) + 1 + Σ_{v의 도약} E′

그러면 G = Σ_v χ(v) − 29이고 χ(v) ≥ 0이다. 첫 방문이 아닌 v에서 χ(v) = 0이 되는 것은 다음 조건이 모두 성립할 때뿐이다.

* e_in(v) = 0
* v가 mid 조각으로 시작한다.
* 첫 도약이 감싸기이다.
* 나머지 도약의 E′가 모두 0이다.

이런 방문을 **회전형 방문**이라 부른다. 단일 개방에서는 모든 방문이 χ = e + 1 ≥ 1이다.

### 6.2 이음매 보조정리와 조각 2개 분할

**재정식화(정리 Q6).** 분할 trail S의 두 꼭짓점 S(a) ∈ P, S(b) ∈ Z를 생각한다.

* 덮개는 경로 P와 순환 Z 하나이다(정리 Q2).
* Z에서 S(b)를 지우고 Z − S(b)를 P 뒤에 붙이면, trail 30개가 정확히 한 번씩 나오는 수열 Σ가 된다.
  * P의 끝과 Z − S(b)의 첫 원소 사이를 **이음매**(junction)라 한다. 이음매에는 변이 없다.
* 그러면

      G = 1 + F_J + β,   F_J = [c(Σ₁) = 2] + Σ_{이음매를 뺀 Σ의 변} e,   β = e(Σ_끝 → S(b)) + e(S(b) → 이음매 다음) ≥ 0

  이고, 이 대응은 전단사이다(S ∈ P, b ≠ a, 같은 판본). Lean `single_split_decomposition`.

**정리 Q8 (이음매 보조정리).** 모든 수열 Σ(30 trail, 각 1회, 임의 선택지)와 모든 이음매 위치 1 ≤ j ≤ 29에 대해 F_J ≥ 21이다. ⟨S⟩

* 따름정리(Lean `junction_consequences`):
  * 조각 2개 분할은 G = 1 + F_J + β ≥ 22이다.
  * §6.5의 도약 E′ ≥ 0 가족은 G = 1 + E′ + F_J + r ≥ 22이다.
  * 회전 사슬 절제는 G = F_J + r ≥ 21이다. 등호는 F_J = 21이고 R의 두 변이 모두 e = 0일 때뿐이다.

**계산.**

* HT(S, t, c): 이음매가 아직 없는 상태에서 "이음매를 포함하는 나머지"의 완화(A 정체성 자유) 최소이다.
  * ckB의 H에 JUMP 항을 더한 역방향 DP이다(`ckT.c`).
  * JUMP = 끝 사슬 a₁ + 자유 시작 경로 표 PLf[남은 φ][c − a₁].
  * 완화 근 값은 **16**이다(이음매가 시작 사슬 안이면 20).
* 신원 인지 전진 탐색(`ckT_search.c`): 상태는 (S, t, M, J)이다.
  * J = 0이면 HT, J = 1이면 H로 가지친다.
  * 이음매 전이는 끝 사슬 D1(정확) + 자유 시작 사슬 D2(정확)이고, 대기 상태(S, M′)를 거친다.

### 6.4 단일 회전 사슬 절제(감싸기 도약, 순 벌점 0)

trail T 하나에서 완전 사슬 C를 a₁에서 회전해 V1로 두고, 나머지 R = T − C를 한 조각으로 다른 곳에 두는 단어 전체이다. 경우는 넷이다.

* **E1. R이 V1과 이웃하지 않고 경로 안쪽에 있을 때.**

  * **다리 하한.** hin(x) = min_R e(x → R_in), hout(y) = min_R e(R_out → y)로 둔다.
    * 최소는 다른 trail의 완전 사슬 나머지 R 1200개 전체에서 잡는다.
    * hin = 0인 선택지는 1632개, hout = 0인 선택지는 120개이다. A 선택지의 hout 최소는 1이다.
    * 이 하한을 넣은 HT(`ckT.c`, `CKT_BRIDGE=1`)와 전진 탐색(`ckT_search.c`, `CKT_BRIDGE=1`)이 F_J + hin + hout ≤ 21인 패턴을 모두 낸다.
  * 패턴을 `excise_eval.c`로 정확히 평가한다.
    * T는 이음매에 이웃하지 않는 모든 위치에 둔다.
    * a₁은 모든 완전 사슬의 내부 run이다.
    * 나머지 선택지는 강제 DP로 최소화한다.
  * 결과: ⟨E1⟩
* **E2. R이 맨 앞일 때.**
  * G = e(T(C_start) → o₁) + Σ e ≥ F − 1 ≥ 21이다.
  * 등호는 F = 22, c(o₁) = 2, e = 0일 때뿐이다(Lean `excision_at_start`). 따라서 F = 22인 순서 24개만 보면 된다.
  * 24개 순서의 모든 (T, 사슬, a₁, 선택지)를 정확히 점검했다(`excise_start.py`, 166,032개). 최소 G = 24이다(`excision_case_E2_start.json`).
* **E3. R이 맨 끝일 때.** G = F + e(o₃₀ → T(N_start)) ≥ 22이다.
* **E4. R이 V1과 이웃할 때.** T는 조각 3개짜리 단일 방문이 된다. 정리 Q7(3조각 전부 지배)에 따라 G ≥ 22이다.
  * §2.3의 등호 단어가 바로 이 경우의 G = 22이다.

### 6.5 한 trail 3조각·방문 2개, 도약 E′ ≥ 0 (건너뛰기 방문)

* 구조: trail T를 u, α, β에서 자른다.
  * 2조각 방문은 [u, α) → 도약 α−1 → β → [β, u)이다. 진입 u, 진출 u−1이므로 선택지 T(u)처럼 행동한다.
  * 건너뛴 조각 [α, β)는 진입 T(α), 진출 T(β)로 다른 두 trail 사이에 둔다.
  * 순환 순서로 조각 3개의 2조각 방문은 모두 이 모양이다(이름만 바꾸면 된다).
* 장부: G = 1 + E′ + F_J + e(Σ_j → T(α)) + e(T(β) → Σ_{j+1})이다(Lean `skip_decomposition`).
* E′ = −1이면 감싸기, 곧 §6.4이다. E′ ≥ 0이면 정리 Q8에 따라 G ≥ 22이다. ⟨S⟩
* 건너뛴 조각이 방문과 이웃하면 3조각 단일 방문이 되어 정리 Q7에 따른다.

## 9. 일반 분할 전하 정리 (항목 9)

**정리 Q5.** 이 가족의 모든 다중 개방 단어에 대해 다음이 성립한다.

    J = 77 + G,    G = Σ_{방문 v} χ(v) − 29,
    χ(v₁) = κ(v₁) ≥ [mid(마지막 조각)] ≥ 0,
    χ(v) = e_in(v) + 1 + Σ_{도약} E′ ≥ e_in(v) ≥ 0   (v ≥ 2).

* χ(v) ≥ 1이 깨지는 것은 회전형 방문뿐이다. 이때 감싸기 1회가 추가 방문 벌점 1을 상쇄한다.
* 덮개 형식으로도 같다: G = (P − 30) + [c_s = 2] + Σ_{덮개 변} e. 변의 e는 trail 사이에서 ≥ 0, 감싸기 −2, 사슬 시작 w3 도약 −1이다.
* 단일 방문은 (I5)에 따라 trail 안 최소 해밀턴 경로이다. 지배 판정은 κ ≥ slack이다(§3).
* 특수한 경우:
  * 단일 개방: χ = e + 1, G = F.
  * 조각 2개 분할: G = 1 + F_J + β.
  * 한 trail 3조각·방문 2개: G = 1 + E′ + F_J + r. 감싸기(E′ = −1)이면 G = F_J + r이다.
* Lean: §1–4의 대수, Q3, 단일 방문 순서 열거를 형식화했다. 계측 사실(e ≥ 0, 도약 목록, 지배 표)은 표로 남긴다.
