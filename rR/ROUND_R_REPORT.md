## 2. P = 32, V = 32의 정확한 결정 (§2, §11, §15)

### 2.1 덮개 그래프, 종수, 괄호 나무

* V = P이면 같은 trail의 두 조각이 이웃하지 않는다. 경계는 모두 trail 사이 결합이다.
* 절단(cut) 선택지 P개 위에서 순열 둘을 정의한다.
  * σ: 절단 → 같은 판본에서 다음 절단. 순환 수는 30이다(trail마다 하나).
  * τ: 조각의 끝 절단 → 단어에서 다음 조각의 시작 절단. 마지막 → 처음을 닫는 호를 더한다.
  * 단어 순서는 τσ의 순환이다. 단어가 하나이므로 cyc(τσ) = 1이다.
  * τ에서 닫는 호를 빼면 경로 하나와 순환 c개가 된다. 이것이 **덮개 그래프**이고, cyc(τ) = c + 1이다.
* **정리 R1 (종수).** 오일러–하이퍼맵 공식으로
  `30 + (c + 1) + 1 = P + 2 − 2g`, 곧 **c = P − 30 − 2g** (g ≥ 0)이다.
  * P = 32이면 c ∈ {0, 2}이다.
  * c = 2(g = 0)는 **괄호 나무**이다. 순환마다 닻(anchor) 하나가 있고, 닻의 trail은 다른 절단을 부모 쪽에 둔다.
  * c = 0(g = 1)은 교차 배치이다.
* G의 장부: **G = (P − 30) + [c₁ = 2] + Σ_{덮개 호} e** (Lean `bracket_cost`).
* P = 32, c = 2의 배치는 정확히 세 모양이다.
  * 형제: 두 닻 trail의 주(main)가 모두 P에 있고 서로 다른 trail이다.
  * 같은 trail 닻: 한 trail이 조각 3개이다. 주는 P에 있고, 닻 둘은 서로 다른 run이다. 단어는 [a,b₁) Z₁ [b₁,b₂) Z₂ [b₂,a) 꼴이다.
  * 중첩: Z₂의 닻 trail이 주를 Z₁에 둔다.
  * 이 밖의 배치는 추이성(σ, τ가 만드는 군의 추이성)에 어긋난다.

### 2.2 우회 보조정리와 c = 0

* **L1** (세 trail이 서로 다름): e(x, y) ≤ 1 + e(x, u) + e(u, y).
* **L2** (tr x = tr u₂, tr u₁ = tr y ≠ tr x): e(x, y) ≤ 2 + e(x, u₁) + e(u₁, u₂) + e(u₂, y).
* 기계 확인: 서로 다른 trail의 순서쌍 90,599,040개 전부. 구현 둘(`bmat.c`, `l2check.c`)의 루프 순서가 다르다.
  * L1: 초과 최대 0, 등호 26,856,084개.
  * L2: 초과 최대 0, 등호 41,820개(`rR/certs/detour_lemmas_L1_L2.txt`).
* **정리 R2.** L1/L2를 사슬로 쓰면, 절단을 지워도 G가 늘지 않는다(Lean `detour`, `detour_start`, `detour_end`).
  * c = 0인 V = P 경로는 덮개가 경로 하나이다. 추가 절단을 모두 지우면 단일 개방 경로가 된다.
  * 따라서 **c = 0 ⇒ G ≥ 22**이다(Round P의 단일 개방 최적).
* **정리 R3 (V = P 환원).** 임의의 V = P 경로는 G를 늘리지 않고 다음 꼴로 환원된다.
  * 괄호 나무(종수 0)이다.
  * 추가 절단은 모두 닻이다.
  * 순환마다 주가 하나 이상 있다.
  * 순환 수 c′ ≤ c이다.
  * 방법: 순환-trail BFS 나무로 남길 주와 부모 닻을 고른다. 나머지 절단은 L1/L2로 지운다. 닻만 있는 순환은 통째로 지운다(G가 준다).
  * 따름정리: V = P 경로 중 환원된 괄호 수가 c′ ≤ 2인 것은 c ≤ 2 괄호 나무 탐색으로 결정된다. **P와 종수에는 상관없다.**

### 2.3 c = 2: 접합 정식화

* 순환을 닻에서 열어 Σ = P ++ Z₁′ ++ Z₂′로 이어 붙인다. 접합(junction)은 2개이다.
* **G = c + [c₁] + Σ_{접합이 아닌 호} e + Σ_i β_i**, β_i = e(z_end → u_i) + e(u_i → z_1) (u_i는 닻 선택지)이다.
* 닻의 결합 비용 B(z_end, z_1)은 대개 4–5이다. 분리 하한(hout(z_end) + hin(z_1))은 대개 0–2이다(`anchor_bounds_hin_hout.json`).
* 단일 trail 순환의 정확한 닫힘은 loop1(z) = min_u e(z → u) + e(u → z) ≥ 3이다(`two_cycle_costs.json`).

### 2.4 이완 표와 탐색 (`ckM2.c`, `ckM2_search.c`)

* **역방향 이완 DP `ckM2.c`.** Round P 검사기 B의 표준 상태 위에서 계산한다.
  * 표는 HZ0(마지막 순환 안), HZ1(접합이 하나 더 남음), HP(P 안, 접합 1–2개 남음)이다.
  * 닫힘 이완:
    * trail 2개 이상인 순환은 hout(마지막) + hin(처음)이다.
    * φ 하나뿐인 순환은 정확한 loop1 − hin이다.
    * A만 있는 순환은 A 하나면 정확한 loop1이고, 둘 이상이면 분리 하한이다.
  * 4비트 저장(층 최솟값 오프셋)을 쓴다. 15 GB이고, 40분 44초 걸렸다.
  * **이완 근(root)은 16**이다. P에 φ가 있으면 16, P가 A만이면 20이다. 근이 21보다 작으므로 표만으로는 닫히지 않는다. 그래서 전진 탐색과 정확 평가가 필요하다.

  * 상태는 (집합, 마지막 φ, 쓴 A 집합, 접합 수, 한 trail 순환 깃발)이다.
  * 가지치기는 J = 0이면 HP, J = 1이면 HZ1, J = 2이면 HZ0으로 한다. 대기 접합 상태는 PL1/PL0으로 자른다.

### 2.6 결론과 Round Q와의 교차 확인

* **정리 R6.** P = 32, V = 32인 경로는 모두 G ≥ 21이다(길이 ≥ 46183).
  * c = 0이면 G ≥ 22이다(정리 R2).
  * c = 2이면 위 계산이 THR 20 이하의 모든 괄호 나무를 정확 평가로 배제한다. G ≤ 20은 없다.
  * 이 부분 가족의 정확한 최솟값(21 또는 22)은 따로 구하지 않았다(지시대로 문턱 20의 결정만 했다).
* **따름정리.** Round Q 결과(P ≤ 31; P = 32, V ≤ 31)와 합치면, **P ≤ 32인 6A + 24φ 다중 개방 경로 전체의 정확한 최적값은 G = 21, 곧 길이 46183**이다.
* **Round Q와의 교차 확인.** 같은 탐색의 c = 1 패턴 130개를 THRG 21로 따로 평가했다(`c1_crosscheck_thr21.json`).

## 3. χ = 0 방문의 완전한 분류 (§3, §6)

* **정리 R4 (Lean `chi_eq`, `chi_nonneg`, `chi_zero`, `tight_grammar`, `chi_zero_first_mid_wrap`).**
  * v ≥ 2인 방문의 전하는 χ(v) = (w_in − 3) + [mid f_s] + Σ_j ε_j이다.
    * ε_j = E′_j − [mid f_j] + [mid f_{j−1}] ≥ 0 (보조정리 Q3의 국소형).
    * w_in ≥ 3 (trail 사이 결합)이다.
  * χ(v) = 0 ⇔ 다음 셋이 모두 성립한다.
    * w_in = 3이다.
    * 마지막 조각이 사슬 시작에서 시작한다.
    * 모든 도약이 꼭 맞는다(ε = 0).
  * 꼭 맞는 도약은 세 종류뿐이다. mid → mid는 꼭 맞을 수 없다(mid로 가는 w2는 자연 결합뿐).
    * mid → 시작, E′ = −1: 감싸기(wrap) C₆ → C₀만 가능하다.
    * 시작 → mid, E′ = +1: w3로 mid run에 들어간다(J3m).
    * 시작 → 시작, E′ = 0: 비자연 w3로 사슬 시작에 들어간다(J3s).
  * e_in = w_in − c(f₁) − 1 = 0이므로 첫 조각은 mid이고, 첫 도약은 감싸기이다.
* **문법.**

      ROT = [C_a … C_6] ─wrap→ [C_0 … C_j]      (완전 사슬 C, 1 ≤ a ≤ 6, 0 ≤ j ≤ a−1)
      V   = ROT ( J3m ROT | J3s START )*         (START = 사슬 시작에서 시작하는 조각)

* **각 방문의 매개변수.**
  * trail 종류: A 또는 φ.
  * 진입 상태: 완전 사슬의 mid run C_a. trail 사이 w3 호가 있어야 한다. 그런 호는 5184개이고 진입 run 4992개, 진출 run 4992개이다. trail 사이 w3 호는 내부 run에서 mid run으로만 간다.
  * 진출 상태: 마지막 START 또는 ROT 접두의 끝 run.
  * 회전량: a.
  * 조각 수: 2·(ROT 수) + (J3s 수).
  * 앞/뒤 호환:
    * 앞 방문의 진출 run에서 C_a로 가는 w3 호가 있어야 한다.
    * 뒤 방문의 전하에는 e(진출 → 다음 진입)이 들어간다. 따라서 뒤로는 제약이 없다.
* **완전 회전**(j = a − 1)은 표준 선택지 S(C_a)와 진입·진출이 같다.
* **유한 궤도 분류**(`chi0_orbits.py`, `rR/certs/chi0_orbits.json`). 가족 대칭군(위수 12)은 모든 구성 요소에 자유롭게 작용한다. 궤도 크기는 모두 12이다.

|---|---|---|---|
| 완전 회전 (C, a) | 5472 / 456 | 1728 / 144 | 600 |
| ROT 조각 (C, a, j) | 19152 / 1596 | 6048 / 504 | 2100 |
| J3m 도약 | 7536 / 628 | 2016 / 168 | 796 |
| J3s 도약 | 1056 / 88 | 288 / 24 | 112 |

* φ에서 a = 1인 완전 회전(288개)은 영전하 진입이 없다. a = 2…6은 모두 있다. A에서는 a마다 섞여 있다.
* **회전 매크로 상태와 합성 법칙**(§6, `rR/certs/rot_macro_composition.json`).
  * 상태는 ROT(C, a, j)이다. 궤도로 2100개이다. 진입은 C_a, 진출은 C_j이다. 완전 회전(j = a − 1)은 S(C_a)와 같은 포트를 가진다.
  * 합성 R₁ ∘ R₂는 같은 trail-판본 안에서 R₁의 진출 run C_j에서 다른 사슬 D의 mid run D_b로 가는 꼭 맞는 w3 호(J3m)가 있을 때만 정의된다.
  * 이런 호는 진출 run마다 많아야 하나이다. A는 2064개이다(진출 위치 j = 0…4에 각 288, j = 5에 624). φ는 288개이다(**모두 j = 5**).

  * 같은 사슬 안의 w3 호(A 5472, φ 1728)는 다른 사슬로 가지 않으므로 합성에 쓰이지 않는다. 그런 호로는 같은 사슬의 조각만 이을 수 있다.
  * 회전량은 사슬마다 따로 정해진다. 사슬 사이에 더해지는 "순 회전"은 없으므로 매크로들이 군을 이루지 않는다.
* **§5 중복 회전의 배제.** 아래는 모두 한 경로 안에서 생길 수 없다.
  * 같은 사슬을 두 번 회전하는 것, 역회전 쌍: 감싸기 호는 사슬마다 하나이고 run마다 다음 run은 하나이다. 그래서 사슬은 한 경로에서 많아야 한 번 회전한다.
  * 순 비용 0인 회전 순환: 회전의 포트는 선택지의 포트이고, 비용 0 전이는 영 결합 그래프 Z의 호이다. Z는 비순환이다(§9).
  * 중복된 끝점 상태 전이: 경로에서 run과 선택지는 한 번씩만 쓰인다.

## 4. 영전하 압축 보조정리 (§4, §5, §7)

* **강한 국소형은 거짓이다(반증).**
  * 완전 회전 R은 진입·진출이 S(C_a)와 같다. 그러므로 경계 x → y 사이에 R을 넣는 비용은 e(x, C_a) + e(C_{a−1}, y)이다. L1에 따라 넣어서 얻는 이득은 많아야 1이다.
  * L1의 등호는 26,856,084번 성립한다. 그러므로 영전하 회전은 국소적으로 정확히 1을 아낄 수 있다.
  * 즉 "χ = 0 사슬은 G를 늘리지 않고 언제나 표준 대상으로 바꿀 수 있다"는 국소 논법으로 증명할 수 없다. 회전 하나를 없애면 그 자리에서 G가 1 늘 수 있다.
* **정확한 장부(정리 R5).** 한 trail에서 연속한 완전 사슬 k개를 떼어 내고(trail 안 도약 P_end → N_0 하나), 각 사슬을 회전해서 다른 곳에 넣으면 ΔG ≥ E′(P_end → N_0) − k이다.
  * 넣은 회전마다 L1에 따라 −1이 하한이다.
  * 따라서 국소 장부만으로는 이득 가능성을 배제할 수 없다. 이것이 이번 라운드가 겨냥한 핵심 구멍이다.
* **기록 단어에서의 정확한 탐침**(`excise_rot_probe.py`, run 수준 정확 길이).
  * 연속 완전 사슬 k개를 떼어 낸 뒤, 각 사슬을 회전량 7가지와 모든 run 결합(약 5040곳) 중 가장 좋은 곳에 넣는다.

* **약한 형(증명됨).**
  * χ = 0 방문은 문법 R4를 따른다.
  * 첫 도약은 감싸기이다. 감싸기 호는 사슬마다 하나이므로 χ = 0 방문은 서로 다른 완전 사슬을 쓴다. 그래서 그 수는 ≤ 600(판본 벡터마다 완전 사슬 수)이다.

## 5. 전하 예산과 양전하 핵 (§8, §9, §10)

* **예산.** G ≤ 20 ⇔ Σ_v χ(v) ≤ 49이다. 모든 방문에서 χ ≥ 0이다.
  * 비회전 방문(v ≥ 2)은 χ ≥ 1이다(χ = 0은 회전형뿐).
  * 첫 방문은 χ = κ(v₁) ≥ 0이다.
  * 그러므로 G = χ(v₁) + Σ_{v≥2}(χ(v) − 1) + (V − 30)이다. 회전형 방문 하나는 "−1 항"이 되고 나머지는 ≥ 0이다.
* **양전하 핵.**
  * χ = 0 방문을 빼고, 그 사슬을 원래 trail에 되돌린 경로를 핵이라 한다.
  * G ≤ 20인 경로의 핵은 길이 46182 + (되돌림 비용) 이하의 경로이다. 되돌림 비용은 정리 R5의 장부로 정해진다.
  * 핵의 유한 목록을 만드는 데까지는 가지 못했다. 정리 R5의 하한 E′ − k가 k에 따라 음이 될 수 있어서, 핵이 길이로 묶이지 않는다.
* **§10 재삽입**: 고정된 경로에 회전을 넣는 문제는 정확히 풀린다(§4의 탐침: 사슬마다 모든 결합 × 7가지 회전). 일반 경로 위의 정확 DP/SAT는 하지 않았다.

## 6. 조각 ≥ 5개인 A trail 방문 (§12)

* 정리 Q7(Round Q)은 A trail의 조각 3–4개 단일 방문이 모두 지배됨을 보였다. 최대 이득은 0이다.
* 조각 수별 순서 수(첫 조각 고정, 자연 이웃 없음): 3 → 1, 4 → 2, **5 → 9**, 6 → 44, 7 → 265.
* 전하 정리로 보면 κ = [mid f_s] + Σε이고, 꼭 맞는 도약(감싸기, J3m, J3s)만으로 이어진 긴 방문은 κ = 0일 수도 있다. 그러므로 "조각이 많으면 비싸다"는 일반 논법은 없다.
* **사슬 수준 공식(정리 R7, 정확).** 한 trail-판본의 단일 방문 H(run의 해밀턴 경로)에 대해
  `κ(H) = (H의 최대 w2 구간 수 − 사슬 수) + Σ_{w2가 아닌 이음} (w − 3)`이다. 두 항은 모두 ≥ 0이다.
  * 이유: κ = Σ_{이음}(w − 2) − (k_T − 1)이다(k_T = 사슬 수). w2가 아닌 이음 수 = w2 구간 수 − 1이다.
  * 완전 사슬은 회전해도 w2 구간 하나이다(감싸기도 w2이다). 그래서 회전 자체는 κ를 늘리지 않는다.
  * 따라서 κ ≤ 5인 방문은 "결함" ≤ 5개짜리이다. 결함은 사슬을 더 쪼갠 구간이나 w ≥ 4 이음이다.
  * 결함 사이에서는 사슬 하나가 블록 하나(완전 사슬은 회전 a = 0…6 중 하나, 경로 사슬은 자연 순서)이다. 블록과 블록은 w3로 이어진다.
* **결함 0 블록 그래프**(`rR/certs/A_chain_level_zero_defect.json`). 블록 진출 → 다른 사슬 블록 진입(w = 3)의 호를 사슬 순번 차이로 센다.

|---|---|---|---|---|---|---|
| A (12개 모두 같음) | 104 (76) | 284 | 104 | 4 | 56 | 120 |
| φ | 6 (6) | 12 | 6 | 0 | 6 | 0 |

  * 따라서 조각 ≥ 5인 A 방문 문제는 "결함 ≤ 5인, 이 성긴 블록 그래프 위의 사슬 수준 해밀턴 경로"로 정확히 환원된다. 블록 그래프는 거의 순환이다.
  * 이 환원을 끝까지 전수하지는 못했다. 결함 ≤ 5를 허용하면 매크로 조각이 많아야 6개이므로 유한한 문제이다. 다음 라운드의 정확한 과제로 남긴다.

## 9. 음·영 순환, 퍼텐셜, SCC (§17, §18, §19)

* **퍼텐셜.** 전하 정리가 곧 실행 가능한 퍼텐셜이다. 방문마다 감소 비용 χ(v) ≥ 0이고 G + 29 = Σχ이다(Lean `chi_eq`, `chi_nonneg`, `potential_bound`, `no_negative_cycle`).
  * 음의 순환은 없다.
  * 등호(감소 비용 0)인 방문은 정확히 회전형 방문이다(Lean `chi_zero`, `tight_grammar`).
* **영 결합 그래프의 SCC**(`zero_scc.py`, `rR/certs/zero_scc.json`).
  * 선택지 10080개, e = 0인 trail 사이 호 8448개이다.
  * **강연결 성분은 모두 크기 1이다(비순환).**
  * 영 호만으로 된 가장 긴 경로는 선택지 9개이다.
  * 그러므로 단일 조각 방문만으로 된 영 비용 구간은 길이 ≤ 9이다. 몫 그래프는 그 자체이다.
* **영 순환의 분류**: 감소 비용 0인 닫힌 보행은 꼭 맞는 변만 쓴다(Lean `zero_sum_all_zero`). 선택지 그래프에는 그런 순환이 없다. 남는 영 비용 구조는 회전형 방문뿐이다.
* **trail 안 도약 그래프의 음의 순환.** run 수준에서 도약 비용 E′의 그래프에는 음의 순환이 **있다**.
  * 완전 사슬마다 w2 7-순환(자연 결합 6개 + 감싸기)이 비용 −1이다. 판본 벡터마다 600개이다.
  * 감싸기 여러 개를 0 비용 w3로 이은 순환도 있다.
  * 그러나 한 경로에서 run은 한 번씩만 쓰이므로 이 순환을 되풀이할 수 없다.
  * 조각 단위의 퍼텐셜 p(조각) = [mid]를 쓰면 감소 비용 ε = E′ − [mid 머리] + [mid 앞 조각] ≥ 0이 된다(보조정리 Q3). 그래서 한 방문 안의 도약 합은 ≥ −1이다. 이것이 전하 정리의 국소형이다.
  * 즉 음의 순환은 정확히 "회전"이다. 그 효과는 방문마다 많아야 −1이고, 방문마다 +1(V − 30 항)이 상쇄한다. χ = 0이 등호이다.
* G ≤ 20 경로의 길이 상한: 양전하 방문 ≤ 49, 첫 방문 1, 회전형 방문 ≤ 600, 곧 V ≤ 650이다.

## 13. 최종 보고 (13항목)

1. **P = 32, V = 32의 정확한 결과**: **G ≤ 20 없음 (G ≥ 21)**. c = 0은 우회 보조정리로 ≥ 22이다. c = 2는 패턴 759,270개, 배치 2,960,139개를 정확 평가했고 모두 단계 B에서 G > 20으로 닫혔다. 따라서 P ≤ 32 부분 가족 전체의 최적값은 정확히 21(46183)이다.
2. **χ = 0 방문의 완전한 분류**: 완료.
   * χ = 0 ⇔ w_in = 3, 마지막 조각이 사슬 시작, 모든 도약이 꼭 맞음(Lean `chi_zero`).
