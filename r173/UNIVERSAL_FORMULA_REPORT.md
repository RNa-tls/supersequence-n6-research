# Round 173 — 일반 n 최소 superpermutation 길이: 감사, 정리, 반례

**결론 먼저:** 모든 n에 대한 정확한 공식 `L_n = f(n)`은 **얻지 못했습니다.** 이 보고서에 있는 것은 네 가지입니다.
- 일반 n에서 성립하는 정리 몇 개
- 짧은 수열에 맞춘 후보 공식 하나의 **반례**
- `Δ(n)`에 대한 새 하한 `Δ(n) ≥ 1 (n ≥ 5)`. 프로젝트의 일반 n 보조정리를 조건으로 합니다.
- 다음에 증명해야 할 정확한 정리

표기는 `CONST(n) = n! + (n−1)! + (n−2)! + n − 3`, `L_n = CONST(n) + Δ(n)`입니다.

## 3. 일반 n 구조 (§3 요구사항)

`σ(s) = s[1:]+s[0]`, `τ(s) = s[1:n−1]+s[0]+s[n−1]`, 육각형은 σ-류(순환 순서)입니다.

- **(G1) 전이 가중치.**
  - 무게 1: σ만 가능합니다.
  - 무게 2: `σ²(x)` 또는 `ρ(x) = x[2:]+x[1]x[0]` 두 가지입니다.
  - 완전한 pass(`e`에서 시작하는 n개 창)의 출구 `x = σ^{n−1}(e)`에서 나가는 무게-2 이동은 `ρ(x) = τ(e)`로 정해집니다(일반 n, 무조건).
- **(G2) τ-블록의 육각형 집합 (보조정리 P1).** `e = c₁…cₙ`일 때 `τʲe = c_{j+1}…c_{n−1} c₁…c_j cₙ`입니다.
  - 따라서 블록 `{τʲe : 0 ≤ j ≤ n−2}`가 덮는 육각형 `H(e)`는 순환 `(c₁…c_{n−1})`의 n−1개 틈에 `cₙ`을 끼운 순환 순서들입니다.
  - 즉 `H(e) = {D : D에서 cₙ을 지우면 (c₁…c_{n−1})}`이고, `|H(e)| = n−1`입니다.
  - 각 육각형은 정확히 n개의 τ-블록에 속합니다. 육각형을 τ-블록으로 정확히 덮으려면 블록이 `HEX/(n−1) = (n−2)! = ORB`개 필요합니다(예: 특수 기호 n을 고정한 (n−2)!개 블록).
- **(G3) 강제 연속 (보조정리 P2, 증명은 §4).** 블록 출구 `x`에서 무게 3으로 갈 수 있는 여섯 후보 중 다섯은 `H(e)`와 겹칩니다. 남는 하나는 `φ(e) = c₂…c_{n−2} c₁ c_{n−1} cₙ`이고, φ는 위수가 n−2입니다.
  - 모든 e에 대한 전수 확인: n=4..8은 전부, n=9는 40,320개. 위반 0 (`r173/certs/phi_lemma_173.json`).
- **(G4) 경험적 관찰 (R8, 정리 아님).** n=5..9의 모든 기록 단어에서 `Z = B* = D2 = Qs = 0`, `G = c`, `t = k + H`입니다.
  - n ≥ 7 기록은 모두 `H = 0`, `t = k`입니다(n=7: k=22, n=8: k=119, n=9: k=720).
  - 고전적 재귀 구성은 반대 극단입니다(n=9, 409113: k=0, H=867).

## 4. 증명

### R3. 등호 특성화

**정의 (완전 사슬).** 수열 `e₁,…,e_m`, `m = (n−2)!`로서 다음을 만족하는 것입니다.
- (i) 블록 `T(e_i) = {τʲe_i}`들이 모든 육각형을 정확히 한 번씩 덮는다.
- (ii) `x_i = σ^{n−1}(τ^{n−2}e_i)`일 때 `e_{i+1}[:n−3] = x_i[3:]`이다(무게-3 joint).

**(⇐, 무조건).** 완전 사슬을 문자열로 쓰면 모든 순열이 나옵니다. 길이는

`n + (N − HEX) + 2(HEX − m) + 3(m − 1) = CONST(n)`

입니다. `r173/src/perfect173.py`의 `spell`로 n=3(9)과 n=4(33)를 확인했습니다. n=4 문자열은 알려진 최소 초순열과 같습니다.

**(⇒, R2의 보조정리에 의존).**
1. `L = CONST(n)`이면 `t = 0`이고, 네 항이 모두 음이 아니므로 `k = Z = H = B* = 0`입니다.
2. `k = 0`이면 `O = ORB`입니다. `D_φ = (n−1)O − P ≥ 0`이므로 `P ≤ HEX`이고, 모든 육각형에 pass가 있으므로 `P ≥ HEX`입니다. 따라서 `P = HEX`, 즉 모든 pass가 완전합니다.
3. `G = 0 = Z + D2 + c`이므로 `D2 = c = 0`입니다. `B* = 0`에서 `S = O − 1 = ORB − 1`을 얻습니다. `H = 0`이므로 무게 ≥ 3인 joint는 모두 무게가 정확히 3입니다.
4. (G1)에 의해 무게-2 joint는 `e → τ(e)`입니다. 따라서 무게-2로 이어진 run은 τ-궤도의 구간이고, run의 수는 ORB입니다.
5. 사용된 궤도도 ORB개이고, 궤도마다 원소가 n−1개이며, `HEX = (n−1)·ORB`입니다. 그러므로 각 궤도는 정확히 하나의 완전한 run이고, 이것이 완전 사슬입니다. ∎

### R4. 강제 연속 (보조정리 P2, 일반 n ≥ 4)

`e = c₁…cₙ`, `f = τ^{n−2}e = c_{n−1} c₁ … c_{n−2} cₙ`, `x = σ^{n−1}f = cₙ c_{n−1} c₁ … c_{n−2}`로 둡니다. 후보는 `M = c₂…c_{n−2}`에 대해 `M·π(cₙ, c_{n−1}, c₁)`입니다.

후보 e′의 블록 육각형 집합은 "e′의 마지막 기호 s를 지우면 e′[:−1]의 순환"입니다(P1). 여섯 후보를 하나씩 보면:

| π | 후보 | s | 나머지 순환 | `H(e)`와 공유하는 육각형 D |
|---|---|---|---|---|
| (cₙ,c_{n−1},c₁) | M cₙ c_{n−1} c₁ | c₁ | (M cₙ c_{n−1}) | D = (c₁ … c_{n−2} cₙ c_{n−1}) |
| (cₙ,c₁,c_{n−1}) | M cₙ c₁ c_{n−1} | c_{n−1} | (M cₙ c₁) | D = (c₁ … c_{n−1} cₙ) |
| (c_{n−1},cₙ,c₁) | M c_{n−1} cₙ c₁ | c₁ | (M c_{n−1} cₙ) | D = (c₁ … c_{n−1} cₙ) |
| (c_{n−1},c₁,cₙ) | M c_{n−1} c₁ cₙ | cₙ | (c₂…c_{n−1} c₁) ≅ (c₁…c_{n−1}) | `H(e)` 자체 |
| (c₁,cₙ,c_{n−1}) | M c₁ cₙ c_{n−1} | c_{n−1} | (M c₁ cₙ) | D = (c₁ cₙ c₂ … c_{n−1}) |
| (c₁,c_{n−1},cₙ) | **M c₁ c_{n−1} cₙ = φ(e)** | cₙ | (M c₁ c_{n−1}) | 없음 (특수 기호는 같고 순환이 다름) |

각 행의 D는 "cₙ을 지우면 (c₁…c_{n−1})"과 "s를 지우면 해당 순환"을 둘 다 만족하므로 `H(e) ∩ H(e′) ≠ ∅`입니다. `H(e)`는 이미 사용되었으므로 다음 블록은 반드시 `φ(e)`입니다. ∎

### R5. n ≥ 5에서 Δ(n) ≥ 1

1. R4에 의해 완전 사슬은 `e, φe, φ²e, …`로 강제됩니다.
2. `φ^{n−2} = id`이므로 n−2번째 다음 후보는 `e` 자신의 블록이고, 이미 사용되었습니다. 따라서 사슬 길이는 최대 n−2 블록입니다.
3. 필요한 블록 수는 `(n−2)!`이고, n ≥ 5에서 `(n−2)! > n−2`이므로 완전 사슬은 존재하지 않습니다.
4. R3에 의해 `L_n ≥ CONST(n) + 1`입니다. ∎

**계산 확인.** e₁ = 항등 순열로 고정한 전수 탐색(S_n 기호 치환 대칭)의 결과입니다.

| n | 결과 | 탐색 노드 |
|---|---|---|
| 5 | 없음 | 19 |
| 6 | 없음 | 25 |
| 7 | 없음 | 31 |

**독립 확인.** n=5는 무조건적 Chaffin 계산으로 따로 확인되었습니다(R9). 이 결과가 이미 문헌에 있는지는 확인하지 못했습니다(arXiv 접근이 네트워크 정책으로 막힘). 논증이 짧으니 알려져 있을 수도 있습니다.

### R6. 영역 `k = Z = B* = 0`

R3의 ⇒ 방향 1~5단계에서 `H = 0`만 빼면 같은 결론이 나옵니다. 모든 pass가 완전하고, 각 τ-궤도가 한 블록이며, 블록 사이 joint가 ORB−1개입니다.
- 무게-3 joint는 R4에 의해 φ로 강제되므로, 무게-3로만 이어진 연속 블록은 최대 n−2개입니다.
- 따라서 무게 ≥ 4인 joint가 최소 `(n−2)!/(n−2) − 1 = (n−3)! − 1`개 필요하고, `H ≥ (n−3)! − 1`입니다. ∎

즉 **추가 τ-궤도를 쓰지 않는 구성(k = 0)은 `L ≥ n!+(n−1)!+(n−2)!+(n−3)!+n−4`를 넘지 못합니다.** 이 값은 n=5, 6에서 실제 최소값과 같고, n=7에서는 5907입니다.

## 5. 후보 공식과 반례 (§4, §5 요구사항)

| 후보 | 근거 | 상태 |
|---|---|---|
| `Δ(n) = 0` (4chan 하한이 tight) | n ≤ 4 | **반증** (n ≥ 5: R5, n=5 무조건) |
| `Δ(n) = (n−3)!` (Egan 상계가 tight) | n=7,8에서 Egan 문자열(5908, 46205) | **반증**: n=6 (872 < 873), n=7 (5906), n=8 (46204) |
| `Δ(n) = (n−3)! − 1`, 즉 `L_n = n!+(n−1)!+(n−2)!+(n−3)!+n−4` | n=3..6의 다섯 값에 정확히 맞음 | **반증 (R7)**: n=7 예측 5907, 검증된 문자열 5906 존재 |

R7은 이 공식이 우연이 아님을 보여 주는 동시에 그 한계도 보여 줍니다. 이 공식은 정확히 R6의 k=0 영역 하한입니다. n=7의 5906 문자열은 k = 22(추가 τ-궤도 22개)를 써서 이 영역을 벗어나고, 그래서 더 짧습니다.

n=3..9의 상계 수열 (0, 0, 1, 5, ≤22, ≤119, ≤720)으로 공식을 만들지 않았습니다.

**상계 (문헌 인용, 재증명 안 함).** Egan(2018)의 일반 구성은 `Δ(n) ≤ (n−3)!`을 줍니다. 이번 라운드에서는 그 사례인 n=7(5908)과 n=8(46205) 문자열만 검증했습니다. 따라서 **모든 n에서 `1 ≤ Δ(n) ≤ (n−3)!` (n ≥ 5)**입니다. 하한은 R3 조건부, 상계는 문헌 기준입니다.

## 6. n=6 확인 (§6 요구사항)

`CONST(6) = 867`, `L₆ = 872`, `Δ(6) = 5`. 이 보고서의 결과들과 모순이 없습니다.
- R5는 Δ(6) ≥ 1을 줍니다.
- R6은 k=0 영역에서 t ≥ 5를 줍니다. 실제로 k=0인 n=6 단어는 873(H=6)입니다.
- 872 단어들은 모두 k ≥ 3입니다(아카이브 44,120개 전부 확인).

프로젝트 자체의 L₆ ≥ 872 증명은 n=6 전용 계산 기계에 기대고 있습니다. 그 최종 재인증(load-bearing 셀 35개)은 11/35가 끝났고 진행 중입니다. 이 보고서는 872를 일관성 점검으로만 썼습니다.

|---|---|---|
| `L₇ ≥ 5884` | R2 (및 문헌) | 일반 정리의 대입 |
| **`L₇ ≥ 5885`** | R5 (n=7에서 완전 사슬 없음. 일반 증명 + 노드 31개 전수) | R3 ⇒ 방향 조건부 |
| k=0 구성은 `≥ 5907` | R6 | R2 조건부 |
| `L₇ ≤ 5906` | 검증된 문자열 139개 | 구성 |

따라서 **`1 ≤ Δ(7) ≤ 22`**입니다. L₇의 정확값은 주장하지 않습니다. 하한을 5906 가까이 올리려면 k ≥ 1 구조(부분 2-cycle)의 비용을 다루는 정리가 필요하고, 그것은 없습니다.

## 8. 보편 공식을 얻었는가?

**아니요.** UNIVERSAL_EXACT_FORMULA와 UNIVERSAL_EXACT_ALGORITHM 모두 없습니다.

TSP 정식화 `L_n = n + min Σ ω(v_j, v_{j+1})`는 정확한 알고리즘이지만, 원래 문제를 바꿔 쓴 것일 뿐입니다.

## 9. 가장 작은 정확한 장애물과 다음 정리

**장애물.** `Δ(n)`의 하한은 현재 두 부분으로 나뉩니다.
- k = 0 영역은 R6으로 `(n−3)! − 1`까지 증명됩니다.
- **k ≥ 1(추가 τ-궤도, 즉 부분 pass/부분 2-cycle)이 3-cycle 사이 이동 비용을 얼마나 줄일 수 있는지**에 대한 정리가 없습니다. 기록 단어는 모두 이 경로(t = k)를 씁니다.

**다음 정리 후보 (순서대로):**
1. **t = 1 분류 → 모든 n ≥ 6에서 Δ(n) ≥ 2.**
   - Z = 1은 k ≥ 1을 요구하므로 t ≥ 2입니다(이미 증명: k = 0이면 G = 0이라 Z ≤ 0).
   - H = 1은 R6에 의해 n ≥ 6에서 불가능합니다.
   - 남은 경우는 `B* = 1`(한 궤도가 두 run으로 쪼개짐. 모든 pass 완전)과 `k = 1`(G ≤ n−1개의 부분 pass)입니다. 둘 다 P2를 "부분 run"으로 일반화한 보조정리가 필요합니다.
2. **"k당 절약" 보조정리:** 추가 τ-궤도 하나가 무게-4 joint를 최대 몇 개 대체할 수 있는지의 상계.
   - 예를 들어 `(k + H) ≥ (n−3)! − 1 − c(n)·k` 같은 형태입니다.
   - 이것이 되면 `Δ(n)`의 하한이 (n−3)! 차수로 자라는지가 결정됩니다.
3. 경험적 관찰 R8(`Z = B* = 0`인 최적해가 존재)을 정리로 만드는 것. 되면 문제는 `min (k + H)`라는 깨끗한 조합 문제로 줄어듭니다.
