### A.1 도구 셋 (새로 증명)

**보조정리 W-ins (삽입 비용, 증명 + Lean + 전수 계산).** 조각 p가 순열 P1로 시작해 T로 끝나고 그 절단 결합 T → P1의 무게가 w_i라 하자. 앞 조각이 X로 끝나 X → P1의 무게가 w₁, 뒤 조각이 Y로 시작해 T → Y의 무게가 w₂이면,

    w₁ ≥ w_i 이고 w₂ ≥ w_i  ⇒  w(X, Y) ≤ w₁ + w₂ − w_i,   곧  ins = w₁ + w₂ − w(X,Y) − w_i ≥ 0.

* 증명: 위치 논법. 0 ≤ i < 8 − s(s = w₁ + w₂ − w_i)에서 Y[i] = T[w₂ + i] = P1[w₂ + i − w_i] = X[s + i].
* Lean `ins_lemma`(길이 n, 임의 알파벳, 첨자 함수로 표현한 창): `rW/lean/RoundW.lean`.
* 전수 검사(`rW/csrc/ins_lemma.c`): P1 = 01234567로 고정(재표기 대칭), w_i ≤ 5, w₁, w₂ ≤ 7인 배치 5,299,787,333개에서 위반 0. 가설이 깨지면 ins가 −7까지 내려간다(`certs/wraps/ins_lemma.json`).

**사실 W-chain (전수 계산).** 떼어 낸 사슬 588개의 조각(감싸기 사용) 32,340개는 절단 무게가 1(클래스 안, 28,812개) 또는 2(사슬 안의 무게 2 결합, 3,528개)뿐이다. 사슬 안의 결합은 모두 무게 2이다. 다른 trail 사이의 이음은 무게 ≥ 2이므로(무게 1은 같은 클래스 안뿐), **보조정리의 가설이 언제나 성립한다: 경로형 경로에서 사슬 조각을 빼고 이웃을 이으면 J가 늘지 않는다.**

**사실 W-undo (전수 계산 + 증명).** 숙주가 틈에서 잘리지 않은 감싸기를 되돌리면(사슬을 숙주에 다시 넣음) 길이 변화는 ΔL = (c₀ + c_N + 안쪽 결합 − skip − 2k) − ins이다. 이 상수는 단일 사슬 588개(c₀ = c_N = 3, skip 4, 감싸기 2), 이웃한 사슬 덩이 k = 2, 3, 4(420, 276, 144개)에서 모두 0이다. k = 5(D trail에 사슬 하나만 남는 경우, 72개)만 6이다.

## H. 새 보조정리

**보조정리 W-junction (증명 + 전수 계산; 새 결과).** 길이 46134 이하라고 가정한 칸에서, 사슬마다 결손 d ≥ dmin(r)이고(직선 1·2의 조각 수 보조정리와 구역 명제), 무료 접합은 Lemma J1(c)에 따라
(i) 한 행짜리 성분이 자기 자신의 출발·도착인 고리(그 행의 결손 ≥ 1), 또는
(ii) 양쪽 끝 행의 결손이 각각 ≥ 2이고 합 ≥ 8
이다. 끝 행을 사슬에서 떼어 내면 나머지는 사슬이므로(부분 사슬), 결손의 합은

    Σd ≥ P₀[m](R − F_i − (2F_ii − s)) + F_i + 8F_ii − 6s,   m ≤ n − F_i − s

이다. 여기서 F_i는 고리 수, F_ii는 쌍 수, s는 두 쌍에 함께 걸린 한 행 성분의 수(그 행의 결손 ≤ 6이 두 번 세어짐), P₀[m]은 dmin의 m겹 최소-합 합성곱이다. 이 하한이 Δ보다 크면 칸이 지워진다.
