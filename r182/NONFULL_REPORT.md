## 1. R181 감사

### 1.1 정의와 한정사 (독립 재확인)

모든 양은 정규화 route 하나와, 그 route에 Bridge(n)이 만든 인스턴스 하나에 대해 정의됩니다.

| 기호 | 정확한 정의 | 선택 의존성 |
|---|---|---|
| m | `M − ORB`. M은 S(cost-1 간선으로 들어오지 않는 순열)와 만나는 F-block 수 | route 불변량 |
| b | `q − k`. q는 cost ≤ 2 간선으로 들어오지 않는 순열 수(chain 수), k는 A-성분 수 | route 불변량 |
| η | `p − 1`. p − 1은 cost ≥ 4 간선 수 | route 불변량 |
| N_nf | 인스턴스의 row 가운데 charge ≥ 1인 것의 수. charge(row) = row block의 구멍 수(B9) | **r > 0이면 선택 의존**: 성분마다 어느 block이 row block이 되는지를 surgery(B8)가 고릅니다. r = 0이면 성분 = block이므로 불변량입니다 |
| k_s, ν_s | special s인 row 수, `ν_s = ORB − k_s` | 같은 이유로 선택 의존 |
| ω_s | special ≠ s인 block이 `Hid_s`와 공유하는 순환류 수의 최댓값 | 선택 의존 |

**결론.**
- R181의 정리 CS는 **각 인스턴스마다** 증명되었으므로 어느 선택에서나 성립합니다.
- NF를 Δ 하한에 쓰려면 **어떤 인스턴스 하나에서** 성립하는 것(∃-형)으로 충분합니다. 아래 NF는 모두 ∃-형으로 둡니다.

### 1.2 증명별 감사

| 대상 | 판정 | 비고 |
|---|---|---|
| 보조정리 S | 옳음 | 핵심을 **이번 라운드에 Lean으로 형식화**했습니다(§9) |

| 명제 K | 옳음 | `k_s + k_{s′} ≤ k = ORB + m − (r−a)` |

## 2. NF의 정확한 진술과 영역

**NF(θ)** (θ는 n과 무관한 상수): route의 어떤 Bridge 인스턴스에서 `N_nf ≤ θ·X`, `X := m + b + η`.

| 영역 | 정의 | 관계 |
|---|---|---|
| A | 모든 정규화 Hamilton route | |
| B | 모든 덮개 route(초순열), 정규화 후의 인스턴스로 판정 | 정규화는 A에서 항등이고 모든 덮개 route를 A로 보냅니다(R178 Lemma 2.2). 따라서 **NF_A ⟺ NF_B** |
| C | D ≤ (n−3)!인 정규화 route | Egan 상계 Δ ≤ (n−3)!과 D ≤ Δ에 의해 **모든 최적 route가 C에 속합니다** |

- **덮지 않는 route:** Bridge는 모든 순환류가 S와 만난다는 것(B2)을 쓰므로 정의되지 않습니다. 정의상 NF의 대상이 아닙니다.
- **함의:** `NF_A(θ) ⟹ NF_C(θ) ⟹ Δ(n) ≥ ⌈(ORB−(n−2))/((n−2)+(n−1)θ)⌉` (§6).
- **역방향은 성립하지 않습니다.** 대신 Δ(n) = o((n−3)!)이면 모든 고정 θ에 대해 NF_C가 거짓입니다(정리 F에서).

**명제 T (자명 영역과 경계, 증명).**
- (a) `N_nf ≤ min(k, G) ≤ min(ORB + m − (r−a), (n−1)m − r)`.
  - 따라서 NF(n−1)은 모든 route에서 성립합니다. 다만 θ = n−1은 n에 의존합니다.
- (b) θ > 1이고 `X ≥ ORB/(θ−1)`이면 NF(θ)가 성립합니다. 증명: `N_nf ≤ k ≤ ORB + m ≤ ORB + X ≤ θX`.
  - **따라서 결함이 충분히 큰 route는 NF의 반례가 될 수 없습니다.** 제한 없는 NF가 거짓이 될 수 있는 곳은 `1 ≤ X < ORB/(θ−1)` 대역뿐입니다.
- (c) **X = 0 경계:**
  - m = 0이면 r = 0이고 u = 0이므로 모든 row가 full이고 N_nf = 0입니다.
  - n ≥ 6에서 X = 0은 불가능합니다. 정리 F에서 N_nf = X = 0을 넣으면 n−2 ≥ (n−2)!이 되어 모순입니다.

## 3. special 균형 route — 이중 계수

기호:
- `G` = 총 charge, `Inv` = 어디서도 보이지 않는 순환류.
- `μ(c)` = 순환류 c를 포함하는 row block 수, `h(c) = μ(c) − [c visible]`.
- `ρ(c)` = c를 포함하는 row block과 payload block의 수.
- `J_s = Σ_{B ∈ special ≠ s인 row block ∪ payload block} |cls(B) ∩ Hid_s|`.

**항등식 (모두 증명).**
- **I1** `Σ_s k_s = k`, `Σ_s ν_s = n·ORB − k = (n−1)ORB − m + (r−a)`.
- **I2** `G = Σ_s g_s = (n−1)(m − r + a) + |Inv|`. 보조정리 S와 `(n−1)k = G + (보이는 순환류 수)`에서 나옵니다.
- **I3** `Σ_c μ(c) = (n−1)k`, `Σ_c h(c) = G`.
- **I4** 각 s마다 `J_s ≥ g_s`(CS의 덮기)이고, `Σ_s J_s = Σ_c ρ(c)h(c) − G`.
  - 증명: 한 block B 안의 c에 대해 `#{s ≠ sp(B) : c ∈ Hid_s} = h(c) − [c ∈ Hid_{sp(B)}]`이고, `Σ_B Σ_{c∈B} [c ∈ Hid_{sp(B)}] = G`입니다.
  - 결과: 전체 덮기 여유는 `Σ_s (J_s − g_s) = Σ_c (ρ(c) − 2)h(c) ≥ 0`입니다.

`Σ_s ω_s ν_s`에는 항등식이 없습니다. ω_s가 최댓값이기 때문이며, 대신 I4의 J_s가 그 역할을 정확히 대신합니다.

**수치 확인** (`ident182.py` → `certs/ident182.txt`): route 67개(n = 5, 6, 7; archive, 섭동, greedy, r = 0)에서 I1–I4가 모두 참입니다.

**명제 AV (CS 평균의 공허성, 증명).**
- charge를 가진 special이 둘 이상이고 m ≤ ORB/n이면, CS1을 합한 것 `Σ_s ω_s(m + ν_s)`는 charge 예산 `G ≤ (n−1)m`에 이미 함의됩니다.
- 증명: charge를 가진 s는 ω_s ≥ 1입니다. 그런 두 s, s′에 대해 `ν_s + ν_{s′} ≥ ORB − m ≥ (n−1)m ≥ u ≥ G`입니다.
- 따라서 **균형 special route에서 NF는 CS를 합하거나 평균해서 얻을 수 없습니다.** 필요한 불변량은 special별 덮기가 아니라 trail 구조에 있습니다(§4). R181 표본에서 최적 n = 6 route는 모두 균형(ν_min/ORB ≥ 0.58)이었습니다.

## 4. 전역 charging — 정리 F와 국소 창

**정리 F (non-full row 강제; 모든 n ≥ 6, 모든 정규화 route, 모든 Bridge 인스턴스).**

`(n−1)·N_nf ≥ k − (n−2)τ_used = ORB + m − r + a − (n−2)τ_used ≥ ORB − (n−2)(1 + m + b + η).`

**증명.**
- RUN은 `k ≤ (n−2)τ_used + (n−1)N_nf`입니다. full row 구간은 charge 0인 ModelTrail이므로 C1(0)에 의해 ≤ n−2이고, 계수 부분은 Lean `run_bound_family`입니다.
- 여기에 Bridge의 `k = ORB + m − r + a`, `r ≤ (n−1)m`, `a ≥ 0`, `τ_used ≤ η + 1 + b`를 넣습니다.
- 산술은 Lean `FCore.f_core`입니다. ∎

**따름정리 F1.** 모든 정규화 route에서 `D ≥ X ≥ ⌈(ORB − (n−1)N_nf)/(n−2)⌉ − 1`입니다. 최적 route에 적용하면 다음을 얻습니다.

`(n−3)! − 1 − ((n−1)/(n−2))·N_nf(최적 route) ≤ Δ(n) ≤ (n−3)!` (상계는 Egan).

**따름정리 F2 (Egan 간격의 대가).** D ≤ (n−3)! − 1 − j인 route는 `N_nf ≥ ⌈(n−2)j/(n−1)⌉`입니다.
- n = 7의 5906 route(D = 22, j = 1)는 N_nf ≥ 1이어야 하고, 실제로는 4와 6입니다.

**검증** (`fcheck182.py` → `certs/fcheck182.txt`).
- 대상: route 309개. archive n = 5 148개, n = 6 60개, n = 7의 다섯 길이 5906/5907/5908/5912/5913 각 ≤ 3개, 그리고 섭동, greedy, r = 0 route.
- 인스턴스는 검증기 A, B 모두 통과했습니다. RUN, F_ex, F의 위반은 **0**입니다.
- **등호:** n = 7 archive 5907 route(m = 20, r = 120, η = 3, N_nf = 0)와 5913 route(m = 0, η = 23)에서 여유가 0입니다. n = 5 archive 153도 등호입니다(n = 5는 정리의 가정 밖이지만 수치상 성립).

**국소 창 (n = 6, 7, 8, 9 각각에서 전수, 생략 없는 row).** `windows182.py` → `certs/windows182.txt`.
- 연속한 두 row의 charge 쌍은 모두 가능합니다.
- 연속한 세 row에서 불가능한 charge 삼중쌍은 네 n 모두에서 정확히 `(0,1,0), (0,1,1), (1,1,0), (1,1,1)`입니다.
- 즉 **내부의 charge-1 row는 charge ≥ 2인 이웃이 필요합니다.**
- 귀결: `N₁ ≤ 2N_{≥2} + 2τ`이므로 `N_nf ≤ (3/4)G + τ/2`입니다. **상수배 개선일 뿐이며, C1보다 약합니다.**
- 이것은 각 n에서의 유한 검증이고, 모든 n에 대한 증명은 아닙니다.

**국소 장애물은 없습니다.** charge-2 row만으로 된 trail을 단독으로 찾으면 n = 6에서 30, n = 7에서 82, n = 8에서 273 row였습니다(검증기 A 통과, `certs/lowcharge182.txt`). 따라서 NF는 단일 trail이나 국소 논법으로는 증명할 수 없고, 전역 packing 문제입니다.

## 5. 반례 탐색

**정리 Z (r = 0 실현 보조정리, 증명).**
- **가정:** trail τ개로 된 전역 packing이 생략 없는 row만으로 이루어지고, visible 순환류가 **모든** 순환류를 정확히 분할합니다.
- **구성:** 각 row의 각 visible 상태 x에서 그 순환류의 회전 n개(x, Rx, …, R^{n−1}x)를 차례로 방문합니다. row 순서, trail 순서를 따라 이어 붙입니다.
- **결론:** 이 route는 정규화된 덮개 route입니다.
  - `r = a = b = 0`, `k = row 수`, `m = k − ORB`, `η ≤ τ − 1`, `N_nf = non-full row 수`.
  - 단어 길이는 정확히 `CONST(n) + m + Σ_j (c_j − 3)`입니다. c_j ∈ [3, n]은 trail 경계 간선 τ−1개의 비용이고, `η = #{j : c_j ≥ 4}`입니다.
- **증명:**
  - 순환류 안의 간선은 R(비용 1)입니다.
  - row 안에서는 `N₂(R^{−1}x) = F(x)`(B3; R179 Lean `F_rot_eq_N2`)이므로 비용이 정확히 2입니다.
  - trail 안의 row 사이는 β = α이므로 겹침이 ≥ n−3입니다.
    - 비용 1이면 다음 순열이 x로 돌아가 이미 방문한 것입니다.
    - 비용 2이면 다음 순열이 Ry(방문함)이거나 F(y)(같은 block)입니다. 둘 다 불가능하므로 비용은 정확히 3입니다.
  - R²-간선은 모두 이미 방문한 순열을 가리키므로 정규화 조건이 성립합니다.
  - S는 visible 상태들이고 |S| = HEX이며 A = id입니다.
  - 길이는 `n + (N−HEX) + 2(HEX−k) + 3(k−τ) + Σ c_j`입니다. ∎
- **검증:** 이렇게 만든 route 100개 이상을 `bridge178.coarsen`으로 다시 분해했더니 매개변수가 모두 일치했고, 검증기 A, B를 통과했으며, n!개 순열을 모두 덮었습니다(`r0routes182`, `ttrail182`, `longT182`).
- **의미:** Bridge는 이 부류 위에서 전사(η ≤ τ−1까지)입니다. **따라서 r = 0 route에 대한 NF_A는 순수한 packing 명제와 동치입니다.** "생략 없는 정확 분할 packing에서 `N_nf ≤ θ(k − ORB + τ_min − 1)`"입니다.

- **관찰 (증명 아님):**
  - 긴 T-trail 하나(n = 7에서 77–78 row)를 먼저 놓으면, 남은 순환류에서 찾은 trail은 1–8 row로 무너집니다.
  - T-row 정확 분할이 N_nf/X → ∞인 반례가 되려면 τ = O(m)이어야 합니다. 그러면 비율은 ≈ (n−1)/2가 되지만, 그런 분할은 찾지 못했습니다.
- **결론:** NF(θ)는 θ ≥ 2.2에서 반증되지 않았습니다. 다만 소수의 n에서 얻은 수치로는 θ가 n과 무관하다는 것을 **추론할 수 없습니다.**

## 6. 수정된(amortized) NF와 Δ(n)으로의 귀결

**재구성 (Lean `FCore.nf_delta`, `nf_amort`).** 정리 F와 `N_nf ≤ θX + E`에서 다음이 나옵니다.

`ORB ≤ (n−2) + (n−1)E + ((n−2) + (n−1)θ)·X`

- E = 0이면 `D ≥ X ≥ ⌈(ORB − (n−2))/((n−2) + (n−1)θ)⌉`입니다. R181 공식과 같습니다.
- **반올림:** D가 정수이므로 올림이 정당합니다. θ는 실수 ≥ 0이어도 됩니다(Lean은 θ를 자연수로 검증했고, 실수 형태는 같은 한 줄 산술입니다).
- **영역:** n ≥ 6 (C1(0)).
- **숨은 가정:**
  - 정규화 (R178)
  - NF가 성립하는 인스턴스와 같은 인스턴스에 RUN을 적용할 것 (∃-형으로 충분)
  - `τ_used ≤ η+1+b`
  - `r ≤ (n−1)m`, `a ≥ 0`
- **E = λ·ORB/(n−1), λ < 1인 amortized 형태:** `X ≥ ((1−λ)ORB − (n−2))/((n−2)+(n−1)θ)`입니다.
  - E는 N_nf를 이름만 바꾼 것이 아니라 **(n−3)! 규모의 고정 예산**입니다.
  - 정리 F에 의해 λ ≥ 1이면 아무것도 나오지 않습니다(자명한 한계).
- **가장 약한 충분조건 (θ = 0):** 어떤 최적 route가 `N_nf ≤ (1−ε)(n−2)!/(n−1)`이면 `Δ(n) ≥ ε(n−3)! − 1`입니다. 역으로 `Δ(n) ≤ ε(n−3)!`이면 모든 최적 route가 `N_nf ≥ (1−ε)(n−2)!/(n−1) − O(1)`입니다.

**Δ(n)의 현황.**

| 구분 | 결과 |
|---|---|
| 무조건 | `Δ(n) ≥ ⌈2(n−2)((n−3)!−1)/(n²−4n+1)⌉ ≈ 2(n−4)!`(R178)이 여전히 가장 강한 **점근** 하한입니다. 정리 F 단독으로는 N_nf에 대한 무조건 상계(`N_nf ≤ G ≤ (n−1)m`)만 쓸 수 있어 `D ≥ (ORB−(n−2))/((n−1)²+(n−2))`이 되고, 이는 R178보다 약합니다 |
| 제한 (증명) | 정리 F1: `Δ(n) ≥ (n−3)! − 1 − ((n−1)/(n−2))·N_nf(최적)`. N_nf = O(1)인 최적 route, 또는 m = 0 부류에서는 Egan과 상수 1 차이까지 일치합니다 |
| 조건부 | NF_C(θ), θ = O(1)이면 `Δ(n) ≥ (1/(1+θ) − o(1))·(n−3)!`, 즉 Egan과 같은 **차수 Θ((n−3)!)**입니다 |
| 완화 packing | P-global(R181)에서도 같은 공식이 성립합니다. 정리 F는 R1–R2와 RUN만 씁니다 |
| 수치 | 모든 표본에서 N_nf/X ≤ 2.2입니다. 최적 route에서 N_nf는 n = 6에서 1, n = 7(5906)에서 4–6입니다 |

**점근 차수의 개선은 주장하지 않습니다.**

## 7. 장애물과 상계 구성

- 정리 Z는 **상계 방향의 구성 원리**입니다. 정확 분할 packing과 짧은 trail 경계만 있으면 길이가 `CONST + m + Σ(c_j − 3)`인 초순열이 나옵니다.
- 이번 witness들은 모두 유효한 초순열이지만 길습니다. n = 6에서 930–949(최적 872), n = 7에서 6280–6605(최적 ≤ 5906)입니다. **상계 개선은 없고, 개선이라고 주장하지 않습니다.**
- 정리 F에 의해, Egan 구성보다 j만큼 짧은 route는 non-full row를 ≥ (n−2)j/(n−1)개 가져야 합니다.
  - 따라서 상계를 개선하려는 r = 0 구성은 m이 작으면서 non-full row가 많은 정확 분할을 필요로 합니다. 이것이 바로 NF 반례가 요구하는 구조입니다.
  - 최소 route의 길이가 Egan보다 (n−3)!의 상수 비율만큼 짧아지면(Δ ≤ (1−ε)(n−3)!), 최적 route에서 NF가 필연적으로 깨집니다.

## 9. 다음 의무 (하나)

**생략 없는 row만으로 된 정확 분할 packing(정리 Z의 대상)에서, 다음 가운데 하나를 보이는 것입니다.**
- trail 수의 하한 `τ ≥ c·N_nf/(1+θ) − O(m)`을 n과 무관한 상수로 증명하거나,
- `N_nf/(m + τ) → ∞`인 무한족을 구성하는 것.

근거:
- 정리 Z에 의해 이것은 r = 0 route에 대한 NF_A와 **동치**이고, 순수 조합 문제입니다.
- 가장 유력한 후보는 T-row 정확 분할입니다. τ = O(m)이면 비율이 ≈ (n−1)/2가 됩니다.
- 정확 공식 쪽에서는 정리 F1에 의해 `Δ(n) = (n−3)! − 1 − (non-full row가 사는 절약)`입니다. 따라서 **최적 route의 N_nf가 (n−3)!의 어느 비율까지 올라갈 수 있는가**가 남은 핵심 양입니다.
