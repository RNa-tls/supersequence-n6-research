## 1. 정리 W 감사

**구성** (R180, special cₙ = n−1).
- 한 주기는 T row(길이 n−3, charge 2) 하나와 그 뒤의 full row n−4개입니다. 이것을 K = ⌊(n−3)/3⌋ 주기 반복하고, 끝에 full row 하나를 더합니다.
- 다음 start는 full row 뒤에서 φ(p), T row 뒤에서 `tm(s) = (s[n−2],)+s[:n−4]+(s[n−3],s[n−4],s[n−1])`입니다.

**독립 감사** (`r181/src/auditW181.py` → `certs/auditW181.txt`). R180 코드를 쓰지 않고 새로 구현했습니다.
1. start 사상을 직접 반복하는 시뮬레이션을 만들었습니다.
2. 증명에 적힌 기호 기술만으로 row 단어 다중집합을 따로 만들었습니다.
   - T-row 단어: `W_{j+1} = W_j`에서 위치 `c_j, c_j+1`을 교환, `c_j = n−5−3j (mod n−1)`
   - 주기 j의 row: 틀 `(W_j ∖ x_j, x_j)`, `x_j = W₀[c_j+1]`, `W_{j+1}`에서 x_j가 차지한 간격 이외의 n−3개 간격
3. 두 결과를 순환 단어 집합으로 비교했습니다. 서로 다름, row 수 `(n−3)K+1`, charge `2K`, 공통 special도 확인했습니다.
4. 결과: n = 7..40 **모두 일치**, 검증기 A(n ≤ 16) **통과**.

**상태 구분.**
- **증명됨:** 0 ≤ J ≤ K에서 `M_n(2J) ≥ (n−3)J + 1`. K 주기 접두부이며, 공통 special인 단어의 서로 다름이 Lemma U에 의해 ModelTrail과 동치입니다.
- **수치 결과만:** 주기 walk를 K 너머로 연장한 전체 길이 J(n)(R180 `growth180`, n ≤ 50). 증명에는 쓰지 않았습니다.

**정정된 affine 귀결.** LS(n; A, c)를 `∀g, M_n(g) ≤ A + c·g`로 두면, g = 2K에서 다음을 얻습니다.

`A ≥ 1 + (n − 3 − 2c)·K,  K = ⌊(n−3)/3⌋.`

- c = O(1)이면 A = Ω(n²)입니다. 예: n = 36, c = 1이면 A ≥ 342.
- c = (n−4)/2이면 A ≥ 1 + K ≈ n/3에 그칩니다. 예: n = 36이면 12.
- c ≥ (n−3)/2이면 제약이 없습니다.
- 따라서 **"c < (n−3)/2이기만 하면 2차 절편이 필요하다"는 주장은 틀렸습니다.** R180 요약표 8행이 이렇게 서술했으므로 여기서 정정합니다.

## 2. 정의 (정확한 전역 packing 개념)

**기본 대상.** 기호 집합은 [n]입니다.
- **순환류(class)**: 순열의 R-궤도(R = 한 칸 회전)이며, 모두 HEX = (n−1)!개입니다. 길이 n의 순환 단어와 같습니다.
- **block**: 순열의 F-궤도(F = 마지막 기호를 고정하고 앞 n−1개를 회전)입니다.
- **special symbol**: block의 모든 상태가 공유하는 마지막 기호 s입니다.
- **cyclic word**: block의 앞 n−1개 기호가 이루는 순환 단어 W입니다(길이 n−1, 기호 집합 [n]∖{s}).
- block은 쌍 `(W, s)`와 같습니다. special이 s인 block(s-block)은 ORB = (n−2)!개이고, 각 block의 상태 n−1개는 서로 다른 순환류에 속합니다.

**row 관련.**
- **row block**: marked row `(p, ℓ, Ω)`의 block, 곧 start p의 F-궤도입니다.
- **omitted position**: Ω ⊆ {1, …, ℓ−2}에 속하는 내부 위치입니다.
- **visible class**: 위치 `i < ℓ, i ∉ Ω`인 상태 `F^i p`의 순환류입니다.
- **hidden class**: row block의 순환류 가운데 visible이 아닌 것입니다. 그 수는 정확히 `charge = (n−1−ℓ) + |Ω|`입니다.
- **trail**: 연속 row가 `β(x) = α(y)`로 호환되고, row block이 모두 다르며, visible 순환류가 서로소인 row 열(ModelTrail)입니다.

**전역 packing.** trail들의 유한 모임 `𝒯 = (T₁, …, T_τ)`로서 **모든 trail의 모든 row에 걸쳐** 다음을 만족하는 것입니다.
- row block이 쌍마다 다릅니다.
- visible 순환류가 쌍마다 서로소입니다.

각 trail이 따로 ModelTrail이라고 해서 전역 packing이 되지는 않습니다. trail 사이의 서로소는 별도 조건입니다.

**route 실현 가능 packing과 P-global.** 전역 packing `𝒯`, 음이 아닌 정수 `(m, r, a, b, η)`, block 집합 P가 다음 **R1–R4**를 만족하면 이 셋을 **실현 가능 자료(admissible datum)**라 부릅니다. 모두 Bridge(n)과 UPL이 route에서 증명한 성질입니다.
- **R1**: `Σ|Tᵢ| = ORB + m − r + a`, `τ ≤ η + 1 + b`, `a ≤ r ≤ (n−1)m`.
- **R2**: 총 charge ≤ `(n−1)m − r`, 생략 run 총수 ≤ b.
- **R3**: `|P| = r − a`이고, P는 row block과 서로소입니다.
- **R4**: 어느 row에서도 보이지 않는 순환류는 모두 P의 어떤 block에 속합니다(UPL).

이 자료로 `P-global(n) := min (m + a + b + η)`를 정의합니다.
- 이것은 route가 없는 유한 조합 최적화 문제이므로 Δ(n)을 그대로 다시 쓴 것이 아닙니다.
- Bridge(n) + UPL에 의해 모든 정규화 route가 실현 가능 자료를 주므로 `P-global(n) ≤ D ≤ Δ(n)`입니다.
- **Bridge의 전사성은 가정하지 않습니다.** 따라서 `P-global(n) < Δ(n)`일 수 있습니다.
- 아래 §3–§7의 조건들은 모두 실현 가능 자료에 대한 **필요조건**입니다.

## 3. 공통 special 경쟁 (증명된 구조)

**보조정리 S (s-분할).** 각 s에 대해 s-block ORB개는 순환류 전체를 크기 n−1인 조각으로 분할합니다.
- 증명: 순환류(길이 n인 순환 단어)에는 s로 끝나는 회전이 정확히 하나 있고, 그 회전이 s-block 하나를 정합니다. 개수는 `ORB·(n−1) = HEX`로 맞습니다. ∎

**보조정리 FC (틀 덮기).** block `B = (W′, t)`, t ≠ s가 만나는 s-block은 `W ∖ t = W′ ∖ s`인 `(W, s)`뿐이며, 정확히 n−2개입니다. 그중 하나와는 순환류 2개를, 나머지 n−3개와는 1개씩을 공유합니다.
- 증명:
  - B의 순환류는 W′의 n−1개 간격 가운데 하나에 t를 끼워 얻습니다.
  - 그 순환류가 속한 s-block의 단어는 거기서 s를 뺀 것으로, `W′∖s`의 간격에 t를 끼운 것입니다.
  - W′의 간격 가운데 s 양옆 두 개는 `W′∖s`의 같은 간격으로 합쳐지고, 나머지는 일대일입니다. ∎
- R176 Lemma U(공유 ≤ 2)와 일치합니다.

**명제 K (경쟁).** 정규화 route의 Bridge 인스턴스에서 `k_s`를 special s인 row 수, `ν_s := ORB − k_s`로 둡니다. row block은 서로 다르므로 `k_s ≤ ORB`입니다.
- `Σ_s k_s = k = ORB + m − (r−a)`이므로 s ≠ s′에 대해 `ν_s + ν_{s′} ≥ ORB − m + (r − a)`입니다.
- 따라서 `ν_s < (ORB − m)/2`인 **지배 special은 많아야 하나**입니다. ∎

## 4. 증명된 packing 제약 — 정리 CS

**기호.** 기호 s에 대해 다음과 같이 둡니다.
- `Hid_s` := s-row들의 hidden 순환류의 합집합.
- `g_s := |Hid_s|`. 보조정리 S에 의해 s-row들의 hidden 집합은 서로소이므로, g_s는 s-row들의 총 charge와 같습니다.
- `ω_s := max_{B: special(B) ≠ s} |cls(B) ∩ Hid_s|`.
  - 자명하게 ω_s ≤ n−1입니다.
  - 보조정리 FC에 의해 `ω_s(B) ≤ Σ_{W ∈ 틀(B)} min(2, charge(W 위의 s-row))`입니다. 즉 B의 틀에 정렬된, charge를 가진 s-row만 기여합니다.

**보조정리 RUN.** n ≥ 6이면 모든 packing에서 `row 수 ≤ (n−2)·τ + (n−1)·N_nf`입니다. 여기서 `N_nf`는 charge ≥ 1인 row의 수입니다.
- 증명: 각 trail을 non-full row에서 자르면, full row만으로 된 연속 구간이 남습니다. 이 구간은 charge 0인 ModelTrail이므로 C1(g = 0), 즉 `M_n(0) = n−2`에 의해 row가 ≤ n−2개입니다. 구간 수는 ≤ τ + N_nf입니다. ∎

**정리 CS (모든 n ≥ 6, 모든 정규화 route, 모든 s).**

`ORB − (n−2) ≤ (n−2)(η+b) + ((n−2) + (n−1)ω_s)·m + (n−1)(1+ω_s)·ν_s`

**따름정리.** a ≥ 0이므로 `D + ν_s ≥ (ORB − (n−2)) / ((n−1)(1+ω_s))`입니다. 특히 ν_s = 0이면 `D ≥ (ORB − (n−2)) / ((n−2)+(n−1)ω_s)`입니다.

**증명.** `k_o := k − k_s`(special ≠ s인 row 수), `P := r − a`(payload block 수)로 둡니다.
1. **덮기.**
   - c ∈ Hid_s는 어떤 s-row에서도 보이지 않습니다. 보조정리 S에 의해 c를 포함하는 s-block은 하나뿐이고, 거기서 c는 hidden입니다.
   - 따라서 c는 special ≠ s인 row에서 보이거나(B11), 어디서도 보이지 않습니다. 후자라면 UPL에 의해 payload block에 속하며, UPL은 삼분법 세 경우 모두에서 성립합니다.
   - s-payload block은 보조정리 S에 의해 Hid_s와 만나지 않습니다.
   - 그러므로 `g_s ≤ ω_s·(k_o + P)`입니다.
2. **계수.** `k_o + P = (k − k_s) + (M − k) = M − k_s = (ORB + m) − (ORB − ν_s) = m + ν_s`입니다. 특히 `k_o ≤ m + ν_s`입니다.
3. **non-full 수.** non-full s-row는 charge가 ≥ 1이므로 `N_nf ≤ g_s + k_o`입니다.
4. **RUN.**
   - `k_s + k_o ≤ (n−2)τ + (n−1)(g_s + k_o)`이므로 `k_s ≤ (n−2)τ + (n−1)g_s + (n−2)k_o`입니다.
   - 여기에 `τ ≤ η+1+b`, `k_s = ORB − ν_s`, 그리고 1–2의 결과를 대입합니다. ∎

**검증 상태.**
- 산술 단계 4는 `r181/lean/CSCore.lean`의 `cs_core`와 `cs_corollary`로 core Lean 4.22에서 컴파일되었습니다. sorry는 없고, 공리는 propext와 Quot.sound뿐입니다(`certs/lean_cs181.txt`).
- 조합 전제 1–3은 종이 증명입니다. 근거는 보조정리 S와 FC, Bridge B11, UPL, R176–177의 C1(g = 0)입니다.
- **Bridge(n) 자체는 형식화되지 않았습니다.**

**반증 시도** (`cs181.py` → `certs/cs181.txt`). n = 6 route 32개(archive 12, 섭동 12, greedy 8)와 n = 7 route 5개에 대해 모든 s를 검사했습니다.
- `g_s = s-row 총 charge`, CS1 `g_s ≤ ω_s(m+ν_s)`, CS2, RUN: **위반 0**.
- 반례는 없습니다.

**NF 환원 (조건부).** `N_nf ≤ θ·D`(보조정리 NF(θ))가 성립하면 RUN과 `k ≥ ORB − (n−2)m`에서 `D ≥ (ORB − (n−2)) / ((n−2) + (n−1)θ)`입니다.
- 정리 CS는 지배 special(ν_s = 0)에서 NF(1+ω_s)를 증명하는 셈입니다.
- 수치 자료(`nfscan181`)에서 N_nf/D의 최댓값은 0.965입니다.
- NF는 단일 trail capacity로는 증명할 수 없습니다. 정리 W walk는 N_nf ≈ g/2이기 때문입니다.

## 5. payload 없는 극단점 (r = a = b = η = 0) — 네 수준

| 수준 | 상태 |
|---|---|
| 수치 | **존재.** R178 부등식의 실수 최적점 m = D* ≈ 2(n−2)(n−3)!/(n²−4n+1), τ = 1, k = ORB + m, charge = (n−1)m |
| 서로소 packing | **n = 6, 7에서 배제**(외부 Lean: Δ(6) ≥ 5 > 4, Δ(7) ≥ 14 > 11). **n ≥ 8에서는 미해결.** 정리 W의 기울기는 charge ≤ 2K = O(n)에서만 증명되었고, 필요한 charge는 (n−1)m = Θ((n−3)!)입니다 |
| ForestInstance / 실현 가능 자료 | **미해결.** 다만 새 필요조건이 있습니다(아래) |
| 진짜 route | **미해결** |

**극단점에서 새로 생기는 필요조건.**
- P = 0이면 R4에 의해 모든 순환류가 보여야 하므로 charge는 정확히 u = (n−1)m입니다.
- R179 명제 E대로 UPL은 여기서 공허하지만, **정리 CS는 공허하지 않습니다.** CS는 payload가 아니라 non-s row의 visible 순환류로 Hid_s를 덮는 것을 씁니다.
- 극단점이 실현되려면 **모든** s에 대해 `(1+ω_s)(m + ν_s) ≥ (ORB − (n−2))/(n−1)`이어야 합니다.
- m = D* ≈ 2(n−4)!이므로, 어떤 s에서 ω_s = O(1)이면 `ν_s ≥ (n−3)!/(1+ω_s)·(1 − o(1)) − 2(n−4)!`입니다. 즉 그 s는 지배 special일 수 없습니다.
- 명제 K와 합치면, 극단점은 **special이 균형을 이루거나, 지배 special의 ω가 Θ(n)**이어야 합니다.
- 정리 W walk 하나의 ω는 2입니다(n ≤ 16에서 계산). 같은 special의 walk를 이어 붙여도 ω_s가 O(1)로 유지된다면, 그런 극단점은 배제됩니다. **다만 이어 붙인 뒤에도 ω_s가 유계라는 것은 증명하지 않았습니다.**

## 6. n = 6 장애물의 일반화

R179 gap trail 1의 설정은 다음과 같습니다.
- row 22개가 모두 special 5이고, charge 14, P = 6입니다.
- 보이지 않는 순환류는 24개입니다.

**불변량 (숫자 6, 8이 아니라 구조).** 보조정리 S에 의해 `Inv = (Inv ∩ Hid_s) ⊔ (쓰이지 않은 s-block ν_s개의 순환류)`로 나뉩니다.
- 쓰이지 않은 s-block은 Inv 순환류를 n−1개까지 덮습니다.
- 다른 block은 보조정리 FC의 틀 정렬 때문에 `ω^I_s ≤ ω^H_s + (틀 안의 쓰이지 않은 s-단어 수) + 1`개만 덮습니다. 틀의 s-block 가운데 순환류 2개를 공유하는 것은 하나뿐이기 때문입니다.

**payload 부등식 PI (모든 n, 모든 s; 증명).** `P_s ≤ min(ν_s, P)`인 정수 P_s가 존재해서 다음 두 식을 만족해야 합니다.
- `|Inv ∩ Hid_s| ≤ ω^H_s·(P − P_s)`
- `|Inv| ≤ (n−1)P_s + ω^I_s·(P − P_s)`

여기서 ω^H_s, ω^I_s는 special ≠ s인 block이 `Inv ∩ Hid_s`, Inv와 만나는 최대 개수입니다. 증명은 정리 CS 1단계와 같은 덮기 논법이며, s-payload는 쓰이지 않은 s-block뿐입니다.

**n = 6에서 확인** (`cs181.py`, `n6anatomy181.py`).

| trail | special | 결과 |
|---|---|---|
| 1 | {5: 22} | ν = 2, \|Inv\| = 24, \|Inv∩Hid\| = 14 (s-단어별 3,3,2,2,2,2), ω^H = ω^I = 3. 첫 식에서 P_s ≤ 1, 둘째 식에서 24 ≤ 18 + 2P_s ≤ 20. 모순이므로 **PI가 기호적으로 배제**합니다. 최대 5개를 덮는 block은 쓰이지 않은 s-block 2개뿐이고, 6개 block으로는 ≤ 2·5 + 4·3 = 22 < 24입니다 |
| 2 | {5: 20, 3: 2} | 가능한 P_s ∈ {0, 1, 2}로 **PI가 배제하지 못합니다.** 상위 6개 겹침 합도 26 ≥ 24입니다. R179 전수 set-cover(최소 8)가 여전히 필요합니다 |

결론: PI는 실현 가능성의 필요조건이며 단일 trail capacity보다 강하지만, 충분조건은 아닙니다.

## 7. Bridge를 통한 route와의 관계

- 정규화 route는 Bridge(n) + UPL을 거쳐 실현 가능 자료(§2)를 줍니다. 이 방향만 씁니다.
- 실현 가능 자료에 대한 **기호적이고 검사 가능한 필요조건**은 단일 trail capacity(C1)보다 강하며, 다음 세 가지입니다.
  1. 모든 s에 대한 정리 CS
  2. 모든 s에 대한 PI
  3. 명제 K
- CS는 서로 다른 trail의 row들(non-s row)과 payload가 같은 Hid_s를 **함께** 덮어야 한다는 전역 조건입니다. 그래서 trail별 capacity 한계(R180 천장 정리)의 적용을 받지 않습니다.
- 전사성은 가정하지 않았습니다. 조건을 만족하는 packing이 route에서 온다는 주장은 하지 않습니다.

## 8. Δ(n) 정량화 (`certs/bounds181.txt`)

| n | R178 (무조건) | CS, ν_s = 0, ω = 2 (제한) | CS, ω = 3 (제한) | NF(θ = 1) (조건부) | m = 0 route (제한) | Egan 상계 |
|---|---|---|---|---|---|---|
| 7 | 11 | 7 | 5 | 11 | 23 | 24 |
| 8 | 44 | 36 | 27 | 55 | 119 | 120 |
| 9 | 219 | 219 | 163 | 336 | 719 | 720 |
| 10 | 1322 | 1551 | 1152 | 2372 | 5039 | 5040 |
| 12 | 74821 | 113400 | 84391 | 172800 | 362879 | 362880 |

- **무조건:** `Δ(n) ≥ ⌈2(n−2)((n−3)!−1)/(n²−4n+1)⌉ ≈ 2(n−4)!`(R178, 종이 증명)가 **여전히 가장 강합니다.**
  - 정리 CS를 무조건으로 쓰면 ω_s ≤ n−1과 ν_s ≥ 0만 쓸 수 있어 R178보다 약합니다.
  - **점근 차수 개선은 주장하지 않습니다.**
- **제한 모형 (증명됨):**
  - (a) 어떤 s에서 ν_s = o((n−3)!)이고 ω_s = O(1)인 route: `D ≥ (n−3)!/(1+ω_s)·(1−o(1))`, 즉 Θ((n−3)!).
  - (b) m = 0인 route: r = a = 0이고 모든 row가 full이며 k = ORB이므로, C1(g = 0)에서 `τ ≥ (n−3)!`, 곧 `D ≥ (n−3)! − 1`입니다.
    - 귀결: Δ(7) ≤ 22 < 23이므로 **n = 7 최적 route는 m ≥ 1이어야 합니다.** archive 5906 route는 실제로 m = 20과 24였습니다.
- **조건부:** NF(θ)가 성립하면 `D ≥ (ORB − (n−2))/((n−2)+(n−1)θ)`이고, θ = O(1)이면 Θ((n−3)!)입니다.
- **수치 (증명 아님):**
  - 정리 W walk의 ω는 n ≤ 16에서 항상 2입니다.
  - n = 6 route의 지배 s에서 ω_s ≤ 5이고, N_nf/D ≤ 0.965입니다.
  - n = 6 route는 모두 `ν_min/ORB ≥ 0.458`로 지배 special이 없습니다. 최적 route도 0.583–0.75입니다.
  - n = 7에서는 archive route 하나(m = 0, D = 28)만 ν = 0입니다.
  - 따라서 **최적 소규모 route는 CS가 강하게 작동하는 영역 밖**에 있습니다.

## 9. 정확 공식과 일치 구성

- 상계는 Egan의 Δ(n) ≤ (n−3)!입니다. n = 7에서 알려진 최선은 22 < 24입니다.
- 하계와 상계 사이에는 약 n/2배 차이가 남습니다.
  - 지배 special 영역: 차수가 Θ((n−3)!)로 정해졌습니다(제한 결과 (a)).
  - m = 0 영역: 상수 +1까지 일치합니다(`(n−3)!−1` vs `(n−3)!`). 다만 Egan 구성이 m = 0 영역에 속하는지는 이번 라운드에서 확인하지 않았습니다.
- 정확한 공식을 얻으려면 다음 둘 중 하나가 필요합니다.
  - (i) **균형 special 영역에서 D = o((n−3)!)를 내는 구성**: 극단점처럼 charge를 T row에 얇게 퍼뜨리는 trail들의 전역 packing이 필요합니다.
  - (ii) 그런 구성이 불가능하다는 NF형 하계.
- **(i)의 구성은 알려져 있지 않습니다.** §5에 따라 이런 구성은 모든 s에서 ν_s가 크거나 ω가 Θ(n)이어야 합니다.

## 10. 다음 의무 (하나)

**보조정리 NF(θ)를 θ = O(1)로 증명하거나 반증하는 것입니다.** NF(θ)는 모든 정규화 route의 Bridge 인스턴스에서 `N_nf ≤ θ·(m + b + η)`라는 주장입니다.
- 정리 CS에 의해 지배 special 영역에서는 증명되었습니다(θ = 1 + ω_s). 남은 것은 **균형 special 영역**입니다.
- 증명되면 Δ(n) = Θ((n−3)!)입니다.
- 반례라면, 그 route가 곧 Egan 상계를 차수에서 개선하는 구성입니다.
