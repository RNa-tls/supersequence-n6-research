## 1. 정의 (외부 Lean 정의에서 직접)

- `ModelTrail rows` (`SearchSound.lean`)는 세 조건입니다.
  1. 모든 row가 `Admissible`: 생략 위치 i가 `0 < i`, `i+1 < ℓ`.
  2. 연속 row가 `MarkedCompatible`: `β(x) = α(y.start)`.
  3. 모든 쌍이 `MarkedDisjoint`: block이 다르고 visible 육각형 집합이 서로소.
- `chargeSum rows = Σ charge`, 여기서 `charge = (n−1−ℓ) + |omitted|` (`Coarsen.lean`).
- **`M_n(g) := max { rows.length : ModelTrail rows, chargeSum rows ≤ g }`.** `CapTab.lean` 주석과 `modelTrail_length_le_capTab`의 가정 `chargeSum rows ≤ g`와 같습니다.
  - **총 charge**(trail 전체의 합)에 대한 조건입니다. row별 charge 조건이 아닙니다.
  - marked row(생략 있는 row)를 포함합니다. 생략 없는 모형이 아닙니다.
- 위치 규약(R175와 같음):
  - start `p = w₁…w_{n−1}s`의 row에서 상태 `Fⁱp`는 "W = ⟨w₁…w_{n−1}⟩에 s를 `wᵢ` 바로 뒤에 끼운 육각형"입니다(`w₀ := w_{n−1}`). 이것이 **위치 i**입니다.
  - row는 위치 `{0..ℓ−1} ∖ Ω`를 봅니다.
  - **위치 0과 위치 ℓ−1은 절대 생략되지 않습니다**(내부 조건).
- block은 (W의 순환류, s)로 결정됩니다.

**charge 2인 row의 완전한 목록.** `(n−1−ℓ) + |Ω| = 2`와 내부 조건으로부터 다음 셋뿐입니다.

| 이름 | ℓ | Ω | 숨기는 위치 | 존재 조건 |
|---|---|---|---|---|
| `T` (short row) | n−3 | ∅ | {n−3, n−2} | n ≥ 4 |
| `Lᵢ` (생략 1개인 loop) | n−2 | {i} | {i, n−2} | 1 ≤ i ≤ n−4 (n ≥ 5) |
| `M_ij` (생략 2개인 full) | n−1 | {i, j} | {i, j} | 1 ≤ i < j ≤ n−3 (n ≥ 5) |

**Lemma R0 (charge 분해).** `chargeSum ≤ 2`인 trail은 둘 중 하나입니다.
- (i) 모든 row의 charge가 ≤ 1이다.
- (ii) 정확히 하나의 row x가 charge 2이고, 나머지는 모두 charge 0이다.

charge 0인 row는 ℓ = n−1이고 생략이 없는 full row뿐입니다. ∎

## 3. 보편 도구: Lemma U (두 row의 공통 육각형)

**Lemma U.** 두 block (W, s), (W′, s′)에 대해 다음이 성립합니다.
- s = s′이면: 공통 육각형이 있을 필요충분조건은 W = W′(같은 block)입니다.
- s ≠ s′이면: 공통 육각형이 있을 필요충분조건은 `W∖s′ = W′∖s`(순환 (n−2)-단어로서)입니다. 이 단어를 E라 하면 두 block은 틀 (E, {s, s′})에 함께 속합니다.
  - `eₓ` := W에서 s′ 바로 뒤의 기호, `e_y` := W′에서 s 바로 뒤의 기호로 둡니다.
  - `eₓ ≠ e_y`이면 공통 육각형은 정확히 하나입니다. 위치는 x에서 `idx(prev_W(e_y))`, y에서 `idx(prev_{W′}(eₓ))`입니다.
  - `eₓ = e_y`이면 정확히 둘입니다. 위치는 `(idx(s′), idx′(prev_{W′}(s)))`와 `(idx(prev_W(s′)), idx′(s))`입니다.
  - 여기서 `idx`는 start에서의 1-기반 위치이고, n−1은 0으로 읽습니다.
- 두 row가 충돌할 필요충분조건은 어떤 공통 육각형이 **양쪽 모두에서 보이는** 것입니다.

*증명.*
- H가 공통이면 `H∖s = W`, `H∖s′ = W′`이므로 `H∖{s,s′} = W∖s′ = W′∖s`입니다.
- 역으로 E가 같으면, H는 E에 s′를 `eₓ` 앞에, s를 `e_y` 앞에 끼운 것이어야 합니다.
  - 두 틈이 다르면 H는 하나로 정해집니다.
  - 틈이 같으면 두 기호의 순서 두 가지가 가능합니다.
- 위치는 s가 W의 어느 기호 뒤에 오는지로 읽습니다. ∎

- R175의 틀 규칙(보조정리 4)은 Lemma U의 특수한 경우입니다.
- 검증기 B(§9)는 Lemma U만으로 서로소 여부를 판정하고, 육각형은 열거하지 않습니다.

## 4. charge-2 분류 (기호적, 모든 n ≥ 5)

**4.1 full row 다음(`r = u B y z`, `W = ⟨u B y⟩`, `s = z`).** 후보는 `q = B + (u,y,z의 순열)`입니다.

| q | Lemma U 유도 | 공통 (r 위치, q 위치) | 틀 관점 | 허용되는 q의 종류 |
|---|---|---|---|---|
| `B u y z = φ(r)` | s 같고 W 다름 | 없음 | 틀 보존, special 유지, 틈 +1 | 모두 |
| `B u z y = ψ(r)` | E = ⟨u B⟩, eₓ = u ≠ e_y = b₁ | (1, n−3) | 틀 보존, special 교환, 틈 +1 | q가 n−3을 숨김: **T, M_{i,n−3}** |
| `B y u z` | ⟨B y u⟩ = ⟨u B y⟩ | 같은 block | — | 없음 |
| `B y z u` | E = ⟨B y⟩, eₓ = e_y = b₁ | (0,0), (1, n−2) | 같은 틈, special 교환 | 없음 (위치 0) |
| `B z u y` | E = ⟨u B⟩, eₓ = e_y = u | (0, n−3), (n−2, n−2) | **r과 같은 틈**, special 교환 | q가 n−3, n−2를 모두 숨김: **T만** |
| `B z y u` | E = ⟨B y⟩, eₓ = b₁ ≠ e_y = y | (n−2, 0) | 다른 틈 | 없음 (위치 0) |

**4.2 x에서 full row로.**

(a) `x = M_ij` (β = B)에서 나갈 때: 같은 표에서 x가 첫째 성분입니다.
- 가능한 출구는 `φ(x)`와, i = 1일 때만 `ψ(x)`입니다.
- 나머지는 x가 볼 수밖에 없는 위치 0 또는 n−2, 혹은 full q가 보는 위치에서 충돌합니다.

(b) `x = Lᵢ` (loop, β = A, `x = A x y z`, W = ⟨A x y⟩)에서 나갈 때:
- 출구는 `A y x z`뿐입니다(s 같고 W 다름).
- 나머지 칸의 공통 위치는 다음과 같고(R175 표를 Lemma U로 재유도, 부록 A), 모두 x가 보는 위치 {0, n−3}과 full row가 보는 위치에서 충돌합니다.
  - `A x z y`: (0, n−2), (n−2, 0)
  - `A y z x`: (0, n−3)
  - `A z x y`: (n−3, 0)
  - `A z y x`: (n−2, n−3), (n−3, n−2)

(c) `x = T` (start `p = c₁…cₙ`)에서 나갈 때:
- `β(T) = D := c_{n−1}c₁…c_{n−4}` (R174 정리 2(a), ℓ = n−3).
- 남는 기호는 `v = c_{n−3}`, `w = c_{n−2}`, `z = cₙ`입니다.

| q | Lemma U 유도 | 공통 (T 위치, q 위치) | 틀 관점 | 허용 |
|---|---|---|---|---|
| `D v w z` | W 같음, s 같음 | 같은 block | — | ✗ |
| `D v z w` | E = ⟨c_{n−1}c₁…c_{n−3}⟩, 같은 틈 `c_{n−1}` | (n−2, n−2), (n−3, 0) | T의 틀, 같은 틈, special 교환 | ✓ (T가 둘 다 숨김) |
| `D w v z` | s 같고 W 다름 | 없음 | **새 틀**, special `cₙ` 유지 | ✓ |
| `D w z v` | E = ⟨c_{n−1}c₁…c_{n−4}c_{n−2}⟩, 틈 `c_{n−2}` ≠ `c_{n−1}` | (n−2, n−3) | 다른 틈, special 교환 | ✓ (T가 n−2를 숨김) |
| `D z v w` | 틈 `c_{n−1}` ≠ `c_{n−3}` | (n−4, 0) | 다른 틈 | ✗ (T는 n−4를 봄) |
| `D z w v` | 같은 틈 `c_{n−2}` | (n−3, n−3), (n−4, n−2) | 같은 틈 | ✗ |

- 위 두 표의 위치는 `witness176.py`가 n = 6..11에서 기계적으로 다시 계산했고, 모두 동일합니다.
- n = 5에서는 위치 1과 n−4가 같은 수라 이름표만 다르고, 내용은 같습니다(`certs/witness_176.txt`).

**4.3 종류별 최대 길이 (모두 기호 증명. 정확한 값은 구조 탐색으로 n = 5..12에서 확인).**

- **`M_ij`: ≤ n−2.**
  - 들어오는 전이는 φ, ψ뿐이고 나가는 전이도 φ, ψ뿐입니다(4.1, 4.2(a)).
  - 따라서 R, x, R′ 전체가 **하나의 틀** 안에서 연속된 틈을 차지합니다.
  - 길이 n−1인 row는 위치 0과 n−2를 항상 보므로, 틈이 같은 두 row는 같은 block이거나 충돌합니다(Lemma U).
  - 그러므로 틈은 서로 다르고 row 수는 ≤ n−2입니다. ∎
- **`Lᵢ`: ≤ n−2.**
  - 들어오는 전이는 φ뿐입니다(ψ는 n−3을, `B z u y`는 n−2까지 숨겨야 함). 나가는 전이는 `A y x z`뿐입니다.
  - R과 R′가 둘 다 비어 있지 않으면: R의 마지막 row는 `φ⁻¹(A x y z) = x A y z`이고 R′의 첫 row는 `A y x z`입니다. 둘 다 W = ⟨A y x⟩, s = z이므로 **같은 block**이어서 모순입니다.
  - 따라서 row 수 ≤ 1 + (n−3)입니다(Lemma E). ∎
- **`T`: ≤ 2n−5, 등호 성립(§6).**
  - 들어오는 전이가 ψ 또는 `B z u y`이면 |R| ≤ 1입니다. 그 앞 row `φ⁻¹r₀`와 T의 공통 육각형이 T의 위치 n−4에 오고, T는 그 위치를 봅니다(Lemma U).
  - 나가는 전이가 `D v z w` 또는 `D w z v`이면 |R′| ≤ 1입니다. 그 다음 row `φq₀`의 틈이 `c₁`이고, 공통 육각형이 T의 위치 0에 오기 때문입니다.
  - 2n−5는 **(φ 진입, `D w v z` 출구)** 조합에서만 가능합니다. 다른 조합은 위의 한계와 Lemma E에 의해 ≤ (n−3) + 1 + 1 = n−1 < 2n−5 (n ≥ 5)입니다.
  - 이 조합에서는 T가 주어지면 R = (φ⁻ᵏp), R′ = (φʲq₀)가 완전히 정해집니다. 그러므로 **최적 trail은 relabelling을 빼면 유일합니다**(기호적).
  - `struct176.py`도 n = 5..12에서 같은 결과를 줍니다(`certs/struct_176.txt`).

## 5. S1-U의 증명: 두 row 손실의 불변량

**Lemma F (full 구간).**
- 연속한 두 full row r, r′에 대해 `r′ = φ(r)`입니다(R174 정리 2(c). 증명은 4.1 표의 첫 행과 나머지 행들).
- 따라서 k개의 연속 full row는 `r, φr, …, φ^{k−1}r`입니다. 모두 r의 틀 (E, {a, σ})에 있고 special σ가 같으며 틈이 연속합니다.
- `φ^{n−2} = id`이므로 k ≤ n−2입니다.

**Lemma C (완전한 사슬이 틀 가족을 덮음).**
- 틀 (E, {a,σ})의 **가족**을 `𝔉(E,{a,σ}) := {H : H∖{a,σ} = E}`로 정의합니다. 원소는 (n−2)(n−1)개입니다.
- n−2개 full row의 φ-사슬은 이 가족을 정확히 덮습니다.
- *증명.* H ∈ 𝔉이면 `H∖σ`는 E에 a를 어떤 틈 e 앞에 끼운 것입니다. 그 틈의 full row가 H를 봅니다. 개수도 (n−2)(n−1)로 같습니다. ∎

**Lemma B (경계 상태).** full row r(start `r₁…rₙ`)과 임의의 row x에 대해 다음이 성립합니다.
- (B1) `α(x.start) = β(r)`이면, x의 **첫 상태**의 육각형은 `𝔉(틀 r)`에 속합니다.
  - `β(r) = r₂…r_{n−2}`이고 `x.start = r₂…r_{n−2}t₁t₂t₃`, `{tᵢ} = {r₁, r_{n−1}, rₙ}`입니다.
  - ⟨x.start⟩에서 `r_{n−1}`, `rₙ`을 지우면 `⟨r₂…r_{n−2}r₁⟩ = ⟨r₁…r_{n−2}⟩ = E_r`입니다.
- (B2) `β(x) = α(r)`이면, x의 **마지막 상태**의 육각형은 `𝔉(틀 r)`에 속합니다.
  - 마지막 상태를 `l = l₁…lₙ`이라 하면 `β(x) = drop 3 (lₙl₁l₂l₃…l_{n−1}) = l₃…l_{n−1}`입니다.
  - `r = l₃…l_{n−1}t₁t₂t₃`, `{tᵢ} = {lₙ, l₁, l₂}`이고, r의 틀은 (`⟨l₃…l_{n−1}t₁⟩`, {t₂, t₃})입니다.
  - ⟨l⟩ = ⟨l₃…l_{n−1}lₙl₁l₂⟩에서 세 남는 기호는 연속해 있으므로, t₂, t₃를 지우면 `⟨l₃…l_{n−1}t₁⟩`이 됩니다. ∎
- (B3) 첫 상태(위치 0)와 마지막 상태(위치 ℓ−1)는 절대 생략되지 않습니다(내부 조건).

**Lemma E (한쪽 손실).** trail의 최대 full-row 구간 R이 trail 전체가 아니면 `|R| ≤ n−3`입니다. 즉 R 옆에 어떤 row x든 있으면 그렇습니다.
- *증명.* |R| = n−2라고 가정합니다.
  - Lemma F와 C에 의해 R은 R의 틀 가족을 전부 덮습니다.
  - x가 R 뒤에 오면 x의 첫 상태(B1), 앞에 오면 x의 마지막 상태(B2)가 그 가족에 속합니다.
  - 그 상태는 x에서 보입니다(B3). 따라서 x는 R의 어떤 row와 visible 육각형을 공유하므로 모순입니다.
  - 이 논증은 x의 종류(길이, 생략, charge)와 **무관**합니다. ∎

**정리 S1-U. 모든 n ≥ 4에서 `M_n(2) ≤ 2n−5`.**
- *증명.* chargeSum ≤ 2인 trail을 Lemma R0로 나눕니다.
  - (i) 모든 row의 charge ≤ 1이면 R175 정리 B에 의해 ≤ n−1 ≤ 2n−5 (n ≥ 4)입니다.
  - (ii) 그렇지 않으면 trail은 `R x R′`이고 R, R′는 full-row 구간입니다. Lemma E에 의해 각각 ≤ n−3이므로 전체 ≤ 2n−5입니다. ∎

**"두 row 손실"의 정체.**
- charge 2가 row 두 개를 빼앗는 것이 아닙니다. **charge-2 row 양옆의 full 사슬이 각각 하나씩 완성되지 못합니다.**
- 이유는 경계 불변량입니다. 모든 row의 첫 상태와 마지막 상태는 생략될 수 없고, 이웃 full 사슬의 틀 가족 안에 반드시 떨어집니다.
- 완성된 사슬은 그 가족을 남김없이 덮으므로 이웃을 허용할 수 없습니다. 손실은 x의 종류와 무관한 **한쪽당 1**입니다.
- 이 사실이 S2의 재사용 부품입니다(§10).

## 6. S1-L의 증명: 명시적 기호 족 (모든 n ≥ 5)

기호 `c₁…cₙ`에 대해 다음과 같이 정합니다.
- `p = c₁c₂…cₙ` (short row T, 길이 n−3, 생략 없음, charge 2)
- `R = φ^{−(n−3)}p, …, φ^{−2}p, φ^{−1}p` (full row n−3개)
- `q₀ = c_{n−1}c₁…c_{n−4}c_{n−2}c_{n−3}cₙ`
- `R′ = q₀, φq₀, …, φ^{n−4}q₀` (full row n−3개)
- **trail = R, T, R′**: row 2n−5개, 총 charge 2.

*증명.*
1. **적법성.** 생략이 없으므로 모두 Admissible입니다. charge는 T가 2, 나머지가 0입니다.
2. **호환.**
   - 사슬 안에서는 φ입니다(β(full r) = α(φr)).
   - `φ⁻¹p → T`: `T.start = p = φ(φ⁻¹p)`.
   - `T → q₀`: `β(T) = c_{n−1}c₁…c_{n−4} = α(q₀)` (R174 정리 2(a), ℓ = n−3).
3. **모든 row의 special이 `cₙ`입니다.** 따라서 Lemma U에 의해, 모든 쌍이 서로소이고 block이 다를 필요충분조건은 **2n−5개의 W가 모두 다른 것**입니다.
4. **W의 두 족.**
   - `R ∪ {T}`: `E₁ = ⟨c₁…c_{n−2}⟩`에 `c_{n−1}`을 틈 `c₂, …, c_{n−2}` (R) 또는 `c₁` (T) 앞에 끼운 것. 서로 다릅니다.
   - `R′`: `E₂ = ⟨c_{n−1}c₁…c_{n−4}c_{n−2}⟩`에 `c_{n−3}`을 틈 `c_{n−1}, c₁, …, c_{n−4}` 앞에 끼운 것. 서로 다르고, 틈 `c_{n−2}`가 빠져 있습니다.
5. **두 족의 교집합.** W가 두 족 모두에 속하면 다음이 성립합니다.
   - `W∖c_{n−1} = E₁`이므로 `c_{n−3}`은 `c_{n−4}`와 `c_{n−2}` 사이에 있습니다.
   - `W∖c_{n−3} = E₂`이므로 `c_{n−1}`은 `c_{n−2}`와 `c₁` 사이에 있습니다.
   - 따라서 `W = ⟨c₁…c_{n−1}⟩ = W_T`이고, 이는 R′의 **빠진 틈** `c_{n−2}`에 해당합니다. 따라서 R′와 겹치지 않습니다.
   - 결론: 2n−5개 W는 모두 다릅니다. ∎

**구조적 의미.** T는 두 틀 E₁, E₂의 W-족이 만나는 **유일한 칸**에 있습니다. T는 R 사슬에서 빠진 칸(틈 c₁)이면서 동시에 R′ 사슬에서 빠진 칸(틈 c_{n−2})입니다. 그래서 두 사슬이 각각 한 칸씩만 잃고 이어집니다.

**검증.**
- 검증기 A(직접)와 B(틀 규칙)가 n = 5..14에서 모두 통과했습니다.
- n = 5..10에서 변형 17–27개를 모두 거부했습니다(§9).
- n = 4에서는 같은 구성의 R 첫 row와 q₀가 같은 block이 됩니다. 실제로 `M_4(2) = 2`입니다(A, B 전수). 그래서 S1의 영역은 **n ≥ 5**입니다.

## 10. C1에 대한 결과

**(a) S1이 주는 재사용 부품.** Lemma E는 국소 부등식입니다.
- "charge ≥ 1인 이웃이 하나라도 있는 최대 full 구간은 ≤ n−3".
- charge-2 분리자 하나당 양쪽에서 1씩, 합계 2의 손실을 줍니다.

**(b) 증명된 것: g ≤ 3에서 C1 (n ≥ 7).** C1은 `M(g) ≤ (n−2) + (n−3)g/2`입니다. g ≤ 3이면 charge ≥ 2인 row(분리자)는 최대 하나입니다.
- 분리자가 없으면: 정리 B에 의해 ≤ n−1 ≤ C1이고, charge-1 row가 없으면 ≤ n−2입니다. 여기에는 n ≥ 5가 필요합니다.
- 분리자가 charge 2이고 나머지 charge가 0이면: S1-U에 의해 ≤ 2n−5 = C1(2)입니다.
- 분리자가 charge 2이고 charge-1 row가 하나 있으면(g = 3):
  - row 수 ≤ (n−3) + (n−1) + 1 = 2n−3입니다(Lemma E, 정리 B).
  - C1(3) = (5n−13)/2이고, 2n−3 ≤ C1(3)은 n ≥ 7과 동치입니다.
- 분리자가 charge 3이면: ≤ 2(n−3) + 1 ≤ C1(3)입니다.
- n = 5, 6에서 g = 3은 수치로만 확인했습니다(marked `M(3)` = 5, 7 ≤ 6, 8.5).

**(c) 증명된 환원: S2의 정확한 의무.**
- 분리자 σ(charge ≥ 2)들이 trail을 최대 charge ≤ 1 구간 U(빈 구간 포함)로 나눕니다.
- 구간 U의 손실을 `ℓ_U := (n−2) − |U| + ((n−3)/2)·c_U`로 정의합니다(c_U는 U의 charge).
- 그러면 C1은 `Σ_U ℓ_U ≥ Σ_σ [(n−1) − (n−3)c_σ/2]`와 동치입니다. 대수 계산입니다.
- 우변의 각 항은 c_σ = 2일 때 2이고, c_σ ≥ 3이면 `(7−n)/2 ≤ 0`입니다.
- 좌변의 하한은 다음과 같습니다.
  - c_U = 0이고 한쪽 이웃만 있으면: ℓ_U ≥ 1 (**Lemma E, 증명**)
  - 빈 구간이면: ℓ_U = n−2 ≥ 2
  - c_U ≥ 1이면: ℓ_U ≥ (n−5)/2 (정리 B). n ≥ 9이면 ≥ 2입니다.
  - c_U = 0이고 **양쪽 이웃이 모두 분리자**이면: ℓ_U ≥ 2가 필요합니다. 이것이 **Lemma E2**이고 **미증명**입니다.

> **정리 (환원, 증명).** n ≥ 9이면 E2 ⇒ C1(모든 g)입니다. n ≥ 11이면 양쪽 이웃이 **모두 charge 2**인 경우의 E2만으로 C1이 나옵니다. charge ≥ 3 분리자의 여유 `(n−7)/2 ≥ 2`가 이웃 두 구간의 부족분을 메웁니다.

> **Lemma E2 (S2의 남은 의무).** 최대 full-row 구간의 양쪽 이웃이 모두 non-full(charge ≥ 2)이면 구간은 row가 ≤ n−4개다.

- **수치 근거** (`interior176.py`, `certs/interior_176.txt`):
  - n = 6, 7, 8, 9에서 이웃 charge ≤ 3이면 길이 n−3인 내부 구간이 **없습니다.**
  - n = 5에서는 charge-3 이웃이 있을 때만 예외가 있습니다. (2,2) 이웃에서는 없습니다.
  - 이것은 수치 패턴이고 **정리가 아닙니다.**
- **증명 계획.**
  - 구간 R(n−3개, 빠진 틈 e*)의 가족에서 덮이지 않은 부분은 빠진 칸의 block `B*` 하나뿐입니다.
  - Lemma B에 의해 x의 마지막 상태와 y의 첫 상태가 모두 `B*`에 떨어집니다. 각각 세 가지 경우가 있습니다: x는 B*의 위치 {n−2, 0, 1}, y는 {0, n−2, n−3}.
  - 따라서 x와 y의 block 쌍은 3×3 = 9가지로 정해집니다.
  - Lemma U로 각 쌍의 공통 육각형과 위치를 계산하고, charge 2인 row가 숨길 수 있는 위치 2개로는 모두 피할 수 없음을 보이면 됩니다.

**(d) C1은 아직 증명되지 않았습니다.** S1만으로는 C1이 나오지 않습니다. S1은 g = 2의 경우이고, (b)를 거쳐 g ≤ 3까지 갑니다.

## 11. Bridge(n) 구분과 Δ(n)

| 진술 | 상태 |
|---|---|

| Bridge(n) | **미증명**(일반 n) |

- `E2 ⇒ C1`은 증명했지만 E2 자체가 미증명입니다.
- `C1 + Bridge(n) ⇒ Δ(n) ≥ ⌈(n−2)((n−3)!−1)/((n−1)(n−3)/2 − 1)⌉`에서 Bridge(n)이 미증명입니다.
