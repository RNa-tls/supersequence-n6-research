# Area A: safe pruning ledger

## Scope

This ledger concerns the conditional no-repeat permutation-walk model at
`n=6`, restricted to

\[
F=1,\qquad H=0,\qquad N\le r,\qquad
(P,O,D)=(121,25,4)\text{ at completion}.
\]

Here `r=3` for Area A and `r=0` for the first small exact subcase.  A rule is
used by the macro engine only if it is a necessary condition.  In particular,
neither the old clean-cassette \(C_4/C_3\) argument nor a statistical
fragment archetype is used as a prune.

## Exact state and the macro boundary

The exact state is

\[
\Omega=(p;(M_H)_{H\in\mathcal H};(B_Q)_{Q\in\mathcal Q};F,S,H).
\]

`M_H` is the literal six-window occupancy mask and `B_Q` is the literal
five-phase pass-start mask.  Thus `extend` decides a tail by its only new
permutation window; its target membership test is exact because all tails are
indecomposable.  A macro state is not a coarser state: it is the same exact
state, sampled only at a joint boundary.  A macro edge records a legal
rotation run `w1^ell`, retaining every possible \(\ell\), followed by one
literal `w2` or `w3` joint.

## Rules installed in the engine

| label | condition | status and reason |
|---|---|---|
| `F_exceeded` | \(F>1\) | **proof.** The target has one abandonment and `F` is monotone. |
| `H_positive` | \(H>0\) | **proof.** Area A requires `H=0`; all weights at least four make `H` monotone positive. |
| `P_exceeded`, `O_exceeded` | \(P>121\) or \(O>25\) | **proof.** Both are monotone counts. |
| `N_exceeded_monotone` | \(N>r\) | **proof, using the blocked-\(w2\) lemma.** For a joint, \(\Delta N=\Delta S+\Delta F-\mathbf1_{\rm new\ orbit}\ge0\). A `w3` joint has \(\Delta S=1\); a `w2` joint can open a new orbit only after an abandonment, so \(\Delta F=1\). |
| `final_D_impossible` | no integer completion of `D=4` | **proof.** If \(a\) of the remaining \(r=121-P\) pass starts lie in new E-orbits, then \(D_{\rm final}=D-r+5a\), \(0\le a\le r\). Failing this congruence/capacity condition is impossible to repair. |
| `remaining_pass_starts_exceed_remaining_windows` | \(720-v<121-P\) | **proof.** Every remaining pass start contributes a new permutation window. |
| `remaining_cover_capacity_impossible` | \(720-v>5+6(121-P)\) at a macro boundary | **proof.** The current pass has at most five unused rotations; every future pass has at most one joint window plus five rotations. This ignores collisions, so it is only a necessary upper bound. |
| `F1_fragment_normal_form_impossible` | exact F≤1 partial-hex normal form fails | **proof.** With at most one abandonment, there is at most one non-current partial hexagon and at most `F+1` directed partial arcs. The exact mask state remains available for the check. |
| `insufficient_future_orbit_opening_credit` | needed E-orbits exceed remaining joint and abandonment credits | **proof, deliberately loose.** Each future joint can begin at most one E-orbit, and no more than `1-F` abandonment credits remain. |
| `collision` | a literal target window is already in `M_H` | **proof.** This is exactly the no-repeat constraint. |
| `memo_duplicate` | canonical exact child already seen | **proof for reachability.** Canonicalization is a quotient by the left `S_6` action, which commutes with every right tail. It is a child quotient; no strict canonical-parent assumption is made. |

## Candidate rules deliberately not installed

### Weight-three reachability

`H=0` restricts a deep joint to weight three, but it does *not* imply that a
weight-three joint stays inside a clean cassette.  The measured 87% clean
locality is therefore an experimental statistic, not a prune.

### Fragment repair rule

The exact state tests every `w1/w2/w3` target directly.  No assertion that a
repair must have a particular phase offset, must saturate a five-phase orbit,
or must be a two-arc hexagon is used: three-arc fragment hexagons occur in
valid data.

### Clean-interval \(C_4\) collision

The \(C_4/C_3\) proof is a theorem for the `F=0` complete-cassette regime.
An abandoned partial hexagon invalidates its block hypothesis.  Until a new
lemma explicitly verifies the hypothesis from the literal masks, this is
recorded only as a possible diagnostic annotation, never as pruning.

## Completion certificate

A successful terminal state must literally satisfy

\[
v=720,\quad P=121,\quad O=25,\quad D=4,\quad F=1,\quad H=0,
\quad N\le r.
\]

Since all 120 hex masks are then full and the state was generated by literal
tails without repeated targets, the unique fragmentation chronology is
already represented by the masks and pass-start phases; no additional
post-hoc repair assumption is made.

## Classification

The statements headed **proof** above are mathematical consequences of the
exact state definition and previously proved blocked-`w2` lemma.  The macro
engine separately runs finite literal-replay controls.  Any profile or
enumeration result remains a finite computation; no bounded profile is a
nonexistence proof.
