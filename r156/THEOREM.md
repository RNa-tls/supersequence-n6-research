# 추출 정리 (H.extract) — 복원·수리된 진술과 종이 증명

이 문서는 `src/l6_extraction_145.py` 가 **구현하는** 정리를, 구현을 정리로
받아들이지 않고 정의에서 다시 세운 것이다.  라운드 156 감사의 산출물이며
원본 문서(`src/l6_extraction_145.py` 도입부, `r149/PROOF.md` §3)는 **수정하지
않는다**.  두 원본의 진술과 이 진술이 어디서 갈라지는지는 §6 에 적는다.

## 0. 표기

`n >= 3`, `N = n!`, `r = n-1`, `HEX = N/n`.

`W` 는 **고정 대표원**(H.fixedrep): 선택 창 `q_1, ..., q_N` 의 모든 간격이
`omega` 와 같은 덮개.

* `sigma(w) = w[1:]+w[0]`, 육각형 = `sigma`-류 (`HEX` 개, 크기 `n`).
* `tau(w) = w[1:n-1]+w[0]+w[n-1]`, 궤도 = `tau`-류 (`N/r` 개, 크기 `r`).
* **pass** = 간격 1 인 선택 창의 극대 연속열.  pass `i` 는 `(v_i, l_i)`.
  `P` = pass 수, `G := P - HEX`.
* `nu(i)` := 진입점이 `sigma^{l_i}(v_i)` 인 pass ("같은 육각형의 다음 호").
* `alpha := nu + (* |-> *)`, `T` := `(P+1)`-순환 `0->1->...->P-1->*->0`,
  `beta := T alpha^{-1}`.  그러면 `beta(nu(i)) = i+1` (`i <= P-2`),
  `beta(nu(P-1)) = *`, `beta(*) = 0`.
* 접합 `i -> i+1` 은 보조정리 C 로 쌍 `(nu(i), i+1)` 에 재배정된다.
  `x = nu(i)` 에 대해 `w(x)` = 그 접합의 무게, `type(x)` = 카탈로그 유형.
  **쓰이는 유형 이름은 `E`, `A`, `B` 셋뿐이다**:
  `E`: `w=2` 이고 `v_{beta(x)} = tau(v_x)`;
  `A`: `w=2` 이고 `v_{beta(x)} = sigma(v_x)`;
  `B`: `w=3` 이고 `v_{beta(x)} = sigma^2(v_x)`.
  꼭짓점 `nu(P-1)` 과 `*` 은 유형을 갖지 않는다.
* `S = #{w(x) >= 3}`, `H = sum max(w(x)-3,0)`, `h = #{w(x) >= 4}`,
  `D2 = #A`, `Qs = #B`, `cleanE = #E`.
* `K = c(beta)`,
  `R_int = sum_{beta 성분 y} sum_f (|{x in y \ {*} : hex(x)=f}| - 1)`.
* `O` = pass 진입점의 서로 다른 궤도 수, `k = O - N/(n r)`.
* `blocks := P - cleanE`, `c` = 순수 성분 수(아래), **`B* := blocks - (O - c)`**.
* `g := (G+1-K)/2`, `z := G - c`, `Z := z - D2`, `d := K - 1 - c`.

## 1. 수입하는 가설 (각각 이미 증명된 노드)

* **(F)** H.fixedrep — `W` 는 고정 대표원이다.
* **(A,B,C,D)** H.splice 보조정리 A–D — 육각형의 호가 육각형을 분할하고
  (`P = HEX + G`), `nu` 는 순열이며 그 순환이 육각형이고, 접합 재배정이
  아무것도 바꾸지 않으며, `beta` 는 순열이다.
* **(E)** H.splice 보조정리 E — 간선이 전부 clean E 인 `beta` 성분("**순수**")은
  pass 를 정확히 `r` 개 가지며, 그 진입점이 **한 궤도의 `r` 원소 전부**이고,
  그 궤도에는 다른 pass 가 없다.
* **(K1)** H.catalogue — clean E 간선은 `v |-> tau(v)`: **같은 궤도**.
* **(K2)** H.catalogue — type A 는 `v |-> sigma(v)`, type B 는 `v |-> sigma^2(v)`:
  **같은 육각형**.
* **(LF)** H.splice 보조정리 F — `blocks = P - cleanE = S + 1 + D2`.
* **(I)** H.incidence — `R_int <= 2g` (§5 의 마지막 한 줄에서만 쓴다).

## 2. 추출의 정의 (수리된 형태)

`beta` 성분을 `Y_*`(`*` 를 포함하는 것), 순수 성분 `Y^pure_1..Y^pure_c`,
나머지 `Y^1..Y^d` (`d = K-1-c`) 라 하자.

1. **꼭짓점 `*` 을 지운다.**  이로써 유형 없는 두 간선 `nu(P-1) -> *`, `* -> 0`
   이 사라지고 `Y_*` 는 **경로**가 된다.
2. 순수 성분의 `r c` 개 꼭짓점과 그 `r c` 개 clean E 간선을 지운다.
3. 각 `Y^t` (`t = 1..d`) 를 **비-E 간선 하나**에서 **개방**한다.
   (비순수 성분은 정의상 비-E 간선을 갖는다.)
4. (분할 모형) 무게 `>= 4` 인 간선을 전부 자른다.  (병합 모형은 4 를 생략.)

남은 유향 그래프의 성분이 **사슬**이다.

> **1 단계가 이 정리의 수리 지점이다.**  `Y_*` 는 비-E 간선을 가질 필요가
> 없고(실측 40/794 사례), `*` 은 포트가 아니므로 사슬 안에 있어서도 안 된다.
> 원본 두 문서는 `d+1` 개 성분을 **전부** 비-E 간선에서 개방한다고 적었다.

## 3. 정리

위 표기에서, 임의의 고정 대표원 `W` 의 추출에 대하여:

**(0) 사슬은 잘 정의된다.**  결과 그래프의 모든 꼭짓점은 진입·진출 차수 `<= 1`
이고 살아남은 유향 순환이 없다.  사슬은 순수 성분 밖의 `P - r c` 개 pass 를
분할하고, 각 사슬은 **하나의 `beta` 성분 안**에 있다.  **clean E 간선은 3·4
단계에서 절대 잘리지 않는다.**

**(1) Claim 1.**  `sum_i P_i = P - r c = HEX + G - r c`.

**(2) Claim 2.**  `sigma_bar := sum_i O_i - (O - c)`, `D_i := r O_i - P_i` 라 하면
`sum_i D_i = r k - G + r sigma_bar`.  (`n=6`: `5k - G + 5 sigma_bar`.)

**(3) Claim 3.**  각 사슬에서 `blocks_i = O_i + tok_i`, 합하여
`sum_i tok_i = B* - sigma_bar`.

**(4) Claim 4.**  `0 <= sigma_bar <= B*`, 그리고 사슬이 하나면 `sigma_bar = 0`.

**(5) Claim 5.**  `rep_i` := 사슬 `i` 에서 육각형이 앞서 나온 포트 수.
`sum_i rep_i <= R_int`.  유지된 type A / type B 간선은 각각 서로 다른 반복
하나를 차지하므로, `a_i + bb_i + e_i = rep_i` (`e_i >= 0`) 로 쓰면
`sum (a+bb+e) <= R_int <= 2g`.

**(6) 사슬 수.**  개방 간선 중 무게 `>= 4` 인 것의 개수를 `s` 라 하면
`#사슬 = d + 1 + h - s <= d + 1 + h`.  병합 모형에서는 `#사슬 = d + 1`.

**(7) 행 예산 봉투.**  `a := sum a_i <= D2`, `bb := sum bb_i <= Qs`,
그리고 **`e := sum e_i <= Z - Qs`**.

## 4. 증명

### (0)

`beta` 는 순열이므로 모든 꼭짓점의 진입·진출 차수가 정확히 1 이다.  꼭짓점과
간선을 지우는 것은 차수를 늘릴 수 없으므로 결과는 경로와 순환의 분리합집합이다.
살아남은 순환은 간선이 하나도 지워지지 않은 `beta` 성분이어야 하는데, `Y_*` 는
`*` 에 붙은 두 간선을 잃었고, 순수 성분은 꼭짓점 전부를 잃었으며, 각 `Y^t` 는
개방 간선을 잃었다.  따라서 순환은 남지 않는다.  사슬은 `beta` 를 제한한 그래프의
연결 부분이므로 한 성분 안에 있다.  개방 간선은 선택상 비-E 이고, 무게 `>= 4`
간선은 clean E(무게 2)가 아니므로, clean E 간선은 잘리지 않는다.  ∎

### (1) Claim 1

3·4 단계는 간선만 지운다.  1 단계는 pass 가 아닌 `*` 을 지운다.  2 단계는
**(E)** 에 의해 순수 성분마다 정확히 `r` 개, 합해서 `r c` 개의 pass 를 지운다.
따라서 남은 꼭짓점은 순수 성분 밖의 `P - r c` 개 pass 이고, (0) 에 의해 사슬이
이들을 분할한다.  `P = HEX + G` 는 `G` 의 정의다.  ∎

### (2) Claim 2

**(E)** 로 순수 궤도에는 비순수 pass 가 없으므로, 사슬이 만나는 궤도는 순수
순환 밖의 `O - c` 개 궤도 중 하나다.  따라서
```
sum_i D_i = r sum_i O_i - sum_i P_i
          = r (O - c + sigma_bar) - (HEX + G - r c)
          = r O - HEX - G + r sigma_bar.
```
`O = N/(n r) + k` 이고 `HEX = N/n = r · N/(n r)` 이므로 `r O - HEX = r k`.  ∎

### (3) Claim 3

사슬 `(x_1, ..., x_p)` 를 고정한다.  `blocks_i` 는 clean E 간선의 극대 연속열
수이므로 `blocks_i = 1 + #{비-E 간선}`.  **(K1)** 로 clean E 간선은 궤도를
바꾸지 않으므로 **새 궤도를 열 수 없다**.  거꾸로 사슬이 만나는 `O_i` 개 궤도는
`x_1` 이 여는 하나와, 각 궤도를 처음 여는 간선(반드시 비-E)이 여는 `O_i - 1` 개다.
즉
```
#{새 궤도에 착지하는 비-E 간선} = O_i - 1,
tok_i := #{이미 연 궤도에 착지하는 비-E 간선},
#{비-E 간선} = (O_i - 1) + tok_i,
blocks_i = O_i + tok_i.
```
합하면 `sum blocks_i = (O - c + sigma_bar) + sum tok_i`.  한편 (0) 으로 clean E
간선은 잘리지 않았고, 지워진 꼭짓점은 `*` 과 순수 성분(간선이 전부 clean E,
성분마다 `r` 개)뿐이므로 살아남은 꼭짓점은 `P - r c` 개, 살아남은 clean E 간선은
`cleanE - r c` 개다.  clean E 부분그래프는 진입·진출 차수 `<= 1` 이고 순환이
남지 않았으므로 성분 수 = 꼭짓점 - 간선 :
```
sum_i blocks_i = (P - r c) - (cleanE - r c) = P - cleanE = blocks.
```
따라서 `sum tok_i = blocks - (O - c) - sigma_bar = B* - sigma_bar`.  ∎

*(이 마지막 등식이 보조정리 F 의 "순수 순환을 지워도 블록 수가 변하지 않는다"를
절단된 숲에 대해 다시 증명한 것이다.)*

### (4) Claim 4

순수 순환 밖의 모든 궤도는 비순수 pass 를 하나 이상 품고, 그 pass 는 어떤 사슬에
속한다.  따라서 사슬 궤도집합의 합집합이 그 `O - c` 개 궤도 전부이고
`sum_i O_i >= O - c`, 즉 `sigma_bar >= 0`.  사슬이 하나면 `sum O_i` 가 곧
합집합의 크기라 `sigma_bar = 0`.  `sigma_bar <= B*` 는 (3) 과 `tok_i >= 0`.  ∎

### (5) Claim 5

`rep_i = P_i - #{사슬 i 의 서로 다른 육각형}` 임에 주의한다.  `beta` 성분 `y`
와 육각형 `f` 를 고정하고, `y` 안의 `f`-꼭짓점이 `m` 개이며 `y` 안의 사슬들에
`m_1, ..., m_t` 로 나뉜다고 하자 (사슬들은 `y \ {*}` 를 분할한다).  그러면
```
sum_j max(m_j - 1, 0) = m - #{j : m_j >= 1} <= max(m - 1, 0),
```
이고 우변의 `f, y` 에 대한 합이 정확히 `R_int` 다.  순수 성분은 좌변에 0 을
기여하고 (지워졌다) 우변에 `>= 0` 을 기여하므로 부등호는 안전하다.  따라서
`sum_i rep_i <= R_int`.

유지된 `type(x_j) in {A, B}` 간선에 대해 **(K2)** 로
`hex(v_{x_{j+1}}) = hex(v_{x_j})` 이고 `x_j` 는 사슬에서 `x_{j+1}` 의 바로 앞이므로
`x_{j+1}` 은 육각 반복 하나를 차지한다.  `beta` 가 단사라 서로 다른 A/B 간선은
서로 다른 표적을 가지므로 서로 다른 반복을 차지한다.  또 A/B 간선의 표적이
사슬의 **첫** 포트일 수는 없다 — 그렇다면 그 A/B 간선 자신이 잘린 간선이다.
따라서 `a_i + bb_i <= rep_i`, `e_i := rep_i - a_i - bb_i >= 0`.  마지막으로
**(I)** 로 `R_int <= 2g`.  ∎

### (6) 사슬 수

1·2 단계 뒤의 그래프는 `d` 개 순환 + 1 개 경로다.  3 단계는 각 순환에서 간선
하나를 잘라 경로로 바꾸므로 성분 수는 그대로 `d + 1`.  4 단계는 무게 `>= 4` 인
`h` 개 간선을 자른다.  그 어느 것도 순수 성분(무게 2)에도, `*` 에 붙은 두 유형
없는 간선에도 있지 않으므로 `h` 개 전부가 그래프에 있다.  그 중 `s` 개는 개방
간선과 겹쳐 이미 잘렸고, 나머지 `h - s` 개는 각각 경로를 둘로 쪼갠다.  따라서
`#사슬 = d + 1 + h - s`.  4 단계를 생략하면 `d + 1`.  ∎

### (7) 예산 봉투

`a <= D2`, `bb <= Qs` 는 유지된 A/B 간선이 전체 A/B 간선의 부분집합이기
때문이다.  `e` 에 대해서는: type A 는 무게 2, type B 는 무게 3 이므로 **A/B 간선은
결코 heavy 절단 대상이 아니다**.  따라서 살아남지 못한 A/B 간선은 반드시
**개방 간선**이고, 개방은 정확히 `d` 개다:
```
(D2 - a) + (Qs - bb) <= d.
```
(5) 로 `a + bb + e <= 2g` 이므로, `z = 2g + d` 즉 `2g = z - d` 를 써서
```
e <= 2g - a - bb
   = 2g - D2 - Qs + [(D2 - a) + (Qs - bb)]
   <= 2g - D2 - Qs + d = (z - d) - D2 - Qs + d = z - D2 - Qs = Z - Qs.   ∎
```

> `r149/PROOF.md` §3 은 이 결론을 `e <= 2g - D2 - Qs = Z - d - Qs <= Z - Qs`
> 로 유도하는데, 첫 등호는 `a = D2` 이고 `bb = Qs` 일 때만 성립한다.  결론은
> 참이지만 **유도는 위의 "잘린 A/B 는 개방뿐, 개방은 `d` 개" 단계를 빠뜨렸다.**

## 5. 완화 방향 (실제 덮개 -> 모형)

각 단계의 성격:

| 단계 | 성격 | 포트에 대한 영향 |
|---|---|---|
| pass 생성 | 동치 변환 | 없음 |
| `beta` 성분 분해 | 분할 | 없음 |
| `*` 삭제 | 포트 아닌 꼭짓점 삭제 | 없음 |
| 순수 순환 삭제 | 정확한 삭제 | `r c` 개 감소, `required` 에 반영 |
| 개방 / heavy 절단 | 간선 삭제 | 없음 |

어떤 단계도 포트를 만들거나 복제하지 않는다.  따라서 실제 덮개는 좌표행 `C` 의
모형에 **허용되는 배치** 하나를 제공하고, 그 배치의 포트 합이 `required` 다.
모형은 최대화하므로 `bound_M(C) >= required` 여야 하며, `bound_M(C) < required`
는 그 좌표행의 덮개가 없음을 뜻한다.  사슬 수가 모형의 `d+1+h` 보다 **적어도**
건전하다: 남는 사슬에 예산 0 을 주면 되고 `cap(0,0,0,0,0) = 20 >= 0` 이므로
모형 값은 줄지 않는다 (`r156/certs/modelfeed_156.json`: 648 회 비교, 위반 0).
