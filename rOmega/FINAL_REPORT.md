# 최종 라운드 Ω 보고서: n = 8 종결 보고서

브랜치 `claude/n6-supersequence-length-rn17wf`, 디렉터리 `rOmega/`. 출발점은 Round Z의 커밋 `0cc7394`이다. 출발 상태표는
`rOmega/STATE_TABLE.md`(새 연구 전에 작성, §1 의무 표)이다.

증거의 종류를 끝까지 구분한다. **형식**(Lean 커널, 공리 명시), **전수**(정의역 전체를 빠짐없이 도는 정확 계산; 탐색이면
방문·유지 수가 Halfar의 수와 같음을 확인), **증명서 확인**(서로 다른 구현 둘이 같은 결과), **증명**(손 논증), **제한 가족**
(고정된 공개 16-trail 선택의 정해진 경로 가족 안에서만 참), **관측**·**가설**(하한도 상한도 아님). 시간 초과는 UNSAT이
아니고, 제한 가족의 결과는 전역 결과가 아니며, 가설 계산은 칸을 지운 것으로 세지 않는다.

## 0. 결론

* **두 결정적 결과 중 어느 것도 얻지 못했다.** 길이 ≤ 46172인 n = 8 초순열을 만들지 못했고, 모든 초순열이 ≥ 46173임을
  증명하지 못했다. 전역 구간은 그대로 **46134 ≤ L(8) ≤ 46173**이다. 표지: **L8_UNSOLVED_FINAL**.
* 46135 경계는 증명된 제약만으로 **34칸 → 27칸**이 되었다(§F). 새 도구는 **두 문턱 공존표**이다(§I):
  * 직선 2: 값 ≥ 231인 원시 부분은 값 ≥ 200인 다른 어떤 원시 부분과도 행이 겹치지 않게 공존할 수 없다(Compat₂(231, 200)
    거짓). 222–230의 부분은 219 미만의 부분과만 공존한다(Compat₂(222, 219) 거짓, Compat₂(222, 215) 참).
  * 직선 1: 값 ≥ 51인 원시 부분은 값 ≥ 43인 다른 원시 부분과 공존할 수 없고(Compat₁(51, 43) 거짓, (51, 42) 참), 값 ≥ 53인
    부분은 ≥ 42인 부분과 공존할 수 없다. 49–50의 부분은 48 이하의 부분과만 공존한다.
  * 이 표들은 θ = 200(직선 2), θ = 45(직선 1)의 **완전한** 배치 목록을 접두 축소로 정제해 정확히 얻었고(§I.1, Lean
    `coexistence_from_prefixes`), 핵심 "불가" 항목은 다른 코드(Round X의 `disjoint_bits.c`)로 쌍 목록을 직접 다시 판정해
    확인했다.
  * 배낭(수준별 사슬 유형 + 공존표)은 두 구현이 칸마다 최소 결손까지 같다: 상태 동적 계획(`frontier_compat.py`)과 특수
    사슬 배치 명시 열거(`frontier_compat_enum.py`).
* **(769, 0, 0)은 살아남는다(margin −4).** 이 칸은 "769행, 이음매가 모두 무게 3인 해밀턴 사슬"의 존재와 같다. Round Z의
  계수 완화에서 HiGHS가 중복 첨자 때문에 제약 한 줄을 **조용히 버리고 있었음**을 찾아 고쳤다. 고쳐도 결론(실행 가능)은
  같다. 기호 구간마다 직선 상한과 구간 사이 공존 제약을 더한 새 완화도 실행 가능하며, 명시적 해(거의 한 세계, 쪼개진
  2-순환 42개)를 냈다(§H). 남은 장애물은 셈이 아니라 d-걷기의 기하이다.
* 상한 쪽: 새 단어 없음. 세 46173 단어를 두 언어(상한의 Q, J / 하한의 R, N, Δ, W, M)로 같은 표에 놓았다. 세 단어 모두

## I. 긴 사슬 공존 상태

### I.1 두 문턱 공존표 (신규, 정확)

**정의.** FP(t) = 첫 도달 사슬(값 ≥ t, 모든 진부분 접두 < t; 정규 시작 12345678). Compat(a, b) = FP(a)의 사슬과 FP(b)의
사슬을 어떤 재표기 g ∈ S₈와 방향으로 놓아 클래스가 겹치지 않게 할 수 있다. Compat(a, b)가 거짓이면 해밀턴 경로에는 행이
겹치지 않는 원시 부분 둘(값 ≥ a, ≥ b)이 없다(각 부분의 첫 도달 접두가 그런 배치가 되므로; Round X의 X2′ 논법).

**계산(전수).** 기반 문턱 θ의 **완전한** 쌍 목록(모든 쌍, 모든 g, 두 방향; Round Z `disjoint_z.c`, 쌍마다
`disjoint_bits.c`와 일치)을 고정하고, 높은 문턱의 사슬마다 그 θ-접두를 찾아(언제나 목록에 있음을 assert), 목록의 배치마다
모든 연장 쌍의 클래스를 직접 비교했다(`rOmega/src/compat2d.py`, 클래스 계산은 C 도구와 독립). 접두가 클래스를 덜 가지므로
이 정제는 정확하다(Lean `coexistence_from_prefixes`). 목록의 배치 수가 줄의 개수 열과 같음을 assert했다(잘림 없음).
