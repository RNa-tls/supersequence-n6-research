## 3. 3단계 — 하한의 독립 재유도

1. **Bridge(n)이 주는 것.** row 수 = `k = ORB + m − r + a` (등식), trail 수 ≤ `τ = η + 1 + b`, charge ≤ `u = (n−1)m − r`.
   - 쓰는 것은 route에서 직접 정의한 양뿐입니다.
   - dictionary의 개별 등식 **a = Z, b = B\*는 쓰지 않습니다.**
2. **trail별 C1.** 각 trail은 `ModelTrail`이므로 `rowsᵢ ≤ (n−2) + ((n−3)/2)cᵢ`입니다.
   - 빈 trail도 만족합니다. k ≥ 1이므로 trail이 0개인 경우는 없습니다.
3. **합산과 정리.**
   `(n−2)! − (n−2) ≤ (n−2)(η+b) + β_n m + (1 − (n−3)/2) r − a`, 여기서 `β_n = (n²−4n+1)/2`.
4. **허용 매개변수에 대한 최소화.**
   - n ≥ 5에서 r의 계수 ≤ 0이고 a의 계수 < 0입니다.
   - `β_n ≥ n−2`이므로, 주어진 D에서 우변이 가장 큰 경우는 **r = a = 0이고 D가 모두 m에 들어간 경우**입니다(§5에서 사용).
   - 따라서 `D ≥ 2(n−2)((n−3)!−1)/(n²−4n+1)`입니다.
5. **정수와 분모.** 분모는 n ≥ 4에서 양수입니다. D가 정수이므로 올림이 정당합니다.
6. **`Δ(n) ≥ D`.** 경로 공식, 정규화, `L_c ≤ n + 무게`에서 나옵니다.
7. **n = 6 경계.** 하한 4는 실제 Δ(6) = 5 이하입니다. 외부 Lean은 D ≥ 5를 보였고, 이와 모순되지 않습니다.
8. **퇴화 경우.** m = 0이면 u = 0, r = 0입니다. 이때 k = ORB + a개 row가 full이고, 식은 그대로 성립합니다.

**작은 n 대조.** 하한은 n = 6, 7, 8, 9에서 4, 11, 44, 219입니다.
- 알려진 값: Δ(6) = 5, Δ(7) ≥ 14 (Lean), Δ(7) ≤ 22, Δ(8) ≤ 119, Δ(9) ≤ 720.
- 모순이 없습니다.

**Liu와의 비교.** 6 ≤ n ≤ 300의 정확 계산일 뿐입니다. **모든 n에 대한 우월성은 주장하지 않습니다.**

## 5. 5단계 — payload 구조

**정리 UPL (보편 payload 보조정리, 모든 n ≥ 4, 삼분법 세 경우 모두).** Bridge(n) 인스턴스에서 다음이 성립합니다.
- (a) 각 row block의 **모든 선택 상태(run start)가 visible**입니다.
- (b) row의 visible 순환류에 속하지 않는 순환류는 모두 run start를 **row block이 아닌 touched block**에만 갖습니다. 그런 블록은 정확히 `M − k = r − a`개입니다.

*증명.*
- (a) row 구간은 block에서 남긴 gap의 구멍만 뺀 것이고, 생략 위치는 구간 안의 구멍뿐입니다. 따라서 선택 상태는 모두 보입니다.
- (b) 모든 순환류는 run start를 가집니다(B2). 순환류 C의 run start가 row block에 있으면 (a)에 의해 C는 보입니다. 따라서 보이지 않는 C의 run start는 row block 밖에 있고, run start를 포함하므로 touched block입니다. ∎

외부 Lean은 이 조건을 (iii)에서만 기록했습니다(`ForestInstance.payload_cover`). 이번 정리로 (i), (ii)에서도 성립함이 증명되었습니다. `audit179.py` T4는 세 경우 모두 route 50개에서 위반 0이었습니다.

**명제 V (payload의 개수 조건은 공허함).** `CoarsenedInstance(k = ORB+m−r+a, τ, u, b)`에서 charge ≤ u이면, 보이지 않는 순환류 수는 ≤ `HEX − ((n−1)k − u) = (n−1)(r−a) − r ≤ (n−1)(r−a)`입니다.
- 즉 payload 블록 r − a개의 순환류 용량만으로는 **개수 조건이 항상 만족됩니다.**
- 따라서 payload가 무언가를 배제하려면 §4처럼 **어느 순환류가 어느 블록에 있는지**를 써야 합니다.

**명제 E (극단점에서 payload는 비어 있음).** §3의 4단계에서, R178 하한을 결정하는 매개변수는 `r = a = b = η = 0, m = D`입니다.
- 이때 τ = 1, k = ORB + m = M(모든 touched block이 row block), payload 블록은 r − a = 0개입니다.
- b = 0이므로 경우 (iii)이고 charge = u = (n−1)m입니다. visible 순환류 합이 정확히 HEX이므로 row들이 **모든 순환류를 정확히 분할합니다.**
- UPL은 이 경우 공허합니다.

## 6. PC1과 삼분법

**PC1의 정의 (payload coverage capacity).**
- 대상: `CoarsenedInstance(k, τ, u, b)`와 row block에서 서로소인 블록 집합 P(|P| = r − a)의 쌍으로, UPL (b)를 만족하는 것.
- 덮기 관계: 순환류 C가 P에 덮인다 ⇔ 어떤 블록 B ∈ P가 순환류 C의 상태를 포함한다. 즉 C∖t를 W로, t를 special로 갖는 블록이 P에 있다.
- 찾는 부등식: `k ≤ (n−2)τ + λ(n)u + P(n, r−a)`.

**상태.**
1. **payload로 λ를 줄이는 것은 불가능합니다(증명).**
   - 명제 E에 의해, 하한을 결정하는 경우는 `r − a = 0`인 단일 trail 정확 분할입니다. 거기서 payload 항과 덮기 조건이 사라집니다.
   - 따라서 P가 payload 크기에만 의존하는 한, PC1은 그 경우에 순수 capacity 부등식 `ORB + m ≤ (n−2) + λ(n−1)m`으로 줄어듭니다.
   - 결론: **λ(n) = O(1)을 PC1이 아니라 단일 trail capacity 자체에서 얻어야 합니다.**
2. **λ = O(1)의 반례 시도.**
   - 작은 g에서는 `M(2) = 2n−5`이므로 **절편이 (n−2)인 균일 선형 상한에서 λ ≥ (n−3)/2가 강제됩니다.** 즉 λ = O(1)은 절편을 키우지 않는 한 **거짓**입니다.
   - 절편 A를 허용하면 문제는 **큰 charge에서의 기울기**로 옮겨갑니다.
3. **삼분법별 처리.**
   - (iii): UPL과 명제 E. (i), (ii): UPL은 성립하지만 charge가 u보다 작을 수 있고(ii) 생략 run이 있습니다(i).
   - 세 경우 모두 C1 기반 유도에서는 같은 극단점으로 줄어듭니다. 극단점은 b = 0이므로 (iii)입니다.
   - (i), (ii)를 위해 따로 쓴 경계는 없고, (iii)의 결론을 (i), (ii)에 적용하지 않았습니다.
   - 세 경우 공통의 payload 불변량은 **UPL**입니다.

## 7. 구체적 결과 — 하나의 보조정리로의 환원

**LS(n; A, c) (큰 charge의 단일 trail 기울기, 미증명):** 모든 g ≥ 0에 대해 `M_n(g) ≤ A + c·g`, c ≥ 1.

**정리 (환원).** `Bridge(n) + LS(n; A, c)` ⇒ `Δ(n) ≥ ⌈((n−2)! − A) / max(A, c(n−1) − 1)⌉`.
- 증명: Bridge 인스턴스의 τ개 trail에 LS를 적용해 합하고, §3과 같은 계수 논증을 씁니다(c ≥ 1이면 r의 계수 ≤ 0).
- 산술은 Lean `ls_core`로 검증했습니다(기울기 c/d, 분모를 없앤 형태).

**따름정리 (조건부).** A = αn + O(1), c = O(1)이면 `Δ(n) ≥ (1 − o(1))·(n−3)!/max(α, c)`입니다.
- Egan 상계 `Δ(n) ≤ (n−3)!`와 **차수가 같아집니다.**
- 즉 Bridge(n)은 증명되었으므로, **Δ(n) = Θ((n−3)!)는 LS 하나로 환원됩니다.**
- 참고로 C1은 LS(n; n−2, (n−3)/2)이고, 이것이 `≈ 2(n−3)!/n`의 원인입니다.

**LS에 대한 증거 (유한 범위 관찰일 뿐, 증명 아님; `certs/slope_fit_179.txt`).**

| 자료 | 범위 | 관찰 |
|---|---|---|
| n = 6 B(u) (논문) | u ≤ 20 | `M ≤ 8 + u`가 성립. 끝 8단계의 평균 기울기 1.125 (C1 기울기 1.5) |
| n = 7 capTab (Lean 인증) | g ≤ 36 | 끝 8단계의 평균 기울기 1.75 (C1 기울기 2). `c = 1`로 맞추려면 필요한 절편이 범위 안에서 계속 커짐(g = 36에서 30) |

n = 7 자료는 c ≈ 1을 **지지하지 않습니다.** 증명이 필요한 영역은 하한을 결정하는 g ≈ 2(n−2)!/n 부근입니다(n = 7에서 대략 g ≈ 66–84). 이는 인증된 범위 밖입니다.

## 8. 가장 강한 정당화된 일반 하한

- **n ≥ 6:** `s(n) ≥ n! + (n−1)! + (n−2)! + n − 3 + ⌈2(n−2)((n−3)!−1)/(n²−4n+1)⌉`.
  - 근거는 C1 + Bridge(n)이며, 둘 다 종이 증명입니다. 이번 감사를 통과했고 부분적으로 형식화되었습니다.
  - 외부의 독립 검토 전까지는 "증명됨(비형식)"으로 표기해야 합니다.
- **형식 검증된 일반 하한으로는 여전히 Liu가 최강입니다.**

## 9. 정확 공식까지의 장애물

1. **LS:** 큰 charge에서 단일 trail capacity의 기울기가 O(1)인지. 참이면 Δ(n) = Θ((n−3)!).
2. 차수를 넘어 **정확한 선행 상수**를 얻으려면 다음 둘을 모두 해야 합니다.
   - 하한 쪽에서 `max(α, c) → 1`인 LS를 증명하는 것.
   - 상한 쪽에서 Egan 구성 `(n−3)!`의 최적성을 보이는 것. n = 7에서 이미 22 대 14의 간격이 있습니다.
3. payload(UPL)는 참이지만 극단점에서 공허합니다. 따라서 정확 공식에 필요한 정보는 **단일 trail의 전역 구조**, 곧 큰 charge에서 순환류를 정확히 분할하는 trail에 있습니다.
