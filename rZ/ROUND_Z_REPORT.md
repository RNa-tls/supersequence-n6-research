# Round Z 보고서: 긴 사슬의 공존과 769행 장벽

증거의 종류를 끝까지 구분한다. **증명**(손으로 쓴 논증, 산술은 Lean), **전수 계산**(정의역 전체를 빠짐없이 도는 계산; 탐색이면 방문·유지 수가 Halfar의 수와 같음을 확인), **증명서 확인 계산**(서로 다른 구현 둘이 같은 결과), **제한 가족 정리**(정해진 가족 안에서만 참), **관측**(일부만 본 계산, 휴리스틱), **가설**(참인지 모르는 명제를 넣었을 때의 계산). 가설 계산은 칸을 지운 것으로 세지 않는다.

* **L(8) ≥ 46135는 증명하지 못했다.** 표지: **L8_UNSOLVED**. 공존 정리가 39칸을 모두 지우지 못했으므로 N8_LONG_CHAIN_COEXISTENCE는 붙이지 않는다.
* **46135 경계: 40칸 → 35칸**(증명된 제약만 씀, §F). 새 공존 정리 셋으로 다섯 칸이 지워졌다.
  * **κ₁(45) ≤ 2** (직선 1): 덮개 하나에 직선 1 값 ≥ 45인, 서로 행이 겹치지 않는 원시 부분은 많아야 둘이다(Round X는 46).
  * **X2(222)** (직선 2): 직선 2 값 ≥ 222인 원시 부분은 모두 한 사슬에 있고 한 행을 공유한다(Round X는 230). **문턱은 정확하다**: 221에서는 거짓이다. 반례는 165행 v₂ = 221 사슬 두 종류의 배치 셋뿐이다.
  * **κ₂(210) ≤ 2** (직선 2): 직선 2 값 ≥ 210인, 서로 행이 겹치지 않는 원시 부분은 많아야 둘이다.
  * 지워진 칸: **(764, 5, 0)**(R = 764의 마지막 칸), **(765, 4, 3)**, **(767, 2, 8)**, **(768, 1, 9)**, **(769, 0, 9)**. 이제 경계는 R = 765–769이다.
  * 문턱은 모두 정확하다: **κ₁(44) ≤ 2는 거짓**이고(110행 v₁ = 44 사슬 셋이 한 기호 세계에 서로 겹치지 않게 놓인다, 독립 검사기로 확인), X2는 221에서 거짓이다. 직선 1 묶음은 45에서 끝난다.
* **기호 일관성(전수 계산)**: 시험한 모든 문턱에서 겹치지 않는 배치가 **모두 이동 기호를 지킨다**(g(8) = 8). 직선 1은 θ₁ = 48에서 77개, 47에서 89개, 46에서 761개, 45에서 873개, 44에서 6,794개이고, 직선 2는 θ₂ = 221–219에서 3개, 215에서 89개, 210에서 154개이다. 다른 기호의 배치는 하나도 없다. 높은 사슬끼리의 공존은 같은 기호 세계 안에서만 일어난다.
* **기호 변화의 값(전수 계산)**: 모든 사슬은 **4r − 9d + 4L ≤ 56**을 만족한다(L = 기호를 바꾸는 b/c/f 이음매 수). 탐색은 282억 사슬을 방문했고, 최댓값 사슬은 독립 검사기로 확인했다. 기호 변화 하나는 직선 1 값 4(결손 4/9)만큼 비싸다. 따름: 경계 덮개의 기호 변화는 칸마다 많아야 L 예산(§F 표)이고, **(769, 0, 0)의 사슬은 기호를 많아야 16번 바꾼다**(Lean).
* **전역 보조정리(증명, 실제 단어 셋에서 확인)**: 6블록 행 보조정리 P6 ≤ M + E + 2L + 2n, 완전 행 연속의 전역 셈, 두 기호 블록 항등식 W = 7Σ_B(a_B + b_B − 6), 이음매 입구 항등식(b는 앞 행 2-순환의 다음 클래스로 들어간다 등). 블록 하나를 호로 덮는 방법을 모두 열거했다.
* **정확한 남은 장애물(§ 남은 장애물)**: 35칸 가운데 28칸은 묶음 수를 직선 2 θ₂ = 180, 직선 1 θ₁ = 40까지 가정해도 지워지지 않는다. 묶음 논법의 한계이다. 높은 직선 2 부분이 둘인 18칸은 θ₂ = 210의 겹치지 않는 배치 154개(쌍 80개) 가운데 하나를 덮개 안에 실현해야 한다. 다음 라운드의 유한 대상은 이 목록이다.
* **(769, 0, 0)은 살아남는다(margin −5 → −4).** 이 칸은 "769행, 이음매가 모두 무게 3인 해밀턴 사슬이 있는가"와 정확히 같다(§G). 769행 사슬의 결손은 비둘기집 원리로 언제나 ≥ 343이고, 등호는 해밀턴일 때뿐이다. 따라서 "결손 < 344인 769행 사슬"을 따로 열거할 대상이 없다. 증명된 필요조건(기호 ≥ 2개, 기호 변화 ≤ 16, 경우 B의 두 끝 등)을 모두 넣은 계수 완화는 실행 가능하다(명시적 해, §H). 남은 장애물은 셈이 아니라 d-걷기의 기하이다.

### A.3 다른 기호의 공존이 없는 이유

* 완전-완전 보조정리(Round Y): 기호가 다른 두 사슬의 완전 행은 같은 {z, s}-블록에 함께 올 수 없다. 높은 사슬은 {8, s}-블록 120개 중 45–93개에 완전 행을 두므로, 이 판정 하나로 쌍의 96% 이상에서 다른 기호의 배치가 모두 배제된다. 나머지 (s, y) 조합(θ₁ = 44에서 40,597,014개)을 클래스 단위로 모두 판정했고 살아남은 배치는 없다.
* 그래서 지금까지의 모든 문턱에서 **"높은 효율 ⇒ 한 기호 세계에 집중"**은 관측이 아니라 전수 계산된 사실이다. 일관성이 깨지는 문턱이 있다면 θ₁ < 44, θ₂ < 210에 있다. 그 아래는 첫 도달 사슬이 많아(θ₁ = 42: 22,429개, 쌍 2.5억) 이번에 계산하지 않았다.

## B. 쌍과 덮개 전체의 공존 정리

**정리 Z-B1 (κ₁(45) ≤ 2).** σ²-환원 해밀턴 경로에서 앞쪽 또는 뒤쪽 원시이고 직선 1 값 ≥ 45이며 서로 행이 겹치지 않는 부분 사슬은 많아야 둘이다.
* 증명: Round X 보조정리 X2′의 논법 그대로이다. 셋이 있으면 각자의 첫 도달 접두(뒤쪽 원시는 뒤집어서)가 재표기로 첫 도달 목록의 사슬이 되고 서로 겹치지 않는다. 목록의 쌍 판정(A.2, 두 구현이 쌍마다 같음)이 겹치지 않는 배치를 모두 내고, 삼중 판정은 두 구현(`rX/csrc/triple_test.c`, 그리고 합집합을 의사 사슬로 넣은 `disjoint_z.c`: 4,256,748쌍) 모두 셋째를 찾지 못했다.
* 실제 단어와의 대조: 세 46173 단어의 사슬에서 가장 높은 부분 값은 직선 1 33(r = 0 단어 둘은 24), 직선 2 140(102)으로 문턱 45, 210, 222보다 낮다(`rZ/src/word_max_windows.py`). 이 정리들은 실제 단어를 배제하지 않는다.

**반례 Z-B1′ (κ₁(44) ≤ 2는 거짓).** θ₁ = 44 첫 도달 목록에는 서로 겹치지 않게 놓이는 사슬 셋이 있다. 예: 110행 d = 44(v₁ = 44) 사슬 둘(#1125, #8350)로 만든 X, g(Y), h(Z)이고, 각각 726클래스, 셋 모두 기호 8이다. 삼중 판정 도구가 (배치, Z) 조합 40개 이상을 찾았고(그 뒤 멈춤), 그중 하나를 공유 코드 없는 파이썬 검사기(`rZ/src/verify_triple.py`)가 재표기 h를 직접 찾아 서로 겹치지 않음을 다시 확인했다. 따라서 **κ₁ ≤ 2가 성립하는 가장 낮은 문턱은 정확히 45**이다. κ₁(44) ≤ 3을 가정해도 배낭은 35칸 그대로이다(가설).

**정리 Z-B2 (X2(222)).** 직선 2 값 ≥ 222인 원시 부분은 모두 한 사슬 Q*에 있고 한 행을 공유한다. 221에서는 성립하지 않는다(A.2의 반례).
* 증명: Round X 보조정리 X2와 같다(쌍마다 공통 행, Helly). 첫 도달 목록 939개의 쌍 441,330개 전부에서 두 구현이 배치 0을 냈다.

**정리 Z-B3 (κ₂(210) ≤ 2).** 직선 2 값 ≥ 210이며 서로 행이 겹치지 않는 원시 부분은 많아야 둘이다.
* 증명: 쌍 판정(배치 154개, 두 구현이 쌍마다 같음) + 삼중 판정 두 구현(비트셋, 합집합을 의사 사슬로 넣은 disjoint_z) 모두 0.

**덮개 전체의 따름(증명).**
* 기호 일관성: 덮개 안에서 서로 행이 겹치지 않는 높은 부분(θ₁ ≥ 44 또는 θ₂ ≥ 210)의 모임은 첫 도달 접두가 모두 같은 기호를 쓴다. 쌍마다 같은 기호이므로 모임 전체가 한 기호를 공유한다. 이것이 쌍 판정에서 나오는 덮개 전체의 명제이다.
* 긴 효율 사슬의 공존: 경우 B의 긴 사슬(r ≥ 764는 반드시 경우 B)은 서로 겹치지 않는 원시 부분 둘을 품는다. 그래서 κ₂(210) ≤ 2에서 **v₂ ≥ 210인 경우 B 사슬은 덮개 전체에 많아야 하나**이고, 그런 사슬이 있으면 다른 사슬은 v₂ ≥ 210인 원시 부분을 갖지 못한다. 배낭에서는 Round X가 준비해 둔 두 단계 형식(U0, U1, U1e, U2, U2e: Σν₂ ≤ 2, 예외 사슬 ≤ 1)으로 들어간다(§F).

## C. 기호 다양성의 값

### C.1 값을 매긴 직선 (전수 계산)

## E. 완전 행 연속과 이음매의 용량

* **완전 행 연속의 전역 셈(정리 Z-E1, 증명).** 사슬 안의 완전 행 연속은 6행 이하이고, 6행 연속은 b/f 이음매나 사슬 시작 뒤에서 시작해 c/f 이음매나 사슬 끝에서 끝난다(Round Y R1–R3). 그래서 F₇ ≤ 5(P + n) + (6행 연속 수), 6행 연속 수 ≤ (b/f 이음매 수) + n이다.
* **6블록 행 보조정리의 전역 형태(정리 Z-E2, 증명, Lean `six_row_lemma`, `ends_or_next_to_true_le`).** **P6 ≤ M + E + 2L + 2n.** 6블록 행은 (i) d로 들어와 d로 나가 앞뒤 행이 한 2-순환에 있거나(S6), (ii) d가 아닌 이음매나 사슬 끝 옆에 있다. (i)과 e 이음매는 각 2-순환의 행들을 경로 순서로 늘어놓았을 때 이웃한 쌍(거리 1 또는 2)에 하나씩 대응하므로 둘을 합쳐 ≤ M이다. (ii)는 ≤ 2(L + E) + 2n이다.
* **실제 단어 확인(`rZ/src/word_lemma_check.py`)**: 세 46173 단어 모두 위반 0. P6 = 28–29(한계 145–147), 6블록 행은 모두 c 이음매 바로 다음 행이고, 6행 연속 12개는 모두 사슬 하나 전체(시작–끝)이다. 기호 변화는 56–57번이고 모두 c(r = 1 단어는 f 하나 더)이다. 값을 매긴 직선의 최댓값은 사슬당 24(r = 1 단어는 37) ≤ 56이다.
* 용량으로 보면: 6블록 행은 기호 변화나 쪼개짐에 묶이지만 5블록 행은 묶이지 않는다. 경계 덮개는 6블록 행 없이 7·5블록만으로도 셈을 만족한다(C.3, D).

## I. 완성 비용

(769, 0, 0)에서는 사슬 하나가 덮개 전체라서 보충할 부분이 비어 있다. "주 사슬 + 보충"으로 나눌 수 없으므로 사용자가 제안한 완성 문제는 이 칸에서 정의되지 않는다. 같은 생각을 보통 칸에 쓰면(높은 부분을 고정하고 나머지를 최소 비용으로 채우기), 고정할 대상은 A.2의 배치(예: θ₂ = 221의 165행 쌍 셋, θ₁ = 44의 6,794개)이다. 이번에는 완성 탐색을 하지 않았다.
